# Persistence Policy

## 永続化トリガー

通常の会話は GitHub の変更を発生させない。

以下のようなユーザーの明示指示を永続化トリガーとする。

- 「GitHubに投げろ」
- 「ここまでGitHub反映」
- 「これだけGitHubに投げろ」

「GitHubにはまだ投げるな」が指定された範囲は、後続の会話で内容が明確になっても、解除されるまで反映しない。

## 解釈と反映

会話上の一時的な推論、曖昧な同意、検討途中の仮説を、ユーザー指定の確定事項へ自動昇格させない。

GitHub 反映時には可能な限り次を区別する。

- USER-DIRECT: ユーザーが直接指定したもの
- DERIVED: 確定前提から導出されたもの
- ASSISTANT-PROPOSAL: AI 側の提案・仮説
- OPEN: 未解決
- SUPERSEDED: 後続判断で置換されたもの

## 修正

誤解釈が判明した場合は、履歴を消して「最初からそうだった」ことにはしない。
意味単位で修正し、必要なら supersede / revert を用いる。
