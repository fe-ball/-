# 共通原則

ここには、特定の世界線の固有設定ではなく、複数の仮想歴史シナリオで再利用する考え方を置く。

## 中核文書

- [Simulation Method](simulation-method.md) — 技術成立、量産、配備、運用、戦役効果を分離する。
- [Causality](causality.md) — 分岐原因、情報伝播、敵適応、後知恵の有無を扱う。
- [Authority / Evidence Status](evidence-status.md) — current authority、歴史時計、状態、出所を区別する。

## 最低限の共通原則

- 技術可能性、量産可能性、配備可能性、戦役効果を分離して扱う。
- 後知恵を持つ主体が存在しても、材料・工作・試験・訓練・物流等の物理的制約を消去しない。
- 後知恵を持つ主体が存在しないシナリオでは、後世の正解を当時の要求へ逆輸入しない。
- 国家・組織・人物の判断は、その時点で入手可能な情報と制度的制約から扱う。
- 単一兵器のカタログ性能だけで戦略結果を決めない。
- 史実アンカー、ユーザー指定、モデル導出、未確定仮説の出所を可能な限り区別する。
- 最新の日付や大きいversion番号だけで現行正本を決めない。

具体化は各シナリオで行い、共通化が妥当になった時点でここへ昇格する。
