# 仮想歴史総合

複数の仮想歴史シナリオを管理するための総合リポジトリ。

## 運用原則

- 通常の会話・検討は GitHub へ自動反映しない。
- ユーザーの明示指示「GitHubに投げろ」等を永続化トリガーとする。
- AI が導出した内容と、ユーザーが直接指定した内容を区別する。
- 未確定・提案・保留は、確定事項として扱わない。
- シナリオ固有の設定と、複数シナリオに共通する史観・シミュレーション原則を分離する。
- 誤解釈が後から判明した場合は履歴を隠さず、修正または supersede する。
