# BRANCH B — Surface Hull Difference Watchlist v001

- date: 2026-09-05
- status: canonical working watchlist
- purpose: 「史実艦名だから史実の同日性能」と自動処理しないための巡洋艦系警告表。

## A. すでに差が確定・暫定確定している項目

1. **最上型**：既存詳細監査あり。教師群/成熟群、損傷後機能保持差を持つ。
2. **北上/大井**：北上のみ40門実証。大井は通常軽巡。
3. **高雄型**：高雄/愛宕と摩耶/鳥海を同一改装状態として扱わない。1942-11の4艦同時雷撃射線は48。
4. **妙高型**：1939–41大改装はBranchの成熟した改装計算の影響を受け、実用速力・燃費・故障tail・DC/I-Oが史実同型より安定する。
5. **利根型**：新造段階から計算援用の残差還流が入り、主差は初期不具合tailと偵察cycle。
6. **旧5500t軽巡**：安定性工事後は概ね32kt級。竣工時36kt級として戦時計算しない。
7. **阿賀野/大淀**：新造艦なので改装艦より設計・艤装段階のBranch差が大きい。ただし兵器物理は別。

## B. 歴史上の後続改装を自動適用してはいけない項目

- **最上の航空巡洋艦化**：史実MI損傷が原因。Branch MIでは因果が違うため自動発生しない。
- **摩耶の1943–44大防空改装**：被害・修理dock・対空要求を再判定する。
- **五十鈴の防空/護衛巡洋艦化**：Solomons消耗・護衛需要の因果を再判定する。
- **北上/大井の高速輸送化**：Guadalcanal輸送需要を史実からコピーしない。
- **北上の回天母艦化**：回天成立・戦況閾値の別監査。
- **大淀の連合艦隊旗艦化**：E15K運用失敗、司令部需要、艦隊配置の因果を別監査。
- **1943–44 AA/電探増備**：個艦、入渠、機材供給、戦訓、時期で監査。カレンダーだけで一律追加しない。

## C. 二重計上禁止

- 艦級の「射撃I/O改善」を `TECH-GUNFIRE-SURFACE-1942-001` の命中率補正へ追加加算しない。
- 艦級の「魚雷較正」を九三式の信頼性/散布改善へ二重加算しない。
- 「電探用配線・電源余裕」を電探の探知距離・精度改善として扱わない。
- DC改善を装甲厚、HP、浸水無効化に変換しない。効くのは故障伝播・火災/浸水隔離・mission-killへの遷移tail。
- 計算援用による速力差は、基本的に計画値の再現性・船底/負荷状態での保持・機関信頼性。新しい最高速ボーナスではない。

## D. 個艦状態が艦級profileに優先

以下は常に艦級overlayより優先する。

1. 当該日までに実施済みの改装。
2. 搭載電探/高角砲/機銃の個艦日付。
3. 戦闘損傷と修復時計。
4. 機関不調・船底汚損・過積載。
5. 弾薬・魚雷・航空機の残量。
6. 乗員・司令部の経験と疲労。
7. 実際の所在・任務・燃料。

## E. 現在のNC夜戦で特に注意

- Atago/Takao = 16射線ずつ、Maya/Chokai = 8射線ずつ。
- Sendaiは旧5500t軽巡の約32kt級profile。新鋭35kt軽巡として扱わない。
- Type 21系電探があっても、Washington/South DakotaのSGレーダー射撃優位は残る。
- Branch側の利点は、砲雷撃解への収束、魚雷扇面管理、重複射撃低減、通信/I-O、損傷後の機能保持の「悪いtail低減」に主に出す。
