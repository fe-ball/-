## 1. User-fixed costing rule
英国側の対策は、当面 **gross / 満額** で計上する。整備重複・兼務・『本来ほかに使えなかった』等の割引はまだ行わない。ただし同一船体の同一日を二重請求しない。後段の世界資源監査で、英国が本当にこの請求を同時に払えるかを検査し、払えなければ対潜措置低下・他戦域からの引抜き・商船待機増などへ不足を押し出す。

## 2. WIO-1C tactical/traffic ruling
5–12 June の通常潜水艦撃沈12隻は Branch B でも維持する。

- 5 Jun: Atlantic Gulf / Melvin H. Baker / Johnstown — 対策実効化前。
- 6 Jun: Susak / Wilford — 対策開始直後だが、航路統制・哨戒密度が未成熟。
- 8 Jun: Christos Markettos / Agios Georgios IV / King Lud — 巡洋艦哨戒は始まっているが、独航船の曝露を消せず、潜水艦接触を逆転させる確認済みイベントもない。
- 11 Jun: Mahronda / Hellenic Trader — 10 Jun の evasive routing 承認後だが、すでに危険海域へ入った独航船を即時に消せない。
- 12 Jun: Clifton Hall / Supetar — 同上。通常商船の船団化は護衛不足で実行不能。

**中心裁定: 12 ships / 52,840 GRT. Branch delta through 18 Jun = 0 ships / 0 GRT.**

これは『英国対策が無効』という意味ではない。対策の効果発現が first group の撃沈列より遅く、主効果は 18 Jun 以後の第二段階へ移る。

## 3. Why Branch C does not pre-save these 12 ships
Branch Operation C では 5 Apr に Indomitable / Formidable を喪失しており英国の警戒心は史実以上でもよい。しかし、その警戒心は護衛艦・A/S 艦・通信統制能力を新造しない。史実司令部自身が Mozambique Channel 攻撃を予期していた一方、通常商船を船団化することは護衛不足から infeasible と判断している。

したがって Branch の追加警戒は、まず troop convoy / Queen Mary / fast ship など高価値標的へ集中させる。5–12 Jun に沈んだ独航貨物船を、4月の時点から一律に安全航路へ移していたことにはしない。

## 4. Branch carrier substitution
史実の対策命令には INDOMITABLE の投入余地があり、10–16 Jun に FROBISHER と行動した。Branch では INDOMITABLE は存在しない。

満額対策方針に従い、この response slot を無料で削除せず、**HERMES を 10–16 Jun の7 carrier-daysで投入**する。これはモデル裁定であり史実記録ではない。HERMES の探索・航空運用能力を INDOMITABLE と1:1同等には扱わないため、この代替だけで追加の潜水艦撃沈や商船救済は与えない。
