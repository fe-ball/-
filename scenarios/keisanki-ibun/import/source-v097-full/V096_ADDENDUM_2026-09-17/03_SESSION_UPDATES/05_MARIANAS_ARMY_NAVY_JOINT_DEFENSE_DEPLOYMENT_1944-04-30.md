# MARIANAS / PALAU ARMY-NAVY JOINT DEFENSE DEPLOYMENT — 1944-04-30

## 1. Why Army air enters

Feb22–23 Marianas raid shows that warning/plot can function yet fighter mass is insufficient. Therefore 24–25 Feb the Inner South Seas Joint Air Defense policy is formalized.

## 2. 59th Sentai — Ki-44-II

- Selected because it can provide immediate, mature interception without stripping China-west 22nd Sentai or Tokyo-defense 47th Sentai.
- Ferry: Formosa -> Luzon -> Palau -> Yap -> Tinian.
- Mar12–15 combat capable.
- late-Apr: physical31–33, ready24–28 center.
- main mission: short-warning interceptor against bomber/attack groups; not sustained F6F fighter-sweep duel.

## 3. 11th Sentai — Ki-84

- Formed/re-equipped using lessons from the 22nd Sentai China operational evaluation.
- 22nd Sentai stays in Hanzhong; do not cannibalize the Hump-pressure mission.
- Ferry: Home Islands -> Iwo -> Saipan in weather windows, with rescue staging.
- late-Mar first cell ready10–12.
- Apr10–15: physical29–33 / ready22–27.
- Ha-45 package moves with the unit: spare engines, specialty tools, dedicated engine team.

## 4. Joint command I/O

Not unified service command.

Navy plot provides:
- target/track number;
- sector;
- altitude band;
- bearing/range/heading;
- freshness/confidence.

Army liaison converts this to Army radio net. After contact, each sentai commander retains tactical control.

The aim is to reduce organizational translation delay, not erase Army-Navy rivalry.

## 5. Late-Apr Marianas air

- Navy fighters58–74 ready.
- Ki-44 24–28.
- Ki-84 22–27.

## 7. Palau

- 14th Division physically arrives by 18 Apr.
- Navy base/air/radar/port system remains separate but coordinated.
- exact tanks and island allocation OPEN.
- Peleliu/Babeldaob/Angaur distribution is the next ground-placement audit topic.

## 8. Fortification

By late Apr:
- mature dispersal/revetment/alternate C2/communications redundancy;
- first useful tunnel/mountain-store/reverse-slope works in service;
- not yet a fully continuous cave fortress.

Priority: Saipan > Tinian ~= Guam for Marianas. Palau accelerates sharply after 14th Division arrival.
