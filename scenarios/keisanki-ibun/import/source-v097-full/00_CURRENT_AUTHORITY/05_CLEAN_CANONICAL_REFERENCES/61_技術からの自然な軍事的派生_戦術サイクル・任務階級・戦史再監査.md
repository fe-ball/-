# 計算機異聞・技術からの自然な軍事的派生

本書は、計算機の存在から生じる技術変化が、当時の軍人・技術者・部隊の試験と経験を通じて**自然にどのような戦術・作戦上の変化へ派生するか**を扱う。

外部から後世の戦術思想を注入しない。必要条件は、当時の部隊が演習・試験・実戦から差を観測でき、その差を利用する動機があることである。

個別装備の性能は10～60の担当正本を優先する。本書は「その性能差が戦い方の質を変えるか」を横断判定する。

---

# 1. 質的変化の判定

技術差を次の四種類に分ける。

## A. 量的性能差

- 最高速。
- 航続。
- 上昇。
- 射程。
- 兵装量。

同じ任務・同じ戦術のまま効果量が変わる。

## B. 信頼性・再現性差

- 故障率。
- 可動率。
- 同型艦・量産機のばらつき。
- 投下・発射・着艦の再現性。

数字上は地味でも、予定どおり戦力を揃えられる確率を変える。

## C. 任務階級を変える差

従来は任務不適または偶発的にしかできなかった装備が、別の任務を通常任務として担える。

例：航空機輸送艦が限定的な攻略支援空母として使える。

## D. 戦術サイクルを変える差

従来の「一回やって終わり」が、反復・接触維持・時間差投入等の閉じたサイクルへ変わる。

例：魚雷第一斉射後、再装填して第二斉射を同一夜戦内に予定する。

### 質的変化と判定する条件

次の一つ以上を満たす場合、歴史考察では「性能を数％上げる」だけで処理しない。

1. 従来は偶発的だった行動を予定行動にできる。
2. 一装備・一部隊の任務階級が変わる。
3. 一回攻撃が反復サイクルへ変わる。
4. 必要部隊単位が縮小し、編成・目標配分が変わる。
5. 敵へ継続的に別の行動を強制する。

## 1.1 技術利得の伝播パターン

技術上の改善が確認された場合、その利得を「戦力化した／しなかった」の二値で処理しない。少なくとも次の五類へ分けて、どこへ流れたかを追跡する。

### I. 閾値増幅

数％の改善が、沈没・戦闘不能・再攻撃可能時間・必要部隊単位・任務可否等の閾値を越え、戦術・作戦上は数％を大きく超える差になる。魚雷再装填、航空雷撃、着艦余裕等が代表である。

### II. 素直な戦力化

最高速、航続、命中、可動率、故障率、整備時間、出撃可能機数等へ概ね連続的に伝播する。小利得であっても、そのまま小利得として記帳する。

### III. 吸収・再投資

得られた余裕が別の性能、構造余裕、装備、燃料、防御、寿命、製造公差へ使われ、元の指標には現れない。これは利得の消滅ではない。何へ再投資されたかを記す。

### IV. ボトルネック減衰・時間窓外化

要求、生産設備、発動機、材料、教育、母艦、補給等が律速し、当該作戦期の前線兵力数・制式化日・出撃数をほとんど動かさない場合がある。それでも、試験収束、歩留まり、予備品、整備負担、教育事故、後続型、翌期の配備等へ利得が残っていないか確認する。

「1942年9月には主力として現れない」と「技術改善が無価値である」は同義ではない。

### V. 相殺・敵側適応

自軍の改善が、敵の警戒、回避、分散、防御、戦術学習等を誘発し、最終戦果では小さく見える場合がある。この場合も、自軍利得と敵適応を別々に記帳し、最初から相殺済みのゼロ効果として扱わない。
\n### VI. 人員循環・組織撹拌\n\n技術・制度改善が、個々の部隊性能より先に**人員がどこへ移動するか**を変える場合がある。戦傷後送、修理艦航空隊、補充機受領、新編隊、空地分離、専任空輸等が代表である。\n\nこの場合、効果を「熟練者数が増えた」とだけ扱わない。\n\n- 経験者が別部隊へ接触する回数。\n- 新編隊が経験核なしで前線へ出る確率。\n- 部隊間の手順差・練度分散。\n- 艦上/陸上/夜間/航法等の任務資格の適合。\n\nへ伝播させる。平均性能が同じでも、下側の極端な低練度部隊が減ると、多部隊協同作戦の成功率は非線形に上がり得る。海軍航空の現行詳細は46を正本とする。\n
したがって歴史考察では、各技術差について

> 技術利得 → 実装 → 配備 → 部隊使用 → 敵適応 → 戦果

のどの段階で増幅・吸収・減衰・相殺されたかを明示する。

# 2. 1941～42年に成立する主要な質的変化

## 2.1 水雷戦――第二斉射を予定できる

担当：31。

再装填装置の最良値を縮めるのではなく、長時間故障側を削る。第一線艦で魚雷再装填6～9分級、発射から第二射撃解・再発射まで12～20分級が中心となる。

これにより、

- 一斉射即離脱。
- 再装填後再突入。
- 複数駆逐隊の時間差投入。

が演習・作戦計画へ入る。

質的効果は「魚雷火力二倍」ではなく、**20～60分の夜戦で次発魚雷を戦闘火力へ変換できる確率が高まること**である。

敵側も第二斉射を警戒すれば不規則変針を長く続ける必要があり、砲術の安定追尾にも負担を与える。

## 2.2 航空攻撃――必要攻撃隊単位の縮小

担当：50・52。

航空雷撃、対運動艦急降下爆撃は、同一条件で実戦命中率が相対10～25％向上する中心値を持つ。

この差を「同じ36機で命中が少し増える」とだけ扱わない。

空母・戦艦等には、

- 飛行甲板使用不能。
- 速力低下。
- 浸水限界。
- 火災・弾薬誘爆。

という損害閾値がある。

したがって再監査では、

> **一艦を高確率で戦闘不能にするために必要な艦爆・艦攻数が何機か**

を求める。

もし36機が30機で同じ損害確率を得られるなら、余った6機は単なる余剰ではない。

- 第二目標へ分ける。
- 第二波へ保持する。
- 索敵・CAPへ回す。
- 第一波全損時の予備へする。

という編制差へ変わる。

これは真珠湾、MO、MI等を大きく動かし得るため、歴史考察へ必ず伝播させる。

## 2.3 艦艇ASW――接触保持と反復攻撃

担当：41。

史実前半型の単艦爆雷は、攻撃艦が潜水艦直上へ入ると探信接触を失う。

本世界では、

- A艦：接触維持。
- B艦：爆雷攻撃。
- A艦が再捕捉。
- 必要なら役割交代。

を標準化する。

船団では全護衛艦が一潜水艦を追わず、1～2隻を攻撃へ分離し、残りは船団へ残す。

これは探信距離10％増という量的改善ではなく、

> **発見→攻撃→接触喪失→再探索**

から、

> **発見→接触保持→攻撃→即再捕捉→反復攻撃**

へ時間構造が変わる質的差である。

ただし1942年には護衛艦レーダー、前方投射兵器、東海・カ号の本格体系がないため、夜間浮上潜水艦の広域発見等の穴は残る。

## 2.4 軽・改装空母――任務階級越え

担当：60。

艦載機側の失速、加速、重量管理、甲板処理、整備が改善すると、低速・軽量空母の物理的限界は残しながらも任務階級が一段上がる場合がある。

- 航空機輸送艦→限定護衛・攻略支援空母。
- 軽空母→小型艦隊空母。
- 改装商船空母→低速中型艦隊空母。

最大の効果は機数ではなく、**正規空母を使わず航空支援できる作戦正面が増えること**である。

これにより、決戦空母、攻略支援空母、船団航空甲板という役割分化が史実より早く進む。

## 2.5 揚陸――第一波を諸兵科パッケージ化

担当：60。

第一日総揚陸15～25％増、重装備揚陸15～25％増、積載・海岸間違い20～35％減、上陸後戦闘準備2～8時間短縮という差は、単純な「兵員が多く上がる」だけではない。

演習・実戦で差が観測されれば、積載計画は、

- 歩兵だけを大量に浜へ出す。

から、

- 歩兵大隊。
- 砲。
- 弾薬。
- 通信。
- 工兵資材。
- 車両・牽引具。

を同じ浜・同じ時間帯へ揚げ、**数時間以内に一つの戦闘単位へする**方向へ寄る。

したがって上陸戦の再監査では「上陸兵員数」だけでなく、何時に何門の砲・何台の車両・何日分の弾薬が戦闘可能になったかを見る。

## 2.6 多層索敵・再捜索――一回索敵から継続接触へ

担当：50・52・水上機系。

1941年開戦時から完全完成ではない。

- 1941年：機体可動率、航法、索敵計画の改善。
- 1942年春：D4Y、B5N、水偵等の役割分担が増える。
- MI戦訓後：夜明け広域索敵＋午後再捜索、接触疑いへの再確認を教程化。

質的な閾値は、

> 朝一回探して見つからなければ終わり

から、

> 広域索敵→接触疑い→再捜索→高速機で確認→追尾→午後位置更新

へ移るところである。

これは1942年中に成熟するが、開戦初日から完成済みとしては扱わない。

# 3. 1942年にはまだ質的転換へ達しないもの

## 3.1 レーダー

レーダーは粗い探知だけでも重要である。暗夜・雲・雨で「何かいる」を得られることは、光学にはない能力である。

しかし1942年段階では、少なくとも日本側は、

> 電探員読取→伝送→作図→光学照合→射撃指揮

という段階にあり、直接自動照準ではない。

米側でも、レーダー探知が即座に、

- 艦種識別。
- 正確な目標運動。
- 完全なCAP誘導。
- 必中の砲撃。

へ変わるとはしない。

したがって1942年は、

**視界外警戒・早期警告という新しい入力を既存の人間・光学・射撃指揮へ足す段階**であり、艦隊戦術全体をレーダー中心へ組み替える閉ループにはまだ達していない。

質的転換は、探知→航跡化→複数目標管理→戦闘機誘導／射撃指揮が一つの系として成立する1943年以後を主に見る。

## 3.2 通常艦砲射撃

30の中心では、通常昼間水上射撃の総合命中率は相対2～5％向上、初回夾叉まで5～10％短縮。

強い改善だが、

> 斉射→観測→修正→効力射

という戦術サイクル自体は変わらない。

1942年段階では主に既存砲術の高信頼化・収束短縮として扱う。

## 3.3 水上艦の最高速

多くの艦で最高速差そのものは小さい。しかし、

- 満載。
- 船底汚損。
- 数日間の連続行動。
- 機関酷使。

でも予定速力を出せる確率が高い。

これは作戦予定の実現率を大きく変えるが、それだけで新しい戦術形式を生むとは限らない。

一方、魚雷再装填・夜間再突入等と結びつく場合は質的変化の成立条件を支える。

# 4. 1942末～43年以降の質的変化候補

## 4.1 潜高系列――水中逃避から水中機動へ

担当：20。

第一世代潜高が水中18.5～19ktを60～70分級維持できるなら、従来潜水艦の、

> 水上で射点を作る→潜航して攻撃→水中は逃避

から、

> 潜航状態で射点へ移る→側面へ回る→接触を維持する

という新しい運動が可能になる。

数が揃うのは1943年以後が中心で、1941～42年主要会戦へ大量投入しない。

## 4.2 東海・カ号・護衛艦――接触情報を引き継ぐ層状ASW

担当：40・41。

- 東海：広域探索。
- カ号：船団近傍で接触維持。
- 磁探：位置確定。
- 固定翼／護衛艦：攻撃。
- 船団・基地指揮：情報統合。

の役割分担が成立すると、

> 見つけた機体が自分で仕留める

から、

> **接触情報を失わず別の攻撃役へ渡す**

へ変わる。

これは明確な質的変化だが、東海・カ号の中心時計は1942試験、1943実用であり、真珠湾・MO・MIには遡及させない。

## 4.3 レーダー閉ループ

1943年以後、レーダー距離、光学方位、航跡予測、複数目標管理、戦闘機誘導・射撃指揮が一つの情報系へ近づくと、レーダーは「粗い早期警告」から戦術の中心へ移る。

この転換は30で装備時計を監査し、本書では成立時期だけを横断管理する。

# 5. 戦史再監査の規約

80～84の太平洋開戦後の戦況・損耗は、2026年8月9日時点までの技術入力で組んだ作業史線である。

魚雷・航空命中・再装填等の非線形効果を十分に伝播していなかったため、**1941年12月以後の戦果は現行正本結果として固定しない**。

80～84は次の用途で保持する。

- どの作戦案・政治判断を考えたか。
- 史実比較でどこを問題にしたか。
- 戦力配置・補給・米側反応をどう考えたか。
- 再走査時に検証すべき分岐点。

## 5.1 再監査の順序

1. 真珠湾。
2. マレー沖。
3. フィリピン～蘭印航空・水上戦。
4. 初期潜水艦戦。
5. MO。
6. MI。
7. AL・FS。
8. 中国・インド洋・連合輸送への二次波及。

後段は前段の損害・生残艦・搭乗員・修理時計を引き継いで再計算する。

## 5.2 戦闘を平均値だけで処理しない

命中率や故障率の相対改善が小さくても、戦果には閾値がある。

再監査では、

- 命中期待値。
- 3本以上、4本以上等の閾値超過確率。
- 航空運用停止。
- 速力低下。
- 沈没／曳航／修理日数。
- 生残搭乗員。
- 次作戦参加可否。

へ変換する。

## 5.3 敵側の学習を入れる

初期戦果が変われば敵も同じ行動を続けるとは限らない。

例：

- 日本魚雷第二斉射が実戦で確認されれば、米側は発射後も長く不規則変針を続ける。
- 航空雷撃が明確に強ければCAP配分・対空隊形・雷撃機優先迎撃が変わる。
- 日本の多層索敵が成功すれば米側は無線・欺瞞・接近経路を変える。

この反作用を入れず、日本側の初期利得だけを雪だるま式に累積しない。

# 7. 更新規約

新しい技術値を正本へ追加する際は、数値表だけで終わらせず、次を確認する。

1. その差は同じ任務の効率向上だけか。
2. 偶発的行動が予定行動になる閾値を越えるか。
3. 一部隊の必要規模が変わるか。
4. 次の攻撃・再出撃までの時間が戦闘中に収まるか。
5. 任務階級をまたぐか。
6. 敵に継続的な別行動を強制するか。
7. その変化は当時の演習・試験・実戦から当事者が自然に発見できるか。
8. 技術時計・要求時計・生産時計・部隊時計のどこで成立するか。

一つでも質的閾値を越える場合、担当技術正本から本書へリンクし、歴史再監査項目に追加する。


# 8. 2026年8月13日更新――「存在する戦力を任務へ変換する」規約

戦術サイクルの技術設定が存在しても、歴史考察側で該当艦艇を護衛・背景戦力に固定すると、設定上の利得は実戦へ伝播しない。これは「敵の都合で利得が相殺された」のではなく、モデル側の脱落である。

以後、各主要作戦では次の順に艦艇を処理する。

1. **Hull ledger**：その日付に存在し、修理・訓練を終えた艦を列挙。
2. **Availability**：燃料、弾薬、乗員、整備、速力、泊地、航続で使用可能率を判定。
3. **Mission set**：護衛、前衛、夜戦、邀撃、砲撃、輸送船団突入、索敵、対空、対潜等を列挙。
4. **Mission coefficient**：設計・射撃・I/O・電探・損害制御・水雷戦等の利得を62で統合。
5. **Enemy anticipation**：敵が存在・性能・戦術をどこまで把握しているかを別勘定。
6. **Allocation**：最も価値の高い任務へ割り当てる。割り当てない理由を記録。
7. **戦闘後**：被害だけでなく、敵に強制したCAP、battle line拘束、変針、掃海、ASW、護衛分散等も戦果へ入れる。

### 8.1 雑な倍率計算の扱い

設計利得1.1、射撃1.1、レーダー1.1、防御1.1を単純に掛けて「1.46倍」とする方法は、そのまま正本値にはしない。ただし、複数の小改善が連続条件の成功確率へ積で効き、総体として大きな任務差へなることを見落とさないための**診断用上限・警報**として有効である。

したがって、最終値は個別イベント確率・時間・稼働率へ戻して判定するが、「各改善が小さいから艦全体も10％しか違わない」という逆の誤りも禁止する。

### 8.2 大規模海戦とレーダー差

双方が敵主力の存在・大まかな海域を知る大規模海戦では、レーダー差を「発見できる／できない」の二値へしない。

- 薄明・夜間・スコール越しに何分早く接触するか。
- 艦種・針路・速度を何分早く安定推定するか。
- 射撃・魚雷回避・CAP誘導へ何分早く入力できるか。
- 煙・混戦で光学追尾を失った後に何分で復帰するか。

へ変換する。水上砲戦では日本側光学・射撃盤・計算補助が差を一部取り返し得る。艦隊防空では米側レーダー、戦闘機指揮、VT信管、5in/38大量配備の閉ループ優位を大きく残す。

# 9. 戦史再監査v3の発動

85～88で再走査した1942～43年史線は保持する。89の1943年12月～1944年6月10日も、Marshall・Truk・Eniwetok・Palau等で日本主力水上艦隊を投入しない理由が成立しているため、結果の中心線を保持する。

一方、Marianas決戦準備は水上艦隊の価値が作戦目的そのものへ入る。したがって**1944年6月10日を安全な継続点とし、それ以後を戦史再監査v3として再走査する。**

再走査では、

- 米軍は日本主力艦隊がMarianasへ出ることを高確率で予想している。
- 金剛型等既知艦級、大型脱条約戦艦の存在も概ね認識している。
- ただし日本艦の1944年型射撃・I/O・損害制御・再装填・対空の体系能力を割り引いている可能性がある。

## 2026年8月13日追加――設計学習・編成下限・損傷状態遷移

### 設計学習の閉ループ

1934年以後の海軍計算援用は、難しい式を解くことだけでなく、**設計予測→工場試験→公試実測→残差分類→次艦／次回改装へ戻す**閉ループとして扱う。第四艦隊事件後は、計算結果だけでなく「実艦で何が当たり、何が外れたか」を保存する制度を強める。

分野ごとに検証度を持つ。

- 未検証：計算値は参考。史実同等以上の余裕を維持。
- 単艦確認：補正係数へ使うが、安全余裕は大きく詰めない。
- 姉妹艦再現：局部的に設計余裕を詰めてよい。
- 複数艦成熟：標準設計値・整備規則へ昇格可能。

安全率を一律に削るのではなく、**予測誤差のために積んでいた余裕だけを、検証済み分野で縮める**。極端波浪、爆発、戦闘損傷等の未検証現象へ定常計算の成功を外挿しない。

### 複数艦編成では最低性能艦が効く

複数艦で一個任務を行う場合、平均性能ではなく、最も遅い艦・故障した艦・燃料余裕の少ない艦が部隊全体を拘束する。したがって同型艦の燃費・速力・故障・射撃I/Oの**ばらつき縮小は、個艦平均値改善以上の部隊任務成立率**を持ち得る。

この効果を単純な独立確率の積へ固定しない。海況、燃料品質、整備状態、共通設計欠陥等の共通原因を先に条件として置き、その条件下で各艦が要求性能を満たすかを見る。

### 防御は損傷状態遷移で扱う

装甲、防御区画、配電、消防、排水、操舵、損害制御を一個の「防御力倍率」へ潰さない。基本状態は次を使う。

**健全 → 局部損傷 → 機能低下 → 任務不能 → 航行不能 → 喪失**

計算援用による区画・電路・配管・注排水・局部支持改善は、主として中央の遷移確率を下げる。主装甲貫通、弾薬庫破壊、設計防御能力を大きく超える複数魚雷等では効果を小さくする。

また「被害後に射撃を続けられる」「負傷艦が自力離脱できる」は、防御と攻撃へ別々に倍率を掛けず、**中程度損傷後の任務機能保持**という一個の事象として扱う。

### 将来成長余地は option value として扱う

未搭載の装備を開戦時戦力へ加算しない。一方、重量、KG、電力、配線、空間、弾薬庫転換性、射界を準備しておくことで、戦訓後の改装に必要な工期・工廠占有を減らせる場合は、**将来選択肢の価値**として戦略評価へ入れる。

大和型翼側15.5cm砲塔の将来撤去・高角砲換装は代表例である。1937年に将来の航空戦を知って高角砲を先積みするのではなく、兵装転換の難所だけを事前に処理する。

### 反復兵器の火力は変換確率で評価する

次発魚雷、第二波航空隊、再攻撃可能な潜水艦等は、保有弾数を初撃へ単純加算しない。**戦闘時間内に次の有効攻撃機会へ変換できる確率**で評価する。陽炎・夕雲型の次発魚雷は0/4/8本状態を基本とし、再装填・再接触・指揮維持を満たして初めて第二波火力になる。

# 2026年8月14日追加――戦術研究・組織学習層

44を新たな正本入力とする。

従来61は「技術差が自然に戦術差へ達する」ことを扱ったが、**生残する艦・指揮官・航空隊そのものが研究母集団を増やす効果**を明示していなかった。

今後は各戦役で、技術差に加えて以下を監査する。

1. 同種実艦を何隻使って比較演習できるか。
2. 前戦の指揮官・参謀・飛行長・整備長がどれだけ生存しているか。
3. 次戦までに連続何週間の訓練を確保できるか。
4. 戦訓を口伝でなく諸表・教範・訓練課目へ落とせるか。
5. その標準化が艦隊全体へ伝播する前に緊急出撃で中断されないか。

史実後期に確認される成功例は未来知識として遡及適用しない。ただし、当時の物理能力・操艦技術で成立可能だったことの証拠として使い、本世界の演習・過去実戦から同型の手順が早期発見され得るかを判定する。


# 2026年8月14日追加――運用制度と敵システム対抗の監査

45を正本入力に追加する。技術差・戦術学習が成立しても、部隊編制が基地・艦へ固定され、戦力の集散離合に数日を要するなら、作戦時計へ十分伝播しない。以後、航空戦力は次を別に監査する。

1. **Platform availability**：艦・基地が使えるか。
2. **Air unit availability**：飛行隊・搭乗員・直接整備が使えるか。
3. **Host compatibility**：別空母・別基地が燃料、弾薬、工具、通信、着艦等を受け入れられるか。
4. **Transfer time**：飛行戦力を別拠点へ移して即応するまでの時間。
5. **Counter-system doctrine**：敵の探知→CAP→AA→回避のどの段階を攻撃側が過負荷へ追い込む計画を持つか。

これにより `艦を失った＝航空隊を失った`、`基地を叩いた＝その方面の飛行隊が消えた`、`対空火力が強い＝各波が同じ割合で落ちる` という単純化を禁止する。

敵防空破綻は恒常的な防御力低下ではなく、特定の数分間・方位・高度に生じる一時状態として扱う。成功した場合だけ終末攻撃へ到達する機数が非線形に増え得る。
