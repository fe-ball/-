# 15. Tank fortification changes

The Branch tank-defense system should no longer be represented as only:
> “tank dug into one pit at the beach”

The preferred system is a **mobile armored cell**.

## A. protected waiting positions
- 1–3 tanks per revetted/camouflaged pocket;
- blast separation;
- overhead camouflage/light splinter protection where practical;
- away from the visible waterline;
- nearby fuel/ammunition kept divided.

Purpose:
survive naval/air preparation.

## B. prepared firing bays
Each important tank section/platoon receives multiple possible firing positions where terrain permits.

Features:
- hull-defilade / partial excavation;
- pre-measured arcs;
- flank shot into beach exits / road cuts / tank lanes;
- camouflage until firing;
- reverse exit or ramp.

The tank is **not permanently entombed** unless mobility has already been lost or terrain makes movement useless.

## C. short concealed movement routes
- vegetation/cut/terrain masking;
- reverse-slope road;
- night-marked routes;
- alternate assembly points;
- repair/recovery access.

Typical use:
fire several rounds / expose position → withdraw → reappear from another bay.

## D. false positions
- empty tank pits;
- dummy tracks/revetments;
- decoy fuel/maintenance signs.

Purpose:
consume U.S. air/naval/fire-support attention.

# 17. Saipan armored-defense geometry

Saipan has limited maneuver room but enough road/terrain complexity for a real local reserve.

By Apr 25 tank-related construction should prioritize:

1. several dispersed reserve pockets inland from likely landing sectors;
2. prepared firing bays covering:
   - beach exits;
   - road junctions;
   - valley/choke approaches;
3. concealed connecting tracks;
4. tank recovery/workshop pockets with spare track/running-gear material;
5. mine/AT-gun lanes tied to Shinhoto firing geometry;
6. alternate nighttime assembly points.

Do not place all 50+ 9th-Regiment tanks into one mass reserve park.

A likely organizational model:
- several **4–8-tank local packets**;
- a larger regimental reserve retained behind the most probable landing sector;
- medium vehicles weighted toward prepared anti-tank lanes;
- Type 95 packets cover secondary sectors / night movement.

# 22. Recovery / “reappearance”

Branch tanks are more reliable and repairable, not better armored.

On suitable mobile fronts, repairable vehicles can reappear faster.

On bombarded islands:
- use the lower local benefit band;
- wreck access, naval gunfire, burned vehicles and lost workshops dominate.

A tank mission-killed by:
- track;
- clutch;
- running gear

may reappear in 24–72h if recovered.

A tank:
- burned;
- penetrated catastrophically;
- abandoned behind U.S. lines;
- hit by heavy naval/artillery fire

does not come back through process quality.

# 24. Current interpretation

By 25 Apr the Branch Japanese island armor system is no longer doctrinally:
> “save tanks for one glorious counterattack.”

It is:
> **survive bombardment → channel U.S. armor → expose a small number of tanks from prepared positions → displace → repair/reappear → commit only a bounded reserve when the local tactical payoff is real.**

This does not create Sherman parity.

It turns Japanese tanks from a one-shot casualty pool into a more persistent **mobile direct-fire / anti-engineer / local-countermove system**.
