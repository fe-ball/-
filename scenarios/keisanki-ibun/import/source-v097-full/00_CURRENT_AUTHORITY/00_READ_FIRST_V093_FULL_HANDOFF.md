## 2. v093の主要確定事項

### Santo
- 1942-07-29のSanto主要基地群の作戦的陥落を **14:30前後中心**へ再実行。
- 旧17:30級は参照解へ格下げ。
- 29日24時の連合軍内陸残存は約700〜900、中心800。

- Santoは単純な固定OOBではなく、**Rabaul -> Halavo/Tulagi -> Santo**の前進航空物流ノードとして扱う。

### New Caledonia
- 7/30に日本は **GO-PREPARE**。Fiji/Samoa自動継続は禁止のまま。
- 米1st Marine Division/Watchtower系船団はGuadalcanalへ行かずNCへ振替。Americal等と合わせて8月末NC地上防御は40k超級へ増大。

- 主軸Boulouparis/Baie de Saint-Vincent、第二軸Ouano/La Foa。
- Tontoutaは **9/6夕刻** 日本占領中心。
- Nouméaは **9/14午前〜昼** 作戦的陥落中心。
- 島全体の掃討完了ではない。東〜南東部へ米残存軍12〜16k級が退却し、その後軽歩兵化・縮小。

### 9/7–8 第二次水上介入
- South DakotaはTonga出港時の座礁を維持し、9/7–8 NC戦へは不参加。
- 米中心：North Carolina + Minneapolis + New Orleans + San Juan + Juneau + DD8〜9。
- 日本夜戦中心：Kongo + Kirishima + Atago + Takao + Maya + DD6。Haruna/他CAは後詰め・近接支援、Hieiは第一夜損傷後の後方重支援。

### Efate
- 9月後半〜10月は占領せず、**pulse suppression**。
- 9/20〜10/20第一期の作業中心：
  - 本格攻撃7〜9回、武装偵察/掃討8〜14回、警報のみ5〜10回。
  - Santo+Tontouta二方向攻撃は一回最大効果、以後米側学習で効果低下。
  - 日本零戦不可逆6〜9、陸攻2〜4。

- 10月後半以後は攻撃密度を下げ、Efateを「米資源を吸う前哨基地」として生かしつつ抑圧する。

## 3. 猿ガッソー要素の現在位置

ここでいう猿ガッソーは、史実Guadalcanal/Eastern Solomons/Santa Cruz等で消えるはずだった
艦艇・航空機・搭乗員・整備能力・陸軍予備が、Branchでその戦闘系列がないため残る効果をいう。

禁止：
- 一律の可動率/命中率/生産倍率へ変換しない。
- 史実損失を「ボーナス機数」として二重加算しない。
- Branchで実際にNC/Efate等で払った損失は必ず引く。

1942-11-20頃：
- 日本：龍驤、比叡、霧島、Guadalcanalで史実喪失するCA/DDの相当部分が残る。
- 艦載/基地航空の中堅搭乗員層も史実より厚いが、NC/Efateで一部を消費済み。
- 陸軍でも史実南東方面へ吸われる第6/41/51/20師団級の戦略的深みを維持。
- 米側もGuadalcanalで失う艦艇・航空要員の一部が残るため、猿ガッソーは日本専用ではない。

## 6. 二線/軽/補助空母についてのv093運用裁定

「弱いから守る」だけにしない。

- Junyo/Hiyo：25kt級の大型第二梯団。CAP relief、第二撃、回収、船団攻撃。第一線高速boxの常時同速運動は避ける。
- Ryujo：快速小甲板。fighter-heavy CAP relay、索敵、小規模打撃、緊急回収。大編隊同時発着・荒天連続運用は不得手。
- Zuiho/Shoho：28kt・30機級。CAP、索敵、小雷撃隊、第二撃、地域/船団航空予備。
- Ryuho：竣工直後はwork-up/訓練/フェリー/回収。成熟前に第一線へ数えない。
- Taiyo/Unyo/Chuyo：21kt級。航空機輸送、船団CAP/ASW、搭乗員輸送、後方回収。決戦機動部隊へ入れない。
- Hosho：着艦訓練・資格維持・work-up。

搭乗員品質は艦格と自動連動しない。小型艦でも選抜隊なら攻撃隊の質は第一線級になり得る。制約は甲板処理・海況・艦速・回収容量。
