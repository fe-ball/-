# Branch B v090 — Supersession Map
## Aleutians re-audit / 1943-11-05 global overlay

### HARD OVERRIDES

1. **Legacy Aleutians settlement**
   - `ALEUTIANS_ATTU_KISKA_REAUDIT_1943-03_07_SETTLEMENT_v001.md` is provenance/reference only.
   - It may be used for comparison, but not as current Attu/Kiska outcome authority.

2. **North-Pacific logistics method**
   - Replace “late emergency supply only” models with the v090 continuous system:
     `1942 autumn strategic allocation -> Kiska/Attu bulk landing -> Semichi/Amchitka satellite activity -> Crowbar response -> Feb/Mar blockade adaptation -> LANDCRAB`.
   - Count **effective landed construction cycles**, not simply ship arrivals.

3. **Weather / seakeeping doctrine**
   - No magical local-forecast certainty.
   - No hull-shape rewrite.
   - Branch advantage enters through machinery reliability, navigation, convoy cohesion, better synoptic weather judgment, unloading-window selection, abort timing, and recovery/restart speed.
   - Carrier aviation limits remain stricter than carrier navigation limits, especially for Ryujo.

4. **Attu May-1943 OOB**
   - Current local center uses the v090 weapon/airfield/sensor snapshot.
   - The old “almost no land fighter / only a few float fighters” center is superseded.

5. **Carrier-air skill treatment**
   - Do not impose a blanket “second-line carrier = second-rate attack accuracy” penalty.
   - Branch carrier-air cellularization, pilot rotation, and the avoided South-East-Pacific aircrew bleed preserve selected strike-team quality.
   - Apply penalties through deck cycle, carrier-specific aircraft compatibility, weather recovery, and unit transition/new-airframe readiness instead.

6. **LANDCRAB local chronology**
   - U.S. invasion remains 1943-05-11.
   - Current center is settled only through 1943-05-20 evening.
   - Night 20/21 May and later outcome remain OPEN.

### DEPENDENCY OVERRIDES

- Existing 1943-08 Midway, 1943-09 Gilbert, and 1943-10 Wake settlements are **not allowed to constrain the Attu outcome backwards**.
- If the open Attu continuation causes material carrier/hull/aircrew loss, downstream Pacific OOB and raid settlements must be re-audited.
- If the Attu continuation remains a local battle with modest naval loss, later Pacific settlements may be retained with explicit loss/tempo deltas.
