# Santo航空物流ノード規律
## 1942-08 -> NC / v093

Status: WORKING CLOSED LOGISTICS RULE

Santo航空は、飛行場にその瞬間存在する固定配備機だけで評価しない。

## 四層wallet
1. Fixed OOB — Santo所属の日常CAP/索敵/基地防空。
2. Forward replacement — Halavo/Tulagi–Santo間の短距離フェリー在庫。
3. Rear replacement — Rabaul/Kavieng等の次発補充。
4. Sea pipeline — 本土/Trukから二線空母・航空機運搬船・水上機母艦等で前方へ動く機体/発動機/部品。

後三層は同時MRではない。戦闘後の再生速度として使う。

## 1942年8月末NC準備 working center
- Santo固定零戦：26–30 assigned / 21–24 MR。
- 水戦：10–12 assigned / 8–9 ready。
- E13A/F1M：10–14 / 8–11 ready。
- Halavo前方補充：零戦中心8–12機級。
- Rabaul次発：8–12機級。
- 海上輸送：10–20機級ロットが周期的に存在。
- H6K/H8Kは任務ローテーション。
- G3M/G4Mは常時全数常駐でなく、必要時に前進。

## 主要フェリー線
本土/Truk -> 海送 -> Rabaul -> Halavo/Tulagi -> Santo。
小型単発機にRabaul-Santo直行を標準化しない。

## MR化の必要条件
交換機体だけでなく：
- qualified crew
- direct maintenance personnel
- fuel/oil
- ammunition
- drop tanks
- engine/propeller spares
- radio/oxygen/sight equipment
- host-base capacity
を支払う。

## 禁止
- fixed / forward / rear / sea-pipelineを二重加算しない。
- 機体補充を同数の熟練搭乗員へ変換しない。
- 二線空母を航空機輸送だけのため敵航空圏へ無理に前進させない。
- 猿ガッソーを一律の可動率ボーナスにしない。
