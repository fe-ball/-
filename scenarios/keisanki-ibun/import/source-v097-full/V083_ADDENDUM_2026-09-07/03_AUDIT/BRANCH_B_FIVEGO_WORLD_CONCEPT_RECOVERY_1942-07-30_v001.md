## 1. 五号の戦略目的 — 「重慶へ一直線」ではない

Branch Bの五号は、史実の四川作戦構想を母体とするが、計算・兵站文化の改善によって次を明示的に分離する。

1. **軍事的に西安・宝鶏・漢中へ到達可能か。**
2. **到達後の道路・鉄道・河川・駄馬輸送で攻勢を維持可能か。**
3. **その占領が重慶政権の政治的屈服につながるか。**

3は1・2より不確実であり、「西安を取れば中国降伏」等を兵站前提へ混ぜない。

中心目的は:
- 関中・漢中の鉄道/道路/飛行場/倉庫を奪う;
- 中国軍の有効予備、砲、車両、弾薬、通信を継続的に消耗・固定する;
- 四川を安全な奥地から前線隣接地域へ変える;
- 重慶側の財政・輸送・軍再建コストを上げる;
- 占領地の南京政権・現地行政へ静的任務を段階移管する;
- ただし秦嶺/巴山の兵站が限界なら、四川盆地深部へ自動追撃しない。

## 4. 作戦段階

### Phase I — 潼関 → 西安 → 宝鶏

北方10個師団級の主力で関中へ進む。

同時に宜昌方面6個師団級が西方圧力を掛け、中国軍の予備を拘束・分散する。

ここはFive-Goで戦車・自動車・鉄道支援の価値が最大になる区間:
- 平地/道路軸で機械的信頼性と回収能力が実際のtank-daysへ転換する;
- 装甲そのもの・砲威力は別物にならない;
- 歩兵、砲兵、工兵、橋梁と同期しなければ効果は頭打ち。

### Phase I logistics reset — 宝鶏

宝鶏到達を「そのまま秦嶺へ突入する通過点」にしない。

ここで:
- 鉄道/道路補修;
- 弾薬・燃料・食料の再集積;
- 車両修理;
- 橋梁資材;
- 駄馬・人力輸送への積み替え;
- 中国軍位置・破壊道路t/day;
を再計算する。

### Phase II — 秦嶺越え → 漢中

前進兵力は自然に **4–5個師団級**、最前線は **3–4個師団級**へ絞る。

戦車師団主力を山岳へ押し込まない。
- 中戦車主力は関中/宝鶏側の機動予備・道路警備・反撃阻止;
- 南へ入れるのは選抜軽戦車/中戦車小隊、tankette、工兵牽引車等のpacket;
- 価値は道路節点、固定陣地直射、工兵/車列護衛、短距離反撃。

主律速は戦車性能でなく、**道路t/day、橋梁、工兵、駄馬、天候、補給中継**。

### Phase III-A — 漢中からさらに圧力を掛ける場合

1942計画時点では **CONDITIONAL**。

回収された後続思考では、四川全土征服より先に **広元級の前進航空/物流節点**を狙う案が合理的とされた。

目的:
- 成都・重慶を「安全な奥地」から前線隣接空域へ変える;
- 偵察・迎撃・限定爆撃の前進点を得る;
- 中国軍5–7個師団相当を北四川防御へ固定し得る;
- Hump/航空援助の高価値貨物へ防空・修理・燃料税を掛ける。

しかしこれは **現在の実行決定ではない**。Hanzhong到達時に初めて審査する。

## 5. Branch技術差の具体的な使い方

### 車両/戦車
- reliability / dispatchability;
- repair return;
- recovery;
- spare-parts organization;
- production tolerance/QC。

効果は **同じ車体が予定日に何回戦闘へ出るか**。
砲/装甲をSherman級にしない。

後年のworking auditでは同一OOB・史実品質比でPhase Iのcombat-effective tank-daysが約116–128（史実品質=100）という帯を置いたが、同時に燃料+12–20%、戦車弾+15–25%、workshop/recovery load+25–45%を払う。これは「無料の戦力倍率」ではない。

### 砲兵
計算能力が直接効く場所:
- 射表;
- 気象/装薬補正;
- 測地/射撃諸元;
- 砲身摩耗;
- 弾薬lot管理;
- 修正射と弾薬浪費の低減。

砲兵大隊数は減らさない。perfect counterbattery / first-round magicは禁止。

### 鉄道・兵站
- 列車ダイヤ;
- 貨車回転;
- depot在庫;
- 車両整備;
- 橋梁/道路修理順序;
- workshop throughput;
- spare標準化;
- load plan。

Five-Goの技術配当は「名目要求を削る」より、**idle dayと予備在庫を減らして29–31万人級作戦を実際に同期させること**に出る。

## 6. 情報・政治の扱い

- 高: 自軍鉄道輸送、既知道路/橋梁/飛行場、中国軍大部隊概位置。
- 中: 中国師団実員。
- 中–低: 敵弾薬備蓄、破壊後道路容量。
- 低: 現地調達、士気、撤退時期、地方軍閥政治。
- 非常に低: 西安/漢中喪失が蒋政権崩壊へ直結する確率。

計算文化の最大効果は、**作戦可能性と政治的降伏予測を別変数にすること**。
