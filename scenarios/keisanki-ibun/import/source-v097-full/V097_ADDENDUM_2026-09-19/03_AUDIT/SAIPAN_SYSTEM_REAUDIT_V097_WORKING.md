# Saipan System Reaudit — v097 working overlay
## Clock remains 1944-04-30T24

## 1. Doctrinal state
Do not model Saipan as merely a stronger 1943 beach fortress.
Branch learning chain:
- Attu: terrain, reserve, logistics depth, repair/recovery, artillery repeatability.
- Santo/New Caledonia: large amphibious throughput, beach traffic control, heavy-support timing, second-echelon absorption, port recovery.
- Tarawa: limits of waterline-only strong defense.
- Marshalls: flat-atoll depth ceiling; need to hide from naval gunfire, not merely endure it.
- Marianas raids/HAILSTONE: decisive-belt priority and urgency.

Current interpretation:
**Peleliu-type depth-defense logic exists before historical Peleliu.**
This does not mean uniform D4 cave density or completed construction.

## 2. Heavy artillery interpretation
Branch should exploit earlier allocation, installation, survey, ammunition subdivision, alternate firing points and protected logistics before inventing new weapons.
Historical Saipan had meaningful numbers of heavy weapons physically present but not all installed/ready; Branch process gains can convert more of that physical stock into combat-ready batteries.
Exact final gun-by-gun Branch OOB remains OPEN and must be traced against production/donor cost.

## 3. Reception / “back door” system
Conceptual layers:
1. Tanapag / Garapan = primary heavy reception.
2. West/south supplementary handling = personnel, boxed ammunition, light vehicles and urgent stores.
3. East-coast emergency points = low-throughput high-priority night reception.
4. Saipan–Tinian short-range small-craft transfer = local rear/dispersal layer before U.S. sea control closes the channel.

Do NOT create a magical second deep-water port.
The value is graceful degradation after the primary port is hit.

## 4. Island internal logistics
Use roads as primary tactical circulation.
Existing narrow-gauge rail can move bulk, time-insensitive loads and release trucks for artillery towing, emergency ammunition, casualties and local reserve movement.
Stores should be subdivided by defense sector; do not keep island-wide ammunition at the waterfront.

## 5. Reinforcement absorption
New units should arrive with preassigned defense sectors / work packages.
Cross-load critical equipment so a single transport loss does not remove an entire specialist function.
The branch improvement is not teleportation; it is a shorter interval from physical arrival to useful combat integration.

## 6. Army–Navy integration
Do not create a fully unified service.
Retain separate administrative chains, but standardize combat I/O:
- common grids and target numbers;
- formatted reports;
- joint reception / unloading priorities;
- joint engineer priority table;
- emergency ammunition / transport release rules;
- air warning / plot handoff already established in current canon.

## 7. Invasion-time reinforcement
Mouse/small-craft reinforcement becomes easier because reception points, routes and assignment are prepared.
Large post-invasion reinforcement still requires a temporary break in U.S. sea/air control.
Forced large counterlanding is a conditional gate, not baseline capability.
