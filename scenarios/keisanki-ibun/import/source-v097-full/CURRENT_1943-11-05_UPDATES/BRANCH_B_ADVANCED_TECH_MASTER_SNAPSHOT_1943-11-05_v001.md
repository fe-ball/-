# Branch B 技術正本スナップショット
## 1943年11月5日 — 計算・EW・航空・潜水艦連絡・先端研究

**Status:** CURRENT WORKING MASTER SNAPSHOT  
**Clock:** 1943-11-05  
**Purpose:** 以後の戦史で「日本は何を既に持ち、何が限定配備で、何がまだ未来か」を固定する。特に米側/日本側の察知判定で、史実イベントや将来技術が勝手に這い戻ることを防ぐ。

---

# 0. 正本原則

Branch Bの「先端技術」は、未来兵器の大量前倒しではない。

中心は、

**計算 → 計測 → 公差/ロット管理 → 故障分類 → 情報I/O → 運用手順 → 部隊中央値**

の改善である。

したがって、

- 試作最高性能だけが上がるのではなく、量産中央値・即応率・故障復旧・情報鮮度が改善する。
- 一つの技術を全国一律倍率にしない。
- 「発明」「技術成立」「量産安定」「前線標準化」「局地配備」を別時計にする。
- ドイツ技術は、日本国内に無かった万能能力を一括移植するのではなく、国内研究で欠けていたカードを埋める。
- 技術が存在しても、その戦域・艦・基地・飛行隊に配備されていなければ戦闘には使わない。

# 1. 技術状態ラベル

## A — 広く実用
1943年11月に、該当する主要部隊で普通に戦史へ入れてよい。

## B — 選抜/優先部隊で実用
能力は成立しているが全軍一律ではない。A級基地・一部艦艇・一部潜水艦等だけ。

## C — 初期配備/部隊審査
実戦利用は可能だが数量が小さく、local allocation gateが必要。

## D — 試作/研究
試験設備では成立。戦闘OOBへ数えない。

## F — 将来物理ゲート
資料・実物・人員がまだ物理的に到達していない。未来情報を先取りしない。

# 2. 基盤技術 — この世界を変えている本体

## 2.1 計算機の普及【A】

1930年代から計算機を「一社一台の所有物」ではなく、

- 受託計算
- 使用権
- 中央計算所
- カード統計設備
- 設計案件ごとの共同利用

として広げた。

軍事的な主効果は、

- 航空/艦船/潜水艦の重量・重心・振動・熱・構造計算
- 射表・気象補正
- 光学設計・公差計算
- 発動機故障統計
- 生産ロット比較
- 輸送/倉庫/修理計画
- 暗号設計・鍵運用監査
- 通信交通分析

である。

**禁止:** 「日本軍全体が電子計算機でリアルタイム指揮されている」と解釈しない。

## 2.2 計測・品質管理【A】

Branchで非常に強い部分。

- 同型機/艦/装置の個体差縮小
- 不良ロットの早期特定
- 故障原因と交換部品の切り分け
- 工場/作業班/加工機別の不良統計
- 受入試験と較正
- 予防整備・修理復帰

が史実より早く体系化される。

そのため「当たり機は史実にもあった」が「普通の部隊機も試作性能へ近づく」に変わる。

# 3. 暗号・COMINT・情報処理

## 3.1 日本高級COMSEC【A】

1942年以後、日本海軍高級作戦暗号は、米側が史実JN-25相当のように

- 作戦地点
- 正確な日時
- 兵力構成

を短期戦略に使える精度で本文復元することを**通常は許さない**。

これはI-30由来ではなく国内技術線。

高級暗号の強さだけでなく、

- 鍵使用量監査
- 鍵重複検査
- 更新遅延検出
- 通信規律違反統計
- 呼出符号/周波数運用
- 鍵物流

まで含む。

**禁止:** 「米側は何も分からない」としない。

米側には依然として、

- 低級暗号
- 平文
- traffic analysis
- DF
- 偵察
- 基地/港湾活動
- 捕獲資料
- 運用ミス

が残る。

## 3.2 日本側COMINT【A/B】

日本側もSIGABA級最高級米暗号を恒常解読しない。

中心は、

- 低中級暗号
- 定型通信
- 交通分析
- DF
- 呼出符号/周波数
- 基地活動履歴
- 写真/気象/救難/港務通信

の統合。

1943年にはType 2P級処理によって、条件の揃ったM-209級/低級通信で**数日後ではなく数時間～1日**に短縮される局地窓があり得る。

ただし、
**GALVANIC、Tarawa、D-Day、空母数を最高級命令本文から直接読むことは禁止。**

## 3.3 情報の五段階

以後、必ず別にする。

1. 情報取得
2. 分析
3. 確信度
4. HQが採用
5. 現場が実行

「暗号係が気付いた」＝「艦隊が正しく動いた」ではない。

# 4. レーダー・EW・基地C2

## 4.1 1942型日本電探【A】

1942年の日本電探は、

**粗探知/早期警報 → 人間が作図 → 光学確認 → 射撃/邀撃**

というhuman-loop型。

警報としては有用だが、

- 艦種識別
- 安定track
- fighter direction
- 射撃解

まで自動的に成立しない。

## 4.2 1943年A級基地の閉ループ化【B】

1943Q2–Q3から優先基地では、

- 電探
- 目視哨
- DF
- 気象
- 作図
- 戦闘機待機段階
- 高射警報
- 帰投支援

を統合する**基地防空plot/control cell**が成立し始める。

米式GCI/CICと同格ではないが、

- CAPを常時全力で飛ばさず済む
- 燃料/発動機時間/疲労を減らす
- 警報時に雷電等を正しい高度へ上げる
- 第一波の地上撃破を減らす

という実用効果がある。

## 4.3 I-30由来 metric RWR【B】

I-30完全帰還でMetox級実物・運用知識を回収。

時計:

- 1942末: 分解・測定
- 1943Q1: 試作
- 1943Q2: 選抜実用
- 1943H2: 優先艦艇/潜水艦/基地で実戦的

得られるのは主に、

**「対応するmetric帯の発信源がこの方位にいる」**

という警報。

得られないもの:

- 距離
- 艦種
- 空母識別
- 安定track
- 全米レーダーへの警報

**センチ波SG/10cm系は1943年metric RWRの重大なblind band。**

## 4.4 ESM-cued reconnaissance【B】

1943H2では、

EM警報  
→ bearing history  
→ search sectorを絞る  
→ H8K/D4Y/水偵/潜水艦を向ける  
→ 視認/自前電探で確認  
→ 再捜索/位置更新

が可能。

これは「電波だけで艦隊を発見」ではなく、
**広い海を無駄に探す量を減らす能力**。

## 4.5 Würzburg由来精密追尾/較正【B】

I-30貨物のWürzburg級資料・実物が埋めるカード:

- servo
- 精密追尾
- 誤差測定
- 較正
- radar→director interface
- 試験手順

1943Q2–Q3のA級固定基地で意味を持つ。

主効果:

- 対空追尾
- 較正再現性
- 故障時の診断
- 電探距離＋光学方位の組合せ

**禁止:** SG/PPI/CIC相当の水上捜索能力を生やさない。

## 4.6 Electronics field service【B】

1943H2から優先基地/部隊で、

- 共通予備真空管
- 試験器
- 較正表
- fault log
- module交換
- 予備電源
- 分散配置

を持つ電子整備班が成立。

効果は「最大探知距離」より、
**盲目になっている時間を短くすること**。

## 4.7 欺瞞紙・RCM【B/C】

日本のchaff自体は史実技術。

Branch差は敵metric radar帯をよりよく把握し、

- 切断長
- 投下時刻
- raid geometry

を合わせる。

効果は**数分級のclutter/track split**。

**禁止:** 米SG/CICを全面盲目化。

## 4.8 EMCON【B】

選抜艦隊は、

- passive-heavy approach
- 短時間active search
- ESM cue後だけ自前電探を使う

運用が可能。

固定基地は逆に、

- 予備set
- 予備電源
- physical separation
- decoy
- rapid repair

で生残を図る。

# 5. 「察知」判定の永久ルール

以後の戦史で必ずこの梯子を使う。

1. **EM WARNING** — 誰かが発信している
2. **BEARING HISTORY / BATTLE PREPARATION** — 方位履歴から警戒方向、CAP、魚雷準備
3. **SENSOR CONTACT** — 自前電探/目視/聴音
4. **TRACK** — 安定した位置・針路・速度
5. **WEAPON-QUALITY** — 射撃/CAP邀撃/雷撃/攻撃隊発進に使える解

したがって、

**日本が先にEM警報を得る**
ことと、
**米SG/CICが先にweapon-quality trackを作る**
ことは同時に成立する。

逆も同様。

これを「どっちが先に見つけたか」という一行へ潰さない。

# 6. 水上艦火器管制・魚雷

## 6.1 水上砲撃【A】

計算・光学・較正の改善はあるが、機械式射撃盤を置換しない。

通常昼間:
- hit probabilityは同条件で相対+2～5%級
- 有効射撃解への収束5～10%短縮級

長射程/非標準気象では、初期系統誤差の削減効果がより大きい。

**禁止:** 日本砲撃命中率+20～40%の万能倍率。

## 6.2 九三式/九五式魚雷【A】

名目速度・射程・炸薬量は史実級。

Branch差:

- straight-running/depth dispersion低減
- lot variation低減
- 発射管/艦別較正差低減
- start failure/fuze failureの長い裾を削る
- 酸素取扱事故を減らす

主効果は、
**敵回避以前に技術不良で無駄になる魚雷を減らすこと**。

## 6.3 再装填・第二斉射【A】

成熟部隊では、
第一斉射から第二有効斉射まで12～20分級が成立し得る。

これは瞬間火力二倍ではなく、
20～60分戦闘で予備魚雷が本当に戦力になる確率を上げる。

## 6.4 ESM→夜戦魚雷準備【B】

1943H2の選抜巡洋艦/駆逐艦では、

EM bearing  
→ 戦闘配置  
→ 発射管方向  
→ 光学見張りsector集中  
→ 短時間自前電探  
→ 雷撃解

という順序を取れる。

米側がweapon-quality radar trackを先に作っても、
日本側が**砲弾を浴びてから初めて魚雷準備**する必要はなくなる。

適性ドクトリンは、
**一回の魚雷ambush→離脱**。
長時間SG砲戦へ自信満々に居残る設定ではない。

# 7. 潜水艦 — 国内先端技術

## 7.1 通常巡潜の改善【A】

headline speedより、

- 航続
- trim
- dive repeatability
- battery運用
- machinery reliability
- navigation
- sister-ship variance

が改善。

「一艇の性能+○%」ではなく、

- 定刻出撃
- station到着
- on-station日数
- 再出撃

の各段階で利得が出る。

## 7.2 潜高第一世代【A/C — 1943実戦時計】

本Branch独自の大きな先端技術。

中心性能:

- 水中最高速 18.5～19.0kt
- 全速持続 約55～65分
- 潜航 42～47秒
- 3kt水中航続 145～155nm級

ただし運用は、

低速聴音  
→ 接触/誤差帯  
→ 高速sprint  
→ 減速静粛化  
→ 再聴音  
→ 雷撃  
→ 高速離脱  
→ 再び減速

である。

**禁止:**
- 19ktで常時聴音追跡
- 連続高速航走
- 1943年シュノーケル
- modern data-link wolfpack

情報は老化する。潜高の高速は古い接触報告を射点へ変換できるかどうかの閾値技術。

## 7.3 Bold音響囮【B】

I-30帰還品を分析し、1943Q2–Q3から選抜潜水艦へ。

効果:
- sonar contact後のreacquisitionを乱す
- attack chainを切る

効かない:
- 航空レーダー初発見
- 目視
- 最初のsonar detectionそのもの

## 8.3 Penang / Sabang liaison【A/B】

- Penang: 主連絡・補給基地
- Sabang: 二次staging/emergency
- Singapore/日本本土: 深修理/技術解析

U-178到着後、1943H2には独長距離潜水艦のon-station equivalentを中心+0.5～1.0艇程度押し上げ得る。

## 8.4 U-511 → RO-500【実現済み・解析中】

## 8.5 I-8【F — まだ未来】

帰国時計: 1943-12-21。

期待価値は第二世代のtacit knowledge:

- acoustics
- noise diagnosis
- radar/electronics calibration
- test equipment
- fault isolation
- maintenance procedure

11月5日時点ではまだ使わない。

## 8.6 I-34【F — 未決】

Branch高級COMSECのため自動継承しない。

しかしMalaccaの地理的危険、英潜水艦、trim/overload問題は残る。

**生還も喪失もまだ未決。**

## 8.7 I-29第二遣独 / RO-501 / I-52【F】

物理到達するまで効果ゼロ。

特にBMW 003、Jumo 004、HWK 509、Me262/163関連の**実物大型hardware**は、
将来の艇/別輸送gateを通らない限り日本研究へ入れない。

古い技術正本にI-29帰還中心案が残っていても、
現行の再監査では**物理hardware gateを再オープン**している。

# 9. ASW — 日本側も先端化している

- own-noise測定

- propeller/machinery condition
- search speed doctrine

広域航空捜索  
→ contact保持  
→ datum  
→ surface/air handoff  
→ attack/re-attack

radar/visual等でdatumを作った後の**近接localization装置**。

**禁止:** 日本の太平洋全域ASWが一挙に米潜を捕捉。

## 10.3 雷電【A】

8月時点:
- 完成220～250

- 20mm四門標準80～100

**警戒網から短時間上昇→SBD/TBF/爆撃機へ重火力邀撃。**

F6F sweepとの長時間制空戦が主任務ではない。

## 10.4 強風【A/B】

1943年春実戦化。

- 8月 第一線30～45
- 10月 第一線50～65
- 年末 第一線70～90中心
- 標準分遣隊12、通常即応8～10

主任務:
- 爆撃/雷撃機
- 偵察/哨戒機
- 滑走路修復時間帯の防空
- 水上機泊地防空

持続出撃力は同条件陸戦の60～75%級。

最大価値:
**滑走路を潰しても基地航空を終わらせない。**

## 10.5 瑞雲【C】

- 9月初期納入

- 高速偵察
- contact/recontact
- 艦砲観測
- 連絡
- secondary light bombing

broad search  
→ suspicious-contact revisit

- 標準 621～628km/h
- 5,000m 4:05～4:13
- 12.7mm×4
- 防弾/部分防漏

- 要地邀撃

# 12. 発動機・材料

## 12.1 金星【A】
安定・整備性の基準発動機。
1943には金星60型が前線標準化へ。

## 12.2 火星【A】
G4M/H8K/雷電/B6N等と生産競合。
雷電大量増産は無料ではない。

## 12.3 誉【B/C】
1943初期量産で実用短時間1,850～1,950hp級。

Branch差は、
2,000hpが魔法的に常時出ることではなく、

- 気筒温度
- 振動
- 加工公差
- ロット差
- 軸受
- 故障原因

を早く収束させ、量産中央値と即応率を上げること。

整備負担は依然大きい。
金星並みにはならない。

## 12.4 ハ43【D/C】
烈風本命2,000～2,200hp級。
1943後半は試作/飛行時計。
量産・部隊標準化はまだ未来。

## 12.5 ニッケル【限定改善】
New Caledonia等の追加供給で不足解消ではない。

優先して、
- 排気弁
- turbo parts
- turbine blade
- bearing
- jet hot-section
- prototype engine

等へ使う。

1943ジェット/ターボ研究へNi換算20～40t級特別研究枠は可能。

# 13. 自動空戦フラップ

## 状態【A — 強風 / 技術成熟、C/D — 後続機】

時計:
- 1940 強風で自動化案
- 1941末～42前半 強風試験
- **1942中 実用第一型**
- 1942末～43 紫電向け小型化/信頼化
- 1943以後 紫電改・烈風の標準技術

計算機が機上操縦するわけではない。

地上で、
- speed
- g
- flap angle
- lift/drag
- hinge load
- tolerance

を計算して機械/油圧装置へ曲線を写し込む。

採用:
- 強風: 本格
- 紫電/紫電改: 成熟継承
- 烈風: 初期設計から標準
- 金星零戦: 後期簡易型候補
- 雷電: 主任務上、簡易/手動寄り

# 15. 噴進・高高度技術

## 15.1 国内turbojet研究【D】

日本のjet研究はI-29から始まらない。

本格要求は1942年。

国内基盤:
- exhaust turbo
- rotating machinery
- bearing/vibration/temperature measurement
- compressor/combustion research
- 萱場ramjet/油圧/無尾翼経験

1943年中心:
- ネ0: 母機投下/空中着火試験
- ネ4級: **1943年9～11月に短時間完全自立bench run**
- 年末: 選別機で数十分級耐久を狙う
- exhaust turbo: 高高度戦闘機用flight test

**1943年実戦jetは禁止。**

## 15.2 最初の国内jet飛行【未来D/F】

ネ4級で1944年3～5月のpure turbojet flightを狙う。

推力300kg級、短寿命、大直径の研究機。
実戦戦闘機ではない。

## 15.3 ドイツjet技術【F】

BMW003/Jumo004/HWK509等は、
将来の遣独連絡で物理的に届いた時だけ使用。

到着後の効果は、
「jetを発明する」より、

- 失敗枝を切る
- compressor/turbine構成を確認
- 寸法/材料/燃焼/軸受を比較
- 日本のfailure databaseへ答え合わせ

すること。

まず問う:
- 対応bandのEM emissionはあるか
- その戦域にRWR/DF nodeがあるか
- bearingを複数取れたか

# 19. 1943年11月時点の総括

この世界の日本の先端性は、

**「最高性能が米国を全部越えた」ことではない。**

むしろ、

**「史実ではバラバラに存在した研究・試験・優秀機・熟練部隊が、計算・計測・品質管理・情報処理によって、1943年までに“再現可能な部隊能力”へ変わっている」**

ことにある。

そしてI-30以後の日独連絡は、

**国内体系を置換するのではなく、ちょうど欠けていた計測・EW・音響・較正・実装カードを追加し、第二便以降の質問そのものを高度化する。**

そのため1943H2以降は、

- 先に電波警報を受ける
- 無駄な索敵sectorを減らす
- 基地が適切な待機段階へ入る
- 電探を早く復旧する
- 夜戦魚雷準備を早める
- 潜水艦がASW再捕捉を切る
- 水上航空が滑走路制圧後も残る

という、**「時間と情報の質」をめぐる小さな優位が複数戦域で累積する。**

ただし、米側は依然としてSG/CIC、carrier fighter direction、物量、工業回転で強い。

したがってBranch Bの技術戦は、

**日本が未来兵器で米国を圧倒する世界ではなく、史実日本に存在した“技術が兵器体系になる前に戦局が壊れた”時間差をかなり消した世界**

として扱う。
