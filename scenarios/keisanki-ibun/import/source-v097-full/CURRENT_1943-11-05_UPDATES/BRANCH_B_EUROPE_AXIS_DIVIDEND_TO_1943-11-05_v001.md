## 8. 非線形性

欧州枢軸にとって本当に大きいのはgross 1.5万人ではなく、
**その一部が経験ある人員として次の戦闘へ再投入されること**。

例:
1942末に生き残る
→ 1943 Feb/Marに戦う
→ そこでまた部隊崩壊を防ぐ
→ 夏の再建時にcadreになる
→ 秋の防御線へ入る

このrecursive reuseが旧枝で1944年に大きなshadow deltaへ育った。

現行枝でも同じ機構は存在するが、
1943-11時点ではまだ旧枝1944年の大きな値を予約しない。

## 9. Current judgment

1943-11-05時点の欧州枢軸は、
**戦争を勝てるほど救われてはいない。**

しかし歴史より:
- 約1.1–1.9万人分の累積人員損失を回避
- 約0.8–1.4万人がまだ軍事的に利用可能
- 小規模だが装備・車両も多く次戦へ持ち越し
- Tunisia/Sicily/Italyで数日級の時間を購入
- RN/Allied logistics reserveを薄く維持

している。

これは「新しい一個師団」ではなく、
**全戦線へ薄く混ざった半～一個師団級の追加usable manpower + reserve-margin improvement**
と表現するのが最も近い。
