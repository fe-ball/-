# Branch B — Kyofu / water-air nuisance and Europe shadow-loss update, 1943-08-06 v001

Status: WORKING CURRENT AUDIT
Clock: 1943-08-06

## 1. Authoritative Kyofu / water-air baseline recovered from older branch
- N1K1 Kyofu first combat unit: Apr–May 1943.
- 1943-08: 45–60 completed; 30–45 frontline.
- Standard detachment: 12 aircraft; normally 8–10 ready.
- Sustained sortie output from an established sheltered water base: 60–75% of an equivalent land-fighter unit under similar conditions.
- Preferred roles: local interception, bomber/torpedo/reconnaissance denial, runway-suppression bridge.
- Avoid deliberate sustained fighter-sweep combat against F6F-class opposition.
- The larger water-air doctrine uses layered broad search -> suspicious-contact revisit -> fast confirmation -> contact/track -> later position update.
- Small-base search/warning effect: legacy branch working reference +30–70% versus historical local baseline when real aircraft/base/support geometry exists.
- Gunfire observation: +10–25% working reference only when visibility/comms/survival permit.
- Runway cratering does not automatically suppress Kyofu/floatplanes; attacker must also service anchorage, ramps/cranes/tenders, fuel/ammunition, radio and support craft.
- Zuiun is not combat-operational on 1943-08-06; initial deliveries begin Sep and first combat detachments center Oct–Nov.

## 2. Practical nuisance as of 6 Aug 1943
National Kyofu frontline strength supports roughly 3–4 standard detachments, though exact local allocation remains open.
One established detachment provides:
- 8–10 normally ready fighters;
- roughly 5–8 land-fighter-equivalent sustained local sortie output after applying the 60–75% water-base cycle penalty;
- enough strength to make unescorted/poorly escorted PBY/PBM, reconnaissance, SBD/TBF-class low/medium-speed activity risky;
- insufficient strength to contest a full F6F sweep on equal terms.

The important nonlinear effect is not raw kills:
- a runway-only suppression raid no longer guarantees local blindness;
- U.S. planners must allocate fighter-sweep/escort effort and/or separate strike sorties against the water-air support system;
- surviving water aviation can refresh contacts and keep search/spotting alive while land-air sortie generation is temporarily suppressed.

Working interpretation for future event adjudication:
- do not add a universal aircraft-loss percentage;
- if a priority lagoon/base has one ready Kyofu detachment plus a functioning recon/floatplane layer, expect either extra U.S. escort/strike effort or a materially less complete suppression result;
- additional irreversible U.S. losses should be booked only through the actual raid geometry.

## 3. Does this raise the Europe shadow-casualty ledger?
Older mature-branch 1943Q3 Europe figures already assumed the strong Branch water-air technology stack. Therefore Kyofu is not a newly discovered multiplier on the old figures.

Older branch by Sep 1943:
- Tunisia extension: +1,500–3,500 Allied casualties.
- Sicily: +900–1,800.
- Salerno: +700–1,500.
- RN/landing/support: +200–500.
- total by Sep end: +3,300–7,300 Allied casualties, extra dead/missing about 800–1,500.

Current branch differs:
- no renewed 1942 Operation-B heavy-cruiser pulse, so early Indian-Ocean shipping disruption is weaker than old branch;
- British Indomitable/Formidable loss is unchanged and remains the largest nonlinear European naval driver;
- early/strong water aviation and the later Penang/Monsun institutional layer make Indian-Ocean pressure more persistent, partly replacing the missing pulse in 1943H2.

Current working update:
- Kyofu/water-air does not materially change Eastern-Front casualty differences by 6 Aug on its own.
- For British/Commonwealth Europe/Mediterranean effects, water-air persistence should move the current branch modestly toward the old Q3 band, not above it.
- Reasonable current Sep-end sensitivity: roughly +2,800–6,500 Allied casualties, extra dead/missing about +650–1,300, pending actual Tunisia/Sicily/Salerno and Indian-Ocean events.
- Increment attributable specifically to restoring the previously omitted water-air layer is small-to-moderate: order hundreds of casualties by Sep end, not thousands, because it acts through escort/air/search persistence rather than directly fighting in Europe.
- Indian-Ocean H2 escort/ASW binding can plausibly sit around 3–5 hull-equivalents in the current branch once Penang/Monsun starts to matter; 5–8 remains an upper total-pressure band, not a Kyofu-only effect.

## 4. Eastern Front
The water-air correction alone does not justify revising the existing Soviet shadow-loss mechanism upward before Aug 1943.
Main drivers remain:
- Soviet Far-East force retention because Japan remains strategically dangerous;
- small Persian/logistics timing losses;
- Axis units preserved in prior battles and reused;
- later recursive pursuit/recovery differences.

Any post-August increase must be booked through actual Indian-Ocean shipping/escort events and the resulting battle-window shortages, not from Kyofu existence alone.
