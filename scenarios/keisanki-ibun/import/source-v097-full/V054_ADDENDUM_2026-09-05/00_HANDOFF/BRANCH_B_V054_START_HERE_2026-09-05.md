## 1. Water-air support architecture is now CLOSED

The New Caledonia float-fighter system is a distributed three-tier system, not a single vulnerable tender parked off the beach.

### Tier A — rear heavy maintenance / reserve: Santo
- CHITOSE is assigned as the high-value rear mobile seaplane-maintenance nucleus for the NC operation.
- CHIYODA is NOT simultaneously teleported into the same operation; it remains outside this forward commitment unless later movement is posted.
- CHITOSE does not sit in the Boulouparis close-combat anchorage.
- Santo holds heavy repair, major spares, reserve floats/engines, training/replacement pilots, and a material reserve.
- This is Branch-causal: Chitose/Chiyoda remain seaplane tenders and the Branch lacks the historical Guadalcanal emergency conversion pressure.

### Tier B — intermediate mobile support
- KAMIKAWA MARU / 11th Seaplane Tender Division-type support element is the intermediate service layer.
- It remains displaced from the exposed beachhead and moves only after local sea/air security exists.
- It carries fuel/ammunition/maintenance personnel/replacement aircraft and can replenish the forward shore-water nodes.
- Loss of this layer sharply reduces sustained output but does NOT instantly destroy every forward aircraft.

### Tier C — distributed forward lagoon nodes
Beginning 1942-11-09 afternoon, once shore access is secure:
- Saint-Vincent/Bouraké sector node
- Boulouparis/Ouenghi sector node
- progressively a southern Tomo/Tontouta-side node as the road/shore is secured

No single forward node normally holds more than ~4–6 A6M2-N-equivalent aircraft plus a small F1M/E13A complement.
Forward assets use dispersed fuel drums, ammunition caches, towing craft, temporary maintenance shelters and separated moorings.

Consequences:
- one 500/1000-lb bomb cannot mission-kill the entire local float-fighter system;
- US attacks on cranes, fuel, towing craft and moorings can reduce sortie generation locally;
- heavy repair still requires Santo/intermediate support;
- sea state, recovery accidents, salt-water maintenance and towing remain real loss channels.

## 7. Qualitative-threshold result

No qualitative threshold has yet been crossed by 11/11 18:00.

The water-fighter system has:
- saved measurable A6M fatigue/damage,
- forced US fighter/SBD allocation,
- modestly reduced Japanese landing/logistics damage,
- prolonged naval observation windows,
- advanced the Tontouta shelling clock by ~30~45 minutes,

- destroyed the Tontouta air system a day early,

- created air superiority independent of carrier/land-based A6M units.
