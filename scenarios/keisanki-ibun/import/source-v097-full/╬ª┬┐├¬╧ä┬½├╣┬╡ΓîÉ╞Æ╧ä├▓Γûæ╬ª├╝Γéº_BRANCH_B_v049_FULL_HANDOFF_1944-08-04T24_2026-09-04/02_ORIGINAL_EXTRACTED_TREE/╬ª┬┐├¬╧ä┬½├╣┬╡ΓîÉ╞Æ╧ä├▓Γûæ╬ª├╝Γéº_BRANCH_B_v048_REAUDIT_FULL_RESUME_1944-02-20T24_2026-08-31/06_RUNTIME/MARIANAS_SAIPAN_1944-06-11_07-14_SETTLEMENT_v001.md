## 判定原則

米軍・日本軍ともに readiness / fatigue / I-O / sortie cycle / simultaneous-task load / C2 / repair / search freshness / weather / range-payload を有限資源として扱う。米レーダー探知は即時識別・射撃解ではなく、探知→航跡→識別→割当→射撃指揮獲得→発砲→命中を分離する。日本側も同じ基準で、改善を万能化しない。

日本側の1943-44対米艦隊航空防空研究は、early detection → fighter direction → CAP → outer escort AA → individual ship FC → close AA → evasion → damage control の各段階に対し、数分間の time compression / bearing-altitude conflict / target switching / CAP fuel-relief pressure を作る。成熟米防空に対する効果は同一 sortie 数で terminal attack 到達 +10～20%級を上限目安とし、命中率・AA低下へ二重加算しない。
