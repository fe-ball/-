# 1944年春 航空戦闘研究・対敵機/任務別閉鎖 v001

status: AUTHORITATIVE_CURRENT_BRANCH_OPERATIONAL_RESEARCH
as_of: 1944-04-30T24

## 1. 判定原則

最高速度だけで勝敗を決めない。高度0–3km、3–6km、6–9km、9km以上を分け、速度、加速/上昇、急降下、高速操舵、瞬間/持続旋回、ロール、火力、防護、航続、無線・管制適合性を別評価する。さらに先見、位置エネルギー、編隊比、CAP/護衛/邀撃等の任務拘束、離脱可能性を上位変数とする。

### 見逃しやすい変数
- 敵機が「勝たなくても離脱できる」場合、日本側は撃墜機会を強制できない。
- CAPを攻撃隊から引き離した場合、撃墜なしでも任務成功になり得る。
- 同じ機種でも搭乗員中央値、無線、地上管制、整備再生で実効が変わる。
- 一個隊の良好実績を全航空軍へ拡張しない。

## 2. 陸軍主要機

- Ki-44-II後期: P-40Nには上昇/加速/速度で優位を狙える。P-38J/P-51/Spitfire VIIIには位置優位から一撃し追撃しない。邀撃で評価。
- Ki-61四門型: P-40Nに対等～条件付き優位。P-38/P-51/Spitfireとは高速操縦・急降下・射撃安定を利用し持続旋回を避ける。
- Ki-84: P-40Nには明瞭な優位候補。P-38Jは3–6kmで十分戦えるが高高度では不利増。P-51Aは近い性能帯。P-51B/Cは戦闘成立可能だが敵の高速離脱を完全には阻止できない。Spitfire VIIIは近接同格圏。

## 3. 海軍主要機

- 後期瑞星零戦: F6F/F4Uとの正面エネルギー戦は不利。低中速、航続、編隊、任務拘束を利用。FM-2級には優位を狙える。
- 金星零戦改: F6Fとの速度差を大幅縮小し、低中高度で戦闘選択を回復。ただしF6Fの高速急降下、防護、火力、艦隊管制優位は残る。F4Uには位置優位必須。
- 雷電: fighter sweepの決闘機としてではなく、レーダー/作図から攻撃隊へ短時間突入する基地邀撃機として評価。
- 紫電改: 1944春は少数。低中高度でF6Fと正面戦を許容できるが米CIC/数/再生能力は別問題。F4Uには高速縦戦を許さない配置が必要。
- 強風: F6F/F4Uとの制空戦を避け、攻撃機・偵察・滑走路抑圧後の不確実性維持へ使用。

## 4. 教範化

敵機カードは「何が得意か」より「やってはいけないこと」を先に示す。
例: F6Fは高速急降下追撃禁止、P-38は正面火力と高高度長時間垂直戦を避ける、P-51は離脱する敵を追わない。

## 5. 判断理由

機体HARDは既存正本で相当閉じているが、1944春の新型機を敵機別・高度別・任務別へ変換する工程が未閉鎖だった。現在枝では搭乗員循環、警戒管制、整備再生が史実と異なるため、史実撃墜比の直接継承も不適切。

## 6. 再判定Gate

- 新型敵機の実戦遭遇と捕獲/詳細報告。
- 紫電改/金星零戦改の部隊数が大幅増加した時。
- 米側が新しいfighter direction/CAP分業を導入した時。
- 高高度B-29邀撃でKi-44/Ki-84/Ki-45の実戦データが蓄積した時。
