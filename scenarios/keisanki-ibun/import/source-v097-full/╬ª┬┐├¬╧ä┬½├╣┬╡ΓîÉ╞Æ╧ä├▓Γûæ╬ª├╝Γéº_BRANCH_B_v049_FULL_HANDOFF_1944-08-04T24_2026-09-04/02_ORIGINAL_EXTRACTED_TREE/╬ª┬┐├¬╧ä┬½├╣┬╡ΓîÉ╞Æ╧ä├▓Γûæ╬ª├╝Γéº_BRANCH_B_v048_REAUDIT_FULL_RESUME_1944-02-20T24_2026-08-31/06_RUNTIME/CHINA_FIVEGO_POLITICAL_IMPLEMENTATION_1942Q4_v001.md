# 中華民国現況・五号作戦政治実装 1942Q4 v001

status: AUTHORITATIVE_PREPARATION_BASELINE
as_of: 1942-12-31T24

## 1. 中華民国現況

中国は史実以上に脆弱だが、一律兵力倍率で減らさない。

弱体化の重点:
- 装備された有効師団数。
- 重砲/弾薬。
- 車両。
- 航空。
- 指揮通信。
- 工場/修理。
- 政府財政。
- 長距離部隊移動。

人的プール、広大な地理、地方勢力、撤退余地は残る。

## 2. 日本陸軍の認知

高精度:
- 自軍鉄道輸送量。
- 既知道路/橋梁/飛行場。
- 中国軍大部隊概位置。

中:
- 師団実員。

中--低:
- 敵弾薬備蓄。
- 破壊後道路容量。

低:
- 現地食料調達。
- 士気/撤退時期。
- 四川地方軍閥政治。

非常に低:
- 西安/漢中喪失で蒋政権が崩壊する確率。

計算文化の効果は政治予測を魔法化することではなく、計算可能領域と仮定依存領域を明示し、後者を「確定兵站」へ混入しにくくすること。

## 3. 装備差の扱い

「性能が上がったから必要数を減らす」を原則禁止。

- 戦車: 信頼性/再出現は上がっても複数正面を占有するので台数を単純削減しない。関中平原では有力、秦嶺では価値低下。
- 砲兵: 射表/公差/装薬/摩耗管理で弾薬浪費・修正射を減らし得るが砲兵大隊数は削らない。
- 航空: 可動率/任務計画が良くても制空/護衛/偵察/爆撃という別任務を同時に満たすので飛行戦隊数を機械的に減らさない。
- 工兵: 施工能力改善ほど同時多地点施工の価値が増すため削らない。

## 4. 最大要求

- 北方10個師団級。
- 宜昌方面6個師団級。
- 予備1--2個師団相当要求。
- 第3戦車師団主力/大部を平地突破へ。
- 五号関連航空300--340機要求。
- 直接作戦軍27--32万人級要求。

ただし北方10個師団が秦嶺へ同時突入するわけではない。宝鶏以南の前進は4--5個師団級、最前線3--4個師団級へ自然に絞られる。

## 5. 年末採択

- 北方10＋宜昌6個師団級は維持。
- 中央予備1個師団級。
- 直接関連29--31万人中心。
- 航空保有300--320、初動即応260--285。
- 自動車4,700--5,200。
- 工兵/鉄道/通信18--22千。
- 特別集積50--55万t。

技術改善はこれらを削る根拠でなく、可動/回転/修理/弾薬節約へ作用。

## 6. 国家資源・船腹

限定FS終了後に大型輸送船15--22隻級が攻略集中から解放。軍用輸送能力約8--11万GRT級を五号準備へ再配置。

民需からの新規30万GRT恒久徴用要求は首相/陸相・企画院・大蔵が拒否。
1--2月ピーク時のみ3--5万GRT級の短期借上げ余地。

五号の主ボトルネックは船腹から華北鉄道、貨車/機関車、トラック、工兵、航空燃料、弾薬、銅/工作機械へ移る。

## 7. 作戦段階・政治決定

第一期: 潼関--西安--宝鶏、宜昌方面同時西進。
第二期: 宝鶏で兵站を再編し、4--5個師団級で漢中。
第三期: 四川盆地は自動継続しない。

漢中到達時に、敵残存、道路t/day、現地政治、南方情勢を再審査。

1942年末、大本営政府連絡会議は五号実施方針を正式承認。
発起窓1943-03-15--04-10、中心3月下旬。
2月中旬に最終審査。
