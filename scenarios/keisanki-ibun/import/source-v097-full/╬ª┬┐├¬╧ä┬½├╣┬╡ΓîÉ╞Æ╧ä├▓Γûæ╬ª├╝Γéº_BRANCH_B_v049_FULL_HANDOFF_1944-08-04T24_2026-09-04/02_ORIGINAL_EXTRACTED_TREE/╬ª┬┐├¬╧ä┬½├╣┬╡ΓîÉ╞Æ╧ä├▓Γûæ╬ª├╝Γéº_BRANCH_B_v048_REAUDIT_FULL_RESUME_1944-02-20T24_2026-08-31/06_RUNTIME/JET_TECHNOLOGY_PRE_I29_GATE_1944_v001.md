## Pre-German-hardware state

Japanese turbojet work is already active before I-29's later German-data/hardware gate. Historical Japan itself had early wartime turbojet bench activity; Branch adds better computation, metrology, rotor/vibration analysis, test-data retention, selected research-material priority and failure classification.

Do not model this as national technology points. Resolve individual cards: compressor map and surge margin, combustion stability, turbine temperature/cooling/material, rotor balance, bearing/seal, starter/fuel control, engine life, nacelle/airframe integration, production tolerances and materials.
