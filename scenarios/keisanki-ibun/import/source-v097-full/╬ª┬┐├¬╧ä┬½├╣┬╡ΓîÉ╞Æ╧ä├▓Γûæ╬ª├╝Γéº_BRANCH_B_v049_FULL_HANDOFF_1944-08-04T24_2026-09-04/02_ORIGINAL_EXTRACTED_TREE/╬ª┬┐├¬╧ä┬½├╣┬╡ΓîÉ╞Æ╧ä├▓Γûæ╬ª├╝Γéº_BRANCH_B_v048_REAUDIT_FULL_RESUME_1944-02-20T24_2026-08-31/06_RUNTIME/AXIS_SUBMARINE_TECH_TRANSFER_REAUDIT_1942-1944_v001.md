## Core adjudication rule
Technology transfer is not a scalar level catch-up. Treat each transfer as a card inserted into the receiver's existing deck. Effect depends on: missing card, prerequisite cards already held, physical artifact vs drawing vs measurement vs expert tacit knowledge, production/material compatibility, and absorption time. Re-attribute existing Branch capability before adding any new bonus; avoid double counting domestic development plus German confirmation.
