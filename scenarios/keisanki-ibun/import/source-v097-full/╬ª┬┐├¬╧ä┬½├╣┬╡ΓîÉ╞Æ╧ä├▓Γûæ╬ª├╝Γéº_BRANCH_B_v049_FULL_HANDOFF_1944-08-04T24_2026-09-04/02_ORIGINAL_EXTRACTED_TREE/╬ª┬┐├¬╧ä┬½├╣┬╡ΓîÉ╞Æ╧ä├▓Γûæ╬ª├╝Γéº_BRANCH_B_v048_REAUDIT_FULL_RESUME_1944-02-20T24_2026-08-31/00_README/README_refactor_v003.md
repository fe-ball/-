## 基本方針

情報量は減らさない。旧一式は99_LEGACY_UNTOUCHEDに保持し、新構造は索引・裁定・状態投影として追加する。
技術的判断は版番号ではなく、条件整合・物理整合・時計・根拠・再現性で裁定する。
小改善は孤立した割合として扱わず、同一中間変数への重複を除いたうえで、異なる因果段階の複合、閾値越え、再配分を評価する。
