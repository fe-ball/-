## 水上航空
水上航空は国全体の機数bonusではない。局地の機体、搭乗員、泊地/母艦、燃料弾薬、海況、曳航・給油・再武装、整備、通信を通じて出力する。夜間使用も同様にevent-specificで、夜間索敵の一律bonusは置かない。
