# 1941→再走査 Gate Matrix v0.01

## A. 1941-12-07夜に閉じるもの

- 現行航空機性能・機数・可動率。
- 空母別航空隊と任務選択。
- 水上艦Hull/Availability。
- 潜水艦個艦OOB/整備状態/所属。
- 輸送船腹・港湾・揚陸能力。
- 搭乗員・整備員コホートの初期分布。
- 開戦時に成立済みの九一式雷撃、第二斉射、暗号/通信能力。
- 推力式単排気管が開戦時性能へ混入していないことの確認。

## B. 各作戦後に必ず更新

1. 損失・修理。
2. 生残搭乗員/整備員。
3. 配置可能艦艇・航空隊・潜水艦。
4. 次作戦までの時間。
5. 敵が観測した新能力と適応。
6. 新たに成立した技術/制度スイッチ。

## C. 主な再評価点

### Pearl Harbor後
- 航空魚雷/急降下爆撃の非線形損害。
- 帰還機・搭乗員の損耗。
- 米側の早期警戒・防空適応。

### マレー/フィリピン/蘭印後
- 反復出撃による可動率差。
- 基地移動で観測された地上支援の非互換性。
- 水上魚雷第二斉射の実戦認識。
- 輸送回転差が攻略時計へ届くか。

### MO後
- 空母・航空隊・熟練者の生残状態。
- 次作戦へ回せる予備機/搭乗員。
- 米側のCAP・回避・対雷撃適応。

### MI後
- 第一回大規模人員循環ゲート。
- 空母修理/生残航空隊による自然還流。
- 索敵/CAP/予備保持/甲板運用の再研鑽。
- 空地分離の局地試行を開始するだけのデータが揃ったか。
- Guadalcanal型消耗戦を起こす戦略条件が残っているか。

### 1942年末
- 局地護衛指揮。
- 空地分離の主要戦域実用化。
- 人員差の比較から経験核配置仮説。
- 推力式単排気管の量産標準化。
- 東海初期部隊の可否。

### 1943年前半
- 潜高戦闘即応。
- 経験核配置。
- 空地分離と基地間可搬性。
- 東海/カ号/護衛艦の空水協同。
- レーダー/I-O閉ループへの移行度。

## D. 旧結果の扱い

旧戦史は「その時点で考えた作戦案」と「後段スイッチの成熟候補」を再利用するが、損害・日程・生残戦力は前段から再計算する。
