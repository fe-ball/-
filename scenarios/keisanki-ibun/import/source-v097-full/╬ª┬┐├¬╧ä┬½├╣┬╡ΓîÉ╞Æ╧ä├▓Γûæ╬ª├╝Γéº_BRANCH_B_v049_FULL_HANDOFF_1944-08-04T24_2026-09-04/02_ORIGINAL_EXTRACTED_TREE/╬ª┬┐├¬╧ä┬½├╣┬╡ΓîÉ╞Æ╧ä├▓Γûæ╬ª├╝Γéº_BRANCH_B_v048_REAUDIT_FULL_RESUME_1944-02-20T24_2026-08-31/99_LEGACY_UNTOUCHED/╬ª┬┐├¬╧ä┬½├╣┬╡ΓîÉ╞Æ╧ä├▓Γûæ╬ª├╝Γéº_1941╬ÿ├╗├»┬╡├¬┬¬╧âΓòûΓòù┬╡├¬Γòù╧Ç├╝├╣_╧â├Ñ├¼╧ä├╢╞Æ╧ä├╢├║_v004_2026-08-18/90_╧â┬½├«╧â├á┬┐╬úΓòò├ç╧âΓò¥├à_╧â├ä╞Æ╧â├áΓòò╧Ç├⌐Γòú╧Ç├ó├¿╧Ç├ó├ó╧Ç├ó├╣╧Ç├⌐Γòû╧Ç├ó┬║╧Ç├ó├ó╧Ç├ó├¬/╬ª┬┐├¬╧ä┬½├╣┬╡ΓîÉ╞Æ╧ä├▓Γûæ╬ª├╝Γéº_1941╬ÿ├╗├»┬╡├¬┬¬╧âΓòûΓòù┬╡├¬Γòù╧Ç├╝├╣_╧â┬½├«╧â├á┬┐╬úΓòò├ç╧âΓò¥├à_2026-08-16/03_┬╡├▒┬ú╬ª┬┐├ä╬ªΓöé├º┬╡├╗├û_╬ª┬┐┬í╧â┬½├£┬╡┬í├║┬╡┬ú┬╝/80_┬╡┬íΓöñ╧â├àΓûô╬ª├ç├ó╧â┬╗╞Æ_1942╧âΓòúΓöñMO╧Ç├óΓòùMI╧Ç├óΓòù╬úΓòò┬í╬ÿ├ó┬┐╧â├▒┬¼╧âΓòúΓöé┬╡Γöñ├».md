# 計算機異聞・歴史考察　1942年MO・MI・中部太平洋

> **2026-08-10 状態変更：太平洋開戦後の戦果は再監査待ち。**
> 本書は史観・比較・旧作業線・再走査論点を保持する参照資料であり、1941年12月以後の勝敗・損耗・修理・占領地を現行結果として固定しない。魚雷・航空命中・再装填等の非線形効果を反映し、`31_魚雷・水雷戦_魚雷本体・射撃指揮・再装填・運用.md` と `61_技術からの自然な軍事的派生_戦術サイクル・任務階級・戦史再監査.md` に従って開戦から順に再走査する。


# 0. このカテゴリの扱い

80番台は**歴史考察**である。10～70の技術正本とは役割が違う。

- 技術・性能・生産の現行値は10～70を優先する。
- 80番台は、その技術条件から生じる戦役・配置・損耗・政治判断を保持する。
- 本文中の**固定シナリオ事象**、**中心線**、**条件依存**という旧ラベルは、2026年8月9日時点の検討状態を示す履歴ラベルとして読む。

本書の「固定」は現在の歴史結果を拘束しない。再走査では31・61および担当技術正本から改めて判定する。
- 史実資料と本世界推定を混同しない。

本書は2026年8月9日までの会話で成立した、MOからMI直後までの歴史考察を統合する。

# 1. 1942年春の前提

## 1.1 高等暗号

**固定シナリオ条件。**

日本の高等暗号は、少なくとも短期戦略に意味のある時間、精度、単語数では米側がほぼ解読できない。

ただし米側には残る。

- 低級暗号。
- 平文・不注意通信。
- トラヒック解析。
- 無線方位測定。
- 航空・潜水艦偵察。
- 戦略的にあり得る次作戦候補の推定。

したがって米側は「何も分からない」のではなく、**候補を絞れるが、史実MIのように地点・日付・空母数まで詰め切れない**。

## 1.2 南方作戦の前倒し

本世界の南方作戦は輸送・揚陸・航空稼働の改善により、1942年春時点で史実より数日級早く推移する局地がある。

これを年単位の戦略前倒しにはしない。

# 2. MO・珊瑚海

## 2.1 作戦日程・中心線

中心：

- Tulagi占領：4月30日前後。
- 水上機基地：5月1日前後から使用開始。
- Port Moresby攻略船団：5月1日前後出発。
- Deboyne：5月3日前後。
- Port Moresby上陸予定：5月7～8日前後。

Lexingtonは史実より明確な南方脅威に対応してYorktownへ合流するが、史実5月1日より遅く、5月4～5日前後が中心。

## 2.2 索敵

H6K/H8K、水上機、基地航空の稼働率・航法・捜索計画改善により、日本側が米空母群への最初の有用接触を数時間早く得る確率が上がる。

レーダー誘導CAPのような後期能力は持たせない。

## 2.2A Tulagi局地戦

Tulagiは、米軍がMO全体を確信していなくても、現地通報・偵察から攻撃され得る。本世界では少数の水上戦闘機、やや正確な在泊艦艇の射撃・管制、厚い前進索敵により、史実ほど一方的な空襲にはなりにくい。

ただし小艦艇の25mm級近接対空火力そのものが別物になるわけではない。

## 2.2B 対空砲火の上限

- 高角砲：射表・管制・初期諸元改善が比較的効く。
- 25mm等の近距離機銃：照準、旋回、弾倉、射撃時間の物理制約が大きく、計算効果は限定的。

大型艦・高角砲火では命中解への収束が少し良くなるが、艦隊防空全体を米1944年級へ引き上げない。

## 2.3 戦果・固定中心

**中心線：日本側の戦術・作戦勝利。**

日本：

- 翔鶴：爆弾2発前後＋至近弾。沈没危険は低いが航空作戦不能級。
- 瑞鶴：直撃なし～軽微。
- 祥鳳：生存。
- 第五航空戦隊航空機損失：約25～35機。

米国：

- Lexington：魚雷2～3、爆弾1～2級から燃料蒸気・火災連鎖、喪失。
- Yorktown：爆弾2発前後＋至近弾。中程度損傷、自力退避。
- 米航空機損失：約35～45機。
- Crace部隊は壊滅しない。巡洋艦中破級＋駆逐艦軽損傷程度の中心。

## 2.4 Port Moresby

上陸は中止されない。

中心：

- 5月7～8日上陸。
- 主地域制圧：5月13～17日、中心5月15日前後。

以後Port Moresbyは、Rabaulを置き換える巨大兵站基地ではなく、

> **南方の盾・楔。前進防空、偵察、中継、限定攻撃、豪州北東部への圧力。**

として使う。

初夏守備隊9,000～12,000、後に12,000～15,000級が中心。戦闘機重視とする。

# 3. MO後の戦略順序

**固定中心線：MO成功 → MI → その後FS。ALはMIと同時に実施しない。**

ALは承認・準備されているが、龍驤・隼鷹をMIへ投入せず、MI結果確認後に北方へ回す。

このため、史実のようなALとMIの同時行動による兵力分散は緩和される一方、AL準備そのものは存在し、米側交通分析上は北方も本物の候補として残る。

> **正しく戦えば勝負できるが、性能・勢い・経験を含めてなお強力。**

を中心とする。単一の致命的弱点を発見済みとは扱わない。

# 8. 航空搭乗員損耗の読み方

史実MIでも日本空母搭乗員の大多数は脱出・生還したとする研究線を採用する。

本世界でも沈没空母所属者が自動的に全滅するとはしない。

ただし今回は史実以上に長い航空戦で、Midway攻撃、米空母第一撃、Yorktown攻撃、Enterprise攻撃まで繰り返す。

したがって損耗の中心は**艦と一緒に沈むことではなく、空中戦・対艦攻撃そのもの**。

中心推定：

- 艦載航空搭乗員KIA/MIA：70～95名。
- 上振れ100～110名級。
- 負傷・一時非稼働：30～50名級。

加えて三沈没空母の整備員、兵器員、航空燃料員、甲板作業員、航空隊司令部要員等に人的・組織的損失が出る。

「熟練搭乗員全滅」にはしないが、第一線航空組織が無傷でもない。

# 9. Midway攻略

## 9.1 続行判断

**固定中心線：攻略続行。ただし期限付き。**

条件：

- 即時反撃可能な無傷米空母を確認できない。
- Midway航空戦力を十分削減。
- 瑞鶴・瑞鳳が航空掩護可能。
- 上陸船団が健在。
- 燃料・弾薬が許容範囲。

長引くなら中止する。瑞鶴を6月10～11日以後まで不必要に貼り付けない。

## 9.2 6月7～8日

6月7日、Midway残存航空が近藤部隊を攻撃。

中心：

- SBD約20、B-17約8。
- SBD5～7機喪失。
- 日本零戦1～2機損失。
- 日本駆逐艦1隻500lb級1発で中破級。
- 戦艦は至近弾・軽損傷程度。

午後、日本第二次Midway攻撃45～50機級。

夜、金剛・比叡・巡洋艦・駆逐艦による上陸正面砲撃。

6月8日偵察で滑走路・一部AA・沿岸砲が残るが、攻略続行。

## 9.3 6月9～10日上陸

史実計画の約5,800名級を基礎とし、第一日揚陸・舟艇運用は60の改善値を適用する。

6月9日第一波中心：

Eastern Island：

- 一木支隊約1,000。
- 第一時間に750～850程度が戦闘可能状態で上陸。
- 100～150名級の死傷・舟艇損害、残り遅延。

Sand Island：

- 海軍陸戦隊約1,500。
- 第一時間に約1,000～1,150戦闘可能。
- 150～250名級の死傷・遅延。

午前から第二波を入れ、昼まで総上陸3,800～4,300、夜まで4,500～5,000級。

Eastern Islandは6月9日午後までに組織抵抗崩壊。

Sand Islandは沿岸砲、機銃、迫撃砲、軽戦車で抵抗が強く、日本側は一夜で無理な突撃をせず橋頭堡を保持。

6月10日、Eastern側部隊800～1,000名をSandへ転用し、艦砲・限定航空支援の下で11～14時頃に組織抵抗終結を中心とする。

## 9.4 損害

日本攻略部隊：

- KIA/MIA 350～500。
- WIA 650～900。
- 合計1,000～1,350、全体の17～23％級。
- 上陸舟艇全損・大破15～25％級。

米側：

- 海兵隊・基地要員に大損害。
- 1,000名を超える捕虜＋海軍・航空基地要員。
- B-17/PBYの一部は退避。

**6月10日、Midway攻略完了。**

# 10. Midway占領後

Midwayは第二のTrukにしない。

任務：

- 長距離偵察・早期警戒。
- 潜水艦・飛行艇支援。
- Hawaii方面へ米戦力を拘束。
- 再占領作戦への警戒時間を作る。

中心守備：4,500～6,000名級。

航空：

- 零戦24～36。
- 水偵・偵察10～20。
- 飛行艇は一時運用。
- 陸攻12～18、または必要時進出。
- 早期警戒電探を整備。

初期に滑走路、燃料、防護掩体、水・荷役設備を大量投入し、その後は補給需要を抑える。

艦隊はMidwayへ常駐しない。

- Hornet：喪失。
- Enterprise：大破、5～7週間級の本格修理を中心推定。
- Saratoga：健在。
- Wasp：太平洋転属中。

したがって、米国は6月中旬に空母戦力の底を迎えるが、**新造空母ではなくSaratoga・Wasp・Enterprise修理によって8月には3空母級へ戻り得る**。

# 12. MIの戦略的評価

日本側から見れば「本望」に近い。

- 米空母主力を撃破。
- Midway攻略の機会を得る。
- Hawaiiを直接攻略せずとも米戦力を中部太平洋へ拘束。

しかし、

- 正規空母3隻喪失。
- 飛龍大破。
- 艦載機・航空員・整備・甲板組織の損耗。
- 大規模格納庫火災という新しい戦訓。

を同時に得る。

このためMIは「一方的勝利」ではなく、**日本側が次の数か月を買う代わりに、空母戦力の質量双方を大きく支払った勝利**として扱う。

技術上のMI火災戦訓は60へ、搭乗員教育政策は50へ記帳する。
