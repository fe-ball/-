# マレー Phase 1 状態遷移 1941-12-08～15 v0.01

## 0. 目的

1941年12月8～15日を、後続戦果を固定せずに再走査する最初の実動区間とする。

この区間の目的は「日本側の攻略日程を何日短縮できるか」を先に決めることではない。史実でも日本側の初動航空優勢とForce Z撃沈は強く飽和しているため、まず次の状態を翌日へ保存する。

- 機体：即応、軽損、長修理、強制着陸、事故、戦闘損失、転進中。
- 搭乗員：即応、疲労、負傷療養、KIA/MIA、生残転属候補。
- 地上支援：整備員、工具、部品、燃料、弾薬、増槽、輸送車両、修理廠距離。
- 基地：滑走路、排水、爆撃損傷、天候、前進整備能力。
- 任務：割当→基地所在→可動→発進→目的地到達→任務成立→帰還。

性能差・練度差は、局所空戦の詳細戦術を自動学習させるのではなく、上記状態遷移の成功率と損失状態へ作用させる。

## 1. この区間で使う層

`SOUTHERN_AIR_POOL`
→ `MALAYA_TASKED`
→ `BASE_PRESENT`
→ `SERVICEABLE`
→ `LAUNCHED`
→ `MISSION_REACHED`
→ `MISSION_EFFECTIVE`
→ `RETURNED_SERVICEABLE / RETURNED_DAMAGED_SHORT / RETURNED_DAMAGED_LONG / FORCED_LANDING / LOST`

旧正本の「マレー配当760～840機」は `SOUTHERN_AIR_POOL_HYPOTHESIS` へ降格し、直接の `MALAYA_TASKED` や `SERVICEABLE` へは入れない。

## 2. 1941-12-08――最初の状態遷移テスト

日本陸軍航空の戦後モノグラフは、Kota Bharu方面で39機が攻撃を実施し5機が重損、別の53機が悪天候で前進したものの攻撃せず帰投した、とする。またKedah方面では93機が攻撃へ向かい、別隊では暗夜・悪天候による5機喪失が記録される。

ここで重要なのは、53機を「戦力53」と数えないことである。状態は

`SERVICEABLE → LAUNCHED → WEATHER_ABORT → RETURNED`

であり、敵へ効果を与えない一方、燃料、整備時間、搭乗員疲労を消費する。

同日からSingoraへ航空地区部隊が入り、Bataniは洪水、Singoraは排水不良と豪雨で事故が多い。したがって飛行部隊の前進は、基地占領時刻だけでなく `BASE_SUPPORT_CAPACITY` に拘束される。

### 代替世界で先に差を置かないもの

- 悪天候そのもの。
- 地上道路・橋梁・降雨。
- 占領飛行場の排水能力。
- 敵航空機の地上破壊を一律に増やす倍率。

### 差が出てもよい経路

- 機体信頼性・航続余裕による `FORCED_LANDING` の低下。
- 防護/構造改善による `LOST → RETURNED_DAMAGED` の状態移動。
- 高い練度と経験核による集合、航法、事故率の改善。
- 生残整備核により翌日 `SERVICEABLE` へ戻せる割合の改善。

ただし、これらの中心値はPhase 1ではまだ固定しない。まず実史観測を状態形式へ変換する。

## 3. 1941-12-09――反復出撃と前進基地の摩擦

9日もKota Bharu/Kedah方面で反復攻撃が行われる一方、93機規模の隊が悪天候で主目標攻撃を断念して転針している。

この日は、機体性能差より次の二点を測る。

1. 8日の出撃・損傷・強制着陸後、何機が翌日再び `SERVICEABLE` へ戻るか。
2. Singora等へ移った隊が、地上支援の到着量に応じて何機を継続運用できるか。

これが「初日戦果」ではなく「反復航空戦力」の最初の差になる。

## 4. 1941-12-10――Force Zは飽和イベントとして扱う

英海軍Battle Summary No.14では、日本側打撃隊は84機（爆撃34、雷撃50）とされる。戦闘損失は3機・21名で、さらに2機が燃料不足で後に強制着陸した。Prince of WalesとRepulseはいずれも撃沈された。

したがって本世界で航空機性能・運用が改善しても、Phase 1の中心線では**撃沈艦を追加しない**。既に主要戦略結果が飽和しているためである。

差は主に、

- 3機の戦闘損失が何機 `RETURNED_DAMAGED` へ移るか。
- 燃料不足強制着陸2機が回避されるか。
- 多数の被弾帰還機の修理日数がどう変わるか。
- 生残した熟練陸攻搭乗員が後続作戦へ何人残るか。

へ置く。

このイベントは、今回の研究目的にとって「性能向上が戦果に見えなくても、次戦の状態へ効く」典型例として扱う。

## 5. 1941-12-11～15――陸軍航空の部分的空地分離を開戦時能力として扱う

後続資料で「空地分離」を単一の1942～43年スイッチにしていた扱いを修正する。

マレー作戦の陸軍航空は開戦時点で、飛行部隊とは別に、航空地区部隊、飛行場大隊、修理/補給廠、輸送、通信、情報、航法・気象等を前進させる機構を持っていた。10日夜の命令では、3rd/7th Air Divisionへ航空輸送隊を付し、急進部隊の整備員輸送を行うことも明記される。

よって：

- `IJA-AIR-BASE-MOBILITY = OPERATIONAL_PARTIAL` を開戦時から保持。
- `IJN-AIR-GROUND-SEPARATION = LATENT` は別時計。
- 将来の `JOINT-BASE-STANDARDIZATION` も別スイッチ。

ただし「陸軍は完全に空地分離済み」ではない。Singoraは排水不良と豪雨で中旬まで運用制約、Bataniは洪水・爆撃損傷で15日頃まで使用困難であり、地上支援の物理的移動が律速する。

したがってPhase 1の基地状態は少なくとも以下を持つ。

- `runway_capacity`
- `drainage_factor`
- `weather_factor`
- `ground_crew_capacity`
- `fuel_stock_factor`
- `ammo_stock_factor`
- `drop_tank_factor`
- `spares_tools_factor`
- `repair_depot_access`
- `transport_capacity`

## 6. 熟練者還流――Phase 1から追跡を開始する

後続の航空人事監査では、自然還流は制度スイッチではなく戦争状態の通常遷移として扱うことになっている。よって12月8日から、航空搭乗員と直接整備核を次で追う。

- `SURVIVING_IN_UNIT`
- `WOUNDED_CONVALESCENT`
- `REPAIR_REORGANIZATION_RETURN`
- `REPLACEMENT_AIRCRAFT_FERRY_RETURN`
- `TRANSFER_POOL`
- `KIA_MIA`
- `REPLACEMENT_LOW_SKILL`

重要なのは平均練度へ即座に加点しないことである。

損耗が小さければ、低練度補充で穴を埋める必要が減る。さらに療養・修理・転属・補充機受領の過程で経験者が別隊へ混ざる。この二段階を別々に扱う。

日本側戦後記録では、マレー作戦全期間の第3飛行集団で機体損失331機、集中時の悪天候損失46機、補充270機、人員損失582名が記録され、補充要員の能力不足も述べられている。この全期間値はPhase 1の入力ではなく、12月～2月を通した**校正制約**として後で使用する。

## 7. Phase 1で観測するスイッチ・政策トークン

### A. IJA-AIR-BASE-MOBILITY

開戦時 `OPERATIONAL_PARTIAL`。Phase 1ではON/OFFを判定せず、次を実測する。

- 占領から実用化までの時間。
- 飛行部隊到着と地上支援到着の差。
- 整備員空輸が救った時間。
- 燃料/弾薬/増槽/工具不足で失ったsortie。

### B. IJN-AIR-GROUND-SEPARATION

まだ `LATENT`。陸軍の成功・摩擦を海軍がどこまで観測したかを `OBSERVATION_TOKEN` として蓄積するだけ。

### C. A-SKILL-LEVELING

まだ `LATENT`。隊間で、

- 事故率
- 集合/航法失敗
- mission abort
- 損傷帰還率
- 新人補充比率

に差が生じるかを記録する。

### D. A-DELIBERATE-VETERAN-NUCLEUS-REALLOCATION

まだ `LATENT`。自然移動による経験核は存在し得るが、中央が意図的に別隊へ配る制度はまだ付与しない。

### E. ASW / 艦政 / 潜高

このPhase 1だけでは変更しない。ただしForce Z喪失や南方航空成功は、海軍内の航空力評価に `OBSERVATION_TOKEN` を生成する。これを即座に空母建造政策変更へ結びつけない。

## 8. Phase 1の判定基準

12月15日時点で必ず出すもの：

1. 日本陸軍航空：既知の戦闘損失、非戦闘損失、損傷帰還、強制着陸、weather abortを分離した状態表。
2. 日本海軍陸攻：Force Z後の機体/搭乗員状態。
3. 前進基地：Singora/Batani/Kota Bharu等の運用能力状態。
4. 熟練者：KIA/MIA、負傷、生残、転属可能のコホート差。
5. 12月16日へ繰り越す `SERVICEABLE` と修理時計。
6. 後続スイッチへ与える観測トークン。

## 9. 現時点で固定しないもの

- 12月8日時点の日本側Malaya全tasked航空機総数。
- 百式戦/改良九七戦の各飛行戦隊への厳密配分。
- Phase 1だけでの日本側総損失削減率。
- RAF消耗の「何日早い」という旧帯。
- 地上進撃の短縮日数。
- 空地分離・練度平準化の制度化日。

これらは、日次状態遷移を閉じた後の出力にする。
