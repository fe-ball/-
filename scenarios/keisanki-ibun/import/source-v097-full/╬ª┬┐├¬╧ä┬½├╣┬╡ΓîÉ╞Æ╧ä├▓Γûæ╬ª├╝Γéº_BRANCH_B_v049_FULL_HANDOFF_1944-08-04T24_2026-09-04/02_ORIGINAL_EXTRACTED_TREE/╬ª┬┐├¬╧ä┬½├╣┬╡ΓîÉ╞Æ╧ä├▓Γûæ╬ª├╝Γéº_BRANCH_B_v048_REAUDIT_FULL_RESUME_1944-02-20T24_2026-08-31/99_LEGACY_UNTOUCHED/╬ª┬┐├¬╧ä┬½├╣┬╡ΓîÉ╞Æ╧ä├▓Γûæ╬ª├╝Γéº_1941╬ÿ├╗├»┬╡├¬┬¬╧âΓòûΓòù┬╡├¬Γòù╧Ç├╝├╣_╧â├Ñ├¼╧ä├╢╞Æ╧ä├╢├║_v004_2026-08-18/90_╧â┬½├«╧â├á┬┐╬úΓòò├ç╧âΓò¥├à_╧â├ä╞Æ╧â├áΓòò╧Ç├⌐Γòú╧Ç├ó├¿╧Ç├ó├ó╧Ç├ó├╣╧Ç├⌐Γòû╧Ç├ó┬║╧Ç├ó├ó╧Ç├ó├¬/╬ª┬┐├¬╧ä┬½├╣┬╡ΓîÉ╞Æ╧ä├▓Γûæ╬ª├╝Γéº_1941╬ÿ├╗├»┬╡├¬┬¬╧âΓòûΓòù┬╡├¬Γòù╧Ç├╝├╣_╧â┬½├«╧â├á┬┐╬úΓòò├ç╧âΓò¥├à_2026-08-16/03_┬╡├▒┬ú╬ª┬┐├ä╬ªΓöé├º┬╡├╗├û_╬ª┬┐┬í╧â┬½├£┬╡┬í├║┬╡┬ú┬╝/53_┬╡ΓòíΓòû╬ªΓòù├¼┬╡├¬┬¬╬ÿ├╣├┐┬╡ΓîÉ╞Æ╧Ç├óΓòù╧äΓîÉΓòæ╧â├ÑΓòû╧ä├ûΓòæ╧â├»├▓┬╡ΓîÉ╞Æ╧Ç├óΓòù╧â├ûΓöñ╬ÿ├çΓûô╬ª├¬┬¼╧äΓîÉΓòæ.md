# 計算機異聞・海軍戦闘機・空冷発動機・噴進航空正本

# 0. 本書の位置づけ

本書は、瑞星零戦の後に続く海軍戦闘機体系と、その成立を左右する空冷発動機・自動空戦フラップ・噴進機研究をまとめた詳細正本である。

本書では、1942年以降という戦況依存性の高い時期を扱う。このため、因果と開発方針を確定した部分と、戦争継続、工場残存、資材、搭乗員、基地状況に左右される将来仮稿を明確に分ける。

## 0.1 本書で確定する事項

次は**決定**とする。

1. 発動機は、試験台で規定出力を出す「技術成立」、工場で個体差と不合格率が収束する「量産安定」、予備品・工具・教程を含む「前線標準化」の三時計で扱う。
2. 金星・火星の早期熟成は、既に正本化されたG3M、G4M、H6K、H8Kの改善へ重複加算しない。追加効果は後期型の日程、量産中央値、可動率、換装判断へ配分する。
3. 雷電は零戦の代替ではなく、陸上基地の爆撃機邀撃を担当する専用局地戦闘機とする。火星二〇型の成熟と延長軸・冷却系の独立試験により、史実より早く初期完成度の高い状態へ収束する。
4. 烈風は零戦の単純拡大型ではなく、艦上運用、速度、上昇、高速操縦、火力、防護、航続、将来余裕を統合した4.5t級艦上戦闘機とする。主発動機はハ43、誉は日程上の保険と試験用に残す。
5. 紫電改は烈風までのつなぎであるが、零戦全面代替ではない。後期零戦が量的主力、雷電が邀撃、紫電改が陸上高性能万能戦闘機、烈風が次期艦上主力となる。
6. 金星六〇型零戦改は、瑞星零戦の成長限界と烈風本格配備の間を埋める合理的な派生型として成立する。完全新設計の「金星主力戦闘機」は中心線としない。
7. 自動空戦フラップは川西・強風系列で生まれる。計算機は発明主体ではなく、速度・荷重・フラップ角の作動曲線、安定性、公差、量産校正を早く整える。
8. 萱場の無尾翼・ラムジェット研究は1941年に完全消滅せず、主力戦闘機計画から特別研究へ縮小され、1942年以降の陸軍噴進研究へ人員・設備・試験経験を渡す。
9. 日本の本格的なターボジェット軍用研究の要求時計は、史実同様おおむね1942年からとする。1930年代の排気タービン、萱場、無尾翼研究はその前史であり、直接ネ20へ一本につながるとはしない。
10. 遣独潜水艦連絡では、史実で日本向けに移送が企図された技術資料・見本・実物機材が日本側へ到達する。少なくともBMW 003、Jumo 004、HWK 509に関する完全測定可能な実物・主要部品・資料が国内研究へ渡る。
11. ニッケル事情はわずかに改善するが、量産用耐熱材料の制約は消えない。追加分は試験材、原型機、先行発動機、タービン翼等へ優先配分する。
12. 1944年のドイツ技術流入後も、国内研究を全面廃棄しない。ネ4は早期飛行・教育試験線、ネ0・萱場線はラムジェット研究線として残し、ネ20系とJumo 004級国産型を新たな主線とする。

## 0.2 将来仮稿として扱う事項

次は**中心仮稿**であり、戦況・生産統合後に変更し得る。

- 各機体・発動機の最高速度、上昇時間、航続、寿命の具体値。
- 1944年以後の月産、部隊数、実戦投入時期。
- 1945～46年に戦争が継続した場合のネ20機、900kgf級ジェット、秋水、ラムジェット誘導兵器の規模。
- 高高度火星、二段過給ハ43、後期誉の完成時期。

# 1. 発動機系列を先に決める

後期戦闘機を機体名から考えると、必要な発動機が都合よく間に合う設定になりやすい。本書では、発動機系列の成熟曲線を先に置き、そこから機体の日程を導く。

## 1.1 系列地図

| 系列 | 基本性格 | 中心出力帯 | 主な担当 |
|---|---|---:|---|
| 瑞星／ハ26／ハ102 | 小径・軽量14気筒 | 800～1,100馬力 | 初期零戦、軽戦闘機、偵察・襲撃機 |
| 栄／ハ25／ハ115 | 小中径14気筒 | 950～1,200馬力 | 陸軍軽戦、各種軽中型機 |
| 金星／ハ112 | 堅実な中径14気筒 | 1,000～1,500馬力 | 艦爆、陸攻、偵察、後期換装機 |
| 火星／ハ32 | 大径14気筒 | 1,450～1,850馬力 | 陸攻、大艇、雷電、艦攻換装 |
| 誉／ハ45 | 小径高出力18気筒 | 1,800～2,000馬力 | 紫電改、疾風、銀河、彩雲等 |
| ハ43／ハ211 | 中大型18気筒 | 2,000～2,200馬力級 | 烈風、将来大型高速戦闘機 |
| ハ42／ハ44等 | 大型後期発動機 | 2,000馬力超 | 爆撃機・重機・将来機。別途監査 |

計算機の利得は、未来の出力段階を早期に解禁することより、同じ出力段階を量産機が安全に使える時期を数か月から一年程度早めることに現れる。

## 1.2 三時計

| 時計 | 判定内容 |
|---|---|
| 技術成立 | 試作発動機が所定の出力・回転を達成する。選別部品と試験設備を含む。 |
| 量産安定 | 合格率、耐久、個体差、温度、油圧、燃料系が量産規格へ入る。 |
| 前線標準化 | 予備発動機、工具、部品、整備教程、燃料・油規格、交換周期が揃う。 |

試作発動機が一基回った日を、部隊が常用できる日とみなさない。

# 2. 金星系列

金星は、瑞星より大型で火星より軽い、中間の堅実な系列である。後期には1,500馬力級へ達し、多くの機体の強化型や空冷換装案を支える。

## 2.1 金星四〇型級

| 時計 | 中心時期 |
|---|---|
| 技術成立 | 1936年後半 |
| 少数生産 | 1937年 |
| 量産安定 | 1938年前半 |
| 前線標準化 | 1938～39年 |

中心出力は1,000～1,100馬力級。

計算機・試験還流が効くのは、気筒別温度、プロペラ共振、油温・油圧、排気背圧、長時間巡航燃費、ロット別出力差である。この段階の効果は、発動機の発明時期を大きく変えるより、大型機や艦爆へ安心して積める時期を早める。

## 2.2 金星五〇型級

| 時計 | 中心時期 |
|---|---|
| 技術成立 | 1938年後半 |
| 少数生産 | 1939年 |
| 量産安定 | 1940年前半 |
| 前線標準化 | 1940～41年 |

中心出力は1,250～1,350馬力級。

開戦時の金星主力であり、G3M後期型、H6K後期型、D3A強化型等を支える。これらへの性能利得は既存正本へ記帳済みなので、本書ではさらに最高速度を上乗せしない。

追加効果は次へ置く。

- 四発機での出力差縮小と任務中止低下。
- 発動機交換周期の安定。
- D3A強発動機型への移行速度。
- 金星六〇型開発に使える温度・過給・量産統計。

## 2.3 金星六〇型級

| 時計 | 中心時期 |
|---|---|
| 技術成立 | 1940年末～41年前半 |
| 少数生産 | 1941年後半 |
| 量産安定 | 1942年後半 |
| 前線標準化 | 1943年 |

中心出力は1,450～1,560馬力級。

四〇・五〇型より過給、燃料供給、冷却、点火、軸受、減速機、プロペラ吸収馬力が厳しくなる。1941年に試験用発動機が存在しても、1942年初頭から大量常用できるとはしない。

この系列の戦略価値は、後期機をすべて早めることではない。

> 換装・救済・強化の要求が発生した時点で、既に量産可能な堅実な空冷発動機が存在する。

という保険になる。

主な波及先は、百式司偵後期型、D3A後期型、双発機、後期陸攻、金星零戦改、液冷機・誉機の空冷換装である。空冷彗星や五式戦相当は、原発動機の失敗・供給難という要求時計が発生してから始まる。

# 3. 火星系列

火星は大径・大排気量の二列十四気筒である。正面抵抗と重量は大きいが、熱容量と排気量に余裕があり、陸攻、大艇、局地戦闘機で重要になる。

## 3.1 火星一〇型級

| 時計 | 中心時期 |
|---|---|
| 技術成立 | 1938年前半 |
| 少数生産 | 1939年 |
| 量産安定 | 1940年 |
| 前線標準化 | 1940年末～41年 |

中心出力は1,450～1,550馬力級。

G4M初期型とH8K初期型を支える。既存正本の性能へ追加加算せず、発動機本体と機体側冷却・取付・プロペラ問題を区別しやすくなる効果を重視する。

## 3.2 火星二〇型級

| 時計 | 中心時期 |
|---|---|
| 技術成立 | 1940年後半～41年前半 |
| 少数生産 | 1941年後半 |
| 量産安定 | 1942年中盤 |
| 前線標準化 | 1942年後半～43年 |

中心出力は1,750～1,850馬力級。

高回転化、過給機、点火・燃料供給、水メタノール、大径プロペラ、冷却の総合改良である。1941年初頭から1,800馬力を前線で常用できるとはしないが、1942年中に量産中央値が実用範囲へ入る。

直接の受益機は、雷電、H8K2、G4M後期型、B6Nの火星換装線である。

## 3.3 高高度型火星

高高度型は二〇型の量産安定とは別時計とする。

| 時計 | 中心時期 |
|---|---|
| 地上・高空台試験 | 1942年 |
| 飛行試験 | 1942年後半～43年 |
| 少数実用 | 1943年後半 |
| 前線標準化 | 1944年 |

二段過給機、吸気冷却、高高度混合気、過給機駆動損失、高高度プロペラ、酸素設備が必要になる。計算機は過給比・圧力・温度の比較を速めるが、精密羽根、耐熱材料、実高度試験設備を生まない。

初期雷電は高高度型を待たず、一段二速・水メタノール型で成立させる。

## 3.4 生産競合

火星は一機種の専用発動機ではない。

- G4M一機：2基。
- H8K一機：4基に加え高い予備率。
- 雷電一機：1基。
- B6N火星型一機：1基。

雷電60機と予備発動機を整えるだけでも、G4M数十機またはH8K十数機相当の発動機機会費用が生じる。機体工場能力だけで生産数を決めない。

# 4. 雷電

## 4.1 要求と役割

十四試局地戦闘機の要求時期は、史実から大きく変えない。要求は1939年後半を中心とする。

瑞星零戦が1942年も有力であるため、雷電を零戦の失敗救済機にはしない。役割を明確に分ける。

- 零戦：艦隊航空、長距離制空、護衛、一般戦闘。
- 雷電：陸上基地防空、爆撃機邀撃、短時間上昇、重武装、高速攻撃。

艦上適合、長大航続、零戦級低速旋回は要求しない。

## 4.2 設計収束の中心

火星を後方へ置き、延長軸でプロペラを駆動する基本構成は維持する。大径発動機の正面抵抗を抑える合理性があるからである。

ただし、次を飛行試験任せにせず、発動機・軸・支持軸受・減速機・プロペラ・発動機架を一体とした地上試験装置で扱う。

- ねじり・曲げ振動。
- 軸受荷重。
- プロペラ翼通過周期。
- 定速装置応答。
- 発動機架との共振。
- 危険回転域。

中心線では、延長軸を廃止せず、初期段階で少し短く太い第二案へ収束する。

冷却では、理論最高速を数km/h犠牲にしても、後列気筒、夏季地上待機、急上昇、連続邀撃、量産隙間、汚れに耐える入口・出口余裕を採る。

視界、脚、ブレーキ、着陸特性も、実物大模型、脚落下、地上滑走試験を前倒しする。零戦並みの扱いやすさにはならないが、初期量産型での致命的な手戻りは減る。

## 4.3 防護・武装

邀撃任務では爆撃機防御火力へ接近するため、初期から次を持つ。

- 操縦席後方・頭部防弾。
- 防火隔壁。
- 燃料遮断。
- 部分防漏。
- 消火設備。

1942年の初期実用型は20mm二門と7.7mm二門を中心とし、1943年に20mm四門・弾道統一型へ進む。四門型を初号量産へ押し込んで主翼・給弾・機銃生産を遅らせない。

## 4.4 日程仮稿

| 段階 | 中心時期 |
|---|---|
| 十四試要求 | 1939年後半 |
| 基本設計・模型 | 1940年 |
| 延長軸・冷却の実寸試験 | 1940年後半～41年 |
| 初試作 | 1941年末～42年初 |
| 火星二〇型級試作 | 1942年春 |
| 部隊審査 | 1942年夏～秋 |
| 先行量産 | 1942年後半 |
| 最初の戦闘可能部隊 | 1942年末～43年初 |
| 20mm四門標準型 | 1943年前半～中盤 |

## 4.5 性能仮稿

| 項目 | 中心範囲 |
|---|---:|
| 発動機 | 火星二〇型級、1,800～1,850馬力 |
| 通常全備重量 | 3,250～3,400kg |
| 最大速度 | 590～600km/h |
| 6,000m上昇 | 5分20秒～5分45秒 |
| 実用上昇限度 | 11,000～11,800m |
| 内部航続 | 950～1,100km |
| 実用邀撃半径 | 250～350km |

1942年完成機は45～70機程度、年末時点の戦闘可能機25～40機程度を中心仮稿とする。各地へ分散せず、ラバウル、トラック、パラオ、台湾、本土等の一個重要拠点へ集中する。

# 5. 烈風とハ43

## 5.1 後継要求が発生する理由

瑞星零戦が強いことは、烈風計画を不要にしない。

計算・試験によって1940～41年には次が明確になる。

- 零戦の主翼・胴体には防護、四門火力、無線、大出力化を同時に吸収する余裕が少ない。
- 高速操縦性と急降下制限を大幅に上げるには基本構造を作り直す必要がある。
- 大径プロペラ、大重量発動機、艦上脚、防護を積むと零戦の基本規模を越える。

したがって烈風は、戦況悪化への緊急反応ではなく、零戦の成長限界を予測した計画として始まる。

## 5.2 要求思想

「全項目で零戦以上」という曖昧な要求を避け、優先順位を分ける。

### 絶対条件

- 空母で安全に発着艦できる。
- 昇降機・格納庫へ収まる。
- 6,000mまで約6分以内。
- 6,000mで630～640km/h級を目標。
- 爆撃機を破壊できる火力。
- 零戦より高い急降下制限と高速操縦性。
- 防弾、部分防漏、防火・消火。
- 無線、航法、酸素、将来装備の余裕。

### 比較調整条件

- 航続。
- 着艦速度。
- 離艦滑走。
- 旋回性能。
- 翼幅・折畳み。

### 零戦と同値を要求しない条件

- 極低速の瞬間旋回半径。
- 異常に低い翼面荷重。
- 機体の軽さそのもの。

旋回要求は、一周旋回、持続旋回、失速速度、ロール率、空戦フラップ時の性能、高速舵力へ分解する。

## 5.3 機体思想

烈風は初めから4.5t級へ成長する艦上戦闘機として設計する。

| 項目 | 中心作業値 |
|---|---:|
| 通常全備重量 | 4,400～4,650kg |
| 主翼面積 | 30～31m²級 |
| 翼幅 | 約14m、翼端折畳み |
| 発動機 | ハ43艦戦型 |
| 離昇出力 | 2,100～2,200馬力級 |
| プロペラ | 四翅、3.85～3.90m級中心、4.0m比較上限 |

大きな主翼は格闘戦信仰だけによるものではない。着艦、過荷重発艦、高高度上昇、燃料・武装・脚の収容、空戦フラップ、将来重量増加を吸収する。

零戦型の極端な軽量化を繰り返さず、防護、四門火力余裕、大型無線、酸素、強い脚、艦上衝撃、将来300kg級の追加装備を初期重量簿へ入れる。

## 5.4 ハ43を主線とする

ハ43は三菱の瑞星・金星・火星系列から、冷却、気筒温度、過給、減速機、大径プロペラ、潤滑、量産公差の経験を引き継ぐ。しかし18気筒クランクケース、主連桿・副連桿、ねじり振動、後列冷却、2,000馬力級プロペラは新しい課題である。

利得は「問題が出ない」ことではない。

> 問題を冷却、燃焼、潤滑、振動、加工公差、取付へ早く分類し、設計へ戻せる。

ことにある。

烈風用は四翅3.85～3.90m級を中心とし、4.0m級は比較上限とする。2,100～2,200馬力を吸収するだけでなく、高速時の翼端マッハ、脚長、艦上衝撃、減速機重量を同時に比較する。深い減速比、ガバナ、四翅ハブを発動機と別々の性能加算にせず、一つの推進系として閉じる。

## 5.5 誉の扱い

誉は排除しない。

- 小径・軽量。
- 早く2,000馬力級を狙える。
- 海軍側の投資がある。
- 紫電、銀河、彩雲等と共通化できる。

一方、量産公差、冷却、潤滑、部隊整備が厳しく、三菱機体との統合もハ43より間接的である。

量産烈風はハ43を主線とする。誉は、ハ43遅延時に脚、着艦、操縦、空戦フラップ等の機体試験を進めるための試験用・保険用機首として残す。完全な二発動機互換機体は作らない。

# 6. 誉と紫電改

## 6.1 誉は改善するが完全にはならない

計算・計測は、気筒温度、油圧、軸受、クランク振動、過給、混合気、点火、ロット不良を早く切り分ける。

それでも誉は、小径18気筒へ高い出力密度を押し込む発動機であり、次の制約を残す。

- 後列冷却。
- 潤滑と軸受。
- 材料代替。
- 高い加工公差要求。
- 燃料・油品質。
- 前線整備。

初期試作・初期量産が改善し、特に1943年以降の部隊中央値と可動率が史実より良くなるが、「1942年から完全な2,000馬力」を置かない。

### 1943～44年の実用出力・整備入力

| 状態 | 中心作業値 |
|---|---:|
| 試験・選別良好機の短時間最大 | 2,000～2,050馬力級 |
| 1943年初期量産の実用短時間出力 | 1,850～1,950馬力級 |
| 1944年前半の標準良品 | **1,900～2,000馬力級** |
| 1944年前半の部隊中央値 | **1,850～1,950馬力級** |
| 5～6km級の実用出力 | **1,550～1,680馬力級を中心** |

金星の整備負担を1.00とした相対作業値では、誉初期量産は1.45～1.65、1944年前半の改善誉でも1.25～1.40程度を残す。計算機世界の主効果は、最高馬力の魔法的上積みではなく、気筒温度・振動・加工公差・ロット差の相関を早く掴み、「当たり発動機」だけでなく量産中央値を試作値へ近づけることに置く。

誉機は全基地へ薄く配らず、予備発動機、専任整備員、工具、部品を持つ基地・飛行隊へ集中させる。空地分離はこの専門整備単位の可搬化を助けるが、誉そのものを金星並みに扱いやすくするわけではない。

## 6.2 強風から紫電改へ

強風計画は、早期水上戦闘機が存在しても消えない。専用水上戦闘機として荒海運用、大出力、自動空戦フラップを試す価値がある。

陸上型紫電では、中翼・長脚・視界・整備の問題を早く認識し、低翼・短脚の紫電改へ早く移行する。

| 段階 | 中心時期 |

| 誉陸上型具体化 | 1942年 |
| 紫電原型 | 1942年末～43年初 |
| 低翼化判断 | 1943年前半 |
| 紫電改原型 | 1943年後半 |
| 部隊審査 | 1944年初頭 |
| 先行量産 | 1944年前半～中盤 |

紫電一一型は数十～百数十機級の過渡型に抑え、紫電改へ移る中心線とする。

### 6.2.1 強風の1943年実戦化・生産――上書き決定

強風は1942年9月FSの量的主力には数えないが、1943年春から正式な水上戦闘機戦力として立ち上がる。

| 時点 | 中心線 |
|---|---:|
| 1942年末 | 実用型仕様ほぼ確定 |
| 1943年1～2月 | 先行量産開始 |

| 1943年10月 | 完成70～90、第一線50～65 |

史実の少数生産より増やすが、零戦・雷電・紫電改を置き換える数百機級大量生産にはしない。

**判断の理由：** 本世界ではNew Caledonia、Port Moresby、Wake、Marshall等の島嶼線を長く保持し、滑走路制圧後にも航空活動を残す需要が史実より長く続く。一方、巨大中央フロートによる速度・上昇・航続・整備上の不利は消えず、F6F主体の制空戦主力にはならない。専用任務が明確なため史実89機級で早期打切りする圧力は弱いが、量的主力戦闘機へ拡大する理由もない。

### 6.2.2 強風の戦術任務

重要環礁では**水上戦闘機分遣隊12機を標準単位**とし、通常即応8～10機程度を中心とする。大基地は2個分遣隊、第二級拠点は8～12機級。

任務優先順位：

1. 敵爆撃機・雷撃機の迎撃。
2. 偵察機・哨戒機の排除。
3. 味方陸上戦闘機の離着陸・滑走路修復時間帯の援護。
4. 水上機泊地の防空。
5. 敵戦闘機との交戦は任務達成に必要な場合だけ。

敵fighter sweepへ全機を正面投入せず、陸上戦闘機がF6Fを拘束した後、SBD/TBF等へ接触する運用を優先する。滑走路が使用不能になった時間帯には、水面から離水できる強風が**一時的に局地防空の数的主力**となり得る。

継続出撃能力は、同条件の陸上戦闘機を100とした場合の**60～75％程度を作業値**とする。これは機体性能ではなく、着水後の曳航、給油、弾薬、海況、整備台への移動を含む基地運用出力である。

**判断の理由：** 強風の価値はF6Fを一対一で上回ることではなく、敵が「滑走路を潰せば基地航空は終了」と処理できなくなることにある。飛行場と水上機泊地を別々に攻撃させ、護衛戦闘機を爆撃隊へ残させることが主効果である。

## 6.3 「つなぎ」の意味

紫電改は、零戦が役に立たなくなったため海軍戦闘機全体を背負う機体ではない。

- 後期零戦：量的主力、長距離護衛、空母一般隊、小規模基地。
- 雷電：基地邀撃。
- 紫電改：陸上精鋭隊、高速制空、戦闘爆撃。
- 烈風：次期艦上主力。

後期零戦が戦えるため、紫電改は全戦域へ薄く撒かれず、重要基地と精鋭隊へ集中できる。

# 7. 後期零戦と金星零戦改

## 7.1 瑞星後期零戦

瑞星二一型零戦は1942年も量的主力として十分に強い。1942年後半以後の後期型は、単なる発動機出力増加ではなく、短縮丸翼端、カウリング、推力式単排気管、主翼・尾翼剛性、補助翼、高速急降下制限、20mm二号銃、13.2mm機銃、無線、局部防弾、防火・燃料遮断を一体で成熟させる。

## 7.2 金星零戦改が発生する理由

瑞星系列は1,080馬力級以後の大幅な出力増加が難しく、防護、無線、火力、主翼強化で重量が増える。一方、1943年には金星六〇型が前線標準化へ入る。

三菱は1942年中に、瑞星延命案と金星換装案を比較する。

金星化は単なる発動機交換ではない。

- 発動機架・防火壁。
- カウリング、油槽、補機、吸排気。
- プロペラ。
- 前部胴体。
- 中央翼・主脚・車輪。
- 重心・燃料配置。
- 尾翼・艦上荷重。

を改める中規模再設計である。

それでも操縦席以後の胴体、主翼基本形、生産治具、操縦系統、艦上装備、部品体系を相当利用できるため、新規戦闘機より早い。

- 瑞鳳・祥鳳・龍鳳級：瑞星型との混成を中心とし、金星型比率を抑える。
- 龍驤：全面換装せず瑞星型主体を維持する。

主翼基本寸法・折畳時占有面積を大きく変えないため主要空母で格納上の名目搭載数ペナルティは原則置かない。一方、進入速度、着艦間隔、制動索復帰、3.2mプロペラ周辺安全間隔、発艦滑走により航空作業回転率は低下する。

1943年春～夏の艦上審査では、150km/h台進入時のフック、主脚、中央翼、制動荷重を制式化ゲートとする。中心線では1943年9月先行量産を維持するが、局部構造で問題が出た場合は1～2か月級の遅延感度を残す。

先行量産中心は1943年9月6、10月12、11月24、12月36機程度。1944年の生産数は発動機供給・工場・予備率を別途統合するまで計画値として扱い、航空戦へ完成数を直入れしない。

## 7.4 完全新設計の金星主力戦闘機

技術的には成立し得るが、同時期に雷電、紫電改、烈風が存在するため、性能帯と工場投資が中途半端になる。

誉・ハ43・雷電が大幅に失敗し、金星生産能力が余る等の強い引き金がない限り、中心線に置かない。本世界の「海軍五式戦」的な中間役は金星零戦改が担う。

**判断の理由：** 金星零戦改の再設計範囲は大きいが、操縦席以後・主翼基本形・艦上装備・生産体系を相当流用できる。完全新設計をもう一系列立てるより、烈風へ設計資源を集中する方が合理的。

# 8. 自動空戦フラップ

## 8.1 技術的位置づけ

自動空戦フラップは、速度と荷重を感知し、必要な揚力を得るためフラップ角を機械・空圧・油圧で変えるアナログ制御装置である。

計算機が機上で操舵するのではない。地上で、速度、荷重倍数、重量、高度、フラップ角、揚力、抗力、蝶番荷重、主翼荷重を反復し、機械装置へ写し込む作動曲線を作る。

## 8.2 計算機が効く部分

- 速度・荷重・フラップ角の最適包絡線。
- 作動開始と格納点に差を付けるヒステリシス。
- ハンチング防止。
- 水銀量、ばね、管径、弁摩擦、油圧公差の感度。
- 高動圧誤展開時の安全限界。
- 量産機ごとの校正・不良判定。

実機でしか分からない振動、乱流応答、油圧温度差、左右非対称、配管漏れ、塩害は残る。

安全思想は次とする。

- 故障時は原則格納側。
- 操縦者が解除可能。
- 着陸操作が自動空戦系より優先。
- 左右差が大きい場合は両側格納。
- 高動圧では機械的に展開不能。

## 8.3 日程

| 時期 | 中心段階 |
|---|---|
| 1938～39年 | 手動空戦フラップ、揚抗力・旋回表研究 |
| 1940年 | 強風とともに自動化案具体化 |
| 1940～41年 | 感圧・油圧装置、実寸フラップ試験 |
| 1941年後半 | 風洞・飛行試験装置完成 |
| 1941年末～42年前半 | 強風試作機で自動作動試験 |
| 1942年中 | 実用第一型成立 |
| 1942年末～43年 | 紫電用小型化・信頼性向上 |
| 1943年以降 | 紫電改・烈風の標準技術 |

発想が何年も早まるのではなく、強風試作段階の完成度と量産校正が改善する。

## 8.4 機種別採用

- 強風：主要な成立装備。
- 紫電・紫電改：成熟装備として継承。
- 烈風：初期設計から標準装備。
- 金星零戦改：初期は手動、後期に簡易自動型を採用し得る。
- 雷電：低速格闘が主任務でないため、手動戦闘位置または簡易型に留める。

# 8A. 1943年夏の基地邀撃戦闘機体系

1943年夏は、米高速空母増勢により「新しい局戦を考える」時期ではなく、既に成立している雷電・零戦・陸軍邀撃機をどこへ集中するかが変わる時期とする。

## 8A.1 雷電

現行時計は、1942年後半先行量産、1942年末～43年初の最初の戦闘可能部隊、1943年前半～中盤の20mm四門標準型を維持する。

1943年8月までの中心作業値：

- 累計完成 **220～250機**。
- 部隊・教育・修理を除く第一線 **150～175機**。
- うち20mm四門標準型 **80～100機級**。
- 1943年後半は30～40機/月級へ増勢し、年末累計**380～420機前後**。

配備思想：一基地6機ずつではなく、Midway、New Caledonia、Santo、Truk、Palau、本土等の重要基地へ18～30機級邀撃隊として集中する。

**判断の理由：** 米新空母群への対処で必要なのは短航続の欠点を消すことではなく、レーダー・見張り・無線統制から短時間で上がり、攻撃隊を中高度で迎撃する能力である。雷電は火星をG4M/H8K等と競合するため、必要性増大を理由に月産100機級へ無制限増産しない。

## 8A.2 紫電・紫電改

- 紫電原型：1942年末～43年初。
- 低翼化判断：1943年前半。
- 紫電一一型：1943年は部隊試用～先行生産に限定し、長期大量生産しない。
- 紫電改第一原型：**1943年9～10月**。
- 部隊審査：**1943年12月～44年2月**。
- 最初の実戦隊：**1944年3～4月**。
- 先行量産：1944年前半～中盤。

**判断の理由：** 米空母出現を見て1943年秋の救世主として紫電改を前借りしない。一方、中翼・長脚の過渡型を大量生産するより、実戦・生産経験を少数の紫電で得て低翼型へ早く切り替える方が、本世界の試験・比較文化に合う。

## 8A.3 1943年8月時点の役割分担

| 任務 | 主力 |
|---|---|
| 空母／長距離 | 瑞星後期零戦 |
| 重零戦・中間型 | 金星零戦改（試作～量産移行） |
| 海軍基地昼間邀撃 | **雷電** |
| 海軍陸上高速万能 | 紫電→紫電改へ移行 |
| 次期艦戦 | 烈風 |
| 陸軍邀撃 | Ki-44-II |
| 陸軍一般高速戦 | Ki-61 |
| 陸軍次期主力 | Ki-84、量産立上げ中 |
| 高高度排気ターボ | 研究・飛行試験段階 |
| 純ターボジェット | 地上全機関試験段階 |

# 9. 日本噴進研究の史実基準

日本の噴進航空は一本の連続計画ではなく、三つの流れとして扱う。

1. 1935年以降の萱場・無尾翼・ラムジェット研究。
2. 1930年代後半の排気タービン研究を土台に、1942年から始まる国産ターボジェット探索。
3. 1944年のドイツ技術流入による計画再編。

萱場線はネ20の直接の祖先ではない。無尾翼機、油圧機構、ラムジェット燃焼、補助ロケット、高速飛行試験という別枝である。

1942～44年の国内研究は、遠心圧縮機、軸流圧縮機、遠心＋軸流、モータージェット、ターボプロップ、ラムジェット、液体ロケットを並行して比較した探索期である。

ドイツ情報は日本のジェット研究を始めさせたのではなく、既に進んでいた探索へ、飛行実績のある構成と実物寸法を与え、低見込み案を整理した。

---

# 10. 萱場・かつをどり線

## 10.1 研究が残る理由

萱場は1935年から成層圏高速機と無尾翼機を研究していた。本世界では、無尾翼機の安定、重心、翼端失速、フラッターを計算・風洞・滑空試験で整理できる。

さらにカ号で、ローター振動、質量釣合い、クラッチ、特殊航空機を実用へ近づけた信用がある。このため、無尾翼試験事故が起きても会社・研究線全体を切らず、1941年に主力兵器計画から特別研究へ縮小する。

## 10.2 残る成果

- 無尾翼機の縦・横安定、重心、翼端舵、失速資料。
- ラムジェットの吸気、保炎、燃料噴射、点火、燃焼筒。
- 油圧操縦、ロケット補助加速、切離し、安全装置。

地上発進する実用邀撃機「かつをどり」は中心線に置かない。ラムジェットは静止推力を持たず、哨戒・待機・再出撃に向かず、機体・補助ロケット・主機を同時に完成させる必要がある。

## 10.3 日程

| 時期 | 中心線 |
|---|---|
| 1939～40年 | 無尾翼滑空機の安定・構造試験 |
| 1940～41年 | 増加試験、動力化・ラムジェット研究 |
| 1941年 | 主力兵器化見送り、特別研究として継続 |
| 1942年前半 | 陸軍噴進研究へ技術者参加 |
| 1942年後半 | ネ0、補助ロケット、無尾翼試験を統合 |
| 1943年 | 母機搭載ラムジェット試験 |
| 1944年 | 母機投下式無人・有人高速実験機 |

かつをどりの最終的な実用品候補は、有人戦闘機より高速標的、対空・対艦誘導弾、母機発射兵器である。ただし誘導・電波・弾頭は別研究とする。

# 11. 1942年からの国産ターボジェット

## 11.1 開始時計

計算機が存在しても、軍用ターボジェット計画を1930年代前半から本格化させない。外国での飛行情報、高高度過給機経験、発動機将来限界、戦時予算、軍内推進者が必要であり、本格要求は1942年を中心とする。

ただし開始時の基盤は史実より厚い。

- 排気タービン過給機の回転体・高温試験。
- 軸受温度、振動、圧力、流量の多点計測。
- 発動機会社間の共通試験帳票。
- Type 2による熱収支、段効率、回転危険域の反復。
- 萱場の燃焼・無尾翼・油圧経験。

## 11.2 1942～44年の中心線

### 1942年

海軍はTR／ネ10系列、陸軍はネ0、ネ1～4等を開始する。萱場班はネ0ラムジェットと無尾翼投下試験へ参加する。ドイツ製ジェット情報を前提とせず、排気タービン、遠心圧縮機、燃焼、回転体計測の国内蓄積から開始する。

### 1943年

- ネ0：1943年夏～秋に母機投下・空中着火試験。
- ネ4級：圧縮機、燃焼器、タービン単体試験を収束し、**1943年9～11月に短時間完全自立運転**へ到達する中心線。
- 1943年末には選別機で数十分級耐久試験へ進む。
- 排気タービン過給機は純ジェットより先に飛行試験級へ進み、高高度戦闘機用の研究装備として1943年中に実機試験を行う。

### 1944年前半

ネ4を母機懸吊または小型双発実験機へ載せ、**1944年3～5月級に最初の純ターボジェット飛行**を狙う。

これは推力300kg級、短寿命、大直径の試験機であり、実戦主力ではない。排気ターボも1943年末～44年初に雷電等の高高度試験型で飛行可能だが、1943年の米艦載機迎撃の主役にはしない。

**判断の理由：** 計算機と増加ニッケルは熱収支、段効率、危険回転数、材料試験回数を改善するが、耐熱翼の製造、軸受、燃焼振動、溶接、サージを消せない。よって独力研究を数か月前倒しするが、1943年中の実戦ジェットは認めない。

# 12. 遣独技術流入の確定条件

## 12.1 航路・戦況

インド洋情勢は、日本側が全面支配する強い分岐にはしない。1942～43年の東部インド洋とマラッカ海峡で史実より若干安全性が高く、1944年には英潜水艦・航空・東洋艦隊の圧力が増す中庸線とする。

潜水艦の機関信頼性、航続、トリム表、暗号防御、通信沈黙、シンガポールでの人員・資料航空転送が、史実の待伏せ損失を減らす。

## 12.2 結果の固定と流入時期

史実でも日本のジェット研究は1942年に始まっており、BMW 003・Jumo 004等の具体的ドイツ技術が日本側設計を決定的に整理するのは1944年の遣独連絡以後である。本世界でも**1943年夏時点ではドイツ製完成ジェットをまだ知らない**。

遣独潜水艦の機関信頼性、トリム、暗号防御、通信沈黙、Penang/Singaporeからの技術者・図面の航空転送改善を反映し、物語上の中心結果を次とする。

- I-30：欧州から東南アジアまで届いた重要図面・技術情報は、事故・触雷前に航空転送し情報喪失を防ぐ。
- I-8：史実同様の往復成功を維持。
- I-34：狭いMalacca海域の危険は暗号改善で消えず、喪失可能性を高く残す。
- **I-29：史実より追跡精度が低く、日本帰還成功を中心線とする。BMW 003、Jumo 004、HWK 509、Me 262/163関連資料・主要部品を持ち帰る自然な主搬送艇。**
- I-52：1944年Atlantic ASWは依然危険。欧州到達は約60％、完全往復35～45％級の条件付きとし、自動成功にしない。

六回前後の主要遣欧任務のうち、**2～3回の完全往復、4～5回の片道有意貨物到達**を作業中心とする。大量物資輸送ではなく、技術価値／重量の極端に高い資料・見本・技術者移動として扱う。

ドイツ情報は日本のジェット研究を始めさせるのではなく、1942～44年に国内で得た燃焼器、圧縮機、軸受、タービン、計測経験へ**答え合わせと設計空間の縮小**を与える。

**判断の理由：** 本世界の暗号・機関・航法改善はSIGINT待伏せや故障損失を減らせるが、Malacca・大西洋ASWという地理的危険そのものを消さない。また1943年以前にBMW/Jumo情報を前借りすると、史実の技術流入時計を無視するため禁止する。

## 12.3 ニッケル

New Caledoniaその他からのニッケル増加は、研究・試作部門にとって意味があるが無制限ではない。

航空噴進部門では優先的に、

- 材料試験片。
- 原型・耐久試験用発動機。
- 先行飛行用の選別発動機。
- タービン翼、排気弁、軸受等の重要部位。

へ回す。1943年のジェット・ターボ研究用として**ニッケル換算20～40t級の特別研究枠**を確保することは可能とする。

量産型では低ニッケル鋼、マンガン・クロム・モリブデン系材料、冷却翼、低いタービン入口温度、短寿命交換を併用する。

**判断の理由：** 研究用数十基に必要な高級材料量は艦艇・量産航空機全体より小さく、New Caledoniaからの追加供給は試験回数を増やすのに効く。しかし材料製法・精密加工・軸受・溶接の能力はニッケル在庫だけでは増えないため、量産ジェットの急速成立には直結させない。

# 13. 1944年再編後の五系列

ドイツ技術到着後、日本は一種類へ全賭けしない。

| 系列 | 位置づけ | 主用途 |
|---|---|---|
| ネ4系 | 国内経験を切らさない低危険線 | 試験、練習、計測 |
| ネ20系 | 最短実用の小型軸流主線 | 軽攻撃、偵察、限定邀撃 |
| Jumo 004級国産型 | 次世代高推力主線 | 重邀撃、高速偵察、軽爆撃 |
| ネ0・萱場線 | ラムジェット研究 | 高速実験、将来誘導兵器 |
| HWK／秋水線 | 特殊点防空 | ロケット邀撃 |

カンピーニ式、見込みの薄い重複案、地上ロケット発進式の実用かつをどりは中止する。国内で得た燃焼器、軸受、タービン、圧縮機、計測の経験は新主線へ移す。

# 14. ネ4系

ネ4は遠心圧縮機を用いる比較的低危険な国内系統である。

| 項目 | 中心仮稿 |
|---|---:|
| 静止推力 | 280～330kgf |
| 重量 | 300～400kg級 |
| 初期連続運転 | 数十分級 |
| 成熟後用途 | 数時間級試験、練習、計測 |

利点は国内過給機・遠心圧縮機技術を使えること、欠点は直径と推力不足である。

専用戦闘機を量産せず、Ki-48級母機への懸吊試験、小型双発実験・練習機へ使う。ジェット離着陸、スロットル遅れ、片発飛行、始動、火災、整備、搭乗員教育を先行経験する。

ネ20が安定すれば生産は終了するが、1944年に飛行経験を持てること自体が価値となる。

# 16. Jumo 004級国産型

Jumo 004級はネ20拡大型ではなく、独立した900kgf級主線とする。実物から、低合金材、冷却翼、板金燃焼筒、簡易製造、短寿命交換、摩耗・亀裂位置を学べる。

## 16.1 発動機仮稿

| 項目 | 1945年試作 | 1946年初期量産候補 |
|---|---:|---:|
| 静止推力 | 780～880kgf | 820～920kgf |
| 重量 | 750～900kg | 720～850kg |
| 寿命 | 数時間～十数時間 | 10～30時間級 |
| 台上運転 | 1945年後半 | － |
| 飛行試験 | － | 1946年前半 |

工場・電力・空襲・資材条件が悪化すれば、ここまで到達しない。1946年線は将来仮稿である。

## 16.2 搭載機

6.5～8.0t級の双発重邀撃・高速偵察機を中心とする。

| 項目 | 中心仮稿 |
|---|---:|
| 最大速度 | 740～790km/h |
| 武装 | 20～30mm×2～4 |
| 爆装 | 500～1,000kg |
| 実用半径 | 400～650km級 |
| 乗員 | 1～2名 |

主任務は高速邀撃、写真偵察、軽爆撃の順とする。1945年中の大量戦力化はしない。

# 17. ラムジェット・かつをどり後継

## 17.1 1943～45年の実験

- 母機懸吊による高度・速度別点火。
- 無尾翼小型滑空機の投下。
- 固体ロケット短時間加速。
- 母機投下式無人機。
- 1944～45年に有人高速実験機一～数機。

初期実験機の中心仮稿は、点火350～450km/h、有効推力500～700km/h、短時間最大650～800km/h、燃焼数分級とする。

## 17.2 実用品の方向

有人邀撃機より、次へ進む。

- 高速標的。
- 対空誘導弾。
- 対艦誘導弾。
- 爆撃機発射高速兵器。

誘導装置、無線、ジャイロ、弾頭、母機運用は別正本で監査する。ラムジェット主機が成立しても誘導兵器が自動的に完成するわけではない。

# 18. HWK・秋水線

実物HWK 509と完全資料が届くため、燃料ポンプ、タービン、燃焼室、噴射器、調速、配管、シール、始動・停止を正確に理解できる。

しかし甲液・乙液の生産、輸送、給油、事故、搭乗員訓練、無動力着陸は依然として大問題である。

| 段階 | 中心仮稿 |
|---|---|
| 滑空訓練・地上燃焼 | 1944年後半 |
| 無動力・短時間推進試験 | 1945年初頭 |
| 動力飛行 | 1945年春～夏 |
| 少数部隊審査 | 1945年後半 |
| 条件良好時の小部隊 | 1946年 |

秋水は重要工業地帯・基地上空の点防空機であり、雷電、紫電改、烈風を置き換えない。早期警戒と地上管制がなければ有効性が低い。

# 19. 1944～46年の戦力像

## 19.1 1944年

- 雷電が基地邀撃の実用系列。
- 紫電改が先行量産へ入る。
- 烈風は試作・審査。
- 金星零戦改が量産移行。
- ネ4が試験飛行へ到達する可能性。
- ネ0・萱場線は空中着火・無尾翼高速試験。
- ドイツ実物到着後、噴進研究を再編。

## 19.2 1945年前半

- ネ20双発試作機が飛行可能。
- 秋水が地上・滑空・動力試験。
- 900kgf級は部品・台上開発。
- 主戦力はなおレシプロ機。

## 19.3 1945年後半

条件が保たれれば、ネ20機と秋水が少数部隊審査へ入る。高速偵察、軽攻撃、点防空に局地効果を持つが、航空戦全体を置き換えない。

## 19.4 1946年

戦争継続と工業基盤残存を条件に、ネ20機数十機級、900kgf級双発機の試作・先行部隊、秋水小部隊、ラムジェット誘導兵器研究が成立し得る。

この年でも主力は、後期零戦、金星零戦改、雷電、紫電改、烈風、陸軍レシプロ戦闘機である。

# 20. 生産・資材・部隊統合上の注意

後期航空機は、性能表だけで戦力化を判定しない。

## 20.1 競合資源

- 金星・火星・誉・ハ43の工場、試験台、予備品。
- 四翅プロペラ、減速機、軸受。
- 20mm・30mm機銃と弾薬。
- 防弾鋼、防漏材、無線、酸素。
- アルミ、銅、ニッケル、クロム、モリブデン。
- 熟練工、検査員、溶接工、熱処理設備。
- 搭乗員、整備員、教育機、燃料。
- 空母昇降機、甲板、基地滑走路、電源、始動設備。

## 20.2 発動機分散の意味

- 瑞星・金星：成熟した量産戦闘機を支える。
- 火星：邀撃と大型機で競合。
- 誉：紫電改等の高性能小径機。
- ハ43：烈風・将来大型機。
- ネ20・Jumo級：短寿命・少数特殊機。

系列分散は保険になるが、工具、部品、教育、在庫を複雑化する。部隊ごとに主系列を集中し、同一基地へ過剰な発動機種類を置かない。

# 21. 現行結論

本世界の後期海軍戦闘機体系は、一機種がすべてを置き換える形にならない。

> 後期零戦は成熟した量的主力として残る。金星零戦改が速度・上昇・防護・火力を増した中間量産機となる。雷電は火星を用いる基地邀撃機、紫電改は誉を用いる陸上高性能戦闘機、烈風はハ43を用いる次期艦上主力となる。

発動機では、金星・火星の早期熟成が既存機の性能を二重に増すのではなく、後期型、換装、可動率、日程を支える。誉は改善するが完全にはならず、ハ43は三菱系列の蓄積を使って烈風へ間に合わせる。

自動空戦フラップは、川西の発想を計算・試験・量産校正が育てる。強風、紫電改、烈風で重要な装備となり、金星零戦改には簡易型が入り得る。

噴進航空では、萱場のかつをどり線が実用戦闘機ではなく研究枝として残り、1942年の国産ターボジェット探索へ接続する。1944年にドイツの実物と資料が届くことで、国内研究を全面廃棄せず、ネ4の早期飛行経験、ネ20の最短実用線、Jumo 004級の次世代線、ラムジェット研究、秋水の特殊防空へ再編する。

最大の差は、1945年8月に一機だけ飛ぶ孤立した技術ではなく、1944年から飛行経験を持ち、1945年に小型実用線、1946年に高推力線へ続き得る継続的な噴進航空体系が形成されることである。ただし、1945～46年の具体的部隊規模は戦況・工業基盤に依存する将来仮稿である。
