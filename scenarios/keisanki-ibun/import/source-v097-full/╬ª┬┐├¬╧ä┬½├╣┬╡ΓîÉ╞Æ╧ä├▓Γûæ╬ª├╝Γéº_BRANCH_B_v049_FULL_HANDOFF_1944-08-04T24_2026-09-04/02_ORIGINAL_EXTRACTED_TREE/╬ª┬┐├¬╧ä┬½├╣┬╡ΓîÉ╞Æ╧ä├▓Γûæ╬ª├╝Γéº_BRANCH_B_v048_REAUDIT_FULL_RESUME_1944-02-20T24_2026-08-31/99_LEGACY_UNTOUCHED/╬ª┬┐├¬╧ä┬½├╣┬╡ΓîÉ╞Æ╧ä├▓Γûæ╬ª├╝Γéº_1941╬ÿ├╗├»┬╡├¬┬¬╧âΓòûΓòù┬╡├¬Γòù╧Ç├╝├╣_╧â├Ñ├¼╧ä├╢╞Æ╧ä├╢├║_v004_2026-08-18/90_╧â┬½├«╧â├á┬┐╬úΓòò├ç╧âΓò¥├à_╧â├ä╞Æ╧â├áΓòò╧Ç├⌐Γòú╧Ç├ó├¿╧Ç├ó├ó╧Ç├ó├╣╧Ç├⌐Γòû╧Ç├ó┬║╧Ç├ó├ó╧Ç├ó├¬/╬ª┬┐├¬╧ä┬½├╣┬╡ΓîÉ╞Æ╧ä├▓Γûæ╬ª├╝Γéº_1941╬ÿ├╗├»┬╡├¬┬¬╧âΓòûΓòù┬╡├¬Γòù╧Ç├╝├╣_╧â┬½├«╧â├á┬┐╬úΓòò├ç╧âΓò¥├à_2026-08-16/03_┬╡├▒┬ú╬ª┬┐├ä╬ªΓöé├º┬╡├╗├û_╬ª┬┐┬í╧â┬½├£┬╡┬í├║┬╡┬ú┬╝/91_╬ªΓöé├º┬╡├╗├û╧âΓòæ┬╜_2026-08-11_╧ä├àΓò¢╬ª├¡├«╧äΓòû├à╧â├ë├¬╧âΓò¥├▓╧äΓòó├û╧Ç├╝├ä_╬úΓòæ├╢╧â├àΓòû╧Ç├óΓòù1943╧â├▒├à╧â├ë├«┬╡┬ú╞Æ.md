# 計算機異聞・現行総合引継ぎ――五号・1943夏同期

本書は旧90を削除せず、2026-08-11時点の継続地点を要約した**旧引継ぎ**である。2026-08-12以後は92を最新引継ぎとして優先する。技術数値は各正本10～70、現行歴史線は85～87を優先する。

# 1. 方法上の追加決定

今後の判断には、結論だけでなく**「判断の理由」**を併記する。理由は、史実基準、当時得られる情報、物理・工業律速、戦況依存、代替案との比較のうち必要なものを明記する。

未発生戦闘の命中・撃沈艦名は、技術的未確定ではなく戦闘確率変数として事前固定しない。

# 2. FSの現行結果

- 1942年9月1日、New Caledonia南部戦略地区を日本が作戦的に奪取。
- Wasp沈没、Yorktown大破撤退、翔鶴大破。日本輸送船4～5隻沈没。
- 日本地上損害約5.3～5.8千、連合死傷約4.3～4.8千＋捕虜・行方不明2.5～3.2千。
- 第2海兵連隊増強約4,250から当面非稼働1,300～1,450、中心約1,375＝約32％。FS全USMC損耗約1,400～1,550。
- 日本はFiji/Samoa連続占領を行わず、Santo＋NCを基地化し、Efate/Fijiは圧迫対象とする。
- New Caledonia金属は名目フランス主権・民政・企業法人を残し、SMO復旧、SLN等との契約購入、Banque de l'Indochine／円・ピアストル clearing、現地フラン＋物資＋凍結債権等の組合せが中心。接収在庫と継続民間生産を区別する。

**判断の理由：** FSの戦略目的は米豪交通への圧迫であり、島全土の殲滅占領やFijiまでの無制限拡張ではない。補給線・潜水艦狩場・空母航空隊損耗を考えると、勝利後こそ基地化へ切り替える合理性が高い。

# 3. 技術正本の今回更新

## 3.1 伊400・晴嵐

- 1941年秋三機型凍結、1942年春第一艦起工。
- 伊400：1944年1月就役、3～4月戦闘即応。
- 伊401：1944年4月就役、5～6月即応。
- 伊402：1944年7～8月就役。
- 計6隻を実発注中心。18隻完成は採らない。
- 晴嵐50～55機級。二艦六機攻撃は1944年5～6月中心。
- 六隻の機会費用：潜高約4隻＋大型巡潜約1隻相当。

**判断の理由：** 山本生存・船腹改善で史実末期の縮小圧力は弱いが、特殊大型潜水艦を18隻量産する費用は潜水艦隊全体の効率と釣り合わない。

## 3.2 カ号

- 対潜だけでなく本来用途の砲兵観測・連絡を正本化。
- 五号へ12機配当、発起9～10即応。
- 平地・盆地で観測有効、山岳深部で不適。

## 3.3 Ki-84・Ki-100・Ki-67

- Ki-84：1942年12月初飛行、1943年7月先行量産、11月初戦隊。標準630～642km/h。1944年計画約1,700機。
- Ki-100：1943年末検討、1944年試作・少数先行。Ki-84成功下では史実型大量「五式戦」にならない。
- Ki-67：1942年末～43年初原型、1944年1月量産、44年6～7月初戦力。五号には間に合わない。

## 3.4 金星零戦・雷電・紫電改・ジェット

- 金星零戦改：通常全備3.12～3.22t、標準592～600km/h、良好601～606、行動半径650～750km級。1943年9月先行量産。
- 主要空母では名目搭載数減なし。小型空母は瑞星型との混成。
- 雷電：1943年8月累計220～250、第一線150～175級。新米空母群により重要基地邀撃へ優先集中。
- 紫電改：1943年9～10月原型、1944年3～4月初実戦隊。
- 国産ネ4級：1943年9～11月短時間自立運転、1944年春初ジェット飛行中心。
- 1943年夏時点ではBMW 003/Jumo 004の完成情報はまだない。I-29等による1944年流入は、研究開始ではなく答え合わせになる。
- New Caledonia等の追加ニッケルは1943年研究用20～40t級特別枠を可能にするが、製造技術を代替しない。

# 4. Addu・Indian Ocean

- 1942年6月25日±10日、Addu＝Port Tをほぼ確定。
- 攻撃せず、所在を知る敵基地・交通ノードとして秘匿利用。
- 1942年後半のIndian Ocean投入は8～10隻級中心。
- Addu情報そのものの追加撃沈5～7隻、3～5万GRT。
- Indian Ocean全体の史実差：14～20隻、8～13万GRT、中心17隻・約10.5万GRT。
- shipping tax：全体2～4％、危険航路夏秋6～9％→年末3～5％。
- 英側護衛・哨戒残置：護衛艦8～12隻相当＋長距離哨戒2～3個飛行隊。

**判断の理由：** Addu情報で初期接触効率は上がるが、連合側は迂回・船団化・航空哨戒で反応する。旧20～35隻級を半年同率で外挿するのは過大。

# 5. 五号作戦現行線

旧82の「B-29まで大陸大作戦なし」は撤回。史実で準備発令まで進んだ五号作戦が、南東方面の消耗・船腹中止条件の弱化により実施される。

- 1943年3月27日発動。
- 4月15日洛陽。
- 5月4日潼関。
- 5月15日西安。
- 6月1日宝鶏、第一期終了。
- 6月12日第二期。
- 7月9日略陽。
- 7月24～25日勉県・陽平関突破。
- **8月6日漢中占領、第二期終了。**
- 日本累積死傷等約3.1～3.5万、中国約9.5～11万級。
- 漢中から広元へはまだ進めない。補給・政治・太平洋を再判定する。

**判断の理由：** 日本は航空・砲兵・偵察で優勢だが、道路破壊、秦嶺、大巴山、悪天候、鉄道終端という物理的兵站を消せない。作戦勝利と重慶政権崩壊を同義にしない。

# 6. 1943年8月6日の太平洋

- 5月Attuを米軍が奪回。
- 7月日本はKiska撤収。
- Enterprise、Yorktown CV-5は復帰済み。
- Essex、CV-10 **Saratoga II**、Independence等がPacificへ集結し、8月後半から新高速空母群が実戦可能。
- 9月には米側の量的反転が明確になる。

Midway日本側：

- 地上守備4.8～5.5千、島内総員6.5～7.2千中心。
- 零戦＋雷電32～38、危機時42～48。
- 大型陸攻常駐はせず、偵察・潜水艦支援・基地邀撃を主価値とする。
- 主力艦隊の自動救援義務は設定しない。
- 撤収時は港・航路、燃料、滑走路要点、淡水・発電、工作機械を破壊し、「米軍にMidway基地を再建させる」計画を持つ。

# 7. 中国戦時経済・金支援

- 五号の日本側国家経済負荷はまだ耐えられるが、陸軍軍需・鉄道・航空燃料を拘束し、1943年夏からPacific防衛備蓄と競合する。
- 中国側は法幣増刷、歳入・実物徴発基盤喪失、難民、敗走中央軍、四川への徴発が同時進行。
- 民間暗黙相場は漢中危機時70～80法幣/USD級の短期悪化があり得る。
- 米国の金支援は価値密度が高いため重量上は可能だが、Hump軍需と競合。India gold swap等を用い、8月上旬まで30～50t級追加を中心とする。
- 金・海外ドル資産だけでは四川の米・塩・布・燃料へ自動変換されない。
