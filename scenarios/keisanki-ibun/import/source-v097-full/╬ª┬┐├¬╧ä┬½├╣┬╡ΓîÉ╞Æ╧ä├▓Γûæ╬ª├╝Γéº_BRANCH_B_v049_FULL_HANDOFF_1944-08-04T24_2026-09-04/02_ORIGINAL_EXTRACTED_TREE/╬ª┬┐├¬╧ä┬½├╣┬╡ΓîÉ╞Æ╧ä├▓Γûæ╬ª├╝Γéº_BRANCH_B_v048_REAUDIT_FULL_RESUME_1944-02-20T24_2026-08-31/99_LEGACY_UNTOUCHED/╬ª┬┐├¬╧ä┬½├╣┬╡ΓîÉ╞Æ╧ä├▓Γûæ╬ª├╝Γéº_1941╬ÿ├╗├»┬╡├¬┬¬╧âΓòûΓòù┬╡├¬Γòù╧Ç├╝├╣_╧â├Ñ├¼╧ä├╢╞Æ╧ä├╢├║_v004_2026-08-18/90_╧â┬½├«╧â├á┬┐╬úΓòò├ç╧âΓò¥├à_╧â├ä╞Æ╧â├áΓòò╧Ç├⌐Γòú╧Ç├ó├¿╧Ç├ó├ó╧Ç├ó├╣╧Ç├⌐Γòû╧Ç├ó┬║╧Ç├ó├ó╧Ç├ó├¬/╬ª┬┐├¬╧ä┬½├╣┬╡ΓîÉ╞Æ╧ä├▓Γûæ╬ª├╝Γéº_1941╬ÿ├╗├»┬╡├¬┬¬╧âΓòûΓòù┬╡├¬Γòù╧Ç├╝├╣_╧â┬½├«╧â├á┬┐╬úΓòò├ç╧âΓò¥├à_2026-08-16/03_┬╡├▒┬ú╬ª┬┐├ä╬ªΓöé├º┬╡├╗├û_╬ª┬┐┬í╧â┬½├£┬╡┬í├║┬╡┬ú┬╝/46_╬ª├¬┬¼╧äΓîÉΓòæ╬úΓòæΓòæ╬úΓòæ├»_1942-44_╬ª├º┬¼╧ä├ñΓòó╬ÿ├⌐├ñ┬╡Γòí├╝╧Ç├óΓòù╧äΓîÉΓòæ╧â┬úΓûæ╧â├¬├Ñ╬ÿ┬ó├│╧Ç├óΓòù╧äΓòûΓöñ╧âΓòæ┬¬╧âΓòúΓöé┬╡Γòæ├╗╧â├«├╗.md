# 1. 監査理由

従来正本は、MI後に熟練搭乗員の一部を教官・再編要員へ戻す案を置いていた。しかしこれは、**海軍が1942年夏に突然「熟練者を教育へ回すべきだ」と制度改革を悟った**ように見えやすい。

実際には、意図的な教官ローテーションが弱くても、戦争中の航空人員には次の自然な往復が発生する。

- 戦傷・病気・疲労による内地療養。
- 空母損傷・入渠に伴う航空隊の陸上再編。
- 航空隊の損耗補充・改編・新機種転換。
- 補充機受領のための内地往復。
- 新造・修理明け空母へ航空隊幹部・甲板要員・整備員を割り当てるための転属。
- 艦喪失後の生存航空士官・航空員を航空本部、学校、試験・新編部隊へ再配置する人事。
- 基地損傷・戦域移動による飛行隊と基地側組織の分離・再結合。

本世界ではGuadalcanal/Rabaul型の決死的な逐次投入が小さく、これらの往復者が史実より高い確率で**次の任地へ到達する**。空地分離が進むと、人員はさらに艦・基地へ固定されなくなる。

したがって現行中心線では、

> **自然還流 → 人員の撹拌 → 部隊間練度差の可視化 → 最低練度を引き上げる平準化 → 限定的な意図的熟練核配分**

という順序を採る。

「精鋭を大量に学校へ引き抜いたから1944年も強い」という単純因果は採らない。

# 2. 史実基準――人員は実際にかなり動いていた

## 2.1 MI後の強制的な内地還流

USSBSの高田利種少将聴取では、MI後の第一航空艦隊搭乗員について、30%が負傷し、30%が内地へ療養、40%が九州の第三艦隊へ移って再訓練に入ったと説明されている。第三艦隊は1942年7月15日に編成され、次作戦まで約2か月の再編期間を必要と見積もっていたが、Guadalcanalの発生で熟練者をRabaulへ早期投入し、多くを失った。

この事例は、熟練者還流が「教育重視という思想」の有無だけで決まらず、**戦傷・艦隊再編・次作戦準備そのものから大量に発生する**ことを示す。

本世界のMI損耗構造は史実と異なるため30/40%をそのまま適用しない。しかし、飛龍生存、複数空母・航空隊の残存、Guadalcanal緊急投入の欠如によって、MI後に内地・九州・修理艦航空隊へ戻った人員が、そのまま再編期間を完了できる確率は高い。

## 2.2 補充機受領が生む往復

USSBSの勝俣精三少将聴取では、1944年夏に第101航空戦隊という空輸専任組織ができるまで、海外戦術部隊への補充機は、**戦術部隊の搭乗員が内地へ戻り、新機を受領して自隊へ空輸する**方式が一般的だったとされる。

この方式は整備責任と空輸責任が分断され、搭乗員練度・整備・燃料見積りの問題から空輸損失を増やしたため、後に専任組織へ集約された。

本世界では、この史実方式を「良い制度」として維持しない。しかし1942～43年前半には、補充機受領そのものが自然な人員往復を発生させ、航空員が内地の補給・教育・試験組織と接触する経路になる。

その後、損失記録と空地分離が進むにつれ、**戦闘搭乗員をフェリー任務から外す方が合理的**と判断され、専任空輸・受領組織へ段階的に移行する。

## 2.3 生存者が中央・教育・技術へ入る経路

USSBS人物録には、飛龍航空長・加賀航空長を務めた天谷孝久がMI後に海軍航空本部へ移り、1942～44年に空母飛行甲板設備を担当した例がある。また淵田美津雄もMI負傷後に長期療養し、1943年以降第一航空艦隊・連合艦隊航空参謀へ移った。

これは全海軍で体系的に戦訓還流が成功した証拠ではないが、**実戦経験者が艦を失う、負傷する、任務を終えることで自然に中央・教育・技術職へ移り得た**ことを示す。

本世界では生存者母数が大きいため、この偶発的な戦訓伝播経路自体も太くなる。

## 2.4 空地分離は「人員を動かす制度」の史実終着点

史実海軍は1944年7月10日、航空兵力の集散離合を容易にするため全面的な空地分離を実施した。飛行隊を持つ甲航空隊と、基地任務を担う乙航空隊を分け、必要に応じ飛行隊を別基地へ派遣する制度である。

本世界では45で、1942年後半試行、1943年主要戦域実用化、1944年初頭制度整理を中心線としている。

この制度は機体だけでなく、搭乗員・直接整備員・飛行隊幹部を基地固有組織から切り離す。結果として**人員の撹拌と練度平準化を可能にする物理的基盤**になる。

# 3. 自然還流の六経路

## 3.1 戦傷・病気・疲労

前線搭乗員が内地へ戻る最も自然な経路。重要なのは「死なないこと」である。

史実Guadalcanal/Rabaul型では、戦傷以前に搭乗員そのものが未帰還となる比率が高い。本世界では決死局面と逐次投入が減り、同じ被弾・疲労でも、

- 救助される。
- 帰投する。
- 一時後送される。
- 回復後に別部隊・学校・新編隊へ配属される。

という分岐へ入りやすい。

意図的な教育政策がなくても、療養後に元の部隊が別戦域にいる、改編済み、母艦が修理中、新編隊に幹部需要がある、というだけで人員は混ざる。

## 3.2 母艦損傷・修理・改装

空母は航空隊人員の巨大な固定容器でもある。母艦が数週間～数か月入渠すると、航空隊を完全に遊休させる合理性は低い。

- 陸上訓練へ回す。
- 他空母へ一部移す。
- 基地航空へ一時派遣する。
- 新機種転換を行う。
- 新編航空隊の幹部核を供出する。

本世界では空母船体が多いため、「艦が沈んだので航空隊も消える」より、**艦の修理時計に合わせて人員が別組織へ一時移動する**事例が増える。

Efateで翔鶴、Enterprise等のmission-killを扱ったように、艦体の修理と航空隊の人事時計は分離して追跡する。

## 3.3 航空隊の再編・補充・機種転換

機体更新は人員の混合を生む。

- 旧型機隊から新型機隊へ教導要員を出す。
- 新型機経験者を元隊へ戻す。
- 編隊長・航法員・雷撃/爆撃指導員だけ先に集める。
- 整備員の一部を新機種固有要員へ転換する。

計算援用により整備記録・事故記録が比較可能になるため、「機体を配れば部隊になる」ではなく、**どの専門技能が不足しているか**を人員表へ落としやすい。

## 3.4 補充機受領・空輸

1942～43年前半は、史実同様に戦術部隊員が内地へ戻って機体を受領する場合を残す。

この経路は、

前線経験者 → 内地補給拠点 → 新機受領 → 別飛行場・中継基地 → 前線

という長い接触網を作る。

一方、事故率・飛行時間・戦闘搭乗員の浪費が可視化されるため、1943年後半には専任空輸分遣隊を試行し、1944年初頭までに空輸・受領を戦闘航空隊からかなり分離する中心線とする。

史実第101航空戦隊の制度名・編制を未来知識としてコピーせず、機能だけを前倒しする。

## 3.5 新造・修理明け空母の航空隊編成

本世界では生残空母に加え、大鳳、雲龍系等が加わるため、航空隊を新造艦へ割り当てる必要が史実以上に持続する。

新空母を全新人で満たすと戦力化が遅い。逆に既存第一線航空隊を丸ごと抜けば戦線が空く。

その中間として、

- 艦長・飛行長・航空隊司令部。
- 着艦資格を持つ編隊長。
- 洋上航法・索敵経験者。
- 雷撃・艦爆の分隊長。
- 甲板作業長・整備幹部・先任下士官。

を既成部隊から抜き、新人・予備課程修了者と混ぜる方式が自然に増える。

ここで熟練者が「教官」にならなくても、**新部隊の内部教官**として経験が伝播する。

## 3.6 空地分離・基地間移動

45の制度化が進むと、飛行隊は基地固有の警備・給養・施設組織を引きずらず、方面内で移動する。

同じ飛行隊が数か月の間に、

Midway → 内地再編 → South Pacific → Truk

のように複数の受入組織と接触し得る。

基地側から見ると逆に、複数の飛行隊を順番に受け入れるため、

- 燃料・弾薬搭載手順。
- 無線符号。
- 整備票。
- 飛行場交通。
- 事故処理。
- 夜間誘導。

の悪いローカル慣行が維持しにくくなる。

これは人員の平均技能そのものを上げる以上に、**部隊間互換性を上げる**。

# 4. 「撹拌」は無作為混合ではない

練度平準化は、第一航空戦隊の精鋭を全部解体して全隊へ均等配分することではない。

戦争では、決戦用の高練度部隊を残す価値がある。一方、多部隊協同任務は最低練度の部隊に全体が引きずられる。

したがって本世界の最適化目標は、

> **上澄みを完全に消さず、下端の極端な低練度部隊を減らす。**

である。

## 4.1 練度を一軸にしない

人員は少なくとも次へ分ける。

- 艦上発着艦資格。
- 夜間/薄暮発着艦資格。
- 洋上航法・索敵。
- 編隊指揮。
- 雷撃/急降下爆撃の終末攻撃。
- 戦闘機空戦・CAP。
- 無線通信・短符号運用。
- 攻撃隊統合指揮。
- 整備・兵装・甲板処理。

「撃墜数の多いエース」だけを熟練者としない。

FORAGERで重要なのは、むしろ**攻撃セルを時間どおり目標へ連れて行ける指揮・航法・無線・編隊技能**である。

## 4.2 艦上資格の選別が平準化に効く

松田千秋の戦後聴取では、1944年の第四航空戦隊で、陸上作戦には使えるが海上・母艦運用には十分訓練されていない航空隊が存在し、実際に陸上基地へ回されている。

本世界ではこの区別を敗戦末期の緊急措置にせず、早くから資格階層として扱う。

- 艦上第一線資格。
- 艦上予備/昼間限定資格。
- 陸上作戦資格。
- 練成中。

に分け、空母航空隊へ「海上運用に不向きな搭乗員」を無理に混ぜない。

これは搭乗員を増やす改革ではない。**同じ人員を任務適性に合わせて並べ直す改革**である。

# 5. 発生段階

## 5.1 1942年6～9月――自然還流・集積期

主因は制度改革ではない。

- MI負傷者の療養。
- 沈没艦生存者・飛龍等生残艦航空隊の再編。
- 翔鶴・瑞鶴等の修理・補充。
- 新第三艦隊の編成。
- 次作戦準備。

により、経験者が九州・内地・修理艦航空隊へ自然に集まる。

この段階では「毎隊へ精鋭を配る」政策をまだ固定しない。まず戦訓会、飛行記録、事故・未帰還・航法誤差、甲板処理等を比較する。

史実ではこの再編期間をGuadalcanalが途中で切った。本世界では最低8～12週間級を取りやすい。

## 5.2 1942年10～12月――再編過程での人員差の発見

複数航空隊を同じ演習へ参加させると、同型機・同じ飛行時間でも、

- 集合時刻。
- 航法誤差。
- 編隊維持。
- 無線量。
- 着艦事故。
- 雷撃/爆撃の進入安定。

が隊ごとに大きく違うことが見える。

ここで初めて「教育時間を増やす」だけでなく、**経験者を核にした再編の方が短期間でばらつきを削れる**という仮説が立つ。

当初は制度ではなく、艦隊司令部・航空戦隊ごとの局地措置とする。

## 5.3 1943年前半――主要戦域の練度底上げ

空地分離の局地試行と接続する。

- 新編・再編航空隊には、可能な限り実戦/艦上経験のある司令部・編隊長・先任整備員を核として置く。
- 熟練者の一時後方勤務を「学校教官」だけでなく、新編隊・試験隊・機種転換隊・方面練成へ広げる。
- 前線から抜く人数を固定比率にせず、艦隊Availabilityと新編需要で決める。
- 陸上資格しかない者を無理に艦上へ上げず、陸上部隊で実戦経験を積ませる。

この段階での目的は精鋭平均値の上昇ではなく、**全く未経験の部隊単位を前線へ出す確率を下げること**。

## 5.4 1943年後半――平準化を意図的な人事目標へ

Efate、第二次Midway等の実戦記録から、複数隊統合攻撃では「一隊の大崩れ」が全体を壊すことが定量的に見える。

ここで人事・航空本部側に、

- 各航空隊の艦上資格者比率。
- 実戦経験を持つ編隊長数。
- 航法・索敵経験者数。
- 夜間資格者。
- 熟練整備員数。

を比較する需要が生じる。

配置は「有名精鋭隊へ全員集中」から、

> **第一線決戦隊には厚い熟練核を維持しつつ、各新編/第二線隊にも最低限の経験核を置く。**

へ移る。

これを本書では**練度平準化**と呼ぶ。

## 5.5 1944年前半――制度としての循環

45の空地分離が制度整理されると、飛行隊・搭乗員・直接整備員を艦/基地から切り離して管理しやすくなる。

同時に、補充機空輸を戦闘搭乗員へ依存する非効率が統計的に明瞭になるため、専任空輸・受領組織を前倒しして整備する。

この段階で初めて、

- 一定期間前線勤務。
- 再編/教育/試験/新編隊勤務。
- 再び第一線。

という**意図的循環**が広く成立し得る。

ただし米海軍型の規則的combat tour制度をそのまま導入しない。戦況悪化時は熟練者を前線へ戻し、循環は崩れる。

# 6. 教官政策の位置づけを修正する

従来50では第一線航空隊から5～10%級を一時教官へ回す案を置いていた。これは上限側の制度案として残すが、**1942年夏から固定比率で実施する中心線は撤回する。**

中心は次の順とする。

1. 戦傷、修理、再編、補充機受領、新編隊で自然還流が起こる。
2. 還流者の一部が短期間、学校・試験・新編隊幹部を兼ねる。
3. 1943年以後、練度差のデータが蓄積した段階で意図的な短期還流を追加する。
4. 同時点で第一線から純粋に「教育だけ」のため外す熟練者は小さく抑える。

作業上は、1943年以後でも純教官として第一線から同時に外す量を**3～7%級の感度帯**に置き、これとは別に、療養・再編・新編隊・母艦修理等で後方/中間拠点を通過する経験者を数える。

したがって年間を通じて戦訓を別部隊へ渡す経験者は3～7%より多いが、「前線の精鋭を恒常的に10%以上学校へ封じ込める」ことはしない。

この3～7%は史実値ではなく、FORAGER等で人員Availabilityを計算するための**本世界作業値**である。

# 7. 練度平準化が変えるもの

## 7.1 平均より分散を変える

本制度の最大効果は、全搭乗員の平均技能を何割も上げることではない。

- 極端に弱い新編隊が減る。
- 編隊長だけが全員新人、という状態が減る。
- 甲板・整備・航法のローカル手順差が小さくなる。
- 部隊混成時に共通手順が通じやすくなる。

つまり**分布の下側を持ち上げる**。

このため、単機空戦の撃墜比より、

- 大編隊の集合成功率。
- 予定時刻への到達率。
- 途中脱落率。
- 帰投・代替着艦率。
- 夜間/悪天候事故率。

へ先に効く。

## 7.2 複合攻撃は「最弱セル」の影響を受けにくくなる

45の分散接近・多軸・時差収斂型攻撃では、各セルが最低限の航法・通信・独立判断能力を持たないと成立しない。

練度平準化は、攻撃セルを増やす魔法ではなく、**セルへ分けても各群が任務を失わない条件**を作る。

したがってFORAGERでは、46の効果を命中率へ直接加算せず、

- 集合失敗。
- 目標未発見。
- 誤方向進入。
- 通信不成立。
- 燃料計画逸脱。

による攻撃セル消失率へ反映する。

## 7.3 母艦航空隊の再構成

損傷空母から航空隊を引き抜く際、空地分離と資格表があるため、

- 艦上資格の高い者を健在空母へ優先。
- 昼間艦上資格者をCAP・近距離攻撃へ。
- 陸上資格中心の者をMarianas/Yap等へ。
- 新人を内地・後方で追加錬成。

という再配置が可能になる。

この効果は「一隻沈んでも航空隊100%生きる」ではない。帰投可能機、救助、生存整備員、受入甲板/基地、燃料が必要である。

# 8. 空輸専任化の前倒し

史実では1944年夏に空輸専任組織ができた。本世界では次の因果でやや前倒しする。

1. 1942～43年、戦闘搭乗員が補充機を受け取りに内地へ戻る。
2. 計算機で空輸事故、機体不具合、燃料、天候、搭乗員経験を記録する。
3. 「前線経験者を空輸に使う機会費用」と「整備責任分散による損失」が可視化される。
4. 空地分離で、飛行隊と機体輸送を同じ組織に固定する必要が薄れる。
5. 1943年後半に主要航路で専任空輸分遣隊を試行。
6. 1944年初頭～春に機能上の専任組織を標準化。

これにより、1944年前半の戦闘搭乗員は史実よりフェリー飛行へ浪費されにくい。

ただし、専任化が進むと「補充機受領による自然還流」は減る。この時点では既に、空地分離・新編隊・短期人事循環が代替経路になるため、学習伝播は切れない。

# 9. FORAGER用の作業入力

数値は二重計上を避けるため、44・45と別の場所へだけ使う。

| 項目 | 1944年7月中心感度 |
|---|---:|
| 第一線空母航空隊で「艦上運用に著しく不適な隊」が混入する率 | 史実同条件より大幅低下 |
| 新編/再編隊が経験核なしで前線投入される確率 | 相対40～60%低下感度 |
| 編隊長・航法・無線等の不足で攻撃セルそのものが途中消失する率 | 相対15～30%低下感度 |
| 新基地/別母艦へ移した後の手順不一致による追加遅延 | 相対15～25%低下感度 |
| 非戦闘フェリー・受領任務への第一線搭乗員拘束 | 1944年春以後相対30～50%低下感度 |

これらは固定史実値ではない。現行史線での人員・艦艇・燃料を使うFORAGER再計算の感度帯である。

44の「到着時刻分散縮小」、45の「終末攻撃圏到達数」、50/52の「航空攻撃技能」と重複加算しない。

# 10. 1944年7月の質的状態

本世界の1944年7月海軍航空は、1941年第一航空艦隊の熟練度をそのまま保存した軍ではない。

- 1941年級の超熟練者は戦死・事故・負傷・人事で相当減る。
- 燃料制約は強まる。
- 新造空母・航空隊拡大で教育需要も大きい。
- F6F、米レーダーfighter direction、VT信管、大量教育という米側優位は残る。

一方、史実Marianas型の、

- 艦上運用未熟者を急造空母航空隊へ大量混入。
- ほぼ全員新人の新編隊。
- 基地を失うと飛行隊まで固定化・孤立。
- 搭乗員と補充機受領が非効率に結合。
- 熟練整備・航法・編隊長の局地枯渇。

は大きく緩和される。

したがって1944年7月の最大差は、**平均パイロットが超人化することではなく、航空隊単位の当たり外れが小さく、複数航空隊を一つの作戦へ組みやすいこと**とする。

# 11. 二重計上・禁止事項

- 生存者増加をそのまま「全員教官化」しない。
- 自然還流と意図的教官ローテーションを別に数える。
- 空地分離で基地要員が不要になるとはしない。
- 熟練者を均等配分して決戦航空隊の精鋭性を完全に消さない。
- 陸上作戦資格と艦上資格を同一視しない。
- 新母艦へ移した航空隊の即日完全戦力化は禁止する。
- 46の平準化効果を命中率、CAP能力、到着時刻圧縮へ重複加算しない。
- Guadalcanal不発生によって「実戦経験そのものも史実以上」と自動判定しない。実戦経験量はEfate、第二次Midway、GALVANIC、Marshall等の本世界戦役から別途追跡する。
