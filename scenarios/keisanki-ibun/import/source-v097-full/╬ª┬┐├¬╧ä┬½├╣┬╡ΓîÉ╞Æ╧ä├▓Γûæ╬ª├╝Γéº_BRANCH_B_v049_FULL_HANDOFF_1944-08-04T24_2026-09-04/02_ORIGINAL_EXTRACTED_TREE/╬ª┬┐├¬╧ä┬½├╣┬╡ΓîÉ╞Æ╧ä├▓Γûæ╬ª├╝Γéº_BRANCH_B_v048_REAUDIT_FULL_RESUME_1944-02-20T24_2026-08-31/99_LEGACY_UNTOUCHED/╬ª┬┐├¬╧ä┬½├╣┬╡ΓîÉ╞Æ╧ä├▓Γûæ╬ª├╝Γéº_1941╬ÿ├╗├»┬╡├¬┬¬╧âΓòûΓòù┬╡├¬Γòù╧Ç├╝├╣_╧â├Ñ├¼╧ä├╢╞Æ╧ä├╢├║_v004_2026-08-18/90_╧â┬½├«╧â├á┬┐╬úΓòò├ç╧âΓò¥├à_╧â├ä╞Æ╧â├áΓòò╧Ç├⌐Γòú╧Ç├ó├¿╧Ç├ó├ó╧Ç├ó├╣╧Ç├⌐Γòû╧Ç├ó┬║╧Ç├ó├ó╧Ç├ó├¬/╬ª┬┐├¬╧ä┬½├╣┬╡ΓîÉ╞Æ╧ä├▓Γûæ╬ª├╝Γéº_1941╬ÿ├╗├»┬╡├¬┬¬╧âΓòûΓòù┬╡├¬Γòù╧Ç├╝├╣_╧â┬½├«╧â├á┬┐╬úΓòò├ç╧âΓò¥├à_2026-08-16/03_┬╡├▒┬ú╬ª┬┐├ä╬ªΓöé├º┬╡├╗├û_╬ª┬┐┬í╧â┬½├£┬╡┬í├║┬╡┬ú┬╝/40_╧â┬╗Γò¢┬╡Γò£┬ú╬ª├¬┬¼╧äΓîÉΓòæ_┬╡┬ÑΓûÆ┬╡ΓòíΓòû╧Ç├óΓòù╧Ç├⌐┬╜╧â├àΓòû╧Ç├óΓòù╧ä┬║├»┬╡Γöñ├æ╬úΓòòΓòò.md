# 対潜航空への計算機波及

# 0. 現在の位置づけ

東海・カ号・秋津丸は、1941年12月の開戦侵攻能力を直接増す装備として数えない。東海は1942年夏～秋初飛行、1942年末～1943年前半の初期部隊試用、カ号は1942年試験運用、1943年に秋津丸で実用航空隊が中心線である。

したがって、開戦時空母航空戦力、揚陸能力、輸送能力の正本は `60_開戦戦力・輸送・空母・揚陸・砲計算.md`、航空機全体の生産・発動機との競合は `50_航空機研究_陸海軍総合正本.md` を参照する。本書は対潜航空システム成立後の配置、捜索、接触維持、空水協同だけを担当する。艦艇側の探信・聴音・爆雷・二艦協同・船団護衛指揮は `41_艦艇対潜_探信・爆雷・護衛運用.md` を正本とする。

計算機側を東海・カ号の発案者にせず、既存の対潜・電波・磁気・航空・回転翼研究へ、試験記録、雑音分析、装置統合、捜索法、開発結果の高速な戻しで参加させる。

# 1. 東海の早回し

## 1.1 前倒しの主因

史実相当の東海は、正式要求から初飛行まで約一年級で、機体設計自体が極端に遅かったわけではない。

大きな遅れは次にあった。

- 専用対潜機という要求の成立。
- 航空用電探・磁探の成熟。
- 既成機後付けの限界認識。
- 搭載装置と機体の適合。
- 部隊訓練、捜索、攻撃、空水協同。

計算機側は既成機試験の結果を早く整理し、「後付けより専用機が必要」と示す。

## 1.2 開発の因果

1. 既成陸攻等で電波・磁気装置を試す。
2. 発動機、操縦索、軸受、電路、機体構造が磁気・電気雑音を生む。
3. 電源、表示器、操作員席、アンテナ、低空安定性が一体問題と判明。
4. 対潜部門が専用機要求を出す。
5. 航空技術部門と九州飛行機が東海へまとめる。

## 1.3 中心日程

| 時期 | 本作の進展 |
|---|---|
| 1939 | 既成機による電波・無線方位・低空哨戒試験 |
| 1940 | 搭載重量、電源、乗員、雑音の研究 |
| 1941前半 | 専用陸上哨戒機の予備要求 |
| 1941後半 | 正式・準正式試作指示 |
| 1942夏～秋 | 初飛行 |
| 1942末～43前半 | レーダー中心の初期部隊試用 |
| 1943 | 磁探対応型の試験・初期配備 |
| 1943末～44前半 | 電探・磁探統合型の標準生産 |

史実比：

- 予備研究1.5～2年前倒し。
- 正式要求9～15か月。
- 初飛行9～14か月。
- レーダー初期型9～15か月。
- 磁探統合型6～12か月。

1941年実用化は早すぎる。センサー実物が追いつかず、単なる低速双発哨戒機になる。

## 1.4 機体方針

史実相当の低速・長時間・双発・前下方視界重視を維持。

変わる内部方針：

- 探索コイル周辺を非磁性化。
- 発動機・操縦索・軸受からの雑音経路分離。
- 発電機・安定電源を標準装備。
- レーダー・磁探操作員席。
- 装置交換用点検口。
- 電路・アンテナ抵抗を初期設計で計上。
- 低空哨戒時の縦横安定。
- 標識弾投下器との接続。

## 1.5 仮諸元

| 項目 | 本作初期量産型 |
|---|---:|
| 全備重量 | 4.85～5.0t |
| 最大速力 | 315～325km/h |
| 滞空 | 10.5～11時間級 |
| 兵装 | 250kg級対潜爆弾2発 |
| 乗員 | 3名、後期4名案 |
| 電探 | 初期型から配線・電源準備 |
| 磁探 | 後期試作から統合設計 |
| 装置稼働率 | 相対20～30％向上 |
| 機体磁気雑音 | 30～50％低減 |

最高速は大きく増やさない。任務は低速・長時間・安定した哨戒。

# 2. 東海の実戦的哨戒効果

## 2.1 三段階

### 広域発見

レーダーで浮上航行中または急速潜航直前の潜水艦を探す。

初期実用探知距離は条件良好時15～22km程度の作業値。

海全体を覆うのではなく、港湾出入口、海峡、船団前方、既知接触点に集中する。

### 潜航後の確定

磁探は広域捜索ではなく、電探・目視で絞った後に直上位置を取る。

探知帯は狭く、低空で反復横断する必要がある。

### 攻撃・継続追跡

東海単独の爆弾だけでは撃沈確率が高くない。

標識弾、別攻撃機、護衛艦、無線連絡、深度設定をつなぐ必要がある。

初期の東海は「発見と攻撃妨害に強い、撃沈までの能力は中程度」。

## 2.2 効果の本質

東海はまず米潜水艦の自由時間を奪う。

- 昼間浮上時間を減らす。
- 充電・水上高速移動を妨げる。
- 船団への回り込みを遅らせる。
- 攻撃後の再攻撃を難しくする。
- 港湾・海峡出口の待伏せを危険にする。

東海だけで仕留め役が弱い場合でも、覆域内の中心推定：

| 指標 | 変化 |
|---|---:|
| 米潜の昼間浮上時間 | 40～70％減 |
| 船団接近成功率 | 15～30％低下 |
| 有効魚雷発射機会 | 10～25％低下 |
| 再攻撃機会 | 20～35％低下 |
| 船団損失 | 10～20％低下 |

戦闘機区域警戒・攻撃機が連携する場合：

| 指標 | 変化 |
|---|---:|
| 昼間浮上時間 | 60～85％減 |
| 船団接近成功率 | 25～45％低下 |
| 有効発射機会 | 20～40％低下 |
| 船団損失 | 20～35％低下 |

これは覆域内の値。戦域全体へ平均すると初期5～15％程度、1944年以降主要航路10～25％程度まで薄まる可能性。

## 2.3 米軍は気づくか

確実に気づく。

### 数週間～数か月

- 同じ海域で低速双発機を頻繁に見る。
- 低視程・夜間に接近される。
- 視認前に機体が進路を向ける。
- 潜航後も低空反復・標識弾・護衛艦接近が続く。

1943年春～夏の数回の哨戒で、新しい対潜航空哨戒の存在を認識しうる。

### レーダー

夜間・低視程での正確な接近から比較的早く推定。

電波警戒受信機が普及すれば、探知される前に送信を傍受できる場合がある。

### 磁探

受動装置なので正体の確定は遅い。

最初は油跡、気泡、音響、レーダーが水中まで見える等の仮説が混在。

1943末～44前半には「潜航後の短距離位置確認装置」があると推定しうるが、磁気式と確定するには捕獲・情報入手が必要。

### 米側対応

- 航空覆域で昼間潜航。
- 夜間高速移動。
- 船団側面・後方から接近。
- 雲・雨・薄明利用。
- レーダー警戒受信機。
- 磁探接触後の即時深度・針路変更。

初期の不意打ち撃沈効果は減るが、潜水艦を不自由にする抑圧効果は残る。

# 3. カ号観測機の早期化

## 3.1 計算機が効く場所

発想や輸入原型取得ではなく、修復・試飛行から国産量産型へ移る過程。

- ブレード質量、重心、曲げ・ねじり剛性。
- フラッピング、ドラッグヒンジ、前進側・後退側の差。
- ローター回転数と機体固有振動数。
- 脚、予回転クラッチ、ローター軸。
- 操縦入力と円板傾斜。
- 三枚一組の製造・選別。
- 艦上風速・横風・甲板動揺。

史実相当では比較的揃った三枚を選び直して振動を抑えた。本作では製造途中から一組として管理する。

## 3.2 前倒し幅

| 段階 | 史実からの変化 |
|---|---:|
| 修復機初飛行 | 3～6か月前倒し |
| 飛行試験・調定 | 30～50％短縮 |
| 国産型設計凍結 | 6～9か月前倒し |
| 小規模生産 | 6～12か月前倒し |
| 艦上試験 | 12～18か月前倒し可能 |
| 対潜部隊試験 | 約1年前倒し |
| 振動ばらつき | 30～50％縮小 |
| 初期稼働率 | 相対20～30％向上 |

中心線：1942年試験運用、1943年に秋津丸で実用航空隊。

## 3.3 カ号一型改の主線

最初から完全な跳躍離陸を欲張らず、艦上で確実に回る型。

- 改良予回転クラッチ。
- 三枚一組のブレード管理。
- ローター折畳み。
- 防錆、排水、艦上係止点。
- 無線、双眼鏡、標識弾。
- 二重回転計。
- 甲板風速別離着艦表。

| 項目 | 中心推定 |
|---|---:|
| 全備重量 | 1200～1260kg |
| 通常巡航 | 115～125km/h |
| 最大速度 | 160～170km/h |
| 航続時間 | 2.4～2.7時間 |
| 無風離陸滑走 | 40～50m |
| 艦上離陸滑走 | 通常10～30m |
| 着陸滑走 | 3～8m |
| 乗員 | 2名 |
| 通常装備 | 無線、双眼鏡、標識弾 |
| 攻撃型 | 1名＋60kg級爆雷2発程度 |

オートジャイロはヘリコプターではない。

- 空中停止不可。
- 無風・無速力での垂直離陸不可。
- 前進速度喪失時は降下。
- 母艦停止・追い風では条件悪化。

## 3.4 二型改・跳躍離陸

1943年頃、予回転回転数とローターピッチ変更で短い跳躍離陸を試す余地。

ただし秋津丸は艦速で相対風を作れるので、跳躍性能より信頼性、折畳み、展開速度を優先する可能性が高い。

---

## 3.5 陸上砲兵観測・連絡任務

カ号は対潜専用機ではない。本来の陸軍要求である**砲兵観測・近距離偵察・連絡**を第一の陸上用途として併記する。

1942年秋から華北で試験観測班を編成し、野砲・山砲・迫撃砲群との協同、無線通報、標識弾、共通座標による射撃修正を試す。1943年春の大陸大作戦へは、小規模ながら実戦投入可能とする。

五号作戦時の中心配当：

- 配当12機。
- 発起時即応9～10機。
- 北方主攻8機、宜昌方面4機を基本とする。
- 平地・盆地・低山地では砲兵観測へ使用。
- 秦嶺・大巴山の高温高地・峡谷では前線観測価値が急減し、連絡・道路交通確認へ後退する。

観測が継続できる砲兵群では、現行I/O・共通座標・無線体系と組み合わせ、**初弾から効力射までの時間15～25％短縮、同等制圧効果に必要な弾量10～15％低下**を中心作業値とする。

これはカ号単機の性能効果ではなく、観測結果を迅速に砲兵射撃諸元へ戻せる場合だけ成立する。

**判断の理由：** カ号の低速・短距離・短い離着陸は、航空優勢下で友軍陣地近傍を旋回し続ける観測任務と相性が良い。一方、空中停止できず、高高度性能と敵戦闘機からの生残性が低いため、深部偵察や山岳越え任務には向かない。陸上砲兵観測と秋津丸対潜・揚陸支援は競合用途ではなく、同じ機体の別任務系列として成立する。

## 3.6 1943年五号作戦での評価基準

五号作戦での損耗・実戦結果は歴史考察側へ置くが、技術評価は次を正本とする。

- 平地・盆地・低山地の砲兵観測：**有効**。
- 山岳峡谷戦の最前線観測：**能力不足が顕在化**。
- 司令部連絡・道路交通確認：**有用**。
- 敵戦闘機活動時は即退避し、局地制空権のない正面では常用しない。
- 1943年後半以降、陸軍地上部隊用の少数観測隊と、秋津丸等の対潜・揚陸支援隊に用途が分岐する。

**判断の理由：** 実戦で役立つ条件と役立たない条件を分離できるため、対潜で成功・失敗したという一項目だけで機種全体を評価しない。


# 4. 秋津丸への効果

## 4.1 艦の性格変化

固定翼機に対して発艦・輸送中心だった艦が、帰艦できる航空機を継続運用できる。

任務：

- 揚陸時の砲兵観測。
- 上陸地点偵察。
- 船団前路の対潜見張り。
- 航路・海峡反復哨戒。
- 僚船間連絡。
- 漂流者・救命艇捜索。
- 潜水艦接触位置への標識投下。

## 4.2 艦載数

| 運用形態 | カ号 | 固定翼機 | 性格 |
|---|---:|---:|---|
| 揚陸支援重視 | 4～6 | 2～4 | 観測・連絡中心 |
| 船団護衛重視 | 6～8 | 2～4 | 常時一機哨戒 |
| 対潜航空母艦化 | 8～10 | 4～6 | 揚陸能力をかなり削る |

本来の揚陸能力を残すなら4～6機が無理のない幅。

6機で昼間おおむね一機を継続滞空。8～10機なら脅威時間帯に前方捜索、側面・接触地点、待機の三機構成が可能。

## 4.3 対潜での本職

カ号単独の攻撃能力は高くない。

二人乗りでは重爆雷搭載が難しく、一人乗り攻撃型では観測・航法・無線・攻撃・帰投を一人で処理する。

最も強い流れ：

カ号が発見 → 無線通報 → 標識弾 → 低速旋回で再接触 → 固定翼攻撃機・護衛艦が攻撃。

東海が基地から広域を探し、カ号が船団近傍で接触後の空白を埋める。

## 4.4 磁探との相性

低速・低高度・小回りは磁探に向く。

しかし発動機、ローター軸、ハブ、ヒンジ、予回転機構、操縦索という磁性・運動部品が集まり、小型機でコイルを離しにくい。

自然な順序：

- 1942：目視・無線・標識。
- 1943：母艦電探・他機から誘導。
- 1944：軽量磁探を試験。
- 標準磁探はより大型の後継回転翼機へ。

## 4.5 限界

- 荒天、横風、甲板動揺。
- 航続2時間半前後で遠距離哨戒不可。
- 攻撃力不足。
- 母艦・整備資源への集中。
- 予備ローター、折畳み、甲板整理に人員を要する。

秋津丸は本格護衛空母にはならないが、揚陸・観測・連絡・局地対潜を切替可能な多用途艦になる。

# 5. 東海・カ号・護衛艦の統合像

役割分担：

| 層 | 主役 | 役割 |
|---|---|---|
| 広域・遠方 | 東海 | 電探で発見し、潜航を強制 |
| 船団近傍 | カ号 | 目視・標識・低速反復、接触維持 |
| 位置確定 | 磁探機 | 潜航後の直上確認 |
| 攻撃 | 固定翼攻撃機・護衛艦 | 重爆雷・爆雷・音響追跡 |
| 指揮 | 母艦・船団指揮所 | 接触時刻、方位、標識、攻撃順序を統合 |

この体系の価値は、各機体の単体性能ではなく、発見後に位置情報を失わず仕留め役へ渡す確率を上げること。

史実より元気な1943年に成立すれば、潜水艦撃沈数以上に、主要航路で米潜水艦の行動自由を縮小する。

# 6. 未確定・次の計算事項

- 東海・磁探・艦艇ASWの戦果は戦域別歴史考察で処理する。
- カ号の陸上砲兵観測用途、1943年春実戦投入可能性、五号用12機級配当、平地・盆地での有効性と山岳での限界は正本化済み。
- 二型改の跳躍離陸は、秋津丸運用に必須ではないため、実機試験結果を得るまで条件依存とする。
