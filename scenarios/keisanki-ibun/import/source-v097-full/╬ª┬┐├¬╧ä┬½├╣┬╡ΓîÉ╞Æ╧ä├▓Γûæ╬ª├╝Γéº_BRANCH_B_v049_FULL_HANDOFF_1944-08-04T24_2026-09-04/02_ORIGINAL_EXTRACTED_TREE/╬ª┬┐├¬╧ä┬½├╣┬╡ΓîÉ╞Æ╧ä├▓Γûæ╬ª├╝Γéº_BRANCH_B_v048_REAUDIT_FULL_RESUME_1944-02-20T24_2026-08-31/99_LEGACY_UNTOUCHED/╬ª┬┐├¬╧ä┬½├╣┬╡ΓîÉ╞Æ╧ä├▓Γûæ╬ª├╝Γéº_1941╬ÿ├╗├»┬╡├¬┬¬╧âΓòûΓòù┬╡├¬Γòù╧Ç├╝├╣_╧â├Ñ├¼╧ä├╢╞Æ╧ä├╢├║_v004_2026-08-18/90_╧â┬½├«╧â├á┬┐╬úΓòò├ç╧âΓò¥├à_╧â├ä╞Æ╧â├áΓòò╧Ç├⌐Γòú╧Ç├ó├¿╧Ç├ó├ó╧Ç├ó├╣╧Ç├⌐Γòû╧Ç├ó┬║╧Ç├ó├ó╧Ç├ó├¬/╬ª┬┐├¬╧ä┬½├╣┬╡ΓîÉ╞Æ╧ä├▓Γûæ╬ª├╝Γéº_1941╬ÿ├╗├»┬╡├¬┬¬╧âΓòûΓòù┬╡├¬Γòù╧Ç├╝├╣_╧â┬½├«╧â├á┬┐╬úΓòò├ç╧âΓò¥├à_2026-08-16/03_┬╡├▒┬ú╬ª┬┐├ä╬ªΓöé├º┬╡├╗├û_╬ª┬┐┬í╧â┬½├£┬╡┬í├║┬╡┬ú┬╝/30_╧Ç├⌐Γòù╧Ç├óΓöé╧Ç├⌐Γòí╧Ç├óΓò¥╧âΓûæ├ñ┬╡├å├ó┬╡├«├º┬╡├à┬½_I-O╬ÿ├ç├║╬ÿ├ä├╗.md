# 艦載計算機・光学・電探・I/O連鎖

計算機研究はレーダーや光学の単独発明者ではない。測定・転記・表示の律速化から、校正、記録、表示、低速情報処理、装置外への受渡しへ参加する。

1942年段階の電探は、粗い探知・早期警告だけでも光学にない価値を持つが、探知、航跡化、艦種識別、射撃解、命中を同一視しない。電探が「見るべき方向」を与え、光学・人間・機械式射撃盤が情報を詰める場面が普通に残る。米側についてもレーダー探知を完全なCAP誘導・必中射撃へ直結させない。質的なレーダー閉ループの成立時期は61で横断管理する。

1930年代に完全な自動I/O網は成立させない。

魚雷射撃指揮は、史実日本海軍がすでに高度な機械式体系を持っていたことを前提に再監査した。魚雷本体、魚雷射撃盤、発射管、艦別較正、再装填、水雷戦運用の現行値は `31_魚雷・水雷戦_魚雷本体・射撃指揮・再装填・運用.md` を優先する。本書のI/O原則は31へ入力するが、魚雷の命中率や再装填時間を本書から一般化しない。

# 1. 艦載電子計算機の位置づけ

## 1.1 主射撃盤を置き換えない

既存機械式射撃盤は連続相対運動、距離変化率、方位変化率、未来位置を機械的に処理するのに適している。

初期リレー式装置は、全射撃問題を置き換えるより、非線形・多変数補正を担当する方が有効。

分担：

- 機械式射撃盤：目標運動と砲指向。
- 電磁・電子補助器：気圧、気温、高層風、地球自転、偏流、装薬温度、初速、砲身摩耗、弾薬ロット、砲塔差、船体たわみ。

陸上計算で既に射表・カムが改善されているため、艦載器の追加効果は、その場の非標準条件と試射結果を即時反映する部分に限定する。

## 1.2 開発系列

| 時期 | 段階 | 主な場所・艦 |
|---|---|---|
| 1935～36 | 陸上固定用途試作 | 呉・横須賀、砲術学校 |
| 1937～38 | 振動・衝撃・温湿度試験 | 陸上試射場、環境試験室 |
| 1938～40 | 海上テストベッド | 比叡 |
| 1940～41 | 艦隊運用試験 | 長門 |
| 1941 | 建造・艤装段階での最初の正式組込み | 大和 |
| 1942 | 最初の成熟標準搭載 | 武蔵 |
| 1943～44 | 第二世代 | レーダー追尾、対空、戦術表示へ拡張 |

比叡は装置が海に耐えるかを試す技術試験艦。長門は操作、保守、射撃指揮手順を確立する運用試験艦。

大和が、既成艦への単純な後付けではなく、建造・艤装段階で電源、通風、配線、区画へ正式に統合する最初の艦となる。武蔵が最初の成熟量産型搭載艦。大和の基本設計初期から装置完成形が確定していた、という意味ではない。

## 1.3 仮諸元

| 項目 | 大和初期型 | 武蔵改良型 |
|---|---:|---:|
| 封止リード等 | 400～650 | 500～750 |
| 真空管 | 60～100本 | 70～110本 |
| 主方式 | 固定配線・交換定数盤 | 固定配線＋小規模可変手順 |
| 一回の補正計算 | 3～8秒 | 1～4秒 |
| 中央機重量 | 1.5～2.5t | 1.5～2.3t |
| 完全装備重量 | 4～7t | 4～6t |
| 消費電力 | 5～8kW | 5～7kW |
| 床面積 | 10～15m² | 8～13m² |
| 操作・整備要員 | 8～12名 | 6～10名 |
| 稼働率 | 85～90％ | 90～95％ |

完全装備には電源安定器、防振架、操作卓、通風、予備ユニット、信号変換器、配線を含む。

重量、電力、床面積、要員は `10_水上艦_駆逐艦・戦艦改装・大和型.md` の大和型統合勘定へ一度だけ記帳する。比叡・長門の試験装置は仮設を中心とし、恒久搭載を自動的に仮定しない。

## 1.4 追加効果

### 通常昼間水上射撃

- 有効射撃解への収束5～10％短縮。
- 初期諸元の系統誤差10～15％低減。
- 初回夾叉まで5～10％短縮。
- 総合命中率の相対向上2～5％程度。

### 長射程・非標準気象

- 初期諸元系統誤差20～30％低減。
- 有効解収束10～20％短縮。
- 初回夾叉可能性、相対8～15％向上。

### 新砲・新弾の熟成

- 仮射表を試射前に80～90％まで作成。
- 射表確立の実弾試射20～30％削減。
- 射撃盤調定2～4か月短縮。
- 砲術上の技術的戦力化3～6か月短縮。

# 2. 光学研究・メーカーへの計算機配備

## 2.1 配備の自然な順序

| 時期 | 配備先 | 主用途 |
|---|---|---|
| 1932～33 | 陸海軍中央光学研究部門 | 光線追跡、国産硝材置換、測距儀 |
| 1934～35 | 日本光学等の主契約メーカー | レンズ設計、プリズム光路、公差 |
| 1935～37 | 東京光学、富士光学、工廠光学部 | 写真レンズ、照準器、ガラス統計 |
| 1937～39 | 各主要メーカーType 1軽量型 | 日常設計、検査表、原器計算 |
| 1939～ | 中央Type 2、メーカーType 1C | 多波長、公差、赤外、生産統計 |

工場現場へ汎用機を置くのではなく、レンズ処方、曲率表、厚さ・間隔公差、硝材選択、研磨原器修正、組立調整、膜厚表として成果を渡す。

## 2.2 強く効く項目

- 多面・多波長・多画角の光線追跡。
- 曲率、厚さ、間隔、硝材の感度解析。
- 国産ガラスへの置換。
- 温度焦点移動。
- 芯ずれ、傾き、硝材ロットの許容差。
- 量産平均性能を最大化する設計選択。

理論上100点だが公差に極端に敏感な処方より、理論95点で量産平均88点の処方を選ぶようになる。

## 2.3 光学ガラス

溶解炉そのものを計算機が改良するわけではない。

ロットごとに次をカード化する。

- 原料純度・配合。
- 温度履歴・攪拌・冷却・徐冷。
- 屈折率・分散。
- 脈理・気泡・歩留まり。

中心推定：

| 項目 | 効果 |
|---|---:|
| 屈折率・分散のロットばらつき | 30～50％縮小 |
| 一級光学ガラス歩留まり | 相対20～40％向上 |
| 新硝材試験溶融 | 20～35％削減 |
| 設計後の硝材変更 | 30～50％減少 |

規格外ロットも実測定数に合わせて別用途レンズへ再設計し、廃棄を減らせる。

## 2.4 研磨・組立

物理的研磨時間は大幅には縮まらない。

効くのは、工具形状、原器誤差、削り量、研磨時間と面誤差、作業員・機械の偏り、芯出しの統計。

中心推定：

- 研磨後手戻り15～25％減。
- 芯出し・組立調整20～35％減。
- 完成品不合格15～30％減。
- 同型性能ばらつき30～50％縮小。

## 2.5 製品別

### 大型測距儀

- 装置固有ばらつき10～20％低減。
- 大気・観測員を含む総合測距誤差5～8％低減。
- 較正時間20～30％短縮。
- 姉妹艦差30％前後縮小。

### 夜戦双眼鏡

- 微光下識別距離5～12％向上。
- 視野周辺の有効識別範囲10～20％拡大。
- 左右像差、迷光、疲労が減る。

### 航空写真レンズ

- 開発期間40～60％短縮。
- 画面周辺の実用解像範囲20～35％拡大。
- 写真測量歪曲残差30～50％低減。
- 同性能重量10～20％削減可能。

### 潜望鏡

- 多面透過率、色収差、視野、防曇を改善。
- 同像性能で頭部径5～10％縮小余地。
- 個艦差を縮小。

### 赤外線

光学系は早く用意できるが、検出器、増幅、材料、像変換管が律速。

装置全体前倒しは中心6～12か月、特殊試作品で1～2年早い可能性。

## 2.6 総合値

- 新規光学系開発40～60％短縮。
- 設計候補10～20倍級。
- 大幅手戻り30～50％減。
- 光学ガラス有効歩留まり20～40％向上。
- 完成機器性能ばらつき30～50％縮小。
- 複雑機器製造工数15～30％減。

最高の一台より、複雑な新型を早く設計し、多数の量産品で性能を再現することが最大効果。

# 3. 電探との史実的な接続

## 3.1 接続の原則

電探は通信、高周波、真空管、アンテナ、テレビ表示、射撃指揮から生じる。

計算機側は次を持ち込む。

- 時間基準・分周。
- パルス整形。
- 陰極線管掃引・距離目盛校正。
- 模擬反射信号。
- 試験データのカード化・統計。
- 装置外への距離・方位・時刻の受渡し様式。

生のMHz・GHz信号を継電器計算機が処理するわけではない。

信号経路：

アンテナ → 真空管受信器 → 検波・増幅 → 波形整形・表示 → 人間または低速信号化 → 計算機・作図盤。

## 3.2 日程

| 時期 | 本作の進展 |
|---|---|
| 1936～38 | 連続波・電界変動研究へ記録・統計で参加 |
| 1937 | 連続波方式の限界を方式全体の失敗と誤認しない |
| 1938～39 | パルス時間装置、掃引、距離校正を共同研究 |
| 1939末～40前半 | 正式パルス試作 |
| 1940後半 | 沿岸試験装置 |
| 1941前半 | 実用原型 |
| 1941末～42初 | 艦隊実用試験 |

前倒し幅：

- 正式パルス研究12～18か月。
- 沿岸実用原型6～12か月。
- 艦上試験6～9か月。
- 標準搭載開始3～6か月。

## 3.3 組織分担

| 組織 | 責任 |
|---|---|
| 海軍技術研究所電波部門 | 周波数、送受信器、実用装置 |
| 大学研究者 | 電波伝播、アンテナ、マグネトロン、理論 |
| 電機・無線メーカー | 試作、生産設計、真空管、電源 |
| 放送・テレビ系 | CRT、掃引、同期、表示 |
| 計算機側 | 時間基準、校正、記録、統計、I/O |
| 光学・射撃指揮側 | 光学値との照合、射撃利用 |

計算機本部が電探研究を吸収しない。

陸海軍の完全統合も起きないが、メーカー、計測器、カード様式、部品試験に技術者レベルの共通化が生じる。

## 3.4 効果

| 項目 | 史実相当からの変化 |
|---|---:|
| 開発試験反復期間 | 30～50％短縮 |
| 装置性能ばらつき | 30～40％縮小 |
| 初期稼働率 | 相対15～25％向上 |
| 距離目盛・校正誤差 | 30～50％縮小 |
| 実用探知距離 | 5～15％程度向上 |

探知距離が小さいのは送信出力、アンテナ利得、受信雑音が支配するため。

最大の成果は、画面上の反応を艦隊が使える距離・方位・航跡情報へ変える速度と確実性。

## 3.5 艦上試験系列

- 比叡：振動、電源、艦橋アンテナ、CRT、無線干渉の環境試験。
- 伊勢：最初の艦隊実用試験候補。
- 大和：建造・艤装段階で、電探室、電源、冷却、配線、アンテナ基部を正式装備へ統合。
- 武蔵：正式装備として完成する最初の大型艦に近い。

初期電探は警戒・粗い水上捜索用。直接自動照準はしない。

初期情報流：

電探員読取 → 電話・電気伝送 → 作図盤で航跡化 → 光学見張りと照合 → 射撃指揮所。

1942～43年に電探距離、光学方位、機械式射撃盤、電子弾道補助器が組み合わさる。

# 4. 1943～44年以降への波及

Type 2P・Type 3で扱えるようになるもの：

- 複数観測値の平滑化。
- 距離変化率・航跡予測。
- 異常値除去。
- 複数目標番号管理。
- レーダー距離と光学方位の融合。
- 対空射撃の信管・気象補正。

ただし、レーダー映像を現代的にデジタル信号処理するのではない。人間が読んだ値または電子的に保持された低速信号を処理する。

この系統は後のミサイルで重要になる。

ミサイルでは、観測 → 状態推定 → 指令生成 → 操舵 → 再観測という閉ループ全体が兵器になるため、I/O、時間基準、サーボ、電子補助計算の蓄積が大きな先行資産になる。

## 2026年8月13日追加監査――安定垂直・主砲残差・高角射撃I/O

### 安定垂直・ジャイロの時間線

史実日本海軍は1930年代前半から安定垂直を研究しており、比叡でのType 98 Gyro Horizon級試験も本作計算援用以前の基準データとして扱う。計算機研究が発明するのは安定垂直そのものではなく、**ジンバル摩擦、減衰、追随ハンチング、線加速度誤差、取付・振動誤差を分離して最適化する過程**である。

- 1935：比叡の史実級Type 98試験を基準データとして保持。
- 1937～39：計算・精密加工・試験統計で追随系を改善。陸上で総合8～10角分級を目標。
- 1940～41：比叡で5～7角分級の少数成熟試験を高確度暫定とする。
- 金剛・榛名・霧島：1941年末までに簡略化・少数装備7～10角分級を作業帯とするが、全艦隊への量産普及は仮定しない。

安定垂直は完全自動安定射撃を意味しない。九四式方位盤等では人間が追随ループ内に残る。昼間良視界での上積みは小さく、夜間・薄明・煙・水平線不明瞭・動揺時に**性能低下を抑える**効果として扱う。

### 水上射撃――電子補助器の二重計上禁止

大和型Type 98機械式射撃盤は、史実でも自艦・敵運動、風、緯度、温湿度、飛翔時間、砲身摩耗、地球自転、日々の弾道補正等を扱う。したがって電子弾道補助器の利得を「これら補正を初めて可能にした」とはしない。

電子補助器の担当は、次へ限定する。

- 個砲・砲塔・装薬ロット・温度・砲身摩耗の残差更新。
- 非標準気象・長射程条件での補正表再計算。
- 複数測距儀・初速測定・射撃結果の統計処理。
- 機械式主射撃盤を残したまま、初期解収束・補正更新を支援する。

通常昼間の総合命中率改善は相対2～5％級を従来どおり慎重帯とし、長射程では**総誤差ではなく補正可能な系統誤差成分**が20～30％縮小し得る、と読む。物理的固有散布界の改善は0～5％級の小幅な感度帯に留める。

### 高角射撃――九四式は既に相当機械化されている

九四式高射装置と八九式12.7cm高角砲は、1941年時点でも計算・伝送・自動信管調定が相当機械化されている。したがって本世界の利得は、計算精度を一桁上げることより、**捕捉・再捕捉、目標切替、I/O、安定基準、電源・配線、管制チャンネル、弾薬物流、故障時引継ぎ**に置く。

大和竣工時は九四式高射装置4独立チャンネルを有力作業線とし、相互切替を可能にする。将来高角砲を増設する場合は、砲架数だけでなく6チャンネル級まで増設できる台座・視界・電源・信号幹線を準備する。

### 時限信管・自動調定機

九四式高射装置の秒時計算分解能より、1930年代型の歯付き自動信管調定機の機械誤差が大きな律速になり得る。1935～36年の史実試験・改修記録を計算援用の正式対象とし、次の時間線を採る。

- 1935：カム、歯ピッチ、バックラッシュ、信管本体の誤差予算を分離。
- 1936～37：現行歯付き型のカム計算化、芯出し、受入検査、故障率を改善。
- 1937～40：歯付き方式の量子化限界を認識し、連続式／平滑環方式を研究。
- 1941：大和基準装備は成熟した歯付き型。連続式は試作枝に留め、艦の成立条件にしない。

信管本体もロットごとの作動偏差を測定し、不良ロット排除、平均偏差・散らばりの記録を艦へ渡す。計算器・調定機・信管本体の改善を同じ命中率倍率として重複加算しない。

### 高角砲の評価指標

今後の対空艦評価では、砲門数だけでなく次を使う。

1. 探知・目標指示から初回有効射撃までの時間。
2. 独立管制チャンネル数と相互引継ぎ。
3. 急変針・目標変更後の再収束。
4. 弾薬庫から砲尾までを含む持続発射率。
5. 信管計算・調定機・信管本体の総合時間誤差。
6. 指揮装置・配電の一部損傷後に残る管制砲数。

これらは秋月型・大和型将来換装の共通評価軸とする。


## 2026年8月14日追加――潜水艦聴音・静粛化・再捕捉I/O

潜水艦用聴音を、潜望鏡の補助ではなく独立した接触・再捕捉センサーとして扱う。計算援用で装置の物理感度を飛躍させるのではなく、自艦雑音・個艦差・操作条件を較正する。

- 速力・回転数別の自艦雑音地図。
- 電動機、ポンプ、補機、舵・軸系の聴音阻害表。
- 聴音器左右の方位偏差、温度・深度・海況別誤差記録。
- 潜望鏡方位との比較較正。
- `高速移動 → 減速 → 静粛化待ち → 聴音` の標準手順。

潜高は高速中に高精度聴音できるとはしない。高速水中機動は射点修正・離脱のため、敵位置更新は減速後の再聴音・潜望鏡確認で行う。これにより水中高速、聴音、電池の三者を一つのI/O連鎖へ接続する。


## 2026年8月14日追加――火器管制を「敵に破綻させられる系」として研究する

射撃指揮研究は自軍の命中率・再捕捉だけで完結しない。敵の火器管制も、探知、目標割当、追尾、砲旋回、信管・照準、射界、目標切替という有限チャンネルの連鎖である。

本世界では実戦記録から、敵防空の「どこで目標切替が遅れるか」「艦隊変針時にどの射界が薄くなるか」「複数方位・高度から同時に入った場合に何機が終末攻撃圏へ抜けるか」を統計化する。これを敵装置の秘密仕様を知ることとは同一視しない。

攻撃側の具体的運用は45を正本とする。30は、火器管制が有限の追尾・伝送・射界・切替能力を持ち、**対抗側からもI/O連鎖として分析可能である**という技術的前提だけを担当する。
