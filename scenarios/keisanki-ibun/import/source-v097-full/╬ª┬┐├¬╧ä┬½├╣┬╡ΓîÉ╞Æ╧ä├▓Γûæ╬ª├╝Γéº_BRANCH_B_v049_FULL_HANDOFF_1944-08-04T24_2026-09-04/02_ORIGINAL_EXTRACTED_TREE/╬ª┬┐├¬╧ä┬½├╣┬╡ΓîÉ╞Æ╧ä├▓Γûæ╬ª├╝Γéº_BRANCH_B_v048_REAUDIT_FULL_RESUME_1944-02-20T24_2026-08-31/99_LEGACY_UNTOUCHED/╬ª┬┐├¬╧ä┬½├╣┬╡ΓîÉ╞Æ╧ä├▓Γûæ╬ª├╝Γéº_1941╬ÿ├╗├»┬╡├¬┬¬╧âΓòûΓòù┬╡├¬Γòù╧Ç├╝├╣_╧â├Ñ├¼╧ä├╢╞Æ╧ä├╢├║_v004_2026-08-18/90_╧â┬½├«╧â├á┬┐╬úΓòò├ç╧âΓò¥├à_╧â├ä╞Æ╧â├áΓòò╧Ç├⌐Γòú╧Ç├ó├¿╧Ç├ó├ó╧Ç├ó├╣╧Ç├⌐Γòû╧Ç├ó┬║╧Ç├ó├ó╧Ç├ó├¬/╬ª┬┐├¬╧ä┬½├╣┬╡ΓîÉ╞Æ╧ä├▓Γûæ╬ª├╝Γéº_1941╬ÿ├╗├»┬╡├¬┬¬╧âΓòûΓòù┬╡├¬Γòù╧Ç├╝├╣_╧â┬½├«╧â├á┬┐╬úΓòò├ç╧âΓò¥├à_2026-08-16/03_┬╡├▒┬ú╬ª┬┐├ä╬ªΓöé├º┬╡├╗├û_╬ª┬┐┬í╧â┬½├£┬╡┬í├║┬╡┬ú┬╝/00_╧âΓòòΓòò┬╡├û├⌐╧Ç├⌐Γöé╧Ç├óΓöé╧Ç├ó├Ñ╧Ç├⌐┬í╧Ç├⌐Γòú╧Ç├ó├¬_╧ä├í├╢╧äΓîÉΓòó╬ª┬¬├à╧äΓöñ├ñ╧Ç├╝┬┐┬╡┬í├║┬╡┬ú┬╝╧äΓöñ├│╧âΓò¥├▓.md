# 計算機異聞・研究共通規約と正本索引

本書は、海軍・航空機研究に共通する**常時参照用のルート正本**である。個別艦級・機体・装置の数値、近似式、費用、日程は各分野文書だけに置き、本書では繰り返さない。

## 0. 情報の状態

- **決定**：以後の検討で原則として維持する設定・方法。
- **上書き決定**：旧文書の暫定・有力案を更新する。旧記述は資料庫に保持し、正本では現行値を使う。
- **史実基準**：比較に用いた史実側の値。試験状態・資料条件を併記する。
- **監査済み中心推定**：史実基準、部位別改善、性能状態、量産状態を分けて再計算した作業値。
- **高確度暫定**：因果と中心線は安定しているが、一次資料または統合生産監査が未了の値。
- **中心推定／暫定**：会話中の工学推定。正本化・追加監査前に再検討し得る。
- **条件依存・未確定**：要求、資材、工廠、部隊教育、戦況、追加試験により変わる値。

同じ結論・数値を複数正本へ複製しない。更新時は担当正本だけを直し、索引・解説書には位置づけと要約を置く。旧引継ぎ全文は資料庫に保持する。航空横断正本50には現行統合判断を置き、機種別の継承詳細は51～53へ分離する。旧引継ぎ原文は90へ一本化する。

### 歴史考察80番台の状態表示

80番台は技術正本ではなく、**史観・比較・再走査用の歴史考察カテゴリ**とする。

2026年8月10日の魚雷・戦術閾値監査により、太平洋開戦後の戦果は技術入力の非線形効果を十分に伝播していないことが判明した。したがって80～84に記録された1941年12月以後の戦況・損耗・勝敗は、以後の作戦を拘束する現行史線として扱わない。

80～84は次を保持するために残す。

- 当時までに検討した作戦案、政治判断、戦力配置。
- 史実比較で何を問題にしたか。
- 技術入力を歴史へ適用した際に生じた分岐候補。
- 再走査で確認すべき損耗、修理、敵反応、兵站の論点。
- 1937～1941年前史のうち、開戦後再走査に依存しない背景考察。

状態表示は次とする。

- **史実基準**：比較に用いる実史の出来事・数値。
- **旧中心線**：2026年8月9日までに採った作業結果。再監査入力ではなく比較対象。
- **再監査候補**：31・61等の新しい技術入力を反映して再計算する箇所。
- **条件依存**：情報、損耗、天候、工廠、政治判断等で分岐する。

技術性能・生産日程・自然な戦術派生は10～70および61を優先する。太平洋開戦後の戦役結果は、31・61の規約に従って1941年12月から順に再走査するまで固定しない。

### 判断記録の原則（2026-08-11追加）

正本化・現行史線化する判断には、原則として**「判断の理由」**を併記する。最低限、次のうち判断を支える項目を明示する。

- 史実基準または当時取得可能な情報。
- 物理・材料・工場・輸送・教育等の律速。
- 代替案と比較した任務上・資源上の利得。
- 戦況依存部分と戦況非依存部分の区別。
- 不採用案を捨てる理由。

理由を「史実より自然」「この方が面白い」だけで済ませない。一方、未発生戦闘の命中・損害は理由付きでも事前確定せず、戦闘時の確率変数として扱う。

### 戦闘結果の帳尻合わせを禁止する（2026-08-12追加）

戦闘結果の「上振れ／下振れ」は、史実との差や物語上の均衡ではなく、**その時点の兵力、索敵、訓練、戦術、天候、損傷、相手の対策を条件とした分布**に対してだけ用いる。

- 日本側に有利な結果が続いたこと自体を理由に、次の成功確率を人為的に下げない。
- 米側に有利な結果が続いた場合も同様に、物語上の均衡のため失敗を挿入しない。
- 一度の成功から敵が具体的な対策を取った場合は、その対策を次戦の条件へ入れる。これは帳尻合わせではない。
- 既に成立した優位は、敵が対策を取るか、兵力・補給・技量が失われるまで通常どおり戦果へ転化させる。
- 「一回当たったから次は外す」「史実より戦果が多いから次は抑える」という処理は禁止する。

**判断の理由：** 本世界では技術・情報・兵站・損耗履歴が史実と異なるため、史実結果を暗黙の平均回帰先にすると、せっかく積み上げた条件差を無効化する。戦果は毎回、その時点の条件から判定する。


### 個別改装・派生・特殊兵器を決める六問（2026-08-14追加）

後期改装、転用、派生型、特殊兵器は、史実イベントを年表として自動再生せず、毎回次を確認する。これは固定結論を生む教条ではなく、後知恵、性能盛り、二重計上を防ぐ監査手順である。

1. **何が原因で要求されたか。** 損耗、脅威、任務不足、技術試験、資源制約等の発生原因を特定する。
2. **その原因は現行史線でも成立するか。** 原因が消えれば史実改装も自動発生させない。別原因が生じれば史実になかった改装も候補になる。
3. **計算援用が改善する段階はどこか。** 入力整理、設計探索、制御調整、試験解析、後続への学習還流を分ける。材料・電気化学・工作・未知荷重を計算力だけで突破しない。
4. **性能差は任務成功のどの条件へ入るか。** 速力、魚雷本数、砲門数、水中速力等をそのまま戦力倍率へ変換しない。索敵、射点取得、再接触、被害後機能保持等の律速へ接続する。
5. **「可能」と「実施」を分ける。** `再装填完了 ≠ 第二斉射実施`、`射撃解成立 ≠ 発射許可`、`航続可能 ≠ 作戦投入合理的`、`接触成立 ≠ 潜水艦が直ちに攻撃すべき` とする。
6. **同じ利得を重複計上していないか。** 重量、KG、電力、Availability、Mission effectiveness、Coordination、Situationを原因追跡する。

判断状態は**確定／条件付き／未確定**に分け、戦況・実艦試験・工廠余力を必要とするものは条件成立時だけ発火させる。生存艦も自動的に大改装・第一線復帰させず、現役、小改装、転用、予備、練習・試験、除籍を比較する。計算で得た余裕は武装・速力へ自動再投資せず、信頼性・整備性・消防・電力・将来余裕として残してよい。

# 1. 最重要の世界観上の原則

## 1.0 外部干渉と主体の原則

作者側が能動的に置いた分岐は、1928年前後に五人と周辺人物が出会い、当時存在した継電器、二進法・論理代数、ラジオ用真空管、精密加工、磁性材料を正しい順序で結びつけ、計算機を作ることまでである。

彼らは転生者ではなく、未来の戦史、兵器の後世評価、史実上の失敗を知らない。その後の採用・中止・配備は、当時の軍、企業、研究所、工廠、技術者、部隊が取得できる情報と利害から導く。「本作が採用させる」ではなく、誰が、どの試験値・工場・納期・要求を見て判断したかを書く。

## 1.0.1 史実との差を暗黙の上限にしない

史実から離れすぎるという理由だけで、当時の理論、入力、計算量、材料、試験、工場で回収可能な欠陥を残してはならない。一方、優秀な史実機・艦は最高性能の上積みが小さくなり、量産中央値、信頼性、可動率、日程へ利得が出る場合がある。

## 1.1 「万能にしない」ではなく「知りうるものを知る」

計算機効果は次の条件で判定する。

1. 現象の物理が当時知られているか。
2. 必要な入力値を図面・材料試験・模型試験・実艦試験から得られるか。
3. 当時の計算機で必要な計算量を処理できるか。
4. 出力が設計者に読める数表・曲線・盤・カム・射表等へ変換できるか。
5. 発覚時期が、基本設計・詳細設計・建造中修正・後続艦修正のいずれかに間に合うか。
6. 結果を採用しない具体的な制度・予算・製造上の理由があるか。

以上が揃えば、欠陥は原則として回復させる。

## 1.2 残る欠陥の理由

残る欠陥は、物語上の都合ではなく、次のいずれかで説明する。

- 現象モデルが存在しない。
- 入力係数が測れない。
- 実験設備がない。
- 材料・工作精度・溶接・検査が追いつかない。
- 実艦条件が模型と一致しない。
- 疲労、腐食、残留応力、施工不良など長期データが不足している。
- 設計変更が間に合わない。
- 要求側が余裕を別性能へ再投資した。

## 1.3 技術的成功と額面性能を分ける

技術的成功は、必ずしも最高速、兵装、航続距離などの額面性能増加として現れない。

- 予測重量と完成重量が一致する。
- 模型・地上試験と公試・飛行試験が一致する。
- 同型艦・量産機・装置ロット間の性能差が小さい。
- 危険回転域、振動、熱、荷重の予測が実測と一致する。
- 故障原因を再現し、後続艦・後続機・次ロットへ反映できる。
- 設計変更の影響を数値で説明できる。

技術者、乗員・搭乗員、部隊運用者、軍令・予算担当では評価軸が異なる。信頼性、稼働率、整備負担、額面性能、価格を分けて記述する。

# 2. 計算効果の分類

## 2.1 四種類の計算効果

### A. 従来計算の高速化

人手でも可能だった計算を大量・反復して行う。

例：重量、重心、トリム、復原性、縦強度、航続距離、配管圧損、軸系振動。

### B. 設計空間の探索

寸法・配置・材料・回転数等を振り、多数案を比較する。

例：艦幅、タンク分割、軸径、翼厚、プロペラ直径、舵面積。

### C. 不確実性・ばらつきの評価

公称値だけでなく、重量超過、材料ばらつき、加工公差、減衰係数、燃費差を振る。

目的は最軽量案ではなく、安全率と製造余裕を合理化すること。

### D. 設計・試験・製造の循環短縮

模型試験、公試、故障、材料試験の値を次案・後続艦へ迅速に戻す。

この効果は演算速度倍率だけでは評価できない。

## 2.2 三層の発生源

改善は三層から来る。

1. 中央研究・設計部門による全体計算。
2. 工廠、造船所、航空機メーカー、各専門課で増える局所計算。
3. 発動機、タービン、電機、兵装、計器、材料等、他部門から納入される品の性能・均質性向上。

他部門効果を「全体＋X％」として二重加算しない。該当する効率、重量、信頼性、試験値、射撃資料等へ一度だけ記帳する。

## 2.3 質的な軍事的派生を別勘定にする

量的性能差が小さくても、閾値を越えると戦い方そのものが変わる。これを「数％上方修正」へ埋没させない。

- 偶発的だった行動が予定行動になる。
- 一装備・一部隊の任務階級が変わる。
- 一回攻撃が反復サイクルになる。
- 必要攻撃隊・部隊単位が縮小し、目標配分や予備保持が変わる。
- 敵へ継続的な回避・警戒等を強制する。

具体的な横断判定と成立時期は `61_技術からの自然な軍事的派生_戦術サイクル・任務階級・戦史再監査.md` を正本とする。

## 2.4 技術利得を二値で消さない

技術改善は「戦力化した／しなかった」の二値で処理しない。要求・工場・材料・教育・母艦・補給等が律速し、当該期の前線配備数や制式化日を動かさない場合でも、試験収束、歩留まり、可動率、整備余裕、予備品、事故率、後続型、別性能への再投資等へ利得が残る可能性を確認する。

小利得が戦果閾値を越えて増幅する場合もあれば、別性能へ吸収される場合、ボトルネックにより当該観測窓では戦果へ変換されない場合、敵側適応で相殺される場合もある。いずれも「無価値」と先置きせず、伝播経路を追跡する。

# 3. 欠陥の回復可能性

## I. 検算で回復する

- 排水量・重量・重心
- 軽荷、満載、帰投時の状態
- 自由表面
- 標準波縦強度
- 航続距離・燃料
- 電力需要
- 既知の危険回転数

EM-1でも相当処理可能。

## II. 計算項目を増やせば回復する

- 高速転舵傾斜
- 非対称浸水
- 消防水自由表面
- 剛性不連続
- 波高・波長感度
- 一軸停止
- ポンプ能力と浸水速度
- 艦尾構造と起振力

事故・試験で一度認識されれば標準計算項目へ昇格する。

## III. 試験データがあれば回復する

- 舵・船体・プロペラ干渉
- 実海面抵抗
- キャビテーション
- 艦尾振動
- スラミング
- タービン・歯車・船体の連成振動
- 横揺れ減衰
- 溶接疲労

計算機は試験を代替せず、試験から得た係数を設計へ戻す。

## IV. 実故障・長期運用まで本質的に不明

- 未知の荒天荷重
- ホイッピング
- 低温脆性
- 溶接棒と母材の相性
- 残留応力
- 長期腐食
- 実戦損傷の火災・爆発連鎖

一度発生後の原因解析と全艦横展開は史実より速くなる。

# 4. 計算機世代と設計実務

## 4.1 EM-1（1932）

設定資料上の主要値：

- 論理・制御リレー650～750、補助200～300。
- 真空管60～90。
- リレーレジスタ8語。
- 直径15cm、3,000rpmドラム。
- データ2,048語＋命令256語。
- 約155固定ヘッド。
- 毎秒およそ2.5～3命令。
- 紙テープ入力、数字印字。図形出力なし。

代表的な設計用途：

- 選別した十数条件の精密検算。
- 数表出力後、製図工が手作業で曲線化。
- 船体線図は面積・座標表へ人手変換して入力。

## 4.2 Type 1A/B（1934～37）

- 毎秒5～12命令級。
- 16高速語。
- 標準計算手順を紙テープ化。
- 復原性、重量簿、縦強度、タンク、航続、振動を定型化。

代表的な設計用途：

- 一艦数十状態の計算。
- 設計変更後の再計算。
- 艦級間の同一様式比較。

## 4.3 Type 1C（1938～39）

- ドラム4,096語。
- 毎秒8～20命令級。
- 二重入出力。
- 紙テープ50～100字符/秒級。
- 数字印字80～110行/分級。
- カード分類・照合、離線式作図が実用化。

代表的な設計用途：

- カード式重量簿。
- 部品・工数・材料の照合。
- 座標カードから復原梃、剪断力、曲げ、抵抗、振動曲線を機械作図。
- 同型艦間の差の定量化。

## 4.4 Type 2（1939～41）

- 封止リードリレー2,200～2,600。
- 真空管150～250。
- 直接選択コア48～64語＋高速ドラム。
- 主ドラム4,096語級。
- 代表混合処理30～100命令/秒。
- 浮動小数点、反復、条件分岐、係数当てはめが現実的。

代表的な設計用途：

- 多質点振動。
- 多変数反復。
- 試験値への係数フィット。
- 高速潜水艦の水中船型、電池負荷、深度制御。

## 4.5 Type 2P・Type 3（1943～）

Type 2P：パラメトロン演算部を持ち、実業務でType 2の3～5倍程度。

Type 3A/S：パラメトロン、1,024～4,096語コア、50,000語ドラム。

主用途：

- 非定常に近い大量条件走査。
- 音響・振動の周波数別処理。
- 自動深度保持・操舵係数。
- 製造公差を含む統計設計。

# 5. 入出力成果と搭載計算の決定

## 5.1 陸上計算の成果は表・盤・カムとして艦へ載る

朝潮型～陽炎型、同時期の潜水艦では、汎用二進計算機を艦へ載せることが主要効果ではない。

陸上計算結果は次の形になる。

- 射表・仮射表
- 気象・初速・砲身摩耗補正表
- 魚雷射角盤
- カム・目盛環
- タンク使用順序表
- 潜航・浮上手順
- 魚雷発射後補水表
- 電池残量・静粛速力表
- 損傷時注排水盤

## 5.2 艦載計算装置の時期

- 1930年代：機械式・機械電気式射撃盤は既に存在。
- 1938～41年：大型艦で専用電磁補助計算器を試験可能。
- 1941～43年：大型艦・旗艦・一部新造艦へ小型専用機。
- 駆逐艦への汎用計算機標準搭載は不適切。
- 潜水艦では深度・姿勢・電池の専用盤が先に進む。
- Type 3世代で半自動深度保持等へ進展。

# 6. 振動解析に関する決定

1930年代の回転設備振動は「式がない問題」ではない。

計算可能：

- 軸系ねじり振動
- 軸の横振動・危険回転数
- タービン翼固有振動
- Campbell線図
- 歯車噛合い次数
- ノズル通過次数

計算上の基本形：

- 慣性円板＋ねじりばね列。
- `det(K - ω²J) = 0` に相当する固有値問題。
- 実務ではホルツァ法等の逐次試行。

難しい部分：

- 減衰
- 翼根・軸受・船体の実効剛性
- 蒸気流・伴流による励振力
- 加工差
- 疲労・残留応力

結論：既知の共振候補は早期からかなり除去される。朝潮型史実のタービン翼問題が全10隻へ広がる展開は、この世界では不自然。設計試験・陸上試験・初期艦公試のいずれかで捕捉する。

# 7. 局所利得の使途

ある部位の負荷・重量・計算誤差を減らせても、結果は自動的に軽量化や最高性能向上にはならない。

候補：

1. 軽量化・小型化
2. 構造・安全性の強化
3. 最高性能または実用性能の向上
4. 信頼性・稼働率
5. 将来増備余裕
6. 製造公差余裕
7. 整備性
8. 試験・量産・教育の安定化

どこへ再投資するかは、対象分野の史実要求、事故経験、材料・工作限界から決める。水上艦の配分は10、潜水艦は20、センサー・射撃指揮は30、対潜航空は40、航空機は50を正本とする。

# 11. 軍事状況の扱い

後年の艦級・就役時期を推定する際、史実の軍事経過をそのまま書き込まない。

プロジェクト世界では、数段階にわたり米軍を抑え込み、史実ほど早期に経済・輸送・工廠が破綻しない可能性がある。

したがって、次を分ける。

- 技術的に設計可能な時期
- 要求が発令される時期
- 予算・資材・船台が配分される時期
- 実際の就役時期

軍事状況を決め打ちせず、要求発令が同じ場合と、継続研究により要求具体化が早い場合の幅を出す。

# 12. 今後のLLM向け作業手順

1. 対象装備の史実基準諸元を固定する。
2. 設計・開発時期と、利用可能な計算機世代を対応させる。
3. 要求、基本設計、詳細設計、試作・建造、試験、量産・後続型、部隊運用を分ける。
4. 各項目について、当時の理論、取得可能な入力、I/O、実装時期を判定する。
5. 活用度と計算機側の伸びしろを段階評価する。
6. 局所利得を重量、効率、強度、信頼性、ばらつき、日程へ落とす。
7. 利得を軽量化、小型化、強化、性能、稼働率、将来余裕のどこへ使うか、史実要求から決める。
8. 重複を除き、担当分野の統合勘定へ一度だけ記帳する。
9. 艦級・機種・装置全体の重量、寸法、出力、燃料・電力、性能、搭載品を整合させる。
10. 技術者、乗員・搭乗員、部隊、軍令、会計の評価を分ける。
11. 技術時計、要求時計、資材・工廠時計、部隊運用時計を分ける。
12. 暫定値は「中心推定」または「条件依存・未確定」と明記し、設定確定値にしない。

# 13. 計算機世代に共通する設定上の特徴

- 初期から継電器と真空管を役割分担する。
- 1930年代後半には演算速度以上に、測定・転記・通信・表示が律速として意識される。
- 艦載・車載派生型は速度より交換ユニット、二重電源、防塵、防振を重視する。
- 1943年以降のパラメトロンは衝撃、電力、保守の面で艦載用途に有利。

# 14. I/O・センサー・制御の接続原則

自然な連鎖は次のとおり。

1. 計算機が設計・試験を高速化する。
2. 入力測定と出力伝達が新しい律速になる。
3. 計測・変換・記録班が育つ。
4. 光学、振動、電探、磁探、射撃指揮へ参加する。
5. センサー出力を表、盤、作図、低速信号として利用する。
6. 艦載専用計算器が補正と状態推定を担当する。
7. 1943～44年以降、パラメトロンと制御理論が閉ループ制御へ接近する。

1930年代末に、完全な自動探知・追尾・誘導系を成立させてはならない。生の高周波信号を継電器計算機へ直接入れるのではなく、検波・表示・人間読取または低速信号化を介する。

# 15. 時期推定で分離する時計

- **技術時計**：設計、計算、試験、修正が可能になる時期。
- **要求時計**：軍令・部隊が必要性を認識し、要求を発する時期。
- **資材・工廠時計**：予算、材料、船台、工場、熟練工が割り当てられる時期。
- **部隊運用時計**：教育、整備、補給、戦術、配備が実用水準へ達する時期。
- **母艦・基地時計**：海軍航空では空母竣工・航空隊完成、前進基地・水上基地・整備設備が任務に間に合う時期。

設計短縮を、そのまま起工・竣工・初飛行・制式・実戦配備の同幅前倒しにしない。航空機の性能は、試作最良、制式標準、部隊中央値を分ける。

# 16. 分野横断の現在地点

- 駆逐艦では、朝潮型を「事故の教訓を計算で固めた最初の基本計画援用艦」、陽炎型を「実測を戻して良艦を標準化した成熟級」とする。
- 潜水艦では、甲乙丙型までが既存思想の最適化、潜高型から水中中心思想への転換とする。
- 大型艦では新造より先に改装へ入り、大和型の戦略思想・艦級構想は維持しつつ個別設計方針を変える。
- 艦載電子計算機は主射撃盤を置き換えず、非線形・多変数補正を担当する。
- 電探は計算機研究が発明するのではなく、時間基準、校正、表示、試験統計、I/O標準化で接続する。
- 東海・カ号は計算機側が発案せず、既存の対潜・航空・センサー研究を試験処理と統合で早回しする。開戦時戦力には数えず、1942年試験、1943年実用が中心。
- 艦艇対潜では、史実1942年相当の探信・聴音・爆雷を基礎に、自艦雑音表、較正、爆雷深度・投下点、二艦協同、再捕捉を改善する。水上捜索レーダー・前方投射兵器の欠如は残す。
- 十二試艦戦は冷静な比較の結果、瑞星一三型改→一五型→二一型を主線として選ぶ。栄換装待ちを避け、制式標準・部隊配備が数か月早まる。
- 1941年12月の日本軍戦術機は2,850～3,050機、史実比約9～16％増の条件依存値。第一線の実効作戦出力は15～25％増が中心。
- 水上機戦力全体は史実比15～30％増を中心とし、旧案の3～4倍は撤回する。
- 開戦時輸送差は指定船・徴用船の運用改善が中心で、戦時標準船の本格完成は1942年春～夏以後。
- 空母は搭載枠が上限である。低速・改装空母は任務階級を条件付きでまたぐが、着艦・回送・教育との交換が残る。
- 1942年の海軍搭乗員教育は母数・設備を増やすが、MI一会戦だけで第一線課程を粗製化しない。品質変更の判定点はFS等の連続損耗とする。

# 17. 固定しない事項

- 開戦後の戦線、敵軍の進出速度、攻略地図。
- 艦艇・航空機の最終生産数と配備余力。
- 資材、輸送、電力、工廠の戦時劣化。
- 電探・磁探の周波数、素子材料、検出器の飛躍。
- 大和型の軍令要求そのものの大転換。
- 東海・カ号だけで潜水艦を大量撃沈する結果。
- 瑞星一三・一五・二一型の未監査性能値を確定値へ昇格すること。
- G8N、富嶽、1945～46年の噴進機等を、要求・発動機・資材・戦況の統合前に一律前倒しし、量産数を先に固定すること。
- 開戦時の帳簿上の純増、旧型からの置換、可動率による実効増加を同じ「機数増」として加算すること。
- 暫定性能値を、追加資料なしに設定確定値へ昇格すること。

# 21. 2026年8月13日更新――艦艇戦力の伝播と戦史再監査v3

1944年初夏まで歴史線を進めた結果、技術正本10・20・30・31・61に存在する艦艇側の利得を、歴史考察で「艦数は存在するが作戦上はほぼ空母・航空・潜水艦だけで判定する」形に落としていたことが判明した。これは技術設定の不足ではなく、**技術利得→任務設計→艦隊編成→戦果**の伝播不足である。

以後、次を常時規約とする。

1. **現存し、任務に適合し、燃料・整備・指揮上投入可能な艦艇を、理由なく戦史計算から消してはならない。** 投入しない場合は、温存、速力、燃料、航空脅威、海面、指揮、別任務等の理由を記す。
2. 艦艇の設計・射撃・電探・防御・稼働率等の改善を一個の「＋数％」へ潰さない。担当正本の各利得を重複除去し、任務別の成功確率・継戦時間・再攻撃可能性へ変換する。方法は62を正本とする。
3. 10にある「有効戦力＋7～12％」等の旧作業推定は、個別の改装・稼働性を説明する単軸値であり、**艦全体の任務実効値の上限ではない**。射撃、情報、対空、損害制御、可動率、編成効果が同時に効く任務では、最終効果がより大きくなり得る。
4. 水雷戦では31の第二斉射サイクルを常時監査する。20～60分継続する水上戦で次発魚雷を持つ部隊が存在する場合、第一斉射だけで戦闘を閉じない。
5. 後期新造戦闘艦ほど、重量余裕、電力、配線、電探、射撃指揮、対空、損害制御を基本設計から統合でき、複数利得の積が出やすい。潜水艦は水中速力・航続・静粛・攻撃計算・生還が閾値を越えるため、特定任務の実効値が線形差を大きく超え得る。
6. 敵側の認識も同時に更新する。米海軍は日本の既知艦級、生残金剛型、大型脱条約戦艦の存在、日本海軍の決戦思想を概ね認識している。一方、艦内の計算・較正・I/O・冗長性・損害制御・再装填再現性等の**体系能力は割り引いて評価する余地が大きい**。
7. 大規模艦隊戦のレーダー差は万能補正にしない。敵主力の存在が双方に明白な局面では、主に「何分早く安定した状況認識・射撃解・CAP誘導へ入るか」として扱う。艦隊防空の閉ループでは米側優位を大きく残す。

# 22. 2026年8月13日追加――代表艦級再監査の横断規約

金剛型、大和型、陽炎型・夕雲型を代表例として水上艦評価を再監査した。以後、艦艇正本・戦史再監査では次を常時規約とする。

1. **1934年友鶴事件後を大型艦への継続計算援用の主線開始点**とする。1932～33年は例外的試算に限定する。
2. 質量、鉛直モーメント、縦方向モーメント、電力・配管・空間容量を別帳簿にする。重量余裕とKG余裕を加算しない。
3. 設計予測→公試実測→残差→次艦への戻しを制度として扱い、分野ごとに未検証／単艦確認／姉妹艦再現／成熟標準を区別する。
4. 防御は装甲倍率ではなく、健全→局部損傷→機能低下→任務不能→航行不能→喪失の状態遷移で扱う。
5. 同型艦ばらつきの縮小は、複数艦編成の最低性能艦問題を通じて部隊任務成立率へ増幅し得る。
6. 後日搭載可能な装備を開戦時戦力へ加算しない。一方、重量・KG・電力・配線・空間・弾薬庫転換性等を先に用意した場合は、改装の**将来選択肢の価値**として扱う。
7. 反復兵器の予備弾・次発魚雷・第二波を初撃へ単純加算せず、戦闘時間内に次の有効攻撃へ変換できる確率で評価する。
8. 同一の配電・損害制御改善を「生存率」と「攻撃継続率」へ別々に倍率計上しない。条件付き任務機能として一度だけ数える。

代表艦級の技術詳細は10・30・31、戦術への伝播は61、任務係数の感度帯は62を正本とする。
