# 2026年8月14日追記――44による再計算指定

本書の中心戦果は、戦術研鑽・組織学習層44を十分に入れる前の値である。**現行確定戦果として使用せず、FORAGER再計算の比較枝とする。** D-Day、航空損失、飛鷹/隼鷹損傷、夜戦損害、Saipan D+1値は再計算対象。

# 1944年7月8～15日 FORAGER前哨・フィリピン海再監査

## 1. 結論先置き

FORAGERのSaipan D-Dayは、39の暫定中心7月12日から**1944年7月14日**へ2日後退する。

原因は米上陸軍の準備不足ではない。7月10日までに日本第一機動艦隊の東進が確実視され、Marianas基地航空も史実のようにほぼ消滅していないため、Spruanceが**上陸前に艦隊決戦の第一波を受ける**方を選ぶためである。

これは史実でSaipan上陸後、日本第一機動艦隊接近によりGuam上陸が延期され、輸送船の大半を東へ退避させた判断を、今回は「Saipan上陸前に敵艦隊が来ている」条件へ適用したシナリオ推論である。

結果として本世界のフィリピン海海戦は、史実の「Great Marianas Turkey Shoot」ほど一方的ではない。

- 米側は空母航空・レーダーCAP・対空火力で勝つ。
- 日本側はRabaul消耗を受けていない搭乗員、後期戦闘機、基地航空残存、暗号防御、潜水艦、水上前衛を持つ。
- 日本空母航空は大損害を受けるが、一日でほぼ消滅しない。
- 米側もfleet CV、CVL、高速BBにmission-killを払う。
- 大和・武蔵を含む日本主力水上艦隊は、上陸船団への通路が開かなかったため保存される。

戦略判定は**米海軍の作戦勝利、日本海軍の決戦能力一部保存**。

# 2. 7月7日夜――両軍はすでに互いを待っている

日本側は6月末までにMarianas主攻を95％以上と見ている。従って史実のように「米空母空襲を受けてから慌ててA-GOを始動」しない。

7月7日夜：

- 第一航空打撃群・第二航空群：Philippine Sea西部へ東進中。
- 高速水上前衛：空母群より内側/南側を並走。
- 大和・武蔵・長門群：さらに西側で輸送船団突入の条件待ち。
- AO二群：130°E前後より西へ分散給油。
- Marianas基地航空：全機を飛行場へ密集させず、二線基地と水上機泊地へ分散。
- 日本潜水艦：Marianas東側、Eniwetok～Marianas接近線、TF58給油推定帯へ層別配置。

米側も日本主力来援を高確率で見込む。高級暗号から正確な位置を読むわけではないが、潜水艦、長距離哨戒、方探、基地通信量から西方大艦隊の移動を察知する。

# 3. 7月8日――第一前進空襲

TF58五群はSaipan/Tinian/Guamへfighter sweepと飛行場攻撃を実施。

日本側は「迎撃で全部を失わない」ことを優先する。

中心：

- 米出撃：対地・fighter sweep **480～540 sortie級**。
- 日本迎撃：**180～220機級**、残りは退避/後刻使用。
- 日本航空全損・重大損傷：**60～75機**。
- 米航空全損：**18～24機**。

米側は明確に優勢だが、史実型の無抵抗飛行場掃討にはならない。雷電・紫電改は主に爆撃/攻撃機へ突入し、金星零戦改は上空戦と長距離護衛へ使う。

滑走路損傷後も強風・水上偵察が残るため、米側は飛行場だけでなく水上泊地、燃料、通信へ攻撃枠を割く。

# 4. 7月9日――第二波、晴嵐初使用

## 4.1 Marianas

米第二波で日本航空はさらに**50～65機**を失い、米側も**15～20機**を失う。

ただし日本はPagan/Yap/Philippinesへ一部を移し、7月9日夜でもMarianas～一日圏の戦闘使用機を**270～310機**残す。

## 4.2 伊400・伊401／晴嵐

旧89の6月30日奇襲は非正本だった。今回、初使用を**7月9日未明～早朝**へ置く。

理由：

- 7月7～8日のTF58前進でEniwetok/Majuroの補給量が増える。
- ただし米側も警戒しており、旧枝の「AO1重大損傷＋AKA1大火災＋LST1」の大戦果をそのまま採らない。

伊400・401から晴嵐6機発進。4～5機が目標圏へ到達。

中心戦果：

- loaded ammunition lighter / 補給艀1隻級焼失。
- AOまたは燃料補給船1隻軽～中破、**2～4日局地運用離脱**。
- 岸壁・燃料/弾薬集積の小火災。
- 米人的損害**70～120**。
- 晴嵐2機喪失、1機重大損傷、残り離脱。

単独でD-Dayを動かすほどではない。しかし米側に補給分散、夜間CAP、停泊位置変更を強制し、後の潜水艦給油群攻撃と同じ「兵站時計」へ効く。

# 5. 7月10日――日本艦隊捕捉、D-Day延期

米潜水艦・長距離航空が日本空母/戦艦群の東進を複数回確認。exact trackではないが、**48時間以内にMarianas西方へ入る**ことはほぼ確実になる。

この時点でSpruanceは、7月12日予定だったSaipan D-Dayを**7月14日へ延期**する。

- 低速APA/AKA/LSTの主群を東へ保持。
- 高速砲撃群だけをMarianas近傍に残す。
- Lee高速戦艦7隻を西方阻止線へ集中。
- TF58は島制圧より対艦索敵/CAPへ航空枠を増す。

## 5.1 米潜水艦対大鳳

地理的ピケットの一隻が大鳳群へ射点を得る。

**大鳳：魚雷1本命中中心。沈没しない。**

本世界ではMI後の空母戦訓により、航空燃料主管遮断、通風区画化、残油管理、消防・排水の標準手順が史実より強い。従って史実Taihōのような航空燃料蒸気の艦内拡散→大爆発を中心結果にしない。

- 速力：24～26ktへ一時低下。
- 数時間、発着艦を制限。
- その後CAP収容・限定発艦まで復旧。
- **作戦後6～10週修理級**の損傷だが、この日の艦隊から即脱落はしない。

これは「魚雷が効かない」ではなく、**mission kill/修理へ変換され、艦喪失へ連鎖しない**という改善である。

# 6. 7月11日――日本の統合航空攻撃

## 6.1 攻撃規模

日本側は基地航空を先に全滅させず、空母航空の攻撃時刻へ重ねる。

- 空母発進：**320～350機**。
- 基地航空：**135～160機**。
- 同日主攻撃に関与：**455～505機級**。

大鳳の損傷で第一航空打撃群の第二波規模は低下するが、他3主力CVと第二航空群が補う。

## 6.2 米防空

米側は1,000機超の艦載航空を持つため、CAP・barrier CAP・予備を大量に上げられる。レーダー早期警戒、fighter direction、5in/38＋VTの統合優位は維持する。

しかし日本側は史実より、

- 編隊を維持できる搭乗員が多い。
- 金星零戦改等でF6Fとの速度/上昇差が縮小。
- 進路誤認・燃料切れ・未熟な空戦損失が減る。
- 基地航空と別方向から時間を近接させる。

ため、一方的な9割損失にはならない。

中心：

- 日本航空全損：**185～220機**。
- 米航空全損：**55～70機**。

## 6.3 艦艇損害

中心：

- **Franklin CV-13：爆弾2＋魚雷1級、8～12週mission-kill。** 艦喪失なし。
- **Bataan CVL-29：爆弾/至近弾・火災で3～5週mission-kill。**
- CA/CL1隻中破級。
- DD1～2隻中小破。

Franklinを選ぶのは「新造艦だから脆い」という意味ではなく、五個群のうち攻撃方向とCAP再配置が重なったTG58.4に主攻撃の一部が抜けたという戦場配置の結果である。

米大型CVは1隻を一時失うが、なお**9隻**残る。

# 7. 7月12日――米反撃

日本航空攻撃から帰投した機の報告、米長距離索敵、潜水艦接触を統合し、TF58は日本第一機動艦隊の位置を更新する。

米側は上陸をまだ始めていないため、史実20 Juneより「輸送船保護と対地支援に同時拘束される航空」が少ない。Franklin/Bataanを失っても、大規模対艦攻撃が可能。

- 米対艦発進：**420～470機**。
- 日本CAP：**105～125機級**。
- 米全損：**75～95機**（空戦・対空・燃料/夜間回収を含む）。

中心戦果：

- **飛鷹：沈没。**
- **隼鷹：大破、2～3か月mission-kill。**
- 大鳳：既存雷撃損傷のまま生存、追加重大命中なし中心。
- 翔鶴・瑞鶴・飛龍：軽～中小破感度、中心重大損傷なし。
- AO1隻沈没、別AO1隻中破。
- 日本艦載機/甲板上機等：追加**90～120機**喪失。

日本空母航空は戦役前の460～490機から、7月12日夜には**170～210機級の即時戦闘使用**まで減る。史実のほぼ全滅ではないが、もう同規模の攻撃はできない。

# 8. 7月12～13日夜――高速水上前衛とLee battle line

日本側は米大型CVを1隻mission-killしたが、なお9隻級が健在。従って大和・武蔵主力打撃群を輸送海面へ送る閾値には届かない。

ただし、高速水上前衛を何もせず戻すとfleet-in-being効果を捨てる。金剛型4＋高雄型4＋DD群を夜間に東進させ、輸送群の位置を探る。

米側はこれを想定してLee高速戦艦群を西へ出している。

### 接触

- 米SG radarが先に大編隊を捕捉。
- 日本側も粗い電探＋光学・方位情報で敵戦艦線を把握。
- 日本側は輸送群へ抜ける通路がないと判断し、20～60分級の限定砲雷撃後に反転する。

中心損害：

**米**
- **Indiana BB-58：酸素魚雷1本級命中、4～6週mission-kill。**
- DD1隻沈没。
- CA/CL1隻軽～中破。

**日本**
- **比叡：16in砲弾1発級＋至近弾、3～5週mission-kill。**
- 鳥海：中破級。
- DD2隻沈没、1隻中破級。

日本側は長距離雷撃の戦果を得るが、米battle lineを破って輸送群へ入れない。Lee側も日本高速群の殲滅を狙って深追いせず、主目的であるtransport screenを守る。

これが水上艦再監査の中心的帰結である。

> 水上艦は「空母戦で勝った側の護衛」ではなく、上陸日、島砲撃量、夜間輸送船配置、敵battle lineの場所そのものを変える。

# 9. 7月13日――上陸準備へ戻る

日本第一機動艦隊は西へ後退して給油。AO損失と大鳳/隼鷹損傷により即時再攻撃能力は低い。

米側は、

- Franklin、Bataan、Indianaを後送開始。
- TF58はfleet CV9＋CVL7中心へ再編。
- 日本基地航空掃討へ再び比重を戻す。
- Saipan西岸砲撃を強化。

日本Marianas航空は、7月8～13日の累計で**240～290機級**を全損・重大損傷し、Marianas即応は**100～135機級**まで低下する。さらに50～70機級はYap/Pagan/Philippines側へ退避している。

「基地航空完全消滅」ではないため、D-Day後も夜襲・偵察・局地雷撃が残る。

# 10. 7月14日――Saipan D-Day

## 10.1 守備隊

史実Saipanは約31,600軍人級だった。本世界では、

- Marianas攻撃が一か月遅い。
- 日本海上輸送・ASW・暗号防御が史実より良い。
- 史実で43師団輸送船5/7隻が沈み、大量装備も失われた部分を一部回収する。

ため、Saipan軍人を**34,500～37,000人級**とする。

重要なのは人員増より、

- 火砲・弾薬・通信器材の到着率。
- セメント、鋼材、木材、鉄条網。
- 車両・牽引具。
- 予備陣地完成度。

が史実より高いことである。

## 10.2 米初日

米軍はMidway以来の環礁/島嶼上陸経験を持ち、LVT波次、艦砲射撃、航空統制は史実1944年6月より手順面で改善している。

一方、

- TF58の航空損失。
- Lee群の西方警戒。
- Indiana離脱。
- 日本基地航空100機超の残存。
- 日本砲兵陣地完成度上昇。

により、全火力を浜へ集中できない。

中心：

- 上陸自体は成功。
- 初日夜までに連続した海岸橋頭堡を確保。
- Aslito方面への進出は史実より**0.5～1日遅い**。
- 米軍D-Day～D+1死傷：**3,600～4,300人級**。

上陸失敗にはしない。米艦隊・兵站・兵力の絶対優位は大きい。

# 11. 7月15日朝の戦略状態

## 米国

- Saipan上陸成功。
- fleet CV9、CVL7が即時戦闘使用中心。
- Franklin 8～12週、Bataan 3～5週、Indiana 4～6週離脱。
- 艦載航空累計全損：**150～190機級**。
- なお作戦継続可能だが、Guam/Tinianを史実日程の単純平行移動で続ける余裕は低下。

## 日本

- 飛鷹沈没。
- 隼鷹大破、比叡中破、大鳳雷撃損傷、鳥海中破。
- 空母航空の即時使用170～210機級。
- Marianas基地航空100～135機級。
- 大和、武蔵、長門、金剛、榛名、霧島、翔鶴、瑞鶴、飛龍は戦闘可能中心。
- 水上主力の大半を保存。

## 判定

**航空海戦：米勝利。**

**日本空母航空：大損害だが史実型壊滅を回避。**

**水上戦：戦術的相互損害、米transport screen成功。**

**FORAGER戦役：米作戦勝利が進行中。**

日本側はSaipanを救えなかったが、主力水上艦隊を輸送船のいない海面へ突入させず、次段階へ相当数を残した。

米側はSaipanへ上陸したが、史実より二日遅れ、carrier/BB mission-killと追加航空損失を払った。

# 12. ここで止める理由

7月15日以後は、

1. Saipan地上戦の長期化。
2. 日本残存基地航空の夜襲。
3. Guam D-Dayをいつ再設定するか。
4. TinianをSaipan終了前に並行実施するか。
5. 日本主力艦隊が再給油後に二度目の水上出撃を試みるか。
6. 米損傷空母・BB・上陸舟艇がDRAGOON/Normandy後資源配分へ波及するか。

を同時に見なければならない。

したがって現行停止点を**1944年7月15日朝、Saipan D+1**とする。
