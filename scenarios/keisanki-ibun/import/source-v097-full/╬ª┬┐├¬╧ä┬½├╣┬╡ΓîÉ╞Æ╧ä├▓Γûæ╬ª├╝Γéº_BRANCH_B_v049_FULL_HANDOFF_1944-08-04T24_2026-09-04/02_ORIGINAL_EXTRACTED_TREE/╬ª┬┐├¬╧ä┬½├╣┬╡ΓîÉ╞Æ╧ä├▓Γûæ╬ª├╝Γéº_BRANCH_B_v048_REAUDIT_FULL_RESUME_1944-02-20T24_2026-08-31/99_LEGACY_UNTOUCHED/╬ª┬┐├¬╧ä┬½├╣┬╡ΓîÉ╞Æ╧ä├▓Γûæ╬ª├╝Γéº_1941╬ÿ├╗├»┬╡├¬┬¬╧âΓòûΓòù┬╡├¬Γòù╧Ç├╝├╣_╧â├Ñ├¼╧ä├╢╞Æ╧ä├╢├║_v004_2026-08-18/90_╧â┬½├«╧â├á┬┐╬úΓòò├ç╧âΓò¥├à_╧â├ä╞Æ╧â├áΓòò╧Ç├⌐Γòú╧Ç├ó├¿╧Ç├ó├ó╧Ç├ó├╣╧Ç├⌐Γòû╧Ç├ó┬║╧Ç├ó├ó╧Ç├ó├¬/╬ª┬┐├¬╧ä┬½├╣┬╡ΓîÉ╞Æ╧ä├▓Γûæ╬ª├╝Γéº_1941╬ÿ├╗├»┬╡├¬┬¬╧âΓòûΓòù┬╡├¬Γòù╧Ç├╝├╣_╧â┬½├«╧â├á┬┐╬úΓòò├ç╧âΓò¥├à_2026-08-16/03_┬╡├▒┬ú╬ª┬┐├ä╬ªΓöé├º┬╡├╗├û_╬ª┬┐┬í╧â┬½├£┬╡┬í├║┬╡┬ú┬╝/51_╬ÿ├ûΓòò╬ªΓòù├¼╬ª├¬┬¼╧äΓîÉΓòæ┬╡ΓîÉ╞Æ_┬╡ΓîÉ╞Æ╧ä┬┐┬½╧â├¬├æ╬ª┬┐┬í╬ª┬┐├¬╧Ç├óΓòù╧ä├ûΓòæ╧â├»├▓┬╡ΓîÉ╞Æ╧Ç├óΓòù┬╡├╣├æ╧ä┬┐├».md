# 計算機異聞・陸軍航空機　機種別設計・発動機・日程

本書は、旧陸軍航空研究引継ぎの機種別詳細を、現行正本体系へ継承した詳細正本である。各数値の確度表示は維持し、50の上書き決定と競合する場合は50を優先する。

## 0. 本書の目的

本書は、これまで検討した陸軍航空機系列の機種別詳細正本である。横断統合は50が担当し、本書は追加監査と更新に用いる基準として、次の三点を同時に残す。

1. 現時点で維持してよい開発系統、要求、役割分担、実装時期。
2. 現時点の中心性能値と、その確度。
3. 「史実との差を無意識に抑える」誤りを再発させないための研究方法と注意点。

本書の数値は、必ず次の状態表示と一緒に読む。

- **決定候補**：方法論および因果関係が十分に整理され、正本へ移してよい内容。
- **監査済み中心推定**：史実基準、部位別改善、装備状態、量産状態を分けて再計算した作業値。
- **高確度暫定**：大筋は自然だが、新しい監査方式による再計算をまだ終えていない値。
- **暫定**：二次資料依存、入力不足、または概算方式が粗く、正本化前に再検討が必要な値。
- **条件依存・未確定**：生産配分、発動機供給、作戦、追加試験などで変わる値。

## 0.1 再処理の進捗

「とどめる」という表現を契機に、史実差を暗黙の上限として扱っていた可能性を監査した。現在の進捗は次のとおりである。

| 系列 | 状態 | 備考 |
|---|---|---|
| Ki-46百式司偵 | **監査済み** | 一型、二型初期・後期、三型初期・後期を性能状態別に再計算済み。 |
| Ki-44二式単戦 | **監査済み** | 二型初期・推力排気型を分離。速度・上昇を修正済み。 |
| Ki-61三式戦 | **監査済み** | 軽武装型と12.7mm四門型を分離。上昇値を修正済み。 |
| Ki-27九七戦 | 高確度暫定 | 基本線は安定。性能状態別の最終監査は未実施。 |
| Ki-43隼相当 | 高確度暫定 | 1940年後半制式という中心線は維持。部位別空力監査は未実施。 |
| Ki-38／Ki-45／Ki-45改 | 高確度暫定 | Ki-45改は重量・抵抗・航続・片発を詳細計算済みだが、新しい三状態方式での再表示は未実施。 |
| Ki-60 | 暫定 | 不採用という結論は維持。性能値は再監査が必要。 |
| Ki-15九七式司偵 | 高確度暫定 | 役割・発展線は維持。部位別再監査は未実施。 |
| Ki-30／32／36／51 | 暫定 | 役割と固定脚判断は維持。性能値は粗い総抵抗比によるため要再監査。 |
| Ki-48九九式双軽 | 暫定 | 尾翼フラッター処理と任務像は維持。速度・上昇は要再監査。 |
| Ki-21-II／Ki-49 | 暫定 | 並立という結論は維持。性能値・生産数は要再監査。 |
| Ki-67以後 | 未着手 | 1941～42年の限界認識から要求が成立するところまでのみ整理。 |

したがって、陸軍航空全体の「処理が完了した」わけではない。海軍研究へ移るための骨格は十分に整ったが、確定値への昇格前に残る監査作業は明確に存在する。

# 1. 研究方法と最重要の注意点

## 1.1 史実差を上限にしない

この世界の航空機性能を決めるとき、次の操作をしてはならない。

- 「史実より離れすぎるから」速度増加を小さくする。
- 「日本機らしくないから」防護や信頼性を落とす。
- 「万能化を避けるため」科学的に回収可能な欠陥を残す。
- 制式年や愛称を維持するため、技術的完成を意図的に待たせる。
- 後世に失敗と判明した計画を、当時の実測前に中止する。

正しい順序は次である。

1. 当時の要求、利用可能な発動機、武装、材料、工場を置く。
2. 当時知られている物理と測定可能な入力を確認する。
3. 計算機によって増える反復計算、設計空間探索、ばらつき評価、試験還流を特定する。
4. 改善を重量、出力、抗力、冷却、振動、信頼性、工数へ個別に記帳する。
5. 余裕が速度、航続、武装、防護、脚、無線、製造余裕のどこへ再配分されるかを任務から決める。
6. 得られた性能と日程を、その大小にかかわらず採用する。

結果として史実から大きく離れるなら、その因果が成立する限り受け入れる。離れない場合も「優秀な史実機は元々残存損失が小さい」「発動機・材料・工作機械が律速」などの理由を示す。

## 1.2 計算機は性能を直接生まない

計算機が直接、馬力、強度、燃料、熟練工、工作機械を生むわけではない。主効果は次の四種である。

- 従来計算の高速・大量反復。
- 多数の寸法、配置、回転数、フラップ角、冷却開度の比較。
- 重量、材料、加工、発動機出力、組立角度などのばらつき評価。
- 風洞、地上試験、飛行試験、故障、量産不良を次案へ戻す循環短縮。

航空機では、重量簿、重心、荷重、翼捩り、振動、冷却圧損、プロペラ、航続、発動機ロット、試験条件の統一に特に効く。

## 1.3 三種類の性能状態を分ける

以後、最高速度・上昇・航続は最低でも次の三状態に分ける。

| 状態 | 内容 |
|---|---|
| 試作最良状態 | 軽装、選別発動機、良好な表面、試験用整備状態。 |
| 制式標準状態 | 規定燃料、無線、酸素、防護、標準武装・弾薬を含む量産規格。 |
| 部隊中央値 | 発動機摩耗、外板・脚扉・塗装・汚れ、整備差、量産公差を含む実用状態。 |

計算機の大きな効果は、試作最良値の上積みだけでなく、制式標準と部隊中央値を試作値へ近づけ、分布幅を狭くすることである。量産均質化を最高速度増加へ二重計上してはならない。

## 1.4 改善は部位別に記帳する

「全機抗力を五％低減」と先に置かず、次を個別に評価する。

- 発動機の高度別軸出力と使用可能時間。
- プロペラ効率、ピッチ、回転数、過給機切替。
- カウリング・ナセルの入口、内部圧力、冷却出口。
- 液冷機のラジエーター入口、コア、出口、シャッター。
- 翼胴・翼ナセル干渉。
- 主脚・脚扉・車輪覆い。
- 風防、銃座、写真窓、点検扉、銃口、懸吊架。
- 表面粗さ、鋲、段差、外板波打ち、取付角。
- 排気背圧と排気推力。
- 誘導抗力、重量、重心。

相互干渉があるため単純加算せず、低位・中心・高位を置き、重複を除いた合計を使う。

## 1.5 四つの時計を混同しない

航空機の「早期化」は一つの時刻ではない。

1. **技術時計**：設計・試作・性能審査が成立する時期。
2. **要求時計**：軍がその機種・性能を必要と認識する時期。
3. **資源・工場時計**：発動機、プロペラ、工作機械、治具、材料、工員が揃う時期。
4. **部隊運用時計**：教育、整備、予備発動機、無線、補給、教程が揃い戦力化する時期。

試作飛行が数か月早くても、量産・戦力化が同じだけ早くなるとは限らない。制式名は原則として、実際の採用手続・量産体系が成立した年から自然に決める。

## 1.6 後知恵を排除する

- Ki-43初期試作機は、史実同様に九七戦より鈍いと批判され得る。
- Ki-44はKi-43の失敗代替ではなく、別の高速邀撃要求から生じる。
- Ki-60は後に不採用と分かっていても製作する。
- Ki-61は五式戦の成功を知らないため、最初から空冷化しない。
- Ki-46一型は600km/h要求未達でも、当時の実用価値から少数生産する。
- 重武装重爆の「護衛不要」思想は、実戦で破綻するまで一定の合理性を持つ。
- 40mm砲、専用急降下爆撃機、後継司偵などの枝も、当時の要求と試験価値があれば一度は検討する。

## 1.7 残る欠陥には具体的な理由を付ける

残してよい問題は、主に次のいずれかである。

- 非定常空力、剥離、実構造減衰などの係数が飛行前に確定しない。
- 発動機、燃料噴射、軸受、点火、過給機、プロペラが未成熟。
- 材料、工作機械、熱処理、鋳造、水密、互換性、熟練工が不足。
- 前線整備、燃料・冷却液品質、補給、予備部品が不足。
- 疲労、腐食、長期故障、実戦損傷のデータがない。
- 要求側が得られた余裕を別性能へ再投資した。

「物語の均衡」や「日本らしさ」は理由にしない。

# 2. 1937～43年の陸軍航空体系

## 2.1 戦闘機の三本線

1942～43年に、陸軍単発戦闘機は次の三系列へ分かれる。

| 系列 | 代表機 | 主任務 |
|---|---|---|
| 長距離軽戦 | Ki-43相当・百式戦闘機 | 長距離制空、護衛、前線飛行場、低速運動性。 |
| 高速邀撃 | Ki-44・二式単座戦闘機 | 爆撃機迎撃、上昇、加速、要地防空。 |
| 高速総合戦 | Ki-61・三式戦闘機 | 中距離制空、急降下、高速旋回、射撃安定、汎用戦闘。 |

複座系ではKi-45改が、長距離・重武装・双発・対爆撃機・地上攻撃を担う。

この分岐は最初から整然と策定された体系ではない。九七戦後継、高速邀撃、液冷高速研究、双発長距離要求が別々に発生し、試作・実戦後に役割分担が明確になる。

## 2.2 偵察機の二層

| 層 | 代表機 | 任務 |
|---|---|---|
| 司令部偵察 | Ki-15、Ki-46 | 敵深部の飛行場、鉄道、港湾、集積地を高速・長距離で撮影。 |
| 直協・軍偵 | Ki-36、Ki-51軍偵 | 前線観測、連絡、砲兵協同、近中距離戦術偵察。 |

Ki-46の主要価値は機体速度だけでなく、撮影航路、重複率、現像、写真接合、座標化、判読報告の体系化にある。

## 2.3 爆撃・攻撃機の層

| 層 | 代表機 | 任務 |
|---|---|---|
| 直協・近接攻撃 | Ki-36、Ki-51 | 低空観測、車列・砲兵・飛行場攻撃。 |
| 単発戦術爆撃 | Ki-30、Ki-32 | 300～450kg級の戦術爆撃、緩・急降下。 |
| 双発軽爆 | Ki-48 | 400～600kg級、高速反復攻撃、緩・中急降下、夜間。 |
| 標準重爆 | Ki-21-II | 長距離、750～1,000kg、成熟・量産・航続。 |
| 重防御重爆 | Ki-49 | 防漏・装甲・強防御火力、危険正面への侵入。 |

この体系には、1.5～2t級の実用爆装、高速、長航続、重防御を同時に満たす機体がない。その不足が1941～42年の戦地経験から明確になり、Ki-67要求へつながる。

# 3. 戦闘機系列

## 3.1 Ki-27九七式戦闘機

### 位置づけ

九七戦は、固定脚・大翼面積・低翼面荷重・軽い操舵を維持する。計算援用で別機へ変えるのではなく、重量、振動、外板、固定脚覆い、プロペラ、燃料管理、量産公差を整える。

### 高確度暫定値

| 項目 | 本作中心推定 |
|---|---:|
| 通常全備重量 | 1,790～1,810kg |
| 翼面積 | 18.56m² |
| 翼面荷重 | 96～98kg/m² |
| 発動機 | 710馬力級 |
| 最大速度 | **477～485km/h** |
| 武装 | 7.7mm×2を基本 |

史実機に対する主な改善は、最高速度だけではない。

- 安全な高速・急降下域の拡大。
- 尾翼・翼・操縦系の振動低減。
- 航続4～7％程度の改善。
- 量産機間の速度・操舵・振動差縮小。

この改善された九七戦がKi-43の比較対象になるため、Ki-43初期試作への評価は史実以上に厳しくなり得る。

## 3.2 Ki-38からKi-45改まで

### 開発線

- **Ki-38**：双発複座・長距離戦闘機の要求整理と予備設計。
- **原Ki-45**：最初の実機化。速度不足、脚、発動機、ナセル、重量・操縦の問題を露呈。
- **Ki-45改**：発動機換装だけでなく、胴体、主翼、ナセル、脚、武装、装備を全面再設計した機体。

原Ki-45の失敗を消してはならない。約820馬力二基で480km/h級の原型を540km/hへ上げるには、同じ抗力なら総出力を約42％増やす必要があり、磨き込みでは解決不能である。1,000馬力二基と改良ナセルで520km/h級へ達した後、ハ102と全体再設計によって540km/h台が成立する。

### Ki-45改・高確度暫定値

| 項目 | 中心推定 |
|---|---:|
| 乗員 | 2名 |
| 全幅 | 15.02m級 |
| 翼面積 | 32.0m² |
| 空虚重量 | 3,900～4,000kg |
| 通常全備重量 | 5,450～5,600kg |
| 発動機 | ハ102、1,080馬力×2 |
| 最大速度 | **548～555km/h、中心552km/h** |
| 5,000m上昇 | **6分40秒～6分55秒** |
| 実用上昇限度 | 10.3～10.6km |
| 内部燃料最大航続 | 1,650～1,850km |
| 内部燃料戦闘半径 | 450～520km |
| 増槽込み戦闘半径 | 650～720km |
| 初期武装 | 12.7mm×2、20mm×1、後方銃×1 |
| 通常爆装 | 100kg×2または250kg×1 |

### 片発性能

双発であっても、満載・高温・高地・離陸直後の片発は危険である。燃料消費後の低～中高度で、故障側プロペラを停止または低抵抗状態にできれば、最寄り飛行場へ帰還できる範囲が生じる。風車状態では速度・高度維持が大きく悪化する。

### 実装中心線

- 原型初飛行：1938年末～1939年初。
- 原構成の限界確定：1939年夏。
- 全面再設計：1939年秋以降。
- Ki-45改初飛行：1941年初頭。
- 1941年末：試用10～20機程度。
- 制式・量産：1942年初～春。
- 最初の実戦部隊：1942年春～夏。

### 注意

37mm砲、斜銃、後方銃撤去、夜間戦闘機化は、後の敵重爆・夜間侵入を受けて発生する。初期標準へ先取りしない。型別武装名称は一次資料で再確認が必要である。

## 3.3 Ki-43相当・百式戦闘機

### 要求と試作評価

九七戦並みの運動性、約500km/h、高上昇、長航続を同時に求める。初期試作機は、速度・航続を得ても、横転慣性、操舵力、旋回開始、九七戦との差の小ささから批判される。

計算機の効果は「初号機を完成形にする」ことではない。運動性という曖昧な評価を、旋回半径、旋回時間、速度損失、操舵力、横転率、失速位置、燃料重心へ分解し、尾翼、補助翼、操縦索、翼端、空戦フラップの比較を早める。

蝶型空戦フラップは設計者の発想であり、計算機が発明するわけではない。計算機は角度、速度、荷重倍数、旋回半径、抗力、構造荷重を調定する。

### 高確度暫定・1941年標準型

| 項目 | 百式戦一型丙相当 |
|---|---:|
| 制式 | **1940年後半** |
| 乗員 | 1名 |
| 全幅 | 約11.44m |
| 翼面積 | 約22.0m² |
| 空虚重量 | 1,640～1,675kg |
| 通常全備重量 | 2,085～2,135kg |
| 発動機 | ハ25、約980馬力 |
| 最大速度 | **500～504km/h、中心502km/h** |
| 5,000m上昇 | **5分25秒～5分40秒** |
| 内部燃料航続 | 1,250～1,350km |
| 増槽込み最大航続 | 1,800～1,950km |
| 内部戦闘半径 | 350～430km |
| 増槽込み護衛半径 | 600～700km |
| 武装 | 12.7mmホ103×2 |
| 防護 | 小型背面防弾板、遮断・防火。完全防漏なし。 |

初期の武装系列は、7.7mm二挺、7.7＋12.7mm、12.7mm二挺と段階化する。1941年中盤から12.7mm二挺型が主生産になる。

### 実装中心線

- 第一試作：1938年末～1939年1月。
- 運動性問題の分解：1939年春～夏。
- 空戦フラップ試験：1939年後半。
- 増加試作構成凍結：1940年初頭。
- 制式：1940年8～11月。
- 部隊転換：1940年末～1941年。
- 1941年12月の実戦使用可能：280～380機程度。

1939年制式は早すぎる。試作製造、飛行試験、フラップ機構、ホ103、量産治具、部隊審査は省略できない。

### 注意

上記性能は新方式の部位別監査をまだ行っていない。制式時期、武装段階、役割は維持し、数値は正本化前に三状態へ分けて再計算する。

## 3.4 Ki-44二式単座戦闘機

### 開発思想

Ki-44はKi-43の失敗代替ではなく、将来の高速爆撃機を捕捉するための速度・上昇重視機である。九七戦・百式戦並みの持続旋回を主評価にしないが、搭乗員が低速性・着陸性を批判することは残る。

大型空冷発動機を小型機へ搭載するため、カウリング、冷却、プロペラトルク、短胴、着陸速度、高翼面荷重、尾翼・補助翼振動が主要問題になる。

### 監査済み性能

## 3.5 Ki-28、Ki-60、Ki-61

### Ki-28研究線

Ki-28は九七戦選定で不採用となっても、液冷、高速、引込脚、ラジエーター、高翼面荷重、高速操舵の研究系列として残る。これがKi-60／Ki-61へ技術と試験方法を渡す。

ただしKi-28の経験は、後世の「液冷は失敗する」「Ki-60は不要」を教えない。

### Ki-60

重武装・高速・高翼面荷重の液冷迎撃案。Ki-44より速度・上昇・整備で劣り、Ki-61より航続・汎用性で劣るため不採用となる。

暫定中心値：

| 項目 | 暫定値 |
|---|---:|
| 通常全備重量 | 2,750～2,820kg |
| 最大速度 | 568～576km/h |
| 5,000m上昇 | 5分45秒～6分05秒 |
| 武装 | 20mm×2＋12.7mm×2 |

不採用という結論は維持するが、性能は新方式で再監査する。三機で直ちに終了せず、追加審査を含め五～七機級の可能性がある。

### ハ40の扱い

計算できるもの：公差累積、軸受荷重、ねじり振動、冷却圧損、噴射量、気筒温度、故障ロット相関、加工機・作業班別不良率。

計算だけでは増えないもの：精密研削盤、軸受合金、噴射ノズル加工、水密鋳造、熱処理炉、熟練工、前線の清浄な燃料・冷却液。

# 6. Ki-48九九式双発軽爆撃機

本章は開発・運用の理路を維持するが、性能値は新方式で再監査する。

## 6.1 開発と尾翼フラッター

Ki-48はKi-30／32の双発化ではなく、ソ連SB級高速爆撃機を意識した九三式双軽後継である。主な要求は480km/h、400kg以上、長航続、寒冷地運用。

試作時の大問題は水平尾翼・後部胴体フラッター。地上加振、舵面質量釣合い、胴体曲げ捩り、操縦索弾性、プロペラ・発動機周波数を事前に比較し、初飛行に速度制限を設定できる。実機の非定常後流と減衰は飛行試験が必要だが、二～三機の並行比較で量産構成を早く確定できる。

## 6.4 任務転換

1940～42年前半には高速前線軽爆として有効。1942年以降、速度だけでは戦闘機を振り切れず、夜間、近距離反復、橋梁・飛行場・車列への緩降下、雲を利用した小編隊攻撃へ比重が移る。

爆装の小ささは残る。一回で大飛行場を破壊する機体ではなく、補修班、燃料、駐機機、橋、車列など小さく重要な目標を反復して叩く機体である。

1940年末～1941年初に初期量産、1941年春～夏に部隊転換する中心線。

## 7.3 百式重爆二型

ハ109約1,500馬力二基へ換装し、上昇・速度を改善する。

| 項目 | Ki-49-II |
|---|---:|

## 7.4 並立理由

| 項目 | Ki-21-II | Ki-49-II |
|---|---|---|
| 速度 | やや低い | 約15～20km/h高い暫定 |
| 上昇 | 同級 | 同級～わずかに優位 |
| 航続 | 長い・成熟 | 最大値は同級、爆装時は必ずしも優位でない |
| 爆装 | 1,000kg | 1,000kg |
| 防護・火力 | 中 | 強 |
| 生産・整備 | 既存治具、部隊、予備品 | 高価・複雑、ハ109をKi-44と競合 |

Ki-49の防御火力は護衛を不要にしない。敵戦闘機の攻撃時間、追尾、二撃目の危険を増やし、損傷帰還率を上げる装備である。

Ki-21は長距離・量産・信頼性、Ki-49は防護・火力・危険正面として並立する。

## 7.5 片発性能

双発だから安全ではない。標準全備、爆装、燃料、高温、高地、故障側プロペラ状態で大きく変わる。

- Ki-21-IIは軽い分、高度維持で有利になりやすい。
- Ki-49はフラップ、方向安定、防火、損傷局限、不時着で有利になり得る。
- 両機とも最良片発速度、爆弾投棄、プロペラ操作、燃料移送、方向舵トリム、帰還可能距離の表が必要。

# 8. 発動機・生産・補給上の横断論点

## 8.1 瑞星／ハ26／ハ102系列

本世界では海軍零戦が三菱瑞星系列を採用するため、この発動機系列の試験・量産・冷却・排気・二速過給・三翅プロペラ研究が史実以上に厚い。

波及先：

- 九七式司偵二型。
- 百式司偵二型。
- Ki-45改。
- Ki-51。
- 海軍戦闘機系列。

ただし同一系列を複数機種が使うため、試験知識は共有できても、生産数は競合する。

## 8.2 ハ25／ハ115系列

海軍が栄を主力零戦に大量使用しないため、中島側に多少の余力が生じる。効果は、Ki-43、Ki-48、発動機予備、ロット均質化、ハ115試験へ出る。

ただし余力はKi-43、Ki-44、Ki-48、Ki-49、発動機開発へ分散し、一機種だけを一年単位で早めるものではない。

## 8.3 ハ41／ハ109系列

Ki-44とKi-49が競合する。ハ109型Ki-44を増やせば、Ki-49-IIや予備発動機が減る。額面性能だけでなく、防空優先、重爆戦力、工場能力を同じ資源表で扱う必要がある。

## 8.4 ハ40系列

設計性能より、合格数、早期故障、交換部品、整備員、専用工具、冷却液、前線環境が律速。計算機は不良原因とロット相関を早く突き止めるが、精密工作機械や材料は直接増やさない。

## 8.5 生産数の注意

これまで示した1941年末・1942年末の機数は、史実年産、量産開始前倒し、手直し率低下からの作業推定である。正本化には、次を機種横断で統合する必要がある。

- 工場別月産能力と拡張時期。
- 発動機月産、予備率、試験不合格率。
- 同一メーカー内の機種競合。
- アルミ、特殊鋼、機銃、無線、プロペラ、脚の供給。
- 教育・事故・修理・輸送中・内地待機を差し引いた実戦即応率。

各機体の個別検討で得た完成数を単純加算してはならない。

# 9. 設定上の修正・撤回・上書き

## 9.1 撤回する旧案

### Ki-43の1939年制式

早すぎる。初飛行、運動性批判、空戦フラップ、増加試作、部隊審査、量産治具、ホ103を考えると、中心は1940年後半。

### Ki-61の早期空冷化

撤回する。1940～41年には、DB601系の性能、燃料噴射、細い機首、川崎の液冷経験、明石工場への投資が魅力であり、後のハ40量産不良・五式戦成功を知らない。空冷換装は実測問題が揃う1943年後半以降。

### 史実差を「とどめる」処理

撤回する。「優秀な史実機だから改善を小さくする」「離れすぎるから上限を置く」は禁止。残存損失と再配分を計算する。

## 9.2 上書きする性能値

### 百式司偵

以前の二型609～615km/hは部隊中央値として残るが、制式標準は初期613～619km/h、後期623～629km/hへ上書き。三型後期は制式標準650～658km/h。

### Ki-44

以前の二型612～619km/hを、初期制式標準612～617km/h、後期排気型621～628km/hへ分離。上昇は初期4分16～20秒、後期4分05～13秒。

### Ki-61

最大速度598～604km/hは四門標準型として概ね維持し、598～605km/hへ整理。以前の5,000m上昇5分10～25秒は軽武装良好機に限定し、四門標準は5分27～42秒へ修正。

# 12. 海軍研究へ持ち込むべき教訓

海軍航空へ移る際、陸軍側で得た次の教訓を常時適用する。

1. **要求を後世の正解へ書き換えない。** 艦上機特有の着艦、格納、航続、艦隊防空、雷撃・急降下の要求を当時の情報から発生させる。
2. **試作失敗を消さない。** 計算で予測可能な危険を減らしても、プロペラ後流、着艦乱流、フラッター、冷却、兵装分離は実機試験を要する。
3. **空力改善を速度へ自動変換しない。** 艦上機では脚、翼折畳、着艦装置、防食、浮力、無線、航法、防護、搭載兵器へ余裕が再配分される。
4. **艦載・陸上・水上機を同じ基準で評価しない。** 発艦・着艦、甲板長、格納庫、カタパルト、海面運用が性能価値を変える。
5. **発動機系列の共通試験と生産競合を同時に扱う。** 瑞星を零戦、司偵、複戦などで共有する利得と供給競合を二重計上しない。
6. **試作最良・制式標準・部隊中央値を分ける。** 艦上運用では塩害、甲板損傷、整備環境による部隊中央値低下が特に重要。
7. **機体単独で戦果を決めない。** 偵察、無線、航空管制、整備、搭乗員教育、母艦の発着艦回転、弾薬・魚雷・爆弾のI/O連鎖を含める。

# 13. 最終要約

陸軍航空の骨格は、九七戦から百式戦・二式単戦・三式戦へ分岐し、Ki-45改が双発重戦闘を担う形で成立する。偵察はKi-15からKi-46へ移り、機体速度と写真情報処理が一体化する。近接・戦術爆撃はKi-36、Ki-51、Ki-30／32、Ki-48へ階層化し、重爆は成熟したKi-21-IIと重防御のKi-49が並立する。

計算機の最大の波及は、すべての機体を異常な高速機へ変えることではない。欠陥の原因を分解し、設計案を比較し、試験値を戻し、量産ばらつきを狭め、得られた余裕を任務上価値の高い場所へ再配分することにある。

一方、史実差を暗黙の上限にしてはならない。百式司偵のように速度が任務の中心で、史実にも排気・ナセル・冷却の回収余地が残る機体は、量産標準で650km/h要求を達成し得る。二式単戦も推力排気型で620km/h台へ入る。反対に、三式戦は元の空力が優秀で、改善の多くが部隊性能再現性へ現れる。Ki-49のように防護・銃座・乗員へ重量を使う機体では、空力合理化が最高速度だけに現れない。

この差を、物語上の遠慮ではなく、要求、重量、出力、抵抗、工業、運用の勘定から出すことが、今後の海軍航空研究でも最重要となる。
