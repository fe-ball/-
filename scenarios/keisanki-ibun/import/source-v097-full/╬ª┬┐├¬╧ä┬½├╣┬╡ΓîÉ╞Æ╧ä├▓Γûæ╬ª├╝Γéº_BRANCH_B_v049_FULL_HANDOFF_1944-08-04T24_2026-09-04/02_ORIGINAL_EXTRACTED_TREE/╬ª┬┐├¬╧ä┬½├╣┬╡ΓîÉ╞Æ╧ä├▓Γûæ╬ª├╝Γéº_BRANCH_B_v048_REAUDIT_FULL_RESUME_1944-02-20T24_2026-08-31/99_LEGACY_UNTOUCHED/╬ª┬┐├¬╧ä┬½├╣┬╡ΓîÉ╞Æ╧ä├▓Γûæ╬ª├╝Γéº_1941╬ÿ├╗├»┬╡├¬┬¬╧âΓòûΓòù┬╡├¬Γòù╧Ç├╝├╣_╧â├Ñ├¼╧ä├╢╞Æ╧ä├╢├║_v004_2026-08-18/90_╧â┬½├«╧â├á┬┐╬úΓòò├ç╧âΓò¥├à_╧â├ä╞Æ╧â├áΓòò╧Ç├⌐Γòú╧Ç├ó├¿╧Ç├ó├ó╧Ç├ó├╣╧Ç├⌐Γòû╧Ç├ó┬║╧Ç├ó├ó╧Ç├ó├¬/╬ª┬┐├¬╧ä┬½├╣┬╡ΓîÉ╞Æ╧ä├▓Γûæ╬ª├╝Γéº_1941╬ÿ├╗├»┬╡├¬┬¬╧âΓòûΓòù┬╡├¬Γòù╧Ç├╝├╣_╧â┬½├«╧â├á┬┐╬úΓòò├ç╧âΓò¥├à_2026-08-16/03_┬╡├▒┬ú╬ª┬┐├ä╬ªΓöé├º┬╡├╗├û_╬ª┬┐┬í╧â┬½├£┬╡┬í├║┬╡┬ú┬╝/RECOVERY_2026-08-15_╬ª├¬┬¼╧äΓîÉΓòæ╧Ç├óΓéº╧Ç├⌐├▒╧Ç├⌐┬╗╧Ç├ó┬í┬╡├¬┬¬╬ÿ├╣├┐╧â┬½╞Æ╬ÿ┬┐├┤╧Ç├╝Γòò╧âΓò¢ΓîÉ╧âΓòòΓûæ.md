# 1. 現在の判断

戦史時計を1944年7月7日へ戻して再開する、という扱いはしない。

7月7日は適切な基準点ではない。問題は1944年の帝国海軍へ改善機体・改善艦艇を追加した相似拡大型モデルを戦わせていたことであり、それ以前から蓄積しているはずの、

- 電子系
- 航空ソフト
- 航空ハード
- 水上艦
- 潜水艦

の相互作用と、それに由来する戦術・訓練・設計要求の変化を十分に反映していなかったことにある。

# 2. 125以後の戦史枝の扱い

会話中に後から生成された戦史シミュレーション群（FORAGER以後を1945年まで進めた枝）は、現時点では正史入力にしない。

位置付けは、

**統合モデルの失敗テスト／感度実験枝**

とする。

そこから戦果や日程を正本値として引用しない。

役割は、

- どの交差項を落としたか
- どこで史実へ吸着したか
- どの入力を史実固定のまま使ってしまったか

を発見するためのバグ報告とする。

# 3. 直近の作業方針

次は戦争を進めない。

台帳上の航空機を独立した「航空戦実験場」へ出し、米軍機と大量の局所戦闘を行わせる。

目的は、史実交換比を先に置かず、改変後の機体・技能・通信条件から、

- 交換比
- 生存率
- 任務成功率
- 離脱成功率
- 損傷帰還率
- 編隊分裂率
- 射撃位置獲得率
- 弾薬・燃料消費

を測定すること。

# 5. 実験シナリオ

最低限、以下を別々のデータとして持つ。

1. 1対1・同高度同速度・相互発見。
2. 1対1・高度差500/1000/2000m。
3. 一方のみ先に発見する奇襲条件。
4. 2対2。
5. 4対4。
6. 8対8。
7. 12対12。
8. 4対8、8対12等の局所数的不利。
9. fighter sweep。
10. escort vs CAP。
11. bomber interception。
12. disengagement / mission abort / withdrawal。

# 6. 技量差の初期丸め

第一段階では、歴史的な1944年日米交換比を技能係数へ埋め込まない。

標準条件は概ね、

- 操縦／energy management：ほぼ同等
- 射撃：ほぼ同等
- 視認：ほぼ同等
- 個機無線：米軍やや優位
- 編隊内情報共有：米軍やや優位
- 大編隊管制：米軍優位
- 孤立戦：通信差の影響は小さい

とする。

重要なのは「日本0.8、米国1.0」のような一係数へ潰さないこと。

# 7. 戦闘実験の出力

各試行から最低でも以下を記録する。

- kill / loss
- damaged-return
- disengage-success
- first-firing-position acquisition
- firing opportunities
- average engagement time
- fuel expenditure
- ammunition expenditure
- formation split
- mutual-support success
- mission continuation

交換比だけで評価しない。

# 8. sortie再生成との接続

単発戦闘の後で、

- 帰還機
- 損傷機
- repair turnaround
- pilot return
- rearm/refuel

を通し、次sortieへ戻れる割合を別層で測る。

戦史より前に、

**空戦 → 帰還 → 整備 → 次sortie**

の局所サイクルを成立させる。

# 9. フィードバック

この実験結果は最終戦史へ直結させず、まず航空ソフトへ戻す。

例：

機体性能
→ 模擬戦／実戦統計
→ 戦術改訂
→ 訓練改訂
→ 次期機要求
→ 新しい機体性能

という循環を作る。

これにより「1944年の史実的組織へ良い飛行機だけ渡す」モデルから離れる。

# 10. 五系統統合について

最終的には、

- 電子系
- 航空ソフト
- 航空ハード
- 水上艦
- 潜水艦

を同じ状態ベクトルへ戻す必要がある。

ただし直近の作業では、航空局所戦闘の交換関係を先に測る。

そこで得た値を、後で電子・艦隊・潜水艦との交差項へ接続する。

# 11. 史実の使い方

史実は、

- 機体性能
- 発動機
- 武装
- レーダー
- 無線
- 搭乗員訓練
- 整備時間
- 被弾耐性

等の物理・制度校正には使う。

しかし、

「史実でこの海戦がこの交換比だったから、この世界でも近いはず」

という結果アンカーには使わない。
