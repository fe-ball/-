# 後続スイッチ由来・解除監査 v0.06

## 0. 今回の追加洗浄

後続正本の固定文を、`開戦時に既にある能力`、`物理技術時計`、`実戦から生じる制度・政策`、`旧枝の戦史結果`へ再分離した。

### 保持する開戦時能力

- `COMSEC-CENTRAL-STATISTICAL-AUDIT = OPERATIONAL_PARTIAL`：Type 2中央暗号計算・カード統計・鍵使用監査という能力そのもの。
- `ASW-ESCORT-STAFF = PRESENT_LIMITED`：鎮守府・艦隊の護衛担当幕僚という初期能力。全国統合司令部とは別。
- `LOG-WARTIME-STANDARD-SHIP-I = DESIGN_FROZEN_PRODUCTION_TRANSITION`：1940年から準備、1941年中盤～後半に型式確定済みの生産パイプライン。

### 保持するが数量・戦果を再計算する技術時計

- 艦隊電探の1941末～42初実用試験。
- 二式爆雷の1942採用時計。
- 東海の1942夏～秋初飛行時計。
- 推力式単排気管の1942 H1比較～H2標準化候補。
- 第一次戦時標準船の1942春～夏完成立上り。

これらは「研究・試験の物理時計」を保持し、何個・何隻へ配るかは再走査の需要と資源で決める。

## 1. 新たに解除した強い固定結果

### 1.1 1942年高等暗号の「ほぼ解読不能」

70は、1942年の日本高等暗号について、米側が短期戦略に意味のある時間・精度・語数でほぼ利用不能と固定していた。

今回これは**戦史出力へ降格**する。

保持するもの：

- 暗号設計時の統計検査。
- 鍵重複・使用量・更新遅延の監査。
- Type 2中央計算能力。

再計算するもの：

- 前線での鍵配布遅延。
- 同文・定型文・運用ミス。
- 鹵獲資料。
- 通信量増大。
- トラヒック解析・無線方位。
- 米側暗号解析の実機会。
- 情報が作戦決定へ間に合うか。

したがってMO/MIの情報条件は、暗号が強いという設計利得を持ちながらも、作戦ごとに再決定する。

### 1.2 遣独潜水艦の技術貨物到達

70には「到達結果は20で固定」とある一方、20の現行潜水艦正本は「各航海の個艦成否は歴史考察で処理」と明記する。

今回、より任務固有の20を優先して、

`SUB-GERMANY-LIAISON-VOYAGE-OUTCOME = OPEN`

とする。船体・トリム・機関・通信規律の改善は保持するが、2～3往復／4～5片道等の後続作業値は再走査時の出力。

### 1.3 第二次戦時標準船

第一次型の設計・工程準備は開戦時に既に進んでいるので保持。

第二次型の具体形は、第一次型の実運航、船腹損失、修理、鋼材、主機、造船所負荷を見て決めるべきなので、

`LOG-WARTIME-STANDARD-SHIP-II = OPEN`

へ戻す。

## 2. 対潜で追加分離したもの

後続41の「1941末～42春の護衛担当幕僚強化」は、局地護衛指揮所や海上護衛総司令部と同一ではない。

したがって、

- 開戦時：`ASW-ESCORT-STAFF = PRESENT_LIMITED`
- 局地護衛指揮：`ASW-LOCAL-COMMAND = LATENT`
- 全国統合：`ASW-NATIONAL-COMMAND = LATENT`

へ三分する。

専用海防艦・簡易護衛艦の量産優先は、米潜接触・船腹損失・艦隊型DD拘束を観測してから再決定するため、`ASW-DEDICATED-ESCORT-PRIORITY = OPEN` とする。

## 3. 今回のルール

後続文書に「固定する」「以後は～とする」とあっても、次の質問を必ず通す。

1. 1941年12月までに既に物理的に存在するか。
2. 戦前の試験・設計日程からほぼ独立に進む技術時計か。
3. 戦争中の損耗・需要・余力・敵適応に依存する政策か。
4. 旧戦史枝の結果を前提にした出力か。

3は日付を解除、4は全面再計算。1と2だけを開戦状態へ保持する。


## 4. v0.07追加――航空監査47の「MIから再走査」を解除

47はFORAGER再計算用の局所監査として、

- ソフト・ヒューマン差はMI後に自生する
- 戦史再走査は1942年6月MI直後を第一候補

と置いていた。

今回これは撤回する。

### 残すもの

47のHARD監査フォーマット：

`史実発生 → 史実採用 → 本世界トリガー → 計算援用 → 非短縮部分 → retrofit → 初搭載 → 部隊中央値 → 配備時計 → 戦術接続`

技術を後知恵で前倒ししない規約として有効。

### 解除するもの

`ソフト/ヒューマン状態差 = MI後から` という開始点。

実際には、

- 1941-11の戦域集中事故
- 12月の迷航・強制着陸・整備負荷
- 開戦直後の戦闘/非戦闘損失
- 熟練者のKIA/MIA/負傷/生残
- 補充機・補充員への置換
- 基地転進時の地上支援摩擦

から差が累積する。

したがって、

`A-SOFT-HUMAN-STATE-DIVERGENCE = ON from concentration/opening`

とする。

一方、

- 練度平準化
- 意図的熟練核配分
- 海軍空地分離
- 専任空輸

などの**制度化**は引き続きLATENTで、観測・需要・余力ゲートを通る。

### 再走査開始

全体は61の元の順序へ戻し、戦域ごとに開戦前集中を必要なら前置する。

航空については、Malayaは1941-11-15集中から、Pearlは出撃準備/航海中の状態を必要な範囲で前置し、1941-12-07/08を全戦域同期点とする。

## 5. v0.07追加――後年の航空機数を固定しない

47は技術時計と配備量を分ける考え方自体は正しい。今回これを開戦から徹底する。

保持：

- 発動機・機体・武装・装備の研究/試験/耐久に必要な物理時間。

再計算：

- 量産開始の優先度
- 月産
- 発動機配分
- 予備機
- 修理滞留
- 戦域配備
- 機種転換教育

したがって後続50～53/47にある1943～44年の機数帯は、その時点へ到達したときの比較参照であり、今回の再走査へ固定出力として持ち込まない。
