# 1. 監査理由

従来正本は、戦術研鑽を索敵、CAP、甲板サイクル、艦隊回避、射撃I/Oとして扱っていた。しかし、航空部隊を基地・艦の固定組織へ強く結び付けたままでは、戦術研究の成果を戦域間で素早く移動・再編できない。また火器管制の研究を自軍の命中・防御改善だけに使い、**敵の防空システムをどの条件で一時的に破綻させられるか**という対抗研究へ十分接続していなかった。

本世界ではMI後から1944年夏まで、史実より多い空母、航空隊、指揮官、整備要員が残り、Guadalcanal/Rabaul型の逐次摩耗が小さい。したがって、約2年間の反復演習・実戦データから、航空隊の機動運用制度と攻防対抗戦術を成熟させる。

計算機は後世の正解を与えない。飛行記録、被弾方位、迎撃高度、対空砲火開始時刻、攻撃隊到着時刻、損傷艦の操艦、基地移動に要した人員・貨物量等を比較し、当時の軍人が観測できる差を統計化する。

# 2. 史実基準

## 2.1 空地分離

史実日本海軍は1944年7月10日、航空兵力の集散離合を容易にするため全面的な空地分離を実施した。飛行隊を持つ作戦側航空隊と、基地警備・施設・見張・設営等を担う基地側航空隊を分け、飛行隊が必要な基地へ機動しやすい制度へ改めた。

したがって空地分離は本世界だけの架空アイデアではない。史実では制度化がMarianas決戦直前まで遅れたと読む。本世界では、MI後から航空再建・戦域機動を継続研究できるため、実用化を前倒しする。

## 2.2 防空飽和の contemporaneous plausibility

米海軍の戦時対空戦訓は、複数方向からの協同攻撃が対空火器管制を複雑化し、同時攻撃が防空を飽和させることを明確に認識している。史実日本軍も戦争後期には、驚異方向の分散、低空接近、複数機同時進入等で防空系を複雑化させた。

これは1945年型自爆攻撃を1943年へ遡及する根拠ではない。**複数目標・複数方位・時間圧縮によって、有限のCAP・射撃指揮チャンネル・砲の射界・艦隊操艦を競合させるという問題自体が、当時の技術で観測可能だった**ことの証拠として使う。

# 3. 空地分離の本世界時間線

## 3.1 1942年6～9月：問題認識・局地試行

MI戦訓を回収する段階で、次を別問題として記録する。

- 飛行隊を移すたびに基地警備、給食、医療、通信、施設管理まで動かす非効率。
- 艦・基地を失うと、飛行要員と地上要員の再編が同時に詰まる問題。
- 新基地へ航空機だけ先着しても、整備・弾薬・燃料・部品が一致せず即応しない問題。
- 逆に、成熟基地へ過大な固有地上組織を重複配置する無駄。

この時期は全面制度化せず、主要基地間で「飛行隊＋直接整備分遣隊＋最小予備品」を移し、基地側が燃料、弾薬、警備、医療、給養、重整備設備を受け持つ試行を行う。

## 3.2 1942年末～1943年前半：主要戦域で実用化

South Pacific、Midway、Marshall、Truk等の成熟基地を対象に、受入側の標準装備表、工具、補給品、通信手順を統一する。

移動する航空部隊は原則として：

- 搭乗員。
- 飛行隊幹部。
- 直接整備員。
- 機種固有工具・予備部品。
- 機体固有の無線・照準・兵装整備要員。

を持ち、基地側は：

- 警備、防空、見張。
- 給食、医療、宿営。
- 燃料・弾薬の基地在庫と荷役。
- 発電、通信幹線、飛行場保守。
- 共通工作機械、重整備。

を提供する。

## 3.3 1943年後半：主要作戦航空隊の標準方式

主要戦域では実質的な空地分離を標準とする。史実1944年7月の制度用語や編制をそのまま未来知識としてコピーする必要はないが、機能としては同等方向へ到達する。

基地を失っても飛行隊が別基地へ移れば部隊として存続しやすく、逆に基地側は新飛行隊を受け入れられる。航空兵力の「基地ごとの固定保有」から「方面内で可搬な飛行戦力」への移行が進む。

## 3.4 1944年初頭：全海軍の制度整理

1944年初頭までに、主要作戦航空隊について人事、補給、指揮権、整備責任の制度を正式化する。固定訓練隊、内地防空等は例外を残す。

史実の1944年7月10日全面改編は、本世界では既に主要戦域で運用済みの方式を全海軍へ整理する段階に近い。

# 4. 母艦航空隊の可搬化

空地分離と、空母航空隊を艦体へ一対一固定しないことは関連するが同一ではない。

本世界では生残空母が多いため、1943年以後は航空戦隊単位で次を訓練する。

- 損傷空母から他空母への航空隊収容。
- 艦載機・搭乗員・直接整備員の母艦間再配分。
- 新造・修理明け空母へ、既成航空隊の一部を核として移す。
- 一空母の航空隊を完全均質化せず、熟練中核＋新規要員で組み直す。
- 母艦別の甲板長、着艦標識、燃料・兵装位置差を事前カード化する。

ただし「航空隊を今日移して明日完全戦力」とはしない。母艦固有の着艦、甲板作業、通信、整備配置へ馴染む再資格期間を必要とする。緊急時は数日で限定CAP・収容、通常の統合攻撃には1～2週間級の慣熟を中心とする。

# 4.1 空地分離が生む人員撹拌と平準化

空地分離は航空機の基地間移動だけを容易にする制度ではない。飛行隊幹部、搭乗員、直接整備員を基地固有組織から切り離すため、戦傷・母艦修理・再編・新編航空隊・補充機受領で自然に後方へ戻った経験者を、元部隊へ機械的に戻さず別部隊へ再配置しやすくする。

本世界では、まず自然還流が発生し、その後に部隊間練度差が可視化され、1943年以後は「第一線の熟練核を残しながら、経験者ゼロの新編隊を減らす」平準化へ進む。詳細は `46_航空人事_1942-44_自然還流・空地分離・練度平準化.md` を正本とする。

これは全隊を均質化する政策ではない。艦上資格、夜間資格、航法、編隊指揮、無線、整備等を別資格として管理し、任務に必要な経験核を配る。結果として、45の分散セル型攻撃を複数航空隊混成で実施した際の「一隊だけが航法・通信・集合で脱落する」下側リスクを削る。

# 5. 攻防を一体化した火器管制研究

## 5.1 防空を一個の鎖として扱う

敵艦隊防空を次の連鎖へ分解する。

**早期探知 → 戦闘機指揮 → CAP会敵 → 外周護衛艦対空火力 → 個艦高角射撃指揮 → 近距離火器 → 回避操艦 → 損害制御**

攻撃側の目的は全段階を物理破壊することではない。**主攻撃隊が終末攻撃へ入る数分間だけ、一つ以上の段階を局地的に過負荷・誤配分・時間切れへ追い込む**ことを目標にする。

## 5.2 戦術研究で観測する量

- 敵レーダー探知からCAP会敵までの時間。
- CAPの高度、方位、交代時刻、燃料限界。
- 攻撃方位別の高角砲・機銃の密度。
- 各護衛艦が射撃を開始・中止する距離。
- 複数目標出現時の射撃指揮切替時間。
- 艦隊が雷撃回避へ変針した際に生じる射界・隊形・対空火力の穴。
- 空母が発艦・収容のため風上へ向く時間帯。
- 第一波後にCAP、弾薬、射撃指揮が再整定するまでの時間。

正確な米VT信管性能やCIC内部構造を知らなくても、帰還搭乗員の報告、写真偵察、戦闘記録から「どの条件で損失が跳ねるか」は経験的に推定できる。

# 6. 敵防空を破綻させる攻撃手順

## 6.1 時間圧縮

艦爆、艦攻、護衛戦闘機、基地航空をばらばらに到着させず、主攻撃を短い時間窓へ圧縮する。44の「到着時刻分散20～30%縮小」は、この目的を含む。45では別倍率を加算しない。

## 6.2 方位・高度の競合

同一目標へ一方向から密集するのではなく、敵艦に相反する操艦を要求する。

- 雷撃機が一方から艦首・艦尾方向の回避を強制。
- 艦爆が別方位から急降下。
- 一部戦闘機・小編隊が高高度または外周でCAPを拘束。

目的は「四方八方から無秩序に突入」ではなく、**同じ数分間に、敵のCAP配分・射撃指揮・艦隊変針が互いに競合する幾何を作る**こと。

## 6.3 目標切替の強制

複数小群を同時に見せ、外周護衛艦や高角射撃指揮装置に目標切替を強いる。主攻撃隊はその切替直後、または射撃指揮が別目標を追っている方向へ入れる。

これは米防空の火力そのものを消さない。有限の指揮装置・射界・砲旋回・人間判断へ時間コストを与える。

## 6.4 CAPを先に使わせる

偵察、戦闘機掃討、小規模牽制を本攻撃と区別し、敵CAPを遠方へ引き出す、あるいは交代・給油へ入る時刻を推定する。

無意味な囮自殺はしない。牽制群にも偵察、戦闘機撃墜、位置更新等の独立価値を要求する。

## 6.5 第一波と第二波の役割分離

全戦力を第一波へ投入しない。第一波の目的を、損害付与だけでなく：

- CAPの高度・方向を確定。
- 対空射撃密度の高い方位を確認。
- 艦隊を変針させformationを乱す。
- 空母の発着艦サイクルを中断。

とし、第二波が得た情報を使う条件を作る。

ただし敵が再整定する前に第二波を到着させる必要があり、遠距離攻撃では航法・燃料・発進サイクルが律速となる。

# 7. 自軍艦隊防空への反映

同じ研究は防御側にも使う。

- 艦ごとの対空射界と死角をformation設計へ反映。
- 同一目標への過剰集中を避け、方位・高度別の担当を事前指定。
- 雷撃機、艦爆、水平爆撃等の優先順位を状況別に切替。
- 空母の全艦同時変針、局地独立回避、緊急散開を攻撃型ごとに使い分ける。
- CAPの友軍帰投経路と高角射撃区域の競合を減らす。
- 指揮装置損傷時に隣接艦・予備方位盤へ引き継ぐ。
- 大型艦を単なる砲門数ではなく、対空火力・通信・位置保持を含むformation nodeとして評価する。

ただし日本側には米軍と同等のレーダーfighter direction、VT信管、5in/38大量配備、40mm Bofors級火器体系がない。したがって教範改善だけで米艦隊防空へ追いつかない。

# 8. 作業用効果量

以下は独立倍率ではなく、該当場面の初期分布を変える作業値。

| 項目 | 1943後半～44の中心感度 |
|---|---:|
| 準備済み基地間で飛行隊を移す際の随伴人員・機材輸送量 | 30～45%削減 |
| 新基地到着後24～48時間の即応機率 | 史実同条件より+10～20ポイント感度 |
| 同一方面内の航空隊集中に要する時間 | 24～48時間短縮し得る |
| 基地損傷時に飛行戦力そのものが部隊ごと拘束される確率 | 相対20～35%低下感度 |
| 同一出撃数で主攻撃隊が終末攻撃圏へ達する機数 | 対成熟米防空で相対10～20%増感度 |
| 自軍対空射撃の重複・無効配分 | 相対15～25%低下感度 |
| 対空目標切替・再捕捉時間 | 10～20%短縮感度 |

終末攻撃圏到達数の改善は、命中率・機体性能・44の時間圧縮と重複加算しない。FORAGER再計算では各波の「発進→CAP会敵→外周AA→終末攻撃」の機数遷移へ一度だけ入れる。

# 9. FORAGERへの遡及影響

r25で既にr24結果を暫定枝へ降格している。本監査により再計算項目を追加する。

1. 7月7日時点でMarianas、Yap、Palau、Philippinesの飛行隊をどれだけ迅速に再配分できるか。
2. 7月8～10日の米空襲後、基地を失っても飛行隊が別基地へ逃れ、翌日再出撃できる率。
3. 7月11日統合航空攻撃の時間圧縮だけでなく、CAP牽制、複数方位、雷爆同時攻撃、第一・第二波の役割分離。
4. 米艦隊防空のどの段階が一時的に飽和するか。単純な「米AA命中率低下」ではなく、終末攻撃へ抜ける機数で判定する。
5. 7月12日米反撃時、日本側がformation防空、同時変針、射界割当、CAP帰投経路をどこまで標準化できているか。
6. 母艦損傷後の航空隊を他空母・陸上基地へ再配分する速度。

したがってFORAGER再計算は、航空機性能、搭乗員練度、空母数に加え、**航空隊という組織の可搬性と、敵防空をシステムとして研究した成熟度**を入力する。

# 10. 二重計上禁止

- 航空機性能は50/52/53。
- 艦載対空火器、方位盤、電探I/Oは30。
- 戦術時間圧縮、CAP、艦隊回避は44。
- 45は空地分離・部隊可搬化と、敵防空の機能連鎖を研究して攻撃手順へ落とす部分を担当する。
- 「空地分離で基地要員が不要になる」としない。基地側要員・設備はむしろ標準化された常設基盤として必要。
- 「多方向攻撃なら米防空が崩壊する」と固定しない。米側火力とCAP量が十分なら、同時多軸でも大量損失する。
- 防空飽和研究と攻撃命中率を二重に掛けない。終末攻撃へ到達した機数と、その後の個別命中判定を分ける。
