# 0. 結論

推力式単排気管は、原理・実証そのものを本世界の計算機が発明する技術ではない。海外では1932年に後方排気による正味推力増が計算され、1940年のXP-41飛行試験で実機効果が確認され、1940～42年にNACAがノズル面積・形状・長さ・背圧と発動機出力のトレードを系統試験している。

日本側の量産・部隊標準化は、海軍戦闘機史の回顧資料では昭和18年（1943年）夏頃から零戦その他への装備とされる。零戦五二型では個別排気管の外形採用が米海軍写真資料でも確認できる。陸軍側にも1943年5月指示とされる九七式重爆二型の採用例があり、1943年には陸海軍・複数メーカーへ横断的に広がる艤装技術になっていたとみる。

本世界では、既存の計測・比較文化によって「価値の認識」と「最適ノズル探索」を史実日本より早められるが、熱害、排炎、騒音、振動、割れ、カウリング干渉、実機耐久は短縮しきれない。したがって、旧51/90の「1941年末～42年初量産化」は中心線から外し、**1941年中の台上・飛行探索 → 1942年前半の実機比較 → 1942年後半の新造機量産標準化 → 1943年の広範retrofit**を中心線とする。

金星零戦改は1942年中盤に予備設計、1943年前半に初試作という現行時計なので、推力式単排気管は**初試作から標準艤装に内包**する。現行592～600km/h、部隊中央値586～596km/hへ追加で速度ボーナスを足してはならない。

| 欄 | 監査結果 |
|---|---|
| 史実発生 | 世界基準では1932年に後方排気による正味推力増の計算、1940年XP-41で飛行実証。1940～42年NACAがノズル面積・形状・長さ、背圧、発動機出力、ジェット推力を系統試験。日本固有の最初の発想者・最初の試作機は本監査では未確定。 |
| 史実採用 | 日本海軍側は回顧資料で1943年夏頃から零戦その他へ装備。零戦五二型では集合排気から個別排気への変更が確認できる。陸軍側にも1943年5月の採用指示例があり、1943年を横断的標準化期と置く。 |
| 本世界トリガー | 発動機台上試験で集合排気と短い個別排気を同一条件比較し、排気背圧・気筒温度・軸出力を記録。続いて速度試験で速度差が測定誤差を継続的に上回ることを確認した時点を採用トリガーとする。外国知識の先取りではなく、既存の排気背圧・性能計測から自然発生させる。 |
| 計算援用 | ノズル面積、噴出角、管長・曲率、背圧による出力損失、速度別の正味推力を比較し、試す組合せを削減する。飛行試験データを高度・外気温・重量・発動機出力で正規化し、微小な速度差を統計的に識別する。 |
| 非短縮部分 | 排気管の熱変形・割れ・焼損、カウリング・配管への熱害、取付部振動、排炎、騒音、整備性、実機後流との干渉、長時間耐久。ノズルを絞りすぎれば背圧増で発動機出力を失うため、計算だけで即採用しない。 |
| retrofit | 技術的には可能。ただし単純な管交換ではなく、カウル開口、取付、遮熱、周辺配管、場合によりカウルフラップ配置を伴う。工場改修は容易寄り、航空廠・大修理時は中程度、前線で全機即日改修する類ではない。夜間任務機は排炎対策との交換条件を持つ。 |
| 初搭載機 | 本世界の海軍量産中心線では**1942年後半の後期瑞星零戦**を最初の大規模標準化候補とする。雷電・強風等の新造機は各機の艤装審査が通り次第追随。金星零戦改は1943年前半の初試作から標準艤装。陸軍は別系統の実機検証を経て1942年後半～43年に追随。 |
| 性能差 | 技術一般に固定の「+○km/h」を与えない。日本側回顧資料の約10ktは計算上の期待値、XP-41の最大18mph増は特定機・高度・ノズルの実験値であり、そのまま零戦へ移植しない。機種別の同一機体比較が得られるまで速度差は感度枝として扱う。金星零戦改の現行性能値には標準単排気管を含むものとして再構築する。 |
| 部隊中央値 | 可動部のない受動艤装なので複雑な過給・噴射装置より性能散布は小さいとみるが、管の変形、割れ、交換品の形状差、熱害、排気漏れで利得は落ちる。独立の一律倍率は置かず、機体抵抗・実用出力・整備状態の散布へ含める。 |
| 配備時計 | 1941年：台上比較・少数飛行試験。1942年前半：一～二機種でノズル・排炎・熱害を比較。1942年後半：新造・大改修機で量産標準化開始。1943年：複数機種へのretrofitと標準図面化。これは史実日本の1943年夏頃の広範採用に対し、量産標準を概ね半年前～1年弱前倒しする中心線。 |
| 戦術接続 | 最高速だけでなく、邀撃の接敵余裕、離脱、再上昇、編隊再集合に小さく効く。旋回性能を直接改善しない。夜間は排炎・騒音が明確な代価となるため、夜戦・夜間着艦では昼間型と同一の純利益を与えない。 |

# 2. 史実技術時計

## 2.1 世界側

- 1932：後方へ向けた各気筒排気で、発動機＋プロペラ＋排気ジェットの正味推力馬力が増えることが計算で示される。
- 1940：XP-41（Pratt & Whitney R-1830-19、14気筒空冷）で個別後方排気を飛行試験。20,000ftで最大18mphの速度増が報告され、集合排気環と比べて同一吸気圧でわずかな発動機出力増・気筒温度低下も報告。
- 1940～41：NACA Langleyでノズル出口面積を変更した試験。
- 1942：形状・長さを増やした追加試験。小さすぎるノズルはジェット推力を増す一方、排気流を拘束して発動機出力を低下させ、最大速度の正味利得を悪化させ得ることが確認される。

このため本技術は「後ろ向きに排気すれば無料のロケット推力」ではなく、**背圧損失を含む正味推力最適化**として扱う。

## 2.2 日本側

海軍側回顧資料は、集合排気管から各気筒後方排気へ変更し、噴流推力と背圧減少による馬力向上を狙い、計算上約10ktの速度向上を期待、1943年夏頃から零戦その他へ装備したとする。同時に騒音増大と排気光による夜間飛行の困難を記す。

米海軍歴史資料はA6M5が従来型のカウルフラップ部分に排気スタックを用いたことを写真説明で確認している。

陸軍では補助資料上、九七式重爆二型に1943年5月の推力式単排気管採用指示が記録される。これは少なくとも1943年春～夏には陸海軍の双方で本技術が量産改修項目として扱われていたことと整合する。ただし日本での「最初の発明者／最初の一機」を断定する一次資料は本監査では得ていない。

# 3. 伝播判定

本監査では、三菱が発明して他社へ一方向に伝播した、または中島・川西のいずれかが先行した、という一本線を固定しない。

1943年には三菱零戦・陸攻、川西強風の後期機、中島系陸軍機等に採用例が見えるため、実装ノウハウは企業固有の秘伝というより、陸海軍の審査・発動機艤装・各社試験を通じて横断的に再発見・標準化される技術として扱う。

本世界では共通試験票に「排気背圧、気筒温度、排気管出口面積、角度、速度差」を追加することで伝播を早める。ただし図面の横流しだけで他機へ移植せず、機種ごとの遮熱・後流・耐久審査は残す。

# 4. 本世界の日程決定

## 1941年

- 発動機台上で集合排気環と短い個別排気管を比較。
- 背圧、軸出力、気筒温度を測定。
- 少数機で後方排気の速度試験を行う。
- この段階は研究・実験であり、全軍量産標準にはしない。

## 1942年前半

- 高速化の利益が大きい戦闘機・偵察機を優先し、ノズル面積・角度・遮熱を実機比較。
- 夜間排炎、地上整備、カウル焼損、取付部割れを審査。
- 統一部品ではなく「設計法・試験法」を標準化する。

## 1942年後半

- 後期瑞星零戦等、新造・大改修機で量産標準化開始。
- 雷電・強風等は各機固有の艤装審査を通過したロットから採用。
- 既存機は大修理・発動機交換周期に合わせて改修し、稼働機を一斉に引き揚げない。

## 1943年

- 海軍・陸軍で広範な標準技術化。
- 夜戦・夜間偵察では排炎対策型を別管理。
- 金星零戦改は初試作から標準単排気管を前提とする。

# 5. 金星零戦改への接続

現行53の金星零戦改は、1942年中盤に換装予備設計、1942年後半に前部胴体・発動機架試験、1943年前半に初試作、1943年春～夏に飛行・艦上審査、1943年9月先行量産である。

したがって本監査の日程では、排気系は後付け改造ではなく前部胴体・カウリング設計の初期条件に入る。

次回性能再構築時は以下の順序にする。

1. 金星六〇型の高度別「部隊で実際に使える」軸出力を決める。
2. プロペラ径・翅数・吸収馬力・効率を決める。
3. カウリング、冷却開口、単排気管を含む機首抵抗と排気正味推力を一体で置く。
4. 重量・外板公差・艤装抵抗を入れて制式標準速度を解く。
5. 整備・発動機ロット・外板・排気管状態の散布を入れ、部隊中央値を解く。

よって現行の制式標準592～600km/h、部隊中央値586～596km/hは**単排気管込みの統合暫定値として一旦凍結**し、単排気管監査終了を理由に +10kt や +10～20km/hを加算しない。

# 6. 旧仮定の扱い

51および90にある以下の旧線は上書き候補とする。

> 1941年中に飛行試験、1941年末～42年初に量産化し得る。

監査後の扱い：

- **1941年中の飛行試験**：成立可能。維持。
- **1941年末～42年初の量産標準化**：中心線から削除。少数試験装備まで。
- **量産標準化**：1942年後半を中心。
- Ki-44、Ki-46等に置かれた「単排気管型だから固定で+約10km/h」型の差分は、機種別排気・ナセル監査時に再計算するまで暫定解除。

# 7. 残留不確定と信頼度

- 世界側の原理・XP-41飛行実証・NACA最適化：高。
- 日本海軍の1943年夏頃の広範採用：中～高（戦後回顧資料）。
- A6M5の個別排気装備：高（米海軍写真資料）。
- 日本陸軍1943年5月の特定指示：中（機種史の二次整理）。
- 日本で最初に試作・量産採用した人物／会社／機種：未閉鎖。今回の戦史・性能時計には不要なので保留。
- 本世界1942年後半量産標準化：シナリオ推定。史実日本比で概ね半年前～1年弱の前倒しに留め、材料・耐久・実装試験は短縮しない。
