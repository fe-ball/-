# 計算機異聞・1943冬～1944初夏――Marshall・Truk・Palau・FORAGER前

> **現行注意（2026-08-14）：** Truk/Eniwetokは35・36で再監査済み。 本書のMarshall以後は旧前進枝である。GALVANICは32で再監査済み。旧2月20～21日Marshall主上陸は固定せず、GALVANIC後の高速艦隊拘束・修理・補給遅延を入れて再計算する。**GALVANIC再監査32の入力待ち**として読む。


# 0. 本書の位置づけと巻戻し

88の1943年12月13日から時計を進め、Marshall、Truk、Eniwetok、Palau、中国・Burma、1944年型新戦力、OVERLORD、FORAGER準備を1944年6月10日まで同期する。

会話では一度7月4日まで進めたが、その過程で日本水上艦隊を空母護衛・背景へ過度に縮約し、10・30・31・61の技術利得、とくに金剛型高速戦艦、重巡・駆逐艦、水雷戦第二斉射、大和・武蔵等主力戦艦の作戦価値を十分に伝播していなかった。

したがって**現行の安全な継続点は1944年6月10日**とする。6月10日～7月4日に検討した出来事は本書末尾へ「旧枝」として保存するが、62に基づく戦史再監査v3で再計算するまで現行結果へ固定しない。

Marshall～Palauの中心結果は、日本水上主力を固定基地救援へ投入しない理由が成立しているため保持する。ただし米側の作戦計画には、日本決戦艦隊が温存されていることへの警戒を遡及して入れる。

# 1. GALVANIC後の米作戦能力とMarshall選定

Tarawa/Makinは米軍勝利だが、32の現行入力ではTarawa地上2,800～3,100、Makin600～750級の死傷、Lexington II戦役離脱、CVE1沈没、AKA/LST等損傷を受ける。さらに日本高速水上予備の前進により、米高速艦隊解放3～5日・前方修理補給3～7日級の追加摩擦を初期感度へ入れる。

米軍はMarshallへ進む。日本高級暗号本文を十分読めない本世界ではKwajalein直接攻撃は史実ほど自明ではなく、作業分布を、

- Kwajalein＋Majuro直接：約60～65％。
- Wotje/Maloelap等外郭先行：約30～35％。
- その他：約5％。

としたうえで、最終的に**Kwajalein＋Majuro直接**を採用する。

GALVANICの遅延・損耗を反映し、2月20日周辺島・Majuro、2月21日Roi-Namur/Kwajalein主上陸を中心とする。

米主力：4th Marine DivisionをRoi-Namur、7th Infantry DivisionをKwajalein。Tarawaで消耗した2nd Marine Divisionは主力投入しない。

高速空母はEnterpriseを一時Central Pacificへ回し、Yorktown CV-5、Essex、Saratoga II(CV-10)、Bunker Hill、Intrepidを加え大型CV6隻級。Lexington IIは3月以後、Independenceはさらに遅い。

# 2. 日本Marshall防御再編

Marshall本体約27,350＋Kusaie約4,000。中心配備：

- Kwajalein 約8,500。
- Maloelap 約4,000。
- Wotje 約3,600。
- Mili 約4,800。
- Jaluit 約3,200。
- Eniwetok 約2,200。
- Majuro D-Day残置約300～350、実戦要員180～220級。

Kwajaleinは海岸一線死守から、lagoon側・縦深陣地、水・弾薬・通信分散、局地夜間浸透へ変更。D-7以後は環礁間移動を原則凍結する。

2月15日のMarshall前進航空は約155機：後期零戦・雷電・金星零戦改、強風、攻撃機、瑞雲・彩雲・大艇等。高度な夜間雷撃熟練員は18～20組級。潜水艦約12隻。

主力空母出撃閾値は、米有効大型CV2隻以下、または3隻で1隻重大損傷、かつ上陸艦隊を24～36時間確実追尾、とする。Kwajalein陥落だけでは閾値を緩めない。

# 3. Marshall前哨航空・潜水艦戦 2月16～20日

彩雲は2～4機を前進。中心枝では使用可能3、整備1。2月16日午後、彩雲1機が西南西方面で米空母群の一部を発見し、大型空母複数・戦艦級護衛を報告。米側奇襲性を一部失わせる。

- 2/16夜：日本16機夜襲、11～12到達、6～7攻撃。命中0、日本5損失・2損傷。
- 2/17：日本約35全損、米約13。
- 2/18：日本約22、米約9。日本潜水艦がAKA1隻を魚雷大破・mission-kill、のち潜水艦沈没。
- 2/19：日本約14、米約6。夜襲12機級、命中0、約5損失。
- 2/20：日本約6、米約3。

前哨総計：日本約87機全損、12～18修理可能。米約31機全損、15～20修理可能。大型空母重大被害なし。AKA1大破。日本潜水艦1沈没、1～2損傷。

日本航空は物理残存65～70機でもKwajaleinへ直接介入可能18～24機級まで低下。彩雲・分散は航空兵力の一部を保存するが、局地航空優勢を保存するものではない。

Majuroは2月20日占領。米死傷45～65。日本残置守備はほぼ壊滅・捕虜化。破壊工作で米基地利用を24～48時間程度遅らせる。

# 4. Kwajalein/Roi-Namur 2月21～27日

主戦闘残存日本兵約7,800：Roi-Namur約3,150、Kwajalein island約3,900、Ebeye等約750。

事前砲爆撃で日本750～950戦闘損失を出すが縦深陣地は残る。

- 2/21：米地上死傷約1,120。Kwajalein30～35％、Roi80～85％、Namur45～55％確保。
- 21/22夜：日本小部隊浸透。米追加130～170、日本250～330。
- 2/22：Roi抵抗終息、Namur85～90％、Kwajalein60～65％。米約680。
- 2/23：Roi-Namur組織抵抗11時頃終了。Kwajalein80～85％。米430～520。
- 2/24：Kwajalein最終10～15％へ圧縮。米230～300。
- 2/25 10:30頃：Kwajalein island組織抵抗終了。
- 2/25～27：周辺島掃討。2/27夕刻、環礁全体の組織戦終了。

米地上総死傷約2,700中心：戦死580～630、負傷2,000～2,150。日本約7,000～7,300戦死、750～900捕虜・重傷捕獲、残存散兵100～200。

Tarawa戦訓によりLVT(A)、DUKW、hot cargo、艦砲・航空・砲兵統合が効き、日本縦深防御は米損害を史実FLINTLOCK比約1.5倍級へ上げるがTarawa型の比率までは再現しない。

翔鶴・瑞鶴・飛龍は温存。**ただしこの時点でも米側は日本主力水上艦隊の存在と決戦可能性を忘れていない。** 出なかったから脅威が消えたとは判断せず、次の基地空襲・FORAGER計画へ留保する。

# 5. 2月末の戦略認識

米軍は全島攻略を狙わず、Central Pacific最初の大きな作戦終点をMarianasへ置く。Truk等は攻略より空襲・封鎖で無力化する方向が強まる。

日本側は、

- 米軍がMarshallで止まらない：95％超。
- Carolines/Trukが攻撃・無力化される：85～90％。
- Marianasが中期主目標：70～80％、以後上昇。
- Philippinesが最終的大目標：80～90％。

と評価する。

固定島へ歩兵を無限に足すのではなく、航空・潜水艦・工兵・燃料・艦隊を移動可能な形で残す。Marianasは本土・資源線防衛上、単純迂回を許せない決戦候補になる。

# 6. HAILSTONE相当 3月5～6日

Marshallが遅れたため史実2月17～18日型のTruk大空襲も約三週後ろへ移す。

2月28日以後、山本はTrukを「艦隊決戦基地」から偵察・航空・補修・中継基地へ格下げし、主要艦、タンカー、商船、工作機能をPalau～Philippines方向へ分散する。翔鶴・瑞鶴・飛龍をTrukへ戻さない。

3月5～6日、TF58がTrukを大空襲。中心損害：

- 日本航空機75～95全損、35～45要修理。
- 米航空機27～34全損。
- 日本商船・補助艦8～12隻、4～7万GRT級沈没。
- 駆逐艦級1＋小艦艇数隻。
- 陸上燃料・格納庫・工作・通信・滑走路は大損害。

史実型の在泊船大量喪失は避けるが、Trukは大艦隊継続作戦基地として事実上失う。最低限の航空・潜水艦・偵察・救難機能だけ回復し、主力機能はPalau～Philippines～Marianasへ移す。

帰路のMarianas空襲・写真偵察により、日本側のMarianas主目標評価は85～90％へ上昇。

# 7. CATCHPOLE相当 3月10～14日

Kwajalein損耗を受け、Eniwetokは史実ほど即時ではなく3月11日主上陸中心。

- 3/10：周辺小島・砲兵島。
- 3/11：Engebi。
- 3/12：Eniwetok Island。
- 3/13～14：Parry・残余島。

米地上死傷1,150～1,300、戦死230～280、負傷850～1,000級。日本1,950～2,050戦死、130～200捕虜・重傷捕獲。

日本潜水艦はLST1隻を大破させるが、その艇は航空・駆逐艦ASWで沈没。

Wotje、Maloelap、Mili、Jaluitは攻略せず孤立・空襲・封鎖で無力化する。

# 8. 3月後半～4月――1944年型戦力の立上がりとPalau

Truk戦訓からPalauも「重要だが艦隊を置いて守る基地ではない」と判断。燃料・工作・航空を分散し、環礁出口への航空機雷も想定する。

大鳳は3月末～4月初頭に戦闘即応域へ入り、翔鶴・瑞鶴・飛龍と主力4空母を計画可能にする。

紫電改最初の実戦部隊、銀河最初の18～24機級実戦隊も成立。ただし固定基地へ新鋭隊を集めて米高速空母へ昼間消耗戦を挑ませず、後方で練成・夜間長距離航法・邀撃を詰める。

伊400は3月末、完全武装晴嵐三機の実戦想定演習を成功。第一機14～16分、三機27～30分級。潜水艦へ回収せず別水上機基地へ着水する方法も試す。

米DESECRATE相当はMarshall/Truk時計の遅れから**4月15～17日**中心。Palau・Yap・Ulithi・Woleai方面を空襲・機雷敷設。

中心損害：日本航空50～60、修理25～35、商船・補助艦3～5隻・1.5～2.5万GRT級。米航空20～25。主要艦重大損傷なし。

日本側は「固定泊地は空襲だけでなく出口を航空機雷で塞がれる」と学習し、主力泊地長期集中をさらに避ける。

# 9. 晴嵐／伊400の1944年春運用構想

伊400型の機材・日程は20を正本とする。本歴史線で追加したのは**作戦思想**である。

山本生存下では、晴嵐を米本土への象徴爆撃より、敵の次の主攻を遅らせる深部作戦兵器へ再定義する。

中心原則：

1. 三機の嫌がらせで奇襲価値を使わない。
2. 洋上航行中TF58より、固定泊地の高価値支援目標を優先。
3. 目標は停泊空母が第一候補だが、AO、AR、AE、APA/AKA/LST、燃料・弾薬・修理施設を「次作戦の遅延価値」で順位付け。
4. 初回は伊400＋401の六機単位を最低有力単位とし、5月末～6月初頭の戦闘即応を待つ。
5. 通常は浮舟を維持し、攻撃後に日本水上機基地へ逃がして特殊搭乗員を保存。無浮舟・一方攻撃は例外。
6. 晴嵐そのものを通常索敵へ多用せず、彩雲、大艇、潜水艦、通信情報で目標を先に作る。
7. 第一撃後は銀河・陸攻夜襲、通常潜水艦による退避航路攻撃等へつなぐ。

Panamaは戦略予備候補。OVERLORD後にAtlantic→Pacific大転用が観測された場合は順位を上げるが、1944年春のMarianas時計へ即効性が低いため第一目標にはしない。

# 10. 中国・Burma 1944年春

史実型U-Go/Imphalは実施しない。Chindwin西岸・Arakanの限定圧力に留め、航空補給を受ける英印軍相手に三個師団級を山岳深部へ押し込む物流構造を事前計算で拒否する。

中国では五号第三期四川深部進撃を主線にせず、武漢―長沙―衡陽―桂林/柳州方向の航空基地・交通線制圧作戦を準備。第一線7～9個師団級＋独立部隊、南京政府・協力中国軍に鉄道・都市・後方警備をより多く移管する。

**5月6日、華中春季攻勢発動。** 目的は長沙・衡陽方面第14空軍基地圏圧迫、鉄道・道路確保、中国中央軍への機動強制。重慶攻略には行かない。

中国側は五号で学習し、都市への大軍固定を避ける。第14空軍は鉄道・橋梁・車列を攻撃し、日本側の前進を遅らせる。

5月17～19日、Y-Forceは史実よりやや遅れ・やや縮小してSalween渡河。日本がU-GoをしていないためBurma日本軍は史実ほど消耗していないが、重慶側も華中攻勢へ兵力を取られ、6月初頭まで決着しない。

6月8日中心、日本軍は長沙を占領。ただし中国主力の大包囲には失敗。5月6日～6月9日、日本1.0～1.3万、中国3.2～4.2万死傷・捕虜中心。数日再編後に衡陽へ向かう。

# 11. 米軍の1944年春・OVERLORDとの同時進行

米国はEurope FirstでもPacificを停止しない。1944年2～5月が揚陸艇・船腹の最も厳しい期間で、Central Pacific＋New Caledonia大奪回＋SWPA大上陸を三軸同時最大規模にはできないが、Central Pacificの一大作戦連鎖は維持する。

本世界のOVERLORDは**1944年6月6日発動、五海岸・空挺・第一撃規模はほぼ史実**を維持する。差は第一撃ではなく余裕・後続兵站に出す。

中心差：

- D-Day初日投入：史実比98～100％。
- 6月末までのNormandy後続兵站：史実比95～97％級。
- 戦略予備・余剰船腹：史実比90～95％級。
- そのためANVIL/DRAGOONや後続の予備配分が史実より感度の高い領域になる。

米軍の機械・総人口は巨大だが、訓練済みライフル兵、分隊長、小隊軍曹、下級将校は無限ではない。史実でもASTP縮小、他兵科・サービス要員の歩兵転換へ進んでおり、本世界ではPacific側の地上損耗が少し多いため、Europeの歩兵補充危機が数週早く表面化し得る。

これは1944年夏以後のNormandy bocage、Mortain、Lorraine、Hürtgen、Ardennes/NORDWIND等で「立て直しが数日～数週遅れる」可能性を上げるが、6月10日時点では将来検討項目であり結果を固定しない。

# 12. 5月末～6月10日――決戦前の両軍

伊401は4月就役後に慣熟。5月25日前後、伊400＋401の六機合同完全演習を実施し、六機発進28～32分級。5月28日、六機攻撃を戦闘即応と判定する。

しかしMajuro・Eniwetokの標的価値が十分集中していないため、山本はまだ晴嵐初使用を許可しない。

日本第一機動艦隊は大鳳を加えた主力4空母を核とし、隼鷹・飛鷹・龍鳳・龍驤・瑞鳳・祥鳳等も保有する。航空隊律速を入れ、最大10空母を同質に扱わず、決戦時に信頼できる艦載航空機420～460機級を中心とする。

**重要なv3補正：** これら空母だけが決戦戦力ではない。生残金剛型、高速重巡・水雷戦隊、大和・武蔵等主力水上艦、旧式戦艦群を別任務へ割り当てる前提で戦役計画を作り直す。個艦台帳は未監査。

米側も日本艦隊の決戦来援を想定する。大型CVの増勢、CVL、高速戦艦、上陸支援戦艦、巡洋艦・駆逐艦を、空母航空戦だけでなく日本水上突入阻止へ割り当てる必要がある。

6月6日OVERLORD発動後もPacific集積が止まらないことで、日本側は「欧州上陸でPacificが止まる」期待を捨てる。

**6月10日、日本側はMarianas主攻95％以上、Saipan第一目標70～80％、D-Day 6月末～7月中旬と推定。** 伊400・401は、条件成立時にMajuro/Eniwetok等を攻撃できる待機作戦へ進出させる方針まで決定する。

ここを現行安全継続点とする。

# 13. 旧枝――6月10日～7月4日に一度走らせた案（非固定）

以下は会話で一度採ったが、水上艦隊・米対水上決戦計画を十分に入れていないため**参考枝**へ降格する。

- 6月26日TF58 Majuro出撃。
- 6月29日、Eniwetokの上陸・補給船集中を確認し晴嵐六機攻撃許可。
- 6月30日未明、晴嵐六機がEniwetokを奇襲。AO1重大損傷、AKA1大火災・作戦離脱、LST1中破、米170～230人的損害。日本晴嵐2撃墜、1帰途不時着、3離脱。D-Dayを7月5→7日へ2日延期。
- 7月1～3日、TF58がMarianas基地航空を反復攻撃。日本島内航空隊を削減するが、二線配置100機以上を残す。
- 7月4日、日本側がMarianas主上陸確定と判定し空母決戦発動。

晴嵐攻撃の「固定泊地の上陸・補給機構を狙う」という発想自体は有力だが、米側が日本水上決戦を見越して前進日程・battle line・泊地防空・ASWをどう組むか、また晴嵐初撃で米水上戦力配置がどう変わるかを入れて再判定する。

# 14. 戦史再監査v3で最初に閉じる事項

1. **日本個艦台帳**：陸奥の1943年6月8日爆沈事故を本世界でも起こすか。金剛・榛名・比叡・霧島、大和・武蔵、長門級、扶桑・伊勢型、重巡、軽巡、夕雲・秋月等の生残・修理・配置。
2. **艦別任務係数**：10・30・31・41等を62で統合。旧「有効戦力＋7～12％」を艦全体の上限にしない。
3. **水雷第二斉射**：20～60分戦闘で12～20分級の再装填・再射撃を必ず評価。
4. **米側FORAGER計画**：日本決戦艦隊来援を85～95％級で想定し、Lee高速戦艦群、上陸支援戦艦、巡洋艦・駆逐艦、潜水艦、航空索敵をどう配するか。
5. **日本側決戦計画**：基地航空→空母航空だけでなく、高速戦艦前衛→水雷戦→大和・武蔵主力打撃を含む多層作戦へする。ただし「全部突入」ではなく任務価値と生還・燃料を比較。
6. **相互認識**：米側は艦の存在を知るが1944年型体系能力を割り引く。日本側も米レーダー・battle line・艦隊防空を知り、無警戒突入を前提にしない。
7. **レーダー差**：大規模海戦では万能勝敗補正ではなく、状況認識・射撃・CAP誘導へ何分早く入るかで扱う。
8. **FORAGER日付**：旧枝の7月5/7日を固定せず、OVERLORD・Marshall遅延・晴嵐・米水上警戒を統合して再決定。

# 15. 継続点

**1944年6月10日夜。**

- NormandyではOVERLORD橋頭堡成立、まだ突破前。
- 中国では長沙占領直後、衡陽作戦へ再編中。
- BurmaではSalween正面が進行中、史実型Imphal壊滅戦なし。
- 日本は大鳳を含む空母戦力、基地航空、彩雲・銀河・紫電改、伊400/401＋晴嵐六機を戦力化。
- 米軍はMarianas攻略集積を継続。
- 日本主力水上艦隊は保存され、Marianasで初めて「空母護衛」ではなく独立した作戦軸として使うべき段階へ入る。

次回は62に従い個艦台帳を閉じ、FORAGER計画を**米側・日本側双方から再構築してから**6月11日へ進める。
