# 1944年7月 FORAGER 実艦Task Group・決戦配置台帳

## 1. 規約

本書は38の「存在」から、今回の戦役へ実際に出す艦を切り出す。

- **存在艦を全部投入しない。** 速力、航空隊、燃料、後方任務、修理予備を残す。
- **戦闘能力以外を数える。** 艦隊を出せること自体が敵の索敵、CAP、battle line、給油、夜間護衛を拘束する。
- **日米とも敵主力の存在を知っている。** 米側は日本水上主力を軽視せず、日本側もTF58を「空母だけの群」と見ない。
- **高級暗号の万能解読はない。** 米側は地理的潜水艦哨戒、航空偵察、方探、交通分析から日本主力を追う。

中心戦役窓は7月7日夜～14日。D-Dayは43で確定する。

# 2. 米側――TF58五個群への拡張

史実Philippine SeaではTF58は15空母級だった。本世界はYorktown CV-5生残、FORAGERの約1か月後退、Intrepid復帰、Franklin戦力化により、7月前半はfleet CV10＋CVL8を戦域へ置ける。

## 2.1 CVL台帳訂正

7月7～14日に使用するCVL8隻は、

**Princeton、Belleau Wood、Cowpens、Monterey、Langley、Cabot、Bataan、San Jacinto。**

Independenceは修理完了7月15日のため本戦不参加。Bataanを入れる。総数8は変えない。

## 2.2 シナリオ上のTF58編成

以下は史実編成の単純コピーではなく、本世界の18空母を運用するための**シナリオ編成**である。

| 群 | Fleet CV | CVL | 主任務 |
|---|---|---|---|
| TG58.1 | Yorktown CV-5、Hornet II | Belleau Wood、Bataan | 北方CAP、Saipan/Tinian制圧、対艦待機 |
| TG58.2 | Bunker Hill、Intrepid | Monterey、Cabot | 西方対艦主力、長距離索敵 |
| TG58.3 | Enterprise、Lexington II | Princeton、San Jacinto | 中央予備、夜間/索敵統合、艦隊防空 |
| TG58.4 | Essex、Franklin | Langley | Saipan/Guam制圧、第二対艦打撃 |
| TG58.5 | Saratoga II(CV-10)、Wasp II | Cowpens | 南方警戒、Guam/Rota、機動予備 |

艦載航空の戦闘使用可能総数は**1,020～1,090機中心**。全機を対地爆撃へ変換せず、初期から15～22％級を対日本艦隊索敵・外周CAP・Lee battle line援護へ拘束する。

## 2.3 Lee高速戦艦群

中心7隻：

**Washington、North Carolina、South Dakota、Indiana、Alabama、Iowa、New Jersey。**

7月10日以後、日本高速水上群の位置が具体化した時点でTG58.7相当へ集中する。これは島砲撃火力を減らす代わりに、輸送船団へ日本金剛型・重巡群を通さない任務を持つ。

Missouriは就役済みでも訓練時計上不参加。

## 2.4 上陸船団

Saipan主攻は史実FORAGER級の大規模船団を基礎とするが、本世界では日本主力艦隊が上陸前から前進しているため、D-Day前は低速輸送船団をMarianas西側へ出さない。

- 主輸送群：Saipan東～北東の安全帯で待機。
- 高速輸送/火力支援：必要時のみ西岸へ接近。
- 夜間：旧式BB・巡洋艦・DDの相当部分をtransport covering forceへ残す。

# 3. 日本側――A-GOを空母一群へ潰さない

## 3.1 第一航空打撃群

**大鳳、翔鶴、瑞鶴、飛龍**

護衛中心：最上、鈴谷、利根、筑摩、矢矧、DD8～10。

艦載機約**285～305機**。金星零戦改・後期零戦が主戦闘機。烈風は試験/初期生産の少数のみで、主力化しない。

## 3.2 第二航空群

**隼鷹、飛鷹、龍鳳、瑞鳳、祥鳳**

護衛中心：三隈、熊野、青葉、衣笠、能代、DD7～9。

艦載機約**160～180機**。防空、第二撃、損傷機収容を重視する。

**龍驤はGuimaras/Davao側の航空回送・予備艦**として中心決戦列から外す。よって「存在10空母、決戦前進9空母」が中心。

## 3.3 高速水上前衛

**金剛、比叡、榛名、霧島**

**高雄、愛宕、摩耶、鳥海**

大淀、DD12～14（島風を含む）。

主任務：

1. 米輸送群が西へ寄った夜の突入可能性を維持。
2. Lee battle lineを島砲撃から拘束。
3. 空母航空・基地航空が米大型CVを複数mission-killした時のみ、本格接近。
4. 条件不足なら遠距離魚雷・限定接触後に退避する。

## 3.4 主力水上打撃群

**大和、武蔵、長門**

**妙高、那智、足柄、羽黒**、阿賀野級軽巡1、DD8～10。

主任務は上陸船団の破砕であり、Lee高速戦艦群との昼間正面砲戦を目的にしない。高速前衛が通路を作り、米空母航空が減衰し、輸送群位置が鮮明になった場合だけ東進する。

## 3.5 後方戦力

扶桑、山城、伊勢、日向はPhilippines～内側の第二線。古鷹・加古等の一部巡洋艦も後方輸送・基地防衛を埋める。

この層があるため、主力へ35隻級のDDを割いても、AO護衛や後方船団が即空白にならない。これが史実差の主要部分である。

# 4. 日本基地航空

7月7日夜に「Marianasそのものへ並んでいる機数」と「A-GOの一日圏で移動可能な機数」を分ける。

中心：

- Saipan/Tinian/Guam/Rota：**300～330機即応**。
- Pagan/Bonins方向の移動予備：**40～55機**。
- Yap～東Philippinesから一日～二日で投入可能：**55～70機**。
- 飛行艇・水上偵察・彩雲等：**30～40機**。

重複を除くA-GO航空ネットワークの即応は**410～450機級**。

構成の中心は、

- 戦闘機：後期零戦、金星零戦改、雷電、紫電改。烈風は6～12機級の評価/先行量産隊。
- 攻撃：銀河、天山、彗星、後期陸攻。
- 偵察：彩雲、大艇、水上偵察。
- 強風：滑走路制圧後も水上泊地から局地防空を残す。

米F6F主体のレーダーCAPを質的に逆転しない。目的は「D-Dayまで全滅しない」「空母航空の攻撃時刻と重ねる」である。

# 5. 潜水艦

## 5.1 日本

Marianas～Philippine Sea広域へ**20～24隻割当、17～20隻on-station中心**。

- 大型巡潜：外周艦隊接触・報告。
- 通常伊号/呂号：給油群・輸送群・退避路。
- 第一世代潜高：確実に時計が閉じている6隻のうち**5隻投入、1隻整備/予備**。
- 潜高は空母を連続追跡せず、古い接触報告からスプリントして再捕捉/射点化する。

後続潜高改・小型潜高は本戦の確定隻数へ追加しない。技術存在と量産可能性を、閉じていない個艦数へ変換しない。

## 5.2 米

高級日本暗号を史実級に読めないため、潜水艦は精密な航路待伏せより、San Bernardino～Philippine Seaの**地理的ピケット10～14隻級**を中心とする。

日本主力を捕捉する可能性は十分残るが、史実のTaihō/Shōkaku二隻撃沈を自動再生しない。

# 6. 給油・工作

## 日本

- A-GO随伴大型AO/高速タンカー：**7隻中心、6～8感度**。
- 二群へ分散し、一斉給油を避ける。
- 明石はDavao/Philippines内側に残し、決戦海面へ連れ出さない。

燃料は有限。二度目の全艦隊東進を無料にしない。ただし一度の給油失敗で全作戦が終わる史実より再試行余地がある。

## 米国

Eniwetok/Majuro～前進給油群の厚みは大きいが、日本潜水艦・特殊攻撃の存在によりAO群の外周護衛を増やす。高速空母18隻を維持するため、給油場所と時刻の自由度そのものが戦役資源となる。

# 7. 7月7日夜の戦力比較

| 指標 | 米 | 日本 |
|---|---:|---:|
| 決戦空母船体 | CV10＋CVL8 | 前進9＋予備龍驤1 |
| 艦載戦闘使用機 | 1,020～1,090 | 460～490 |
| 基地航空 | Marianas攻撃側にはほぼ艦載主体 | 410～450ネットワーク |
| 高速戦艦 | 7 | 金剛型4 |
| 主力重戦艦 | 上陸支援旧式BB別途 | 大和・武蔵・長門3 |
| 重巡 | 十分多数 | 18存在、14～16決戦可 |
| DD | 絶対数優位 | 55～62存在、32～40決戦可 |
| 潜水艦 | 地理ピケット10～14中心 | 17～20 on-station、潜高5 |
| 前進修理 | 巨大Service Squadron | 明石生存で史実より改善 |
| 給油 | 絶対量圧倒 | AO史実比+2～3隻級、なお燃料制約あり |

**判断：** 空母航空の総量・レーダーCAP・AAでは米側が明確に優勢。日本側の勝ち筋は、基地航空・潜水艦・空母航空で米空母/給油を事前に削り、残った高速水上艦の存在で米軍を分散させ、夜間だけ局所的に閾値を越えることである。
