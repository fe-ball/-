# 計算機異聞・暗号・通信情報正本

# 0. 現在の位置づけ

本書は、暗号設計、自軍暗号防御、鍵管理、通信規律、暗号攻撃、交通分析、暗号用計算設備を担当する独立正本である。

計算機は暗号を自動的に破る魔法の装置ではない。最初に効くのは、傍受記録の分類、照合、頻度計数、重複検出である。その後、Type 1、Type 2、Type 2P、専用真空管機へ進むにつれ、暗号機模擬、候補検定、言語統計、交通分析が段階的に機械化される。

今回、次を上書き決定とする。

1. PURPLEとJN-25の効果を混同しない。外交通信と海軍作戦通信を分ける。
2. 丸暗号の改善だけで海上輸送が安全になるとはしない。
3. 丸暗号が読まれただけで米潜水艦が自由に船団を狩れるとも扱わない。
4. 暗号方式、鍵物流、通信規律、解読、情報利用を別の時計として扱う。
5. 暗号防御の効果は、対潜航空、護衛、船団運用、基地網と統合して評価し、独立した固定損失低減率を置かない。
6. 1942年までに中央の暗号設計・通信分析能力は明確に強化されるが、その作戦上の帰結は次段階で個別に検討する。

旧解説にあった「米潜の眼を潰す」は、次のように読み替える。

> 暗号防御は、敵COMINTが船団・艦隊・潜水艦を高い解像度で追跡する経路を大幅に弱める。ただし地理的待伏せ、哨戒、レーダー、無線方位測定、交通分析は残る。

# 1. 暗号能力を構成する五層

暗号能力を一つの解読率や強度で表さない。次の五層を分ける。

| 層 | 内容 | 計算機が効く場所 |
|---|---|---|
| 暗号設計 | 符号、添加数、換字、機械式ステッピング | 周期、偏り、鍵空間、差分、攻撃模擬 |
| 鍵運用 | 鍵生成、印刷、配布、交換、失効、廃棄 | 重複検査、使用量監査、配布先管理 |
| 通信規律 | 定型文、再送、同文異暗号、平文、呼出符号 | 違反統計、教育資料、監査 |
| 暗号攻撃 | 頻度、接合、深度、重畳剥離、鍵探索 | カード機、Type 2、専用探索機 |
| 情報利用 | 翻訳、評価、優先順位、作戦配布 | 索引、相関、交通分析、時効管理 |

暗号方式が強くても、鍵更新が遅れ、同じ鍵を大量使用し、定型文を反復すれば破られる。逆に暗号文の一部を読めても、翻訳と評価が遅ければ作戦価値を失う。

## 1.1 敗勢との正のフィードバック

史実後半の暗号運用悪化は、暗号技術だけの問題ではない。

- 鍵表の輸送が間に合わない。
- 孤立基地が旧鍵を使い続ける。
- 熟練通信員が損耗する。
- 緊急通信と再送が増える。
- 暗号装置と予備品が不足する。
- 複数系統が同じ内容を送る。
- 鍵表を安全に廃棄できない。

したがって、

> 戦況悪化 → 通信量・緊急性増加 → 暗号運用悪化 → 敵COMINT向上 → 損失増加 → さらに戦況悪化

という循環が起こり得る。

本世界では攻勢期間が長く、基地網、輸送、航空、整備が史実より健全なので、この循環へ入る時期が遅れる。計算機による鍵重複、更新遅延、通信規律違反の監査も、穴が全体系へ広がる速度を抑える。

# 2. 暗号部門は計算機を購入する

## 2.1 最初の購入者

最初の本格購入者は海軍技術研究所の暗号機設計部門を中心とする。

理由は次のとおり。

- 継電器とステッピングスイッチを扱うため、計算機の技術的価値を理解しやすい。
- 試作暗号機の周期、偏り、故障時挙動を自分たちで確認できる。
- 海軍は友鶴事件後に計算機業者との取引実績を持つ。
- 九七式欧文印字機等の開発時期とType 1の普及時期が重なる。

陸軍の暗号・特種情報系統も大きく遅れない。海軍より半年から一年程度遅れ、独自施設を整備する中心線とする。

海軍の設計部門、海軍の解読部門、陸軍の暗号・解読部門、外務省は別系統で動く。陸海軍の設備・資料・成果は原則共有されず、同じ機械と手順が別名義で重複購入される。

## 2.2 機密保持と調達方式

用途名は「暗号解読機」としない。

- 通信統計試験装置
- 符号群分類装置
- 電気式周期試験装置
- 通信記録照合設備

などの契約名を用いる。

調達と保守は次の方式で成立させる。

- 業者には対象国、符号体系、実暗号文を開示しない。
- 受入試験は合成データで行う。
- 実データの穿孔、投入、分析は軍人・選抜軍属が担当する。
- 軍側に専属保守班を置く。
- 業者は交換ユニット、試験器、保守部品まで納入する。
- 故障媒体・ユニットは消去・封印後に扱う。
- 穿孔室、機械室、分析室を物理的に分離する。
- 入出力媒体には通し番号と持出し記録を付ける。

この方式なら、暗号機関は機密の芯を外部へ出さず、民間企業の計算機技術を利用できる。

# 3. 商品別の暗号適性

| 商品・設備 | 暗号用途 | 評価 |
|---|---|---|
| パンチカード統計集計機 | 頻度、接合、重複、送信局・時刻・周波数別分類 | 最初に最も効く |
| EM-1 | 小規模周期検査、試験暗号文生成 | 借用・受託向き |
| Type 1A/B | 暗号機設計検証、定型統計処理 | 設計側が購入 |
| Type 1C | カード機との連携、候補検定、中央暗号計算室 | 最初の旗艦級設備 |
| Type 2 | 暗号機模擬、候補生成・検定、交通分析 | 開戦時の中央能力 |
| Type 2P | 時効の短い戦術通信、複雑候補の高速検定 | 1943年以降 |
| Type 3 | 大量傍受記録の索引、通信網履歴、複数機連携 | 計算所中枢 |
| 真空管式専用機 | 特定暗号の高速探索 | 少数・対象別 |

## 3.1 パンチカード統計集計機

暗号に最初に刺さる商品である。

分類機、照合機、穿孔機、検孔機を組み合わせ、同じカードを複数回通して、数十万件の傍受記録から有望な通信系統、反復、深度、定型性を抽出する。

暗号部署が「計算機」を買う意識を持たなくても、「通信統計装置」なら早期に採用できる。

## 3.2 EM-1とType 1

EM-1は毎秒数命令で、大規模鍵探索には遅い。暗号設計側で、ステッピング周期、偏り、小規模な状態遷移を一晩かけて検査する用途に限られる。暗号部門が専有購入するより、秘密試用または抽象化した受託計算が自然である。

Type 1A/Bでは、暗号機案の比較、故障時挙動、数万文字級の試験系列の統計処理が可能になる。総当たり探索ではなく、設計・検証の機械である。

Type 1Cは4,096語級ドラム、二重入出力、カード設備との接続により、最初の本格暗号計算室を成立させる。

作業の流れは、

> カード機で母集団を縮小 → 人間が仮説を立てる → Type 1Cで統計得点・候補検定 → 分析官が解釈

となる。

## 3.3 Type 2

Type 2は毎秒30～100命令級、48～64語の直接選択記憶と4,096語級ドラムを持ち、反復、条件分岐、サブルーチンが実用になる。

暗号用途では、

- 暗号機の動作模擬
- 鍵候補の生成と検定
- 復号候補への言語統計得点
- 一致指数、接合頻度の計算
- 呼出符号、時刻、周波数、方位の照合
- 自軍の鍵使用量、重複、更新遅延の監査

を行う。

ただし無差別総当たりはできない。カード分析、既知平文、鹵獲資料、運用誤りで候補を数千・数万級まで絞った後に強い。

1941年末の「旗艦級暗号能力」は艦上装置ではなく、陸上の中央暗号計算所として成立する。

## 3.4 Type 2P・Type 3・専用機

Type 2PはType 2の代表業務で3～5倍級となり、数時間から一日で価値が失われる戦術通信にも、条件が揃えば間に合う。

Type 3は万能な解読機ではなく、傍受記録、呼出符号、通信網、過去電文、複数傍受所の情報を統合する計算所中枢として強い。

特定暗号に対する高速探索は真空管式専用機へ分岐する。

- 高速紙テープ読取
- 特定暗号の内部状態模擬
- 設定候補の連続試行
- 条件を満たす候補だけ印字

を行う半固定配線機である。

「日本版コロッサス」という一括表現は避ける。対象暗号、論理条件、紙テープ処理が異なるため、対象別の高速統計・鍵候補検定機とする。

# 5. 自軍暗号防御

## 5.1 暗号設計

計算機が強く効くのは、自軍暗号の採用前検査である。

- 出力頻度の偏り
- ステッピング周期
- 鍵設定間の相関
- 接点故障時の規則性
- 既知平文への耐性
- 添加数生成規則
- 同一鍵使用量

を定量化する。

これにより「理論上は複雑だが統計的に弱い」方式を採用前に落とし、改良案の比較を短期間で行う。

## 5.2 鍵物流

防御の中心は暗号機の機構だけではない。

- 鍵表の生成
- 印刷・封緘
- 配布先と受領確認
- 有効期間
- 使用量
- 失効命令
- 廃棄確認

を一つの物流として管理する。

計算機は重複、過剰使用、更新遅延を発見するが、鍵表を前線へ運ぶ船、航空機、通信網を生み出さない。戦況と兵站が悪化すれば鍵運用も悪化する。

## 5.3 丸暗号

丸暗号を全船で完全な一回限り乱数式に置き換えるのは、鍵表の量と配布が重すぎる。

三階層化する。

| 階層 | 対象 | 中心方式 |
|---|---|---|
| 甲 | タンカー、大船団、重要軍需船、出航・到着予定 | 航海・船団別の短期添加表、使用後廃棄 |
| 乙 | 通常商船、港湾間運航連絡 | 地区別コード＋日替わり添加表 |
| 丙 | 気象、遭難、入港許可、一般事務 | 簡易コード、軍事情報を載せない |

重要情報は船団司令、主要港、海運統制機関へ限定し、一般船には必要最小限だけ知らせる。

丸暗号の堅牢化は海運を単独で救わない。敵が船団予定を得る頻度と鮮度を下げ、対潜・護衛体系の大穴を塞ぐ。

## 5.4 PURPLEとJN-25

PURPLEは外務省の高級外交通信、JN-25は海軍作戦暗号であり、同じ効果として扱わない。

本世界では、計算機による統計検査によって、暗号機・コード・添加数の弱点と運用上の危険を史実より早く認識する。

ただし「最初から絶対に破られない」とはしない。

- 改訂型への更新が早い。
- 鍵期間と添加表使用量を短縮する。
- コード改訂と添加表改訂を適切にずらす。
- 同文送信と定型文を減らす。
- 解読兆候が出た通信系統を早く切り替える。

その結果、敵側の部分解読率、情報鮮度、継続性が低下する。作戦意図が一度も漏れないとは固定しない。

# 6. 暗号攻撃と交通分析

## 6.1 破れる層、破れない層

### 高級暗号

SIGABA級は破れない。巨大な鍵空間と不規則動作を、当時の汎用機・専用機で無差別探索することはできない。

### 中級機械暗号

M-209級は、深度、既知平文、鹵獲機、設定ミス、鍵再使用が揃えば条件付きで解読できる。専用探索機によって「数日後に判る」が「数時間から一日で判る」場合が増える。

### 低級コード

気象、航空、港務、商船連絡、略号は広く分析対象になる。個別の暗号強度より、運用量と定型性が解読を助ける。

## 6.2 交通分析

内容を読めなくても、

- 呼出符号
- 周波数
- 送信時刻
- 通信量
- 無線方位
- 通信網の接続

から、部隊編成、基地活動、作戦準備の兆候を推定できる。

Type 2・Type 3の価値は、暗号文字列だけでなく、長期間蓄積した通信網の履歴を比較する点にある。

## 6.3 情報の時効

解読可能性と作戦価値を分ける。

- 数時間以内に必要な航空・艦隊情報
- 数日有効な船団・補給情報
- 数週間有効な編制・配備情報
- 長期蓄積する通信網・運用傾向

に分類し、機械時間と分析官を優先配分する。

# 7. 暗号と対潜・輸送の統合

潜水艦による船団攻撃は、

> 情報取得 → 哨戒海域への移動 → 接触 → 射点進出 → 有効発射 → 離脱 → 再攻撃

の連鎖で成立する。

暗号解読が直接改善するのは、主に情報取得と移動先の選択である。

本世界では、その後に東海、カ号、護衛艦、船団運用、前進基地が存在する。

- 昼間浮上と充電が妨げられる。
- 水上高速移動が制限される。
- 船団への回り込みが遅れる。
- 接触後の反復攻撃が難しくなる。
- 情報の有効期限内に予定海域へ着けない場合がある。

したがって、丸暗号を一系統解読しても「食べ放題」にはならない。

逆に暗号を完全に守っても、主要航路が固定され、航空哨戒と護衛が弱ければ、地理と交通統計だけで待伏せできる。

正しい位置づけは、

> 暗号防御が対潜戦を成立させるのではなく、成立しつつある対潜・護衛体系から情報上の大穴を除く。

である。

海上輸送損耗は、暗号防御、対潜航空、護衛艦、船団編成、航路、基地、船腹新造・修理を統合して計算する。暗号防御単独の損失低下率は固定しない。

# 8. 現行決定と次の作業

## 8.1 決定

- 暗号部門は機密保持方式を整え、計算機を購入する。
- 海軍暗号設計部門が最初の強い購入者となる。
- 陸軍も大きく遅れず、別系統で重複整備する。
- 最初に効く商品はパンチカード統計集計機である。
- Type 1Cが最初の暗号用旗艦設備、Type 2が開戦時の中央暗号能力となる。
- 1942年までに自軍暗号設計、鍵重複検査、通信統計は史実より明確に強化される。
- 1943年以降、Type 2P、Type 3、対象別真空管専用機へ進む。
- SIGABA級は破れない。
- **1942年の日本高等暗号は、少なくとも短期戦略に意味のある時間・精度・単語数では米側がほぼ解読不能とする。** ただし低級暗号、平文、トラヒック解析、無線方位、偵察は残る。
- 暗号防御は対潜・護衛・船団体系の一要素であり、単独で戦局を決めない。
- 遣独潜水艦連絡で史実上日本向けに企図された技術貨物が到達する結果は20で固定する。これは暗号が完全無欠になった一般効果ではなく、潜水艦性能、通信規律、中継、戦域条件を含む個別作戦結果である。

## 8.2 次の検討――「暗号が固くなった1942年」

次は1942年の断面を扱う。

- どの暗号体系が、いつ、どの程度改訂されたか。
- 艦隊、基地、潜水艦、航空隊、商船で鍵配布がどこまで間に合うか。
- 開戦前の旧鍵・旧装置をどこまで残すか。
- 米側が失う情報と、なお得られる情報は何か。
- 日本側が中低級米暗号と交通分析から何を得るか。
- ミッドウェー、潜水艦戦、船団戦、基地航空戦へどう接続するか。

「1942年に暗号が固くなった」を一括効果にせず、暗号体系、部隊、戦域、情報の時効ごとに分けて検討する。


# 9. 1942年の作戦情報像――高等暗号は固いが情報戦は消えない

## 9.1 上書き決定

1942年の日本高等暗号について、以後の歴史考察では次を固定する。

> **米側は、高等暗号から短期戦略に意味のある時間内に、作戦地点・正確な日程・兵力構成を十分な精度と語数で再構成することがほぼできない。**

「数学的に永遠に破れない」という意味ではない。

- 数週間・数か月後の部分復元。
- 鹵獲資料。
- 運用ミス。
- 暗号系統ごとの差。

は別時計で残る。

## 9.2 米側に残る情報

- 低級コード・戦術通信。
- 平文。
- 気象・港務・商船等の周辺通信。
- 通信量。
- 呼出符号・周波数。
- 無線方位測定。
- PBY等の航空偵察。
- 潜水艦偵察。
- 地理・兵站から見た次作戦候補。

したがって、

> **「次はMidwayか、南太平洋か、北方か」という候補推定はできるが、「Midway、6月X日、空母N隻」まで詰め切れない。**

という情報環境になる。

MIの具体的な米側事前確率・作戦結果は80、FS前の察知は81へ置く。

## 9.3 日本側の米通信分析

日本側もSIGABA等の最高級米暗号を破ることはできない。

主な対象は、

- 中低級暗号。
- 航空・港湾・基地通信。
- 交通分析。
- 無線方位。
- 平文・定型通信。

である。

したがって日米双方とも、1942年後半は**暗号文本文の完全解読より、基地活動・輸送集中・航空偵察を重ねて相手の作戦を推定する比率が高い**。


# 10. 1943年秋の米上陸作戦察知――GALVANIC型情報像

## 10.1 高級暗号本文は読まない

1943年秋もSIGABA級の米最高級作戦暗号を継続解読できる設定にはしない。したがって、日本側が「GALVANIC」「Tarawa」「D-Day」「大型CV何隻」といった最高級作戦命令本文を直接読む展開は中心線から除外する。

**判断の理由：** Type 2P・Type 3が存在しても、巨大鍵空間と良好な運用を持つ最高級機械暗号へ総当たりで届くわけではない。計算機の優越を高級暗号破読へ一括変換しない。

## 10.2 開く窓は上級暗号の周辺である

GALVANIC級の上陸作戦は、暗号本文以外に大量の物理兆候を生む。

- 同じ環礁への反復垂直・斜め写真偵察。
- リーフ、浜、礁湖入口、桟橋を狙う低高度・特定角度の撮影。
- 攻撃せず海岸近くを長時間観測する潜水艦。
- Ellice、Samoa、Fiji等の基地航空・救難・気象・港務通信増大。
- 上陸艇、工兵、写真測量、燃料、医療、舟艇整備等の低級・補給トラヒック。
- 大規模演習前の通信網膨張と、出航直前の一斉無線封止。

Type 2/3の主価値は、これらを数か月分の履歴と比較し、**爆撃準備と上陸準備のパターン差**を見つけることにある。

## 10.3 中低級暗号の短期窓

中心線として1943年10月末～11月初頭、Ellice方面の米陸軍航空・基地補給系統の一部で、M-209級または低級コードについて**2～3日程度の部分解読窓**が開く。原因は定型文、既知平文、鍵再使用、運用量の重なりとする。

読める内容は、航空燃料、写真フィルム、写真測量用品、整備要員、救難、特殊写真任務等の周辺情報まで。Tarawa、GALVANIC、D-Dayを直接読ませない。米側の鍵更新後に窓は閉じる。

**判断の理由：** 中級暗号は条件が揃えばType 2Pで解読時間を短縮できるが、作戦名・日付・全OOBを常時取得する万能窓にはしない。短い成功を交通分析へ統合する方が技術設定と整合する。

## 10.4 1943年11月の推定精度

各情報を統合した日本側の作業確率は次を中心とする。

- 10月7日：Gilberts 40～45％、Marshall直接25～30％、Wake 10～15％、その他。
- 10月末：Gilberts先行65～75％。
- 11月上旬：Gilberts 75～85％、Tarawa主目標55～65％、Makin同時または副目標40～55％。
- 11月20日前後：Gilberts 85％級、3週間以内の攻略作戦70％級。
- 11月28日以後、通信局の一斉消失と船団兆候を得て、12月5～15日中心へ時期を絞る。

日付そのものは最後まで高級暗号から読まない。出航後の方探、潜水艦・哨戒機接触、陸上航空活動によってD-Day数日前まで狭める。

## 10.5 情報を持つ側の節制

Tarawa本命確率が上がっても、Tarawaだけへ露骨に兵力集中しない。写真偵察で増援が発覚すれば、米側が攻撃火力を増す、Makinへ重点を移す、Marshall直攻案を再検討する余地がある。

したがって情報優越は、

- Gilberts全体の築城・弾薬を底上げ。
- Marshall航空隊を反撃帯として強化。
- 潜水艦を上陸・補給航路へ分散配置。
- 大型輸送を攻撃直前に止める。
- 主力艦隊は後方の条件付き邀撃位置に残す。

という形で使う。

**判断の理由：** 敵の意図を知ることと、こちらの確信を敵に教えないことは同時に必要である。暗号・交通分析の利得を一点増援で消費しない。


## 2026年8月14日追加――潜水艦接触報告と時効管理

1943年潜水艦隊を現代的データリンク網にはしない。改善するのは、情報形式と陸上側の時効管理である。

標準報告：`時刻 / 位置 / 敵種 / 針路 / 速力 / 確度 / 自艦状態`。

陸上司令部は複数潜水艦、基地航空、交通分析の報告を照合し、敵の存在確率帯と次の哨戒線・時刻を作る。受信後に潜航した艇は、その後どんどん古くなる情報を自力で外挿し、聴音・潜望鏡で再捕捉する必要がある。

潜水艦は攻撃可能でも、敵主力の位置情報価値が高い場合は発射せず接触維持を優先してよい。攻撃しなかった報告艇を戦果ゼロとして扱わない。
