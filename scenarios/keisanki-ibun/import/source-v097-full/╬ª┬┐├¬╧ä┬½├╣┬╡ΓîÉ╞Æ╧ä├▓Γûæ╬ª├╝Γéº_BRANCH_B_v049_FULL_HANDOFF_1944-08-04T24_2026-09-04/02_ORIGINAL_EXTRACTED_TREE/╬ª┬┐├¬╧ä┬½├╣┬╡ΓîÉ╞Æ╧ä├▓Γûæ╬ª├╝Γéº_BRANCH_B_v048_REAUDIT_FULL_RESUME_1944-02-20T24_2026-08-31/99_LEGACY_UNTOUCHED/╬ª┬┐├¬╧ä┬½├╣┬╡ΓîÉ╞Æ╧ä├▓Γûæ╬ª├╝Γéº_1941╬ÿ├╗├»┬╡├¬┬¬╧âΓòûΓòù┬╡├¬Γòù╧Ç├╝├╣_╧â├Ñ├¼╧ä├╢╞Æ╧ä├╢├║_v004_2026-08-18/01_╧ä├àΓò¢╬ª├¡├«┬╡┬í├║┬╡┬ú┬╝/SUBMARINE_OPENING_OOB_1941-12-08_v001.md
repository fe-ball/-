# 潜水艦 開戦OOB・可用状態台帳 v0.01

## 目的

1941年12月8日の日本潜水艦戦力を、単なる「在籍隻数」ではなく

`HULL → COMMAND_ASSIGNMENT → PHYSICAL_LOCATION → AVAILABILITY → MISSION → ON_STATION → CONTACT/ATTACK/REACQUIRE → RETURN/REPAIR`

で再構成する。

後年の潜高・伊400型・遣独成果は開戦OOBへ混ぜない。潜高は建造・船台機会費用だけを別時計で保持する。

## 史料強度

- 艦隊編制の骨格：Japanese Operational Monograph No.116由来の1941年12月艦隊表を基準。
- 第一期作戦の任務骨格：Japanese Monograph No.97のCombined Fleet orders。第6艦隊はハワイ・米西岸偵察、敵艦奇襲、海上交通破壊を任務集合に持つ。
- 個艦の開戦直前所在・故障・出撃：CombinedFleetの個艦TRoMを補助利用。
- 編制表と個艦TRoMが矛盾する場合、編制表を名目所属、TRoMを実可用・実任務の優先資料とする。

## 1. ハワイ方面：第6艦隊主力

### 第1潜水戦隊

名目編制：伊9、伊15～伊25級の計11隻級。

- 通常哨戒・偵察線：伊9、15、17、19、21、23、25など。
- 特別攻撃隊：伊16、18、20、22、24の5隻が甲標的母艦。
- 開戦時の主目的は、真珠湾から出撃する艦艇の捕捉・攻撃、偵察、後続の米西岸通商破壊。

**モデル上の分離**：

`FLEET_INTERCEPT / RECON / MIDGET_SUPPORT / COMMERCE_RAID`

を別missionとして記帳する。甲標的母艦を通常通商破壊線へ同時算入しない。

### 第2潜水戦隊

名目：伊1～伊7、伊10など8隻級。開戦時はオアフ北東・北西側の哨戒線。

### 第3潜水戦隊

名目：伊68～75系＋伊8、9隻級。開戦時はオアフ南方、救難・哨戒を含む。

### 注意

1941年12月艦隊表の潜水戦隊番号・一部個艦には、後の改称番号や編制時点の混在がある。個艦の実任務はTRoMで照合し、重複登録を禁止する。

## 2. 南方：第4潜水戦隊

個艦TRoMで開戦直前の実働が確認できる編制：

- 第18潜水隊：伊53、54、55
- 第19潜水隊：伊56、57、58
- 第21潜水隊：呂33、34

1941年12月初頭にサマ（海南島）等からマレー方面へ出撃。

**重要**：一部艦隊表には第19潜水隊を「伊56、伊69、伊70」とする転記/時点不整合がある。個艦履歴では1941年11月の第19潜水隊は伊56、57、58。開戦再走査では後者を作業基準とする。

## 3. 南方：第5潜水戦隊

名目：

- 第28潜水隊：伊59、伊60
- 第29潜水隊：伊62、伊64
- 第30潜水隊：伊65、伊66

ただし開戦日のAvailabilityは大きく異なる。

- 伊59：神戸側で整備中。12月8日のマレー哨戒へ算入しない。
- 伊60：近代化工事中。12月8日のマレー哨戒へ算入しない。
- 伊62、64：12月5日にサマを出撃、トレンガヌ方面哨戒線へ。
- 伊65、66：12月5日に出撃、マレー上陸掩護・哨戒へ。

したがって第5潜水戦隊は「名目6隻＝即応6隻」としない。開戦マレー方面の確定実働は少なくとも4隻。

## 4. フィリピン・蘭印：第6潜水戦隊

- 第9潜水隊：伊123、伊124
- 第13潜水隊：伊121、伊122
- 母艦：長鯨

旧式機雷潜水艦4隻だが、任務は敷設・偵察・救難待機・通商/輸送線攻撃。

### 個艦状態差の例

伊123：12月6日、前部潜舵故障で潜航不能。故障状態のままBalabac方面の敷設を実施してCam Ranhへ修理帰投。

伊124：12月7日、Manila Bay沖に機雷を敷設し、その後気象通報・航空搭乗員救難待機を実施。

このため「旧式だから戦力係数0.x」の一値にはしない。敷設・偵察・救難では別の任務価値を持つ。

## 5. 中部太平洋：第7潜水戦隊

第四艦隊所属、Kwajalein基盤。

- 第26潜水隊：呂60、61、62
- 第27潜水隊：呂65、66、67
- 第33潜水隊：呂63、64、68

Wake作戦では、全9隻を同時に第一撃へ投入したわけではない。例：呂60/61/62は開戦時Kwajalein待機、第一回Wake攻撃失敗後に増援として出撃。

よって `AVAILABLE_AT_BASE` と `ON_STATION` を分離する。

## 6. 呉鎮守府・訓練/予備

1941年12月艦隊表には呉鎮守府配下として呂57、58、49、および伊52が記載される。

これらを作戦潜水艦総数には含めても、開戦日戦域投入隻数へ自動算入しない。

## 7. 再走査の開戦状態フィールド

各艦について最低限：

- `hull_id`
- `class_generation`
- `nominal_parent`
- `actual_parent`
- `location_1941_12_07`
- `availability`: READY / AT_SEA / SHORT_REPAIR / LONG_REPAIR / MODERNIZATION / TRAINING / RESERVE
- `mission`
- `mission_start`
- `on_station_eta`
- `fuel_state`
- `torpedo_state`
- `mine_state`
- `aircraft_or_midget_payload`
- `mechanical_state`
- `crew_experience_band`
- `contact_reports`
- `attack_opportunities`
- `reacquisition_opportunities`
- `return_eta`
- `next_ready_eta`

## 8. 旧スイッチの解除

開戦再走査では以下を入力にしない。

- 「日本潜水艦は艦隊決戦専用で通商破壊をしない」という一括教義。
- 後年のGuadalcanal輸送任務拘束。
- 潜高第3ロットの建造決定。
- 遣独潜水艦の個別航海成功/失敗。
- 1942年以後の戦域別配当。

これらは、開戦からの観測・損耗・作戦需要・可用隻数から再決定する。

## 9. 次の閉鎖事項

1. 第1～3潜水戦隊28隻級について、12月7日夜の個艦missionを全艦に付与。
2. 第4/5潜水戦隊の南方哨戒線を日付・海域で閉じる。
3. 伊121～124の機雷搭載量・敷設地点・修理時計を閉じる。
4. Wake用第7潜水戦隊を第一撃/増援/待機に分ける。
5. 開戦直前の工廠在泊艇・訓練艇を作戦投入不能として明記。
