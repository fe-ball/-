# Pearl Harbor 実行状態 v0.03 — bounded causal rerun

v0.02 の `UNKNOWN_NOT_CREDITED = historical lock` は廃止する。

米側の配置、警戒、指揮判断、Enterprise の位置・行動、天候、攻撃目標選択、第三波を実施しない意思決定は、先行因果がない限り史実殻を維持する。

日本側は現行世界設定をそのまま入力する。空母六隻の甲板・格納庫枠と作戦計画は増量しない。差分は主として瑞星零戦、瑞星B5N、1941年後期D3A、九一式航空魚雷の投下・入水・ロット均一性、爆撃・射撃の再現性、故障・帰投・着艦状態に現れる。

実行中心線：
- 有効攻撃参加 353機、感度帯352～354機。
- 日本側不可逆損失 中心28機、帯27～29機。
- 九一式航空魚雷命中：史実約20本級に対し21～24本、中心23本。
- 800kg級水平爆撃命中：史実7～8発級に対し9～10発級。
- 250kg急降下爆撃は固定艦・施設に対して史実同条件比の相対命中改善を適用するが、個艦配賦は攻撃軸ごとに後続処理する。
- Arizona/Oklahoma の戦略結果階級は既に飽和しており基本不変。West Virginia/California も沈座級を維持する可能性が高い。追加命中の主要な作戦差は修理時計、速修復艦、巡洋艦・駆逐艦、航空基地の損傷へ出る。
- 米燃料タンク、修理工場、発電、潜水艦基地を狙う第三波は発生しない。

Enterprise は 0615 時点で Oahu 西方約215海里、18機SBDの進出行動を史実同様とする。日本側性能差に反応する交戦だけ再評価し、Enterprise 本体の発見・攻撃は発生しない。
