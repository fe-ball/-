# 再走査開始状態 1941-12-07夜 v0.04

## 0. 用途

これは1941年12月8日以後を状態遷移で再走査するための初期状態パケットである。旧戦史の1941-12以後の損耗・勝敗・修理時計は入力しない。

状態は `CLOSED / AMBER / OPEN` の三段階で表示する。

- **CLOSED**：現行正本で再走査入力として使用可能。
- **AMBER**：中心帯はあるが、個艦/個隊/人員分布へ落とす必要がある。
- **OPEN**：後続ハンドオフ自身が未処理と明示、または正本に必要台帳がない。

## 1. 航空総量――CLOSED/AMBER

現行正本 `50/90` の開戦時中心帯：

| 区分 | 1941-12-07夜 |
|---|---:|
| 陸軍戦術機 | 1,475–1,600 |
| 海軍戦術機 | 1,375–1,450 |
| 合計 | **2,850–3,050** |
| 史実相当からの純増 | 225–425、約9–16% |
| 旧型→新型置換 | 450–650 |
| 可動率・任務完遂改善 | 200–350機相当 |
| 予備機増 | 100–200級 |
| 第一線実効作戦出力 | 史実相当比 **+15–25%** |
| 反復する陸上基地戦 | 旧仮説 **+20–35%** は出力候補へ降格。日次状態遷移から再計算 |

重要：この「実効作戦出力」は戦闘損失倍率ではない。故障、集合、航法、整備、反復出撃等の複合結果として作戦ごとに展開する。

### 陸軍主要状態

- 百式戦闘機一型：実戦使用可能 **280–380機級**、暫定。
- 改良九七戦：満洲、中国、二線、近距離制空に多数。
- 二式単戦ハ41：試験・実戦審査 **15–25機級**。
- Ki-45改：開戦時戦力に数えない。1942春以後。
- Ki-49-I：少数 **50–90機級**、暫定。

### 海軍主要状態

- 第一線空母：瑞星零戦、瑞星B5N、D3A。
- 基地陸攻：G3M、G4M初期。
- H6Kは実用、H8Kは試作/増加試作で継続戦力に数えない。
- D4Y/B6Nは開戦戦力に数えない。

## 2. 空母航空戦力――CLOSED

`60` の開戦時任務別統合値：

| 艦群 | 実用航空機 |
|---|---:|
| 主力六空母 | 390–410 |
| 龍驤 | 36–40 |
| 瑞鳳 | 27–30 |
| 祥鳳 | 18–24 |
| 大鷹を戦闘運用 | 18–24 |
| 鳳翔 | 12–18、主に訓練 |

鳳翔訓練/回送分を除く戦闘使用可能総量は **490–525機**。史実相当455–475に対し+35–60、+7–13%。

ただし大鷹を戦闘使用すると、一航海あたり補充機20–30機級の回送任務を失う。したがって「戦闘使用可能」と「常時前線投入」は別状態にする。

祥鳳は1941年10–11月竣工中心で、真珠湾主力機動部隊に混ぜる教育完成度はないが、南方・台湾・Palau・回送/船団援護には使える。

## 3. 航空人員――追跡規約CLOSED、初期人数分布OPEN

### 開戦初日から追うコホート

搭乗員・航空直接整備員を、最低限次の状態で持つ。

- 所属：海軍/陸軍、航空隊、母艦/基地/後方。
- 任務資格：戦闘、爆撃、雷撃、偵察、航法、編隊指揮、艦上昼間、艦上第一線等。
- 経験帯：初任、部隊経験、実戦経験、経験核。
- 可用状態：即応、疲労、軽傷、重傷/療養、転属中、教育/試験、新編隊勤務。
- 移動履歴：戦傷、艦修理、機体受領、転属、再編、新編、救助。

### 開戦時に**付与しない**もの

- 1943型の意図的な練度平準化。
- 空地分離による自由な飛行隊再配置。
- 1943以後の経験核配分制度。
- 1944型専任空輸。

### 開戦時から**起こり得る**もの

- 負傷・療養からの復帰。
- 修理艦・再編航空隊からの人員移動。
- 補充機受領や転属で経験者が別組織を通過すること。

この自然移動は「制度スイッチ」ではなく、戦争状態の通常遷移である。

**不足**：1941-12-07時点の搭乗員/整備員を資格・経験帯別に置いた人数台帳は現行正本に未閉鎖。Pearl/Malayaの初回遷移では、作戦参加隊の実員から先に閉じる。

## 4. 航空技術/教範スイッチ――CLOSED

### 開戦時ON

- 九一式航空魚雷：1941 H1までに部隊標準化・投下表整備。技術的散布/投下・入水誤差は史実同条件比15–30%縮小中心、総合実戦雷撃命中は同条件で相対10–25%向上の作業帯。
- 瑞星系列など現行機体の開戦時性能・成熟段階。
- Type 2中央暗号計算所による中央設計監査、統計、交通分析。
- 水上魚雷の再装填信頼性改善と第二攻撃教範。

### 開戦時OFF/前駆のみ

- 推力式単排気管の量産効果：OFF。1941は台上/少数飛行試験。
- レーダーfighter-direction/射撃I-O閉ループ：OFF。1941末～42初は実用試験・粗警戒の前駆。
- 後期多層CAP、成熟した多軸防空飽和研究：OFF。
- 陸軍航空基地機動：**OPERATIONAL_PARTIAL**。飛行部隊とは別の航空地区部隊・飛行場大隊・修理補給・輸送等を既に持つが、滑走路・排水・燃料・弾薬・工具・地上輸送に拘束される。
- 海軍航空の空地分離：**LATENT**。基地転進摩擦を観測する。
- 陸海軍共通基地標準化：**LATENT**。

## 5. 海上輸送・揚陸――CLOSED/AMBER

`60` の開戦時差は、新造標準船の大量増ではなく既存船運用の改善。

| 指標 | 開戦時作業帯 |
|---|---:|
| 一航海の有効軍需輸送 | +4–8% |
| 月間輸送回転 | +5–10% |
| 選別第一線船団 | +10–15%の場合 |

効く箇所：積載、トリム、復原、デリック、ハッチ、舟艇、港湾滞在、修理優先順位。

戦時標準船の本格的な船腹量効果は **1942春～夏以後**。開戦時船腹へ足さない。

**AMBER**：総輸送改善率は閉じているが、南方作戦の各船団へ個船・港湾・揚陸能力を割り当てた状態表は作戦ごとに再構成する。

## 6. 水上艦――設計/評価規約CLOSED、開戦個艦Availability OPEN

開戦から適用する規約：

- Hull→Availability→Mission set→Mission effectiveness→Allocation。
- 損傷後機能を二値化しない。
- 後発艦の成果を、開戦時艦へ後知恵で全面retrofitしない。
- 陽炎型等の第二魚雷攻撃は、次発を即時火力へ足さず、再装填・再捕捉・射界・損傷から0/4/8本等で判定。
- 1940–42の実戦中四本再装填中心7–11分、再射撃可能な戦術サイクル12–20分級を作業線とする。

**OPEN**：空母以外の1941-12-07夜の戦艦・巡洋艦・駆逐艦について、個艦ごとの所属、現在地、整備、燃料、修理、Availabilityをまとめた正本表が現コーパスにない。Philippines/DEI水上戦へ入る前に閉じる。

## 7. 潜水艦――技術/建造時計CLOSED、開戦個艦OOB OPEN

### 既に閉じていること

- 潜高第一ロット2隻：1941 H1発注。高1=呉1941 Aug起工、高2=川崎神戸Sep–Oct起工。
- 1941 Nov追加潜水艦計画から第二ロット4隻へ艦種振替。
- 開戦時の潜高は戦闘戦力ではなく、造船/電気品/工程の機会費用としてのみ存在。
- 第一世代300-cycle電池案は撤回し100-cycle級。
- 1942–43シュノーケル前倒しは禁止。
- 潜水艦戦果は撃沈数だけでなく、出撃、到着、接触、射点、再捕捉、離脱、再攻撃、情報価値で評価。

### 未閉鎖

`97` が次作業として明示しているため、**1941-12-08時点の実在潜水艦の艦級・個艦・所属・整備状態台帳は未完成**。

初期潜水艦戦の再走査へ入る前に、この個艦OOBを新規に閉じる。後年の潜高配置を開戦時へ混ぜない。

## 8. ASW――CLOSED

開戦時は史実相当兵器をやや体系的に扱える前段階。

- 1941末～42春：鎮守府/艦隊の護衛担当幕僚強化を開始。
- 二艦協同再捕捉は経験蓄積中、標準化は1942夏。
- 局地護衛指揮所は1942夏重点線。
- 全国統合護衛組織を1942へ前倒ししない。
- 東海、カ号は開戦時戦力に数えない。

## 9. 再走査の開始順

`61` に従い、順序は次とする。

1. Pearl Harbor
2. Malaya
3. Philippines–DEI air/surface
4. initial submarine war
5. MO
6. MI
7. AL/FS
8. China / Indian Ocean / Allied shipping secondary effects

ただし「順序」は分析上のゲートであり、同日並行作戦の状態更新は実時間で同期する。Pearlの帰還搭乗員を、同時刻に既に南方へいる部隊へ瞬間移動させない。

## 10. 最初の未閉鎖項目

A. Pearl/Malayaを回すため、参加航空隊ごとの初期機数・可動・予備・搭乗員コホートを閉じる。

B. Philippines/DEI水上戦へ入る前に、日本水上艦の1941-12-07個艦Availability/OOBを閉じる。

C. initial submarine warへ入る前に、97で未処理の1941-12-08潜水艦個艦OOBを閉じる。

D. 旧85の「開戦四か月総損失325–345機」「熟練者数十～百数十名多い」は**結果候補**であり入力禁止。Pearl→Malaya→Philippines/DEIを逐次更新した結果として再計算する。

# 11. v0.02追加――後続政策は初期条件へ持ち込まない

後続正本にある以下の「現行決定」は、1941年12月7日夜の世界状態ではなく、旧戦史枝を受けた**条件付き政策**なのでOPENへ戻す。

- MI後艦上航空教育の規模。
- 雲龍/飛龍系の要求数/起工ロット。
- 千歳/千代田・伊勢/日向・信濃・伊吹等の改装/建造判断。
- 戦時型/松型駆逐艦の要求時期。
- 空地分離の試行/標準化日。
- 経験核配置・練度平準化・専任空輸の日付。
- 潜高第三ロット。
- 局地/全国護衛組織の成熟日。

技術的に可能な選択肢・研究成果は残すが、再走査でトリガーが成立するまで選択済みとしない。


## 12. v0.03訂正――マレー再走査前のサービス別制度状態

- `IJA-AIR-BASE-MOBILITY = OPERATIONAL_PARTIAL`。1941年12月のマレーで航空地区部隊・飛行場大隊・修理補給廠・航空輸送が前進する実績を初期能力として認める。
- `IJN-AIR-GROUND-SEPARATION = LATENT`。陸軍の状態を海軍へ自動コピーしない。
- `JOINT-BASE-STANDARDIZATION = LATENT`。工具、部品、燃料弾薬、受入基地手順等の共通化は将来の観測依存スイッチ。
- 旧「マレー配当760～840機」は `SOUTHERN_AIR_POOL_HYPOTHESIS` へ降格し、直接戦力として使わない。


## 13. v0.04追加――開戦前の戦域集中損耗を初期状態へ含める

国全体在庫と戦域到着戦力を分離する。第3飛行集団では、11月15日以後の南方集中そのものに悪天候・夜間・強制着陸等の損耗があり、戦後記録は開戦後331機とは別に集中中46機損失を記す。

したがって、Malayaの12月8日開始状態は `NATIONAL_INVENTORY → PLANNED_CONCENTRATION → ARRIVED_FORWARD_AREA → SERVICEABLE_ON_EVE_OF_WAR` を経て作る。

性能・練度・航法・整備の差はこの集中段階から作用し得る。46機へ一律削減倍率は掛けず、原因が確認できる事故から対応可能性を判定する。
