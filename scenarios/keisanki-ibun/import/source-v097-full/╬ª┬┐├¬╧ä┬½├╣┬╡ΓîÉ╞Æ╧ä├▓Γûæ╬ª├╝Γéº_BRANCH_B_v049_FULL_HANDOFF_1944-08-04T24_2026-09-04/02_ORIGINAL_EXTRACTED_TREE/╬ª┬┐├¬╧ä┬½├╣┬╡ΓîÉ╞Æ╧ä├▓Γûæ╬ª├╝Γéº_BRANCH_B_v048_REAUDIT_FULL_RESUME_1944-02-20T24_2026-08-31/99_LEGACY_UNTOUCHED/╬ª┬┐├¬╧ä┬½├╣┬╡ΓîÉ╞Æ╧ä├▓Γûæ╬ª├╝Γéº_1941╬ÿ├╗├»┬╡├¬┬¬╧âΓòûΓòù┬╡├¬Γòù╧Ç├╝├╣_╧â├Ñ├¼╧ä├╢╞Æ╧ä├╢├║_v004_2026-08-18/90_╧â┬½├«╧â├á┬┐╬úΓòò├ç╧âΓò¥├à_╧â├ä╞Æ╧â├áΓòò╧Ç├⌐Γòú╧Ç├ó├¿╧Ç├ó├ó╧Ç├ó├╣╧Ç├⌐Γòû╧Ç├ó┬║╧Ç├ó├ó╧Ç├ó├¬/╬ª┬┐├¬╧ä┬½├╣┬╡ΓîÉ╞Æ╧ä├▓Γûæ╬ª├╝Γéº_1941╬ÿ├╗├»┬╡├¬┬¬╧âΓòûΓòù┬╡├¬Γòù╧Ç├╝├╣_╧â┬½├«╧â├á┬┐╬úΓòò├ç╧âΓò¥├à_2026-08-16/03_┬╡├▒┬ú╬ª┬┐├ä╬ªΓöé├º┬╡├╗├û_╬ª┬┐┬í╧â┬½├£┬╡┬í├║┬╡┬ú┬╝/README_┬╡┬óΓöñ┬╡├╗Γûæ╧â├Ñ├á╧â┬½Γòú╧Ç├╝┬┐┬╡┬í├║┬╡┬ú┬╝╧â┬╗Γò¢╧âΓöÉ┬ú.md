# 計算機異聞・2026-08-15 全更新パッケージ r30

## 1. 現在地

**1944年7月7日夜、航空機HARD監査継続中。**

r24 FORAGER戦果は比較枝。44/45/46で戦術研鑽、空地分離、人員循環・練度平準化を処理した後、戦闘入力となる機体性能自体に未監査値が多いことが判明したため、47の技術監査へ戻っている。

r30では、推力式単排気管に続き、瑞星後期零戦、金星零戦改、誉／紫電改、ハ43／烈風、B6N護型／火星比較までを機体HARD一巡として正本へ戻した。

## 2. r30主要上書き

- `53`：瑞星後期零戦を52型相当の独立仕様として再構築。
- `53`：金星零戦改を3.25～3.32t級へ修正し、上昇・航続・艦上進入を再計算。
- `53`：誉の量産中央値・整備負担を明示し、紫電改の上昇を下方修正。
- `53`：ハ43の実用出力時計、3.85～3.90m四翅、烈風の5t級艦上設備制約を統合。
- `52`：B6N護型を護主線・火星保険枝とし、1943年初の耐久・50機級統計・交換率・燃費で採用判定。
- `47`：上記の監査進捗を記帳。次はD4Yと横断装備HARD、その後REAL-WORLD QUALITY。
- `118`新設：今回の航空機HARD中間統合。
- `119`新設：**現行最新引継ぎ**。D4Y監査前の停止点。
- `00`：最新索引を119へ更新。

## 4. 航空運用・練度側

45・46は既に、

- 激戦・大量損耗が発生していない期間へ史実の練度崩壊を自動適用しない。
- 戦傷、療養、母艦修理、再編、補充機受領、新編隊から自然還流を作る。
- 空地分離で飛行隊・直接整備員を可搬化し、経験核を再配置する。
- 平均技能を一律上昇させず、部隊単位の下側リスクを削る。

という形へ修正済み。r30ではここを重複更新せず、航空機HARD側との接続だけ47/118へ明記した。

## 5. 次作業

**D4YのHARD監査。**

アツタ高度別実用出力、燃費、冷却、耐久、量産中央値、プロペラ、ラジエータ抵抗、主翼・尾翼捩り、制動板、爆弾分離、艦上重量・進入速度、偵察型先行時計を閉じる。

その後、20mm/13.2mm、防護・防火・部分防漏、無線・航法・酸素・照準器の横断HARDを閉じ、REAL-WORLD QUALITYへ進む。

# 計算機異聞・2026-08-14 全更新パッケージ r28

## 1. 現在地

**1944年7月7日夜、FORAGER再計算前。**

r24のFORAGER戦果は比較枝。r25～27で戦術研鑽、空地分離・防空対抗研究、航空人事循環・練度平準化を追加した。r28では、それらを載せる機体側に暫定値が残ることを明示し、航空機技術の史実発生・採用・量産時計を先に閉じる再監査ゲートを新設した。

## 2. r28主要上書き

- `47`新設：史実技術発生→本世界トリガー→試験→採用→量産→retrofit→部隊中央値の監査形式を固定。
- 金星零戦改、烈風＋ハ43、B6N護型、誉量産中央値を高優先監査に指定。
- 推力式単排気管、プロペラ、水メタノール、防護、防漏、防火、無線、照準器、20mm/13.2mmを「小改良だから無視」せず、任務閾値を動かす入力として監査。
- 50～53の暫定性能値は作業値として保持するが、47が閉じるまで1943～44年大会戦の最終戦果に直接使用しない。
- ソフト・ヒューマン側44/45/46は機体監査後に結合する。
- 太平洋戦史の再走査起点はMI直後を第一候補とし、1941～42前半機体値が大きく動けばMO/MIへ巻き戻す。

# 計算機異聞・2026-08-14 全更新パッケージ r27

## 1. 現在地

**1944年7月7日夜、FORAGER再計算直前。**

r24の7月8～15日戦果は比較枝。r25で戦術研鑽・組織学習、r26で空地分離・航空隊可搬化・敵艦隊防空の対抗研究を追加し、r27で熟練者の自然還流・人員撹拌・練度平準化を追加したため、FORAGERは未再確定。

## 2. r27主要上書き

- `46`新設：戦傷・療養、母艦修理、航空隊再編、補充機受領、新編隊・新造空母配員による熟練者の**自然還流**を正本化。
- MI後の経験還流を、最初から固定教官ローテーションで説明せず、自然還流→撹拌→練度差可視化→平準化→限定的意図還流の順へ修正。
- 空地分離を航空隊機動だけでなく、人員再配置と技能拡散の基盤として45と接続。
- 史実の戦闘搭乗員による補充機フェリーを自然循環経路として採用し、記録比較から1943年後半に専任空輸試行、1944年初頭～春に機能標準化する中心線を追加。
- `50`の「5～10%教官還流」固定中心を撤回。純教育目的で同時に外す熟練者は1943年以後3～7%級感度。別に自然還流者を数える。
- 練度平準化の主効果は平均技能上昇ではなく、極端に弱い新編隊、艦上資格ミスマッチ、部隊間手順差を削ること。
- FORAGERでは46を命中率へ加算せず、攻撃セルの集合・航法・通信・任務継続失敗、別母艦/基地への再配置遅延へ反映する。

## 3. 現行優先順位

- 方法論：`00`。
- 戦術研鑽：`44`。
- 航空運用制度・攻防対抗戦術：`45`。
- **航空人事循環・練度平準化：`46`。**
- 技術→戦術：`61`、艦艇評価：`62`。
- センサー・射撃I/O：`30`。
- 航空：`50`、`52`、`53`。
- FORAGER実艦：`38`、`39`、`42`。
- r24比較枝：`43`。
- 最新継続状態：**`114`**。

## 4. 次作業

1944年7月7日夜から再開する前に、各航空群の艦上資格・夜間・航法・編隊長・無線・整備の経験核を台帳化する。その後、空地分離・人員平準化を反映した7月8～10日の基地航空保存と、7月11日の分散セル型攻撃を「発進→集合/航法→CAP→AA→終末攻撃」の順で閉じる。
