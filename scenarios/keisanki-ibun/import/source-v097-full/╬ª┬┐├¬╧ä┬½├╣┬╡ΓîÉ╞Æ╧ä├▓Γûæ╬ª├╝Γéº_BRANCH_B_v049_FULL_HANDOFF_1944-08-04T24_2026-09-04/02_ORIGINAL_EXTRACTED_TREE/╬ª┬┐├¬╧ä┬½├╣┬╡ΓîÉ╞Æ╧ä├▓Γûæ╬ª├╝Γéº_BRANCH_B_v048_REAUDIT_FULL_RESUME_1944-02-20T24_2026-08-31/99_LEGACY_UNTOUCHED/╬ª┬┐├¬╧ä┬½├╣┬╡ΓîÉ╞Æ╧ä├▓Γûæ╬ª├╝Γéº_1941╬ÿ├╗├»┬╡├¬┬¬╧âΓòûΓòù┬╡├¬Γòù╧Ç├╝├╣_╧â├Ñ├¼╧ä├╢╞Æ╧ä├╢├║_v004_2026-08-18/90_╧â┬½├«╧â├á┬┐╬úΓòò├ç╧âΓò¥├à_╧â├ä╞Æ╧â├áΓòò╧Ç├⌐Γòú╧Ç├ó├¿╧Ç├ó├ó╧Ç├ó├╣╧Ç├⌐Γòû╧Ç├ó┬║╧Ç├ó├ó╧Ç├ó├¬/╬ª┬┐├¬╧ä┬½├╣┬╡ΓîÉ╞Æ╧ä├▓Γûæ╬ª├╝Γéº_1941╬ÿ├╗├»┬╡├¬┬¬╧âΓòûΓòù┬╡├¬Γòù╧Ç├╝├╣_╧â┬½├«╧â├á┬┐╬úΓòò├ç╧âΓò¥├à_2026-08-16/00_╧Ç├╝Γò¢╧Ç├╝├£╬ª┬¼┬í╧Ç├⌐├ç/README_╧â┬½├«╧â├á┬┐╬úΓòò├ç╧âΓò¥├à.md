# 計算機異聞 1941開戦巻戻し・完全一式

作成日: 2026-08-16

## 現在の研究起点

本流は「1941年12月以後の戦果を旧枝から固定せず、開戦初期状態から状態遷移で再走査する」方針。

今回の巻戻しで重視するのは、細かな空戦機動の最適化ではなく、以下の大きな状態変化である。

- 機体性能と実可動率
- 搭乗員・整備員の生残、負傷、自然還流、経験核の撹拌
- 補充人員の質と低練度尾部
- 航法、集合、基地移動、侵入、作戦距離
- 陸軍・海軍で異なる空地分離／基地機動
- 基地容量、燃料、増槽、整備、輸送
- 潜水艦・水上艦のHullではなくAvailabilityと任務配分
- 後続で固定された制度・建造・再配置スイッチを、旧戦史枝から切り離して再判定

- `04_参考枝_旧WIP/`：空戦ミクロ、sortie regeneration、FORAGER再接続など。現在の本流ではない。部品・失敗例・検証結果の参照用。

## 重要な状態

後続資料で成立した因果モデルそのものは捨てない。ただし、旧戦史枝に依存した「何年何月に制度化した」「何隻建造した」「どこへ何機再配置した」といった日付・量は原則として再計算対象。

自然還流は開戦後に突然ONになる制度ではなく、損耗・療養・修理・補充・転属を通じて開戦時から発生する状態遷移として扱う。意図的な練度平準化や熟練核配分は別の制度ゲートとして後から判定する。

陸軍航空の基地機動・地上支援組織と、海軍航空の後年型空地分離は別時計で扱う。

## 次の実行点

南方航空集中（1941-11-15～12-07）を前置き状態として持ち、1941-12-08以後のマレー、真珠湾、フィリピンを並行した状態遷移へ入れる。

旧「第一線実効出力+15～25%」のような総括倍率を入力に戻さず、機体・可動・人員・基地・補給の積み上げから差を出す。
