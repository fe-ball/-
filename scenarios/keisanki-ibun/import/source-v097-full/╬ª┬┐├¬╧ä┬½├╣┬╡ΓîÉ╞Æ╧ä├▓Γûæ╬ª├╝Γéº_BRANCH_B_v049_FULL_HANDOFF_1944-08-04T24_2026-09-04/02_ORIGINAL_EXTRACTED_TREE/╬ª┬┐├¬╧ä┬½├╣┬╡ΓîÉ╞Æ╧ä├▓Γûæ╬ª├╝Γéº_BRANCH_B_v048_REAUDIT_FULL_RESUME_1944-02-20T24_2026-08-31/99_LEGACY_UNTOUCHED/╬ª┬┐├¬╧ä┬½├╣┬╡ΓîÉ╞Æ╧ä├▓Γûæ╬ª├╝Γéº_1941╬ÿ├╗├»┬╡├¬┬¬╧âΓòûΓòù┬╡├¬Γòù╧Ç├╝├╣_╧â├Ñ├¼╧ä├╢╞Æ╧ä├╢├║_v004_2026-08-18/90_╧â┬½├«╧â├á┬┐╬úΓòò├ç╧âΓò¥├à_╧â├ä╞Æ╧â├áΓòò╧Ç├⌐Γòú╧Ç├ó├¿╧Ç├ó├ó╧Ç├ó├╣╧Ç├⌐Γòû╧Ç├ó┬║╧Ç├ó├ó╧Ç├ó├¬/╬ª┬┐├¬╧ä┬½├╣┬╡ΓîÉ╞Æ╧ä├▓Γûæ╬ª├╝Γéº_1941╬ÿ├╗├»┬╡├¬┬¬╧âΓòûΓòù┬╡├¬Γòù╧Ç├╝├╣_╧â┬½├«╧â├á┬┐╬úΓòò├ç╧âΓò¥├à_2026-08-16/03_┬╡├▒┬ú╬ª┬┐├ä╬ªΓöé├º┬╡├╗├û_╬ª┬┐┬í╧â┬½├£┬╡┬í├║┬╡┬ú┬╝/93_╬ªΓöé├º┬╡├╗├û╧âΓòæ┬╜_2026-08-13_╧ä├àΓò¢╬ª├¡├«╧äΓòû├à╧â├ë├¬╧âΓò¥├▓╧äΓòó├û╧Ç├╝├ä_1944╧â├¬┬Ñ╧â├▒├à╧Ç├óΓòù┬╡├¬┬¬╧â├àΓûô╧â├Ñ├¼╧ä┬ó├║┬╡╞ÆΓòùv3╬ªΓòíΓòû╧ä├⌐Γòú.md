# 計算機異聞・現行総合引継ぎ――1944初夏・戦史再監査v3起点

本書は92を履歴として残し、2026年8月13日現在の最新継続状態を要約する。技術数値は10～70、艦艇実効戦力の横断規約は62、現行歴史線は85→86→87→88→89を優先する。

# 1. 最重要更新――戦史再監査v3

1944年7月直前まで歴史を進めた過程で、**水上艦艇を有効活用する観点が歴史モデルから脱落**していたことが判明した。

設定側には既に、

- 金剛型四隻の成熟改装・30kt級実用速力。
- 大和・武蔵の計算援用、射撃・損害制御・電力・区画の成熟。
- 重巡・駆逐艦の高い稼働性。
- 九三式魚雷の艦別較正。
- 再装填6～9分級、発射から第二射撃解12～20分級。
- 第一群発射・離脱・再装填、第二群接触維持、第一群再突入という水雷戦教程。
- 潜高等の水中中心潜水艦。

がある。

これらを空母航空の補助・護衛へ縮約するのは不整合。以後62を正本とし、**Hull count × Availability × Mission effectiveness × Coordination × Situation**で任務別に評価する。

旧10の「金剛型有効戦力＋7～12％」等は単軸改装値であり、射撃・I/O・電探・防御・可動率・編成まで含む艦全体任務実効値の上限ではない。後期戦闘艦は特定任務で史実同世代比1.4～1.7級、条件次第で1.8～2.0級も監査対象。潜水艦は閾値効果により2倍級以上も条件付きで許容する。

# 2. 米側の認識も手戻りする

米軍は日本水上艦隊を知らないわけではない。

- 金剛型等、公知艦級の存在は概ね把握。
- 大型の脱条約戦艦が存在することも史実同様に認識。
- 日本海軍が決戦を企図する思想も既知。
- Marianas級侵攻なら日本艦隊来援を高確率で予想する。

したがってFORAGER計画は最初から日本水上主力の突入可能性を入れ、Lee高速戦艦群、上陸支援戦艦、巡洋艦・駆逐艦、潜水艦、航空索敵を配置する。

一方、米側が割り引きやすいのは、計算・較正・I/O、被害制御、重量・電力余裕、第二斉射の再現性、1944年型対空体系等の**内部能力**。存在は知るが「1942年に戦った日本艦の延長」程度に見る余地を残す。

大規模海戦のレーダー差は万能勝敗補正にせず、「何分早く安定した状況認識・射撃解・CAP誘導へ入るか」として扱う。艦隊防空では米側閉ループ優位を大きく残す。

# 3. 現行時計を1944年6月10日へ戻す

Marshall～Palauの中心結果は保持する。日本水上主力を固定基地救援へ投入しなかった理由が成立しているため。

一度走らせた6月10日～7月4日のFORAGER枝は、晴嵐初撃・Marianas航空制圧等の候補案として89へ保存するが、**現行史線としては非固定**。

次回は6月10日夜から再開する。

# 4. Marshall戦役確定作業線

米Marshall主攻はKwajalein＋Majuro。2月20日周辺島/Majuro、2月21日Roi-Namur/Kwajalein。

日本Marshall本体約27,350＋Kusaie約4,000。Kwajalein約8,500。前進航空約155機、潜水艦約12。

2月16～20日前哨戦：日本航空約87全損、米約31。日本潜水艦がAKA1大破、日本潜1沈没。米大型空母重大被害なし。

Majuro2月20日占領、米45～65死傷。

Kwajalein/Roi-Namur 2月21～27日：米地上総死傷約2,700、戦死580～630。日本7,000～7,300戦死、750～900捕虜・重傷捕獲。2月27日夕刻、環礁全体の組織戦終了。

翔鶴・瑞鶴・飛龍は温存。

# 5. Truk・Eniwetok・Palau

3月5～6日HAILSTONE相当。日本は重要艦・船を事前退避し、航空75～95、商船・補助艦4～7万GRT級を失う。Truk陸上施設は大損害、艦隊基地機能を失う。

3月11～14日Eniwetok。米地上1,150～1,300死傷、日本1,950～2,050戦死。日本潜水艦がLST1大破後に沈没。Wotje/Maloelap/Mili/Jaluitは迂回・孤立。

4月15～17日Palau/Yap/Ulithi/Woleai空襲。日本航空50～60、商船・補助艦1.5～2.5万GRT級。航空機雷戦訓から固定環礁泊地への長期艦隊集中をさらに避ける。

# 6. 1944年型日本戦力

- 大鳳：3月末～4月初頭に実戦域。
- 翔鶴・瑞鶴・飛龍・大鳳：主力4空母。
- 隼鷹・飛鷹・龍鳳・龍驤・瑞鳳・祥鳳等を含め最大10空母級を保有するが航空隊律速。決戦時に信頼できる艦載航空420～460機級を中心。
- 彩雲：1944年1～2月限定実戦配備済み。Marshall前進2～4機。
- 銀河：3月末～4月初に第一実戦隊18～24機級。
- 紫電改：3～4月最初の実戦隊。
- 流星：初期生産、2月戦闘0。大鳳が最初の全面運用母艦候補。
- 雲龍・天城：6～7月完成中心。葛城8～9月。

# 7. 伊400／晴嵐

20の技術正本：伊400 1944年1月就役、3～4月航空込み戦闘即応。伊401 4月就役、5～6月即応。伊402 7～8月就役、9～10月即応。発注上限6隻。晴嵐総生産目標50～55。

山本生存下の運用中心：

- 象徴的米本土爆撃ではなく、敵次作戦の前進兵站を壊す深部作戦兵器。
- 停泊空母、AO、AR、AE、APA/AKA/LST、燃料・弾薬・修理施設を遅延価値で順位付け。
- 三機で奇襲を浪費せず、伊400＋401六機を最小有力単位。
- 5月25日前後六機合同演習成功、5月28日戦闘即応。
- 晴嵐は通常索敵に浪費せず、彩雲・大艇・潜水艦・通信情報で目標作成。
- 浮舟を通常維持し、攻撃後は別水上機基地へ逃がす選択を優先。無浮舟一方攻撃は例外。
- 6月10日時点ではまだ初撃していない。旧枝の6月30日Eniwetok攻撃は再判定対象。

# 8. 中国・Burma

史実型U-Go/Imphalは実施しない。限定圧力に留める。

5月6日、武漢―長沙―衡陽―桂林/柳州方向の華中春季攻勢を発動。第一線7～9個師団級。南京政府側へ鉄道・都市・後方警備をより多く移管。

6月8日中心、長沙占領。ただし中国主力包囲には失敗。5月6日～6月9日、日本1.0～1.3万、中国3.2～4.2万死傷・捕虜中心。衡陽へ再編中。

5月17～19日、Y-Force Salween渡河。日本がU-Goで消耗していない一方、重慶側も華中へ兵力を取られ、未決着。

# 9. OVERLORDと米人的余裕

OVERLORDは6月6日、五海岸・空挺・第一撃はほぼ史実規模。差は余裕に出る。

- 初撃：史実98～100％。
- 6月末までの後続兵站：95～97％級。
- 戦略予備：90～95％級。

米国の工業力は巨大だが、訓練済みライフル兵・NCO・下級将校は相対的に薄い。Pacificで地上損耗が史実より増えた分、Europeの歩兵補充危機が数週早く出る可能性を残す。

将来検討：bocage、Mortain、Lorraine、Hürtgen、Ardennes、NORDWIND等で、史実では立て直した部隊の回復が数日～数週遅れる可能性。結果は未固定。

# 10. 現在地点――1944年6月10日夜

日本：

- Marianas主攻95％以上、Saipan第一70～80％と推定。
- 空母、基地航空、潜水艦、晴嵐に加え、**水上艦隊を独立作戦軸として再設計する段階**。
- 水上主力の個艦台帳・任務係数未監査。

米国：

- FORAGER準備継続。Europe上陸とPacificを同時遂行。
- 日本決戦艦隊来援を前提に対水上戦力を配するはず。
- 日本艦の存在・大枠は把握するが、内部体系能力は過小評価し得る。

# 11. 次回の最優先順

1. 陸奥事故を含む**1944年6月10日の日本水上艦個艦台帳**。
2. 米FORAGER個艦台帳とLee battle line、上陸支援戦艦、巡洋艦・駆逐艦、潜水艦、AO/APA/AKA/LST。
3. 62を用いた戦艦・重巡・駆逐艦・潜水艦の任務係数。
4. 日本側の多層決戦案：基地航空、空母航空、高速戦艦前衛、第二斉射水雷戦、主力戦艦打撃、潜水艦、晴嵐。
5. 米側がそれを知っている前提でFORAGER日付・配置を再計算。
6. その後に6月11日以後を進行。

**禁止：** 旧枝の7月4日からそのまま戦闘を再開しない。まずv3再監査を閉じる。
