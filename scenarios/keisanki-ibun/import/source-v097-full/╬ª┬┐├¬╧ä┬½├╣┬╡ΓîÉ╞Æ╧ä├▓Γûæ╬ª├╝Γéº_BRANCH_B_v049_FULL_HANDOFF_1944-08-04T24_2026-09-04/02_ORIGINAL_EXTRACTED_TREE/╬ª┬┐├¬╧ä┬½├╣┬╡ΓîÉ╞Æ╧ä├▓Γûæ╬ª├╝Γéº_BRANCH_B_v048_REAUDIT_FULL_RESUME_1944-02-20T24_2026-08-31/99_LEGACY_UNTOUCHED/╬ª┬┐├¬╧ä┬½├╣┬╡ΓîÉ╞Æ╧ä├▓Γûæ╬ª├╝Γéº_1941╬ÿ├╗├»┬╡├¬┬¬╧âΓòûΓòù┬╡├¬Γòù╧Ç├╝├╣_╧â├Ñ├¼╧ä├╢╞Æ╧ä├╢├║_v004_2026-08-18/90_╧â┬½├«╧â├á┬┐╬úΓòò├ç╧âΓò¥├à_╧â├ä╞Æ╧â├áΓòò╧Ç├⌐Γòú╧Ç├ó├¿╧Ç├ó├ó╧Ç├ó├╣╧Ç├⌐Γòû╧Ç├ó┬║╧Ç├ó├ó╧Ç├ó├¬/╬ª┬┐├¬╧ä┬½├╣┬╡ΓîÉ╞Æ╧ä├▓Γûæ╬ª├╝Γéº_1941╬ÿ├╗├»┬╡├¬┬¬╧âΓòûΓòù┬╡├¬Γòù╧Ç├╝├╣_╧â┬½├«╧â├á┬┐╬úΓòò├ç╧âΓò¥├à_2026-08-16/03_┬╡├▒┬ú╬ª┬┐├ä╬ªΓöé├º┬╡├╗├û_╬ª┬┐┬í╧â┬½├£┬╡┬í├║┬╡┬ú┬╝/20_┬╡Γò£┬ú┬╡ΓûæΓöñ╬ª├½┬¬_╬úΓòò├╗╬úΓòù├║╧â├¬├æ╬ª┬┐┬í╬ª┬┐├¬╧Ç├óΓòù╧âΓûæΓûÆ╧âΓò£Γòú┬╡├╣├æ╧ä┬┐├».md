# 計算援用潜水艦設計

共通方法論は00を参照する。本書では潜水艦固有の重量・浮量・トリム、圧力船殻、電池、静粛性と、技術時計・要求時計・資材時計を扱う。

旧版「03_潜水艦_世代別計算結果と就役前倒し.md」（本一式には同梱しない）は、本書の原版とほぼ同一なので正本から外す。

# 1. 潜水艦への関与時期

- 1932～33年：研究・既成設計検算。
- 1934～35年：艦政本部で正式利用。建造中艦・既成艦の再計算。
- 1936～38年：新型の基本設計から利用。
- 1939～42年：水中船型、静粛性、深度制御、高速潜水艦へ。

艦級対応：

- 海大5型：完成後の表・運用資料。
- 海大6型a：建造中監査。
- 海大6型b：詳細設計援用。
- 巡潜3型：過渡的全体援用。
- 海大7型・甲乙丙型：基本計画からの本格援用。
- 潜高型：水中中心思想へ転換。

# 2. 潜水艦で特に効く計算

## 2.1 重量・浮量・トリム

- 水上・水中排水量。
- 予備浮力。
- 燃料、清水、食料、魚雷消費。
- 発射後補水。
- 航空機搭載・発進後。
- 前後トリム。
- 潜航・浮上過渡状態。

陸上計算の成果は、トリム表、発射後補水表、潜航盤として艦へ載る。

## 2.2 圧力船殻

- 円筒殻、肋骨、隔壁、ハッチ、司令塔、発射管、格納筒開口。
- 安全率の均一化。
- 真円度・製造誤差への感度。

単純化した弾性座屈近似では耐圧が板厚の三乗に近く比例する。ただし実際は真円度、肋骨、開口、接合、残留応力が律速するため、深度向上を板厚計算だけで決めない。

計算機だけで深度を上げない。材料、溶接、X線検査、実物区画圧壊試験、段階公試が必要。

## 2.3 潜航時間

- タンク容量。
- ベント断面。
- 上構残留空気。
- 前後注水差。
- 潜舵力。
- 艦速・操作順。

最高記録より、繰り返し同じ時間で潜れることを重視。

## 2.4 電池・電動機

- 速力別消費電力。
- 電圧降下、温度、補機負荷。
- 充電計画。
- 静粛速力。
- 使用可能容量。

初期効果は電池化学の飛躍ではなく、同じ電池の使い切りと寿命管理。

## 2.5 振動・静粛性

- 軸系・ディーゼル爆発次数。
- 電動機、ポンプ、プロペラ翼通過周波数。
- 機器台共振。

1934～36年：共振回避。

1936～38年：防振支持。

1938～40年：水中音を実測。

1940年以降：周波数別静粛化。

# 5. この世代の派手さ

甲乙丙型世代の代表的な史実比：

- 水上速力＋0.3～0.4kt。
- 水中速力＋0.15～0.2kt。
- 水上航続＋8～9％。
- 水中持続＋7～10％。
- 潜航時間10～15％短縮。
- 安全深度＋10m。
- 初期機関故障20～35％減。
- 同型艦ばらつき30～50％縮小。

個別には中程度だが、一艦が同時に持つため性能表・乗員体感・艦隊稼働率へ同時に現れる最初の派手な世代。

ただし思想はまだ水上高速・長航続中心で、水中最高速は8kt台。

# 6. 潜高型の前倒し

## 6.1 二つの時計

### 技術時計

設計、検算、試験解析、図面修正、後続艦反映。

計算機が強く効く。

### 要求時計

水中高速艦を必要と認識し、予算化する時期。

計算機は間接的にしか効かない。

史実伊201型は要求後の設計・建造自体が速いため、1942年就役には要求以前からの継続研究が必要。

## 6.2 技術日程

| 時期 | 工程 |
|---|---|
| 1937～38 | 第71号艦・甲標的等の高速水中船型を数値化 |
| 1939 | Type 2で船型・プロペラ・電池負荷系列計算 |
| 1940前半 | 1,200～1,400t級比較設計 |
| 1940末 | 模型・電動機・電池試験 |
| 1941前半 | 基本設計凍結 |
| 1941夏～秋 | 一番艦起工 |
| 1942夏～末 | 第一世代就役 |

# 7. 潜高第一世代（1942年型）

設計決定：

- 史実伊201型より20～40t大きくし、実用乗員・換気・整備空間を確保。
- 高出力100サイクル級電池を採用し、セル選別、温度計測、換気、端子・配線発熱、充放電規則を改善して定格寿命へ近づける。300サイクル級は後続改良型の別設計とする。
- 前部潜舵を初期設計から装備。
- タンク配置を完成後に大修正しない。
- 深度・縦傾斜表示、半自動補助を導入。
- 最大値より、18kt台を安定使用できることを重視。

# 11. 伊400型

## 11.1 設計決定

- 二機案から建造中に三機案へ膨らませない。
- Type 2で二機・三機案を起工前比較し、1941年秋までに三機搭載型として要求・主要寸法を凍結する。
- 格納庫、交差円型船殻、航空燃料、魚雷、四基ディーゼル、潜航時間、カタパルト、専用航空機を一つの重量・容積表で閉じる。
- 途中で「もっと航空機を積める」ことを理由に船体を再膨張させない。

**判断の理由：** 伊400型で計算援用が最も効くのは最高速力ではなく、巨大複合艦で起こりやすい重量・トリム・格納庫・機関配置の設計変更を起工前に収束させることである。史実より早い研究開始を認めても、四基ディーゼル、耐圧船殻、格納筒、カタパルト、専用機の製造時計は消えない。

## 11.2 建造時計と第一建造群

本世界では航空潜水艦研究が1940～41年から継続しているため、史実同様1942年に初めて要求する枝ではなく、次を現行中心線とする。

| 艦 | 主建造所 | 起工中心 | 就役中心 | 艦載機込み戦闘即応 |
|---|---|---:|---:|---:|
| 伊400 | 呉 | 1942年3～4月 | **1944年1月** | **1944年3～4月** |
| 伊401 | 佐世保 | 1942年6～8月 | **1944年4月** | **1944年5～6月** |
| 伊402 | 佐世保 | 1942年10～12月 | **1944年7～8月** | **1944年9～10月** |
| 第4艦 | 呉 | 1943年春 | **1944年末** | 1945年初 |
| 第5艦 | 川崎神戸 | 1943年中盤 | **1945年初頭** | 1945年春 |
| 第6艦 | 川崎／空き大型船台 | 1943年後半 | **1945年春** | 1945年春～初夏 |

- 第一群3隻は建造確定。
- 第二群3隻も建造承認し、**実発注は計6隻で打ち止め**を中心とする。
- 18隻級の長期要求・構想資料が残ることは妨げないが、18隻完成を現行計画としない。
- 伊402をタンカーへ転用する史実末期型の圧力は、本世界の船腹・燃料事情が史実ほど崩れていない限り弱い。

**判断の理由：** 山本生存と史実より軽い船腹逼迫は計画縮小圧力を弱めるが、伊400は通常巡潜・潜高と同じ「一隻」ではない。大型船台、高張力鋼、大型ディーゼル、電動機、熟練溶接、航空艤装を食う特殊艦であり、潜水艦隊全体の戦闘力増加では潜高系列の方が高い。よって特殊戦略兵器として無視できない6隻を確保し、12～18隻量産は行わない。

## 11.3 晴嵐との統合時計

専用航空機は艦完成後に後付けで考えず、1941年秋の伊400要求凍結と同時に主要要求を閉じる。

| 段階 | 中心時期 |
|---|---|
| 伊400・晴嵐要求凍結 | 1941年秋 |
| 晴嵐原型初飛行 | 1942年末～1943年初 |
| 折畳・格納・浮舟・射出試験 | 1943年前半～中盤 |
| 先行生産 | 1943年後半 |
| 潜水航空部隊編成・共同訓練 | 1943年末 |
| 伊400単艦三機攻撃 | 1944年3～4月 |
| 伊400＋401の二艦六機攻撃 | 1944年5～6月 |

総生産目標は、六艦常用18機、艦上予備、教育・試験、補充を含め**50～55機級**。アツタ系発動機需要は予備込み60～70基程度とし、D4Y大量生産を左右する主律速とはしない。

通常練度では、浮上から第一機発進約15分、三機全発進を**25～35分級**へ短縮する中心線とする。就役日と戦闘即応日を同一にしない。

**判断の理由：** 晴嵐の律速は発動機数より、折畳構造、格納筒寸法、カタパルト適合、艦上組立、暖機、潜水艦乗員と航空員の共同手順である。アツタ技術が早く成熟しても、この統合訓練時計は残る。

# 17. 遣独連絡・技術輸送

## 17.1 戦域条件

インド洋は、日本側がセイロン以西まで恒常支配する強い分岐にはしない。1942～43年の東部インド洋・マラッカ海峡は史実より若干安全で、1944年には英潜水艦、航空哨戒、東洋艦隊の圧力が増す中庸線とする。

本世界の潜水艦設計・運用改善は、遣独任務で特に次へ効く。

- 機関故障と航海中止の減少。
- 貨物・燃料消費状態別の標準トリム表。
- 貨物搭載後の急速潜航保証。
- 迂回余裕と会合時刻への無理な高速航行の減少。
- 通信沈黙、暗号防御、会合・航路の情報漏洩低下。
- シンガポール・ペナン到着後の技術者・図面の航空転送。

ただし、喜望峰以西、ビスケー湾、大西洋の連合軍対潜力は日本側だけでは解消できない。一般的な往復成功率を極端に高く固定しない。

## 17.2 結果としての上書き決定

一般成功率を極端に上げず、現行歴史・技術線では次を中心とする。

- I-30：欧州から東南アジアまで到達した重要図面・技術情報は、Singapore/Penang到着後に航空転送し、後続事故が起きても情報そのものを失わない。
- I-8：史実同様の完全往復成功を維持。
- I-34：Malacca海域の狭さ・英潜水艦という地理的危険は暗号改善で消えず、喪失可能性を高く残す。
- **I-29：史実よりSIGINT追跡精度が低いため日本帰還成功を中心線とし、BMW 003、Jumo 004、HWK 509、Me 262/163関連資料・主要部品を運ぶ主搬送艇とする。**
- I-52：1944年Atlantic ASWは依然危険。欧州到達約60％、完全往復35～45％級の条件付きとし、自動成功にしない。

主要遣欧任務約6回のうち、**2～3回完全往復、4～5回は片道で有意貨物を届ける**ことを作業中心とする。

**判断の理由：** 機関・トリム・暗号・通信沈黙改善は故障中止とSIGINT待伏せを減らすが、Malaccaや大西洋の物理的ASW危険は残る。また技術資料・技術者は東南アジア到着時点で航空転送できるため、潜水艦そのものの最終帰還と技術情報到達を分離して評価する。

噴進航空に関する到着時期・技術効果は53を正本とする。ドイツ工業体系、材料規格、工作機械、量産治具一式が移植されることを意味しない。

## 17.3 ニッケル・貨物配分

ニッケル等の戦略材料が史実より多少多く到着しても、艦艇、発動機、装甲、工具、電機等と競合する。航空噴進部門では、試験片、原型発動機、選別先行機、タービン翼・排気弁等の重要部位へ優先し、量産耐熱材の窮乏を消さない。

## 17.4 遣欧輸送仕様

伊30・伊8級任務の経験後、乙型・丙型・大型巡潜に次の標準改装を置く。

- 航空設備・一部魚雷を降ろした貨物区画。
- 耐圧容器、固定架台、重量別積付図。
- 燃料消費段階別トリム表。
- 追加清水、食料、酸素、予備部品。
- 技術者・資料を東南アジアから航空転送する分離手順。

専用輸送化は生存性と貨物保全を改善するが、潜水艦を安全な定期貨物船にはしない。

# 13. 2026年8月13日追記――潜水艦の任務実効値は線形差で扱わない

潜水艦では、水上艦以上に性能閾値が戦術形式を変える。潜高系列等について、水中最大速力だけを史実艦比＋○％として戦史へ渡してはならない。

少なくとも、

- 潜航状態で射点へ移れる確率。
- 護衛線を横切って再接近できる確率。
- 攻撃後に敵ASWから離脱できる確率。
- 一出撃中に第二・第三の攻撃機会を得る確率。
- 生還し、次回出撃へ戻る確率。

へ変換する。これらの複数段階が同時に改善すると、特定任務の生涯攻撃出力・船団阻止能力は単一性能差を大きく超え、**史実同世代艦の2倍級以上になる局面も条件付きで許容**する。これは魚雷威力を倍化する意味ではなく、「攻撃位置へ入り、撃ち、生きて再び撃てる」確率の積である。

逆に、敵の航空哨戒、HF/DF、レーダー、護衛密度、前方投射兵器、浅海域等が新しい律速になれば利得は急減する。62の任務係数と敵適応を用いて戦域別に判定する。

伊400／晴嵐はこの一般潜水艦係数とは別枠の特殊任務体系である。1944年春の現行作業線では、伊400は1月就役・3～4月航空込み戦闘即応、伊401は4月就役・5～6月戦闘即応。初撃は三機単艦の嫌がらせで秘匿を消費せず、六機単位になってから敵前進泊地のAO・AR・AE・APA/AKA/LST等、次作戦の遅延価値が高い固定目標を狙う構想を中心とする。


# 19. 2026年8月14日再監査――潜高を「高速な従来潜水艦」にしない

潜高第一世代は水中18.5～19kt級を保持するが、聴音しながら高速追跡する艦ではない。自艦流体雑音・電動機・軸系雑音と電池消費を考慮し、戦術サイクルを次とする。

`低速聴音・潜望鏡確認 → 敵航跡と誤差帯を作る → 水中高速スプリント → 減速・静粛化 → 再聴音・再捕捉 → 雷撃 → 高速離脱／護衛線横断 → 減速聴音 → 第二射点または離脱 → 夜間浮上充電`

18～19ktは有限の射点修正・離脱用エネルギーであり、常用巡航速力ではない。高速機動用電池残量を魚雷残数と別に管理する。第二攻撃は魚雷が残っていても、離脱用電池・夜間充電機会・敵航空哨戒により断念し得る。

1942～43年潜高にシュノーケルは持たせない。夜間浮上充電が必要であり、敵航空哨戒は潜水艦を直接沈めなくても充電を妨害し、翌日の高速機動予算を削ることで戦力を低下させる。

第一世代の高出力電池は100サイクル級を基本とし、換気・温度・端子発熱・充放電規則を改善する。300サイクル級は後続の潜高改で、約25t級の重量増を含む別設計として検討する。

潜高の任務分化・実戦運用は21、個艦建造ロット・造船所割当・機会費用は22を正本とする。


## 2026年8月14日追加監査――甲標的の位置づけ

甲標的甲型は回天と同列の自殺攻撃兵器として扱わない。極端に生還困難な二名乗り特殊潜航艇ではあるが、初期運用では攻撃後の離脱・母潜との会合・回収を予定する。

戦力評価は魚雷2本の火力ではなく、

`発進成立 × 投入点到達 × 航法成立 × 警戒線突破 × 目標取得 × 発射位置取得 × 魚雷攻撃`

で扱う。計算援用は潮汐、潮流、投入位置、速度別電池消費、トリム、予定到達時刻、港内航路、敵停泊位置候補へ効く。電池密度、二名乗員負荷、潜望鏡視界、障害物、対潜警戒、艇体故障、魚雷2本という物理制約は残る。

母潜港湾襲撃は条件選別型とし、後期は発電機・第三乗員を持つ乙／丙方向を少数継続する。前進基地・狭水道・泊地接近路からの局地迎撃は、陸上充電、測量、潮汐観測、固定帰還点を使えるため相性が良い。回天・海龍・蛟龍は甲標的の自動的後継とせず、戦局逼迫を別途判定する。
