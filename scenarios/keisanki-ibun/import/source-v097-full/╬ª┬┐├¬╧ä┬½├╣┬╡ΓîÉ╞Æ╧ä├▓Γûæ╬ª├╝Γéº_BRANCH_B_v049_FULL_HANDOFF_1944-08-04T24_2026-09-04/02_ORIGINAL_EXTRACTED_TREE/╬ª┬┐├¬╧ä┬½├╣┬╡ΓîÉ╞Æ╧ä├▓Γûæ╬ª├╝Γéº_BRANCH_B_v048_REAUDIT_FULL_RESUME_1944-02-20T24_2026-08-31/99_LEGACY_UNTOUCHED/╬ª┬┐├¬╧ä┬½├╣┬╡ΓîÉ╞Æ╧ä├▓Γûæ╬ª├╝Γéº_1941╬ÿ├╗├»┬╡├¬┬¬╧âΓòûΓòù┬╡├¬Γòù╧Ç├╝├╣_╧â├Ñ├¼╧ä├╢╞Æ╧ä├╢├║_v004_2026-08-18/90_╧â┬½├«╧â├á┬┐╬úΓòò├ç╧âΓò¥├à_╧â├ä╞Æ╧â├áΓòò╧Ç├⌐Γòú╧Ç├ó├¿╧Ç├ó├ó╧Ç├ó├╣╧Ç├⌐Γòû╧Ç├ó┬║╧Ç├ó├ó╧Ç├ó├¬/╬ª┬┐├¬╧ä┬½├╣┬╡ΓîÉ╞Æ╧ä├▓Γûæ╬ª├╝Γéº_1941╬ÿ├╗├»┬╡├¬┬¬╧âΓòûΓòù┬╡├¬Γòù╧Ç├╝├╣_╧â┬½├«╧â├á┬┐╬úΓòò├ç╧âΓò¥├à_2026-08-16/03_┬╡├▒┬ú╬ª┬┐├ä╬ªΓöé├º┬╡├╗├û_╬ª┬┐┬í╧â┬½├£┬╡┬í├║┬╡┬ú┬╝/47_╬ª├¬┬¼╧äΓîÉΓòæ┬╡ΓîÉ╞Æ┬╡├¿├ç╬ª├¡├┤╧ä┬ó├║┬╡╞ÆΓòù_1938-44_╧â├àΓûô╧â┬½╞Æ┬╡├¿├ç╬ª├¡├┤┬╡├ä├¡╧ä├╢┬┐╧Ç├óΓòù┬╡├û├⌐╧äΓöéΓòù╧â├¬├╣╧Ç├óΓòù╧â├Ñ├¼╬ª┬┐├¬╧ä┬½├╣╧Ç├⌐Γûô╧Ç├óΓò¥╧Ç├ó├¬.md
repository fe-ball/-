# 1. 目的

FORAGER再計算前に、航空戦力を「史実機に練度補正を掛けたもの」でも「現行正本の暫定最高速度をそのまま使ったもの」でもなく、**その時点で実際に完成・量産・配備されている機体、発動機、装備、部隊中央値**として再構築する。

今回の監査は次の順序を固定する。

1. 史実技術の発生・試験・採用時期を確認する。
2. 本世界でその技術を認知するトリガーが史実より早まるか、同時か、遅れるかを判定する。
3. 計算・計測・品質統計が短縮できる部分と、材料・工作機械・実時間耐久試験が拘束する部分を分ける。
4. 試作最良、制式標準、部隊中央値を再計算する。
5. retrofit可能性、工場時計、発動機供給、予備部品、母艦・基地適合を確認する。
6. ここまで閉じた後に44/45/46のソフト・ヒューマン側を結合する。
7. 戦果は最後に、実際の敵編成・警戒・CAP・AA・天候・航続条件から再シミュレーションする。

# 2. 現行正本の監査状態

現行50～53は「機種が存在するか」「どの任務へ使うか」については相当進んでいるが、性能・時計の一部は意図的に暫定のまま残されている。

## 2.1 そのまま戦闘計算へ入れてはいけない主要項目

### A. 高優先・時計と性能の両方を再監査

- **金星零戦改**：1942年中盤予備設計、1943年9月先行量産、1944年約1,050～1,150機級という現行線。発動機供給、前部胴体・主翼中央部・脚・プロペラ・艦上審査を個別に閉じる必要がある。
- **烈風＋ハ43**：1943年後半初飛行、1944年前半艦上審査、1944年中盤以後先行量産という現行線。ハ43の実用耐久、四翅大径プロペラ、艦上脚、量産時計の相互拘束を再監査する。
- **B6N護型**：護を継続する中心線は条件依存。燃費、振動、耐久、生産、火星との比較を再検算する。
- **誉搭載機**：誉は改善するが完全にはならないという方向は維持しつつ、1943～44年の量産中央値、交換率、実用出力、整備負担を実戦入力用に再構築する。

### B. 中優先・既存機へ効く史実新技術の採用時計

- 推力式単排気管・排気背圧最適化。
- プロペラ径、翅数、減速比、ガバナ、吸収馬力。
- 水メタノール／高出力時混合気・点火・冷却管理。
- 自動・手動空戦フラップと適用機種。
- 20mm二号銃、弾道統一、給弾信頼性、13.2mmとの混載。
- 防弾、防火、燃料遮断、部分防漏・自己防漏。
- 無線、航法、酸素、照準器、通信信頼性。
- 艦爆の制動板、引起こし荷重、爆弾分離。
- 艦攻の魚雷投下包絡線、高速投下、照準・安定化。

### C. 生産・配備で最終決定する項目

- 量産機数そのもの。
- 前線配備率、予備機率、発動機予備率。
- 空母別搭載適合。
- 基地別整備能力・交換発動機・部品在庫。
- 1944年7月7日に「存在する機体」と「即応する機体」の差。

## 2.2 r30時点の進捗

2026-08-15の中間統合時点で、HARD監査のうち次を一巡した。

| 項目 | 状態 | 現行判断 |
|---|---|---|
| 推力式単排気管 | **閉鎖** | 1941試験→1942前半実機比較→1942後半量産標準化を中心。性能へ別加算しない |
| 金星零戦プロペラ | **閉鎖** | 三翅定速3.15～3.20m、3.20m中心。四翅は比較枝 |
| 金星の過給・混合気・点火・冷却 | **機体統合済み** | 一段二速、短時間WMI、量産使用域を重視。燃料等級の詳細は別監査残り |
| 瑞星後期零戦 | **機体HARD一巡** | 52型相当を独立仕様化。量産標準560～568km/h級、通常全備2.76～2.85t級 |
| 金星零戦改 | **機体HARD一巡** | 通常全備3.25～3.32t、591～597km/h、6km上昇6:25～6:45、半径600～670km級 |
| 誉／紫電改 | **機体HARD一巡** | 誉は量産中央値改善だが高整備負担を残す。紫電改600～608km/h、上昇6:15～6:45級 |
| ハ43／烈風 | **機体HARD一巡** | 4.45～4.65t、628～638km/h、通常進入140～150km/h。1944年7月は戦力へ数えない |
| B6N護型 | **機体HARD一巡** | 護主線・火星保険枝。1943年初に耐久・50機級統計・交換率・燃費で判定 |
| D4Y | **未閉鎖** | 次の機種別HARD監査 |
| 武装・防護・無線・酸素・照準器の横断採用時計 | **部分反映／未閉鎖** | 各機体へ必要分は入れたが、全機種共通の採用・量産・故障時計は別途閉じる |

重要なのは、上表の「機体HARD一巡」をそのまま実戦入力確定としないことである。次にREAL-WORLD QUALITYで、試作最良、制式標準、部隊中央値、故障、交換、整備待ち、非戦闘損失、工場・予備部品を再統合する。

また、45・46で処理した空地分離・自然還流・練度平準化は維持する。**激戦や大量損耗が発生していない時期へ史実の練度崩壊を自動移植しない。** 戦闘・事故・教育・転属・疲労の実際の蓄積から、時点ごとの人員状態を作る。

# 3. 史実資料から見た監査上の重要点

## 3.1 技術情報の基準

Technical Air Intelligence Center の wartime `Japanese Aircraft: Performance & Characteristics, TAIC Manual No.1` を、1944～45年時点で米側が把握した日本機の性能・発動機・武装・無線の横断基準として使う。これを日本側一次資料の代替とせず、機種ごとの日本側要目・取扱資料と突き合わせる。

## 3.2 非戦闘損失を機体監査へ含める

USSBS Pacific Summary は、日本航空機損失のうち戦闘損失より訓練・空輸・その他非戦闘損失の比重が大きかったと整理している。したがって本世界の改善は、最高速度・上昇だけでなく、

- 発動機故障、
- 空輸事故、
- 着艦事故、
- 迷航・燃料切れ、
- 部隊機の個体差、
- 整備待ち、

を別入力として監査する。

これは46の人員循環と接続するが、同じ効果を二重計上しない。

# 4. 技術ごとの因果監査フォーマット

各項目は必ず以下の表で閉じる。

| 欄 | 内容 |
|---|---|
| 史実発生 | 発想・試作・実機試験が始まった時期 |
| 史実採用 | 制式・量産・部隊標準化 |
| 本世界トリガー | 何を見て前倒し/後倒しするのか |
| 計算援用 | 何の計算・統計・試験還流を短縮できるか |
| 非短縮部分 | 材料、加工、耐久、工場、燃料等 |
| retrofit | 既存機へ後付け可能か |
| 初搭載機 | 最初に量産採用する機種 |
| 性能差 | 速度・上昇・航続・信頼性・重量等 |
| 部隊中央値 | 量産公差・整備を含めた実用値 |
| 配備時計 | 試作→量産→部隊化 |
| 戦術接続 | どの任務境界を動かすか |

# 5. 二重計上防止

次の形は禁止する。

> 機体性能 +10% × 熟練度 +15% × 戦術 +20%

代わりに、各戦闘セルで状態遷移を追う。

例：

1. 発動機・排気・プロペラ差から、その高度の実用速度・上昇を決める。
2. 無線・航法・経験核から集合・誘導成功を決める。
3. その時刻・位置で米CAPが接触可能かを判定する。
4. 多軸セル戦術により米CAP割当とAA目標切替を更新する。
5. 被弾、防護、発動機信頼性、燃料余裕から帰還・不時着・全損を判定する。
6. 帰還者と機体を翌日戦力へ戻す。

こうして、小さな速度差が「3分早く接触できる」等の閾値効果になった場合だけ戦果へ大きく効かせる。

# 6. 戦史再走査の起点

ソフト・ヒューマン側の新しい差が自生的に立ち上がるのはMI後である。したがって、航空技術監査完了後の太平洋戦史再走査は、原則として**1942年6月MI直後**を第一候補とする。

ただし、機体監査で1941～42年前半の性能・配備が現行値から大きく動いた場合は、MO/MIまで一段巻き戻す。

再走査は、

- その時点の実在敵機・敵艦・基地、
- 実在/本世界の索敵・警戒、
- 天候、距離、甲板、燃料、
- 当時までに成熟した教義、

を入力し、戦果を先に決めない。

# 7. Legends投入ゲート

現行太平洋戦史を外部の史観・作戦判断レビューへ渡す場合、航空技術監査未了値を混ぜない。投入パケットには、少なくとも以下を入れる。

1. 分岐以前の史実固定点。
2. 1942年6月時点の実艦・実機・搭乗員状態。
3. 技術ごとの「発生済み／試験中／量産中／未発生」。
4. 44/45/46の成熟段階。
5. 既存戦果のうち「固定」と「比較枝」を分離。
6. 判断してほしい論点を、戦果ではなく選択肢・制約として提示。

Legends側の判断を正本へ戻す際も、物理・生産・日程と矛盾する場合はそのまま採用しない。

# 8. 現時点の停止条件

- FORAGER r24戦果：比較枝のまま。
- 現在地：1944年7月7日夜。
- 戦闘機系の主要HARD監査とB6N護型比較は一巡した。
- 次はD4Y、横断装備の残HARD監査、その後REAL-WORLD QUALITYへ進む。
- REAL-WORLD QUALITYと生産・配備統合が閉じるまで、1944年7月航空戦の新しい戦果は固定しない。
- ただし史実資料収集、技術別時系列表、機種別部隊中央値表は並行して進める。
