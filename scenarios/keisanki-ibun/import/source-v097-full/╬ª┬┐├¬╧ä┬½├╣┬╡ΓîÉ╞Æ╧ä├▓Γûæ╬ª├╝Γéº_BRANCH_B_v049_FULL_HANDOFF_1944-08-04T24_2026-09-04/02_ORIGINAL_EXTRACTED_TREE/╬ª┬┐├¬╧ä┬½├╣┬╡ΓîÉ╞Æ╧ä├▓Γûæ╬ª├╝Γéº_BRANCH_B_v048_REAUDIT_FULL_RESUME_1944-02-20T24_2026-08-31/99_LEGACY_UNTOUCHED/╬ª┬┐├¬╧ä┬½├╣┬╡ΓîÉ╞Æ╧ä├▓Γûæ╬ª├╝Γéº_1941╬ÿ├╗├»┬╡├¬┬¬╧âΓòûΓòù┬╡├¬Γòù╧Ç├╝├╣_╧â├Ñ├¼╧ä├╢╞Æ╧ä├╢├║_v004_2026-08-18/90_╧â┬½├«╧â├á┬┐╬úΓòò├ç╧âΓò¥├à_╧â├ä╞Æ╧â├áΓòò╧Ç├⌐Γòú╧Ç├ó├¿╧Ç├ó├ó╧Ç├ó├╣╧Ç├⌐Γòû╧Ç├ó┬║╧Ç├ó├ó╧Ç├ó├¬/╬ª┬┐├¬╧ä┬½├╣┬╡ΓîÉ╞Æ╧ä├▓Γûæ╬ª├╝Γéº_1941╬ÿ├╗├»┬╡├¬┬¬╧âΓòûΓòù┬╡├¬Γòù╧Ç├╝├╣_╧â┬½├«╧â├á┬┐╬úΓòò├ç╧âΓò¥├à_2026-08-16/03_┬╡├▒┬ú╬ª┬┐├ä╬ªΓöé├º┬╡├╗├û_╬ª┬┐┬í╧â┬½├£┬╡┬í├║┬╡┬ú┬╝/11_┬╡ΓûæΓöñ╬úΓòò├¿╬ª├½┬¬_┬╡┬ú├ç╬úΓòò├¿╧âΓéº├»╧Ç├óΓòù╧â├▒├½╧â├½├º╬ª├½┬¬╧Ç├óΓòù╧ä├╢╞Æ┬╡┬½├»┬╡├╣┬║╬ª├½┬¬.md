# 最上型・変則艦・生残旧艦

本書は、代表艦級監査後に残った例外艦・転用艦・延命艦を担当する。基本原則は「生存＝第一線大改装」ではなく、任務、船体寿命、改装工数、船渠・機器・人員の機会費用を比較することに置く。

# 1. 最上型

## 1.1 艦級内部の二群

- **A群：最上・三隈。** 既成船体制約が大きく、公試・実故障から未知問題を発見する教師艦。
- **B群：鈴谷・熊野。** 最上・三隈の実測残差、友鶴後の復原性、第四艦隊事件後の強度知見を建造段階へより深く戻した成熟群。
- 鈴谷と熊野の個艦差は、現時点では数値化しない。

計算機によって条約公称排水量へ艦を押し戻さない。実重量、KG、強度、機関を計算し、余裕は強度、復原性、配電、消防・排水、砲塔支持、将来の電探・対空装備余裕へ戻す。原案37ktを復活させるより、35kt級を予定どおり再現できることを重視する。

## 1.2 構造問題の扱い

友鶴後の重量・KG・復原性は早く収束し得るが、極端波浪、ホイッピング、溶接残留応力、施工差などの未知入力は残る。最上では公試・実海面で構造不具合が発生し得る。

差はその後で、

`船体縦曲げ → 局部甲板変形 → 砲塔環歪み → 旋回抵抗増大`

を実測し、「許容応力内か」だけでなく「この変形で兵装が機能するか」を後続艦へ戻す。鈴谷・熊野ほどこの還流を建造段階で反映する。

## 1.3 20.3cm砲戦

15.5cm三連装5基から20.3cm連装5基への換装可能性はoption valueとして残す。5基10門配置も維持する。3基9門等へ合理化するだけの明確な律速は見つかっていない。

史実同艦・同条件を1.00とした純粋な20.3cm砲戦Mission effectiveness作業帯：

| 状態 | 最上・三隈 | 鈴谷・熊野 |
|---|---:|---:|
| 無傷～軽微 | 1.05～1.06 | 1.06～1.07 |
| 非致命的上部構造被害 | 1.08～1.11 | 1.10～1.14 |
| 砲塔支持・配電・射撃指揮を含む中破 | 1.10～1.13 | 1.13～1.17 |
| 砲塔そのものへの重大直撃 | 1.04～1.08 | 1.04～1.08 |
| 弾薬庫・主機等の破局的損傷 | 1.00～1.05級 | 1.00～1.05級 |

通常損傷経過を含む一回の昼間巡洋艦砲戦では、前期群約1.07、後期群約1.09、4隻平均約1.08を中心とする。装甲が強くなったのではなく、「生きている砲塔まで船体変形・配線損傷で死ぬ」中間遷移を減らす。

通常外洋夜戦・雷撃は条件成立時1.25～1.35級を感度帯に持つが、味方混在の近距離飽和戦では対敵効果を1.10～1.16級へ圧縮し、射撃統制・誤射抑止へ価値を移す。固定総合倍率にしない。

# 2. 北上・大井

史実重雷装艦の四連装10基40門は、片舷へ即時に使えるのが20本で、次発魚雷を持たない。発射管資源に対しては、中心線上発射管＋次発を持つ新型駆逐艦より効率が悪い。一方、船体一隻あたりの瞬間投射量は大きい。

現行中心：

- **北上**：40門重雷装を一隻限りの実験艦として完成。20本一斉射、4/8/12/20本分割射、左→右の連続攻撃、駆逐隊協同、友軍危険扇面、離脱・再集合を試験する。
- **大井**：第二の40門艦への完全改装は中止。通常軽巡として保持し、輸送、護衛、水雷指揮等へ振れる余地を残す。
- **重雷装巡洋艦系列**：量産しない。発射管資源、攻撃位置取得、第二攻撃成立、敵適応を比較すると標準水雷戦兵器にはしない。
- 北上の24門高速輸送艦化は戦況依存。史実Guadalcanal型の輸送危機がなければ自動発生しない。
- 回天母艦化は戦局逼迫が別途閾値を越えた場合だけ発生判定する。

# 3. 島風――高速総合技術実証艦

島風は単なる速度記録艦ではなく、高圧機関・高速船型・推進器・振動・自動燃焼制御・15射線雷撃を統合し、計算援用で駆逐艦の瞬間性能をどこまで押し上げられるかを見る実証艦とする。

暫定中心：

| 項目 | 作業値 |
|---|---:|
| 公試状態 | 2,920～2,950t級 |
| 機関乾燥重量 | 915～930t級 |
| 定格 | 75,000～76,500shp |
| 過負荷 | 79,000～80,500shp |
| 蒸気条件 | 40kg/cm²・400℃を維持 |
| 良好公試 | 41.1～41.4kt級 |
| 実用高速 | 39～40ktを反復使用可能にする |
| 魚雷 | 61cm×15、次発なし。5/10/15本分割射を正式選択肢 |

高圧・高温をさらに上げず、船尾流、プロペラ、タービン、減速歯車、軸系、復水器、給水・燃焼制御の整合で有効推進効率を拾う。史実で問題になった自動燃焼制御と給水系を重点改善する。

40kt級の価値は、35.5kt級艦では戦闘時間内に作れない射点を短時間スプリントで作る閾値に置く。常時40kt艦隊行動ではない。

建造政策：**島風＋改島風2隻を第一次高速駆逐艦実証群の上限**とする。追加2隻（計5隻）は、三隻中二隻以上が39kt級反復、整備日数、射点取得、15本第一射、艦隊行動燃費等の実艦試験を満たした場合のみ条件付き。標準量産はしない。

# 4. 伊勢・日向――生残旧式戦艦の通常改装

史実の航空戦艦化は行わない。後部36cm砲塔2基を失って航空艤装を得る交換は、空母損耗圧力の弱い現行線では割に合わない。

- 36cm連装6基12門を維持。
- 良好公試25.5～25.7kt、作戦計画用連続実用24.5～25kt級。
- 巡航燃費改善は3～5%中心、機関大整備併施の良好例だけ5～7%。
- 14cm副砲は段階的縮小候補。高角砲、電探、射撃I/O、配電・非常電源、消防・排水へ重量と人員を振る。
- 水上機は少数の偵察・弾着観測用。大航空艤装、さらなる高速化は行わない。
- 純水上砲戦Mission effectivenessは無傷1.05～1.08、長時間射撃・軽微故障込み1.07～1.11級。中程度損傷後の任務機能保持は1.10～1.15級の感度帯。装甲倍率ではない。

生存するから常時第一線へ置くのではなく、現役→整備・予備→必要時戦列復帰を許す。第二線戦艦、低速船団・上陸部隊への重砲掩護、基地防御、電探・射撃指揮試験、練習・予備戦艦が自然な任務。

# 5. 生残旧艦の共通判断

扶桑・山城、長門、古鷹・青葉級等は一律ルールで改装結果を固定しない。`残存船体寿命 × 任務適合性 × 改装後Availability` に対して、改装工数、船渠占有、新造艦への機器・熟練工・乗員の機会費用を比較する。

戦力が史実より潤沢なほど、旧艦を第一線仕様へ戻す限界価値は下がり得る。試験艦・指揮艦・訓練艦として学習価値を生む場合は、額面戦闘力が低くても保持価値がある。
