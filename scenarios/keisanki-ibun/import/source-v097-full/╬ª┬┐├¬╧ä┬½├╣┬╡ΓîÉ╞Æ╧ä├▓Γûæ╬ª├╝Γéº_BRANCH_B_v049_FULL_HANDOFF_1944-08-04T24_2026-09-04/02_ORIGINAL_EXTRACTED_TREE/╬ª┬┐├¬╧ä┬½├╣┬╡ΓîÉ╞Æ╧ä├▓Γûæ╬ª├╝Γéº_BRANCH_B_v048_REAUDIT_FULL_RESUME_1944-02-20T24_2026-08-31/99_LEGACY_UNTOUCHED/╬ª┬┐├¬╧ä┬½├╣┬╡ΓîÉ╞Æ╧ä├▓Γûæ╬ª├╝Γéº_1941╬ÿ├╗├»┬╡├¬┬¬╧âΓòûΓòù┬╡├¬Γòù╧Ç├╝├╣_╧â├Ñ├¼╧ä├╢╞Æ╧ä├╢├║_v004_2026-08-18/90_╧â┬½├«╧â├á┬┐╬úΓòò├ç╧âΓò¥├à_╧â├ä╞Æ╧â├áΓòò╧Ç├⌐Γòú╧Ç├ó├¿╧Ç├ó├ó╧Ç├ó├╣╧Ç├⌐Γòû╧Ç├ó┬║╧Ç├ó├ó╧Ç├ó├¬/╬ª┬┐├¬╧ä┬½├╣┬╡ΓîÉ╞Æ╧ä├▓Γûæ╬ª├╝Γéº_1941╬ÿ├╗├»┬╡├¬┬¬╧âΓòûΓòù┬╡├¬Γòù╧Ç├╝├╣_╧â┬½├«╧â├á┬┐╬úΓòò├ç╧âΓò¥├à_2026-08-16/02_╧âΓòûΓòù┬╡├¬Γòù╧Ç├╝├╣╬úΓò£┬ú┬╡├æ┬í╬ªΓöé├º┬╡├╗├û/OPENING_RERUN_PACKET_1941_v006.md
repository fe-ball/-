# 1941開戦再走査 クリーン開始パケット v0.06

## 0. 再走査の始点

- 南方航空：**1941-11-15の集中開始**から状態遷移。
- 全戦域：1941-12-07/08の開戦から実時間同期。
- 旧戦史の戦果・損耗・建造判断・1942–44の「安全線」は入力しない。

## 1. 入力として保持するもの

### 物理/HARD

- 1941-12時点で成立済みの機体・艦艇・魚雷・暗号設計能力。
- 開戦前に起工・設計凍結した工程。
- 技術研究・試験の物理時計。ただし後の量産・配備数量は戦況から再決定。

### 状態

- 艦/潜水艦の個体Availability。
- 機体の可動・損傷・整備状態。
- 搭乗員/整備員の経験帯・資格・負傷・疲労・転属。
- 船腹・基地・燃料・弾薬・増槽・工具・予備品。

## 2. 入力禁止へ降格したもの

- 第一線実効作戦出力 **+15–25%** の直接倍率。
- 反復陸上基地戦 **+20–35%** の直接倍率。
- 開戦4か月航空損失削減率。
- 「春1942に熟練者が何十～百何十人余る」等の後続集計。
- MI後に人事/運用差が初めて立ち上がるというゲート。
- 旧MI/Guadalcanal枝に依存する制度成熟日・建造判断。

これらは再走査後の比較・診断値としてのみ使う。

## 3. 航空

- 陸軍航空の基地機動は開戦時から `OPERATIONAL_PARTIAL`。
- 海軍航空の空地分離は `LATENT`。
- 自然還流は開戦前集中から追跡する。制度ではない。
- 意図的練度平準化・経験核配分・専任空輸はLATENT。
- 細い空戦戦術はscenario側の妥当な設定/伯仲を許し、ここでは主研究対象にしない。
- 大規模な任務配分、侵入距離、集合/航法、基地転進、可動率、人員蓄積を主出力とする。

## 4. Malaya Phase 0

名目OOBと実可動を分離する。

`TABLE_STRENGTH → ARRIVED_FORWARD_AREA → SERVICEABLE_EVE → TASKED → LAUNCHED → MISSION_REACHED → RETURN/LOSS`

既知の集中損失46機と南方軍向け補充第一便148機は、部隊・日時の帰属が閉じるまで**未配賦プール**。46機を12月8日OOBから一括控除しない。

実出撃記録からの下限制約：

- 59/75/90戦隊群：少なくとも **53機**が12月8日に実発進可能。
- 64/12/60/98戦隊群：少なくとも **93機**が実発進可能。

## 5. 潜水艦

第一回個艦OOBを作成済み。候補60隻について所属を整理し、既知の可用状態を別管理。

例：

- 伊59：開戦時オーバーホール/非即応。
- 伊60：近代化工事。
- 伊62/64/65/66：マレー方面で実哨戒。
- 伊123：前部潜舵故障で潜航不能、敷設後修理。

したがって「名簿隻数＝投入可能隻数」を禁止する。

## 6. 水上艦

開戦前の設計・公試・改装差は保持。

1941-12以後は `Hull → Availability → Mission set → Mission effectiveness → Allocation` で再計算し、旧1942–43損耗/建造/改装判断を固定しない。

個艦Opening AvailabilityはまだAMBER。月次艦隊名簿は候補索引に限り、作戦直前に所在・修理・燃料・任務で閉じる。

## 7. 後続スイッチの扱い

`switch_registry_v010.json`：**46項目**。

- 後から発見したMETHOD：開戦まで遡及。
- HARD clock：物理時計を保持。
- 開戦時部分能力：そのまま存在させる。
- SOFT/POLICY：旧日付解除、観測・需要・能力・時間で再判定。
- OUTCOME：旧枝入力禁止。

詳細は `MASTER_SWITCH_AUDIT_v010.md/csv`。

## 8. 次の実動区間

1. 1941-11-15～12-07 南方航空集中の判明事故を状態化。
2. Pearlを同時刻の別状態として更新。
3. 1941-12-08～15 Malayaを日次遷移。
4. Philippines/DEI水上戦に入る前に必要艦だけ個艦Availabilityを閉じる。
5. 初期潜水艦戦は第一回OOBを個艦mission-dayへ展開。

「総量が完全に閉じるまで止まる」方式にはせず、史料で閉じた部分から逐次更新し、UNKNOWNはUNKNOWNとして持ち越す。
