# 計算機異聞・歴史考察　1937～1942前史・中国・ノモンハン・南方

> **2026-08-10 状態変更：太平洋開戦後の戦果は再監査待ち。**
> 本書は史観・比較・旧作業線・再走査論点を保持する参照資料であり、1941年12月以後の勝敗・損耗・修理・占領地を現行結果として固定しない。魚雷・航空命中・再装填等の非線形効果を反映し、`31_魚雷・水雷戦_魚雷本体・射撃指揮・再装填・運用.md` と `61_技術からの自然な軍事的派生_戦術サイクル・任務階級・戦史再監査.md` に従って開戦から順に再走査する。


# 0. 本書の位置づけ（前史保持・開戦後再監査）

本書は、統合時の相互査読で片系統にだけ残っていた、1937年から1942年春までの前史を保存する。1942年後半の中国戦線は82、MO・MI以後は80・81を優先する。

技術性能は10～70の担当正本を上書きしない。本書の戦況・人物評価は、固定事象、中心推定、条件依存を区別して用いる。

# 1. 中国戦線――弱体化するが、地図は急激には崩れない

## 1.1 初期戦の累積弱体化

**シナリオ決定：** 中華民国は1937～38年の初期戦闘で、史実以上に早い部隊壊滅、疎開失敗、人員離脱、工場・行政資産の取りこぼしを受ける。

これは日本軍が意図的に民間疎開を攻撃する設定ではない。前線崩壊が早いため、

- 疎開計画が間に合わない。
- 工場・機械・技能者が全員ついて来ない。
- 輸送手段が不足する。
- 地方軍・官僚・住民の一部が中央政府から脱落する。

という累積で効く。

重慶遷都後を新しい基準にすると、国力・戦闘能力とも史実比で**数割弱い**中心線を採る。ただし領域支配は同じ比率で縮まらない。

## 1.2 なぜ地図が大きく動かないか

中国戦線の制約は、航空機・砲兵性能だけではない。

- 国土が広大。
- 道路・鉄道が不足。
- 占領地治安に兵力が必要。
- 山岳・河川・季節が作戦速度を制約。
- 中国軍は後退しても人員供給源を保持する。

したがって、**戦力は数割弱体化していても、重慶政権が短期間で消滅する中心線にはしない。**

日本側の利得は、同じ前線を保持するための兵力・航空・輸送負担が少し軽くなり、時期によって陸軍予備を戻しやすくなることに現れる。

## 1.3 仏印進駐後

1940年以降、北部仏印の基地化と日本航空戦力の更新で圧力がもう一段上がる。

主な差は、

- Ki-21-II、Ki-48-II、Ki-49等による爆撃の稼働・計画性。
- Ki-43、Ki-44等による制空。
- Ki-45改による長距離戦闘・哨戒・対爆撃機能力。
- Ki-46による偵察処理。
- 鉄道・道路・飛行場に対する計画的圧力。

に出る。

中国軍航空隊と後方輸送の自由度は史実よりさらに狭くなる。

## 1.4 1942年以後の「安定」

**中心推定：** 1942年までに、中国戦線は「日本優勢だが、戦線を大きく動かす合理性が薄い」状態へ入る。

日本側は、

- 主要鉄道・都市・飛行場。
- 占領地治安。
- 局地攻勢。
- 航空圧力。

を維持する。

中華民国側も、太平洋正面で日本が大崩れしていない間は、大規模な反攻へ出る誘因が弱い。

次の大きな外因は、

- B-29等による中国航空基地の戦略価値増大。
- 連合軍側の中国戦線活性化。
- 蔣介石が政治・軍事上の焦りから能動化すること。
- 法幣インフレと政権内統合の悪化。

である。

したがって、史実一号作戦に相当する大規模基地否定作戦は、**B-29問題等が実際に立った段階で再検討**する。

# 2. 南京・重慶・政権安定

南京占領後、日本側が占領地をどこまで行政・交通上の「太い」地域として使えるかは、前線固定化の重要論点である。

中心判断は、

- 南京・上海・華中鉄道沿線は史実より安定化しやすい。
- ただし占領地全域の治安費用が消えるわけではない。
- 中国側の法幣インフレ、徴税能力、地方軍統合は重慶政権を徐々に弱める。
- 蔣介石の政治支配は軍事力低下だけでは即崩壊しない。

とする。

「軍事的には弱いが政治的にまだ倒れない」期間が長いことが、中国戦線の固定化を説明する。

# 3. ノモンハン――勝敗は変えず、交換比と記憶を変える

## 3.1 戦略結果

**シナリオ決定：** 日本中央が拡大を嫌がる限り、ノモンハンを日本の戦略的勝利へ改変しない。

停戦・国境線の政治的帰結は大きく変えず、差は戦闘過程に出す。

## 3.2 計算援用が地上兵器へ出る場所

戦車の装甲・砲威力が突然別物になるのではなく、

- 履帯・転輪・サスペンション。
- 変速機・クラッチ。
- 冷却。
- 燃料・潤滑。
- 部品公差。
- 故障統計。
- 予備品配分。

の改善で、同じ九七式中戦車等が「予定した日に何回出られるか」が増える。

## 3.3 「怖いときのチハ」

ここでいう強みは戦車戦の正面撃破力ではなく、**速力・走破性を盾にした襲撃、離脱、別地点への再出現**である。

中心推定として、故障・整備時間が減り、寿命をケチらず使う部隊では、72時間程度の短い窓における有効出撃・再出現回数が史実相当より**1.3～1.6倍級**になる局面があり得る。

これは個々の戦車性能表より、敵側の「どこにいるか分からない」「また来た」という運用圧力として効く。

## 3.4 ノモンハンの人的帰結

中心線では、

- ソ連側被害がわずかに増える。
- 日本側の下士官・熟練兵損耗がわずかに減る。
- ソ連側の日本軍評価が少し上がる。

とする。

これだけでソ連の対独配置が激変するとはしないが、独ソ戦初期にごく小さな間接利得をドイツ側へ与える可能性は残す。

また、日本陸軍内部では「機械化兵器は寒冷地では必ず役に立たない」という記憶が史実より弱まり、後の過度な精神主義の一部が緩和される。

# 4. 作戦計画・参謀への計算効果

## 4.1 一番効く場所

計算機が参謀の判断を代行するのではなく、次を早く大量に比較できる。

- 船腹・車両・鉄道の輸送量。
- 燃料・弾薬消費。
- 行軍・積卸・港湾待機。
- 航空出撃率。
- 複数作戦案の所要日数。
- 予備率、故障、天候を振った感度分析。
- 図上演習の反復。

そのため、能力の高い参謀・指揮官ほど効果を引き出す。

## 4.2 辻・服部型の人物

強い意志と作戦構想力を持つ「怪物型」参謀は、計算結果を使えば史実以上に強力になり得る。

一方で、結論を先に決めて数字を作る人間も存在する。

本世界では計算導入初期ゆえに、

> **数字を作る人間と、数字から結論を変える人間の差が可視化されやすい。**

本人自身が「自分は数字を作る側だ」と認識する場合すらあり得る。

これは全軍文化を一夜で変えないが、

- 科学・兵站部署が「この作戦はこの前提なら成立しない」と言語化する。
- 作戦課が前提を書き換えた場合、その痕跡が残る。
- 失敗時にどの入力が外れたか検証しやすい。

という制度的なブレーキになる。

## 4.3 悪手を止める効果

「日本軍だから」実行されたと後世一括される悪手の一部は、実際には組織、情報不足、時間、命令関係から生じる。

本世界では、

> **科学・輸送・工兵側が、実行前に『この条件では計算上成立しない』と止める事例が史実より増える。**

ただし最高指揮官が政治・精神・時機を理由に押し切れば実行される。計算は選ばせない。

# 5. 南方初期作戦――基本計画は変えず、細部と回転を変える

日本軍の基本作戦計画は、

- 地政学。
- 南方資源地帯確保。
- 山本の艦隊決戦思想。
- 陸海軍間の調整。
- 英米側の既存配置と判断。

に規定されるため、開戦初期の大枠は史実から大きく変えない。

本世界の差は、

- 航空偵察の可動率。
- 重爆・戦闘機の性能中央値。
- 船団の回転。
- 港湾処理。
- 上陸第一日の重装備。
- 水上機による前進拠点の早期航空化。

に出る。

## 5.1 逃亡・自壊・鹵獲

攻略日程が若干早いほど、連合側が、

- 燃料を焼く。
- 港湾を破壊する。
- 車両・航空機を退避させる。
- 倉庫を処分する。

時間が減る。

ただし「日本軍が到着したので全部無傷で取れる」とはしない。

差は、**破壊率を数十ポイント下げるほどではなく、重要倉庫・車両・燃料・工場設備が史実より少し多く残る**形を中心とする。

仏印、蘭印、フィリピンを合算すると、初期数か月の日本側兵站に無視できないが、国家規模の物量を倍増させるほどではない。

# 6. インド洋初期作戦――主力空母撤収後も圧力を残す

セイロン・ベンガル湾の初期空母作戦は、史実と同じく英国Eastern Fleetへ大きな圧力を与える。

本世界では、

- 艦載機可動率。
- 索敵。
- 水上機・飛行艇。
- 潜水艦航続・稼働。

が少し良いため、商船・港湾・退避船への攻撃機会が増える。

ただし主力空母は太平洋へ帰る必要がある。

その後のインド洋は、空母艦隊による常時支配でなく、

- 潜水艦。
- 水偵・飛行艇偵察。
- 限定的水上襲撃。
- Burma・Andaman・Malayaからの航空圧力。

へ移る。

詳細な船腹・護衛負荷・援ソ波及は `82_歴史考察_中国・インド洋・連合輸送・独ソ戦波及.md` へ分離する。

# 7. Doolittle Raidと本土防空

Doolittle Raid自体は、中華民国が存在し、米側の政治的誘因も残るため発生する中心線。

ただし本世界では、

- 零戦系主力機の性能。
- 雷電開発の先行。
- レーダーのわずかな前倒し。
- 双発戦闘機Ki-45改系。

により、日本本土防空は史実より少しまし。

結果は「完全阻止」ではなく、米攻撃隊の損害や迎撃接触がやや増え、日本側の面子が史実より立つ程度を中心とする。

戦略判断への影響――本土へ接近する敵空母を早く叩きたいという山本の政治的圧力――は残る。
