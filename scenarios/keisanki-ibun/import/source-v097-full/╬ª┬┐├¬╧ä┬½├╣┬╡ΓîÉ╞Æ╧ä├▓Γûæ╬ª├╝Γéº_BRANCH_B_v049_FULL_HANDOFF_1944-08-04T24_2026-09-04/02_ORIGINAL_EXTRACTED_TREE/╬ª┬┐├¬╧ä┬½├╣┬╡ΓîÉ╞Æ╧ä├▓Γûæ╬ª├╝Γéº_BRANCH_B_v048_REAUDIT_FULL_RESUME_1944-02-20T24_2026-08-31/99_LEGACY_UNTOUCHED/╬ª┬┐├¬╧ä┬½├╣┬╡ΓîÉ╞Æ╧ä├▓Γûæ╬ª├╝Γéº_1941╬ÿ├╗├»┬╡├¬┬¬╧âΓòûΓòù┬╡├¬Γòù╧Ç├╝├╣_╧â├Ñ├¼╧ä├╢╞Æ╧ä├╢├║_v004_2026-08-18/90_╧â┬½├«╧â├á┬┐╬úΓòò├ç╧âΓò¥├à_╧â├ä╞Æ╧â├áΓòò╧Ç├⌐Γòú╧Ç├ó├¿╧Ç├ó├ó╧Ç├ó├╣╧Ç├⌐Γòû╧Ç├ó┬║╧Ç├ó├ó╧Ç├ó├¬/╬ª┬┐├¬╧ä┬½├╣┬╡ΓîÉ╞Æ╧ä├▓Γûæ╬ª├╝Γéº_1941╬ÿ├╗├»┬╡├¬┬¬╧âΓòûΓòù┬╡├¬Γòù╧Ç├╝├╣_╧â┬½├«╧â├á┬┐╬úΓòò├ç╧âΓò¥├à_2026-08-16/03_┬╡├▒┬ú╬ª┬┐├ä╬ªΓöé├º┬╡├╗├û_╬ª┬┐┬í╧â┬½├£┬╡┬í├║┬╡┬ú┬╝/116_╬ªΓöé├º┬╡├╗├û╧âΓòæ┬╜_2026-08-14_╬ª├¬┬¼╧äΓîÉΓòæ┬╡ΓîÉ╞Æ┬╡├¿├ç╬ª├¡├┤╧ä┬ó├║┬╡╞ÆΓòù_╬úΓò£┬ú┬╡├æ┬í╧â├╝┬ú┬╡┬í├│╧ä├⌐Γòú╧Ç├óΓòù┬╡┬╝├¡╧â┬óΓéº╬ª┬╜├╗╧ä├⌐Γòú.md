# 1. 現在地

- 戦史時計は **1944-07-07夜** で停止。
- r24のFORAGER/フィリピン海戦果は比較枝。現行結果として固定しない。
- 今後しばらく全文正本更新は行わず、技術監査・計算・時系列検証へ集中する。
- 航空技術監査が閉じる前に、1944年7月の新しい戦果は固定しない。

# 2. 監査の基本順序

航空戦力は以下を順に閉じ、最後に統合する。

1. **ハード**：発動機、過給、排気、プロペラ、冷却、武装、防護、無線、酸素、照準器。
2. **実用品質**：試作最良／制式標準／部隊中央値、故障率、個体差、整備待ち、非戦闘損失。
3. **ヒューマン**：熟練者の自然還流、資格分解、経験核、練度平準化、整備員循環。
4. **ソフト**：空地分離、索敵・CAP・攻防研究、多軸セル、敵防空処理容量への攻撃、艦隊回避。
5. **実戦統合**：発進→集合→索敵→CAP接触→防空管制→終末攻撃→被弾→帰還→翌日即応。

固定倍率の乗算（例：機体+10%×熟練+15%×戦術+20%）は禁止。各差は状態遷移で効かせる。

# 3. 次回の第一監査束

## 3.1 推力式単排気管・排気背圧

確認事項：

- 史実の発想・試験・採用・量産標準化の時期。
- 海軍／陸軍、三菱／中島／川西での伝播経路。
- 本世界で前倒しを生む観測トリガー（排気背圧、速度試験、気筒温度、夜間排炎等）。
- 計算機が短縮できる部分と、実機排気干渉・熱害・工作・耐久等の非短縮部分。
- 既存機retrofitの工数と生産ラインへの影響。
- 速度寄与を単純加算せず、既存性能値に暗黙算入済みかを確認する。

## 3.2 プロペラ

確認事項：

- 三翅／四翅、直径、翅幅、減速比、ガバナ、吸収馬力。
- 発動機の高出力化に対して、プロペラが律速になった時期。
- 艦上機では直径増加による地上・甲板クリアランス、脚長、重量、着艦への代価。
- 最高速だけでなく上昇、加速、発艦、巡航効率への寄与。

## 3.3 過給・水メタノール・混合気・点火・冷却

確認事項：

- 技術成立、量産安定、前線標準化を分ける。
- 高出力を一基の試験機で出せた時期と、量産機が連続して使えた時期を混同しない。
- 燃料品質、ノッキング、温度、点火栓、気化器／噴射、整備負担を含める。
- 金星六〇、火星二〇、誉、ハ43で個別時計を持つ。

# 4. 金星零戦改の現状と未解決点

現行53の暫定中心線：

- 金星六〇型級 1,450～1,500馬力。
- 通常全備 3,120～3,220kg。
- 制式標準最大速度 592～600km/h。
- 良好機・軽状態 601～606km/h級。
- 部隊中央値 586～596km/h。
- 6,000m上昇 5分40秒～6分05秒。
- 先行量産 1943年9月、本格配備1944年前半。

ただし上記速度は**統合暫定値であり寄与内訳が未分解**。排気・プロペラ・冷却・機首抵抗・発動機実用出力などを追加補正として後付けしてはいけない。

次回は、基準状態を一度定義し、各要素が「既に含まれる／未算入／重複不明」のどれかを分類したうえで、速度・上昇・航続・加速・部隊中央値を再構築する。

# 5. 発動機時計の現行仮線

- 金星六〇型：技術成立1940末～41前半、少数生産1941後半、量産安定1942後半、前線標準化1943年。
- 火星二〇型：技術成立1940後半～41前半、少数生産1941後半、量産安定1942中盤、前線標準化1942後半～43年。
- 誉：量産中央値・交換率・実用出力・整備負担を未監査。
- ハ43：烈風時計を拘束するため、耐久・四翅大径プロペラ・艦上脚と一体で未監査。

これらは「未来の高出力を早く解禁する」より、同じ出力段階を量産機が安全に使える時期が早まる、という原則を維持する。

# 6. ソフト・ヒューマン側の現在の因果線

以下は方向性を維持するが、ハード監査後に実戦入力へ結合する。

- MI後の決死的逐次投入減少により、戦傷・修理・再編・転属による熟練者の自然還流が増える。
- 空地分離が飛行隊・整備員の可搬性を上げ、人員を撹拌する。
- 新編隊へ編隊長、航法、無線、先任整備等の経験核を配し、上澄みを均等化せず**下端を持ち上げる**。
- 練度を一値にせず、艦上発着、夜間、航法、編隊指揮、無線、攻撃、CAP、整備などの資格で扱う。
- 自軍火器管制研究から「統制された防御の処理容量」を認識し、多軸・時差・半独立セルによって敵のCAP・火器管制・操艦へ同時に異種問題を与える研究へ派生する。
- 攻撃隊の分散は無秩序化ではなく、事前条件分岐＋短通信による「分散接近・時差収斂」を中心とする。
- 米側も実戦中に適応するため、初見効果を恒久倍率にしない。

# 7. 戦史再走査ゲート

航空ハード＋実用品質＋ヒューマン＋ソフトを統合した後、現行太平洋戦史を再走査する。

第一候補の起点は **1942年6月MI直後**。

ただし航空機監査により1941～42年前半の実用性能・配備時計が現行値から有意に変動するなら、MO/MIまで戻る。

再走査では、各時点の実在敵機・実艦・基地・レーダー・CAP・AA・天候・距離・燃料・修理・当時成立済み教義を入力し、既存戦果を目標値にしない。

# 8. Legends投入の位置づけ

ハード監査と成熟段階表を閉じた後、現行太平洋戦史をLegendsへ渡して史観・作戦判断の引き出しを行う。

渡すもの：

- 分岐以前の固定点。
- 実艦・実機・搭乗員・基地・兵站。
- 技術ごとの発生済み／試験中／量産中／未発生。
- ソフト・ヒューマンの成熟段階。
- 指揮官が実際に知り得る情報。
- 選択肢・制約。

「どちらを勝たせるか」は問わない。返答も物理・生産・時計と照合し、矛盾すれば採用しない。

# 9. 次回開始位置

**推力式単排気管の史実時系列監査から開始。**

その結果を金星零戦改へ直接足さず、まず現行586～596km/hの内訳を解体する。同じ手順をプロペラ、過給／水メタノールへ進める。
