# 計算機異聞・艦艇戦力評価――任務係数・艦隊運用・戦史再監査v3

# 0. 本書の目的

本書は2026年8月13日の歴史考察で判明した横断問題を正本化する。

技術正本では、船体計算、重量余裕、機関信頼性、射撃計算、電探、I/O、損害制御、魚雷再装填、潜水艦水中性能等が個別に改善されていた。一方、歴史考察ではそれらを「艦数＋少量の性能補正」に縮約し、特に1944年Marianas前には空母航空・基地航空・潜水艦を主役、水上艦を護衛・背景とする形へ偏った。

本書の目的は、**一隻が存在する価値と、一隻が任務を達成する能力を同時に評価し、当時の指揮官が使える艦艇を合理的に使い切る**ための規約を作ることである。

# 1. 「何倍」を一語で固定しない

艦艇の総合戦闘力に万能倍率は置かない。任務ごとに必要な連続条件が異なるからである。

たとえば夜間水上打撃なら、

1. 出撃日に稼働している。
2. 必要速力で接近できる。
3. 敵を捕捉・追尾できる。
4. 射撃・魚雷解を作れる。
5. 有効打を与える。
6. 反撃を受けても離脱・再攻撃できる。

が連続条件になる。

各段階が5～20％改善されるだけでも、最終の「有効打を与え、戦闘継続する確率」は30～70％以上変わり得る。逆に、一つの律速が0.5なら他を全部1.2にしても効果は強く制限される。

したがって、会話で用いた「設計1.1×射撃1.1×レーダー1.1×防御1.1」のような**雑ウォーズマン算**は、総体利得を見落とさないための診断には使うが、最終正本値にはしない。

# 2. 基本評価式

作戦で使う簡易構造を次とする。

> 実効任務戦力 = Hull count × Availability × Mission effectiveness × Coordination × Situation

ここで、

- **Hull count**：その日付に実在し、沈没・長期修理でない艦数。
- **Availability**：機関、燃料、弾薬、乗員、整備、訓練、航続で当日出撃できる割合。
- **Mission effectiveness**：その任務に対する速度、射撃、魚雷、対空、損害制御、センサー等の統合値。
- **Coordination**：艦隊編成、通信、第二斉射、航空・潜水艦との時間合わせ。
- **Situation**：天候、昼夜、海面、敵航空優勢、敵レーダー、地理等。

各係数を独立とは仮定しない。同じ原因を二回加算しない。たとえば重量余裕で追加した発電機がレーダー稼働率を改善した場合、「重量1.1」と「レーダー1.1」を完全独立に掛けるのではなく、因果鎖を一度だけ記帳する。

# 3. 艦種別の暫定評価帯

これは技術正本の代替ではなく、戦史再監査で「小差として捨てない」ための初期帯である。

| 艦の性格 | 史実同世代艦に対する特定任務の実効値・初期帯 |
|---|---:|
| 旧式艦・小改装 | 1.05～1.20 |
| 大規模近代化した既存戦闘艦 | 1.15～1.35 |
| 計算効果を途中から基本設計へ入れた新造艦 | 1.25～1.50 |
| 1943～44年に体系設計された新造戦闘艦 | 1.40～1.70 |
| 任務適合が強く複数閾値を越えた後期艦 | 1.80～2.00級も条件付き |
| 潜高等、戦術形式自体が変わる潜水艦 | 2倍級以上も任務・敵条件付き |

「一隻が史実艦二隻を常に撃破する」という意味ではない。対空1.7、昼間砲戦1.25、夜戦1.5、対潜0.9のように任務ごとに異なる。

# 4. なぜ後期戦闘艦ほど差が出やすいか

既成艦改装は、船体、重心、発電、配線、射界、防御区画の制約を受ける。

後期新造艦は最初から、

- 構造重量と予備浮力。
- 発電・配電・冷却。
- 射撃指揮室・電探室。
- 高角砲・機銃の射界と弾薬供給。
- 防火区画、遠隔弁、ポンプ。
- 通信、I/O、交換ユニット。
- 将来上部重量余裕。

を同じ重量簿へ入れられる。

船体計算で3～5％余裕を得て、それを追加装備へ使い、その追加装備を較正・I/O改善で高稼働させる場合、最初の数％が複数段階へ伝播する。これを「同じ船体だから差は10％以内」と一律に抑えない。

# 5. 水上艦隊の価値は空母護衛だけではない

1944年日本海軍が主力艦を保存してきた以上、Marianas級決戦では次の任務を比較する。

## 5.1 高速戦艦群

金剛型は四隻生残している可能性が高く、30kt級実用速力を持つ。空母直衛だけでなく、

- 機動部隊前衛。
- 米巡洋艦・駆逐艦の邀撃。
- 夜間の水雷戦支援。
- Lee高速戦艦群を一方向へ拘束する別働打撃。

を比較する。

## 5.2 大和・武蔵等主力戦艦

第一目的を「敵戦艦との名誉ある砲戦」に固定しない。

- 米battle lineを拘束する。
- 条件成立時に上陸火力支援艦・APA/AKA/LSTへ突入する。
- 夜間・悪天候で上陸海面への存在脅威を作り、米TF58の自由な西進を制約する。

ことも戦略価値である。

## 5.3 重巡・駆逐艦

31の第二斉射を核に、第一群発射→離脱・再装填、第二群接触維持→発射、第一群再突入を検討する。目的は命中本数だけでなく、20～60分にわたり米側へ不規則変針・隊形変更・照明・レーダー監視を強制し、別部隊の進入窓を作ること。

# 6. 潜水艦は倍率がより露骨に出る

潜水艦では、水中速度・航続・静粛・深度制御・攻撃計算・電池信頼性が閾値を越えると、

> 水上で射点形成→潜って攻撃→水中は逃避

から、

> 潜航状態で射点へ移る→攻撃→側面へ再配置→再攻撃

へ変わる。

したがって、攻撃機会取得1.4、生還1.5、再攻撃1.3のような差が同時に成立すれば、生涯任務出力が2倍を超えることはあり得る。ただし敵ASW密度・航空哨戒・海域条件を掛けて判定する。

# 7. 米海軍の対日認識――「存在は知る、体系能力を割り引く」

1944年の米海軍は、日本海軍がいつか決戦を試みることを当然想定する。

- 金剛型等、公知の艦級と生残状況は概ね把握対象。
- 大型の脱条約戦艦が存在することも史実同様に知られている。
- 日本の艦隊決戦思想、夜戦・酸素魚雷の危険も既知。

したがってMarianasへ無警戒で上陸船団を置く設定にはしない。

一方、米側が事前に正確に評価しにくいのは、

- 艦内の重量・電力余裕。
- 射撃盤と電子補助計算、艦別較正。
- 電探距離と光学方位の情報統合。
- 配線・ポンプ・遠隔弁・防火区画による被害耐性。
- 魚雷再装填の故障分布改善と第二斉射教程。
- 後期艦の対空火力をどこまで一つの系として回せるか。

である。

作業用の認識幅は、艦数90～100％、通常公称性能80～90％、大和型実戦能力65～80％、射撃/I-O体系50～65％、第二斉射の再現性40～60％、1944年型艦隊対空60～75％程度から開始し、実戦観測で更新する。これらは確定情報値ではなく**戦史再監査用の事前分布**である。

# 8. 大規模海戦でのレーダー差

双方が敵主力の存在を知る大規模海戦では、米レーダー優位を「日本だけ敵を発見できない」という万能効果にしない。

評価するのは、

- 初接触時刻。
- 艦種識別・航跡安定までの分数。
- 射撃解・魚雷回避へ入るまでの分数。
- スコール・煙・夜間で追尾を失った後の復帰時間。
- CAP誘導と艦隊防空の閉ループ。

である。

昼間・視界良好な水上砲戦では、日本側の光学・射撃盤・補助計算が差をかなり縮め得る。夜間・悪視界では米側優位が大きい。艦隊防空では米側のレーダー、戦闘機指揮、VT信管、5in/38の統合優位を大きく残す。

# 9. 1944年Marianas戦史再監査v3

安全な現行史線は1944年6月10日まで。6月10日以後は次の順で再走査する。

1. **日本個艦台帳**：陸奥事故の扱い、金剛型四隻、長門級、大和・武蔵、扶桑・伊勢型、重巡、阿賀野級、夕雲・秋月等の生残・修理・就役。
2. **米個艦台帳**：大型CV/CVL、高速戦艦、旧式上陸支援戦艦、重巡・軽巡・駆逐艦、APA/AKA/LST、AO、潜水艦。
3. **米FORAGER計画**：日本決戦艦隊来援を高確率で想定し、Lee battle line、航空索敵、潜水艦線、上陸船団夜間護衛をどう配置するか。
4. **日本決戦計画**：空母航空だけでなく、高速戦艦前衛、水雷戦隊、主力打撃隊、基地航空、潜水艦を時間差でどう組むか。
5. **相互欺瞞**：米側にLeeをどこへ拘束させるか、日本側にTF58をどこへ引き付けるか。
6. **晴嵐**：初撃条件を再評価。米前進泊地へ使う場合も、水上艦隊の出撃日・米防空再配置との相互作用を入れる。
7. **戦闘**：一日単位ではなく必要に応じ数時間単位。第二斉射、夜間接触、battle lineの距離、航空攻撃の時間を同期する。

# 10. 戦史上の手戻り範囲

Marshall、Truk、Eniwetok、Palauについて、日本主力水上艦を固定基地救援へ投入しない判断自体は合理的で、中心結果を全面撤回しない。ただし米側は常に日本主力艦隊の存在を意識していたため、作戦計画文脈へ対水上警戒を遡及追記する。

本格的に結果を再計算する境界は、Marianas決戦準備が具体化し、日本水上主力が「島を救う護衛」ではなく「米上陸作戦機構を直接破砕する戦力」になり得る**1944年6月10日以後**とする。

## 2026年8月13日追加――代表艦級での任務係数校正

10・30・31・61の代表艦級監査を受け、任務係数の初期感度帯を校正する。以下は**史実同艦・同条件を1.00とした診断帯**であり、艦の固定総合倍率ではない。戦史へ投入する際はHull count、Availability、Coordination、Situationを別に掛け、関連する同一事象を二重計上しない。

### 金剛型

- 昼間良視界の通常水上砲戦：1.04～1.08級。
- 米新鋭戦艦との昼間正面戦：1.05～1.10級をまず監査。基本装甲の律速を残す。
- 光学接敵が成立する高速夜戦・巡洋艦／駆逐艦邀撃・水雷戦隊支援：1.15～1.25級を感度帯とする。
- 30kt級の価値は最高速差ではなく、四隻戦隊が予定速力・燃料・故障条件を満たす再現性に置く。

### 大和型

- 46cm主砲体系の通常昼間射撃部分：1.03～1.07級。
- 長距離の初期射撃・初回夾叉機会：条件次第で1.08～1.15級を試験するが、飛翔時間・敵運動推定が律速するため戦闘全体へ同じ倍率を掛けない。
- 艦全体の利得は、砲威力ではなく、射撃成熟前倒し、実用速力、配電・操舵冗長、装甲支持、損害局限、対空指揮・給弾の統合に置く。
- 中程度損傷からmission killへ進む確率の相対10～20％低下を感度試験対象にするが、破局的損傷では効果を小さくする。

### 陽炎型・夕雲型

一艦の魚雷命中率倍率より、次の事象を独立に持つ。

1. 第一斉射5～12kmで技術的無駄弾を減らす効果。
2. 第一斉射後、各艦が0/4/8本の第二斉射状態へ達する確率。
3. 駆逐隊のうち何隻が13～25分級で再接触できるか。
4. 敵の回避・隊形崩壊を金剛型等の砲戦部隊が利用できるか。

「32本＋次発32本＝64本」の単純火力換算は禁止する。第二斉射能力は、平均火力より**戦闘後半にも魚雷脅威が残る確率**として敵の変針、速度変更、隊形維持、射撃解へ波及させる。

### 防御・攻撃の重複禁止

配電分離、消防・排水、操舵冗長が「生存率」と「射撃継続率」の双方へ効く場合、1.1×1.1のように別倍率で重ねない。中程度損傷後に残る任務機能を一つの条件付き状態として計算する。


## 2026年8月14日追加――例外艦・延命艦の評価規約

史実で沈没・大破・緊急転用された艦が現行史線で生残する場合、史実改装を年次だけで自動発生させない。`現役続行 / 小改装 / 任務転換 / 予備 / 練習・試験 / 除籍` を比較し、残存船体寿命、任務適合性、改装後Availabilityに対して、改装工数、船渠占有、機器・熟練工・乗員の機会費用を置く。

最上型の1941年純20.3cm砲戦は前期群約1.07、後期群約1.09中心。夜戦・雷撃は条件が整う場合1.25～1.35級だが、味方混在の近距離飽和戦では1.10～1.16級へ圧縮し、誤射抑止・射撃統制へ価値を移す。固定総合倍率にはしない。

伊勢型の旧8～12%等も固定戦闘力倍率ではなく、改装・可動・I/O・損傷後機能保持の単軸作業値として読む。


## 2026年8月14日追加――潜水艦任務実効値の分解

潜水艦では、魚雷命中率・最大水中速力だけで任務係数を作らない。最低限、

`出撃成立 × 配置時刻 × 接触 × 射点変換 × 再捕捉 × 攻撃 × ASW離脱 × 充電成立 × 再出撃`

へ分ける。

潜高は水中高速で射点変換・離脱・再配置を改善するが、高速時の聴音低下と電池消費を同時に持つ。敵航空哨戒は撃沈だけでなく夜間充電を妨げ、翌日の高速機動予算を削る。攻撃せず敵主力位置を通報した艇の情報価値、航路変更・護衛・航空哨戒を強要した敵拘束も任務成果へ含める。

21の任務分化を用い、甲乙型、通常攻撃艇、呂号、潜高を同一の「日本潜水艦」倍率へまとめない。


# 10. 2026年8月14日追記――Marianas実艦台帳監査の閉鎖

Marianas前に要求していた日本実艦台帳の第一段階は38で閉じた。以後FORAGER OOBでは、艦種総数を再び丸めて消さず、38のA/B/C状態と任務適合を入力にする。

特に、

- 日本の主力空母航空は米国より量的劣勢が大きい、
- しかし戦艦・重巡・駆逐艦・明石・AOの残存差は史実より大きい、
- Marianas遅延は米Franklin/Intrepidを実戦化する一方、日本雲龍/天城は艦体完成だけで航空隊が追いつかない、

という三点を同時に維持する。したがって戦史再監査は純空母戦へ戻さず、基地航空、潜水艦、給油群攻撃、高速水上前衛、夜戦、水雷第二斉射、大和型主力打撃、修理・再給油を別時計で評価する。

# 2026年8月14日追加――戦術成熟係数は独立勘定

44を参照し、艦艇評価へ「戦術成熟」を追加する。ただしMission effectivenessへ一律乗算しない。

- 索敵：見落とし率・再捜索時間。
- 空母：CAP交代、攻撃隊到着分散、甲板危険状態時間。
- 水上艦：同時変針、緊急散開、再集合、第二魚雷斉射。
- 対空：回避操艦と高角砲射界の両立。
- 指揮：複数案の演習比較と投入閾値の事前化。

特に1944年Marianasでは、史実型の「未熟搭乗員＋未完成隊形運用」を自動継承しない。一方、F6F、米レーダーfighter direction、VT信管、米側の大量飛行訓練・生産優位を消さない。
