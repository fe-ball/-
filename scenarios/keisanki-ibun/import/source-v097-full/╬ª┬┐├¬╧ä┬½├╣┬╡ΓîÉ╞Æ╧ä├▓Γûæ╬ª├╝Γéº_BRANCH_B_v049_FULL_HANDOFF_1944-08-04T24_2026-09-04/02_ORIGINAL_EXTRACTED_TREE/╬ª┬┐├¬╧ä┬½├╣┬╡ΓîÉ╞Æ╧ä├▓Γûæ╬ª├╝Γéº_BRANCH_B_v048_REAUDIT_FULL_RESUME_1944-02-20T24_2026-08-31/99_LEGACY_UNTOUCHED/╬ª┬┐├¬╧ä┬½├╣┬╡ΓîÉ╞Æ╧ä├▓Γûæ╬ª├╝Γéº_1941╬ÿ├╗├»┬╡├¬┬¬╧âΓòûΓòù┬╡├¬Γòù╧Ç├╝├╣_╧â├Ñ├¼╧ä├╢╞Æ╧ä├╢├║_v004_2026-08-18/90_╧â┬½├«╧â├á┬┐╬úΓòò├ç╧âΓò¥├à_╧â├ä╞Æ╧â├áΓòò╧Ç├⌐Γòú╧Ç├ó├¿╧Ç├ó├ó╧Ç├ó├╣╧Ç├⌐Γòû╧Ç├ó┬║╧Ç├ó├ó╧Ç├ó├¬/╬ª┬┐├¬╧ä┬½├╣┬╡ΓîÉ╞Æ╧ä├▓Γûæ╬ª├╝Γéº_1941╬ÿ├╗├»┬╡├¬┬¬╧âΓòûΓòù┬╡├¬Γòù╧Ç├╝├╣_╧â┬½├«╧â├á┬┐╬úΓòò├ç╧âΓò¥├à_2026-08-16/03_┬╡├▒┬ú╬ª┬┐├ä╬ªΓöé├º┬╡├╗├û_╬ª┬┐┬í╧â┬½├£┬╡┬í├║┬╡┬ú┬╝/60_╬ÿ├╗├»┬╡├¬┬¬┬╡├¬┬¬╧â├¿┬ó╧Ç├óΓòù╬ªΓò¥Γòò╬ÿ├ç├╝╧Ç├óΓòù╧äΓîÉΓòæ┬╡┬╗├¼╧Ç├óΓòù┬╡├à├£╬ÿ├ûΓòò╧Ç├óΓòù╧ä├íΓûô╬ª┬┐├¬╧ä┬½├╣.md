# 計算機異聞・開戦戦力・輸送・空母・揚陸・砲計算

## 0. 本書の役割

本書は1941年12月前後の侵攻能力を、輸送、空母、揚陸、砲計算の横断勘定として扱う。航空機の機種別・発動機別正本は `50_航空機研究_陸海軍総合正本.md` とし、ここでは重複させない。

航空側の接続値は、日本軍戦術機2,850～3,050機、帳簿上の純増約9～16％、第一線の実効作戦出力15～25％増を中心とする。空母搭載枠はほぼ固定であり、機体生産増をそのまま搭載機増へ足さない。

# 1. 民間船への計算利用――制度は簡略化して結果だけ固定

詳細な組織ヘッドカノンは詰めすぎない。次の程度でよい。

> 両軍が研究所と一部企業とともに組織した特別な計算部隊に対し、指定された機密案件の計算依頼を出す権利が秘密裏に付与される。

一般民間会社へ計算機が全面公開されるのではない。利用権は会社全体でなく案件につく。

- 軍艦、軍指定船、有事改装予定船は早期から直接利用。
- 一般商船は公開計算法、卓上機、工程・品質文化の間接効果が中心。
- 1937年以降、軍需関連船へ対象拡大。
- 1940年末以降、海運統制の内側へ入った徴用・軍需輸送案件へ広く適用。
- 開戦後の即効性は新造船設計より、改装、積載、船団、港湾、修理、燃料管理。

# 2. 開戦時の輸送能力と戦時標準船

## 2.1 開戦時の固定表現

**決定：1941年12月の輸送能力差は、指定船・徴用船の「計算依頼」による、いくらかの純増。戦時標準船による本格的な船腹増加はその後。**

開戦時に効くのは、積載、トリム、復原、デリック、ハッチ、舟艇、港湾滞在、修理優先順位である。

- 商船総船腹：史実比2～4％増が上限級。
- 一航海の有効軍需輸送：4～8％増。
- 第一波揚陸物資：6～12％増。
- 港湾・泊地滞在：8～15％短縮。
- 月間輸送回転：5～10％増。
- 選別された第一線船団の実効輸送：10～15％増の場合。

## 2.2 第一次戦時標準船

- 1940年から秘密案件として設計・工程準備。
- 型式確定：1941年中盤～後半。
- 貨物船、鉱石船、油槽船のおおむね10系統を維持。
- 船型数より、主機、発電機、ポンプ、ウインチ、弁、扉、ハッチ等を共通化。
- 船台切替：史実より3～5か月早い。
- 本格完成：1942年春～夏。
- 1942年新造量：史実比12～20％増。
- 累積純増：5～9万総トン級。
- 稼働・載貨を含む輸送力：史実比8～14％増。

第一次型の中心改善：工数10～18％減、手戻り20～35％減、載貨2～4％増、燃料3～6％減、荷役8～15％短縮。

## 2.3 第二次戦時標準船

極端な粗製船を消さず、量産性を維持しながら速力・耐久を少し戻す。

| 型 | 本世界航海速力・中心 |
|---|---:|
| 2A | 10.5～11.0kt |
| 2D | 9.5～10.0kt |
| 2E | 7.8～8.4kt |
| 2TL | 13.0～13.5kt |
| 2TM | 10.5～11.0kt |
| 2ET | 7.8～8.5kt |

- 設計耐用7～10年。
- 史実第二次型より建造期間5～10％長く、鋼材2～4％増。
- 休航率20～35％低下。
- 一隻当たり年間有効輸送量15～25％増。
- 第三次型は大きな世代交替より、第二次改型の連続ロット改善へ吸収される可能性。
- 木造標準船は沿岸・二次輸送専用。外洋船腹の代替と数えない。


## 2.4 暗号防御との接続

暗号設計、鍵物流、通信規律、暗号攻撃、交通分析は `70_暗号・通信情報_設計防御・攻撃・運用.md` を正本とする。

1941年末～1942年には、中央のType 2級暗号計算所とカード設備により、自軍暗号の偏り検査、添加数重複、鍵使用量、更新遅延、通信規律違反を史実より早く発見できる。

ただし丸暗号の改善だけで海運が安全になるとはしない。潜水艦の船団攻撃は、情報取得、哨戒海域への移動、接触、射点進出、有効発射、離脱、再攻撃の連鎖で成立する。暗号解読が強く効くのは前半であり、その後は東海、カ号、護衛艦、船団運用、前進基地の圧力を受ける。

したがって、暗号防御は対潜戦を単独で成立させるものではなく、成立しつつある対潜・護衛体系から情報上の大穴を除くものと位置づける。

海上輸送損耗は、暗号防御、対潜航空、艦艇対潜・護衛、航路・船団編成、港湾、船腹建造・修理を統合して計算する。艦艇側の対潜性能・二艦協同・局地護衛指揮は `41_艦艇対潜_探信・爆雷・護衛運用.md` を参照する。暗号防御単独の損失低下率は現段階で固定しない。

# 3. 空母・改装空母――任務階級をまたぐ効果

## 3.1 基本判断

日本空母は合成甲板風に強く依存する。低速空母でも正面自然風を得て、艦載機側の失速・加速・フラップ・重量管理が改善すれば、発艦任務では上位級へ近づく。

ただし着艦は制動エネルギー、艦の風上転針、動揺、甲板事故があるため、階級差が残る。階級越えは条件付き。

低級空母が上がるのは排水量階級ではなく、次の任務階級。

- 航空機輸送艦→限定護衛・攻略支援空母。
- 軽空母→小型艦隊空母。
- 改装商船空母→低速中型艦隊空母。

戦闘任務に使えば回送能力と食い合う。その交換関係自体が、作戦選択肢の増加になる。

## 3.2 開戦時各艦

### 龍驤

- 最大速力29.0～29.4kt。
- 実用航空隊36～40機。
- 最大回送45～48機級。
- 戦闘機12～15、艦攻・艦爆21～25の例。
- 甲板処理10～15％改善。
- 任務階級：小型艦隊空母。

### 瑞鳳

- 最大28.0～28.4kt。
- 実用27～30機、過載回送32～35機。
- 編制例：零戦15＋B5N12、または零戦9＋D3A9＋B5N9。
- 出撃回転8～15％改善。
- 完全な軽艦隊空母。

### 祥鳳

- 改装工事15～25％短縮、約2～3か月前倒し。
- 竣工：1941年10～11月中心。
- 開戦時実用航空隊18～24機。
- 1942年初頭24～27機級。
- 真珠湾機動部隊には教育不足だが、南方、台湾、パラオ、回送・船団援護へ使用可能。

### 大鷹

- 艦速21kt、飛行甲板約162m級という制約は残る。
- 回送専用：27～32機。
- 混成：18～24機＋輸送6～10機。
- 戦闘形態：18～24機、例として零戦9～12、B5N6～9、予備3。
- 主任務：CAP、PBY・Hudson等の追い払い、対潜・索敵、軽爆撃、揚陸支援。
- 良好な正面風で任務階級をまたぐ。無風・悪天候・重装備雷撃では低速空母へ戻る。
- 一航海戦闘運用すると、補充機20～30機級の回送を失う。

### 鳳翔

訓練、試験、旧式機・軽機回送。大改装して戦闘艦へ戻すより、祥鳳・大鷹・隼鷹へ資材を回す。

## 3.3 開戦時空母航空戦力

| 艦群 | 本世界の実用航空機 |
|---|---:|
| 主力六空母 | 約390～410 |
| 龍驤 | 36～40 |
| 瑞鳳 | 27～30 |
| 祥鳳 | 18～24 |
| 大鷹を戦闘運用 | 18～24 |
| 鳳翔 | 12～18、主に訓練 |

- 鳳翔の訓練・回送機を除く戦闘使用可能合計：約490～525機。各艦の幅を単純合算した値ではなく、航空隊完成度、予備機、回送任務、大鷹の任務選択を重複調整した統合値。
- 史実相当約455～475機に対し、35～60機、7～13％増。
- 大鷹を回送専任にすれば、常時増加は25～40機相当。
- 数的増加以上に、正規空母を使わず航空支援できる作戦正面が一つ、条件により二つ増える。

## 3.4 1942年以降

### 隼鷹・飛鷹

- 約25.5kt、実用45～50機、最大回送55～60機級。
- 改装工期15～25％短縮。
- 公試後手直し25～40％減。
- 機関・通風初期故障20～35％減。
- 隼鷹船体完成1942年2～3月、航空隊完成4～5月中心。
- 飛鷹船体完成4～5月、航空隊完成6月前後。
- 任務階級：低速中型艦隊空母。

### 龍鳳

- 26.5～27.0kt。
- 実用27～30機、最大32～35機級。
- 船体強度・区画性改善。
- 完成1942年8～10月級。ただし敵空襲・潜水艦被害は別時計。

### 秋津丸とカ号

開戦時侵攻には影響しない。1942年試験、1943年実用航空隊が中心。カ号4～6機なら揚陸能力を残しつつ観測・連絡・局地対潜。8～10機は対潜重視で揚陸能力との交換。

# 4. 揚陸舟艇・特殊船――現行中心線

現行判断として、この分野は際限なくなるため一旦停止。ただし既に出した中心線を保持する。

- 上陸舟艇純増：史実比8～15％。
- 実働率：7～12ポイント増。
- 第一日総揚陸量：15～25％増。
- 第一日重装備揚陸：15～25％増。
- 平穏時往復回数：10～15％増。
- 荒天時改善：3～10％程度。
- 積載・海岸間違い：20～35％減。
- 機関・軸系故障：15～30％減。
- 上陸後戦闘準備：2～8時間短縮。
- 連続島嶼作戦の再準備：2～5日短縮する場合。

大発・特大発の主効果は最高速ではなく、故障せず、正しい積荷を正しい海岸へ運び、重火器・車両を数時間早く戦力化すること。神州丸は隻数を増やさず、舟艇発進・復原・積載・火災区画・第一波編成を改善する。

この差が演習・実戦で安定すると、積載思想自体が「歩兵人数を先に出す」から「歩兵・砲・弾薬・通信・工兵・牽引具を同一浜・同一時間帯へ揚げ、数時間以内に諸兵科戦闘単位を作る」方向へ自然に寄る。これは61で**揚陸パッケージ化**として質的戦術変化に分類する。

# 5. 砲計算の進捗

## 5.1 考察済み

- 初号機の主要キラーアプリとして射表計算。
- 弾道数値積分、抗力表補間、気温・気圧・風・装薬補正。
- 砲身摩耗、装薬温度、弾薬ロット別初速補正。
- 光学、測距儀、照準器公差。
- 砲架・砲塔・支持部の振動。
- 大和型46cm砲で試射数を20～30％削減しつつ、射表・射撃盤の技術的戦力化を3～6か月短縮する中心推定。
- 艦載光学、電探、機械式射撃盤、電子弾道補助器の分担と情報受渡しは `30_センサー射撃指揮_I-O連鎖.md` を正本とする。

海軍水上射撃の現行中心値：

| 条件 | 効果 |
|---|---|
| 通常昼間水上射撃 | 総合命中率2～5％相対向上、初回夾叉まで5～10％短縮 |
| 長射程・非標準気象 | 初期諸元系統誤差20～30％低減、射撃解収束10～20％短縮、初回夾叉可能性8～15％向上 |

艦砲の実戦命中率を一律20～40％向上とはしない。技術的誤差、夾叉までの時間、最終命中率を分ける。

## 5.2 未考察・未統合

### 海軍砲術の残作業

測距儀、方位盤、射撃盤、艦載補助器の基本分担は考察済み。未了なのは、次を艦種・交戦条件別の兵器体系へ落とす作業である。

- 横揺れ・縦揺れ、斉射散布、砲塔別初速。
- 九一式徹甲弾の空中・水中弾道と命中後効果。
- 夜戦、探照灯、航空観測、電探測距の手順。
- 主砲、副砲、高角砲、機銃の指揮系統。
- 上陸支援射撃と艦隊砲戦の別個の交戦モデル。

### 陸軍砲兵

- 野砲、山砲、重砲、臼砲、高射、対戦車系列。
- 測地、地図、気象、前進観測、無線・有線。
- 観測射から効力射、複数大隊集中、対砲兵。
- 航空観測、弾薬消費、牽引・展開。

弾道・射表・公差改善の原理は共有できるが、実戦命中率10～30％という旧総括値は撤回し、体系監査まで未固定とする。

### 高射砲・高角砲

三次元目標、未来位置、信管秒時、追随速度、電探・聴音・探照灯との接続を独立して処理する必要がある。近接信管なしでは弾幕中心が残る。実戦命中率10～30％という旧総括値は撤回し、射撃指揮装置、信管、追随速度、部隊教育を統合するまで未固定とする。

侵攻能力の統合を再開する場合、陸軍砲兵は上陸後進撃、海軍砲術は艦隊戦・上陸支援、高角・高射は防空体系の段階で処理する。

# 7. 1942年MI後の空母建造政策

## 7.1 歴史シナリオ条件

本節は現行暫定史線 `85_歴史考察_2026-08-10_MO・MI再監査_暫定作業線.md` のMI後事象、すなわち、

- MI作戦目標はほぼ達成。
- 米空母主力へ壊滅的損害。
- 日本も赤城・加賀・蒼龍喪失、飛龍大破。
- 三空母で大規模格納庫火災・二次災害を経験。

を受けた艦政・造船判断である。

## 7.2 飛龍／雲龍系の数量要求

**上書き中心判断：史実の「飛龍型14隻級」要求そのものを、後世的に単純な過大要求とは扱わない。**

14隻級は一時に建造する数ではなく、複数年度にわたって米国の将来空母増勢と戦時消耗へ対応する長期要求として読む。

本世界でも、

- 米国の公知・推定可能な空母大量建造は消えない。
- MIで日本自身も「一会戦で複数空母が消耗する」ことを経験する。

ため、**雲龍／飛龍系の長期要求は12～14隻、中心は14隻級を維持してよい**。

ただし、

> 要求隻数 ≠ 同時起工隻数 ≠ 実完成隻数

である。

船台、乾ドック、機関、減速歯車、電装、兵装、熟練工、航空隊を監査し、起工はロット化する。

現段階では「6～8隻しか造らない」と固定しない。前半ロットを実際の工場へ割り当て、後続起工時期を戦況・工業実績で再監査する。

## 7.3 MI勝利で減るのは緊急代用空母

MIで米空母主力へ大損害を与えたため、史実ほど「何でも飛行甲板にする」短期圧力は強くない。

現在の中心判断：

- 隼鷹・飛鷹：既存改装を完成。
- 龍鳳：既存改装を継続。
- 雲龍第302号艦：建造継続。
- 大鳳：建造継続。
- **千歳・千代田：空母改装せず、水上機母艦として維持する。** 1943年秋に強風・瑞雲・分散水上機泊地の運用価値が実戦で確認され、可搬水上航空基盤としての任務が明確化した。将来の重大な空母損耗が起きた場合のみ再検討する。
- **伊勢・日向の航空戦艦化：中心線では実施しない。**
- 商船・水上機母艦の追加緊急空母化：近完成・既決定分を除き抑制。
- **信濃：MI直後に空母化を自動決定しない。** 大型横須賀ドックをいつ空けるかを含め、戦艦続行・空母・航空支援艦・一時中断を比較する。

千歳・千代田は上記のとおり**現行決定**へ昇格した。信濃は第9章で上書きする。

## 7.4 大鳳系

大鳳は別系統の「質」の空母として継続する。

雲龍を大鳳化しない。

大鳳後続は史実の大規模要求を即時全数確定するのではなく、最初の1～2隻級または設計・資材枠を保持し、大鳳実艦・工数・雲龍量産実績を見て再判断する中心案とする。

# 8. 雲龍系――MI戦訓反映基準

## 8.1 位置づけ

**上書き決定。**

雲龍系は、飛龍を基礎とする17,000t級・34kt級の高速中型量産正規空母という基本思想を維持する。

大鳳級の装甲空母へ統一しない。

要求は、

- 艦隊速力。
- 50～60機級実用航空能力。
- 次世代5～6t級艦上機。
- 大鳳より小さい工数・船台負担。
- 同型大量建造に適する標準化。

である。

## 8.2 MI戦訓を明記する

今回のMIは、**作戦結果としては史実日本側の理想に近い一方、日本側にも大量空母損失と大格納庫火災が発生した戦闘**である。

最重要戦訓：

> **飛行甲板を一発で使用不能にされることは避けきれない。しかし、飛行甲板を失うことと艦を失うことを同義にしない。**

雲龍系は「被弾後も必ず航空攻撃を続ける空母」ではなく、

> **一発被弾でmission killを受けても、火災・燃料・弾薬・煙・消防水の連鎖を局限し、曳航または自力で帰れる確率を高める空母**

を設計目標へ追加する。

## 8.3 第302号艦・雲龍で即時反映するもの

基本船型・機関・二段格納庫は凍結し、詳細設計・艤装で反映する。

高確度採用候補：

- 消防主管の区画分割。
- 片側主管喪失時のクロスコネクション。
- 消防ポンプ・非常ポンプの電源・吸水経路分散。
- 格納庫スプリンクラー／水幕の細分化。
- 泡消火設備増強。
- 航空燃料主管の区画別遮断弁。
- 遠隔遮断＋現場手動遮断の二重化。
- 給油時以外の主管残油を減らす運用。
- 格納庫排水能力増強。
- 消防水滞留と自由表面の計算表。
- 通風ダンパー区画化、火災時煙隔離モード。
- 非常発電・照明・航空／応急通信の冗長化。
- 爆弾・魚雷の格納庫内長時間仮置きを制限。
- 防火材・難燃内装の採用範囲拡大。
- 帰還燃料機と武装待機機を可能な範囲で分離する運用。

## 8.4 第302号艦で行わないもの

- 装甲飛行甲板化。
- 格納庫一段化。
- 船幅の大幅拡張。
- 第三エレベーター追加。
- 機関配置全面変更。
- 大鳳級水中防御の移植。
- 基本搭載機数を大幅に削る重装甲化。

これらは後続改型の比較案であり、雲龍一番艦の起工・工期を壊してまで入れない。

## 8.5 後続艦

後続ロットでは第302号艦より深く、

- 航空燃料タンク周辺構造。
- 配管貫通部。
- ポンプ室位置。
- 消防主管配置。
- 排水路。
- 非常電源。
- 通風。
- 艦内通信。

を構造設計段階から整理する。

ただし「大鳳-lite」にはしない。量産中型空母という役割を維持する。

## 8.6 追加安全重量

現段階では最終排水量を固定しない。

**100～300t級の追加安全・サービス重量を許容する比較設計**から始め、消防、燃料、排水、電源、通風、防火材の重量簿を積み上げる。

これは確定重量ではない。

優先順位：

1. 艦隊速力。
2. 次世代艦上機50～60機級運用。
3. 単発被弾時の艦喪失率低下。
4. 建造工期。
5. 搭載機数微増。

安全設備のため数機分の格納余裕を失う場合でも、無理に搭載数を戻すため防火設備を削らない。

## 8.7 「火災計算」の範囲

1942年に可能：

- 燃料量×発熱量の熱負荷概算。
- 管径、圧力、破孔、遮断時間から流出量。
- 格納庫容積、換気量、危険蒸気蓄積の近似。
- 消防主管の圧損、ポンプ喪失組合せ。
- 主管・電路・通風の故障木。
- 放水量、排水、消防水自由表面、復原性。
- 遮断・移送・弾薬処理の時間系列。
- 複数の命中位置・在庫状態を振った故障シナリオ比較。

1942年に精密予測できない：

- 任意の乱流火炎伝播。
- 爆弾破片による着火時刻。
- 弾薬誘爆の完全な確率過程。
- 任意戦闘損傷での全カスケード。

MIは未知の火災連鎖を全部解く事件ではない。

> **何を実験し、何を設計計算へ昇格させるべきかを、実戦時系列で初めて大量に教える事件**

とする。

## 8.8 今後の造船所監査

雲龍系の長期要求を実完成数へ落とすには、

- 横須賀。
- 呉。
- 佐世保。
- 川崎神戸。
- 三菱長崎。
- 舞鶴。
- 播磨等。

について、船台、乾ドック、艤装岸壁、機関工場、減速歯車、電装、熟練工、修理工事との競合を個別監査する。

# 9. 1943年夏秋の空母・改装艦政策――上書き決定

## 9.1 改装空母を増やしすぎない

既存・進行中の改装は完成する。

- 隼鷹、飛鷹、龍鳳、冲鷹：完成・運用。
- 大鷹、雲鷹等の既存補助空母は輸送・護衛・訓練任務を継続。

一方、1942年MI後の現行戦力と1943年の造船余力を踏まえ、次は**新規空母改装しない**。

- 海鷹。
- 神鷹。
- 千歳、千代田。
- 伊勢、日向の航空戦艦化。
- 伊吹の空母化。

**判断の理由：** 本世界では史実Guadalcanal型の連続空母・駆逐艦消耗がなく、緊急に「あらゆる船体を飛行甲板へ変える」圧力が弱い。改装は船台・機関・電装・熟練工・航空隊を消費する。量は雲龍系、質は大鳳という専用艦系列で確保し、水上機母艦・重巡・商船の本来任務を残す方が総合効率が高い。

## 9.2 信濃

**信濃は空母化しない。戦艦としても完成させない。**

1943年第4四半期を中心に、横須賀大型船渠を解放できるところまで船体を完成・浮揚し、その後は未成艦として係留保管する。

**判断の理由：** 既に投入した船殻を即解体する利益は小さいが、46cm戦艦三番艦を完成させる戦略需要も、巨大空母へ改装する短期需要も弱い。最大の機会費用は横須賀大型船渠を占有し続けることであり、船渠解放を優先する。

## 9.3 大鳳と雲龍系

- 大鳳：装甲・防御・新艤装を試す**質の試験艦**として完成。1944年2月完成中心。
- 雲龍系：**量の主線**。大鳳化せず、中型高速空母の標準化と建造回転を優先。
- 大鳳後続：設計・資材枠を1隻分程度保持し、大鳳実艦試験後に起工判断。複数隻同時量産はしない。

現行建造時計中心：

| 艦 | 中心線 |
|---|---|
| 雲龍 | 1944年6～7月完成 |
| 天城 | 1944年6～7月完成 |
| 葛城 | 1944年8～9月完成 |
| 笠置 | 1945年前半 |
| 阿蘇 | 1945年前半～中盤 |
| 生駒 | 1945年前半～中盤 |

**判断の理由：** 改装空母を減らして浮く工数は1943年中に数隻の新空母を生むほど大きくない。効果は1944～45年に雲龍系二次ロットの停滞を小さくする形で出る。空母航空隊・整備員の養成が艦体数とは別の律速として残る。

# 10. 1943～44年の鉄鋼・商船・沿岸輸送政策

## 10.1 粗鋼・鋼塊の中心線

| 年 | 中心 | 範囲 |
|---|---:|---:|
| 1943 | 8.1百万t | 7.9～8.4百万t |
| 1944 | 8.7百万t | 8.2～9.3百万t |
| 1944高位枝 | 9.5～10.0百万t | 条件依存 |

理論炉能力13百万t級へ急接近する線は採らない。高炉・製鋼炉の物理容量より、鉄鉱石、原料炭、屑鉄、港湾、鉄道、コークス、焼結、耐火物、電力、圧延が実効生産を制約する。

物理的製鋼容量の増加は1944年まで0～3％、1945年まで3～5％級。計算・保全・工程改善による実効稼働率上昇を3～7％級中心とする。

**判断の理由：** 史実でも日本の製鋼設備は理論能力より原料輸入不足に強く拘束された。本世界では船腹・護衛・港湾運用が健全なため1944年の史実型急落を避けやすいが、炉を短期間に倍増する技術ではない。

## 10.2 商船建造

1944年の鋼製商船建造は**1.2～1.45百万GRT級**を中心とする。史実末期型の最大トン数競争より、速度、機関信頼性、荷役、標準部品、修理性を重視する。

- 一隻あたり年間有効輸送量：史実緊急標準船比で15～25％高い局地を許容。
- 造船用鋼材比率：総鋼材の25～30％級を作業線とし、鉄道、トラック、工作機械、港湾設備へ余力を残す。
- 「史実1944年商船建造量を必ず超える」を目標にしない。失船が少ない場合は、同じ有効船腹をより少ない新造トン数で維持できる。

**判断の理由：** 本世界の輸送優位は新造量だけでなく、沈没回避、修理日数短縮、稼働率、荷役、航路統制から生じる。史実の緊急粗製船を同じ比率で量産する必要がない。

## 10.3 木造・コンクリート沿岸船

1943～44年の木造標準沿岸船は**400～700隻、8～14万t級**を中心とする。建造労務8～15％、木材3～6％、手直し15～25％、燃料4～8％、休止15～25％程度の改善を作業幅とし、年間有効輸送10～20％増を目標にする。

コンクリート自航貨物船は10～30隻級に抑え、艀、油・水・貯蔵用途を数十隻追加する。

**判断の理由：** 沿岸輸送は北海道・九州炭、内地原料、港間輸送を鋼製外航船から切り離す。コンクリート船は主造船所を空ける補助策にはなるが、鉄鋼不足が史実ほど極端でないため主力船種へ拡大しない。

## 10.4 輸送台帳で分けて追うもの

以後、輸送力は総GRTだけでなく、最低限次を別台帳にする。

- 輸入鉄鉱石・原料炭の到着量。
- 北海道・九州炭の沿岸輸送量。
- 外航／沿岸輸送比率。
- 船腹新造、沈没、長期修理、港湾待機。
- 艦艇・商船建造が消費する鋼材と熟練工。

1943年の沿岸輸送比率16～18.5％、1944年15～18％を暫定中心線とする。
