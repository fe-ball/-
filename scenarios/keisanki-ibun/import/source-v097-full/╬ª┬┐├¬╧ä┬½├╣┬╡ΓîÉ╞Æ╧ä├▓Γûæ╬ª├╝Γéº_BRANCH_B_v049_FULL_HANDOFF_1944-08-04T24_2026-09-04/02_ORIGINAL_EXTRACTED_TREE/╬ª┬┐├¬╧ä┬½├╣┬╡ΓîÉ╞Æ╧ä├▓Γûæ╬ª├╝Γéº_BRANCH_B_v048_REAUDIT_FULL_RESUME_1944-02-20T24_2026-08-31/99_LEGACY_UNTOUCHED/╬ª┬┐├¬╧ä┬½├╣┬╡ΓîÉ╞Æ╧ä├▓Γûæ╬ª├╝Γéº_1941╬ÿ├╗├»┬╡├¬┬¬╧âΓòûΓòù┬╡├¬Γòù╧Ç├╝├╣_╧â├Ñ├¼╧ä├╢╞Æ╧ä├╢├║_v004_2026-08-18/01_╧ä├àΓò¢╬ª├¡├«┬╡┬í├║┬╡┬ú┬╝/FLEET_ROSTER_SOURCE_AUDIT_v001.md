# 1941年12月艦隊表 史料監査 v0.01

## 結論

CGSC掲載の `Japanese Fleets, December 1941` は、開戦時編制を復元する便利な索引だが、**1941年12月7/8日瞬間の個艦可用表としては使わない**。

理由：同表は「December 1941」の月次整理であり、大和をCombined Fleetの1st Battleship Divisionに含めるなど、月内の就役・編制変化を含む。したがって開戦瞬間の状態を作る際は、個艦の就役日・工廠状態・出港記録・作戦命令で補正する。

Monograph 116自身も、資料欠落・不完全性を明記し、研究用referenceであって単独完結資料ではないとしている。

## 使用規約

### 使用してよい

- 艦隊・戦隊・潜水隊の編制候補を拾う。
- 個艦名の網羅的な探索母集団を作る。
- 後続の個艦照合で「漏れ」を検出する。

### 使用してはいけない

- 表に載っている = 12月8日に即応。
- 表に載っている = その戦域へ既に到着。
- 月内の編制を12月8日瞬間値へ固定。
- 表の転記ミスを個艦履歴より優先。

## 潜水艦で既に見つかった補正例

- 第5潜水戦隊：伊59/伊60は開戦日に整備・近代化中。名目6隻をマレー即応6隻にしない。
- 第4潜水戦隊第19潜水隊：月次艦隊表の個艦表記と個艦TRoMが食い違うため、開戦実任務は個艦履歴を優先。
- 第6潜水戦隊：伊123は潜舵故障で潜航不能、敷設後修理帰投。名目「1隻」を完全任務可能1隻にしない。

## 水上艦へ同じ規約を適用

各主要艦について、12月7/8日夜の状態を

`COMMISSIONED → IN_COMMISSION_LOCATION → MECHANICAL_READY → FUEL/AMMO → CREW → ASSIGNED_FORCE → ACTUAL_TASK → SAILING/ON_STATION`

で照合する。

特に大和のような月内就役艦、工廠改装艦、訓練中艦は開戦戦力へ誤算入しない。
