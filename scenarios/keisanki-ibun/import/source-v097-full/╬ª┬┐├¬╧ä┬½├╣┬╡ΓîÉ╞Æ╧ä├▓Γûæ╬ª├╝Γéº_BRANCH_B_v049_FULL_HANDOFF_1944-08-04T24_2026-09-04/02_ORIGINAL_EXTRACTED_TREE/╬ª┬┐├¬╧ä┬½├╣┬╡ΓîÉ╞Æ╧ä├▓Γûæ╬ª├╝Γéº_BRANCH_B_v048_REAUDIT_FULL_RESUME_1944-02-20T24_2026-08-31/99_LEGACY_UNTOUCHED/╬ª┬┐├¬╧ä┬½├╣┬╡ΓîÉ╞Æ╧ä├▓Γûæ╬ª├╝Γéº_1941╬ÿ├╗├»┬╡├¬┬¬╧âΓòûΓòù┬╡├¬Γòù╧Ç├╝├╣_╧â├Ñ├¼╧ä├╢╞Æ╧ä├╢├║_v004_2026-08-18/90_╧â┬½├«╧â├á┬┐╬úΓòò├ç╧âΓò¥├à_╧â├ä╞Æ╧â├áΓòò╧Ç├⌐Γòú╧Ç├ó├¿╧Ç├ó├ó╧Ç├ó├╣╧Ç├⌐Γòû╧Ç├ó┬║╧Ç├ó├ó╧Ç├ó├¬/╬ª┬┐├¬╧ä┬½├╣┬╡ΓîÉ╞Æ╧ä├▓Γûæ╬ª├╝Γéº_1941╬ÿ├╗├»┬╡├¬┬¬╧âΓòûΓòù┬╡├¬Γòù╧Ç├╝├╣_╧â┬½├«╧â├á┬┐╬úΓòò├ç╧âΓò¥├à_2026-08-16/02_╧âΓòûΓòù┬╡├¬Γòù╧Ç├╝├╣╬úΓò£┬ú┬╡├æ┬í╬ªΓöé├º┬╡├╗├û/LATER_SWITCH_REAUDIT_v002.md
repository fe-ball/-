# 1941巻戻し 後続スイッチ再監査 v0.02

## 0. 今回の追加結論

1941年12月から再走査する際、後続正本にある「制度・戦力・作戦の成熟」を一つのON/OFFスイッチとして扱わない。

今回の追加監査で、特に次を修正する。

1. **陸軍航空と海軍航空の空地分離時計を分離する。**
2. **南方航空760～840機級を、マレー当日出撃可能機数として使わない。**
3. **開戦四か月損失10～18%減、マレー実効出力+20～35%、RAF消耗数日～一週間前倒し等を、入力仮定から出力仮説へ降格する。**
4. **熟練者の自然還流だけでなく、「低質補充で置換されなかった熟練者」を人員状態として持つ。**
5. **旧Guadalcanal不在枝を前提にした潜水艦艦日、駆逐艦政策、空母再編期間等を全て再オープンする。**

---

## 1. 空地分離は陸海軍で同じスイッチではない

後続45は主として海軍航空を対象に、史実1944年7月10日の全面空地分離を参照し、本世界での前倒しを研究していた。

しかしマレー作戦の陸軍航空では、開戦時点から以下が別組織として存在する。

- Air Sector Unit / 航空地区部隊。
- Airfield Battalion / 飛行場大隊。
- Ground Crew Company / 地上勤務・整備部隊。
- Field Air Repair Depot / 野戦航空修理廠。
- Air Supply Depot / 航空補給廠。
- Air Transport Unit / 航空輸送部隊。
- Air Signal / Intelligence / Navigation Aid / Meteorological Unit。

3rd Air Groupは、占領したSingora、Batani、Kota Bharu等へ地上部隊を逐次前進させ、飛行部隊を追随させている。12月10日以後の命令には、急進する整備員を航空輸送すること、各air sector unitが新飛行場で整備・補給・通信を担うことが明記される。

従って1941年12月の状態を次のように修正する。

### IJA-AIR-MOBILITY

- 開戦状態：`OPERATIONAL_PARTIAL`
- 既に機能分離の要素あり。
- ただし飛行場状態、排水、燃料、弾薬、増槽、工具、修理廠の追随が律速。
- 「飛行隊だけ移せば即戦力」ではない。

### IJN-AIR-GROUND-SEPARATION

- 開戦状態：`LATENT / ORGANIZATION-BOUND`
- 後続45/46の制度化時計はRESET-TRIGGER。
- 南方、空母損傷、基地喪失、再編、補充機受領等から摩擦を累積し、実際の必要と余力で成熟時期を再決定する。

### JOINT-BASE-STANDARDIZATION

- 開戦状態：`LATENT`
- 陸海軍・方面間で工具、部品、燃料、弾薬、通信、受入手順を標準化する別スイッチ。
- 陸軍に部分分離が既にあることは、このスイッチが完成していることを意味しない。

## 2. マレー「760～840機」を一旦解体する

旧50/90の「日本側約760～840機級配当」は暫定値であり、今回の再走査では直接戦力へ使わない。

今後は最低限、次を分ける。

1. `SOUTHERN_AIR_POOL`：南方作戦全体へ配当された航空資源。
2. `MALAYA_TASKED`：マレー・南タイ・シンガポール作戦へ命令上割り当てられた部隊。
3. `BASE_PRESENT`：当日、指定基地に物理的に存在する機体。
4. `SERVICEABLE`：飛行可能な機体。
5. `LAUNCHED`：実際に発進した機体。
6. `MISSION_REACHED`：天候・航法・機械故障を越えて攻撃域へ到達した機体。
7. `MISSION_EFFECTIVE`：目標を確認し、任務を実施した機体。
8. `RETURNED_SERVICEABLE / RETURNED_DAMAGED / LOST`。

12月8日だけでも、53機が悪天候で攻撃を断念し、別の部隊では暗夜・悪天候、強制着陸、飛行場状態による損失・損傷が出ている。従って「配当機数×性能倍率」は禁止する。

旧760～840は `SOUTHERN_AIR_POOL_HYPOTHESIS` に降格し、3rd Air Group、22nd Air Flotilla、支援輸送・偵察、ビルマ/タイ兼任を個別に復元した後でのみ再集計する。

## 3. 旧航空効果帯の扱いを変更

旧50/90にあった以下は、再走査の入力にしない。

- マレー・フィリピン・蘭印の実効作戦出力+20～35%。
- マレーRAF第一線消耗が数日～一週間早まる。
- 任務中止・航法失敗15～30%減。
- 非戦闘損失15～25%減。
- 開戦四か月日本航空機総損失10～18%減。
- 1942年春に熟練搭乗員が数十～百数十名多い。

これらは**検算帯・旧仮説**としてのみ保持する。

新しい出力順序：

`機体/発動機品質 → 当日serviceable → launch → weather/navigation → combat/AA → damaged return → field/repair queue → next-day serviceable → crew survival/fitness → transfer/replacement → next operation`

この日次・作戦間遷移を積み上げた結果が旧帯へ入るかを後から比較する。

## 4. 熟練者生残の記帳を強化する

自然還流は1941年12月から常時ONの物理過程とする。ただし、今回さらに次を分ける。

- `SURVIVING_IN_UNIT`：同じ部隊でそのまま戦列に残る。
- `WOUNDED_CONVALESCENT`：負傷・療養後に戻る可能性。
- `REPAIR_REORGANIZATION_RETURN`：母艦/基地/部隊の修理・再編で後方を通る。
- `REPLACEMENT_AIRCRAFT_FERRY_RETURN`：補充機受領等で内地・中間拠点へ戻る。
- `TRANSFER_POOL`：別部隊へ再配分可能。
- `KIA_MIA`：不可逆損失。
- `REPLACEMENT_LOW_SKILL`：低技能補充で置換された席。

重要な差は「熟練者が何人増えた」だけではない。

**損失が少なければ、そもそも低技能補充へ置換する必要が減る。**

マレー作戦の3rd Air Group戦後記録は、航空機損失とともに人員損失が大きく、補充人員の能力不足が問題だったとする。従って同じ総員数でも、

- 経験者比率。
- 編隊長/航法/無線資格の穴。
- 整備班長・修理経験者の残存。
- 新人だけで構成される小隊/中隊の発生率。

が後段で変わる。

## 5. 後続文書で追加解除する枝依存条件

### 潜水艦

21の「Guadalcanal型孤立守備隊補給が現行史線で発生しないため、輸送艦日を攻撃へ戻す」は、1941開始状態から削除する。

- そのような戦役が実際に発生しなかった時だけ艦日が戻る。
- 発生すれば輸送拘束を実状態として差し引く。

Indian Ocean、South Pacific、Attu/Kiska、Efate等の後続配分・戦果は全て再計算出力。

### 水上艦

「Guadalcanal型駆逐艦消耗がないので簡易駆逐艦を急がない」は再オープン済み。今回、同じ規則を艦艇任務配分にも明示する。

- Hull/Availability/mission coefficientという評価方法は1941から適用。
- 1943/44の生残艦数・役割は引き継がない。

### 空母

旧MI後8～12週間再編、空母航空隊可搬化、戦術標準化等の日付を解除する。

- 大規模空母戦の実損耗。
- 次作戦までの時間。
- 生残指揮官・航空員。
- 燃料・訓練余力。

で毎回再判定する。

## 6. 再走査での状態機械をサービス別にする

すべてを同じ `LATENT→OBSERVED→TRIAL→STANDARD→INSTITUTIONAL` に押し込まず、サービスごとに初期状態を設定する。

例：

| 機能 | 1941-12初期状態 |
|---|---|
| 自然還流の物理過程 | ON |
| IJA飛行部隊/基地支援の機能分離 | OPERATIONAL_PARTIAL |
| IJN全面空地分離 | LATENT |
| 陸海軍共通基地標準化 | LATENT |
| 意図的な練度平準化 | LATENT |
| 経験者を含む部隊内自然核 | PRESENT |
| 経験核の意図的再配分 | LATENT |
| 専任空輸 | LATENT |
| 艦艇Hull→Availability→Mission評価 | METHOD_ON |
| 潜水艦on-station/再捕捉/再出撃評価 | METHOD_ON |

## 7. 次の実動ゲート

マレーは次の二段階で回す。

### Phase 1: 1941-12-08～12-15

目的：

- 開戦航空攻撃。
- 天候・飛行場・基地移動。
- Kota Bharu/Kedahの連合軍航空後退。
- Force Z。
- Singora/Batani/Kota Bharu等の前進基地化。

ここで最初の `base_transfer_friction` と `crew_survival_delta` を生成する。

### Phase 2: 1941-12-16～1942-02-15

目的：

- 反復出撃と修理・補充。
- 南進に伴う地上部隊・修理廠・補給廠の追随。
- 熟練者損失と低技能補充の置換。
- Singaporeまでの航空支援密度。

Phase 2終了時に初めて「総損失差」「熟練者残存差」「方面航空力差」を確定候補へ上げる。
