# 計算機異聞・魚雷／水雷戦

本書は、これまで20・30・52・60へ分散していた魚雷関係を独立させる。

中心原則は、**魚雷の名目性能を計算機だけで増幅しない**ことである。九三式・九五式の速力・射程・炸薬量、九一式の水中速力等は原則として史実級を基準とする。計算が強く効くのは、試験結果の分離、艦別・発射管別較正、ロット均一性、投下・発射包絡線、再装填装置の信頼性、射撃後の部隊運動である。

また、史実日本海軍の水上艦魚雷射撃指揮はすでに高度であった。計算機が「魚雷の射角計算」を初めて可能にする設定にはしない。変化は、既存の射撃盤・方位盤・発射管・魚雷・人員を一つの誤差勘定として扱い、試験と実戦から係数を早く戻すことに置く。

---

# 1. 状態表示

- **決定**：以後の検討で原則維持する。
- **高確度中心**：一次資料と既存正本の因果が揃い、戦史入力値として使用可能。
- **中心暫定**：合理的だが、個艦装備・ロット母数等の追加監査で動き得る。
- **交戦ごとに計算**：絶対命中率を固定せず、距離、追尾、警戒、発射本数、変針等から都度評価する。

魚雷分野では、絶対命中率より**技術的散布、設定不良、射撃解誤差、敵の未来運動**を分ける。

---

# 2. 史実側の技術基準

## 2.1 水上艦魚雷射撃指揮

USNTMJ O-32が記録した日本の巡洋艦用魚雷射撃指揮は、目標距離・方位・速力・針路、目標旋回、魚雷速度、発射管方位、発射修正、散開等を扱う複雑な体系である。したがって本世界で新たに生じるのは「相対運動を計算する能力」ではない。

中心的な改善対象は次である。

- 艦別発射修正表の精密化。
- 発射管軸線、方位盤、艦首尾線、ジャイロ指示の統合較正。
- 常備・満載・燃料消費後の喫水・トリム差の補正。
- 射撃盤、方位盤、発射管間の伝達・照合ミス低減。
- 実射後の偏差を艦・発射管・魚雷ロット別に分離。

## 2.2 発射管と再装填

USNTMJ O-01-3では、九二式四連装発射管系の機力装填装置は理想状態で四本を約3分で再装填できる一方、装置不調により実用上20～30分へ延びる傾向が記録されている。手動装填の最速例も約5分級である。

したがって、再装填問題の主要部分は「物理的に二十分必要」ではなく、**索、滑車、ローラー、空気モーター、減速機、艦体変形、塩害、整備状態等による長時間側の故障分布**である。

これは計算・統計・実艦試験の還流が強く効く。

## 2.3 航空魚雷

USNTMJ O-01-2では、九一式航空魚雷の発達で横転防止安定器、入水姿勢、浅深度化、高速投下耐性等が重要であることが確認できる。

本世界では、実投下試験から高度、速度、姿勢、入水角、横転、潜入深度、安定器寸法を比較し、次の試験条件を早く選べる。水槽・実投下試験を消すのではなく、**試験一回あたりから回収する情報量を増やす**。

# 3. 魚雷本体――1941～42年中心値

## 3.1 九三式・九五式

### 決定

- 公称速力、射程、炸薬量は原則として史実級。
- 計算援用のみを理由に高速化・長射程化しない。
- 酸素という危険物性、圧力容器、燃焼、腐食、実走試験は物理時計として残る。

### 高確度中心

| 項目 | 史実相当からの変化 |
|---|---:|
| 直進・深度等の兵器単体技術散布 | 15～25％縮小 |
| ロット間性能差 | 25～40％縮小 |
| 艦・発射管別較正差 | 25～40％縮小 |
| 発射前点検・較正所要 | 10～15％短縮 |
| 設定・照合・転記ミス | 20～35％減 |

### 中心暫定

| 項目 | 史実相当からの変化 |
|---|---:|
| 明白な異常走行・始動不良等 | 相対15～25％減 |
| 信管固有の技術的不作動 | 相対15～25％減 |
| 平常時の酸素取扱い不良・事故 | 相対20～30％減 |

これらは絶対不良率ではない。母数の十分なロット資料が得られるまで相対値で保持する。

### 変わらないもの

- 被弾時に甲板上の酸素魚雷が危険である本質。
- 爆発・火災が発射管・次発魚雷区画へ及ぶ危険。
- 海況、艦の大角度回避、発射時姿勢による偶発差。
- 長距離航走中に敵が変針する不確実性。

## 3.2 九一式航空魚雷

### 決定

- 水中速力・射程を計算援用だけで増やさない。
- 主差は投下から安定走行までの再現性。

### 高確度中心

- 技術的散布・投下／入水誤差：史実相当より15～30％縮小。
- 実戦雷撃の総合命中率：同一条件で相対10～25％向上。
- 不良ロット排除、ジャイロ・舵・尾部安定器の均一化を含む。

この「実戦命中率」は照準だけの改善ではない。

1. 適正高度・速度へ入れる率。
2. 投下器から正常分離する率。
3. 入水姿勢が包絡線へ入る率。
4. 横転・深潜り・跳躍を起こさない率。
5. 正常に浮上し、設定深度へ入る率。
6. ジャイロ・舵が狙いどおり働く率。
7. 搭乗員の照準・目標運動誤差。

を通した総合値である。

### 技術時計

- 1938～40：実投下試験データの整理が進み、安定器・尾部・入水包絡線の候補絞り込みが早まる。
- 1940年中：横転防止系の実用試験が史実より早く収束する有力候補。
- 1941年前半：部隊標準化と投下表整備。
- 1941年末：史実1941年より半年～1年程度熟成した投下・入水・ロット管理。
- 弾頭増量や圧力容器変更は別の要求・材料時計であり、一律同じだけ前倒ししない。

# 4. 水上艦魚雷射撃指揮

## 4.1 史実設備を前提にする

計算機が射撃盤を置換するのではなく、中央計算・試験・工廠較正が既存装置を支える。

1942年の能力階層は、個艦装備監査が終わるまで次で扱う。

| 水準 | 能力 |
|---|---|
| A | 方位盤＋表・簡易盤。目標運動推定の人間依存が大きい |
| B | 目標針路速力計＋九三式級射撃盤。連続追尾から射角・射程・散開を算出 |
| C | 一式級。自艦・目標の連続位置作図、短時間見失った目標の外挿、間接射撃能力 |

1942年FS級の作業仮定：

- 重巡：Bを基本、Cは個艦監査まで少数候補。
- 新型駆逐艦：A～B混在。
- 旧式駆逐艦：A中心。

## 4.2 計算援用による中心改善

| 項目 | 中心値 |
|---|---:|
| 射撃諸元準備 | 10～20％短縮 |
| 安定追尾時の射撃解系統誤差 | 5～10％縮小 |
| 自艦運動・敵変針等の非標準条件 | 10～15％縮小 |
| 艦・発射管別較正差 | 25～40％縮小 |
| 伝達・指針照合・設定ミス | 20～35％減 |

史実装置が高度なので、計算そのものの改善を大きく取りすぎない。

# 5. 距離と命中――絶対率を固定しない

九三式の長射程は、長距離命中を保証しない。魚雷が長く走るほど、目標の未来運動誤差が支配的になる。

49kt級の魚雷なら、おおむね、

- 5km：3分強。
- 10km：6分半前後。
- 15km：10分弱。
- 20km：13分前後。

航走する。

30ktの敵艦が発射後に数度変針するだけで、10～20km先の未来位置は数百m～1km級で移る。これは射撃盤やジャイロの改善量を容易に上回る。

したがって、本世界の**同一射撃機会に対する相対命中改善**は距離・警戒状態で扱う。

| 条件 | ～5km | 5～12km | 12～20km | 20km超 |
|---|---:|---:|---:|---:|
| 安定追尾・敵未警戒 | +5～10％ | +10～20％ | +5～15％ | 0～5％ |
| 敵警戒・回避開始 | 0～5％ | +5～10％ | 0～5％ | ほぼ0 |

これは絶対命中率ではない。史実同条件の交戦モデルに掛ける補正である。

### 戦術上の意味

- 6～12km級：精密狙撃的な斉射で最も恩恵が大きい。
- 12～20km級：敵隊形が安定している場合は有効だが、警戒されると効果が急減。
- 20km超：単艦狙撃より、船団・艦隊の予想進路へ扇面を張る用途。

**長射程を命中精度と混同しないこと**を1940年前後までの演習統計から海軍側が学ぶ中心線とする。

# 6. 再装填――最大の質的変化

## 6.1 技術側

史実装置の最良値がすでに約3分であるため、最良値を縮めることが目的ではない。計算援用は、20～30分へ伸びる故障・艦差・海況依存の長時間側を削る。

改善対象：

- 空気モーターの負荷・圧力。
- 索張力と伸び。
- 滑車・案内ローラー摩擦。
- 減速機と軸受。
- 艦体たわみと装填軌道の芯ずれ。
- 塩害、潤滑、整備周期。
- 艦別故障統計と入渠時改修。

## 6.2 1940～42年の中心値

| 状態 | 四本再装填の中心 |
|---|---:|
| 停泊・最良試験 | 3～4分 |
| 良好海況・安定針路 | 4～6分 |
| 艦隊演習の通常中央値 | 6～9分 |
| 実戦中、局部損傷なし | 7～11分 |
| 大角度回避・荒天 | 10～18分、しばしば中断 |
| 発射管・軌道・索周辺被弾 | 不能も普通にある |

魚雷が管へ入る時間と、再び敵へ撃てる時間を分ける。

**発射から第二射撃解を得て再発射するまで：12～20分級。**

この12～20分は、離脱、再装填、再捕捉、射撃解、再接近・射界確保を含む戦術サイクルである。

## 6.3 戦術への自然な派生

史実でも次発魚雷と再装填装置は存在する。したがって新しい戦術思想を外部から与える必要はない。

1936～38年頃から装填装置の信頼性が改善し、演習で10分弱の再装填が反復できる艦が増えると、部隊側が次の運用を試し始める。

### A. 一斉射即離脱型

第一斉射後は砲戦へ拘泥せず、暗夜・煙幕を使って離脱。再装填完了後に状況が悪ければそのまま離脱する。

### B. 再装填後再突入型

第一斉射後、比較的安定した針路で再装填し、12～20分後に損傷・隊形脱落した目標へ第二斉射する。

### C. 複数隊時間差投入型

第一群が発射・離脱・再装填する間、第二群が接触を維持する。第二群発射後に第一群が戻る。

これにより、敵から見れば20～30分以上にわたり「魚雷を撃てる駆逐艦」が途切れにくくなる。

## 6.4 何が変わらないか

- 次発魚雷は通常一回分で、無限に撃てない。
- 発射管・次発魚雷区画への被弾で能力は容易に失われる。
- 激しい回避中は装填時間が延びる。
- 15分以内に決着する近距離乱戦では第二斉射が間に合わない場合が多い。
- 甲板上の酸素魚雷の被害時危険性は残る。

したがって「魚雷火力が二倍」ではない。

正確には、**20～60分継続する水上戦で、搭載している次発魚雷が実際の戦闘火力へ変換される確率が大幅に上がる**。

# 7. レーダー・光学と魚雷戦

1942年はレーダーが光学・人間を全面的に置き換える時期ではない。

### 米側レーダーの強み

- 暗夜・雨・煙幕でも敵の存在を先に得られる。
- 早い警報により、発射前から不規則変針・増減速へ入れる。
- その結果、日本側の未来位置予測を壊せる。

### 日本側光学・射撃盤の強み

- 視認後の艦種識別、方位、継続追尾。
- 安定した数分間の追尾から比較的良い射撃解を得る。
- 艦別較正・射撃盤・九三式の均一性改善により、6～12km級で有効な扇面を作りやすい。

したがって1942年の夜戦では、

> **米：接触開始・早期警告で強い。**  
> **日：視認後の継続追尾と魚雷斉射で強い。**

とする。

敵が早期警戒して変針を始めれば、日本側の長距離魚雷改善は小さくなる。逆にレーダー接触があっても艦種・正確な針路・速度が確定せず、距離が詰まって日本側が安定追尾を得れば九三式は依然危険である。

# 8. 潜水艦魚雷

潜水艦用射撃計算器は水上艦用より改善余地が大きいが、最終命中は潜望鏡観測に強く支配される。

既存20の中心値を維持する。

- 諸元準備：10～20％短縮。
- 非標準条件の系統誤差：10～20％低減。
- 艦ごとの盤較正差：約30％縮小。

魚雷本体は九五式等について、九三式と同様に直進、深度、ジャイロ較正、姿勢安定を改善する。

ただし、

- 目標距離。
- 敵速。
- 艦首角。
- 追尾時間。
- 敵変針。

の観測誤差が支配的なので、潜水艦の絶対命中率へ一律補正を掛けない。交戦ごとに計算する。

# 9. 1932～42年の発達史

## 9.1 1932～34：試験記録の分離

EM-1～初期Type 1期。

- 魚雷ロット、ジャイロ、舵、圧力、海水温、発射角、艦速をカード化。
- 「外れた」を一括せず、魚雷本体、発射管、射撃解、観測誤差へ分ける。
- 初期量産から安定ロットへの移行が数か月早まる。

## 9.2 1934～37：艦・発射管・魚雷を一体で較正

- 発射管軸線と艦首尾線の定期測定。
- 艦別発射修正表の細分化。
- 入渠後の再較正を標準化。
- 再装填装置の故障箇所を艦・部品別に統計化。
- 1936～37年頃から改修ロットが出始める。

## 9.3 1937～39：演習統計から射程と命中を分離

実射・演習母数が増え、超長距離での主要誤差が魚雷本体より敵未来運動であることが明瞭になる。

教程は次へ寄る。

- 決定的狙撃斉射：6～12km級。
- 中長距離：敵隊形が安定している場合。
- 超長距離：単艦狙撃より予想進路への扇面射撃。

## 9.4 1938～41：航空魚雷の投下・入水体系

- 投下高度・速度・入水角・横転・潜入深度を統計化。
- 横転防止・尾部安定の試験収束が早まる。
- 部隊投下表とロット判定が統一される。
- 1941年末には、史実同時期より半年～1年程度熟成した運用状態。

## 9.5 1939～41：再装填を戦術へ組み込む

再装填中央値が一桁分級へ安定すると、第一線水雷戦隊の演習に、

- 第一斉射後離脱。
- 再装填中の接触維持役分担。
- 10数分後の再突入。
- 複数駆逐隊の時間差投入。

が自然に入る。

## 9.6 1941～42：実戦で警戒済み目標問題を学ぶ

敵がレーダーや見張りで先にこちらを認識し、不規則変針へ入ると長距離射撃解の価値が急減することを実戦データで確認する。

射撃可否判断へ、

- 安定追尾時間。
- 敵がこちらを認識しているか。
- 最終変針からの経過時間。
- 敵隊形が崩れているか。

を強く入れる方向へ進む。

# 10. 戦史へ渡す入力値

本書は戦闘結果を固定しない。太平洋戦争初頭の再監査では、次を必ず入力する。

## 航空雷撃

- 出撃機数。
- 目標到達機数。
- 有効雷撃位置へ入った機数。
- 投下距離・高度・速度。
- CAP・対空砲火による妨害。
- 目標の回避開始時刻。
- 魚雷の正常入水・走行率。
- 同一条件での実戦命中率相対+10～25％。
- 目標ごとの損害閾値。

## 水上魚雷

- 艦級別発射管数、次発魚雷数。
- 射撃指揮水準A/B/C。
- 発射距離。
- 安定追尾時間。
- 敵の警戒状態。
- 敵の変針・増減速。
- 散開角。
- 第一斉射後の戦闘継続時間。
- 再装填可能条件。
- 第二射撃解まで12～20分級。

### 非線形性

魚雷命中数は単純な加算ではなく、

- 空母の航空運用停止。
- 艦速低下。
- 操舵障害。
- 火災・浸水限界。
- 第二斉射での追撃容易化。

等の閾値を越える。

したがって史実同条件で平均命中が10～25％増えるだけでも、「中破生還」と「喪失」の比率が大きく動き得る。

# 13. 2026年8月13日追記――戦史側で第二斉射を消さないための強制監査

2026年8月13日の1944年史線点検で、技術・教程として成立済みの第二斉射思想が、歴史考察の艦隊戦モデルから脱落していたことが判明した。以後、次を強制チェック項目とする。

水上戦に、次発魚雷を持つ巡洋艦・駆逐艦が参加し、戦闘が20分以上継続し得る場合、必ず、

1. 第一斉射を何km・何本・どの扇面で撃つか。
2. 発射後に砲戦へ拘泥するか、煙幕・暗夜で離脱するか。
3. 再装填可能艦が何隻残るか。
4. 誰が接触を維持するか。
5. 12～20分級で第二射撃解を作れるか。
6. 第二斉射の目標が主力か、損傷・隊形脱落艦か、輸送・火力支援艦か。
7. 米側が第二斉射を知っている／疑っていることで、変針・隊形・照明・レーダー監視をどう変えるか。

を記録する。

第二斉射を実施しない結果も許容するが、「描写しなかったので存在しない」は許容しない。近距離15分以内で決着、発射管被害、次発魚雷火災、昼間航空脅威、隊形崩壊、目標喪失等の阻害条件を明示する。

1944年Marianas相当の大規模戦では、魚雷戦の目的を「一斉射で敵戦艦を沈める」だけに置かず、**米battle line・巡洋艦・駆逐艦へ長時間の回避運動を強制し、別働水上主力の進入窓を作る**運用も比較する。

## 2026年8月13日追加監査――陽炎型・夕雲型の魚雷攻撃サイクル

### 魚雷射撃指揮の標準帯

九三式級魚雷射撃盤は最新・大型級駆逐艦への搭載を前提にした体系で、駆逐艦用の通常計器範囲はおおむね4,000～16,000m級である。したがって陽炎・夕雲型の標準精密射撃を20km超へ常態化させない。

- ～5km：近距離。計算改善より戦術状況が支配。
- **5～12km：主たる高精度魚雷射撃帯。**
- **12～16km：安定追尾・敵未警戒なら有力。**
- 16km超：標準九三式盤の通常使用域外。隊形予想、上級指揮、特殊射法の領域。
- 20km超：個艦精密狙撃の主線から外す。

装備区分は、初期陽炎型では過渡差を許し、後期陽炎型は九三式級Bを標準線、夕雲型はBを基本標準とする。一式級Cは例外・次世代扱いを維持する。

計算援用の主効果は魚雷射程を伸ばすことではない。艦速・発射管角・発射管高さによるtail flip、発射管番号、魚雷ロット、ジャイロ、深度、舵の残差を艦ごとに管理し、**技術的理由で無駄になる魚雷本数を減らす**。感度帯は、5～12km・敵未警戒で同一機会の有効性相対+5～12％、12～16kmで+3～8％程度を主線とし、大回避中は0～5％程度へ縮む。

### 次発装填――3分記録を基準値にしない

九二式四連装発射管の次発装填装置は理想状態で4本を約3分級で再装填し得るが、史実通常状態では装置不調により20～30分へ伸びることがあった。したがって本世界の主効果は最良3分をさらに縮めることではなく、**20～30分へ飛ぶ故障裾を削る信頼性工学**に置く。

重点監査項目は、索張力、プーリー・ローラー芯出し、空気モーター圧力、減速機、塩害、潤滑、艦体たわみ、整備周期、発射管・装填軌道の個体差とする。

高確度暫定の作業帯：

| 条件 | 初～中期陽炎 | 後期陽炎 | 夕雲 |
|---|---:|---:|---:|
| 停泊・最良試験 | 3～4分 | 3～4分 | 3～4分 |
| 良好海況・安定針路 | 5～7分 | 4～6分 | 4～6分 |
| 通常演習中央値 | 7～10分 | 6～9分 | 5～8分 |
| 実戦・無損傷 | 9～14分 | 8～12分 | 7～11分 |
| 荒天・激しい回避 | 10～20分超／中断あり | 10～18分 | 10～18分 |

四連装2基は、双方の装填装置・要員・圧縮空気系が健全なら原則として並行作業する。したがって8本の再装填時間を「4本時間×2」で足さない。一方だけ完了した場合には4本の部分第二斉射も可能である。

### 第一斉射→第二斉射の戦術サイクル

管へ魚雷が戻った時刻と、再び有効射撃ができる時刻を分ける。離脱、安定針路、再装填、接触維持、再捕捉、射撃解、射界確保を含む中心帯は次とする。

- 初～中期陽炎：**15～25分**。
- 後期陽炎：**13～22分**。
- 夕雲：**12～20分**。

15分以内の近距離乱戦では第二斉射の寄与は小さい。30～60分継続する夜戦では大きくなる。

### 駆逐隊火力の数え方

陽炎・夕雲型4隻なら第一斉射最大32本、次発32本を持つが、**64本を即時火力として加算しない**。次発は、各艦について無損傷、再装填成功、再接触、射界、指揮維持を満たして初めて実火力へ変換される。

戦史モデルでは各艦の第二斉射状態を **0 / 4 / 8本** で持ち、駆逐隊全体では第二波へ変換される期待本数と、二隻以上が再突入できる確率を別に見る。再装填再現性の改善は、平均命中率倍率より「第二波そのものが成立する確率」で非線形に効く。

### 未閉鎖の駆逐艦側論点

次回以後、巡洋艦へ移る前に必要なら次を一括で閉じる。

1. 次発九三式8本を搭載して砲戦・空襲を受ける被害拡大リスクと投棄手順。
2. 12.7cm主砲、対空、配電、消防・排水を含む被害後魚雷戦能力。
3. 駆逐隊・水雷戦隊の時刻同期、目標分担、接触維持、第二波再投入の指揮通信。
4. 島風を量産主線ではなく、速力・魚雷本数の閾値試験艦としてどう評価するか。


## 2026年8月14日追加監査――発射許可・友軍危険扇面・変則水雷艦

魚雷攻撃サイクルへ**発射許可**を独立段階として追加する。

`探知 → 追尾 → 射撃解 → 射界確保 → 友軍危険扇面照合 → 発射許可 → 発射`

九三式の長航走距離を考慮し、目標後背の友軍泊地・船団・他隊行動域を危険扇面として作図する。射撃解が成立しても友軍危険が高い場合は保留・本数縮小を許容する。第二攻撃も `再装填完了 ≠ 第二斉射実施` とし、再接触、射界、目標価値、既被攻撃量、友軍危険を見て決める。

北上・大井の重雷装艦、島風の15射線は魚雷本数を即時戦力倍率へ変換しない。詳細艦級判断は11を正本とする。
