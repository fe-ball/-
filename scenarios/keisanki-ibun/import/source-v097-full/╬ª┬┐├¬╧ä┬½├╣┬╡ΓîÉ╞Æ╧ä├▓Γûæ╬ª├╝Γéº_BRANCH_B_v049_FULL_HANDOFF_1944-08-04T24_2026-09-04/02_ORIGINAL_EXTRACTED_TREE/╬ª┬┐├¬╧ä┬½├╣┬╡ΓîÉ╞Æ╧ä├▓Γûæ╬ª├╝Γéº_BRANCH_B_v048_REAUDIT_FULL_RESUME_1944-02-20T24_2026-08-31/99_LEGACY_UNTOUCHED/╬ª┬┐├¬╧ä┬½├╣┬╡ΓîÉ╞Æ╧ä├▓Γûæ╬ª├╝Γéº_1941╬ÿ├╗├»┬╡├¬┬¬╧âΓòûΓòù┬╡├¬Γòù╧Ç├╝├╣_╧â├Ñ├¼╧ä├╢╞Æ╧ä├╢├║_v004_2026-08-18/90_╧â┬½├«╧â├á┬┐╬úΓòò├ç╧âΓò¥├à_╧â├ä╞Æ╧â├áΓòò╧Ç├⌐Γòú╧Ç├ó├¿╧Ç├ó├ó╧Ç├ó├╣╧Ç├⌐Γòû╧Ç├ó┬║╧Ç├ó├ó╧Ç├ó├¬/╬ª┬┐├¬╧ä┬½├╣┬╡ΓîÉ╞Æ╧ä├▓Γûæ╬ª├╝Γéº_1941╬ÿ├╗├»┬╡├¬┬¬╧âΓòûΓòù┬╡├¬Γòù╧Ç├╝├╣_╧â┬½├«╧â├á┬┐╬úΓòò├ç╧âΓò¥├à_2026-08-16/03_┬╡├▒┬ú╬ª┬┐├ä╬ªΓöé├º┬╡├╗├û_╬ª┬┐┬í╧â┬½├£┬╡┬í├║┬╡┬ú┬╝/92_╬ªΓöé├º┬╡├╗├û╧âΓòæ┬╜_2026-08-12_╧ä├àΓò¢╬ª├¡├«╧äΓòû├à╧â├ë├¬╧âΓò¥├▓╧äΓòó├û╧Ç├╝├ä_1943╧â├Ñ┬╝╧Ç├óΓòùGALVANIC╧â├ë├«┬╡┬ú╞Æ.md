# 計算機異聞・現行総合引継ぎ――1943冬・GALVANIC同期

本書は91を削除せず、**2026-08-12現在の継続地点だけを要約する最新引継ぎ**である。技術数値は各正本10～70、現行歴史線は85→86→87→88を優先する。

# 1. 方法論

戦闘の「上振れ／下振れ」は史実との差や物語の均衡に対して使わない。その時点の兵力、索敵、戦術、損傷、敵対策を条件とした分布にだけ使う。有利な戦果が続いたことを理由に次戦の成功確率を人為的に下げない。敵が対策を取った場合はその対策を新条件に入れる。

**判断の理由：** 史実を暗黙の平均回帰先にすると、本世界で蓄積した戦力・情報・兵站差を消してしまう。

# 2. 正本更新

## 2.1 水上航空

- 強風：1943年4～5月初実戦、10月第一線50～65、年末70～90機級。標準分遣12機、即応8～10。滑走路制圧後に一時的な防空数的主力となる第二層。詳細53。
- 瑞雲：9月初期量産引渡、10～11月初実戦分遣、年末第一線15～25。1943秋は高速水偵主体、軽爆撃・有利な偵察機攻撃は副任務。詳細52。
- 千歳・千代田：空母化せず水上機母艦として維持。可搬水上航空基盤。詳細60。

## 2.2 空母・艦政

- 新規に海鷹・神鷹・千歳・千代田を空母化しない。
- 伊勢・日向航空戦艦化なし。伊吹空母化なし。
- 信濃：空母にも戦艦にも完成せず、1943Q4に船渠解放可能まで完成・浮揚し未成係留。
- 大鳳＝質の試験艦、雲龍系＝量産主線。雲龍・天城1944年6～7月、葛城8～9月中心。
- 1942年7月～43年6月の主要艦建造時計を10へ追記。島風は一艦試験で量産しない。

## 2.3 鉄鋼・輸送

- 1943鋼塊8.1百万t中心、1944 8.7百万t中心。
- 1944鋼製商船1.2～1.45百万GRT級、高品質標準船を優先。
- 木造沿岸船400～700隻、8～14万t級。コンクリート自航船10～30隻級。
- 輸入鉄鉱石・原料炭、北海道/九州炭沿岸輸送、外航/沿岸比率を別台帳化。

## 2.4 暗号・作戦情報

SIGABA級は破らない。GALVANIC察知は、反復写真偵察、攻撃しない潜水艦、基地・港務・補給通信、短い中低級暗号窓、通信網膨張と出航前沈黙の統合で行う。11月上旬Gilberts 75～85％、11月末にはD-Dayを12月5～15日中心へ絞る。

# 3. 第二次Midway

D-Day 1943年8月29日。米18～20千、日本守備6千弱。9月3日夕刻に組織抵抗終了。

米地上総死傷約2,650中心、航空65～75。CVL Independence大破、給油艦大破、輸送/AKA大破、駆逐艦中破。日本戦死約4,700、捕虜約800、基地航空約50、潜水艦1沈没・1損傷。

翔鶴・瑞鶴・飛龍は米大型CV4～5健在のため出撃せず。Midwayは喪失するが主力艦隊を保存し、基地復旧を約一か月遅らせる。

# 4. 五号作戦と中国

五号第一・第二期を漢中で成功終了。1943年中の第三期広元侵攻は保留。

中国側には「米Pacific攻勢は四川防衛の外郭線」という認識が強まるが、Stilwell系から実際の中国軍反攻・Burma協力を要求される。

10月7～18日、川北限定反攻：中国4.8～5.8万、局地10～20km前進。中国死傷7.5～9.5千、日本2.7～3.5千。漢中は保持。

11月初旬～12月初旬、日本第11軍は常徳方面限定攻勢。中国2.5～3.5万、日本0.8～1.2万死傷中心。恒久占領せず予定撤収。日本は二正面を同じシーソー法則で動かさない。

# 5. Wake 1943年10月5～6日

米大型CV4＋CVL2、艦載約400級。日本Wake守備約5,100、陸戦22、強風10＋旧水戦2、水偵類約10、瑞雲中心1。

二日間：米航空約38全損、駆逐艦1中～大破。日本航空約32、潜水艦1中破、地上550～750死傷。Wakeは保持、歩兵大量増援せず施設分散・修理・弾薬を補う。

# 6. GALVANIC準備

11月上旬にGilberts本命を高確率で察知。Tarawa約5,600、Makin約1,550、Apamama300～450。Marshall側に戦闘機85～95、強風18～22、攻撃機40～45、水偵・大艇15～20、瑞雲6～8級。潜水艦10～11隻を分散。

11月20日以後、大型輸送をGilbertsへ送らない。主力艦隊は後方条件付き邀撃。

# 7. GALVANIC前哨・本戦

12月5夜、日本陸攻18機級の夜間雷撃でLexington IIに魚雷1本、戦役離脱。日本約8機損失。

12月8、潜水艦がAKA1大破、日本潜1沈没。

12月10 Tarawa D-Day。潮汐は史実11月20日より良く、LCVPの相当数が満潮前後に礁越え。米約7,100上陸、初日地上死傷約1,270、日本約1,500戦闘不能・死傷。

12月11未明、Makin支援CVE1隻を日本潜水艦が撃沈。12日夜、陸攻がLST1大破。

12月13 16:30中心、Tarawa組織抵抗終了。Tarawa米地上2,600～2,800死傷、日本戦死・致命傷4,700～4,900、捕虜・重傷捕獲450～600級。

Makinは12月13午前終了。米地上550～700、日本戦死1,250～1,350、捕虜・重傷150～220級。

米側はLexington II戦役離脱、CVE1沈没、AKA1大破、輸送艦1損傷、LST1大破、航空70～90級損失。それでも大型CV4隻級健在。翔鶴・瑞鶴・飛龍は出ず、金剛夜戦部隊も反転。

**戦役評価：** 米軍の明白な作戦勝利。ただし高くついた成功。日本は島を失う代わりに攻勢機構へ損害を与え、主力艦隊を保存する防御体系を成立させた。

# 8. 現在地点――1943年12月中旬

米軍はGilbertsを足場にMarshallへ進めるが、空母・CVE・上陸輸送・第2海兵師団に損害。Europe First、イタリア、BOLERO/OVERLORD準備の制約もあり、Pacific上陸を無制限には連発できない。

日本はMarshallをTarawaの大型版にするだけでは不十分。島間航空、強風・水上機泊地、夜間攻撃、潜水艦、主力艦隊の条件付き邀撃をどう組み直すかが次の本題。

# 9. 次の作業順

1. GALVANIC直後の米空母・CVE・上陸部隊・輸送船艇の修理補充時計。
2. 米Marshall作戦の目標・D-Day・投入可能戦力。Europe Firstとの競合を明示。
3. 日本Marshall防御再編：守備隊規模、飛行場、水上機泊地、航空分散、潜水艦、夜戦部隊、撤収不能部隊の配分。
4. 1944年初の五号第三期再審査と中国・Burma・Cairo後の相互要求。
5. 1943年末の日本基地航空・夜間陸攻・搭乗員補充。主力空母航空隊との人材競合。
