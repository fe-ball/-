# 潜水艦隊全体の再監査

潜水艦の変化を魚雷命中率だけへ縮約しない。主量は多数の通常伊号・海大・呂号が「予定日に出る・指定海面へ着く・長くいる・帰ってまた出る」こと、質的な尖りは少数潜高が「古くなった敵情報を水中高速機動で攻撃機会へ変換する」ことに置く。

# 1. 潜水艦隊の量的主力

史実日本は1942～43年にも高水準で潜水艦を建造しており、開戦準備時には潜水艦32隻の追加発注も行われた。本世界の潜高は無料上乗せではないが、完成した通常伊号・呂号を同数だけ消す一対一置換にも固定しない。既存造船所への直接割込み、追加計画の艦種振替、1942年後半の条件付き追加発注を分けて記帳する。個艦・造船所台帳は22を正本とする。

通常艇の計算援用効果は、機関故障、トリム、電池使用、潜航、航法、同型艦ばらつきの改善である。技術項目の20～35%改善を潜水艦戦力1.3倍へ直接変換せず、次へ分配する。

- 出撃中止・早期帰投率の低下。
- 指定哨戒線への到着時刻誤差の縮小。
- on-station艦日の増加。
- 接触後に任務を継続できる日数の増加。
- 帰投後の修理・再出撃間隔の縮小。

# 2. 艦種別任務分化

| 系列 | 主任務 |
|---|---|
| 甲・乙型大型巡潜 | 長距離外周索敵、水偵、敵艦隊交通監視、接触報告 |
| 丙型・海大型 | 通常雷撃、艦隊接近路待伏せ、商船戦 |
| 呂号 | 前進基地周辺、海峡、Santo/Efate/Fiji等の局地哨戒・交通阻止 |
| 潜高第一世代 | 外側から得た情報を使い、内側の有力通過帯で水中機動邀撃・再配置 |
| 潜高小型 | 1943後半以後、基地・狭水道・泊地接近路の局地迎撃候補 |
| 甲標的乙・丙 | 再使用可能な極小局地迎撃・特殊港湾攻撃。回天と同列にしない |
| 伊400型 | 一般潜水艦係数とは別の特殊航空作戦 |

Guadalcanal型の孤立守備隊補給が現行史線で発生しないため、史実なら潜水艦輸送に吸われた艦日を、攻撃・索敵・哨戒へ戻せる。これは魚雷改善とは独立した大きな量的効果である。

# 3. 潜高第一世代の戦闘サイクル

潜高は「19ktで敵を聴きながら追う艦」ではない。高速時は自艦雑音が増え、聴音性能を損ない、電池も急消費する。

標準サイクル：

1. 3～5kt級または停止に近い低速で聴音・潜望鏡確認。
2. 敵位置、時刻、針路、速力の誤差帯を作る。
3. 必要量だけ17～19kt級水中スプリント。
4. 減速・静粛化後、再聴音して誤差を更新。
5. 潜望鏡で最終確認し雷撃。
6. 護衛線横断・側方離脱に高速電池を使う。
7. 再び低速聴音。第二射点を取るか、離脱・充電を選ぶ。
8. 夜間浮上充電。敵航空・レーダー哨戒が濃ければ攻撃機会そのものを減らす。

射点10海里修正なら、8kt級で75分、18kt級で約33分。価値は速度倍率ではなく、敵が射点を通過する前に間に合う閾値である。一方、30分超の全速は約60分級の高速予算の半分を使うため、第二攻撃・離脱余力と交換になる。

# 4. 電池・充電・安全性

第一世代は100サイクル級高出力電池。計算援用でセル選別、温度、端子、配線、換気、充放電規則を改善し、「定格以前に壊れる」率を下げる。電気化学そのものを前倒ししない。

300サイクル級は潜高改で、約25t級の重量増を払う候補。重量増はトリム、予備浮力、居住、魚雷・燃料と競合させる。

1942～43年にシュノーケルを自動導入しない。夜間浮上充電の必要が残るため、航空哨戒・レーダーは直接撃沈だけでなく翌日の電池予算を削る対潜効果を持つ。

# 5. 聴音・潜望鏡・I/O

潜水艦戦では聴音を独立センサーとして扱う。計算援用で新しい超能力ソナーを作るのではなく、次を改善する。

- 回転数・速力別の自艦雑音地図。
- ポンプ・補機別の聴音阻害表。
- 聴音器の個艦較正、左右方位偏差。
- 低速・停止・旋回時の方位誤差表。
- 海水温・深度・海況と聴取実績の記録。
- `高速移動 → 静粛化 → 再聴音` の標準待ち時間。
- 潜望鏡方位との照合。

1943年段階で現代的水中データリンクは成立させない。受信した敵情報は時間とともに古くなり、潜水艦自身が外挿し、再捕捉しなければならない。

# 6. 通信と司令部の役割

送信形式を短い標準電文にする。

`時刻 / 位置 / 敵種 / 針路 / 速力 / 確度 / 自艦状態`

司令部側は複数報告、基地航空、交通分析から敵の存在確率帯を計算し、各艇へ次哨戒線・時刻を指示する。潜航中の連続更新はできない。潜水艦は「古くなる情報」で戦う。

攻撃可能でも、敵空母群・高速戦艦等の情報価値が高い場合は、無理に発射して位置を暴露せず接触維持を優先してよい。

# 7. 潜高建造ロット

個艦・造船所・機会費用は22を正本とする。ここでは運用に必要なロットと即応数だけ保持する。

上書き中心案：

- **第一試験ロット2隻**：1941年夏～秋起工。呉・川崎神戸へ各1隻。既存建造列へ直接割り込む。1942年秋～末完成、1943年1～2月戦闘即応。
- **第二ロット4隻**：1941年11月以後の潜水艦追加計画の艦種構成を潜高へ振り替え、1942年2～6月に呉・川崎神戸へ段階起工。同型反復で11～13か月級へ工期を短縮する。
- **第三ロット4隻**：1942年後半、第一艇進水・陸上電気試験を条件に追加発注対象へ入れる。7・8番艦は量産移管、9・10番艦は潜高改への型式変更を可能とし、1943年6月戦力には数えない。

従って1942年末の潜高系列は「発注対象最大10隻」だが、1943年前半の戦力を作るのは第一・第二ロット6隻である。

戦闘即応中心：

| 時期 | 即応潜高 | 感度帯 |
|---|---:|---:|
| 1942年末 | 0～1 | 0～1 |
| 1943年2月 | 2 | 1～2 |
| 1943年4月 | 3 | 2～3 |
| 1943年5月 | 4 | 3～4 |
| 1943年6月中旬 | **5** | **4～5** |
| 1943年7月末 | **6** | 5～6 |

潜高6隻の費用は、完成通常艇6隻の消滅ではなく、伊183一隻級の実質取消、伊179・伊181等の工程後退、追加計画で従来艇を増勢できた枠の放棄、大型電動機・蓄電池・銅・熟練電工への優先配分として払う。

小型潜高は1942末～43前半試作、1943後半に最初の実用艦、1943末以後量産判断へ後退させる。大型潜高の増勢と電池・電動機を二重使用しない。

# 8. 戦史での評価指標

今後、潜水艦を撃沈隻数・GRTだけで評価しない。

| 指標 | 意味 |
|---|---|
| 出撃成立率 | 計画艇のうち実際に哨戒へ出た割合 |
| 配置時刻誤差 | 指定哨戒線への到着遅延 |
| on-station艦日 | 有効哨戒日数 |
| 接触率 | 艦船を発見、または情報を受領した回数 |
| 射点変換率 | 接触を攻撃位置へ変えた割合 |
| 再捕捉率 | 一度失った敵を再び取った割合 |
| 再攻撃率 | 第一攻撃後に第二攻撃機会を作った割合 |
| 高速電池消費 | 射点修正・離脱・再攻撃のエネルギー制約 |
| 充電露出 | 浮上充電を妨害・発見された回数 |
| ASW離脱率 | 攻撃後の生還率 |
| 再出撃間隔 | 帰投から次哨戒までの日数 |
| 非攻撃情報価値 | 攻撃せず報告した敵艦隊移動 |
| 敵拘束 | 航路変更、護衛、航空哨戒を強要した量 |

# 9. 1941末～1943夏への遡及

- **MI以前**：主効果は出撃成立、哨戒線到着、接触報告。史実Midwayの潜水艦線遅延は再監査対象だが、既存85の米空母損害が飽和しているため、自動的な追加空母撃沈へはしない。
- **Indian Ocean**：1942年7～12月は戦域割当51艇月、約43実効艇月・約1,320 on-station艦日を中心とする。潜水艦単独の史実差は追加14～20隻・8～13万GRT、中心17隻・約10.5万GRT。Addu外周偵察と通常艇の稼働改善を統合し、攻撃しない情報哨戒の価値も記帳する。
- **1942秋南太平洋**：Guadalcanal輸送が消えるため、甲乙型を外周索敵、呂号をSanto/Efate/Fiji局地哨戒へ回す。9～12月の追加商船・輸送船撃沈は4～6隻、2.5～4万GRT中心。史実Guadalcanalで生じたWasp等への大戦果を重複加算せず、輸送阻止・索敵・護衛拘束へ効果を移す。
- **Komandorski～Attu**：北方潜水艦は大型艦撃沈狙いへ偏らせず、敵艦隊兆候・上陸艦隊接近・輸送監視へ用いる。史実Kiska潜輸送13隻の一括投入は再現せず、5～7隻上限へ抑え、6～8隻級を他戦域へ残す。
- **1943春～Efate候補戦**：大型巡潜で外周艦隊移動を拾い、通常艇・呂号で交通線を監視し、潜高4～5隻級を米高速艦隊の有力通過帯へ内側配置する。潜高の役割は「魚雷を当てる艇」だけでなく、古くなった敵情報を射点へ変換し、航空戦後の退却線へ再配置することである。

1942年6～12月は23、1943年1～5月は24で戦域別数量配置と粗い戦果を閉じた。Efate候補戦直前の累計商船・輸送船等史実差は+33～49隻、中心約41隻・約20～29万GRT級。1943年5月末の額面戦力差は+4～6隻級、実働哨戒力は史実比1.4～1.6倍級を中心とする。次段階は1943年6月Efate候補戦のOOB・索敵・潜水艦三層網を閉じる。
