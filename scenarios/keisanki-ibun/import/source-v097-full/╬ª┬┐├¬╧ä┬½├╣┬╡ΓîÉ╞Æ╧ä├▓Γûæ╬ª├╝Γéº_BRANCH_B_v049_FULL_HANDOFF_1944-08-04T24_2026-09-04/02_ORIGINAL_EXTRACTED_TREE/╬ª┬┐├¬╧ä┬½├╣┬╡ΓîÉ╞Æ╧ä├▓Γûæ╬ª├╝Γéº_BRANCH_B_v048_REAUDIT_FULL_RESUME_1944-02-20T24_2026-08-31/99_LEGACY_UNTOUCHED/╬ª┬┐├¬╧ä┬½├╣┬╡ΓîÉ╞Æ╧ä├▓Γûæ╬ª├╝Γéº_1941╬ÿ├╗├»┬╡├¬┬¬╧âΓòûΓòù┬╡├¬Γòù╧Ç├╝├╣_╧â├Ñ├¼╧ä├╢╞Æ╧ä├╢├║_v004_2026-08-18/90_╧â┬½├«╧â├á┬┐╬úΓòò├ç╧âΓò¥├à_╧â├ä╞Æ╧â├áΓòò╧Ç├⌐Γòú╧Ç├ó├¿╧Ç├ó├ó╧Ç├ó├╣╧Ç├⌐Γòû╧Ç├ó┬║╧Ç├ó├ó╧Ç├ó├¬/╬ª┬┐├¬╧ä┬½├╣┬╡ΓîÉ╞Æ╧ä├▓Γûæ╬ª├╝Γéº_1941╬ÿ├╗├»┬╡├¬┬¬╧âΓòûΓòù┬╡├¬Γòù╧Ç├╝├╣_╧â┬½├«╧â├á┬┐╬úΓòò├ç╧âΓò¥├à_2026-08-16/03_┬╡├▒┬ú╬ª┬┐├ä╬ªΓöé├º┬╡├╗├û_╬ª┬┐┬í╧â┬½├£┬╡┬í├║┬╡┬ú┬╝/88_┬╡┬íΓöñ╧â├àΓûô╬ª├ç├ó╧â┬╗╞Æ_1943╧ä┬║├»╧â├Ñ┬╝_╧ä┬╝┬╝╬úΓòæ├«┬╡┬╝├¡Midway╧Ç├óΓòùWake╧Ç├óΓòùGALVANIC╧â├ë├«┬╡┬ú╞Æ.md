# 計算機異聞・1943秋冬 第二次Midway・Wake・GALVANIC同期

# 0. 本書の位置づけ

本書は87の1943年8月6日から時計を進め、第二次Midway、五号第三期の再判断、中国軍の能動反応、Wake空襲、1943年12月のGALVANIC相当作戦までを同じ時間軸へ載せる現行作業線である。

個々の戦闘結果は、史実への平均回帰や物語上の均衡ではなく、その時点の兵力、索敵、訓練、戦術、相手の対策から判定する。成立済みの戦果を後から「上振れすぎる」という理由だけで削らない。方法論正本00の2026-08-12追加規則を優先する。

# 1. 1943年夏の工業・艦政の同期

## 1.1 鉄鋼・輸送

現行中心線：1943年鋼塊8.1百万t（7.9～8.4）、1944年8.7百万t（8.2～9.3）。高位枝1944年9.5～10.0百万t。理論炉能力へ急接近する線は採らない。

輸送崩壊が史実より弱く、鉄鉱石・原料炭の輸入と国内沿岸輸送が健全なため1944年史実型の急落を避ける。一方、炉・港・鉄道・コークス・焼結・耐火物・電力・圧延が律速する。

商船は1944年1.2～1.45百万GRT級の高品質標準船を中心とし、最大トン数競争を行わない。木造沿岸船400～700隻、8～14万t級を補助とし、コンクリート自航貨物船は10～30隻級に抑える。

**判断の理由：** 本世界の輸送優位は「造った量」だけでなく、沈没回避、修理日数、稼働率、港湾、沿岸船による外航船解放にある。史実末期の粗製船大量建造を戦況差なしに再現しない。

## 1.2 空母・主要艦政策

既存改装の隼鷹・飛鷹・龍鳳・冲鷹は完成。新規に海鷹・神鷹・千歳・千代田を空母化せず、伊勢・日向航空戦艦化、伊吹空母化も行わない。

信濃は空母にも戦艦にも完成させず、1943年第4四半期に横須賀大型船渠を空けられる状態まで完成・浮揚して未成係留。

大鳳を質の試験艦、雲龍系を量の主線とする。雲龍・天城1944年6～7月、葛城8～9月、笠置・阿蘇・生駒1945年前半～中盤を中心とする。

**判断の理由：** 1943年に史実ほどの緊急空母欠乏がなく、改装艦へ工数を振るより専用量産艦と航空隊養成を維持する方が長期効率が高い。効果は1944～45年に現れる。

# 2. 北・北東豪州の非対称戦――1942秋～1943夏の背景

日本側は豪州本土侵攻を行わず、Horn Island反復、Cairns時折、Townsville低頻度夜襲、潜水艦通商破壊を組み合わせる。昼間陸攻をレーダー・F4U/F6F級防空へ反復投入しない。

1943年夏までの史実差中心：連合商船・輸送船10～12隻、5～6万GRT級追加損失、長期損傷7～12隻、連合航空機追加損失20～35、日本潜水艦0～2隻損失、航空18～28機損失。

6月以後は通商破壊の一部を中部太平洋の索敵・邀撃へ戻す。

**判断の理由：** 最大価値は豪州占領ではなく、輸送・護衛・航空を拘束しつつ、日本側の熟練航空・潜水艦を使い潰さないことにある。

# 3. 第二次Midway――旧中心線（2026年8月14日追記で未確定へ戻す）

> **2026年8月14日再更新：** 第二次Midwayは `28_歴史考察_1943年9月_第二次Midway再計算.md` で再計算済み。以下3.1～3.4は履歴比較専用であり、日付・OOB・戦果を現行線へ使用しない。

> **状態注記：** 以下3.1～3.4は旧87から連続して作った参考枝である。1943年6月Efate能動作戦候補と潜水艦隊再配置を先に処理するため、日程・OOB・戦果は現行中心線として固定しない。

## 3.1 米軍の作戦条件

D-Day中心は1943年8月29日。米上陸兵力18,000～20,000、中心は第27歩兵師団15～16千＋Seabees・海軍工兵・通信・砲兵3～4千。初日に12～13千を上陸させる。

米高速空母側は大型CV4～5を戦場で使用可能、CVL2～3級。**以下の「大型CV4隻以上なら日本3空母を自動投入しない」は旧作業条件であり、2026年8月14日追記により硬い自動条件としては保留する。**

## 3.2 8月26～28日の前哨航空・潜水艦戦

- 8/26：米第一大制圧約230～250ソーティ。米航空機約19損失、日本戦闘機約14損失。日本昼間G4M雷撃12機は失敗し約6機＋護衛2機損失。
- 8/26夜：日本潜水艦が米給油艦1隻を大破・mission-kill。
- 8/27：米fighter sweep約70。米9、日本11機級損失。夕刻、日本G4M8機夜襲で**CVL Independenceに魚雷1本、戦役離脱**。日本約4機損失。
- 8/28：重爆撃・艦砲射撃。日本即応戦闘機6～7、修理可能2～3まで低下。重沿岸砲4～5門級、対空火力約60％が残る。

8/26～28の米航空機損失45～50、日本基地航空約50。日本側は米大型CV4～5健在と判断し、第一機動部隊を650～750海里西方の条件付き邀撃位置に維持する。

**判断の理由：** Midwayの価値より、大型CV三隻を米4～5隻へ正面投入して1944年の主力航空戦力を失う危険の方が大きい。基地航空・潜水艦で一～二隻を先にmission-killできた場合だけ再評価する。

## 3.3 地上戦 8月29日～9月3日

日本守備隊は総員6千弱、戦闘可能5,400～5,700。Sand約3,600～3,800、Eastern約1,700～1,900。

- 8/29：米橋頭堡成立。米700～900、日本900～1,150死傷。
- 8/30：Eastern飛行場周辺、Sand橋頭堡拡張。米550～700、日本1,000～1,200。
- 8/31：Eastern組織抵抗終了、Sand中央へ。米450～600、日本900～1,100。
- 9/1：Sand中央・港湾戦。米350～450、日本800～1,000。
- 9/2：日本統一指揮が崩れ地区防御へ。米250～350、日本700～900。
- 9/3：夕刻、組織抵抗終了。9/4～6に掃討。

最終中心：米戦死約650、負傷約2,000、地上総死傷約2,650（2,200～3,250）。日本戦死約4,700、捕虜約800、行方不明・舟艇脱出100～250。

戦役全体で米航空機65～75損失。Independence大破、給油艦大破、輸送/AKA1大破、駆逐艦1中破。日本は潜水艦1沈没・1損傷、基地航空約50機喪失。

## 3.4 Midwayの評価

日本側にとって島喪失は明確な敗戦だが、主力艦隊を無傷で保持し、突出基地を一年以上使用した末に米軍へ地上約2,650、航空65～75、CVL・給油艦・輸送艦の戦列離脱を課した。後知恵では交換条件は良い。

ただし「今後の島でも同じ交換率が自動的に再現される」とは置かない。米軍は改善するが、一度の戦闘で上陸戦を完全学習する設定にもせず、火力優勢の下で同型損害を再び払う可能性を残す。

基地復旧：9/6～8緊急着陸、9/9～12小規模戦闘機、9/18～25暫定通常前進基地、9月末～10月初燃料・整備・通信、10月末～11月中旬に潜水艦・大型支援機能が概ね復旧。

**判断の理由：** Midwayは平坦で米側が旧基地資料を持ち、Tarawaより攻略条件は良い。一方6千人級の準備守備隊を三日で消滅させる線は過小。主力艦隊保存と基地破壊による一か月級遅延を戦果に含める。

# 4. 五号第三期と中国側の反応

## 4.1 五号を漢中で閉じる

9月上旬、大本営は第一・第二期を漢中占領で所期目的達成として区切る。漢中→広元の本格第三期を1943年中は発動せず、漢中確保・寧強方面前哨・道路整備へ移る。

漢中→広元の先端輸送は当初300～450t/日級。広元方面には中国軍名目11～16個師団、実効5.5～7.5万人級が再集結する。

**判断の理由：** 戦術的に広元攻略は可能でも、そこから四川政権崩壊へ直結せず、Pacificで米大型CV5隻級を実見した直後に工兵、対空、通信、トラック、航空燃料を追加投入する利益が小さい。勝っているからこそ、成果を確定して無理をしない余裕がある。

## 4.2 中国側の「太平洋は四川の外郭線」という認識

重慶上層、胡宗南系、四川地方勢力には、**米軍が太平洋で日本海軍・航空・工兵・輸送を拘束しなければ、日本軍は四川北口へさらに入る**という認識が強まる。

これは政治的には抗戦継続を支える一方、「米国が戦えば待てる」という戦力保存論にも使える。Stilwell系米武官は「米軍が太平洋で血を流して余力を吸ったなら、中国軍も反攻・Burma協力で実績を示せ」と圧力を強める。

蒋介石政権は崩れない。四川地方勢力は日本へ寝返るより中央政府の徴発・指揮要求へ値段を付ける。胡宗南系は五号損耗で弱体化し、共産党封鎖の実効兵力が低下、共産党は陝甘寧・華北で組織力を静かに増す。

**判断の理由：** 漢中喪失とMidway奪回が一か月内に起きるため、中国側には両戦域の連動が観測可能である。ただし日本側第三期停止には兵站限界も大きく、米軍行動だけを唯一原因にはしない。

# 5. 中国軍川北反攻――1943年10月7～18日

中国軍は「到来を待つだけではない」ことを示すため、広元側から6～8個師団相当、実動4.8～5.8万人を北上させる。目標は漢中奪回ではなく、日本前哨を押し戻し、道路を再破壊し、日本軍3個師団級を漢中周辺へ拘束すること。

10月前半に局地8～15km、最終10～20km級を押し戻すが、日本36・37師団＋41師団一部、航空・山砲の反撃で停止。

戦役中心：中國軍死傷7,500～9,500、日本2,700～3,500。

**判断の理由：** 中国軍は血で政治資本と時間を買うしかなく交換率は悪いが、作戦目的は敵主防御線突破だけではない。日本側も有利な交換で受け止める一方、これを追って広元へ入り直すと兵站とPacific配分を再び悪化させるため追撃しない。

# 6. 日本側の二正面非同期化と常徳

日本側は「米軍が太平洋で攻めると中国で止まり、帰ると四川へ攻める」という法則を自ら作らない。漢中正面の第三期は保留したまま、在地兵力・在地備蓄で動ける第11軍が11月初旬から常徳方面の限定攻勢を行う。

中心：11月3～5日開始、4～5個師団基幹6～7万人。常徳を一時攻略し、中国第6戦区を拘束、北Burma・四川への兵力移動を妨げる。12月5～9日に予定撤収。

中心損害：中國軍2.5～3.5万、日本0.8～1.2万。

**判断の理由：** これは五号第三期の代替四川侵攻ではない。中国軍に「日本はPacificの都合だけで中国戦を止める」と読ませず、同時に中国戦の局地攻勢能力を保持する。恒久占領を目的にしないため、輸送・守備負担の増大を限定する。

# 7. 1943年秋の水上航空再立上げ

技術数値は50・52・53を正本とする。

- 強風：1943年4～5月初実戦隊、10月第一線50～65機級。滑走路制圧後に水面から発進し、一時的に防空の数的主力となる「第二層」。F6F sweepを主任務にせず、SBD/TBF・偵察機・哨戒機を優先。
- 瑞雲：9月引渡開始、10～11月初実戦分遣。10月は「妙に高速な新型単フロート水偵」程度。偵察・触接主体で、行き掛けに軽爆撃する場合がある。
- 千歳・千代田：空母化せず、水上機飛行隊・予備機・整備員・部品を前進泊地へ運ぶ可搬航空基盤として維持。

**判断の理由：** 米高速空母は滑走路を制圧できるが、環礁の水上機泊地は別目標である。陸上機と水上機の二系統を持つことで、敵に追加ソーティ・護衛・索敵を要求する。

# 8. Wake空襲――1943年10月5～6日

米TF14相当は大型CV4（Essex、Saratoga II、Lexington II、Yorktown CV-5）＋CVL2、艦載約400機級。IndependenceはMidway被雷修理中。

Wakeは守備約5,100、陸上戦闘機22（後期零戦16、雷電6）、強風10＋旧水戦2、水偵・水観約10、瑞雲中心1機。主飛行場と水上機泊地3地区を分散運用する。

二日間中心：米航空機約38全損、駆逐艦1中～大破。日本航空機約32、潜水艦1中破、地上死傷550～750。主飛行場は4～6日大規模作戦不能、水上機泊地は部分生存。

瑞雲1機は索敵・触接に使われ、外周艦へ一発爆撃して外れる程度。米側には新型高速水偵として記録される。強風は第一波後、滑走路が傷んだ時間帯に一時的な防空数的主力となり、爆撃隊へ接触する。

**判断の理由：** 強風の価値を「米制空を覆す」ではなく、滑走路制圧後も防空処理を終わらせないことに置く。Wakeは保持するが歩兵大量増援をせず、次回も敵に二日程度の作業を要求できるよう施設分散・弾薬・電探・修理資材を補充する。

# 9. GALVANIC察知と日本側準備

高級米作戦暗号は読めない。70の現行決定どおり、反復写真偵察、攻撃しない潜水艦、Ellice方面の低級通信・補給トラヒック、短い中低級暗号窓、通信網の膨張と出航直前の沈黙を統合する。

11月上旬にGilberts 75～85％、Tarawa主目標55～65％。11月20日頃Gilberts85％級。11月28日以後、大規模輸送・舟艇系通信局の一斉消失を「無線封止して出港」と判定し、D-Dayを12月5～15日中心まで絞る。

## 9.1 日本側島嶼配置

- Tarawa：5,400～5,800、中心5,600。追加は工兵・通信・対空・迫撃砲要員中心。弾薬・水・医療・予備通信を厚くする。
- Tarawa航空：陸上戦闘機14～18、強風8～10、水偵4～6、水観2～3、瑞雲0～2。
- Makin：1,400～1,700、中心1,550。史実より増援率を大きくし、縦深陣地・地雷・迫撃砲を強化。
- Apamama：300～450。死守せず監視・破壊・遅滞。
- Marshall：Gilberts反撃可能な陸上戦闘機85～95、強風18～22、陸攻・艦攻40～45、水偵・大艇15～20、瑞雲6～8級を分散。
- 潜水艦：10～11隻をGilberts東方、Marshall間、補給路へ散開。第一優先は輸送・LST・給油、次にCVE、損傷CV、健全CV。

11月20日以後は大型輸送船をGilbertsへ送らない。

**判断の理由：** Tarawa一点へ兵員を大量集中すると米写真偵察に日本側の確信を教える。既存5千人級の生存性を上げ、Marshall航空・潜水艦という島外反撃層を強化する方が米上陸作戦機構へ効く。

# 10. GALVANIC前哨戦――1943年12月5～9日

米側高速空母は大型CV5級＋CVL3級を作戦全体に使用可能。ただし各群はMarshall制圧、CAP、ASW、Gilberts支援へ分散する。

12月5、Marshall制圧戦開始。日本側は飛行場防衛で全機を使い潰さず一部をMaloelap・Kwajaleinへ退避。

12月5夜、陸攻18機級の夜間雷撃で**Lexington IIに魚雷1本命中、mission-kill、戦役離脱**。日本陸攻約8機損失。

12月8、日本潜水艦が攻撃貨物輸送艦1隻を大破させるが、潜水艦1隻はASWで沈没。

D-Day直前までの米航空機損失35～45、日本航空機65～80級。日本側は米大型CV4隻が依然健在と判断し、翔鶴・瑞鶴・飛龍を出さない。金剛型2＋重巡級の夜戦部隊は待機・東進準備まで。

**判断の理由：** Lexington II被雷は、夜間索敵・集中雷撃を準備した条件下では中心線に置ける。成功したこと自体を理由に次の命中率を下げないが、攻撃機数減少と米夜間警戒強化は次戦条件へ入れる。

# 11. GALVANIC D-Day――Tarawa 12月10～13日

## 11.1 12月10日

12月10日は史実11月20日ほど異常な低潮条件ではなく、満潮前後にLCVPの相当数が礁越え可能とする。米側は史実より多く兵員・弾薬を初日に上げられる。

日本沿岸砲は戦艦への早射ちより、駆逐艦、掃海、上陸統制艇、LVT集結海面を優先。米側も重砲生存を前提に近接艦砲を上陸直前まで継続。

日没までに米約6,800～7,500、中心7,100上陸。Betio35～40％を確保。米地上死傷1,150～1,400、中心1,270。日本死傷・戦闘不能1,350～1,650、中心1,500。

日本側は全軍夜襲を行わず、局地浸透・陣地移転・通信線攻撃に留める。

## 11.2 12月11～13日

12月11：米軍は飛行場を横断して日本軍を分断。日没でBetio60～65％、日本組織戦闘員2,200～2,600。米当日550～700、日本950～1,150死傷。

12月11未明、事前配置潜水艦がMakin支援CVE群へ侵入し、**CVE1隻を魚雷2本で撃沈**。人的損失250～400級。潜水艦は損傷離脱。

12月12：Tarawa約80％米掌握、日本組織戦闘員1,050～1,300。米360～480、日本1,050～1,250死傷。夜間陸攻10機級がLST1隻を大破、4機損失。潜水艦雷撃は外れ、別艇1中破。

12月13：米軍が東端を掃討。16時30分を中心にBetio組織抵抗終了。

Tarawa最終中心：米戦死720～820、負傷等1,850～2,050、地上総死傷2,600～2,800。日本戦死・致命傷4,700～4,900、捕虜・重傷捕獲450～600級。

**判断の理由：** 守備隊は史実より多く、築城・指揮・弾薬も良い。一方12月10日の潮汐と米側の近接艦砲・初日補給は史実より良く、米軍一人当たりの交換率は改善する。守備隊を増やしたから史実より米死傷を必ず増やす、とは置かない。

# 12. Makin――1943年12月10～13日

日本守備約1,550、米約7,000。日本側は海岸一線集中を避け、中央・東部へ縦深化。

12月13午前に組織抵抗終了。日本戦死約1,250～1,350、捕虜・重傷捕獲150～220級。米地上死傷550～700。CVE沈没の人的損害は別勘定。

**判断の理由：** MakinはTarawaほど強固ではないが、史実より守備隊を増やした限界効用が大きい。米側も戦車・砲兵を使えるため、長期包囲ではなく三日級の攻略になる。

# 13. GALVANIC戦役収支と艦隊判断

米軍はTarawa・Makinを奪取し、作戦目的を達成した。明白な米軍勝利である。

米側損害中心：

- Lexington II：魚雷大破・戦役離脱。
- CVE1沈没。
- AKA1大破。
- 攻撃輸送艦1損傷離脱。
- LST1大破。
- 駆逐艦等複数損傷。
- 航空機70～90級全損・重大損失。
- Tarawa地上2,600～2,800死傷。
- Makin地上550～700死傷。

日本側：Gilberts守備隊約7千の大部分、Marshall航空兵力の相当部分、潜水艦少なくとも1隻喪失＋複数損傷。

12月13時点でも米大型CV4隻級が使用可能と判断されるため、**翔鶴・瑞鶴・飛龍は出撃しない。金剛夜戦部隊も反転する。**

**判断の理由：** 島を救うことと艦隊を決戦へ投入することを切り離す。大型CV4隻以上健在なら3空母を正面投入しない既定条件を、Tarawa陥落が近いという理由だけで緩めない。島側とMarshall・潜水艦で敵を削り、条件が成立した時だけ主力を使う。

# 14. 1943年12月中旬の双方の認識

米国：日本基地は攻略できるが、兵器で血を完全代替できない。上陸前から高速空母・補助空母・輸送艦へ損害を受け、Marshall本体ではさらに大きな航空基地網を処理する必要がある。Europe First、Italy、BOLERO/OVERLORD準備のため、Pacificで上陸作戦を無制限連発できない。

日本：島は米高速空母＋艦砲＋上陸火力に長期保持できないが、守備隊・水上航空・夜間航空・潜水艦を重ねれば攻勢機構へ実損害を与え、主力艦隊を保存できる。次のMarshallではTarawaの単純大型版ではなく、島間航空・潜水艦・撤収不能部隊の配分を再設計する必要がある。

中国：米Pacific攻勢が四川深部侵攻を抑えるとの認識を維持するが、日本軍が常徳等で独自時計の限定攻勢を続けるため「米軍が攻めれば中国は何もしなくてよい」という単純法則にはならない。米側も中国にBurma・局地反攻の実績を要求し続ける。

# 15. 次に残る論点

1. GALVANIC直後の米高速空母・CVE・上陸部隊の補充・修理時計。Lexington IIの戦列復帰時期。
2. Marshall攻略の目標選定・時期。米軍がKwajalein/Majuro/Maloelap等をどう比較するか。
3. 日本側Marshall防御を「Tarawa型島守備」からどこまで分散航空・潜水艦・機動予備型へ変えるか。
4. 1944年初の五号第三期再審査。中国川北・常徳・Burma・Cairo後の政治軍事情勢。
5. 1943年末の日本航空隊教育・艦載機補充。主力空母は無傷でも、基地航空・夜間陸攻の消耗をどう補うか。
6. 米国がEurope First下でMarshall作戦へ割ける上陸船艇・工兵・CVE・補給艦の実数監査。


## 2026年8月14日追記――第二次Midway自動不参戦条件の保留

旧3章の「米大型CV4隻以上健在なら翔鶴・瑞鶴・飛龍を島救援へ自動投入しない」は、**硬い自動条件としては保留**する。

主力空母投入は敵大型空母数だけでなく、敵空母の分散・損傷、基地航空支援、水上部隊の接近可能性、潜水艦接触情報、敵航空損耗、給油状態、作戦目的を合わせて段階判定する。

投入段階：

1. 基地航空・潜水艦のみ。
2. 主力空母を邀撃位置へ出す。
3. 一部航空攻撃。
4. 水上部隊を夜間投入。
5. 条件が極端に良い場合のみ主力空母決戦。

Midwayで米4～5CVが集中健在、島基地航空が制圧されているなら旧慎重判断はなお有力。しかし、潜水艦・基地航空で1～2群がmission-kill、給油で分離、輸送船団が露出等なら限定投入を再評価する。

さらに、87追記の1943年6月Efate能動作戦候補が先に発生し得るため、**第二次Midwayの日程・OOB・日本投入判断はEfate戦役を閉じるまで未確定へ戻す。**

## 2026年8月14日追記――Efate確定後の再接続条件

27でEfate無力化作戦を閉じた。Enterpriseは6月14日級にmission-killされ10～12週修理、翔鶴も6～8週修理、日米双方の艦載航空隊に大きな損耗が出る。Victoriousは7月帰英中心。

したがって旧3章の第二次Midway OOB・日付・戦果は引き続き未確定。次回は、Yorktown CV-5＋Essex＋Saratoga II＋Lexington II等の戦闘即応日と、翔鶴の艦体/航空隊復帰、瑞鶴・飛龍の補充、潜水艦配分を同期して再計算する。旧「大型CV4隻以上なら自動不参戦」条件は復活させない。
