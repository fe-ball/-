# 1941-12-07 Pearl Harbor RUN v0.01

## 固定条件
- 米側配置・警戒・指揮、港内艦艇配置、天候・時刻は史実。
- Enterprise は0615時点Oahu西方約215海里。18機SBDの進出・捜索行動は同じ。
- 日本側は六空母、目標選択、二波攻撃、第三波なし。

## 日本側差分
- 瑞星零戦、瑞星B5N、1941後期D3A。
- 九一式航空魚雷は1941年末時点で史実より半年～1年程度熟成した投下・入水・ロット管理。
- 雷撃総合命中率は同条件相対+10～25%。水平爆撃点目標+15～35%、急降下固定目標+15～30%、戦闘機対地固定銃+20～40%。

## 実行結果（中心線）
- 有効攻撃参加353機（352～354）。
- 不可逆損失28機（27～29）。
- 航空要員死亡53名前後（50～55）。
- 航空魚雷命中23本中心（21～24）。
- 800kg級重爆弾命中9発中心（9～10）。
- 米航空機の追加完全損失は6～12機級。ただし地上破壊なので搭乗員損失へ同数変換しない。

## 艦艇結果
Arizona/Oklahomaは既に損害閾値を大きく越えるため結果級は不変。West Virginia/Californiaも沈座級。追加命中の価値は、既沈艦への過剰損傷より、Nevada、Tennessee、Maryland、Pennsylvania、巡洋艦・駆逐艦等の修理時計へ出る。個艦配賦は元の攻撃軸を保存したまま次層で閉じる。

## パイプライン
米側は艦艇修理・航空機補充要求が史実より少し増すが、燃料タンク、修理工場、発電、潜水艦基地は第三波なしのため残る。従って補充・修理系全体が破断するほどではなく、主効果は修理キューと前線航空機補充への小さな追加負荷。

日本側は29機→単純27機のように決め打ちせず、28機中心。帰投損傷機、搭乗員負傷、整備工数、Wake派遣可能機数へ後続伝播する。
