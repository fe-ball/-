# 計算機異聞・艦艇対潜　探信・爆雷・護衛運用正本

# 0. 本書の位置づけ

本書は、これまで `40_対潜航空_東海・カ号・秋津丸.md` に空側だけが正本化されていた対潜戦について、**艦艇側の探知・追跡・爆雷攻撃・船団護衛**を独立してまとめる。

二艦協同による「接触保持→攻撃→即再捕捉→反復攻撃」は、単なる探信距離・爆雷精度の改善ではなく戦術サイクル自体を変えるため、61の質的変化一覧へ接続する。

1942年の日本海軍を「ソナーも爆雷もなく、潜水艦に何もできない」とは扱わない。史実でも実用探信儀、聴音機、爆雷、駆潜艇、旧式駆逐艦、海防艦等は存在する。

一方で、本世界の計算機が新原理ソナー、前方投射兵器、護衛艦用高性能レーダーを突然発明することもしない。

本世界で先行するのは、次の部分である。

- 自艦雑音と探信距離の定量化。
- 艦ごとの探信儀較正と性能ばらつき縮小。
- 接触後の潜水艦運動予測。
- 爆雷深度・散布・投下時刻の表化。
- 二艦協同による接触維持と再捕捉。
- 船団に護衛を残しつつ攻撃艦だけを分離する運用。
- 接触位置、攻撃結果、故障、爆雷消費を局地護衛指揮へ戻す循環。

したがって1942年夏の中心評価は、

> **史実1942年相当の兵器を、史実より一段まともな体系として使う。重点船団は明確に攻撃しにくくなるが、米潜水艦を海域から締め出すほどではない。**

とする。

本書の史実比較値と改善率は、型別一次資料の統一監査が終わるまで**高確度暫定または中心推定**として扱う。

# 1. 史実側の装備基準

## 1.1 九三式水中探信儀級

史実側の米海軍戦後調査で、日本の九三式水中探信儀級は1930年代後半から実用されていた中程度のアクティブ探信装置である。

公開資料からの比較基準として、可靠探知距離はおおむね次のように扱う。

| 自艦速力 | 史実側の可靠探知距離・目安 |
|---:|---:|
| 6kt | 約2,500m |
| 10kt | 約2,000m |
| 12kt | 約1,500m |
| 14kt | 約1,000m |

平均的な方位誤差は約5度、距離誤差は数十m級を比較基準とする。

ここで重要なのは、装置の最高性能より、**自艦速力と自艦雑音が急速に探知能力を食うこと**である。

## 1.2 聴音機

停止～低速時の受動聴音は、条件が良ければ2km級以上の接触を得る余地がある。ただし目標・海況・自艦機械音の影響が大きく、方位のみで深度を直接与えない。

## 1.3 爆雷

艦隊駆逐艦は数十発級、駆潜艇も数十発級の爆雷搭載が可能であり、爆雷そのものが不足して攻撃不能という出発点ではない。

九五式爆雷に加え、**二式爆雷は史実でも1942年採用**で、深い設定まで選べる。

本世界では二式爆雷を年単位で早期発明しない。採用後の生産・配備・設定表・教育が少し早く安定する。

# 2. 自艦雑音――本世界で最も早く効く部分

`10_水上艦_駆逐艦・戦艦改装・大和型.md` では、朝潮型・陽炎型の段階で、軸系ねじり・横振動、歯車噛合い、タービン、プロペラ、船尾流、製造公差を計測して後続艦へ戻す体系が成立している。

潜水艦側でも水中音の実測と静粛化が進むため、艦艇対潜部門は自然に同じ測定文化を利用する。

## 2.1 速度別探信表

各艦について、

- 艦速
- 軸回転数
- 補機状態
- 海況
- 目標方位
- 探信周波数・利得

と探知距離の関係を試験表にする。

その結果、艦長・対潜班へは単なる「探信儀最大距離」でなく、

- **捜索速力：8～10kt中心**
- **接触追跡：10～12kt中心**
- **15kt以上：位置変更・追越し用で、捜索には不利**

という速度別用途が明瞭に教育される。

高速駆逐艦ほど「速く走ればよく探せる」という誤認を避ける効果が大きい。

## 2.2 装置そのものの改善幅

新原理化しないため、最良条件の距離を倍増させない。

中心作業値：

- 最高条件の探知性能：史実比0～10％改善。
- 量産艦の中央値：10～20％改善。
- 艦ごとの性能ばらつき：20～40％縮小。
- 10kt級の可靠探知：成熟艦で約2,100～2,300m級を安定して出す場合。
- 方位誤差：平均5度級から4～4.5度級へ小幅縮小する余地。

主効果は「最高の一艦」ではなく、同型艦が同じ手順で同程度に使えることに置く。

# 3. 爆雷攻撃――深度と投下点を計算する

## 3.1 深度設定

史実前半の対潜攻撃では、爆雷設定が浅すぎ、真上で爆発しても米潜水艦へ致命傷を与えない例がある。

本世界では友軍潜水艦を用いた演習から、

- 潜航開始からの時間
- 推定潜航率
- 推定速力
- 最終視認深度
- 最終探信距離

を用いて、**時間×推定深度表**を作る。

例示的な運用区分：

- 接触直後：30～60m。
- 数分経過：60～90m。
- 深深度逃避が疑われる：90～120m。
- 長時間接触・大型米潜：より深い設定も混合。

これは深度を直接測る技術ではない。潜水艦が取り得る運動から確率分布を作るだけである。

## 3.2 信管・炸裂深度のばらつき

加工・検査・ロット統計の改善により、

- 信管部品の加工ばらつき：20～30％縮小余地。
- 海象・投下姿勢を含む実炸裂深度散布：10～20％程度縮小。

を中心作業値とする。

## 3.3 最終接触後の攻撃盤

通常爆雷攻撃では、艦首直下へ目標が入り、爆雷投下直前に探信接触を失う。

本世界でもHedgehog級の前方投射兵器はないため、この構造的欠点は残る。

しかし最後の数十秒について、

- 最終探信距離
- 方位
- 方位変化率
- 推定潜水艦速力
- 自艦速力
- 転舵量
- 爆雷沈降時間

を大量に陸上計算し、簡易盤・尺・表へ落とす。

典型的には、

> 「最終接触○百m、右方位変化○度/分、自艦○ktなら、○秒後に○度変針して投下」

という実務表になる。

艦上に汎用電子計算機を置く必要はない。

# 4. 二艦協同と再捕捉

爆雷投下艦は、自艦騒音と爆発音のため、一時的に耳を失う。

そこで本世界では早めに、

- 一艦：接触維持
- 一艦：攻撃

を基本とする二艦協同が標準化される。

攻撃艦が爆雷投下後、少し離れた接触維持艦が再捕捉し、必要なら役割を交代する。

ただし船団護衛では全護衛艦が一隻の潜水艦を追わない。

護衛3～4隻なら、中心原則は、

- 1～2隻を攻撃へ分離。
- 1～2隻は船団直衛を継続。

とする。

## 4.1 「油膜＝撃沈」をやめる

演習で友軍潜水艦に油・気泡・浮遊物を放出させれば、油膜だけで撃沈判定できないことは戦前に認識可能である。

したがって撃沈確認には、

- 再捕捉不能の継続
- 大量破片
- 大量油と気泡の継続
- 水中爆発後の明確な構造物
- 後続情報

を組み合わせる。

これにより「早く勝ったことにして船団へ戻る」誤判定は減るが、確実撃沈確認のために護衛を無制限に拘束もしない。

# 5. 船団護衛の組織

史実の海上護衛総司令部級の全国統合組織を1942年に前倒ししない。

本世界の1942年は、輸送・港湾・暗号・航路計画が既に史実より体系化されているため、まず**局地護衛指揮**が先行する。

## 5.1 中心日程

- 1941年末～42年春：鎮守府・艦隊の護衛担当幕僚強化。
- 1942年夏：Truk–Rabaul–Port Moresby、Rabaul–Solomons等の重点線に局地護衛指揮所。
- 1942年秋以後：接触・損失が増えれば、局地組織を常設化。
- 全国統合組織の成立時計は、実際の潜水艦損害・船腹事情を見て決める。

## 5.2 指揮所が集約するもの

- 船団出港日・速力・航路。
- 護衛艦割当。
- 潜水艦接触位置・時刻。
- 過去の接触密度。
- 航空哨戒要求。
- 爆雷消費。
- 探信儀故障・較正。
- 攻撃後の再捕捉成否。
- 敵潜の行動時間・海況との相関。

「同じ海図を別部署が別々に作る」状態を減らすことが主効果である。

# 6. 1942年FS前後の護衛戦力像

この時点では、護衛用の新造海防艦が大量に湧くとはしない。

中心は、

- 旧式駆逐艦
- 艦隊型駆逐艦の一部
- 駆潜艇
- 掃海艇・哨戒艇
- 既成海防艦

である。

新鋭陽炎・夕雲型は優秀だが、2,000t級35kt水雷戦駆逐艦を通常船団護衛へ常用するのは高価である。

したがって米潜水艦の圧力が増えるほど、

> **艦隊型駆逐艦を護衛に貼らずに済む専用護衛艦が必要**

という要求が強くなる。

これは後の海防艦・簡易護衛艦の要求時計へつながる。

## 6.1 船団の中心像

通常小船団：

- 輸送船4～8隻。
- 護衛2～3隻。

重点船団：

- 輸送船8～15隻級。
- 駆逐艦・旧式駆逐艦2～4。
- 駆潜艇・掃海艇等2～4。

FS攻略船団のような最重要船団は、さらに艦隊型駆逐艦、航空哨戒、場合によっては航空甲板による掩護を付ける。

## 6.2 FS前に利用できる補助要素

- 二式爆雷への切替開始。
- 艦別探信性能表と速度別捜索法。
- 二艦協同の標準化。
- 昼間の通常航空目視哨戒。
- 重要船団では大鷹等の航空掩護を選択可能。ただし補充機回送能力との交換を伴う。
- 高級暗号から船団時刻を高精度に抜かれにくい通信環境。

これらは護衛艦レーダー、前方投射兵器、東海・カ号の本格部隊を代替しない。

# 7. 1942年時点で残る明確な穴

## 7.1 水上捜索レーダー

護衛艦へ夜間浮上潜水艦を広域探知するレーダーは、まだ標準装備としない。

したがって夜間・悪天候では米潜水艦に大きな自由が残る。

## 7.2 前方投射兵器

Hedgehog級の「接触を保ったまま前方へ投射する」兵器はない。

爆雷攻撃では最後に接触を失う構造が残る。

## 7.3 深度直接測定

探信儀は目標深度を精密に直接与えない。深度設定は統計・推定である。

## 7.4 小型艦の装備差

全護衛艦が同じ探信儀を持つわけではない。聴音中心の小艦、古い装置、整備不足は残る。

## 7.5 海況

荒天・高海況では探信性能が急落する。

# 8. 実戦効果の中心作業値

**十分な護衛が付いた重点船団**について、史実日本1942年相当との相対比較として、次を研究用作業値とする。

| 指標 | 本世界の変化 |
|---|---:|
| 接触後の再捕捉成功 | 相対20～35％改善 |
| 潜水艦の二回目以降の攻撃機会 | 15～30％減 |
| 爆雷による重大損傷確率 | 相対20～40％改善 |
| 潜水艦撃沈数 | 上記ほど比例して増えない |

重要なのは撃沈数ではなく、

> **第一射後に深深度潜航・離脱を強制し、同じ船団へ二撃目を許さない**

ことに置く。

1942年の米潜水艦には魚雷不良も残るため、日本側の護衛改善と相まって、良い狩場が存在しても「一方的な漁」にはならない。

一方で、沖合の広海面、夜間、航空哨戒外では米潜水艦の活動余地は十分残る。

---

# 9. 対潜航空との接続

1942年夏の時点では、東海の本格部隊はまだない。通常水偵・飛行艇・基地航空の目視哨戒と艦艇護衛が主役である。

1942年末～43年以降、`40_対潜航空_東海・カ号・秋津丸.md` の東海・カ号が立ち上がると、艦艇側は、

> 発見 → 標識・接触維持 → 艦艇が探信再捕捉 → 爆雷攻撃

へ接続する。

東海・カ号が潜水艦を大量撃沈するのではなく、潜水艦の水上高速移動・再攻撃・港口待伏せを抑え、艦艇側が接触を継続しやすくする。

# 10. 艦種別の使い分け

## 10.1 艦隊型駆逐艦

対潜能力は高いが、高速水雷戦・空母護衛用の高価な資源である。通常船団へ常時貼り付けず、FS攻略船団など最重要船団、既知接触点の掃討、空母直衛との兼務を中心とする。

## 10.2 旧式駆逐艦

中速船団の護衛へ適する。改装時には探信・爆雷・通信・発電の更新を優先し、船団から離れすぎない二艦協同を標準化する。

## 10.3 駆潜艇

港湾出入口、狭水道、短距離船団、既知接触点の追跡に用いる。外洋で艦隊型駆逐艦と同等の速力・耐波性を要求しない。

## 10.4 海防艦

1942年夏にはまだ数的主役ではない。1942年末～43年に米潜活動と船団需要が増えた段階で、専用護衛艦として建造・配備の優先順位を上げる。

# 12. 史実照合に用いた代表資料

本書の史実側装備・評価は、会話中に確認した以下の系統を基礎とする。

- U.S. Naval Technical Mission to Japan / ONIの日本対潜兵器調査。
- U.S. Navy wartime/postwar anti-submarine warfare reports。
- 日本側海防・駆潜艇・爆雷・探信装備に関する公開要目。

本世界の改善率は史実資料の引用値ではなく、本プロジェクトの計算援用・品質統計・試験還流を適用した**中心推定**である。
