# 1. この監査へ入った経緯

FORAGER/フィリピン海級の航空戦を再計算した際、日本側の航空戦術・航空隊運用が、本世界で積み上げた研究・空母運用・空地分離・人員循環に比べて史実的に鈍いことが問題になった。

確認すると、

1. 戦闘処理に史実的な航空戦術・練度消耗を残したまま、本世界の機数・一部性能だけを載せた箇所があった。
2. 44/45/46で戦術研鑽、空地分離、自然還流・練度平準化を再監査した。
3. その入力となる航空機性能自体も、排気、プロペラ、発動機高度出力、防護重量、燃料、艦上適合が統合監査されていなかった。
4. そこで戦史時計を1944-07-07夜で止め、47の航空機技術監査へ戻った。

したがって今回のHARD監査は、機体を都合よく強化する作業ではなく、**戦闘シミュレーションの違和感から入力値を逆監査した結果**である。

# 2. 世界観上の処理原則

登場人物は未来を知らない。後世の成功機・失敗機の評価は開発判断へ注入しない。

計算機が増やすのは、

- 比較案の数。
- 荷重・重量・振動・冷却・燃料・弾道計算の反復。
- 試験条件の統一。
- 故障・量産不良のロット相関。
- 試験結果を次案へ戻す速度。

である。

材料、工作機械、熟練工、燃料品質、長時間耐久、腐食・疲労の実時間は消えない。

性能は「排気+10km/h、プロペラ+5km/h」のように加算せず、高度別軸出力→プロペラ→冷却・カウリング・排気→重量・抵抗→部隊ばらつきの順で一体計算する。

# 3. 推力式単排気管

117で閉鎖済み。

中心時計：

- 1941年：台上・少数飛行試験。
- 1942年前半：機種別比較。
- 1942年後半：量産標準化。
- 1943年：広い後付け・改修。

金星零戦改は初試作から統合する。瑞星後期零戦は1942年後半型から標準化可能。個別速度ボーナスは禁止する。

三翅定速約3.0～3.05m、1942年後半以後は推力式単排気管、20mm二号＋13.2mm、無線改善、主翼・尾翼剛性、高速急降下域を改善する。

水メタノールは比較試験するが、空母主力瑞星型の標準にはしない。1,080馬力級を安定して使うことを優先する。

防護は全面自己防漏ではなく、背面・頭部の限定防弾、燃料遮断、逆止弁、防火・消火、局部防漏を中心とする。

旧560～575km/hは系列包絡として大崩れしないが、575km/hは良好機側へ送る。

金星換装は発動機交換ではなく、前部胴体、架、カウリング、油・補機、吸排気、プロペラ、中央翼、脚、車輪、重心、燃料、尾翼・艦上荷重を含む中規模再設計とする。

主要空母では格納上の名目搭載数ペナルティを原則置かないが、発着艦回転率は瑞星型より悪化する。小型空母は混成、龍驤は瑞星主体。

# 6. 誉／紫電改

誉は「失敗作」でも「完全な2,000馬力」でもない。小径18気筒の高出力密度ゆえ、後列冷却、潤滑・軸受、材料代替、加工公差、燃料・油、前線整備が厳しい。

# 7. ハ43／烈風

ハ43は41.7L級18気筒・2,100～2,200馬力級を狙う三菱主線。三菱の金星・火星・瑞星で得た冷却、過給、減速、潤滑、公差管理は使えるが、18気筒クランク系、後列冷却、2,000馬力級プロペラは新規課題として残る。

中心時計：

- 1940年後半：予備研究。
- 1941年：本格開発。
- 1941末～42前半：初期試作。
- 1942後半：1,950～2,050hp級。
- 1943前半：飛行用2,000～2,100hp級。
- 1943後半：選別2,100～2,200hp級。
- 1944前半：先行量産。
- 1944後半：量産標準化。

| プロペラ | 四翅3.85～3.90m中心 |
| 最高速・良好機 | 638～645km/h |

4.5t級は一般正規空母の5t級昇降機を意識した硬い重量上限として扱う。通常全備5t超を標準化しない。

1944年7月は試作・審査・先行生産段階。FORAGERの実戦戦力へ数えない。最初の小規模実戦部隊は1944年末中心。

# 8. B6N護型／火星比較

護一一型は約1,870hp級。火星より燃費が良い方向、火星と近い出力帯、史実で量産前半まで実際にB6Nへ搭載されたことから、最初から火星へ切り替えない。

本世界では海軍零戦の栄大量需要が小さく、中島の余力が増える一方、火星はG4M/H8K/雷電と競合するため、護を成熟させる機会費用上の意味が大きい。

1943年初頭に、

- 200時間級耐久。
- 50機級部隊統計。
- 予定外発動機交換率。
- 工場不合格率。
- 同一条件巡航燃費。

で判定する。

中心線は**護主線・火星保険枝**。

# 9. 航空運用・人員側との接続

45・46の中心線は維持する。

- 激戦・大量損耗が発生していない時期へ、史実の搭乗員・整備員練度崩壊を自動移植しない。
- MI後は戦傷、療養、母艦修理、航空隊再編、補充機受領、新編隊で自然還流が起こる。
- 空地分離が飛行隊・直接整備員の可搬性を高める。
- 経験者ゼロの新編隊を減らし、艦上、航法、無線、編隊指揮、整備等の資格を別に扱う。
- 平均搭乗員を超人化するのではなく、部隊単位の下側リスクを減らす。
- 一方、戦闘・事故・疲労・教育不足が実際に積み上がった場所では、その損耗を普通に反映する。

したがって今後は「1944年だから史実同様に練度が低い」と置かず、各戦役で実際に失った人員、飛行時間、補充、再編を追う。

# 10. 現在の意味

今回の監査で、後期海軍戦闘機体系は性能表だけでなく役割が再び見えるようになった。

- 瑞星後期零戦：軽量・長航続・扱いやすい量的主力。
- 金星零戦改：重量・航続・艦上余裕を払い、速度・防護・火力を買う重艦戦。
- 雷電：火星を使う基地邀撃。
- 紫電改：誉の整備負担を受け入れて重要基地へ集中する陸上高性能万能機。
- 烈風：5t級艦上設備限界を意識した次期艦上主力。
- B6N護型：大型空母向け高速長距離雷撃機。火星とは信頼性だけでなく燃費・生産競合で比較する。

「成立理由のある高性能は残し、成立理由のない数字だけ落とす」状態へ移った。
