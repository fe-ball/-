# 1944年7月 Marianas直前 実艦・Availability台帳

## 1. 帳簿規約

本台帳では、**存在する艦 ≠ 戦闘即応艦 ≠ 決戦へ投入すべき艦**を分離する。

状態記号：

- **A**：第一線即応。訓練・整備・航空隊を含め決戦投入可能。
- **B**：戦闘可能だが、航空隊充足、慣熟、速力、修理、別任務等に制約。
- **C**：艦体は存在/就役直後だが、Marianas決戦の第一線へ数えない。
- **D**：建造・艤装・保管中。
- **X**：本世界でも喪失。

中心基準日は**1944年7月10～12日前後**。FORAGER D-Day自体は39で7月8～15日感度帯、中心7月12日を暫定時計とし、戦闘結果はまだ固定しない。

Marianas直前の艦上機は、甲板搭載可能数ではなく搭乗員・整備員律速を入れ、

- 実際に艦上で戦闘使用できる機体：**460～500機級**
- 全部隊から無理に抽出する短期上限：**約510機**
- うち第一線資格・編隊練度が比較的高い層：**420～460機級**

を中心とする。

|---|---|---|

| 天城 | C/D | 7月完成圏。さらに慣熟不足。第一線不参加 |

**重要：** Marianasが1か月遅れたことで雲龍・天城の船体完成は近づくが、これは即座に「日本空母2隻増」ではない。航空隊・甲板要員・機関慣熟・損害管制訓練が律速する。

### 空母化しない艦

- 千歳・千代田：水上機母艦のまま。
- 信濃：未成船体として係留保管。空母・戦艦のどちらにも数えない。
- 伊吹：重巡完成線。空母化しない。

## 2.2 戦艦

### 現存11隻中心

| 群 | 艦 | 状態・任務 |
|---|---|---|
| 大和型 | 大和、武蔵 | A。主力水上打撃、敵戦艦拘束、上陸船団突入候補 |
| 長門型 | 長門 | A/B。主力線へ投入可 |
| 金剛型 | 金剛、比叡、榛名、霧島 | A。高速前衛・夜間邀撃・空母群外周打撃 |
| 扶桑型 | 扶桑、山城 | B。25kt級。第二線・基地砲撃・予備 |
| 伊勢型 | 伊勢、日向 | B。航空戦艦化せず12×36cm砲戦艦のまま。第二線・砲撃・予備 |
| 長門型 | 陸奥 | X。1943年6月8日爆発喪失を本世界中心線でも維持 |

### 陸奥の最終扱い

陸奥事故の原因は確定不能で、計算機援用が直接除去したと断定できる因果がない。弾薬温度・棚卸し・火災検知等の改善で事故確率を下げる余地はあるが、史実事故を消すには根拠が弱い。

したがって**現行中心線では陸奥喪失を固定**する。生存は低確率枝（20～30％級の感度）としてのみ残し、Marianas OOBへ数えない。

### 決戦で実用しやすい数

- 高速前衛：金剛型**3～4隻**。
- 主力砲戦：大和・武蔵・長門**3隻**。
- 旧式第二線：扶桑・山城・伊勢・日向から**2～4隻**。

「存在11隻」を一つの艦隊へ全部積むのではなく、速力・燃料・航空掩護・上陸船団距離で分ける。

## 2.3 重巡

史実MI/Savo/Guadalcanal型の喪失が消えているため、既成18隻は全艦生存中心。

| 艦級 | 艦 |
|---|---|
| 古鷹型 | 古鷹、加古 |
| 青葉型 | 青葉、衣笠 |
| 妙高型 | 妙高、那智、足柄、羽黒 |
| 高雄型 | 高雄、愛宕、摩耶、鳥海 |
| 最上型 | 最上、三隈、鈴谷、熊野 |
| 利根型 | 利根、筑摩 |

- **存在：18隻**。
- 定期整備・局地任務を引いた第一線即応：**16～18隻**。
- Marianas決戦へ実際に割当可能：**14～16隻**中心。

最上・三隈はMI衝突なし。加古・古鷹・衣笠も史実Solomons型戦没を免れる。

### 伊吹

伊吹は重巡として建造継続。**1944年6月末～7月前半の完成/就役圏**へ置くが、Marianas直前ではC。公試、射撃、機関慣熟、水雷・電探・部隊通信統合が不足するため、第一線夜戦隊へ入れない。

したがって帳簿上は「19隻目の重巡船体が存在し始める」が、決戦即応重巡は既成18隻から数える。

## 2.4 軽巡

中心線でMarianas直前に存在する第一線/通常軽巡は次を基礎とする。

- 天龍、龍田。
- 多摩、北上、大井、木曾。**球磨はX**（1944年1月Malaya方面潜水艦戦没を維持）。
- 長良、五十鈴、名取、由良、鬼怒、阿武隈。
- 川内、神通、那珂。
- 阿賀野、能代、矢矧。
- 大淀。
- **夕張はX**（本世界Palau後退避中、1944年4月26日前後に潜水艦雷撃で喪失）。

よって主要軽巡は**19隻存在中心**。このうち第一線即応は**16～18隻**、Marianasへ直接割り当てるのは**10～13隻**程度。

北上のみ40門重雷装実証艦。大井は通常軽巡として扱う。北上は良条件夜戦の特殊札であり、常時編成へ足さない。

香取型等の練習巡洋艦は別帳。Truk退避による香取生存可能性は高いが、決戦巡洋艦数へ含めない。

## 2.5 駆逐艦

個艦割当は戦役差が多く、巡洋艦以上ほど完全には閉じない。ここでは**存在確度の高い個艦群＋級別範囲**で固定する。

### 大きな生残差

史実Guadalcanal/Solomons/Rabaulで失われた多数艦が本世界では残る。高確度の復帰候補には、吹雪、叢雲、夏雲、暁、夕立、綾波、高波、照月、巻雲、村雨、峯雲、新月、長月、嵐、萩風、江風、夕雲、初風、涼波、大波等が含まれる。

一方、すべてを生存させない。開戦初期、潜水艦、機雷、事故、Aleutians、1944年Philippines集中航路等の損失は残る。

### 1944年春夏の追加固定

- 若竹：4月Palau空襲でX。
- 水無月：6月6日前後、Tawi-Tawi周辺で米潜水艦によりX中心。
- 早波・谷風：本世界ではASW/航路分散差により生存中心。ただし高危険感度艦。
- 島風：A。高速実証艦として実戦化済み。
- 改島風：Marianasまでの完成艦0。後続実証艦は建造/試験段階としても第一線へ数えない。

### 数量中心

- 艦隊型駆逐艦存在：**55～62隻**。
- 戦闘即応：**45～52隻**。
- Marianas決戦へ割当可能：**32～40隻**。

級別の粗い存在帯：

| 系統 | 存在中心帯 |
|---|---:|
| 吹雪・暁系 | 11～13 |
| 初春・白露系 | 8～10 |
| 朝潮型 | 7～8 |
| 陽炎型 | 12～14 |
| 夕雲型 | 10～12 |
| 秋月型 | 5～7 |
| 島風 | 1 |

**判断の理由：** 本世界では駆逐艦を増やしたというより、史実の連続水雷輸送・Solomons夜戦・Rabaul航空戦で消えた艦が残る効果が大きい。そのため一戦の護衛数より、護衛・水雷・空母直衛・後方輸送を同時に満たすAvailabilityが改善する。

## 2.6 工作・給油

### 明石

**A。生存。** TrukからPalauを経てDavao/Philippines方面へ退避し、Palau空襲を回避。Marianas前には前線泊地へ常置せず、Davao～Tawi-Tawi/Philippines内側で修理回転を支える。

明石生存は砲力ゼロでも重要で、CA/DDの中破→戦列復帰時計を短縮する。

### 艦隊給油艦

Palauで史実喪失したIro・Ose・Sata級の主要タンカーを中心に複数が生存。4～6月の潜水艦戦で中小タンカー喪失は続くため全保存ではない。

Marianas直前：

- 大型艦隊給油艦・高速タンカー：史実同時期比**+2～3隻級**の純生残差。
- A-GO級作戦へ実際に積載・随伴できる大型AO/タンカー：**6～8隻中心、上振れ8～10**。

燃料そのものは有限であり、給油艦生存を「燃料無限」としない。ただし高速艦隊の再給油・離脱・再突入選択肢は史実より明確に増える。

## 3.2 Light carrier

1944年7月7～14日にMarianas第一線へ置けるIndependence級8隻：

**Princeton、Belleau Wood、Cowpens、Monterey、Langley、Cabot、Bataan、San Jacinto。**

**Independence CVL-22は除外する。** 史実でも1943年11月の雷撃損傷後の修理完了は1944年7月15日で、7月3日にPearl Harborへ戻っていても7月前半のMarianas決戦へ戦闘参加できる時計ではない。一方Bataan CVL-29は史実Philippine Sea参加艦である。

Marshallで本世界独自にmission-killされたCVL1隻は4～6週時計を終えているため、**7月7～14日の戦闘可能CVLは8隻中心**という総数自体は変わらない。Independenceは7月15日以後の夜間航空訓練・後続作戦から復帰候補とする。

## 3.3 米艦載航空

史実Philippine SeaのTF58は7 fleet carrier＋8 light carrier級で約900機規模だった。本世界の7月候補ではfleet carrierが9～10隻へ増える。

したがって、整備・予備・部隊ローテーション込みでMarianas戦域へ投入可能な艦載航空は**1,000～1,100機級**を中心とする。

全機を一回の攻撃隊へ変換しない。日本水上主力生残のため、対艦索敵、CAP、潜水艦警戒、Lee battle lineの上空援護へ史実以上の一定割合を拘束される。

## 3.4 高速戦艦

Marianas第一線の高速戦艦：

**Washington、North Carolina、South Dakota、Indiana、Alabama、Iowa、New Jersey**の7隻中心。

Missouriは1944年6月11日就役だが、その年の残りを戦闘準備に使うためMarianasへ数えない。Wisconsinも艦体は存在するが、Marianas第一線へ間に合わない。

上陸砲撃用旧式戦艦群も別に存在し、米側は「高速戦艦7隻を島砲撃へ全投入」せず、日本水上突入阻止へ保持できる。

## 3.5 巡洋艦・駆逐艦

米側は新造量が大きく、日本側のような「一隻の生残差が全艦隊の護衛不足へ直結する」段階ではない。

- 重・軽巡：高速空母群、上陸支援、夜間邀撃を同時に構成可能。
- DD/DE：日本潜水艦・水上艦が史実より厚いためASW/CAP picket/外周警戒への拘束が増えるが、絶対数は不足しない。

個艦巡洋艦・DD台帳はFORAGER OOB確定時にtask group単位で閉じる。

# 4. 日米比較――「艦数が増えた」の中身

## 4.1 日本側が特に増えたもの

- 金剛型4隻が揃う。
- 重巡18隻がほぼ揃う。
- 艦隊型DDが史実よりかなり厚い。
- 明石が生きている。
- 主要AOが複数余計に生存。
- 史実Solomons/Rabaulで失った巡洋艦・DD・搭乗員を他任務へ回せる。

これらは、**水上突入、修理回転、護衛の肩代わり、給油、複数作戦群の同時編成**へ効く。

## 4.2 米側が特に増えるもの

- Yorktown CV-5生存でfleet CV +1。
- 本世界Intrepid損傷が史実ほど長期修理でないため7月復帰。
- Marianasの約1か月遅延でFranklinが実戦圏へ入る。

結果として、空母航空の純量比は日本に有利へ近づくどころか、**史実より米側へ開く可能性が高い**。

## 4.3 したがってMarianasで比較すべきもの

単純な「日10空母対米18空母」ではなく、

- 日本：第一線主力4＋第二線6、実効艦載機460～500。
- 米：fleet CV9～10＋CVL8、実効艦載機1,000～1,100。
- 日本：戦艦11現存中心、重巡18、DD55～62、明石・AO増。
- 米：高速BB7＋上陸支援戦艦多数、巡洋艦・DD絶対量大。

という**航空量では米優勢、水上艦の残存・任務選択肢は史実より日本が大幅改善**した構図で見る。

日本側の勝ち筋は純粋な空母航空一回勝負ではなく、基地航空、潜水艦、給油群攻撃、高速戦艦/重巡前衛、水雷戦、大和型主力打撃を時間差で重ね、米艦隊の航空優勢を「上陸船団を守りながら一日中どこへでも使える」状態から崩すことである。

- 雲龍・天城をMarianas後の8～9月に何時点で実戦空母へ昇格できるか。
