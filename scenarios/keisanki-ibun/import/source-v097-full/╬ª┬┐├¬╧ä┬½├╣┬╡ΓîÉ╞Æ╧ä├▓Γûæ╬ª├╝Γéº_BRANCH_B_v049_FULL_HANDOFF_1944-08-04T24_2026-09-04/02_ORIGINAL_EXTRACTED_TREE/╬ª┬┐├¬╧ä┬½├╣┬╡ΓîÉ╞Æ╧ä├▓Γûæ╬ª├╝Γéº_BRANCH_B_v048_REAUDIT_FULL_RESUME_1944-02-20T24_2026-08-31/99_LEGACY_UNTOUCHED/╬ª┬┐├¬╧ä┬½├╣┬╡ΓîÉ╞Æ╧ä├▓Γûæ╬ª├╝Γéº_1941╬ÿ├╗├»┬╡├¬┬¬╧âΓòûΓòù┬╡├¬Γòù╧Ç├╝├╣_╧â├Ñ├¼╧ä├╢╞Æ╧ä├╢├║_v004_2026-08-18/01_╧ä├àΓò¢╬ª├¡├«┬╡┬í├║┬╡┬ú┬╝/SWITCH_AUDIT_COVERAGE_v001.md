# 後続スイッチ監査カバレッジ v0.01

## 0. 結論

後続文書の「後からONになったもの」を洗う際、単純な制度名検索では四種類が混ざる。

1. **METHOD**：後から発見した評価規約。開戦まで遡及。
2. **HARD_CLOCK**：戦前研究・試験・工業工程から来る技術時計。基本保持。
3. **SOFT/POLICY**：実戦観測・需要・余力で開始日が変わる。日付を解除。
4. **HISTORICAL_OUTPUT**：旧戦史枝の戦果・再配置・建造結論。全面的に再計算。

raw candidate scan は後続ハンドオフ群から213行を抽出したが、その多くは4の旧結果であり、全部を「switch」として登録すると二重管理になる。

- 艦隊/航空隊/潜水艦の戦域再配置

- 修理時計

## 3. 旧枝から必ず解除するもの

- MO/MI/AL/FSの勝敗・損耗
- Guadalcanal/Rabaul型消耗戦の有無
- 1942夏以後の再編余裕
- 空地分離成熟日
- 練度平準化成熟日
- 雲龍/改装空母/信濃/千歳千代田/伊勢日向/伊吹の最終判断
- 松型等の量産要求時期
- 潜高第三ロット
- 1943以後の潜水艦戦域配当
- ASW全国統合時期
- 1943～44の戦域別投入数
- 欧州波及量

これらは後続資料を削除せず、「旧比較枝 / decision candidate」として参照する。

## 4. 保持する設計学習

水上艦監査94で確定した

`設計予測 → 公試実測 → 残差分類 → 次艦・改装へ戻す`

は戦史結果ではなく、1934年以後の設計プロセスとして保持する。

同様に、61の

`技術利得 → 実装 → 配備 → 部隊使用 → 敵適応 → 戦果`

と、人員循環・組織撹拌の評価規約も保持する。

今回の巻き戻しで消すのは「後続でそうなった理由のない固定日付」であって、既に確立した因果モデルではない。
