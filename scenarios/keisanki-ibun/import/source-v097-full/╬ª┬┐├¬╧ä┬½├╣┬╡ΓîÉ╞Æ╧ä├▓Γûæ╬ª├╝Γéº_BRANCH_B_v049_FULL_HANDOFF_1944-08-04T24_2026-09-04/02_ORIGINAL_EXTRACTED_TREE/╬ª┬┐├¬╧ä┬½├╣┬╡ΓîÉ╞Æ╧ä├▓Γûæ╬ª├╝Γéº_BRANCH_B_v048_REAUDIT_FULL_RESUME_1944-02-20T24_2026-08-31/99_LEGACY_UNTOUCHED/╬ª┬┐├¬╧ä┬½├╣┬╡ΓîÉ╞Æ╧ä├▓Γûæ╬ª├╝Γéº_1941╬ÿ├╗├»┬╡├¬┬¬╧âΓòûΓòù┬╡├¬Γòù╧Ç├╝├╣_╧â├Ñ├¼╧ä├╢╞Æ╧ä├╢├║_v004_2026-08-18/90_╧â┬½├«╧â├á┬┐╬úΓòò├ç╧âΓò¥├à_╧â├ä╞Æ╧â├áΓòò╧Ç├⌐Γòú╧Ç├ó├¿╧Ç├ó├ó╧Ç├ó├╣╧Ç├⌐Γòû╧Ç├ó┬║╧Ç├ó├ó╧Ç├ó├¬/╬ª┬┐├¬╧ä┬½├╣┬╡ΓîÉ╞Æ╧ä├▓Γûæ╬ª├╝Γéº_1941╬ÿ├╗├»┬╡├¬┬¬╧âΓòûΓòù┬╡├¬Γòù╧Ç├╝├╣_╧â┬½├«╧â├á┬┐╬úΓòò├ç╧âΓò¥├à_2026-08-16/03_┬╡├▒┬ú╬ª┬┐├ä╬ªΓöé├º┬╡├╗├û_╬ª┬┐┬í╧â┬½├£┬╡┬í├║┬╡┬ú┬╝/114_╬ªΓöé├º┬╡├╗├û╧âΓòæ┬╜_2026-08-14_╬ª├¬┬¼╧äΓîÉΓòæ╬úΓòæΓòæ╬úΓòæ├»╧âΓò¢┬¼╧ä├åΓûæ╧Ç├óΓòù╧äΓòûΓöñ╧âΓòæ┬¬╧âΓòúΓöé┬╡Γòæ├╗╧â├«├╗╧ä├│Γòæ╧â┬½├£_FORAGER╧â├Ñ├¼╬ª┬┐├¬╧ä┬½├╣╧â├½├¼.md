# 現在地

1944年7月7日夜。r24のFORAGER戦果は比較枝。r25で戦術研鑽、r26で空地分離・敵防空対抗研究を追加し、r27でさらに**熟練搭乗員・整備員の自然還流、人員撹拌、練度平準化**の未反映を修正した。

# r27で確定した因果

1. 1942年夏から一律の「精鋭を教官へ戻す」政策を発明したとは扱わない。
2. MI戦傷・療養、母艦修理、航空隊再編、補充機受領、新編隊・新造空母への配員により、経験者の自然還流が先に発生する。
3. 史実ではMI後、療養・第三艦隊再訓練へ大きな人員移動があり、本来約2か月の再編期間がGuadalcanalで中断された。本世界ではこの時間を確保しやすい。
4. 史実では1944年夏まで戦術部隊搭乗員が内地へ戻って補充機を空輸しており、人員往復自体は存在した。本世界では1943年後半から専任空輸を試行し、1944年初頭～春に機能上標準化する。
5. 空地分離は飛行隊を可搬化するだけでなく、自然還流した人員を別部隊へ配り直す基盤となる。
6. 1943年以後、複数隊統合の成否が「一隊だけ極端に弱い」ことへ強く依存すると分かり、第一線精鋭を残しつつ新編/第二線隊へ最低限の経験核を置く**練度平準化**が人事目標になる。
7. 平準化は平均技能を大幅に上げるのではなく、低練度尾部、手順差、艦上資格ミスマッチを削る。
8. 艦上資格、夜間、航法、編隊指揮、無線、雷爆、整備を別資格として管理する。陸上で使えるが母艦では不足する搭乗員を無理に空母へ載せない。
9. 純教育目的だけで第一線から同時に外す熟練者は1943年以後3～7%級の感度帯。これとは別に自然還流者が戦訓を運ぶ。
10. FORAGERでは46の効果を命中率へ直接加算せず、攻撃セルの集合・航法・通信・任務継続失敗率、別母艦/基地へ移した際の再資格遅延へ入れる。

# 時間線

- 1942年6～9月：自然還流・戦訓集積。
- 1942年10～12月：複数隊比較で練度分散を認識。
- 1943年前半：新編隊へ経験核を配置、空地分離局地試行と接続。
- 1943年後半：練度平準化を意図的な人事目標へ。専任空輸分遣隊も試行。
- 1944年初頭～春：空地分離・資格管理・人員循環・空輸専任化を主要航空戦力で制度整理。

# FORAGER再計算への追加入力

- 7月7日時点の各航空隊を「平均練度」だけでなく、艦上資格、夜間、航法、編隊長、無線、整備経験核で分ける。
- Marianas/Yap/Palau/Philippinesの航空隊を、基地固有隊ではなく方面内可搬戦力として再配置する。
- 7月8～10日の米空襲後、基地損傷で機体が飛べても組織が拘束される率を45＋46で再計算する。
- 7月11日攻撃では、各攻撃セルの「出撃したが集合/航法/通信で任務を失う」確率を史実Marianas型より下げる。
- 損傷空母発生時、航空隊を健在空母・陸上基地へ資格別に再配分する。
- 44/45/46を同じ命中率へ三重に掛けない。

# 次作業

1944年7月7日夜からFORAGER航空戦を再開する前に、各航空群の**練度分布・資格分布・経験核**を作業台帳化する。その後、7月8～10日の基地航空保存・再配置、7月11日の分散セル型攻撃を順に回す。
