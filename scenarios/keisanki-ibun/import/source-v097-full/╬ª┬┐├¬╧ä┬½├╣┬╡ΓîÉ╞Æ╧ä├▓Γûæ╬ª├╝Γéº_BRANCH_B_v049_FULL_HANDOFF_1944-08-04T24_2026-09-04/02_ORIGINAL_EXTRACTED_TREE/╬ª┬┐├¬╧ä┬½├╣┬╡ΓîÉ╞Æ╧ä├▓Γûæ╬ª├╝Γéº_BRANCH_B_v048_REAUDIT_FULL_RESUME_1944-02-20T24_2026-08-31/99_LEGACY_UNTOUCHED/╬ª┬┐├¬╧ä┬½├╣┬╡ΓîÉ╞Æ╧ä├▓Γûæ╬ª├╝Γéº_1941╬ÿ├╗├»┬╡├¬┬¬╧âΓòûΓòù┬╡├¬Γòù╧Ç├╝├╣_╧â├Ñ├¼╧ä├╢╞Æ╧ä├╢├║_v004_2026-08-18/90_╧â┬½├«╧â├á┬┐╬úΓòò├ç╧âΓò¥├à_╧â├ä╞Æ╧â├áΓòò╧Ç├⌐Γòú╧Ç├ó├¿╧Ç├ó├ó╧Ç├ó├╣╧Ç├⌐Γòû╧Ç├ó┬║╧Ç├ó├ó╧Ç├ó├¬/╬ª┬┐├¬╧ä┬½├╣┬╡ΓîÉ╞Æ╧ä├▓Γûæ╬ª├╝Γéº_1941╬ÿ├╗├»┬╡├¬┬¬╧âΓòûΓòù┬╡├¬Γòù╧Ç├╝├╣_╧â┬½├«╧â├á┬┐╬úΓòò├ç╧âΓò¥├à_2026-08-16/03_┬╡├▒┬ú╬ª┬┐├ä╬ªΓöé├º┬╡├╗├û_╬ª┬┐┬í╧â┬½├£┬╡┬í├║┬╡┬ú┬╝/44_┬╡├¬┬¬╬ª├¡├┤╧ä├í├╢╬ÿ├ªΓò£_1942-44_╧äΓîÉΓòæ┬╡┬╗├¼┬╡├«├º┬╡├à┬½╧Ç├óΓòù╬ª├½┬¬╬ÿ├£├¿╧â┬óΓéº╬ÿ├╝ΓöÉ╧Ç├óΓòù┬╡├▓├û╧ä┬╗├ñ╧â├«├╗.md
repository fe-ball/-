# 1. 監査理由

従来正本は、計算援用による射撃、索敵、I/O、損害制御、魚雷、Availabilityの改善を個別に扱っていた。一方、歴史側ではそれらの改善を主に「同じ戦術を少し上手く行う」ものとして扱い、**生残空母・生残指揮官・生残航空隊・長い訓練時間そのものが戦術研究の母集団を増やす効果**を十分に伝播させていなかった。

本世界では、1942年MI後も飛龍が生還し、翔鶴・瑞鶴その他の空母、航空隊、甲板要員、整備員、司令部要員が史実より多く残る。さらにGuadalcanal/Rabaul型の緊急投入・逐次摩耗が小さいため、史実で開始されながら中断された再編・再訓練を継続できる。

この効果は計算機が「正解戦術を教える」のではない。当時の部隊が、演習・実戦・兵棋・射撃/飛行記録から差を観測し、計算機が多数の条件を比較・集計することで、**経験則を再現可能な手順へ変える速度が上がる**と扱う。

# 2. 史実基準

戦後聴取では、日本側はMidway後に攻撃偏重を反省し索敵訓練を増やし、空母を中核とする複合艦隊へ再編しようとした。しかしGuadalcanalにより、第三艦隊が必要と見積もった再編期間を完了する前に熟練航空隊を南方へ投入した、と証言している。

また1944年の日本空母航空については、訓練時間不足、熟練者を前線で使い切り訓練核を残さないこと、燃料・教官・整備員不足が質低下の主因として挙げられている。

Cape Engaño後の松田千秋聴取では、空襲時に先導艦の変針へ全艦が同時追随する原則があった一方、巡洋艦・駆逐艦が独断散開して混乱する欠点が記録されている。これは「回避能力が存在しない」のではなく、**個艦能力を艦隊標準へ揃える組織学習が未完成**だったことを示す。

なお、1944年10月の史実事例を1944年7月へ未来知識として持ち込まない。同事例は、当時の船体・操艦・指揮技術で成立し得た能力の存在証拠としてのみ使う。

# 3. 本世界で増える学習資源

## 3.1 人的資本

- 飛龍生還に伴い、第二航空戦隊司令部・飛行甲板・航空隊・整備系統の経験が大きく残る。
- 山口多聞は飛龍喪失と運命を共にする史実条件が消えるため、生存中心とする。以後の人事は固定しないが、空母運用研究に使える上級実戦指揮官が一名増える。
- 翔鶴・瑞鶴、龍驤、祥鳳等の生残により、艦長、飛行長、整備長、甲板作業長、航空隊幹部の実艦経験母集団が大きい。
- 小沢治三郎、原忠一等、史実でも空母運用経験を持つ指揮官と並行して複数系統の戦術案を比較できる。

## 3.2 艦艇資本

空母が多いこと自体が研究設備になる。

- 2艦、3艦、4艦以上の分散/集中隊形比較。
- CAP発艦と攻撃隊発艦を競合させた甲板サイクル試験。
- 戦艦・巡洋艦を近接直衛へ置く/外周へ置く比較。
- 故障艦を含むformation keeping。
- 複数空母間の収容・緊急着艦・予備航空機移送。

伊勢・日向は航空戦艦化されず、1943～44年に第二線戦艦・電探/射撃試験艦・艦隊演習艦として使える。したがって大型艦の回避、対空射撃中の変針、隊形維持、通信手順を反復試験する母艦となり得る。

## 3.3 時間・燃料

Guadalcanal/Rabaul型の緊急逐次投入が小さいため、1942年夏秋に最低8～12週間級のまとまった再編・演習期間を確保しやすい。燃料制約は残るため米海軍型の大量飛行訓練へは到達しないが、史実1943～44より訓練を前倒し・集中できる。

# 4. 1942～44年の戦術成熟

## 4.1 1942年6～10月――戦訓回収期

優先課題：

1. 索敵扇形の重複と未捜索域を定量化。
2. 全力攻撃と予備攻撃隊の比較。
3. CAPを一括待機せず、時刻・高度別に回す。
4. 発艦・収容中の燃料/爆装機露出時間を短縮。
5. 空母と高速戦艦・巡洋艦の距離を変えた防空/砲戦支援。
6. 艦隊回避時の同時変針と緊急散開の境界条件。

この段階では教範完成ではなく、実戦経験者の戦訓会・兵棋・反復演習が中心。

## 4.2 1942年末～1943年――標準化期

演習結果を「名人芸」から手順へ移す。

- 索敵：単一線ではなく重複・再捜索・帰投余裕込みの確率表。
- CAP：高度層、滞空交代、緊急発進、帰投機収容の時間割。
- 対艦攻撃：艦爆・艦攻・護衛戦闘機の到着時刻差を縮める発進順。
- 甲板：燃料・爆装・待機機を同時に最大化しない危険状態管理。
- 艦隊回避：攻撃軸別の同時変針、散開許可条件、再集合方位を事前化。
- 水上戦：第二魚雷斉射、複数駆逐隊の時間差投入、戦艦/重巡の追撃射撃を統合。

## 4.3 1943年末～1944年――情報統合期

30の電探/I-O改善と結合する。

- レーダー警戒→見張り確認→CAP指示を短縮。
- 敵方位・高度・速度の不確実幅を明示し、CAPを一点へ過集中させない。
- 回避操艦と高角砲射界の競合を艦種別に整理。
- 空母が急変針した際の直衛艦追随を「全艦同時追随」「局地独立回避」「緊急散開」の三モードへ分ける。
- 損傷空母の航空機を他艦へ収容する際の甲板余裕・燃料・護衛を事前表化。

# 5. 作業用効果量

以下は固定倍率ではなく、該当任務だけへ使う感度帯。

| 項目 | 1943以後の作業値 |
|---|---:|
| 指定索敵域の見落とし率 | 相対20～35%低下 |
| 発艦/収容/再武装サイクルの時間ばらつき | 15～25%縮小 |
| 複数空母攻撃隊の目標到着時刻分散 | 20～30%縮小 |
| CAPが敵主攻へ会敵できる確率 | 相対10～20%向上 |
| 計画された艦隊同時変針の隊形崩れ | 相対30～50%低下 |
| 通常の単軸航空攻撃に対する被命中確率 | 相対10～18%低下感度 |
| 多方向飽和攻撃時の被命中確率 | 相対5～10%低下感度 |

被命中率低下は装甲・対空火力倍率ではない。変針開始時刻、攻撃解の崩し、隣接艦との衝突回避、速度保持の改善である。激しい多軸攻撃、操舵損傷、低速艦、狭水道では効果を縮小する。

# 6. 搭乗員育成・人員循環への波及

史実の「熟練者を前線に置いたまま消耗し、訓練核が枯れる」をそのまま継承しない。ただし、1942年夏から一律の教官ローテーションを発明したとも扱わない。

本世界では、戦傷・療養、母艦修理、航空隊再編、補充機受領、新造/修理空母への配員によって、経験者の**自然還流**がまず発生する。Guadalcanal/Rabaul型の決死的逐次投入が弱いため、その還流者が次任地へ到達する比率が高い。空地分離・母艦航空隊可搬化が進むと、この自然還流が部隊間の人員撹拌へつながる。

1943年以後、部隊間の練度ばらつきが多部隊協同作戦を壊すことがデータで見えるようになってから、意図的な短期教官・新編隊幹部・試験勤務を追加する。詳細な発生機序、練度平準化、空輸専任化は `46_航空人事_1942-44_自然還流・空地分離・練度平準化.md` を正本とする。

その結果、1944年7月の空母航空隊は1941年の第一航空艦隊級ではないが、史実Marianasの「訓練時間不足・海上経験不足」より明確に上。最大差は平均技能の超人的上昇ではなく、**極端に未熟な隊の減少、艦上資格の選別、複数隊混成時の互換性向上**に置く。機体性能差、F6F、米レーダーfighter direction、VT信管、大量の訓練飛行という米側優位は残る。

# 7. 戦史への遡及影響

## Efate～Marshall

既存結果は方向として維持するが、日本損失側を数%～一割程度再点検する。特に、空襲回避・CAP交代・夜戦編隊保持へ軽微な補正が必要。

## Truk/Palau

「危険を早く認識して逃がす」という既存結果と整合し、中心結論は維持しやすい。退避船団の隊形・対空回避・護衛交代で局地損失は再点検する。

## FORAGER

影響が大きい。43の7月8～15日結果は本監査前のため**暫定枝へ降格**する。

再計算項目：

1. 7月8～9日基地航空保存率。
2. 7月11日日本統合航空攻撃の到着分散・護衛・第二波保持。
3. 米CAPとの会敵高度/時刻。
4. 7月12日米反撃時の日本艦隊回避と対空隊形。
5. 飛鷹沈没・隼鷹大破の確率再評価。
6. 12～13日夜高速水上前衛の隊形保持・第二魚雷射撃。
7. 以上を受けたSaipan D-Day。

# 8. 二重計上禁止

- 損害制御改善は既存30/62/43の大鳳処理と重複させない。
- 航空雷撃・爆撃命中率の技術改善は50/52側と重複させない。
- 電探探知距離そのものは30側。ここでは情報を戦術へ変える手順だけを扱う。
- 「指揮官が生きているから常に正しい判断をする」としない。案の比較、演習回数、失敗からの学習率だけを上げる。

# 9. 史実参照

- USSBS Interrogation NAV No.64 / Rear Admiral Takata Toshitane: Midway後の空母中心再編、索敵訓練強化、Guadalcanalによる再編期間不足、Marianas時の訓練不足。
- USSBS Interrogation NAV No.69 / Rear Admiral Matsuda Chiaki: Cape Engaño、空襲下の艦隊変針教義、独断散開による混乱、熟練核・教官・燃料・整備員不足。
- NHHC, "Midway: Sheer Luck or Better Doctrine?": 日本海軍の多空母協同攻撃教義、空母脆弱性、山口多聞による戦艦の空母直接支援提案。


# 10. 2026年8月14日追加――空地分離・攻防対抗研究との接続

航空戦術の成熟は、同じ部隊を同じ基地・同じ母艦へ固定したままでは戦域全体へ伝播しにくい。航空隊の機動運用制度、母艦間再配分、基地側支援の標準化は `45_航空運用制度_1942-44_空地分離・攻防火器管制破綻研究.md` を正本とする。

また、敵防空を単に「強い対空火力」として扱わず、早期探知、fighter direction、CAP、外周護衛、個艦火器管制、回避操艦の連鎖として分解し、その一部を短時間だけ過負荷へ追い込む研究も45へ置く。44の到着時刻分散縮小、CAP・艦隊回避の効果量と二重計上しない。

FORAGERでは、44が**戦術を再現可能にする組織学習**、45が**その戦術を戦域間で可搬化し、敵防空システムへ対抗設計する制度**を担当する。
