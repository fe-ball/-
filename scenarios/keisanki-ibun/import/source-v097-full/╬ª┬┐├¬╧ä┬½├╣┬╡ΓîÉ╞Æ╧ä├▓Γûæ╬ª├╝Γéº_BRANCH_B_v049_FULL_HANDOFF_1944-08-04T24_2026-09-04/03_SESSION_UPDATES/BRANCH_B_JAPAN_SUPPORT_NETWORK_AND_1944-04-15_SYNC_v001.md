# 1. Support-network rule

A place contributes only if all relevant gates pass:

1. physical facility exists;
2. Branch has delivered fuel/material/maintenance support;
3. aircraft/unit/hull is actually present or can transfer on a dated clock;
4. range permits the requested mission;
5. return/recovery or next-stage field exists;
6. communications can convert the sortie into useful support.

Therefore:
- an airfield is not a free squadron;
- ferry range is not combat radius;
- a seaplane base is not a fighter base;
- a large anchorage is not a useful fleet base if it cannot be defended or supplied;
- a remote Japanese-held base can matter strategically while contributing **zero** same-day aircraft.

# 10. Shipping policy after the Palau raid

Historical Japanese shipping had to abandon or redirect several direct routes because of carrier/submarine pressure and escort shortage.

Branch escort/ASW depth is healthier.

Therefore Branch does **not** automatically abandon:
- Japan/Marianas;
- Formosa/Philippines/Palau;
- Davao/Palau;
- Palau/Marianas.

But it does change their use:

1. no large high-value ship waits at Palau;
2. direct Japan→Palau used selectively;
3. Formosa/Philippines staging preferred when threat is high;
4. Saipan/Guam northern feeder remains the main heavy-reinforcement lane;
5. Palau→Truk traffic is deprioritized because Truk is no longer fleet hub;
6. convoy arrival windows are synchronized with carrier-threat information.

This is paid with longer transit and port handling, not free survivability.
