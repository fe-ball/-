- It became part of the Americal Division defensive system.
- Contemporary U.S. light-tank battalions in the same period used a **54-M3-light-tank** order of magnitude.

## 4. Counterattack-clock correction

Because St. Vincent overlaps the Japanese chosen Boulouparis/Baie de Saint-Vincent main operational sector, v087's old generic “Tontouta-origin” center is too slow as the most dangerous case.

For the Japanese main axis, authorization must survive:
- landing confirmation to first U.S. movement order: **~20–50 min**
- St. Vincent assembly / road deployment: **~30–70 min**
- local movement into Boulouparis-area counterattack geometry: **~30–70 min**, highly beach-lane dependent

Therefore:
- **first useful armored packet can threaten the lodgment roughly H+1.5 to H+3.5**
- **center planning danger point: ~H+2.5**
- a larger 20–30 tank packet becomes plausible around **H+3 to H+5** if Japanese air/naval interdiction does not break the road movement

This supersedes only the slower generic Boulouparis M3 center where St. Vincent location was not yet known.

1. Japanese H+2/3 organic AT/mines/signals requirement becomes a **hard authorization gate**, not a desirable target.
2. First 75-mm/direct-fire guns should be combat-usable by **~H+3/4 center**, not merely H+4–6 if hydrography permits.
