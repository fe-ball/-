相当10％の命中率が20％改善する場合、12％になるという意味である。

ただし航空雷撃・対運動艦急降下爆撃は、戦史上「ほんの少し多く当たる」とだけ処理しない。艦艇には航空運用停止、速力低下、沈没・修理期間等の閾値があり、相対10～25％の命中改善が必要攻撃隊単位を縮小し、目標分割や第二波保持を変える場合がある。戦術・作戦への自然な派生は61、魚雷本体・投下／走行の体系は31を参照する。

艦砲は `30_センサー射撃指揮_I-O連鎖.md` を優先する。高角砲・高射砲、陸軍砲兵は個別体系監査が未了であり、航空側の波及割合から最終命中率を代入しない。

| 兵器・射法 | 技術的散布・誤差の改善 | 実戦効果の中心推定 |
|---|---:|---:|
| 戦闘機固定銃・対戦闘機 | 15～30％ | 命中率10～25％相対向上 |
| 固定銃・対爆撃機／地上目標 | 20～40％ | 命中率20～40％相対向上 |
| 爆撃機旋回銃 | 10～25％ | 命中率5～15％相対向上 |
| 水平爆撃・点目標 | 15～30％ | 命中率15～35％相対向上 |
| 水平爆撃・面目標 | 10～20％ | 命中率5～20％相対向上 |
| 急降下爆撃・固定目標 | 15～25％ | 命中率15～30％相対向上 |
| 急降下爆撃・運動中艦船 | 10～20％ | 命中率10～25％相対向上 |
| 航空雷撃 | 15～30％ | 命中率10～25％相対向上 |
| 艦砲・通常昼間水上射撃 | 初期諸元系統誤差10～15％低減 | 総合命中率2～5％相対向上、初回夾叉まで5～10％短縮 |
| 艦砲・長射程／非標準気象 | 初期諸元系統誤差20～30％低減 | 初回夾叉可能性8～15％向上、射撃解収束10～20％短縮 |
| 高角砲・高射砲 | 個別監査未了 | 最終命中率を未固定 |
| 陸軍砲兵 | 個別監査未了 | 最終命中率を未固定 |
| 小銃・軽機関銃 | 5～15％ | 命中率0～10％相対向上 |

小銃や高速空戦では人間と戦場条件の比率が大きい。艦砲では光学・弾道補正の技術誤差が減っても、目標運動、波浪、観測、斉射散布、指揮手順が残るため、通常条件の総合命中率を20～40％向上と一般化しない。

## 3.7 波及速度の注意

航空で成果が出た翌日に、すべての艦砲・魚雷・陸上砲が改善されるわけではない。

- 同じ会社・工廠の内部なら比較的速い。
- 共通の発注仕様・試験規格へ入るには年度単位を要する。
- 既存装備の改修は重量、場所、予算、入渠・修理時期に縛られる。
- 学校・部隊の射法変更には教材、訓練、弾薬を要する。
- 組織間の秘匿・管轄争いで遅れる。

したがって他分野の正本では、航空側の効果を即時・一律の係数として加算せず、個別の接続経路と実装時期を設定する。

# 6. 次世代艦上攻撃機

## 6.1 十三試艦爆D4Y

### 開発原則

- 小さな正面面積。
- 細い胴体。
- 燃料噴射。
- 急降下時の燃料供給。

## 6.2 十四試艦攻B6N

### 護一一型の扱い――監査後中心線

史実の結果を知って最初から火星へ切り替えない。中島と海軍は、護一一型の燃費、出力、発展性、火星需要との競合を実測で評価する。

本世界では、

- 栄の海軍大量需要が小さい。
- 中島の試験・量産余力が史実より増える。
- クランク・プロペラ・機体振動を測定結果から分離しやすい。
- 火星はG4M、H8K、雷電と競合し、B6Nへ回す機会費用が大きい。

ため、護を初期主力として継続する合理性が史実より強い。

一方、護専用工具・部品・教程を維持する固定費があるため、少数生産で終わるなら火星統一の方が合理的である。B6Nを数百機級の主力艦攻として使う場合にのみ、護系列を独立維持する利益が大きくなる。

### 1943年初頭の採用ゲート

護継続は成功確定ではなく、次の実測で判定する。

- 200時間級耐久試験を複数基が完走する。
- 50機級初期部隊で異常振動・過熱による重大故障が収束傾向を示す。
- 予定外発動機交換率が火星比較群の1.2～1.3倍以内へ収束する。
- 工場不合格率が量産拡大に伴って下降する。
- 同一重量・高度・巡航速度で火星より明確な燃費優位が確認される。

予定外交換率が火星の1.5倍以上で改善傾向がない、または軸受・熱処理・クランク寿命が量産公差で収束しない場合は、火星換装へ移る。この数値閾値は本世界の採用判断用作業値であり史実統計ではない。

| 部隊中央値 | **472～480km/h** |
| 5,000m上昇 | **10分00秒～10分35秒** |
| 魚雷任務半径 | **650～750km中心** |
| 良条件・短時間交戦 | **750～800km級** |
| 最大航続 | **3,200～3,450km級** |
| 良好試験状態 | 3,500km前後も可 |
| 兵装 | 800kg魚雷または爆弾 |

護成熟の利得は最高速度への一律加算ではなく、同程度の速度で燃料を節約し、火星をG4M/H8K/雷電へ回し、量産中央値と任務中止率を改善するところへ置く。

### 火星換装枝

火星B6Nは廃案にしない。発動機架、カウリング、冷却、プロペラの比較試作・設計図を保険枝として維持し、護が耐久ゲートを落とした場合に数か月級で移行できるようにする。

中心線は、

- **B6N護型：主線。**
- **B6N火星型：量産保険枝。**
- **1943年初頭に実測判定。**

とする。

### 艦上適合

進入速度137～148km/h級は中心作業値として維持する。ただし通常全備約5.2t、最大離陸約5.6tのため、一般的な5t級昇降機を「魚雷・満燃料の完成状態」で使う前提にしない。

格納庫・昇降機移動時は、

- 魚雷なし、
- 燃料一部、
- 必要に応じ弾薬一部、

として5t未満へ落とし、甲板上で魚雷・燃料を完成させる。大型正規空母では成立するが、B5Nや戦闘機より甲板サイクルを圧迫する。

魚雷満載時の大型空母甲板滑走は135～180m級の作業推定を維持する。

### 雷撃包絡線

| 項目 | 中心値 |
|---|---:|
| 通常投下速度 | 280～320km/h |
| 高速投下 | 330～350km/h級 |
| 投下高度 | 20～45m |
| 投下距離 | 900～1,600m級 |

最高速度と魚雷投下速度を混同しない。高速雷撃は魚雷本体の入水・姿勢・深度・強度と一体で監査し、機体最高速から自動的に許容しない。

### 防護

初期設計から、背面防弾、防火隔壁、遮断、消火、主燃料槽の部分防漏、左右燃料系分離、浮力装置を検討する。追加90～140kg級。全面自己防漏ではない。

### 日程

| 段階 | 中心線 |
|---|---|
| 十四試要求 | 1939年末 |
| 試作一号機 | 1941年2～4月 |
| 振動・冷却・トルク試験 | 1941年 |
| 増加試作・艦上試験 | 1942年前半 |
| 先行量産 | 1942年夏 |
| 初期部隊 | 1942年末～43年初 |
| **護継続／火星判定** | **1943年初頭** |

1941年末の実戦配備には間に合わない。1943年初頭の採用判定後も、予備発動機、工具、整備教程、量産合格率が揃うまでを別時計として扱う。

### 確度上の注意

護の1,870hp級、火星との近い性能帯、護の燃費優位という方向は史実側資料と整合するが、護一一型の詳細な一次燃費曲線・耐久統計は未確保である。したがって航続・交換率閾値は本世界の監査作業値として保持し、後日の一次資料取得時に更新し得る。

# 8. 大型飛行艇系列

## 8.1 九七式大艇H6K

### 位置づけ

日本海軍が四発・長距離・単葉飛行艇を実用化する最初の本格的成功作。

- 高アスペクト比主翼。
- パラソル配置。
- 飛沫から離した発動機。
- 大量燃料。
- 四発長時間運転。
- 洋上航法・通信。

を成立させる。

計算機があっても、最初から片持ち肩翼H8K型へ飛躍しない。H6Kで水槽・艇体・飛沫・長距離運用の係数を取得する。

### H6K5後期標準・高確度暫定値

| 項目 | 中心推定 |
|---|---:|
| 偵察全備 | 約17.5t |
| 発動機 | 金星五一型級×4 |
| 最大速度 | **392～398km/h** |
| 部隊中央値 | 385～394km/h |
| 5,000m上昇 | **10分15秒～10分40秒** |

主効果は、四発出力差、燃料使用順序、離水重量表、支柱・艇体疲労点検、発動機交替運転、量産トリム差の改善。

1941年には旧式化が始まり、後に輸送・訓練・後方哨戒へ比重を移す。

## 8.2 九九式飛行艇H5Y

双発中型飛行艇として、安価な沿岸哨戒・訓練・救難を狙う。計算不足だけでなく、出力、搭載量、航続、H6Kとの競合が限界。

未来知識で試作を消さず、H6Kとの比較後に用途を限定する。

- 沿岸哨戒。
- 飛行艇訓練。
- 通信・連絡。
- 救難。
- 二線輸送。

生産15～25機級の中心線。

## 8.3 十三試大艇H8K

### 要求

H6Kの実運用から、

- 大幅な高速化。
- 7,000km級航続。
- 2t級兵装・魚雷二本。
- 強防御火力。
- 防漏燃料槽・局部装甲。
- 外洋離着水。
- 長時間哨戒。
- 三発飛行能力。

が要求される。

後世の評価を知って「傑作機」を作るのではない。H6Kの速度、防御、火災、飛沫、離水、疲労、燃料移送の不足へ対応した結果である。

### 計算援用の中心

#### 艇体・離水

水槽試験の速度、トリム、浸水面積、抵抗、ステップ、重心、波高、飛沫を係数化する。第一試作機にも艇首上下動、片側飛沫、重心別滑走姿勢などの問題は残るが、原因を艇首、チャイン、ステップ、飛沫抑制、昇降舵操作へ分解し、3～5か月級で改修へ戻す。

#### 巨大主翼

空虚、偵察、満燃料、魚雷、外側一発停止、燃料不均衡、荒い着水を別荷重状態として処理する。空中荷重だけでなく、艇体から翼へ入る水面衝撃を扱う。

#### 四発振動

四基の回転数差によるうなり、主翼曲げ、ナセル、配管、計器、照準器、無線、乗員疲労を処理する。禁止回転域、巡航回転数、同期許容差、一発停止時の安全速度を運用表にする。

#### 燃料・防護

防漏槽、区画化、逆止弁、遮断、消火、発動機防火、局部装甲、燃料・電路・弾薬分離を採る。大型四発機であるため、一式陸攻より防護重量を受容しやすい。

# 10. 発動機・生産・補給の横断論点

## 10.1 瑞星系列

零戦とB5Nの共通化により、

- 工具、予備部品、点火、気化器、ポンプ。
- カウリング、冷却、排気。
- 発動機ロット試験。
- 空母整備員教育。

を共有できる。

一方、零戦、艦攻、司偵、複戦などと生産競合する。技術データ共有と発動機現物供給を二重計上しない。

## 10.2 金星系列

D3A、B5M、G3M、H6Kなどに広く使われる。多機種の試験値が冷却・プロペラ・排気へ戻る一方、量産・予備品・整備系統の負担も大きい。

## 10.3 火星系列

G4M、H8K、将来の雷電・他機種で競合する。H8Kは一機で四基を使用し、発動機予備率も高く必要。H8K生産数を機体工場能力だけで決めてはならない。

## 10.4 護系列

栄大量需要の減少で中島に余力が生じるが、陸軍ハ25／115、ハ109、Ki-49等と競合する。B6N護型の成否は、計算能力だけでなく軸受、熱処理、加工、不合格率、予備部品に依存する。

## 10.5 アツタ系列

陸軍ハ40とのデータ共有は可能だが、海軍側の工場・補機・規格・部品は別。D4Yの実用化は発動機合格数と急降下構造の二重律速になる。

## 10.6 生産数の注意

# 13. 設定上の注意・撤回すべき話法

## 13.1 転生者的な説明を禁止する

- 「史実で燃えるので最初から完全防漏にした」。
- 「護は失敗するので火星にした」。
- 「アツタは問題が出るので空冷にした」。
- 「D4Yは高速なので偵察機に回した」。
- 「H8Kは傑作になるよう設計した」。

という説明は不適切。

正しくは、当時の要求、試験、損害、量産統計によって判断が発生する。

## 13.2 「計算機が設計した」を避ける

計算機は設計者ではない。技術者が案を作り、試験を行い、計算機を使って比較・整理する。

## 13.3 「成り行き」を無秩序と誤解しない

外部から逐次介入していないことと、因果がないことは同じではない。

- 利用可能な計算能力。
- 既存の企業・軍組織。
- 発動機系列。
- 戦地損害。
- 工場・資材。
- 技術者の発想。

が相互作用し、歴史が分岐する。これを「成り行き」と表現するときも、各段階の判断材料と主体を記述する。

# 14. 最終要約

海軍航空の主線では、複葉・固定脚のB4YとD1Aが、艦上雷撃・急降下爆撃の運用技術を蓄積し、B5NとD3Aが開戦時の完成された主力になる。

B5Nは、引込脚、折畳翼、三座航法、800kg魚雷を一体化し、本世界では零戦と共通する瑞星一五型を採用する中心線とする。速度は量産標準で391～397km/h級だが、主価値は航続、発艦、航法、兵器投下、整備共通性にある。

D3Aは、引込脚による8～12km/h級の速度利益より、急降下構造、制動板、爆弾架、艦上信頼性を優先して固定脚を維持する。1941年後期標準で394～400km/h級。計算援用は命中率だけでなく、急降下事故と量産機の挙動差を減らす。

次世代のD4YとB6Nは、大型正規空母向けの高速・大出力機となる。D4Yは液冷アツタのまま進み、偵察型が先行する。B6Nは護を実測統計で評価し、成功が保証されるのでも、未来知識で中止されるのでもない。両機とも開戦には間に合わない。

基地航空では、G3Mが成熟した長距離雷撃・爆撃・偵察機として残り、G4Mが速度・航続・火力を引き上げる。一式陸攻は燃料区画、遮断、消火、局部防漏・装甲を持つため史実相当より燃えにくいが、大量翼内燃料を持つ軽構造機という本質は残る。

大型飛行艇では、H6Kが水槽・艇体・長距離四発運用を成立させ、その実測不足からH8Kが生まれる。H8Kの高性能は未来知識による介入ではなく、H6Kの成功と不足、川西の水槽・構造・飛行試験、利用可能な計算能力が結び付いた結果である。

航空研究の横断効果は、すべての兵器を一律に高精度化することではない。光学、振動、弾道、弾薬公差、無線、情報受渡しの技術的誤差を減らし、最良の射手・機体だけでなく部隊中央値を引き上げる。航空雷撃・爆撃の中心推定は本巻に保持するが、艦砲は30を優先し、通常昼間射撃の総合命中率は相対2～5％向上を中心とする。高角砲・高射砲、陸軍砲兵の最終命中率は個別監査まで固定しない。人間、目標運動、天候、敵火力は残る。

そして、これらの変化を起こした外部の手は、彼らの出会いと計算機の発明までである。その後は、未来を知らない当時の人々が、増えた計算能力と現実の試験・損害・資源を使って選択した歴史として記述する。

# 15. E16A瑞雲――1943年秋の先行実戦化

## 15.1 現在の位置づけ

**上書き決定。**

1942年9月FSには瑞雲を数えない。試作・水上・急降下試験を経て、1943年秋に初めて少数が前線へ出始める。1943年秋の瑞雲を「水上爆撃機隊の主力」とは扱わず、**零式水偵より高速・重武装で、必要時に急降下爆撃もできる高級水上偵察機**として扱う。

## 15.2 日程中心線

| 段階 | 中心時期 |
|---|---|
| 試作・水上・急降下試験 | 1942年 |
| 構造・ダイブブレーキ・実用装備の整理 | 1943年1～3月 |
| 量産仕様承認 | 1943年4～5月 |
| 増加試作・先行生産 | 1943年6～8月 |
| 初期量産機引渡 | 1943年9月 |
| 最初の実戦可能分遣 | 1943年10～11月 |
| 1943年末完成 | 25～40機中心 |
| 1943年末第一線 | 15～25機中心 |

前倒しは史実時計から4～5か月級を中心とする。水上試験・急降下試験という物理時計は飛ばさない。

**判断の理由：** 計算援用が効くのはフロート抵抗、重心、急降下荷重、ダイブブレーキ、フラップ、爆装時強度、量産重量の比較反復である。水面試験や実機急降下試験は必要で、試作から即量産へ飛ばさない。

## 15.3 1943年秋の任務

優先順位は次のとおり。

1. 高速索敵・触接。
2. 艦砲射撃観測・基地間連絡。
3. 帰投途上など条件の良い場合の小型艦・舟艇・地上目標への軽爆撃。
4. 低速・単独の敵偵察機を有利な条件で捕捉した場合の攻撃。

F6F等との制空戦、定常CAP、昼間の大編隊艦隊攻撃を主任務にしない。

1943年10月Wakeでは通常0機、存在しても前線試用1～2機級、上振れして2～4機まで。連合軍側の初期認識は「零式水偵より妙に高速で、軽爆撃もできる新型単フロート水偵」程度とする。12月Gilberts/MarshallsではMarshall側に合計6～10機級が分散して索敵に参加し得るが、独立攻撃隊とはしない。

**判断の理由：** 少数機の価値は撃沈数ではなく、旧式水偵より高速な触接機を得て、夜間陸攻・潜水艦・水上部隊へ座標を渡すことにある。少数段階で空戦・爆撃戦果を主価値にすると、機数と教育時計を超過する。
