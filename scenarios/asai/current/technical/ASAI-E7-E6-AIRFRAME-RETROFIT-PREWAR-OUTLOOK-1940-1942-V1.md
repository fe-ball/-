## 1. Why this outlook exists

Do not freeze a future aircraft to the E-generation available when its project began. E-generation is a continuous technology-front coordinate, while production packages, service-equivalent ratings and aircraft installation gates have their own clocks.

The current integrated E7 schedule is already target-closed:

- 1939 — E7 component/rig program;
- 1940 H1 — full compressor and hot-section rigs;
- 1940 H2 — integrated gas-generator demonstrator;
- 1941 H1 — full-core ground development;
- 1941 H2 — ground-qualified development core; inherited aft-fan advanced-ground / limited flight-release candidate;
- 1942 Q1-Q2 — earliest E7-dedicated-aircraft first-flight target.

Therefore, **if the program is not disrupted and a wider Pacific war does not begin materially earlier than the historical late-1941 window, E7 core research is expected to reach ground qualification before that expansion of the war**. This is a research/qualification outlook, not a claim that E7 has entered mass service by then.

The natural bridge is not to wait for a completely new E7 aircraft. It is to fly selected E7 packages in already-mature E6 airframes as soon as the installation and flight-release gates close.

## 2. Capability coordinates used here

The upstream E7 capability envelope is not itself an installed product rating. For aircraft outlook only, use:

- medium pure-J organization design coordinate: ~970 kgf; Asai-direct upper development coordinate ~980-1,000 kgf;
- inherited aft-fan: ~1,100-1,150 kgf;
- front low-BPR/reheat branches remain separate, higher-risk clocks and are **not** assumed for the first service retrofit.

No installed E7 dry mass, diameter, TSFC, altitude map or TBO is yet closed. Every aircraft result below is therefore conditional on package mass/drag not defeating the stated benefit.

## 3. E6 Single -> E7-J retrofit outlook

### 3.1 Baseline

Current E6 Single service center:

- E6-M-J ~850 kgf normal product coordinate;
- ~2.85 t service center;
- wing ~17.5 m2;
- ~750 km/h at 6 km, ~772 km/h at 8 km;
- 6 km climb ~5.6-6.0 min;
- internal mission radius ~400-500 km.

### 3.2 Direct retrofit effect

970-1,000 kgf is +14-18% static thrust over the 850 kgf E6-M-J center. In an unchanged subcritical drag field, cube-root thrust scaling would imply roughly +4.5-5.6% maximum-speed potential. The real aircraft reaches compressibility drag first, so do not multiply current top speed without a cap.

**H->A retrofit planning band, assuming installed mass growth stays within roughly 3% and inlet/CG changes remain local:**

- ~6 km clean maximum: **~785-800 km/h**;
- ~8 km clean maximum: **~800-815 km/h**;
- 6 km climb: **~4.8-5.3 min**;
- existing 400-500 km mission radius should be retainable at equal mission load if E7 cruise TSFC is no worse than the mature E6 service package; exact range waits for installed map.

This is enough to justify a **1941 limited retrofit / conversion-development block** if E7 flight release closes. It is not enough to justify pretending the unchanged straight-wing E6 Single is an 850+ km/h aircraft.

### 3.3 What happens next

For Single, E7 first appears as obvious speed/climb. Once clean speed reaches the ~800 km/h class, the wing/inlet/tail become the limiting system. The rational sequence is:

1. 1940 — E6-M-J serial Single;
2. 1941 H2 earliest conditional — selected E7-J retrofit flight articles / service-development conversion;
3. 1942 — new thin-wing / modest-sweep E7-dedicated fighter if HS/high-speed gates justify it.

Do not enlarge the whole airframe merely to absorb E7 unless installed mass/CG or new mission load actually requires it. The first E7 Single should be a re-engine test because that produces the clearest generation delta at lowest integration cost.

## 4. E6 Twin -> E7-JF/J retrofit outlook

### 4.1 Baseline

Current E6 Twin JF center:

- ~984 kgf per engine at the 835 C long-life center;
- ~4.40 t clean/service center;
- ~5.05 t heavy takeoff planning ceiling;
- ~790 km/h class at 6-9 km;
- compression/wing/nacelle drag-rise already dominates further clean-speed growth.

### 4.2 Direct E7 aft-fan retrofit

1,100-1,150 kgf per engine gives 2.20-2.30 tf total, about +12-17% over the current JF center. Raw cube-root scaling would promise more speed than the straight-wing/high-Mach installation can use.

**H->A unchanged-airframe clean-speed outlook:** roughly **~805-825 km/h class**, not a 900 km/h aircraft.

The more valuable result is payload/weight margin. At the current 4.40 t center, static T/W rises from ~0.447 to ~0.50-0.52. If local wing-root, gear, brake and tyre qualification is paid, an **~5.4-5.6 t heavy design target** still gives static T/W around or above the present E6 heavy-aircraft condition. This is a design target, not a closed placard weight.

That extra weight budget should normally be spent on one or more of:

- retaining more internal fuel with Type 91 Mod 2 torpedo;
- D320F + mission load without giving away climb;
- armor / fuel-system protection where service experience demands it;
- heavier radio, navigation, future detection equipment and electrical generation;
- larger cannon/ammunition package;
- higher-altitude mission reserve.

Thus Twin experiences E7 primarily as **same ~790-820 km/h speed class with substantially more useful airplane**, not merely a top-speed upgrade.

### 4.3 J variant

A pure-J Twin retrofit uses the same logic as Single: high-speed/high-altitude comparison value remains, but straight-wing compressibility limits the payoff. Keep a smaller J development subset; do not make J the main long-range/service Twin merely because the new core has more thrust.

## 5. Prewar / 1941 research-close semantics

For planning language, use the following:

- **1940:** E7 is active hardware research, not a paper future generation.
- **1941 H1:** full core is a ground-development object; aircraft installation teams may already do mount/inlet/control/CG studies against expected envelopes.
- **1941 H2:** ground-qualified development core is the expected research close; inherited aft-fan may become a limited flight-release candidate. This is the earliest rational window for an E6 Twin retrofit flight article and, if pure-J release is equally healthy, E6 Single retrofit articles.
- **before a historical-date late-1941 Pacific-war expansion:** research closure is technically plausible; limited flight evaluation is plausible; serial service conversion is **not pre-recorded**.
- **1942 Q1-Q2:** earliest E7-dedicated new-aircraft first-flight target remains unchanged.

If war begins earlier, test losses/yield falter, or E7 package mass/TSFC misses targets, move these gates right; do not force calendar compliance.

## 6. Mandatory future-aircraft selection rule

For B6N, D4Y successors, AT-3, later E6 derivatives and any 1941-42 new aircraft:

1. record engine generation available at **project start**;
2. re-open propulsion choice at **detail-design freeze**;
3. re-open again before **first-flight engine installation** if the next E-generation has reached credible flight release;
4. compare a mature lower-generation/service-equivalent package against the new high-end package on mass, TSFC, altitude map, TBO, production yield and installation cost.

Do not automatically select the newest E-number. Do not automatically retain the older engine merely because the airframe began around it.
