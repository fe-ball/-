# SURFACE FLEET ARCHITECTURE AND NON-LINEAR OPTION VALUE — V14

## 1. Surface combatant baseline
Through 1941, battleships, cruisers, destroyers and carriers remain predominantly steam-propelled historical-type hulls. The Asai-worldline delta lies more in design/acceptance/availability and integration than in headline speed.

Yamato remains all-steam. Better computation/QC can improve 13-go diesel technical defects, but cannot manufacture the missing service history required to trust a novel diesel family in the most important ship.

## 2. Non-linear fleet effects
### Availability as a system multiplier
Small individual reliability improvements can multiply across a multi-ship task force because a plan may require all critical ships to be available at once. V14 does **not** set a universal availability percentage; it records the mechanism and keeps exact rates empirical/replay-local.

### FCS/electrical integration
The value is not a universal hit-rate bonus. Director, calculator, transmission, switchboard, mount and power continuity form a chain. Better calibration, synchronization and acceptance can increase multi-target system throughput and reduce re-acquisition/reset friction.

### Future sensor integration
Radar/request clocks remain Navy-driven. Pre-routed power, structural foundations, reserved volume, grounding/bonding and test practice shorten the time between a workable sensor and a fleet installation. This is an option-value effect, not early magical radar.

### GT high-speed craft
By 1941, marine-GT small-craft technology is no longer at "invent the principle" stage. If a Navy requirement is raised, the program can start from prototype/acceptance/production engineering. This strategic option exists even if series inventory is zero on 1941-12-08.

### Heavy landing craft
Moving from a ~15 t practical vehicle class to a ~20–22 t payload class can cross a categorical threshold: vehicles previously impossible to beach-land become possible. This is more than a proportional cargo-tonnage improvement.

### Submarines
Reliability, rapid-dive, battery safety and quiet/avoid-rpm maps reduce lost attack opportunities. The meaningful unit is not only maximum speed but usable patrol/attack opportunity.

## 3. Large-ship GT boundary
No selected carrier/cruiser/destroyer GT boost or primary installation before 1941-12-08. Large-ship GT remains most attractive first for boost, emergency power or limited-return propulsion; M3 primary propulsion remains later.
