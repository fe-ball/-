# COMPUTATION TO FLEET CHRONOLOGY — 1921–1941

## 1920s: industrial/computational foundation
The first naval change is not a GT warship. Early turbo/GT work creates high-speed rotating machinery, bearings, seals, balancing and long-running machinery feedback. Card/accounting/computation capability spreads into engineering bookkeeping: displacement, weight, CG, hydrostatics, fuel/water states and materials.

## 1930–33: computation enters ship quality
Design comparison expands from a few hand-worked points into systematic matrices:
- loading-state stability and weight moments;
- resistance -> propeller -> shaft -> reduction -> turbine/diesel matching;
- torsional-vibration and critical-rpm analysis;
- manufacturing tolerance and acceptance data.

The first-order effect is reduced redesign/commissioning friction and better repeatability, not a magical increase in top speed.

## Tomozuru / Fourth Fleet rule
Tomozuru and Fourth Fleet-type events are not erased merely because computation exists. If the physical/model input is wrong, fast calculation returns the wrong answer faster. Their worldline significance is that, once the missing stability/sea-load input is learned, Navy organizations can compare many corrective states rapidly and institutionalize the new model.

## 1936–39: Navy self-sufficiency
Routine ship design becomes a Navy/yard organizational competence using inherited computation/test methods. Asai becomes a supplier/collaborator rather than the person who computes every ship.

By late 1930s the fleet benefit is therefore systemic:
- weight/stability changes are audited faster;
- shaft/gear/propeller issues are localized earlier;
- acceptance tests use repeatable ledgers;
- FCS/electrical integration is treated as a system problem;
- negative gates—why a technology should **not** be fitted—are found earlier.

## 1940–41: option-value fleet
The visible ships stay largely historical in architecture, but the engineering pipeline contains mature alternatives: high-speed marine GT, modular test infrastructure, improved submarine electrical/noise work, higher-speed aerial-torpedo release integration, heavy landing craft and future radar-ready electrical/structural provisions. Their significance is faster response once Navy demand actually appears.
