# 回転翼の体系——四段の技術世代表（改訂正本）

**2026-08改訂**：旧稿の二つの短絡——**短絡A**「オートジャイロに450〜600馬力ターボプロップを載せる→観測機として最高性能になる」／**短絡B**「小型タービンは燃費が悪い→最初のヘリは1,000〜1,500馬力・4〜5.5t級であるべき」——を廃止し、**発動機能力と機体世代を分離**した四段の技術世代表へ再構成する（戦車で行った「240馬力→チヌ級」廃止と同型の処理）。既存の「カ号観測機」「レ号系中型回転翼機」は削除せず、**発展順序と能力配分を再構成**する。対象はまず開戦前（〜1941年末）。規則は `tensei-engineer-kufu-shu.md`、数値は【確認済み】【物理】【設定】【要確認】、固有名は【設定】。

## 1. 二門で切り分ける（維持・修正）

**発動機の門＝開く**。ターボシャフトはターボプロップからプロペラを外し軸出力をローター伝動へ回す系（社内E-6S、`turboprop-program` §2）。タービンの軽さは重量に敏感な回転翼に効く——これは維持。

**機体の門＝律速**。ローター頭・反トルク・伝動・振動疲労（地上共振・ブレード疲労）・操縦安定は反復でしか作れない——これも維持。先知が開くのは**構成**（単主ローター＋尾部ローター・斜板が正解という探索の短縮）で、信頼性は反復。

**修正＝伝動の勘定（旧稿の過大表現を弱める）**。旧稿は「ヘリの巨大減速はターボプロップとは別の未知技術」と書きすぎた。浅井はこの世界で1930年代半ばまでに、**高速タービン軸・自由動力タービン・高比率減速・精密歯切り・高速/高荷重軸受・潤滑・動釣合い・疲労設計・探傷・ショットピーニング・品質管理**をターボプロップ・過給機・GTで育てている。ゆえにヘリ伝動で**新しく残る難所**は、

- 大トルクを受ける主減速機の**耐久（寿命）**
- ローター主軸・尾部ローターへの動力分岐・フリーホイール（オーバーランニングクラッチ）
- 急激な負荷変動とローター**周期荷重**
- ローターヘッド・操縦系・地上共振・振動

に絞られる【設定】。**「歯車工業から始める」必要はない。ただし「既に減速ギヤがあるからヘリ伝動も完成済み」でもない**——既存技術が難所の一部を前払いしている、が正しい勘定。

## 2. 萱場との連携（維持）

機体門の律速は専門家に渡す。**萱場（1927創業・萱場資郎）＝日本の回転翼の専門家**——史実で陸軍カ号観測機（ケレットKD-1A系・1941初飛行・仙台・量産約98〜240機・あきつ丸で対潜）を実機化した唯一の系譜であり、油圧・緩衝器・精密機構の下地がローター操縦・ダンパーに効く【確認済み】。萱場自身の史実の道はオートジャイロ→ヘリプレーン（1950年代）【確認済み】。分業＝**機体・ローター＝萱場／発動機・材料・軸受・歯車・試験計測＝浅井**。所管は両軍。

## 3. 技術世代表（四段＋ヘリ系列）——本稿の芯

**発展の本線は二本並行**：(a) オートジャイロ系列（第0段→第1段→第1.5段）で**ローター空力・フラッピング・地上共振・プリローテーション・jump take-off**を学び、(b) **別系統の小型ヘリ実験系列**（ヘリ第0→第1世代→小型ターボシャフト）で**動力ローター・反トルク・伝動耐久**を学ぶ。後に両者が合流して中型ヘリへ至る。**ジャイロダインは必須の橋から研究枝へ降格**（§8）。

### ヘリ第0世代　小型ピストン実験機（仮1935〜38）

**オートジャイロと並行する別系統**。目的は性能でなく実測——主ローター駆動・周期/総ピッチ・反トルク・尾部ローター・フリーホイール・オートローテーション・地上共振・振動・操縦。**1〜2名・数百kg〜1t級・ピストン100〜200馬力級でよい**。史実のFw61（1936）・VS-300（1939・約500kg級の小型機）と同時代であり【確認済み・利用者確認】、**「小さいヘリはタービン経済性で不利」≠「最初のヘリ開発機として小型が不利」**——むしろローターヘッド・周期ピッチ・尾部ローター・フリーホイール・減速機・振動を一つずつ殺すなら小さい方がいい（短絡Bの解除）。構成は未来知識で**単主ローター＋尾部ローターを本線に早期固定**し探索を減らす。ただし信頼性は反復で作る【設定】。

### 小型ターボシャフト・ヘリ（仮1940〜41）

**最初のタービンヘリは小型**——1〜2t級・2〜4名・**数百軸馬力級**。観測・連絡・軽救難・負傷者後送試験。「小さいからタービンを使わない」と決めつけない——出力重量比は小型回転翼でも重量面の利益が大きく、問題は燃費・価格・小型コア効率との**交換**【物理／設定】。発動機は既存コアを無理に使わず、**(a)減格した小型軸出力機 (b)より小さいコア種類 (c)APU/小型GT側から育った軸出力系列**を比較し、**工程B（2026-08）で(b)に決定した**（下記）【設定】。

| 評価 | 内容 |
|---|---|
| 初飛行 | 拘束浮揚1940後半・**自由飛行1940後半〜41初**【設定】 |
| 実用試験 | **1941＝自由飛行を反復し任務試験（ホバー・前進・オートローテーション・担架・無線・短距離連絡）へ**。量産なし |
| 律速 | 主減速機寿命・ローターヘッド・フリーホイール・尾部伝動・地上共振・整備教育（発動機より機体側が上位） |
| 継承 | ヘリ第0〜1世代の機体・第1.5段の予回転/クラッチ知見 |
| 新規 | **小型化そのもの**（翼端隙間の相対増・低レイノルズ・小翼列公差・シール/軸受の相対損失）＝E5-S-S〔小端〕 |
| 量産 | 未（試験） |

**発動機確定（工程B・2026-08）**——三案判定：**A（既存E4-Sの大幅減格）＝飛行ミュール限定**【設定】——1939〜40年に「タービンでローターを回す」最初の飛行と機体・伝動側の先行試験には最短だが、630馬力級コアを約50%運転点で使うため燃費が悪く（熱効率12〜15%級→SFC0.56〜0.70kg/kWh）、機関もE4-S系で180〜250kg級の目安＝制式候補として棄却（試験形態は搭載を絞るか地上リグ併用）。**B（E5-S-S〔小端〕）＝採用**。**C（APU/極小GT発展）＝主機化しない**——SFC約0.57のまま330馬力なら燃料約140kg/h で重すぎ、寿命・応答・自由動力タービンまで改良するとBへ収束する＝小型燃焼器・始動・小径軸受・小型製造法の**技術供給源**として使う。

**機体一型確定（工程C・2026-08）**【設定】——**小型ターボシャフト・ヘリ一型**（制式名称なし）。単主ローター＋尾部ローター・**標準2名／最大3名または担架1＋付添**。重量三用語＝推定空虚**約920kg**／標準運用約1,230kg／3名運用約1,300kg／**設計全備1,350kg**／成長上限約1,400kg（1,400kgで高温高地のOGEホバーを保証する意味ではない＝海面低温・短時間以外は重量制限を受けてよい）。主ローター＝三枚関節型・**直径11.2m**（98.5m²・約230rpm・翼端約135m/s・DL＝1,350kgで13.7・1,400kgで14.2kg/m²）。尾部ローター＝二枚・約2.0m・1,200〜1,300rpm級・主出力の8〜10%消費。**ホバー帳簿**＝1,350kgの理想誘導約131hp→初期機FM0.55〜0.60で主ローター約220〜240hp→尾部＋伝動効率87〜90%を払って**発動機側265〜305hp**＝定格330shpで海面ホバーは成立するが余裕は無限でない（360shpは高温・離陸・急上昇・重量上側の短時間余裕であり常用前提にしない）。速度＝最大140〜150・巡航105〜115km/h（**330馬力を速度へ変換しない**＝出力の主用途はホバー/垂直上昇/高温条件/3名搭載/操縦余裕/伝動損失/尾部ローター）。燃料120kg・巡航150〜180hp級→**実用滞空1.8〜2.0時間級**（カ号観測機の3.5時間観測機とは役割が別＝タービンヘリでカ号観測機を置換しない）。上昇2〜3m/s級・実用高度2,500〜3,000m級（「タービンだから高高度ヘリ」とはしない）・航続180〜220km級（航続は売りにしない）・**武装なし**。**伝動＝ヘリ固有の技術税**：発動機130kgに対し**主減速機＋フリーホイール＋尾部取出しで約125kg**＋尾部伝動軸/軸受/尾部ローター約40kg＝「タービンが軽いからヘリも軽い」とはしない。総減速比は機体側で**約35〜40:1**（発動機出力軸8,000〜10,000rpm→主230rpm）。操縦は**機械式リンク基本**（油圧操縦補助を標準化せず新規性を増やさない。萱場の油圧はダンパー・脚・試験装置へ）。**地上共振＝主要ブロッカー候補**＝リード/ラグダンパー・広輪距の油圧緩衝固定脚・脚剛性の左右差管理・ローター追跡・関節遊び管理で対処し、共振域が見つかれば技量でなく**運転禁止回転域の設定と機械側改修**で処理。**オートローテーション**は大きめローター（11.2m・DL13〜14）＋三枚の回転慣性＋フリーホイールで有利側だが、最適降下速度・最小沈下率・フレア高度・重量別手順は実飛行で詰める＝**危険域（低高度＋低速＋着陸適地なし）は試験で地図化している途中**とし、完成したH-Vダイアグラムを最初から持たない。詳細帳簿は本節と`fix-queue`の査読記録に集約（個別ファイルは作らない）。

**採用機 E5-S-S〔小端〕**【設定】：E-5世代技術（1934〜37成熟）のS系列小流量派生を1938〜40に派生開発。約2.5kg/s・PR5〜5.5・TIT760〜780℃・**非Ni**（温度を下げて寿命を買う）・正味比仕事約100〜110kJ/kg（**E5-Sの126kJ/kgを小型化損失で明示的に割り引く**——「2.5kg/sだから422馬力」とはしない）・**定格330軸馬力／短時間360**・熱効率約18.5〜20%・SFC約0.42〜0.45kg/kWh・乾燥約120〜140kg（**ヘリ主減速機・ローター主軸・尾部分岐・機体側フリーホイールは含まない＝機体側の別帳簿**）・自由動力タービン式（出力軸8,000〜10,000rpm・内蔵減速一段含む→機体側でなお数十対一の主減速が要る＝ヘリ固有の律速は残る）・寿命は1940ベンチ数十時間→**100時間級の反復**→1941に200〜300時間級目標。**タービンを採る理由は燃費でない**——軽さ・低振動・冷却簡素・高出力密度・灯油・高温高地の出力保持・始動性。発展順序＝1937〜38ピストンヘリ並行＋E4軸出力試験→1938〜39小流量コア設計→1939〜40 E4ミュール→1940ベンチ→1940〜41換装・330馬力級で反復試験→**1941末＝試作・実用試験段階（量産主機にしない＝§6の段付き正準を維持）**。カタログ行＝`turboprop-catalog` §4。中型レ号系中型回転翼機（E6-S-S約1,500馬力・第二世代）とはコア別・伝動/運用経験のみ継承（§3末尾）。

### レ号系中型回転翼機＝**1942+はv32正準へ移管**

本稿の開戦前結論は「1941年末には中型機は設計研究段階」までを保持する。旧稿で置いた**4〜5.5t・1,000〜1,500馬力級を最初の中型中央とする指定はv32でSUPERSEDED**。

1942年以後の上位正準は `asai-works-rotorcraft-1942-plus-rebaseline-1942-55.md`。中央は、まず**約3.2t・15mローター・E6-S-S減格900shp連続/1,000shp短時間**のprototype/service-testから始める。用途は連絡・担架後送・短距離貨物・艦上試験・目視海上哨戒。dipping sonar hunter-killerは戦中正準から外す。

---

## 4. 性能の再較正（旧正準の解除）

旧稿の「最高190〜200km/h・上昇11〜16m/s・上限6,000〜8,000m・滞空3〜5時間・搭載+400〜600kgを一台で全部」を解除する【設定】。

- **観測型（ピストン）＝滞空・視界・維持性優先**。性能はカ号較正の常識帯（`autogyro-ka-go` §4）。
- **タービン艦上型＝「短い発着・搭載・灯油・高温高地」との交換で滞空を決める**。タービンは部分負荷燃費が悪いため「大出力だから滞空も長い」とはしない。
- **高度**：「タービンは高度で出力を保つ」は「**自然吸気ピストンより高度低下が緩く、設計された高度補償域で有利**」程度に直す。無制限に定格を維持する意味にしない（`tank-diesel-turbo` §1Cの高度補償と同じ作法）。

---

## 5. 艦上運用の再評価

「小艦ならどこでもカ号観測機を載せられる」とはしない【設定】。回転翼機でも、**ローター直径ぶんのクリアランス・艦の動揺・着艦位置・係止・格納・整備・風向・排気/プロペラ流・甲板員**が要る。jump take-offは甲板長を減らすが、**ローター径と運用面積は消さない**。

- 1941年以前の艦上カ号観測機は、「飛行甲板を持たない任意の小艦」ではなく、**あきつ丸級・補助艦・商船改造護衛艦・回転翼運用場所を確保した専用/準専用艦**程度から始める。
- 対潜用途は「艦隊の潜水艦問題を解決する」ではなく、**低速目視哨戒・発見・通報・局地的制圧**として扱う（史実カ号も発見・通報で、撃沈記録なし【確認済み】）。艦隊規模の対潜効果の試算（`asw-effect`）は戦時中の拡大側の話として読む。

## 6. 1941年末の状態（各段評価からの帰結・正準）

| 系列 | 1941年末 |
|---|---|
| 1. ピストン型カ号観測機（第1段） | **部隊配備・量産中**（陸軍観測・砲兵観測・連絡。海軍でも基地・補助艦で使用） |
| 2. jump take-off／カ号観測機タービン上位型（第1.5段） | **少数実用**＝艦上運用試験〜初期運用（あきつ丸級・準専用艦）。量産の主力ではない |
| 3. 小型ピストンヘリ（第0〜1世代） | 実験飛行済み・**第1世代試験機が試験配備段階（少数）** |
| 4. 小型ターボシャフトヘリ | **試作試験中**——ただし内実を一段具体化＝**機体一型（1,350kg・E5-S-S〔小端〕330shp）は成立し、自由飛行を反復して任務試験（ホバー・前進・オートローテーション・担架・無線・短距離連絡）に入った段階**。試作数機〜一桁機級を想定しうるが**台数は正準化しない**。「少数実用配備」へは上げない——理由は発動機でなく主減速機寿命・ローターヘッド・フリーホイール・尾部伝動・地上共振・整備教育の未成熟 |
| 5. 中型レ号系中型回転翼機 | **設計研究段階**（機体未着手〜要素試験。第二世代＝1942年以後） |

「1941年末に中型タービンヘリが大量存在」とも「カ号相当しか存在しない」ともしない——上の段付きが正準【設定】。ORBAT（`orbat-1941`）へはこの段付きで反映する。

## 7. 用途と所管（維持・表現修正）

- **陸軍**：観測・砲兵観測・連絡・負傷者後送（ピストンカ号観測機が主力。ヘリは試験段階）。
- **海軍**：艦上対潜哨戒（カ号観測機タービン上位型・少数）・救難試験・連絡。
- 両軍にまたがる。機体＝萱場・発動機＝浅井の共同計画。

---

## 8. ジャイロダインの位置（降格）

旧稿の「オートジャイロ→ジャイロダイン→ヘリ」の一本道を解除する【設定】。ジャイロダインは動力ローター＋別推進系＋複合制御を同時に持ち、**必ずしも単純な中間段階ではない**。技術の橋として本当に要るのは、**(a)オートジャイロでローター空力・フラッピング・地上共振を学ぶ (b)jump take-offで動力プリローテーション・クラッチ・ピッチ操作を学ぶ (c)別系統の小型ヘリ実験機で動力ローターと反トルクを学ぶ**——ここから普通にヘリへ合流できる。ジャイロダインは**研究枝として保持**（萱場の史実の軌跡＝ヘリプレーン1950年代への敬意も込めて）するが、本線にしない。

---

## 9. 正直な限界

- 機体門の律速は消えない：ローターヘッド・伝動耐久・振動・操縦の信頼性は反復でしか得られない。早期のヘリは搭載が小さく・航続が短く・整備が重い。
- タービンの利得は「軽さ」であって「燃費」ではない：小型ほど燃費・価格の交換が重い。段ごとに交換を明記する。
- 艦上は場所を食う：jump take-offでも運用面積・係止・格納は残る（§5）。
- 年次はすべて仮置き【設定】。各段の一型詰め（カ号観測機・レ号系中型回転翼機）はこの世代表の確定後に行う。
