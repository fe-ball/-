## 0. Core conclusion

The Navy does not discover the E6 twin in 1940 as a completely new class. It already has 1937-39 operational experience with E5 twin land reconnaissance / high-cover / light-strike aircraft. That experience naturally creates two related but institutionally distinct E6 Navy branches:

1. a **high-speed land-reconnaissance branch** retaining the E5 reconnaissance lineage; and
2. a **high-speed land-attack branch** optimized around one Type 91 aerial torpedo or the existing ~0.35-0.40 t internal bomb mission.

The land-attack branch is not a G3M/G4M replacement. It buys speed, rapid concentration, survivability and fast post-release acceleration at the cost of torpedo-range/endurance and payload mass.

## 1. Service-year and designation working proposal

Japanese type-year numbering follows adoption/production acceptance year. Project/short codes are a separate layer and do not have to equal the type year.

### 1.1 Army E5 reconnaissance lineage

- E5 Twin reconnaissance/command service acceptance is treated as **1938** for naming purposes.
- Working Army long-form service-name proposal: **九八式司令部偵察機** (Type 98 Headquarters Reconnaissance Aircraft).
- Package airframe identity remains **E5 Twin**.
- Older E5 evaluation-ledger `Ki-40 command/high-speed recon` wording is retained only as a historical evaluation/allocation label and is **not** promoted as the current formal Army project code, because later current support uses Ki-40 for a distinct turboprop reconnaissance lineage.

This prevents a live designation collision while preserving old provenance.

### 1.2 Navy E5 reconnaissance lineage

- Working Navy long-form service-name proposal: **九八式高速陸上偵察機**.
- Short code: **R1As**.
- `As` denotes Asai manufacturer lineage in this package.
- The adjective `高速` intentionally distinguishes this branch from the historical C5M **九八式偵察機** lineage, which remains present as a separate conventional reconnaissance family.

### 1.3 E6 Navy reconnaissance lineage

- E6 Twin Navy reconnaissance service acceptance is placed in **1940**.
- Working Navy long-form service-name proposal: **零式高速陸上偵察機**.
- Working short code: **R2As**.
- Model 11 is the first normal JF service block; pure-J aircraft remain specialized high-speed/high-altitude comparators rather than the main reconnaissance model.

### 1.4 E6 Navy land-attack lineage

- Working Navy long-form service-name proposal: **零式陸上攻撃機**.
- Working short code: **G4As**.
- Initial service model: **G4As1 / 零式陸上攻撃機一一型**.

`G4As` is treated as a supplementary high-speed branch opened under the broad **12-Shi land-attack requirement space** after E5 operational evidence made a radically different speed/range trade credible. It therefore shares the G4 project number with Mitsubishi G4M in the same way that Japanese Navy competitive programs could share the category number while differing by manufacturer suffix. The two aircraft are not hardware variants of each other and do not share the same payload/range requirement closure.

- **G4M:** long-range conventional land attack; larger fuel/payload reach.
- **G4As:** short/medium-range high-speed land attack; one torpedo, rapid attack geometry and fast withdrawal.

G4M later retaining the historical **一式陸上攻撃機** service identity is not blocked by G4As receiving a 1940 Type 0 service name.

## 2. Why a torpedo branch appears before E6 production is mature

E5 Navy service from 1937-39 has already demonstrated:
- high-speed low-level and light-strike work;
- mission-bay / release-table discipline;
- radio/navigation/photo integration;
- JF low-speed thrust and go-around value;
- external-fuel carriage and jettison;
- repeated instrumented flight-test methods.

A Navy question of **"can the fast twin carry a Type 91 torpedo?"** is therefore expected by 1938 rather than appearing after E6 is already in mass service.

Current closure:
- **1938H2:** E5 structural/clearance/low-level torpedo-carriage study.
- **1939:** 2-4 Navy E5 development/service aircraft can be used serially for torpedo carriage, release, low-level approach and sight/envelope trials. This is a technical-development claim only; it does not add unrecorded 1939 combat torpedo attacks.
- **1939H2-Q4:** E6 Twin naval attack prototype/conversion can inherit the E5 torpedo school.
- **1940Q1:** G4As service trials / torpedo release qualification.
- **1940Q2:** Type 0 land-attack service acceptance is technically credible.
- **1940H2:** serial Navy allocation can expand inside the Navy share of E6 Twin production, subject to actual replay allocation/training.

## 3. G4As1 airframe mission closure

G4As1 remains recognizably E6 Twin but is not merely an R2As with a torpedo hung from an ordinary rack.

### Common with E6 Twin / R2As
- two-seat common forward crew architecture;
- E6-M-JF x2 main production propulsion;
- common wing, tail, major nacelle and systems architecture;
- prepared-field tricycle undercarriage;
- common radio/electrical/oxygen family;
- common high-speed production/QC school.

### Land-attack-specific structure
- reinforced lower-fuselage longitudinal load path;
- **single centerline semi-recessed torpedo trough** for a 45 cm Type 91-class aerial torpedo;
- torpedo shoulder/fairing and removable aerodynamic closure use molded plant-FRP where non-load-bearing; primary fittings remain metal;
- local landing-gear / nose-gear bay geometry must preserve torpedo clearance;
- repeatable deceleration device / speed-brake provision for torpedo approach without relying solely on large engine spool-down;
- torpedo sight / heading / release interface derived from Navy FCS1/FCS2 practice;
- camera equipment is normally omitted on torpedo missions.

### Load rule
A torpedo mission is a dedicated load state, not a free combination.

For Type 91 Mod 1 (~0.78 t class) or later Mod 2 (~0.94 t class):
- torpedo + carrier/fairing occupies the principal external/centerline attack load;
- D320F full pair is not a normal simultaneous torpedo load;
- internal fuel is traded to hold the heavy-takeoff envelope;
- the ~0.40 t internal bomb mission remains available when no torpedo is carried.

### Working mission radius
Initial 1940 torpedo attack planning radius is **~300-400 km class**, with a possible ~350-450 km favorable-band growth after drag/fuel/approach data close. This is intentionally shorter than G3M/G4M long-range land-attack reach.

## 4. Speed problem: aircraft-side solution first, torpedo-side solution second

E6 is badly mismatched to an early-1930s low-speed aerial-torpedo release envelope if one tries to use its clean maximum performance directly.

The rational development sequence is:

### Phase A — 1939 to early 1940: aircraft accommodates the torpedo
- high-speed ingress remains possible well above ordinary torpedo-attack speed;
- the last several kilometers are flown as a deliberate deceleration segment;
- release is initially in a conservative **~320-370 km/h class** envelope inherited from Type 91 practice and E5 trials;
- after release, ~0.8-0.95 t disappears and JF low-speed thrust makes rapid acceleration/escape a core G4As advantage.

### Phase B — 1940: torpedo release envelope moves upward
Instrumented E5/E6 testing creates a 1940 technical target of approximately **390-430 km/h** low-altitude release for selected Type 91 air-drop configurations.

The work is primarily:
- repeatable air-entry attitude and roll control;
- afterbody/local structural margin;
- standardized expendable air-stabilizing tail/fairing;
- sight/release-delay/heading tables;
- production acceptance/QC.

The torpedo body and explosive system do not become an Asai design. Asai contribution is test method, metrology, computation, selected materials and airframe/weapon integration.

### Phase C — 1941 Type 91 Mod 2 high-speed standard
The historical 1940-design / 1941-service **Type 91 Mod 2** remains the service identity, but the worldline qualification requirement is changed by G4As experience.

Current worldline closure for the 1941 service standard:
- normal qualified air-drop band: **~400-430 km/h class**;
- selected development growth: **~450 km/h class** after sufficient release/entry evidence;
- anti-roll stabilization is treated as service-significant rather than an incidental late correction;
- an expendable molded plant-FRP air-stabilizing/fairing component is permitted where it improves repeatability and manufacturing consistency; the torpedo pressure body, warhead and concentrated fittings remain conventional metal.

Do **not** back-port the historical 300-knot / 350-knot late-war strengthened torpedo state into 1941. That remains a later structural-development ladder.

## 5. Tactical consequence for G4As

The key advantage is not dropping the torpedo at E6 clean top speed.

A representative 1940 attack cycle is:
1. approach the target area at high subcritical cruise / dash speed;
2. use geometry and speed to distribute attack sections widely before final run-in;
3. descend and decelerate only in the terminal zone;
4. release at the qualified Type 91 speed band;
5. immediately retract speed brakes, clean the airframe and accelerate away with a much lighter aircraft.

This shortens the duration during which the aircraft behaves like a conventional straight-running torpedo bomber. It does **not** remove the basic vulnerability of the final low-level, low-evasion release run.

E6 speed is also valuable **before** the release: multiple sections can reposition more rapidly for crossing / multi-azimuth torpedo geometry than slower land-attack aircraft.

## 6. Effect on carrier attack aircraft

The high-speed torpedo program is not an E6-only technology silo.

### B5N2 / Type 97 Carrier Attack Aircraft
By 1939-40 current V10 already gives B5N2:
- progressive EX2 exhaust adoption on later production, ~+4-6 km/h physical exhaust-only shadow when comparing true EX0 vs EX2 aircraft;
- improved engine/prop/cooling/QC/serviceability;
- FCS1 torpedo-sight calibration, gyro/heading/instrument QC and better torpedo-envelope tables;
- FCS2 mechanical lead aid when separately adopted.

NAVALJETTORP1 does **not** redesign B5N2 into a high-speed aircraft. Its benefit from the 1941 Type 91 high-speed program is mostly:
- larger release-envelope margin;
- better entry/roll consistency;
- less sensitivity to exact low-speed setup;
- improved shallow-water / special-envelope development where separately qualified.

### B6N Tenzan / 14-Shi Carrier Attack Aircraft
The historical 14-Shi requirement starts in Dec 1939 and already asks for a much faster B5N successor while retaining the same external weapon class. In this worldline the G4As / Type 91 program makes high-speed torpedo integration **design-origin** rather than a late accommodation.

Close the B6N requirement inheritance as:
- torpedo release target **~400-430 km/h class** from the outset;
- carrier approach/landing requirement remains separate and is not weakened by torpedo speed;
- torpedo sight, release linkage and clearance are designed around the faster envelope;
- late-1941 selected ~450 km/h growth is a test target, not an automatic fleet value.

An **E6-S-T turboprop Tenzan** remains an existing technical candidate in the current support stack, but E6S power was later rebaselined to ~1,300 hp standard / ~1,400 hp short high-flow. Therefore NAVALJETTORP1 does **not** yet lock the Tenzan engine. It locks the **torpedo interface requirement**, which benefits B6N regardless of whether the final powerplant is E6-S-T or a conventional piston alternative.

### B7A Ryusei
B7A remains Aichi's independent integrated carrier attack design, not a B6N derivative.

When its 1941-42 development gate is reached it inherits two mature Navy schools:
- D3A/D4Y dive-brake / dive-release / high-speed-store qualification; and
- G4As/B6N high-speed Type 91 torpedo release.

This strengthens the case for a genuinely unified torpedo/dive-bomber mission rather than merely putting two nominal weapon choices on one airframe.

## 7. Effect on carrier dive bombers

### D3A1 / Type 99 Carrier Bomber
No large airframe rewrite is created by this closure.

Existing current differences remain:
- progressive EX2 exhaust, ~+4-6 km/h physical shadow when applicable by lot;
- better engine/prop/cooling/QC realization;
- improved dive-sight calibration;
- more repeatable dive-angle / airspeed / release-delay tables;
- faster convergence on dive-brake vibration and stability problems through instrumentation and test discipline.

Type 91 torpedo development gives D3A no direct weapon benefit. The shared benefit is the broader Navy high-speed-store / release / instrumented-separation culture.

## 8. Strategic portfolio closure

The 1940-41 Navy land-attack portfolio is deliberately plural:

| system | main advantage | main cost / limit |
|---|---|---|
| G3M/G4M | long-range land attack, larger fuel/payload reach | slower and more exposed in terminal attack |
| G4As Type 0 land attack | very high ingress/egress speed, rapid multi-axis concentration, fast post-release recovery | one torpedo, shorter radius, prepared-base/turbine support |
| B5N2 | carrier compatibility, mature deck system | lower speed; older airframe |
| B6N | faster carrier torpedo attack / general carrier attack | carrier geometry and development burden |
| B7A | later unified torpedo/dive attack | larger, expensive, 1942+ technology/procurement gate |

No one type automatically cancels the others.
