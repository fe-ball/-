# ASAI WORLDLINE — E5 TWIN / KI-42 AUXILIARY FUEL & DROP-TANK CLOSEOUT V1
## Research, qualification, production provision, fielding and operating rules through 1939

**Status:** TECH / PRODUCT / SERVICE-EQUIPMENT CLOSED  
**Purpose:** Close the previously implicit auxiliary-fuel hardware behind E5/Ki-42 range doctrine without retroactively inflating already-closed mission radii.

---

## 0. Precedence / no-double-count rule

Existing closed mission envelopes remain authoritative:

### E5 Twin JF
- command/photo reconnaissance: **350–450 km routine radius**
- light high-speed reconnaissance: **400–500 km routine radius**
- exceptional light recon: **550–600 km**
- normal ~0.4 t attack: **250–350 km**
- exceptional light attack: **~400 km**
- rapid courier: **700–900 km one-way**, 1,000–1,100 km exceptional
- ferry / extended: **1,300–1,550 km class**

This closeout explains **how fuel is configured** to obtain those envelopes.

It does **NOT** add another range multiplier on top of them.

If a previously replayed E5 sortie was already credited at the exceptional/range edge, assume the appropriate internal/external auxiliary-fuel configuration was used and its weight/drag/reserve cost was already implicit.

# 1. Upstream requirement — auxiliary fuel is not a 1939 invention

The military twin lineage already required:
- long-distance fuel arrangements;
- greater fuel flexibility;
- mission-bay / payload exchange;
- fuel/payload trade studies.

The Asai aviation product doctrine already specifies three mission fuel states:

1. **clean/light**
2. **internal mission fuel**
3. **ferry/extended using jettisonable external kerosene tanks or mission-specific extra fuel**

Therefore the question is not whether drop tanks are invented in 1939.

The closure question is:
**when were the hardware, qualification and field stocks mature enough to use routinely?**

---

# 2. Historical calibration

By 1938–39 the historical Japanese Army already had practical jettisonable auxiliary-tank technology.

The Ki-27b could carry:
- two underwing slipper-type drop tanks;
- nominal capacity roughly **130 L each**.

Therefore:
- racks,
- fuel connections,
- vents,
- release mechanisms,
- pilot procedures,
- unit handling of detachable tanks

are not anachronistic technologies in 1938–39.

Asai turbine aircraft use kerosene-family fuel, which reduces volatility/fire-handling burden but does not eliminate:
- leaks,
- structural loads,
- drag,
- CG,
- release failure,
- landing-weight constraints.

# 3. E5 Twin fuel-equipment family

## 3.1 E5 fixed/internal fuel

Exact cell-by-cell production-airframe tank geometry remains a local-detail drawing question.

For service accounting, the fixed internal system is the **normal mission-fuel state**.

Do not reinterpret the previously closed 1,300–1,550 km JF endurance/range anchor as a new “clean aircraft plus another full drop-tank bonus.”

The declared service range already includes mission-specific fuel loading where appropriate.

---

## 3.2 E5-M300 removable internal mission tank

**Product designation (working): E5-M300**

Configuration:
- removable mission-bay auxiliary tank;
- nominal capacity: **~300 L**
- usable fuel: **~285–295 L** after expansion/unusable allowance
- kerosene fuel mass at full usable load: **~230–240 kg**
- installed empty tank/plumbing mass: **~26–34 kg**

Purpose:
- command reconnaissance;
- long-range photo reconnaissance;
- courier / specialist transport;
- ferry;
- range-reserve increase in poor-wind / alternate-field conditions.

Trade:
- occupies mission-bay volume;
- displaces central bomb / cargo installation;
- creates a real CG / landing-weight case;
- cannot be treated as free fuel on top of full normal payload.

1939 normal rule:
**M300 and normal 0.4 t attack payload are mutually exclusive as standard mission configurations.**

Special partial-load combinations require a local weight/CG sheet and are not automatic.

---

## 3.3 E5-D200 jettisonable external tank

**Product designation (working): E5-D200**

Arrangement:
- two external tanks;
- one per wing / inner-wing-nacelle station;
- nominal **200 L each**
- total nominal capacity: **400 L**
- usable fuel: ~375–390 L total
- fuel mass: **~300–315 kg**
- tank + rack + plumbing empty installed mass: **~40–50 kg per pair**

The tank is streamlined/slipper or compact low-drag external form, not a crude cylindrical drum.

### Aerodynamic cost while carried
Working 1938–39 operational penalty:
- maximum speed: approximately **20–35 km/h lower**
- cruise fuel burn / drag burden: roughly **+6–10%** at comparable airspeed
- climb worsens materially at full fuel weight
- one-engine margin worsens until fuel is burned / tanks dropped

After clean jettison:
- aircraft returns close to clean external-drag state;
- rack residual drag remains small but nonzero.

### Use
Preferred:
- long-range recon transit;
- same-type distant high cover;
- ferry;
- long command/courier legs where mission bay must remain free.

Not preferred:
- normal shallow-glide attack;
- low-level strike into defended target;
- rough-field heavy return.

Combat doctrine:
**drop before intentional fighter combat / high-speed escape if fuel state permits.**

# 4. E5 combined extended configuration

M300 + D200 pair can be physically installed only on strengthened late-1938 production-standard airframes and only with a mission-specific loading sheet.

It is **not** a normal combat load.

Typical use:
- ferry,
- exceptional one-way reposition,
- test/endurance flight.

Restrictions:
- no normal bomb load;
- reduced mission equipment;
- prepared runway;
- takeoff/landing-weight controls;
- external tanks expected to be emptied / jettisoned before landing where necessary.

This combined state does **not** create a new routine range number beyond the already-closed 1,300–1,550 km practical ferry/extended service envelope.

Reason:
the existing service envelope is a mission-planning envelope, not a theoretical “every tank full, best-weather still-air” maximum.

No 2,000+ km operational E5 credit is created here.

# 6. E5 production provision and fielding

## Production-airframe provision

From the first 1938 production block onward:
- structural hard points / local reinforcement: standard;
- fuel-line / vent / control provision: standard or kit-ready;
- jettison electrical/mechanical control provision: standard;
- tank itself is NOT permanently carried.

Earlier development/evaluation aircraft:
- selective retrofit only.

Thus by 1939:
**nearly every normal production E5 military airframe is structurally capable of using M300 and/or D200.**

Capability is not the same as tank-set availability.

## Tank-set availability

### 1938 year-end working stock
E5 completed: 40 total program aircraft in the replay ledger.

Mission equipment available:
- M300 sets: **~20–24**
- D200 pairs: **~12–16**

Interpretation:
- enough for repeated operational use;
- not enough to put every aircraft into maximum-range configuration simultaneously.

### 1939 Q1
With E5 production expanding:
- M300 production becomes ordinary mission-equipment work;
- D200 pair production expands more slowly because tank bodies, racks and handling stock are additional logistics.

Forward-unit planning ratios:
- M300: **~0.6–0.8 set per forward E5**
- D200 pair: **~0.35–0.50 pair per forward E5**

This is theater stock, not permanent aircraft ownership.

### 1939 summer
For high-priority Manchuria / China E5 units:
- M300 shortage is no longer a major limiting factor for selected missions;
- D200 remains a finite expendable item because combat jettison destroys/relinquishes the tank.

Typical operational practice:
- do not drop tanks merely to improve speed if combat is not expected;
- jettison is authorized when interception / emergency / landing-weight conditions justify the material loss.

## 7.2 Ki42-D130 drop tank

The most rational Army-compatible solution is a **130 L class slipper/drop tank ×2**, because:
- the historical Ki-27b already uses this size class;
- Army supply / handling doctrine therefore exists;
- Ki-42 does not need a unique giant tank.

Configuration:
- nominal capacity: **130 L each**
- pair nominal: **260 L**
- pair usable: ~245–250 L
- full fuel mass: **~195–200 kg**
- tank/rack/plumbing mass: **~28–38 kg per pair**

### Normal operational fill
Because Ki-42 is only ~2 t:
- ordinary long-cover load uses approximately **100–110 L per tank**
- total external fuel ~200–220 L
- fuel mass ~160–175 kg

Full 130 L ×2:
- ferry / light-load condition;
- reduced internal fuel or ammunition as needed;
- prepared runway;
- explicit weight sheet.

**Full external tanks are not simply added on top of every normal fully-fueled 2.08 t mission.**

# 8. Ki-42 performance / use with tanks

While tanks are carried:
- max speed penalty: **~15–25 km/h**
- climb noticeably worse;
- takeoff run materially longer;
- high-speed maneuver loads restricted.

Doctrine:
- use tanks for transit / distant cover;
- drop before planned combat;
- do not enter sustained high-g combat with tanks retained.

Range/endurance effect is not a simple +57% fuel = +57% radius.

Working planning effect versus the same clean mission:
- distant-cover station reach: **~+25–35%**
- ferry / transfer reach: **~+35–45%**
- or convert the fuel into additional station time rather than distance.

No absolute Ki-42 combat-radius number is frozen in this file because the existing aircraft canon has not yet closed a clean mission-radius table.

# 12. Tactical implications

## E5 reconnaissance
D200 can:
- extend outbound transit,
- preserve reserve,
- provide more loiter.

Before hostile interception:
- tanks can be discarded;
- aircraft regains most clean high-speed performance.

## E5 same-type high cover
This is one of the strongest uses:
- E5 cover aircraft can accompany a distant recon package without becoming the first aircraft forced home by fuel.

## E5 strike
Normal 0.4 t strike does **not** automatically receive D200 + M300.
Payload / fuel / field length must be traded.

## E5 courier
M300 is often preferable to D200:
- less drag;
- no expendable external hardware;
- mission bay remains unavailable for bulky cargo, so cargo/fuel trade is explicit.

## Ki-42
D130 makes:
- distant high cover,
- ferry,
- reinforcement between bases

more practical.

It does not convert Ki-42 into a long-endurance patrol fighter with no cost.
