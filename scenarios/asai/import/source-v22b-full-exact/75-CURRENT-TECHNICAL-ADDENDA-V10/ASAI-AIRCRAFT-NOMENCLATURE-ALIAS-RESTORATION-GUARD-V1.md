# ASAI AIRCRAFT NOMENCLATURE / ALIAS / RESTORATION GUARD — V1 NAMEGUARD1

**Status:** CURRENT V10 nomenclature-control overlay.  
**Scope:** names/codes only. No airframe identity, engine family, performance, OOB, production, mission, clock or combat result is changed by this guard.

## 1. Governing rule

Aircraft **technical identity** and **service nomenclature** are separate axes. A technical branch can be closed while its eventual Army/Navy type-year name, project code or long-form service title remains provisional.

Any long-form Japanese service name or new project code introduced during the 2026-09-07 technical wash is a **WORKING ALIAS** unless an earlier current source already establishes that exact designation. Such a working alias:

- does **not** delete or overwrite older names, evaluation labels or historical project codes;
- may be replaced, restored, split or merged when the formal adoption/naming review is performed;
- must not be used as proof that a service has already issued that exact designation;
- leaves all technical conclusions attached to the underlying airframe/engine family intact.

When an older name is later selected as the formal service name, it can be **re-promoted without any retcon to hardware history**. The package should then record the temporary alias as provenance rather than erase it.

## 3. What remains closed

This guard does **not** reopen:

- E5/E6/E7 engine-generation hierarchy;
- E5/E6 Twin or E6 Single physical/technical identities;
- Army/Navy mission-family splits;
- R1As as an already attested older current code referent;
- G4As/R2As technical branch concepts as shorthand within the 2026-09-07 analysis, provided they are read as aliases rather than formal adoption proof;
- torpedo, bomb, performance, production or mission calculations.

## 4. Future naming review procedure

At an adoption/nomenclature gate, choose names using:

1. the service's contemporaneous naming rules;
2. collision checks against existing Army/Navy names and project codes;
3. the actual adoption year, not the year of first prototype flight;
4. continuity with already-used unit paperwork where appropriate;
5. preservation of every superseded/temporary alias in provenance.

Until that gate is explicitly closed, use the **technical identity first** (`E6 Twin Navy land-attack derivative`) and put the working alias in parentheses only when useful.
