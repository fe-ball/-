## 0. v25で閉じるもの／閉じないもの

### 技術側でCLOSED

- 1939年時点で、日本陸軍内部に「将来、戦車が対戦車戦闘を強いられる」という問題意識と、次期戦車を横断審議する制度的入口が存在すること。
- 浅井世界の計算・試験・QC文化を加えると、**現在要求と将来余裕を分離して試験する**設計方法が成立し得ること。
- 18t級チヘとは別に、**20–22t級の技術試験車へ24–25t試験荷重、1.70m級砲塔環、75mm完全弾の装填/反動試験、300hp級伝動余裕**を持たせることの技術的成立性。
- 75mm砲は、680m/s級車載経験→720–750m/s級中間段階→770–800m/s級対戦車砲という段階発展が可能で、いきなり後世砲を前倒しする必要がないこと。
- 21.7L V12を無理に絞る代わりに、**27L級V12 300hp連続/320hp短時間級**を次期研究対象とすることの成立性。30L級330–350hpは次段階の試験候補。

## 1. 史実制度アンカー——ノモンハン以前から問題意識はある

1939年3月6日の陸軍省機械課委員「新中戦車設計条件」は、主任務を歩戦直協としつつ、57mm戦車砲を当面案としながら**対戦車砲または機関砲への換装可能性を予期し、将来戦では戦車が対戦車戦闘を余儀なくされる機会が多い**との認識を明記している【確認済み・JACAR「戦車装備に関する綴 昭14」、C14010847600】。

同年10月の第6回戦車研究委員会は、製作隘路、部品規格統一、発動機・装軌車両の種類整理、会社間技術情報、次期戦車、関係機関の人的拡充まで横断して扱う【確認済み・同綴】。1940年には陸軍技術本部第五部が戦車・自動車を担当し、1941年4月には陸軍機甲本部が機甲部隊教育・戦車学校等・戦車/牽引車/自動車整備の基本を所管する【確認済み】。

したがって、**ノモンハンは次世代戦車思想の発生源と固定しない**。ノモンハン相当戦闘が起きた場合は、既存の問題意識を検証し、優先順位を変えるvalidation eventである。

## 2. 砲に対する軍事思想——「最大貫徹値」から任務効果へ

### 2.1 仮置きする思想

**【条件付き推論】** 浅井世界の計算文化が戦車研究委員会・技術本部・戦車学校へ浸透した場合、主力中戦車に要求される対戦車能力は次の責任分界へ収束しやすい。

- **標準敵中戦車**：戦車部隊自身で排除可能であること。
- **特殊重装甲車**：主力中戦車単独の正面撃破を必須にせず、自走砲・対戦車砲・野砲・工兵・側撃・特殊弾を含む諸兵連合で処理。
- **陣地・火点**：榴弾能力を捨てない。

この思想は「戦車は戦車だけを狩る」ではなく、**戦車部隊が機動の自由を失わないための最小自立対戦車能力**を定義するもの。

### 2.2 評価カード

砲の採否を口径/初速だけで決めず、以下を同時評価する【設定・方法論】。

- 想定装甲に対する距離・入射角別の撃破可能性
- 発見→指示→旋回→照準→第一有効弾までの時間
- 2発目/3発目までの時間、即応弾消費後の射速
- 砲塔30°/60°転換後の射撃時間
- AP/APHE/HEの役割、榴弾炸薬量
- 完全弾重量、携行弾数、装填手疲労
- 砲身寿命、駐退故障、発砲煙/砲口炎
- 砲塔重量・リング径・旋回機構・車体重量へのintegration tax

ゆえに800m/s級が750m/s級より常に上位とはしない。**撃破距離の閾値を大きく越える場合にのみ、弾数・装填速度・重量の代価を払う**。

## 3. 1940年「次期中戦車技術試験車」shadow

> **HYPOTHETICAL SHADOW — 実在/採用を正準化しない。**

陸軍が1939–40年に先行研究を選んだ場合の、最小限の技術実証車。

| 項目 | 条件付き設計shadow |
|---|---|
| 性格 | 制式戦車ではなく技術試験車 |
| 初期重量 | 約20–22t |
| 構造/走行試験荷重 | 24–25tまでバラストで試験 |
| 砲塔環 | 内径約1.70m級（1.75mは後段候補） |
| 乗員 | 5名、3人砲塔、車長専任 |
| 砲 | 75mm完全弾を扱える空間。680m/s級で砲塔/反動/装填試験、720–750m/s級を並行研究 |
| 初期機関 | 21.7L **240hp連続**級でも車台試験可。250〜260hpは工場/試験ratingで、運用増力を継承しない |
| 次期機関 | 27L級V12、280–300hp試験→300hp連続/320hp短時間を目標 |
| 伝動 | 25t・300hp級のトルク/熱/寿命を試験 |
| 履帯 | 450mm級開始、500mm級比較 |
| 防御 | 40–50mm級から開始。60mm級は脅威入力後 |
| 電装 | **radioを設計前提**。intercom・動力粗旋回・広視界装置はそれぞれ試験gateで比較し、自動継承しない |

ここで買う「将来余裕」は量産車全車の余分な装甲ではない。**空間余裕・荷重余裕・熱余裕・トルク余裕・試験余裕**へ分解し、少数試験車に集中させる。

## 4. 27–30L級戦車用ディーゼルshadow

> **HYPOTHETICAL SHADOW — 開発着手年・完成年は未確定。**

現行21.7L V12の240hp連続/260hp短時間は、熱・冷却・最終減速機が律速。300hp超を同機関へ無理に要求せず、平均負荷を大きく上げない排気量拡大を採る。

- 約27L級（例：130×170mm級V12）なら、300hp連続/320hp短時間はチヘ機関と近いBMEP帯で狙える【物理概算】。
- 約30L級（例：135×175mm級V12）なら、330hp連続/350hp短時間を次段階候補にできる【物理概算】。
- 律速は排気弁/頭部/ピストン冠/油温/冷却fan/クランク剛性/ねじり振動/クラッチ/変速/最終減速。

**条件付き中央案**：1940研究開始を選んだ場合、27L級を第一世代、30L級を第二世代研究とする。350hp連続を1941年標準とは置かない。

## 5. 75mm砲の発展shadow

### A：680m/s級

九〇式75mm級の車載経験を使い、砲塔内の後座、砲耳、装填、弾庫、排莢、発砲煙、旋回中装填を試す。**対T-34本命ではなくintegration test gun**。

### B：720–750m/s級

八八式75mm高射砲級の既存弾道技術を参考に、戦車用の砲尾・駐退・砲架へ再設計する中間段階。**1940–41研究を選んだ場合に成立し得るが、実在年次は条件付き**。

### C：770–800m/s級

> **T-34級を標準敵中戦車と認定した場合にのみ要求が立つ。**

通常APで標準敵中戦車へ実用交戦距離を持たせる本命。L/50級を中央shadowとする。特殊ウラン合金芯弾は補助であり、弱い通常弾道を正当化する理由にしない。貫徹mmは射撃較正なしに正準化しない。

### D：810–830m/s級

1942–43以後の成熟候補。L/55級、砲塔/弾薬/砲身寿命への代価が許容される場合のみ。**自動的な到達点ではない。**

## 6. T-34/KV情報を得た場合の分岐

> **CONDITIONAL EVENT INPUT — 独ソ戦情報の入手・評価自体を世界線史実として固定しない。**

### 分岐T：T-34級を「次期標準中戦車」と認定

研究車を実戦候補へ昇格する理由が立つ。第一回重量帳簿の中央shadow：

- 設計戦闘重量 約23–24t、成長上限24–25t級
- 75mm L/50級、770–800m/s級
- 砲塔環 1.70–1.75m級
- 前面主要部55–60mm級、側面30–35mm級
- 27L級 300hp連続/320hp短時間
- 500mm級履帯
- 5名・3人砲塔、全車無線。**intercom・動力粗旋回・広視界装置は別gate**で、脅威/乗員試験/旋回時間が要求した場合のみ採用

この包絡は**成立可能性のshadow**であって、1942年に実車が存在するとの主張ではない。

### 分岐K：KV級を「特殊重装甲脅威」と認定

主力中戦車の要求基準にはしない。通常75mmでの正面撃破を必須にすると重量・砲塔・弾数・輸送・回収の代価が急増するため、75mm自走砲、牽引対戦車砲、野砲、側撃、工兵、特殊弾へ責任分配する。

### 分岐K-heavy：KV級を主力中戦車自身の正面撃破基準にする

> **高仮定枝。現段階では非推奨shadow。**

30t超やさらに大型砲へ押し上げる可能性がある。これを採るには「重装甲車が例外でなく多数の標準脅威になる」という追加情報が必要。単にKVが存在するだけでは開かない。

## 7. 1943–45成熟shadow

> **HYPOTHETICAL / NOT CURRENT A**

T-34/M4級との継続交戦、実射試験、25t級車体の耐久試験、27L機関の成熟がすべて成立した場合に限る。

- 25–27t級
- 前面65–70mm級、側面35–40mm級
- 75mm L/55級・810–830m/s級候補
- 30L級330hp連続/350hp短時間候補
- 砲塔駆動、車長視察、照準器、被弾後生残性、整備/回収を重点改善

**「1945年の最終戦車はこれ」とは固定しない。** 戦訓入力が違えば20t級遠征中戦車、25t級対戦車中戦車、SPG/対戦車砲優先など別枝が成立する。

## 8. 兵站重量規則の更新

従来の15–19tは**全戦域で既存船舶・鉄道・橋梁・舟艇との摩擦が比較的小さい量産主力帯**と再定義する。物理上・制度上の将来戦車上限ではない。

- 15–19t：全戦域向け主力帯。
- 20–27t：満州・大陸の特定正面など、輸送/橋梁/回収を選ぶ**戦域限定中戦車帯**。
- 30t級：さらに配備先・回収・橋梁・揚陸を大きく選ぶ重量帯。

したがって「日本だから20t超を研究しない」も、「300hpがあるから25tを全戦域主力にする」も禁止する。

## 9. 開発史上のgate

1. **1939問題認識gate**：標準敵中戦車を自力排除する責任を主力中戦車へ持たせるか。
2. **1940研究予算gate**：20–22t技術試験車・1.70m環・27L機関研究へ少数資源を割くか。
3. **情報gate**：敵新型を標準脅威と認定できるだけの情報があるか。
4. **砲gate**：通常APで必要な撃破距離を得るため750m/s級で足りるか、770–800m/s級が必要か。
5. **重量gate**：24–25t化の戦術利益が輸送・回収・生産代価を上回るか。
6. **量産gate**：試験成功と戦況要求を満たして初めて制式/量産へ移る。
