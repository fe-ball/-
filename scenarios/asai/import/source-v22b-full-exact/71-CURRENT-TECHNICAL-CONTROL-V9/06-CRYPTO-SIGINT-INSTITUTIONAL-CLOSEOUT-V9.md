# CRYPTO / SIGINT INSTITUTIONAL CLOSEOUT — V9 TECHCLOSE2

## Status

**1939 CENTRAL TECHNICAL/INSTITUTIONAL BASELINE: CLOSED.**

**NAMED TARGET-SYSTEM BREAKS, COVERAGE AND OPERATIONAL EXPLOITATION: EVENT/NETWORK GATED, NOT A GLOBAL TECHNICAL OPEN.**

This file applies the cheat-distance guard to cryptography. The cryptologic toolchain remains in Navy hands; the reincarnator is not silently inserted into the code room.

## 1. Ownership and distance

The normal 1939 relationship is:

`Asai electromechanical/computation supplier (CD1 -> CD2 interface) -> Navy secure technical organization (CD3) -> stations/ships/operators (CD4)`

The Navy controls cipher design, keys, traffic, target selection, language material and cryptanalytic conclusions. Asai maintenance/support may work on sanitized equipment with key material removed.

## 2. What is institutionally closed by 1939

Selected central Navy cryptographic/communications organizations may possess and routinely use:

- reliable special printing/switching/electromechanical equipment with improved contacts, power, synchronization and shipboard durability;
- secure customer-side calculation rooms using card/relay machinery rather than exporting sensitive data to Asai;
- card-assisted key-generation/check/distribution bookkeeping;
- machine-assisted classification, frequency counts, comparison, coincidence counting and candidate-list generation;
- local cryptanalytic records, reusable procedures and trained personnel that remain Navy assets;
- opportunistic red-team testing of own systems as an engineering practice.

These are no longer contingent on Asai personally attending each problem. They are institutional capabilities.

## 3. What the cheat does not provide

Asai's principal expertise is not operational cryptanalysis. The worldline therefore does **not** assume that he remembers or reconstructs the exact solution to every historical cipher, identifies unknown key material, supplies native-language cribs, or predicts an enemy operator mistake.

Even at CD0, a generic later-known concept such as statistical search or improved machine architecture is different from a target-specific break.

## 4. Operational chain

For a named enemy network/system/date, close the following locally:

`collection/continuity -> traffic analysis -> target-specific cryptanalytic insight -> key/material/crib access -> machine search/counting -> system/key recovery -> decrypt volume/latency -> language/translation -> intelligence fusion -> secure dissemination -> operational use`

The 1939 baseline gives the Navy a better **mechanized middle** of this chain and a lower administrative burden. It does not make the first, insight, or exploitation stages automatic.

## 5. Canonical consequence

The global question "does Japan have stronger computation-supported cryptologic capacity than the historical organization would have had without this industrial branch?" is **CLOSED: YES, institutionally and mechanically**.

The question "is named enemy cipher X broken by date Y, with Z% traffic readable and exploited?" is **not a technical baseline question**. It belongs in a target/date operational ledger when the scenario reaches it.

This distinction removes the broad TECH-009 open without creating automatic intelligence victories.

## 6. Own-cipher consequence

Own cipher-machine reliability and key administration may improve. More frequent or better-controlled key changes become cheaper administratively. This does not guarantee cryptographic strength: algorithmic weakness, procedure, operator error, captured material and compromised keys remain separate.
