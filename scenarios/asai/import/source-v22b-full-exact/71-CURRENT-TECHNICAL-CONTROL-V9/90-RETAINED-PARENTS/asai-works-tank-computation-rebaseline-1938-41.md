# 九七式チハ→新砲塔47mm→一式中戦車チヘ 再基底化 1935–41（v27正本）

> **v27 supersession**：詳細な上流再監査は `asai-works-tank-early-computation-materials-rebaseline-1928-41.md` を優先する。本稿はチハ→チヘの橋渡し。v24の「新砲塔チハ5名3人砲塔」「チヘ240/260hp」「400mm履帯」「電動粗旋回」「全乗員intercom標準」はcurrentから撤回した。

## 1. チハ

- 陸軍のチニ/チハ競争と三菱高性能案が発生源。浅井は要求主務ではない。
- 1937に170hp自然吸気比較車と200hp低圧過給車を比較。
- 1938量産中央：15.3–15.6t、**200hp連続/220hp短時間**、38–40km/h、57mm、25mm、4名二人砲塔。
- 220–240hp級は1938–39の強化車台試験で、量産240hpチハではない。

## 2. 47mm新砲塔チハ

- 1938研究→1939試験→1940技術成立級。
- 15.8–16.0t、200/220hp、47mm 800–820m/s級。
- **4名・二人砲塔、車長兼装填、手動旋回。**
- 既存チハを最小変更で対戦車火力更新する型。25mm級防御を基本維持。
- 無線搭載余地/照準品質/砲塔荷重計算は改善するが、未来の3人砲塔を押し込まない。

## 3. 一式中戦車チヘ

- 日本側の次期戦車研究・チホ・新砲塔チハの人間系ボトルネックから発生。
- 開発開始1940前後、技術成立1941後半～42初頭候補。実採用/生産はHISTORY。
- **約17.5t、240hp連続、高地flat-rating、5名3人砲塔、47mm、車体主前面50mm、側面25mm級。**
- **260hp operational boostはDROP**。250–260hpは試験rating。
- **330mm級履帯**を基本。400mmは後期要求が出た場合のみ。
- **砲塔旋回手動**。電動粗旋回は成立条件からDROP。
- radio全車設計前提。全乗員voice intercomは初期標準にしない。
- cupola/単純視察器/4倍級直接照準。計算は公差・像質・reticle・零点再現性へ効く。

## 4. 浅井の位置

浅井は戦車メーカーでも陸軍技術本部でもない。供給するのは過給器、歯車/軸/摩擦材等の材料、熱処理/QC、重量/伝動/冷却/砲塔/光学計算。要求と採用判断は陸軍・三菱側。

## 5. CLOSED / HISTORY BOUNDARY

技術側は上記仕様でclosed。実生産台数、配備、実戦、1942+次世代車は別会計。1942+の技術shadowは `asai-works-tank-next-generation-conditional-1939-45.md` を維持する。
