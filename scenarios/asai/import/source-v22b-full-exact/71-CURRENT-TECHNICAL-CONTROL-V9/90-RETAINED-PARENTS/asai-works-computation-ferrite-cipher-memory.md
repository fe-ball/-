# フェライト・暗号・磁気記録／記憶——計算機史の磁気枝と官需接続の正本

> **2026-08-22 正本統合**：本稿は `computation-2026-08-22/02-ferrite-cipher-magnetic-memory.md` を正本へ統合したもの。
TDKは史実どおり齋藤憲三中心で1935年創業し、浅井は買収者ではなく**最初期大口顧客＋測定・用途スポンサー**とする。暗号機の信頼性改善とカード／計算機による暗号解析は同じ電気機械基盤から分岐するが、方式・鍵・実通信は厳密に区画化する。フェライト発見から成熟コアRAMへ直行させず、HF磁心→磁気スイッチ→磁気記録／ドラム→小容量状態保持→戦後寄りのX-YコアRAMという階段を守る。

## フェライト

史実では1930年に加藤与五郎・武井武がフェライトを発見。1932年には三菱電機との企業共同研究が成立しており、企業が大学へ人・費用・器具を入れ、試作品を外へ持ち出す形は当時すでに可能。

浅井は1931–32頃から試料評価・高周波測定・ロット管理・耐振/耐湿を手伝う。TDK前身は史実通り齋藤憲三が1935年創業するのを基本とし、浅井は買収者でなく**最初期大口顧客＋測定/用途スポンサー**になる。

加速は研究・試用で1–2年、工業化は半年～1年程度を目安。金だけで焼結科学・用途・曝露を飛ばさない。

## 暗号

入口は海軍向け特殊印字・切替・電気機械の普通の官需。取引事実は社外秘程度、方式・鍵・実通信は厳密に区画化。出張保守員は事前身辺調査・担当機種限定・作業時に鍵材料撤去。

作る側では接点・電源・印字同期・艦載耐久を改善。解く側ではカード分類、頻度、比較、一致計数、候補探索機を供給。

両方が育つ結果、1930年代半ばには「新型解析機が出たら自軍現用暗号も模擬攻撃する」という赤チーム的試験が、制度改革というより機会的な技術慣行として発生してよい。鍵生成・検査・配布管理もカード化され、更新頻度を上げる運用コストが下がる。

## 磁気記憶

フェライトを知ったから即コアRAMにはしない。

1. 高周波磁心、チョーク、ノイズ抑制
2. 飽和リアクトル/磁気スイッチ、状態保持への関心
3. 1936以降の武井のフェライト円盤/円筒磁気記録研究を中断せず継続
4. Tauschek型の磁気ドラム概念と接続し、1938–40に数万～数十万bit級の作業記憶
5. 1940年代前半に専用配線の小容量磁気レジスタ/シフト的状態保持
6. 本格X-YコアRAMは戦後寄り。1940年代後半に史実より早い実用が射程

カードは長期保存・交換、ドラムは大容量作業記憶、磁心は高速小容量という自然な階層になる。

コア配線の量産では、織機・巻線・カード穿孔で育った女性作業者と、コア保持治具・張力・通線検査・半自動「織機」化が浅井の製造上の強みになる。
