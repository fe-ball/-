# 計算能力の再伝播 1923–45 —— engine/metallurgy/aviation method authority

> **v38 authority.** 計算機hardwareの詳細年表は既存computation parentsを継承する。本稿は、その能力が本職のengine/metallurgy/aviationへ何を変えるかを固定する。性能ボーナス表ではない。

## 1. 主人公と計算機屋

主人公は計算機そのものを主戦場にしない。engine側から大量反復、翌朝返却、標準データ、再利用可能な計算手順を要求し、数学・統計・カード・電話交換・電機・暗号・精密機械の人材を集める。現地計算機技術者がmachineを発明・構成・運用し、主人公は需要、資金、問題選択、提案選択、限定的な強いヒントを供給する。

## 2. 方法論の転換

- **1923–28**: arithmetic / transcription / recalculationを設計者から外す。主利得は人日、検算、比較条件数、記録再利用。
- **1929–34**: 計算手順・algorithmを機械へ移す段階。parameter sweep、反復解、粗map、多変数比較が日常化し始める。
- **1935–37 / U4**: `coarse search -> priority physical test -> recalculation -> independent check` が設計組織の標準になる。これは単なる高速計算ではなく設計方法の転換。
- **1938–40**: electronic/relay/drumでL3のmatching、transient、thermal network、rotordynamics等のcase量が増える。
- **1941+ technical capability**: reduced-order simulation、反復同定、より大きなdata loopへ進む。ただしmodern CFD / future computerを仮定しない。

## 3. GTへの再伝播

- E1–E4: v38を理由にPR/TIT/eta/lifeを自動上積みしない。未来知識と試験・計算の因果を明示する。
- **E5**: U4組織化の転換点として扱う。設計候補を多く保持したまま、重点rigへ資源を振り、失敗を次世代へ戻す能力が大きくなる。
- **E6**: electronic computationがL3のcompressor/turbine matching、start/accel、thermal、rotordynamicsへ本格的に効く最初の大きな段階。
- E7/E8: 多年のmap/data/methodを回収できるが、surge実境界、cooling加工、metal temperature、creep/oxidation/thermal fatigue、yield/enduranceはL4 physical gate。
- E9: two-spool / high-PR / high-TIT / full-core transientでcoupling taxを新たに払う。

## 4. 航空への再伝播

H->C->M->E->P->I->Aは維持する。Cは問題別O/Gで読む。blanket speed/weight/range bonusは禁止する。

主人公の最も強い航空寄与はengine/airframe interfaceである：inlet recovery、cooling drag、exhaust、propeller/reduction、altitude engine map、CG/mount、vibration、instrumentation。airfoil、structure、flutter、stability/controlは機体専門家と風洞/構造/flight testが物理gateを保持する。

## 5. 将来の計算能力を見込んだ前払い

主人公は計算機が速くなってからデータを集めるのではない。早期から試験番号、部品版、heat/lot、加工条件、計器serial、校正、run条件を標準化し、後年のmodel identification / correlationへ食わせられるarchiveを作る。これは計算能力そのものより強い長期配当を持つ。

## 6. 禁止

- `computer exists -> +x% performance`
- `O=x% -> product x% better`
- computationによるcreep/fatigue/corrosion実時間の消去
- future-CAD benchmarkをfuture materials/factory benchmarkへすり替える
- post-1941 technical capabilityからactual procurement/OOB/combatを自動生成する
