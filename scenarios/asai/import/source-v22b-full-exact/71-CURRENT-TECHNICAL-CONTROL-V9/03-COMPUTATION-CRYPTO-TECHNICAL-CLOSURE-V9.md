## 2. What computation changes

Computation is not a generic `+X% performance` card. Credit it only through a named causal channel:

1. larger design-space search and trade studies;
2. faster test-data reduction and independent checking;
3. separation of error sources / tolerances / failure modes;
4. better subsystem integration and schedule matching;
5. QC, repeatability, maintenance and redesign turnaround.

It cannot erase material limits, fatigue/creep time, qualification hours, manufacturing capacity, training, procurement or service adoption. Later local V8/V9 engine, airframe, vehicle, naval and weapon files outrank generic examples in older computation parents.

## 3. Naval/basic-design implication

By the late 1930s, computation is a design infrastructure for weight/trim, multi-state stability, shaft torsion/vibration, propeller and machinery matching, structural case comparison and test-data reduction. The effect is chiefly to keep more alternatives alive, find systematic errors faster and converge repairs/redesigns sooner.

Tomozuru/Fourth Fleet are not erased: if the stability/strength criterion or input model is wrong, a faster calculator reproduces the wrong model faster. Post-event reconstruction is where the large advantage appears.

## 5. Operational cryptographic strength STOP LINE

Do not collapse the following chain into `better computer -> reads enemy cipher`:

`intercept collection -> traffic metadata/continuity -> traffic analysis -> cryptanalytic insight/cribs/weakness -> machine search/counting -> key/system recovery -> decrypt throughput -> language/translation -> intelligence fusion -> secure/timely dissemination -> operational exploitation`

A stronger machine can improve only some stages. A named system/date/network requires a local ledger before decrypt success, coverage, latency or operational effect is asserted.

Likewise, stronger own cipher-machine engineering and key administration do not imply invulnerability; procedure, operator error, captured material and cryptanalytic weakness remain independent.
