# 1943Q1 PISTON-AIRFRAME TECHNICAL SNAPSHOT — V8 AIRPOWER4

## Purpose
Compact handoff state at the forward edge that can be discussed without selecting a 1943+ war branch.
This is **not** a combat-history clock advance. Current revalidated combat checkpoint remains 1939-04-20 24:00.

## Propulsion / propeller state
- Homare 10/12: serial-reproducible mature family path (`EA-S`), subject to actual production allocation.
- Homare 20/21: qualified good-engine capability (`EA-Q`) with serial reproducibility being established; good-engine high-alt realization near 6.1 km centered ~1,640-1,650 hp.
- Ha-43 base engine: selected flight-grade `EA-D` engines plausible; `EA-Q/EA-S` not branch-neutrally closed.
- 3.3-3.45 m four-blade high-power propeller: `PA-Q`, selected serial families can be `PA-S`.
- 3.6 m / 2,000-2,200 hp low-rpm propeller: development/selected qualification hardware `PA-D/PA-Q`; mass serial priority not fixed.
- hydraulic governor is the preferred V8 high-power combat-aircraft path.
- fan cooling remains aircraft-specific; Ha-43 does not automatically require a fan.

## Aircraft state
### J2M
High-power radial fighter integration experience already exists. A J2M2-class 3.3 m hydraulic-four-blade/higher-power Kasei installation can have meaningful flight-test experience by this point.

### B7A
Homare + ~3.45 m four-blade + carrier-aircraft integration has been flying since roughly 1942Q2 on the central path. The test program is a major source of Homare installation data. Production outcome remains open.

### N1K1-J
Central V8 path has the first land-fighter prototype flying during 1942Q4. By 1943Q1 the long/telescoping gear, mid-wing packaging and cooling characteristics are real measured aircraft issues rather than paper guesses.

### N1K2-equivalent
A low-wing/short-gear redesign can be formally active by 1943Q1 if the Navy continues the program. First flight remains a later conditional result.

### Reppu-equivalent
1941 persistent successor pre-design is available. If a 1942 carrier-fighter requirement exists in the replayed worldline, Homare detailed design/prototype manufacture can be underway and Ha-43 static integration can be underway by 1943Q1. The requirement itself, engine selection and flight dates are not preselected.

### Army / other programs
Homare/four-blade technology availability may enable an equivalent 1942 Army high-performance fighter or other receivers, but their requirements and priorities remain combat-branch dependent.

## What this snapshot means for replay
When combat history is replayed into 1942-43, the game does **not** ask whether Japan can invent a high-power four-blade propeller or whether a good Homare can exist.
Those engineering questions are already closed within stated availability limits.

The replay must instead decide:
- what operational requirements are generated;
- which programs are authorized;
- which engines/propellers/factories are allocated;
- whether resource/fuel/oil/industrial conditions preserve the qualified technical state;
- which airframe-specific defects delay service introduction.

That keeps technological preparation separate from war-derived procurement outcomes.
