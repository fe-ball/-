## 1. Historical anchor
High-authority Smithsonian records place Mitsubishi Ha-43 development beginning in 1941 and describe a 41.7 L, 18-cylinder, two-row radial rated about 2,200 hp at 2,900 rpm, approximately 1.23 m diameter and ~980 kg in the referenced Ha-211 Ru artifact.

A detailed secondary synthesis based on Mitsubishi/Japanese engine histories gives:
- work underway mid-1941;
- design completed October 1941;
- first engine completed February 1942;
- operational testing not passed until June 1943 in reference history;
- development slowed after the Navy selected Homare for multiple high-power fighter programs and because some high-altitude variants added remote-turbo development problems.

The engine was therefore not physically impossible. It was an ambitious, under-prioritized and incompletely matured program.

## 2. Severity comparison with Homare — CLOSED
Approximate base-engine comparison:

| item | Homare 21 class | Ha-43-11 class |
|---|---:|---:|
| cylinders | 18 | 18 |
| bore × stroke | 130 × 150 mm | 140 × 150 mm |
| displacement | ~35.9 L | ~41.6–41.7 L |
| max-power rpm | ~3,000 | ~2,900 |
| takeoff power | ~2,000 hp | ~2,200 hp |
| mean piston speed | ~15.0 m/s | ~14.5 m/s |
| approximate BMEP at headline takeoff power | ~16.6 bar | ~16.3 bar |
| diameter | ~1.18 m | ~1.23 m |
| reference mass | ~830 kg | ~980 kg |

Interpretation:
- Ha-43 obtains much of its extra power from larger displacement rather than a radically higher BMEP;
- in pure cylinder-pressure/rpm severity it is not automatically more extreme than Homare;
- it pays instead in size, mass, cooling demand, large-bore head/valve thermal problems and later availability.

This is why a technically healthy Ha-43 can be a strong growth engine without making the earlier/lighter Homare irrational.

## 3. V8 program start — CLOSED
Existing V8 engine-team canon remains:
- `1940Q3`: larger Mitsubishi 18-cylinder pre-study may begin;
- `1941Q1`: formal project start;
- `late 1941–early 1942`: first hardware window.

This is modestly ahead/deeper than reference history but not a one-year miracle.

Why pre-study may begin in 1940Q3:
- Mitsubishi already owns the Kinsei lineage and 140 × 150 mm cylinder experience;
- Homare makes the compact 18-cylinder fighter-engine requirement visible as an industrial trend;
- Asai high-output combustion/supercharging/bearing/test methods are already circulating through controlled military/industrial channels;
- four-blade/high-power propeller rig work exists as an enabling system program.

Pre-study is not formal mass development and does not produce an aircraft engine in 1940.

## 4. What V8 transfers to Mitsubishi
The same generic shelf that helps Nakajima is available, but Mitsubishi must do its own 18-cylinder integration.

Transferable:
- knock/fuel/ADI mapping method;
- high-load bearing/surface/precision process;
- corrected supercharger maps;
- fuel-metering/injection precision methods;
- high-altitude oil-system tests;
- dynamic/torsional instrumentation;
- process-control, gauges and lot traceability;
- mission-selective Asai exhaust-turbo hardware/control knowledge.

Not transferable as finished answers:
- Ha-43 crankshaft/master-rod dynamics;
- 140 mm-bore cylinder-head cooling;
- Ha-43 intake runner distribution;
- cooling-fan requirement for a specific installation;
- propeller reduction/airframe match;
- exact fuel-injection pump/distributor behavior;
- remote-turbo exhaust/duct/heat installation.

## 5. Ordinary Ha-43 and turbo Ha-43 must be separated — CLOSED
Later discussion must not burden every Ha-43 with the schedule of a remote turbosupercharger.

### Base fighter-engine branch
Use a conventional mechanically driven supercharger path for the ordinary Ha-43-11/MK9A-class fighter engine.
This is the relevant comparison to Homare Reppu-type applications.

### `Ru` / remote-turbo branch
High-altitude variants add:
- turbine wheel/hot-side material;
- exhaust collectors;
- wastegate/control;
- ducting/intercooling decisions;
- fire/heat management;
- aircraft nacelle/fuselage integration.

Failure/delay of the turbo branch does **not** automatically prove the base mechanically supercharged Ha-43 is equally delayed.

# 6. V8 central timeline through 1943Q1

## 1940Q3 — pre-study
- 18-cylinder Kinsei-bore architecture comparison;
- diameter/mass/cooling target study;
- 2,100–2,200 hp class target analysis;
- bearing/crank/reduction and four-blade-propeller interface studies;
- no complete engine.

## 1940Q4
- preliminary cylinder/head cooling work;
- supercharger and fuel-system architecture comparisons;
- production feasibility and supplier capacity review.

## 1941Q1 — formal design start
- program becomes formal under current V8 central timeline;
- target remains ~2,200 hp class, not inflated above history;
- use multi-fuel/ADI and oil-class qualification architecture from the start;
- explicit separation of base mechanical-supercharger engine and optional remote-turbo research branch.

## 1941Q2
- cylinder/head thermal rigs;
- injection/metering rigs;
- bearing/crank component work;
- supercharger corrected maps;
- reduction gear / propeller torque work;
- production CTQ planning.

## 1941Q3
- detailed design largely converged;
- critical castings/forgings and long-lead hardware underway;
- complete-engine instrumentation/test plan frozen;
- no aircraft availability yet.

## 1941Q4
- design freeze / first-engine manufacture window.
Reference history completed design in October 1941; V8 central case may reach equivalent maturity modestly earlier in Q4, not enough to create a 1941 service engine.

## 1942Q1 — first running
Reference first-engine completion in February 1942 provides the hard anchor.
V8 central range: **January–February 1942 first complete engine**, with March still plausible if supplier integration slips.

Expected early problems remain:
- large-bore head cooling;
- 18-cylinder mixture/injection balance;
- crank/master-rod vibration;
- reduction/propeller interaction;
- oil distribution and return;
- accessory/fuel-distributor reliability.

The engine may show ~2,000+ hp development power before it is reliable enough for flight.

## 1942Q2
- endurance and full fuel/oil map closure;
- ~2,200 hp takeoff-class development point is physically plausible without raising BMEP beyond Homare-class severity;
- base-engine cooling and vibration work dominates;
- remote-turbo work proceeds independently and must not hold the base engine hostage.

`EA-D` for an aircraft should not yet be assumed at the start of the quarter.
Late-Q2/early-Q3 development-flight availability is possible only if the specific installation accepts manufacturer-intensive support.

## 1942Q3
- base-engine reliability/production-intent revisions;
- first military/customer engines may exist;
- service qualification still incomplete;
- if an aircraft requirement selects Ha-43, a flight-test installation can now be prepared without waiting for engine invention.

Important branch guard:
Historical Navy selection of Homare in September 1942 slowed Ha-43. V8 must not assume that same procurement decision before the carrier-fighter requirement is replayed.
Therefore **program priority after 1942Q3 is a branch variable**, while the technical engine state achieved to that point is preserved.

## 1942Q4
Branch-neutral minimum:
- several complete engines/test configurations can exist;
- the base mechanical-supercharger configuration has accumulated meaningful endurance/cooling/vibration data;
- production-process definition exists at prototype/pilot level;
- turbo branch can still lag.

Central V8 possibility if funding remains adequate:
- `EA-D = YES` for a priority prototype aircraft late 1942 to 1943Q1;
- `EA-Q = NO/EMERGING`, not presumed service-ready;
- `EA-S = NO` for volume production.

## 1943Q1 — pre-branch checkpoint
This is as far as Ha-43 should be closed before combat/procurement play decides priorities.

Canonizable:
- Ha-43 is a running 2,200 hp-class development engine;
- a base mechanically supercharged flight-grade engine can plausibly be available to a selected prototype program;
- engine-side design is no longer hypothetical;
- cooling/vibration/service qualification remains less mature than V8 Homare;
- remote-turbo/high-altitude versions remain a separate, harder development track.

Not canonizable:
- full service qualification date;
- monthly production;
- whether Navy/Army prioritize it;
- which fighter receives the first flight-grade engines;
- fleet reliability.

# 7. Branch-neutral engine availability comparison at 1943Q1

| engine | technical state at 1943Q1 | aircraft meaning |
|---|---|---|
| Homare 10/12 | `EA-S` established under intact production conditions | ordinary production/service aircraft can use it subject to installation and supply |
| Homare 20/21 | `EA-Q` good engines available; `EA-S` emerging/limited by exact model | priority new prototype/service-trial aircraft may use real ~2,000 hp-class engines |
| Ha-43 base | `EA-D` plausible for selected prototype; `EA-Q` not assumed | a design can be built/flown around it if procurement funds the installation |
| Ha-43 turbo/Ru | development branch | dedicated high-altitude program only; not a generic fighter-engine availability claim |

This relation is intentionally asymmetric: Homare is earlier and more production-ready; Ha-43 has more growth margin.

# 8. Consequence for later fighter work
At the point where the 1942 carrier-fighter requirement is replayed, the correct question is not:

`Which engine is objectively better?`

It is:

`Which engine state is available at requirement freeze, prototype manufacture, first flight and production release?`

This makes a rational parallel branch possible:
- Homare: earlier/lighter/lower integration risk;
- Ha-43: later/heavier but ~10% more displacement/power and more growth margin.

No procurement outcome is closed here.
