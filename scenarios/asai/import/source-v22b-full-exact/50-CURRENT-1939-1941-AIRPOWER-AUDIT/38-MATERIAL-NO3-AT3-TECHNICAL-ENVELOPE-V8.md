# MATERIAL NO.3 / AT-3 HEAVY TRANSPORT TECHNICAL ENVELOPE — V8 AIRPOWER11

> Technical design shadow only. It closes a physically coherent target for the practical Material No.3 aircraft without awarding a future first flight, Army procurement, tanker fleet or combat effect.

## 1. Central architecture

- high wing;
- four E6-M-T turboprops;
- tricycle landing gear with multiple low-pressure main wheels;
- large non-pressurized cargo box;
- rear lower ramp plus upper/side cargo-door architecture as required by loading study;
- strong longitudinal floor load tracks, numerous tiedowns and removable rollers/carts;
- ramp loads supported into the ground rather than treating the open ramp as an unsupported heavy cantilever;
- large simple empennage and conservative handling; speed is secondary to cargo usability and structural/service data.

## 2. Propulsion

Use current E6-M-T semantics rather than an invented new heavy-transport engine:

- takeoff/normal high-power coordinate around **2,050-2,100 shp per engine** where the current E6-M shaft package permits;
- transport/continuous center around **1,850-1,870 shp per engine**;
- four-engine takeoff aggregate roughly **8,200-8,400 shp**;
- four-engine continuous aggregate roughly **7,400-7,480 shp**.

Large constant-speed/feathering four-blade propellers in roughly the **3.6-3.9 m** design band are natural for a high-wing transport and inherit the AIRPOWER4 high-power propeller school. Exact diameter/model remains a local installation result; reverse pitch is not required for the first-generation runway claim.

## 3. Weight / cargo coordinate

Retain the old shadow as a useful current technical target:

| item | current technical center |
|---|---:|
| normal MTOW | **52-55 t** |
| structural/short overload | **58-60 t** candidate |
| operating empty | **28-30 t** target |
| standard cargo | **13-15 t** |
| short-range cargo | **17-18 t** candidate |
| wing area | **235-245 m2**, center ~240 |
| cargo box | about **13.2 x 3.25 x 3.0 m** |
| crew | mission-dependent multi-crew; exact cockpit crew not yet closed |

At 55 t / 240 m2, wing loading is about **229 kg/m2**. With a mature high-lift system around CLmax 2.2-2.5, calculated stall speed is roughly **147-138 km/h**, giving a maximum-weight approach-planning band around **180-190 km/h** before detailed handling margins. These are design calculations, not measured flight results.

## 4. Performance shadow

A coherent first-generation target is:

- economic/cruise roughly **330-360 km/h**;
- maximum-speed neighborhood roughly **390-415 km/h** depending drag/propulsive installation;
- **13-15 t practical range ~2,000-2,300 km**;
- **10-12 t practical range ~2,800-3,200 km** candidate;
- prepared/compacted-runway takeoff/landing design class roughly **1,000-1,200 m**, not extreme STOL.

The runway goal is bought by wing area, high lift, four large propellers, brakes and low-pressure multi-wheel gear. Do not assume reverse pitch if it has not been locally qualified.

## 5. What makes it useful before military adoption

The practical cargo mission includes:

- complete replacement aircraft engines / turbine modules and return of failed units;
- vehicles/tractors/engineering machines that fit the cargo box and floor limits;
- precision machinery, radios, optical/electrical equipment and urgent industrial cargo;
- medical/litter and personnel configurations;
- large spares that lose value when dismantled for ordinary transport.

A low-rate fleet can therefore generate real service cycles and material/repair data without requiring mass military procurement.

## 6. Conditional later modules

Technically plausible but not current historical facts:

- paratroop / medical kit;
- removable tanker kit after the separate air-to-air transfer system is mature;
- selected later CFRP components as Series I-III allowables become available;
- military Ki-92 evaluation identity;
- low-rate first production lot.

Do not make the cargo fuselage automatically become a bomber; a heavy combat aircraft would require a different mission fuselage even if wing/power/gear/tooling are shared.

## 7. Relationship to the materials ladder

Material No.3 is where three streams meet without being confused:

1. **Material No.1/2** supply bonded/sandwich/process and structural-test practice;
2. **CFRP I-IV** supplies increasingly capable carbon-composite blocks when qualified;
3. **large transport operation** supplies scale, repeated cargo/door/floor/gear cycles, weather and field-repair data.

This is why the old memory of a 'very large transport made possible by material gain' and the material-test-aircraft lineage both point to the same Material No.3.
