# 中島AT-3 / Ki-92 大型輸送機 —— 55t級材料・輸送・給油プラットフォーム

> **status: TECHNICAL SHADOW CLOSED / DEVELOPMENT-PROCUREMENT CONDITIONAL**
>
> 本稿は技術的に成立する第一世代55t級大型輸送機の設計包絡を閉じる。実際の陸軍発注、初飛行、量産数、戦場使用は固定しない。

## 1. 発生理由

発生は「GFRPを使いたいから50–60t機を作る」ではない。1939頃の大型材料・接着構造研究から、**高価値10–15t級貨物を分解せず直接運ぶ**市場/軍事ニッチが見えることが起点。

浅井が1–2機級研究機を自費・共同負担し、中島が大型機製造を担当。陸軍・政府は開発支援/購入保証を条件付きで付ける。民間航空会社へのlease/共同運航で貨物市場と乗員・整備網を育てる形が自然。

## 2. 主体

- 完成機メーカー：**中島**。
- 浅井：材料、計算、E6、system integration/test。
- 陸軍：Ki-92評価番号候補。
- 民間名：**Nakajima AT-3**。
- 1943採用が起きた場合の年式名候補：**三式大型輸送機**。

## 3. 機体

- 高翼、四発、前輪式。
- 4×E6-M-T derated。
- 多輪主脚、粗地/低接地圧寄り。
- rear upper door＋lower ramp。
- cargo box 約**13.2×3.25×3.0m**。
- floorは4本程度の強いlongitudinal load track＋多数tie-down＋removable roller/cart。
- rampはvehicle loadを地面支柱で受け、自由片持ちにしない。
- first generationは非与圧。primary CFRPを使わない。

## 4. 重量・性能shadow

| 項目 | 値 |
|---|---:|
| normal MTOW | **52–55t** |
| structural/short overload | **58–60t** |
| operating empty | **28–30t** |
| standard cargo | **13–15t** |
| short-range cargo | **17–18t** |
| wing area | **235–245m²、中央240** |
| cruise | **330–360km/h** |
| 15t practical range | **2,000–2,300km** |
| 10–12t candidate | **2,800–3,200km** |

short-field能力は500–700m級の極端STOLではなく、**1,000–1,200m級prepared/compacted runway**を実用目標とする。逆ピッチは使わず、Fowler/前縁装置、多輪低圧脚、通常brake、prop dragで成立させる。

## 5. 人員輸送

- paratroop **50–60名級**。rear side doorsを左右対称に置き、投下時は170–185km/h級、partial flap、low AoAの安定水平飛行。
- litter patient **40–50名級候補**。
- 大型vehicleはparadropでなく**airland**を本線。空挺作戦での短距離着陸価値は、占領飛行場へ重装備をすぐ降ろすこと。

## 6. 開発shadow

- **1939 H2**：材料研究からconcept。軍の15t要求が先にあるわけではない。
- **1940**：full-scale floor/door/rear fuselage/gear test。bonded metal＋hemp/paper sandwich、GFRPはcoupon/local。
- **1940 H2**：中島参加。DC-4E/G5N級大型機データを利用。
- **1941 H1**：formal design。52–55t/15t/high-wing/rear-rampをfreeze候補。
- **1941 H2**：detail/tooling。
- **1942 H1**：full-size wing/center fuselage static、gear drop/brake/ramp、E6四発統合。
- **1942 late**：X1 first-flight candidate、48–50tから開始。
- **1943 H1**：X2 52–55t、13–15t、short-field/CG/E6/secondary GFRP。
- **1943 mid-late**：X3 paratroop/medical/cargo/dual-use test。
- **1943 late**：4–6機first lotは条件付き。
- **1944**：8–12機initial operational groupは条件付き。

これらは**development shadow**であり、実在史ではない。

## 7. 生産

この機体は低率生産でも意味がある。

- 10–20機でも戦略輸送能力を作れる。
- 通常1機/月級。
- 3–4機/月超は新工場/transferを要し、連山等大型軍用機を圧迫する。

軍がcapabilityを買い、民間運航が一部償却・乗員/整備/市場形成を担うのが自然。

## 8. 空中給油系列

大型タンカーを深山/連山から恒常的に抜かない。

1. **1939–40 AT-2/L1N1級試験**：約1t transfer、hose/coupling/formation。
2. **1941–42 L5Si tanker kit**：約4.2–4.6t transferable、最初のpractical top-up。
3. **1942–43 深山 tanker**：必要なら一回限りのheavy-transfer experiment。標準ではない。
4. **1943–44 Ki-92 tanker kit**：**12–14t standard transferable**。1機で4–5tを2–3 receiversへ。

cargo/tanker dual-role。ground refueling「flying gas station」も価値がある。初期空中方式は改良loop-hose。modern probe/drogueを1943標準とはしない。

## 9. 大型重任務派生

同じ翼・power/gear/fuel/tail/toolingを使う50–60t級**大型重任務機**は成立するが、輸送胴体そのものを爆撃機にしない。新しい爆撃/哨戒胴体を作る。

- E6 first generation max **390–425km/h級**。
- E7で**430–460中央、470上側**。
- normal bombs 6–8t、short max 10–12t、long 3–4t。
- 夜間重爆、heavy/special bomb、long-range minelaying、maritime patrol/ASW、大型誘導兵器、EW/command、tanker/transport。
- daylight deep penetrationは連山が担当。

## 10. 物流shadow（非戦史）

10機が500km hub→secured forward airfieldを2波飛べば、約300t/夜を理論的に運べる。実運用で10機を出すならunit保有12–13機程度が必要。

15–16t級tankならfirst wave 10両、second waveでlight tank/tractor/artillery/repair/fuel/ammo/comm/medicalを足し、**strengthened tank-company combat group**を一夜で形成できる。これはregiment輸送ではない。

return cargoはready wounded、高価値故障engine/transmission、technical captured equipment等。最も経済価値が高いのは「新品engineを前へ、故障engineを後ろへ」のrepair loopになり得る。
