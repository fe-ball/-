# 一式大型輸送機 L5Si — 幹線軍用輸送の正準案

## 0. 位置づけ
- 1941制式：**一式大型輸送機**、海軍略号 **L5Si1**。
- E6-M-T減格ターボプロップを用いる5t級大型輸送ワークホース。
- STOL機ではない。**整備された大型飛行場間の幹線輸送**を担当し、末端は一式指揮連絡機/STOL、鉄道、トラック等へ渡す。

## 2. 使い方
- 重い砲弾・燃料・食糧の大量補給を航空だけで置換しない。
- 医薬、無線、精密部品、軸受、交換タービン、噴射ポンプ、光学機器、搭乗員、専門整備員など「小さいが欠くと部隊が止まる貨物」を優先。
- 中国：後方hub→前方大型飛行場をL5Si、そこからSTOL/地上輸送。
- Midway：Wake–Midway約1,900km区間を通常3.5〜4.5t＋十分な予備燃料で運用。6〜8機級で月100〜200tの高優先度貨物。

## 3. 二一型 L5Si2（1943以後）
- 一次主構造をCFRP化しない。
- 接着アルミ構造、紙ハニカム、麻/GFRP二次構造、CFRPプロペラを採用。
- 空虚−450〜650kg級を中央。
- 同じ5tで航続/安全率を伸ばす、短距離なら5.5t級へ振る、高温高地の離陸余裕へ振る。
- 大型輸送機では素材の利得を最高速より**貨物・燃料・疲労寿命・生産性**へ配る。

## 4. 空中給油との関係
- 1942時点ではL5Si受油を標準装備にしない。
- 灯油共通の空中給油体系が1943に実用化してから、長距離輸送/偵察機へ受油装置を横展開する余地。
- 給油型L5Si（着脱式タンク＋給油装置）も将来候補だが未FIX。
