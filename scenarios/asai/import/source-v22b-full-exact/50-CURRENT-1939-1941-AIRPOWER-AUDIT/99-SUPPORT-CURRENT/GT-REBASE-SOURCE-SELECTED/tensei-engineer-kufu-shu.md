## 1a. 横断技術の想起ゲート

個別検討の前にルートの `CROSS-DOMAIN-PREFLIGHT-V46R1.md` と `CAPABILITY-TRIGGER-MATRIX-V46R1.tsv` を走査する。会話に名前が出ていなくても、年代・推進/エネルギー・材料/構造・機構/制御・生産/整備の各族を一度候補へ上げ、`CHECKED / GATED-OUT / N/A` を決める。特に「ターボ」は航空過給・ディーゼル過給・潜水艦2サイクル複合掃気・独立GT・TP/TS・ジェットを分離し、「FRP」はエポキシ工程・植物繊維FRP・GFRP・CFRPを分離する。**名前が思い出せなかったことを不採用理由にしない。**

## 2. 検討の枠組み（分類ではなく、重ねて用いる視点）

これは区分ではない。同一の事柄——彼は答えと道筋をあらかじめ知っている——を異なる角度から述べたもので、重ねて用いる。

二つの門（既存の土台であり、妥当なので維持する）。

- 着想の門＝何を理解し設計できるか。先知によりほぼ無償に開く。史実の遅延の多くは各者が手探りに費やした時間であって、彼はそれを要しない。
- 基盤の門＝何を溶解・加工・調達できるか。先知でも省略できない。ただし日本の当時の地力で評価する事項であり、ドイツや英国の事情を当てはめない。
- 要点は両門の境界にある。一方の門の制約を他方の門の問題へ置き換える工夫が存在する（例：冷却により安価な鋼を高温で用い、希少金属の不足を設計で回避する）。

能力の読み方（レールでなく帯。詳細は `asai-works-core-hierarchy.md`）。

- 世代の数値はベンチマークの帯（床・中央・上端）であって、達成の上限を定めるレールではない。下流（機体・商品）は帯の上端と迂回まで含めた達成可能から駆動され、中央値を天井として相続しない。
- 能力は標的でなく予算。ある軸の余剰は、別の軸の軽減や利益へ付け替える（例：入口温度の余剰を寿命や軽量や効率へ）。最大値を全軸同時には使わない。可能性を先に潰さない。
- 制約は「天井」と一語で書かず、何が縛るかに分解し、各々に迂回札を併記する。ベタ書きの天井は迂回の芽を摘み、「実在する制約のみを制約とする」に反する。

何ができるか、の重なった視点。

- 適切な方式を最初から選ぶ。
- その場で、不自然さなく、本来は後年の発明を提示する。
- 本来は難航する解を、着想の経緯を伏せたまま記す（外向きの説明が変わるのみで、機能する事実は変わらない。読者に対して機能すると偽ることとは異なる）。
- 長い熟成を要する物を、必要が生じる前に着手し、あらかじめ熟成させておく（時間そのものを先に費やす）。
- 他分野で確立した手法や、他分野の新発明を、早期に転用する。

窓の考え。

- ある技術が史実で普及した年は、最初に物理的に可能になった年ではなく、着想が得られた年、または量産が引き合う年で決まる。粗い実装の下地はより早く存在する。
- その差が、着想や偶然によって史実より早い実用化が可能になる範囲（窓）である。窓の広さは内容による——着想のみの物は早期から全面的に可能、必要な物が揃い供給のみが要る物は供給を確保できる場で可能、下地の一部が後年の物は粗い実装のみが早期に可能となる。
- 偶然は作り手が設定できる。窓を開くのは隣接する能力だからである（例：製鉄用の酸素設備があればアルゴンを得て清浄溶接が可能になる。海軍の水中聴音に関与していれば超音波探傷へ接続できる）。物理は実際に機能するため虚偽ではなく、隣接能力を持たせるのは作り手の設定として無理がない。

新規性の載せ方（何を一度に投入してよいか）。

- 開発の妥当性は、投入する新規性の**数**でなく、異常を**切り分け**られるか（帰属できるか）と、失敗しても**後退**できるか（実績の良品へ戻れるか）で決まる。この二つが保てる範囲でのみ新規性を載せる。
- 実証の土台を残す。新規の一群を除く全系を実績品にし、異常をその新規性へ帰属できるようにする。実証機（実績機体×新核）と材号機（実績核×新構体、`asai-works-structural-testbeds.md`）は、同じ規律を発動機側・構体側から適用したもの。載せ替え（暫定発動機で先に飛ばし本命核へ、`archive/aviation-pre-v48/v46-main/asai-works-aviation-rework.md` §4-1）はその時間版。
- 切り分けは道具で買う。地上供試体と飛行機を同工程の双子にし、管理図（常因と異常原因の分離、§4a）と非破壊検査（§4d）で、材料のばらつき・設計の誤り・その新規性を分離する。双子と管理図がなければ新規性は帰属できない。
- 順序は律速で決める。安く戻せない物・より基盤的な物から潰す（地上→空、低速→高速、供試体→部材→全機）。飛行制限の段階解除と脱出の余裕を後退路として残す。
- 判別は結合であって数でない。互いに独立な新規性（同じ機構・荷重路・破壊モードを共有しない）は束ねてよい。むしろ束ねた方が交互作用まで測れる——実験計画法（要因を同時に振る配置）は、一つずつ振るより効率も情報量も上、というのが実務の結論である。同じ機構を共有して結合する新規性だけを、切り分けのために順序化する。
- 「新機軸は一度に一つ」は、この規律の特別な場合（新規性が一個の強く結合した群に凝集し、独立に切り分けられないとき）の言い換えにすぎず、数を数える規則ではない。純ジェットの実証機（圧縮機・燃焼器・タービン・ノズルという束を実績機体に載せて飛ばす）が既にその証拠で、新規の束でも実証土台の上なら帰属でき後退でき、妥当になる。

## 3. 評価の基準（史実の同種をどう扱うか）

- 史実の同級品（ドイツや英国の同時期の機関など）を上限として用いない。そこからは不変の物理のみを抽出し、年表は採らない。読者が水準を測る目印としてのみ、別途残す。
- 成果物は、その時期の同等品と比べる。後年の完成形と並べて測らない（例：初期ジェットの相手はその年の実在機であって、ヘルキャットやメッサーシュミットMe262やファントムではない）。同等品が何かは分野ごとに史実から定める。
- 基準は、物理と、日本の当時の素材・工業の地力である。日本は制約の所在が異なる（ニッケル・コバルト・工作機械では制約が大きいが、精密・光学・一部の鋼では優位がある）。
- 「何年早いか」は単一の数値では表せない。知識で決まる事項では史実のいずれより前へ出られ、基盤で決まる事項では止まり、しかもドイツや英国とは異なる箇所で止まる。軸ごとに異なる。
- 通俗的な誤り（敗戦末期の崩壊を全期間に投影する見方、明治を明・昭和を暗とする図式）は採らない。事実として、海軍航空技術廠は1932年設立、帝大の航研機は1937年初飛行・1938年に長距離世界記録、九六式艦上戦闘機（堀越設計）は1936年、崩壊期の1945年にも国産の軸流式ターボジェット（環状燃焼器）を飛行させている。さらに戦後の日本は品質管理で世界的な地位を得ており、その手法の起点は1924年の管理図にある。彼はこれを四半世紀早く着手する。

## 4. 工夫の項目（分野別）

各項目に、内容／関係する門／窓の開く時期／確認状況を付す。「確認済み」は本検討で裏付けを得た物、「要確認」は次に確認する物。

### 4a. 品質と工程

- 管理図による工程管理。ばらつきを図上で常因と異常原因に分け、検査による事後選別から工程内での作り込みへ移す。要するのは記録・測定と作図のみで、着想の門のみに属し、早期から全面的に可能。史実：ウォルター・シューハートがウェスタン・エレクトリックのホーソン工場で1924年5月16日に最初の覚書を作成（確認済み）。
- 統計的品質管理を社内の慣行とする。戦後の日本に品質上の優位をもたらした手法を、工程表と会議の中で四半世紀早く定着させる。慣行は短期間では定着しないため事前着手の工夫であり、電話機の製造から自社工程への転用でもある。史実：デミングが日本科学技術連盟の招きで1950年に講義し、同年にデミング賞が設けられた（確認済み）。
- 限界ゲージと標準公差、治具の整備。互換性と歩留りの基礎。着想が中心で早期から可能（要確認：日本での普及時期）。
- 非破壊検査（X線透過・磁粉・超音波探傷）で鋳造・溶接の内部欠陥を出荷前に捉える＝歩留りと信頼性の目。X線は1900年代、工業用ラジオグラフィと磁粉は1920–30年代、超音波は海軍の水中聴音から接続（前掲の隣接能力）＝下地は当時に揃う。着想＝検査を『事後選別』でなく『作り込みの目』として工程へ組む（要確認：日本での普及時期）。
- 流れ作業（移動組立・工程分割）で発動機／タービンを量産する。フォードの移動組立（1913）は当時既存＝先取りは『それを精密機械の量産へ規律正しく適用する』こと。互換部品（限界ゲージ）＋管理図＋流れ作業で、希釈労働でも数と歩留りを出す（米が30万基を作れた側の組織力）。

### 4b. 材料・冶金（基盤の比重が大きい分野。ただし境界を置き換える工夫がある）

- 冷却により安価な鋼を高温で用いる（中空の空冷翼）。希少金属の不足を設計で回避する、境界を置き換える中心的な工夫。冷却の着想は早期から可能だが、中空翼の鋳造・加工は基盤に依存する（要確認：当時の精密鋳造の能力）。
- 精密鋳造（インベストメント／ロストワックス）で中空・複雑形状の翼を作る。蝋原型を耐火材で包んで焼き、脱蝋して耐熱合金を注ぐ古法（宝飾・歯科で既存）をタービン翼へ応用する＝**上の中空空冷翼を成立させる直接の手段（その要確認を解く）**。着想は先取り、下地（蝋型・耐火材・脱蝋・注湯・遠心／減圧鋳造）は当時の地力にある。史実：投資鋳造はWW2で米が発動機・タービン部品に復活し量産（要確認：耐熱合金への適用時期・歩留り・中子による冷却孔の成形）。
- 耐熱合金を二系統で研究する。**非ニッケル系統**（冷却＋拡散/セラミック皮膜＋クロム・マンガン系オーステナイト鋼。自給でき禁輸に強いが、入口温度・寿命は控えめ）と、**ニッケル系統**（析出強化の超合金。高い入口温度・長寿命だが供給依存）。冷却が両系統を繋ぐ要で、効くほどニッケルが要らない（冷却＝ニッケルの部分代替）。実在の前例：Jumo004の空冷中空翼＋クロマドゥア（Mn18/Cr12/Ni0.2、生産型で戦略材料を切り詰め）と、英ニモニック80（1941・W.2B）（いずれも確認済み）。詳細と備蓄との噛み合わせは `asai-works-core-hierarchy.md` §4。
- ショットピーニングによる疲労寿命の向上。圧縮の残留応力を付与する。安価で、粗い実装でも効果がある（要確認：手法の確立時期）。
- 拡散による表面処理（アルミナイズ等）で酸化と高温腐食を抑える。既存の化学により安価な合金を保護する（要確認）。
- 超硬合金（粉末の焼結）。切削能力の大幅な向上であり、後のタービン円板の粉末冶金へ連なる基礎でもある（要確認：欧州での実用時期）。
- もみの木型の翼根。熱膨張を許容し、交換も容易（要確認）。

### 4c. ターボ機械（着想の効果が大きい中心分野）

- 多段軸流圧縮機の設計（翼型、速度三角形、失速の回避）。初期のガスタービンが正味出力を得られなかった問題を解く中心。着想の門。
- 遠心圧縮機で先に正味出力を示し、後に軸流へ移行する。製作の容易さで実証を先行させる、方式と順序の選択。
- 可変静翼と抽気弁。広い範囲で失速と急な逆流を避け、運転域を拡大する。着想が中心で、機構として実装できる。
- 燃料供給を運転に応じて調整する機構。過渡時の失火と過熱を防ぐ。これがなければ実用にならない。機械式で、粗い実装でも効果がある。
- 回転体の釣り合わせ。高速回転に不可欠で、時計製造の精度が活きる（他分野からの転用）。

### 4d. 振動・破壊・検査（事前の予防。事故を未然に除く）

- 共振を避ける設計（回転数と固有振動数を対照し、危険な回転数を外す）。着想の門で、作図のみで可能。史実：ウィルフレッド・キャンベルがゼネラル・エレクトリックで1924年に発表（原型は蒸気タービンの円板の軸方向振動、確認済み）。
- 欠陥の存在を前提に設計し検査する。考え方は早期から採用でき、精密な計算式は後年。史実：アラン・グリフィスが1920年に着想・1921年に論文（確認済み）。
- 超音波による内部欠陥の検出。粗い方式（透過した超音波の減衰で見る）はソコロフの1928年の提案と1930年代前半の実演から可能で、下地は水中聴音（ランジュバン、1917〜18年）から転用できる。反射の往復時間を測る精度の高い方式は短いパルスの電子機器を要し、1940年代まで遅れる（いずれも確認済み）。隣接に海軍の音響業務を置けば窓が開く。

### 4e. 推進と冷却の艤装（着想で先行できる空力の工夫）

- 冷却器の排熱を、導管の設計により推力へ転換する。物理は以前から成立しており、要するのは着想である。導管の取り入れ口を胴体の乱れた気流から離す細部まで、設計で対応できる。史実：F.W.メレディスが英国の王立航空研究所で1935年に報告し、直後にスピットファイア等へ適用（確認済み。溶接のメレディスとは別人）。
- 排気を後方へ噴いて推力にする（推力式単排気管・エジェクタ排気）。発動機を替えず排気管の設計だけで、ほぼ無償の推力。史実：スピットファイア（マーリン）で300 mph時に約70 lbf＝約70馬力相当、推力にして約7%増（プロペラ効率込みで約9%）、最高速+10 mph（確認済み）。高速・高高度のレシプロ戦闘機一般では全推力の**一割強**が目安〔Hoerner『Fluid-Dynamic Drag』はプロペラ推力の0.11〜0.13倍とする〕。**Bf109で全推力の約1/3という数字は出所を確認できなかったので使わない**——追える範囲では出典なしの掲示板記述一件のみで、質量流量から検算しても一割強にしかならない。日本は遅れた＝全ピストン機に後付けで効く安い底上げで、過給機とは別の独立した広い需要になる（`asai-works-aero-turbosupercharger.md` §9）。**利得は速度に比例するので、低速機ほど小さい**：零戦二一型（148 m/s）では推力比約4%＝+6〜10 km/h止まり（`asai-works-validated-derivations-2026-08-15.md` §D01）。
- 空力的な清浄化（沈頭鋲、付け根の整形など）。抗力を低減する着想。着想が中心。

### 4f. 溶接・接合（必要な物は揃う。供給と着想が要点）

- タングステン電極を不活性ガスで覆う溶接。軽金属を清浄に溶接する。下地はいずれも1910年代に揃う——アーク溶接は1907年までに成立（被覆電極、シェルベリ）、金属電極は1891年、延性タングステンは1910年（クーリッジ）、遮蔽用のアルゴンは空気分離装置（1900年代以降）の副産物（いずれも確認済み）。史実が1941年（ノースロップのラッセル・メレディス）まで遅れたのは、着想と戦時の需要と安定供給による。アルゴンを確保できる工場であれば、1920年代でも先行的な実装が成立する。

### 4g. 商業・時間の工夫（事業環境の整備）

- 景気の波と戦略金属の先行確保。好況期に投資し借入を抑え、恐慌期に同業の設備・人材を低価格で取得し、禁輸の前に金属を確保する。事前着手の工夫の代表（史実の景気変動は別途確認可）。特に**ニッケルの先行備蓄**は、ニッケル系統コアを回せる年数＝窓の幅を直接決める一軸として持つ（史実でニッケルは決定的に逼迫。`asai-works-core-hierarchy.md` §4）。
- 公知の地味な目標で本命を覆い、資金と正当性を得る（既存の論点）。
