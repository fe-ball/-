# 能力収斂フレームワーク 1903–45 —— future-CAD benchmark / O-G 正本

> **v38 authority.** 本稿は「転生知識・現地工業・計算・組織学習が、現地で製造可能な最良設計へどこまで近づけるか」を監査する上位規則である。個別製品の性能値を自動変更しない。

## 1. 100% benchmark

100%は未来工場の召喚ではない。材料、素材品質、工作機械、工員、工場、計測器、電力、資金、調達、試験設備、creep/疲労/腐食に必要な実時間は、その年の現地条件へ固定する。

理想化するのは設計室だけである。**future-grade CAD/analysis + future-grade expert subordinates** が、その現地条件で製造可能な最善に近い青写真、公差、工程表、検査計画、試験計画、failure-mode一覧、trade studyを返す状態を100%とする。

よって100%でも、現地で溶かせない合金、加工できない孔、測れない現象、まだ回していない1000 h creep testは得られない。

## 2. O / G

- **O-score / Optimization Proximity**: 100% benchmarkの設計解へどの程度近いか。完成品性能ではない。
- **Gp / performance gain capture**: benchmarkなら得られる性能改善余地のうち回収した比率。
- **Gd / development gain capture**: benchmarkなら除ける試作、人日、手戻りのうち回収した比率。
- **Gq / quality gain capture**: benchmarkなら改善できる寿命、信頼性、歩留まり、個体差、保守性のうち回収した比率。

**O/Gは監査座標であり、性能ボーナスではない。** `O=70%` を出力・速度・効率へ70%加算してはならない。額面利得は、まず「100% benchmarkと基準設計の差」を物理的に求め、その差へ対応するGを掛ける。

## 3. 問題クラス

- L0: 方式選択・大枝。後知恵が最も強い。
- L1: 低次元・閉形式・表計算。
- L2: 多変数semi-empirical、map、統計・試験相関。
- L3: coupled/dynamic、反復、時間積分、flutter/rotordynamics/start-accel等。
- L4: 3D剥離、実surge境界、creep/腐食/疲労寿命、界面・量産歩留まり等、実物依存が強い。

同じ年代でもL0/L1は100%へ近く、L4は遠い。年代だけの一律スコアは禁止する。

## 4. 主人公の役割

主人公の本職は発動機・GT/jetで、冶金と航空へ強く伸びる。計算機は補助インフラであり第二の主人公専門ではない。

計算分野では中央として、需要を出す、人を集める、正しい問題を投げる、現地提案のうち実る枝を後知恵で選ぶ、必要な時だけ強いヒントを出す。未来CPU/未来計算機一式を本人が青写真で直接投下することは中央線にしない。

## 5. 長期的な意味

初期は `protagonist score >> organization score` でよい。1920–30年代に計算型、カード、試験標準、QC、failure feedbackが蓄積すると、主人公本人が答えを書かなくても組織が正しい設計へ収斂する。この**組織能力の複利**が「15年で実用、20年で怪物」の主要因の一つである。

## 6. 境界

- v38では既存E系列PR/TIT/eta/thrust、航空機速度・重量・航続、製品TBOを一律変更しない。
- 史実年号は比較アンカーであってO/Gの天井ではない。
- 計算は未知物理、未測定係数、加工不能、qualification実時間を消さない。
- 個別性能差し戻しは本稿を入力に別H→Aで行う。
