# コアの要素分解——世代（E系）を独立軸へ分離する

> **v44 installed-product authority.** v43 compressor stage/flow/operability remains authoritative. v44 closes E6 shaft installed product power: E6-S non-Ni 1,300hp standard, E6-S-N 1,500hp standard, E6-M-T 2,100hp retained flat-rated. Jet thrust and downstream platform H→A remain separate.

> **v41 E4/E5 product authority.** `w_gross` と `w_installed` の分離はv40を継承し、v41でE4 standard flow **6.7 kg/s / 500 kW**、E5-S **7.6 kg/s / common 1,000 hp**をproduct-size rebaselineとして受領した。current product authority=`asai-works-e4-e5-product-massflow-size-rebaseline-1931-37.md`。

`asai-works-core-hierarchy.md` が原則として置いた「能力は予算・天井は分解できる前線」を、**数値の層まで降ろす**。すなわち、いまだ `asai-works-gt-core-generations.md` §2 で **E-n ごとに一行へ束ねられている世代**を、独立に選べる要素軸と、そこから閉じる従属量へ分離する。これが、エンジン機種を複数並べる（カタログ化する）前に要る土台。規則は `tensei-engineer-kufu-shu.md`、数値の芯は `core-generations`、構造は `core-hierarchy`。数値は【確認済み】【物理】【設定】【要確認】で区別する。

## 0. 問題——「E-n世代」は束ではなく、前線の対角線

現状、`core-generations` §2 の表は E-n の各行に {圧力比・入口温度・部品効率・熱効率・比仕事・寿命} を**一括で束ねて**いる。`core-hierarchy` は三層（世代→コア種類→エンジン商品）と「能力＝予算」を原則として置いたが、**数値はまだ束のまま**で、製品が「E-5」を丸ごと相続してしまう。

要素へ分離する核心は一つ——**独立に選べる軸と、そこから計算で閉じる従属量を、はっきり分ける**こと。独立軸はわずかしかない。比仕事・熱効率・実出力・寿命は独立変数ではなく、**従属量**である。これを混同して「世代の比仕事」を独立に置いてきたのが、製品展開で表が崩れる原因だった（`core-generations` §3 が比仕事を固定して逆算したのは、その崩れの兆候）。

## 2. 独立と従属の境界は「厳密」である（崩れの元を断つ）

比仕事・熱効率を従属量に置く根拠は、近似でなく**式が閉じる**こと。示強3軸（TIT・PR・部品効率）を入力にブレイトンで計算すると、`core-generations` の中央値を**ぴたりと再現する**【物理・検算済み】。

| 世代 | 入力（TIT/PR/η） | 比仕事（計算→正本） | 熱効率（計算→正本） |
|---|---|---|---|
| E-4 | 710℃ / 4.5 / 0.82 | 93.5 → 93 kJ/kg | 18.4% → 18% |
| E-5 | 800℃ / 6 / 0.83 | 125.5 → 126 kJ/kg | 22.6% → 22.5% |
| E-6 | 870℃ / 7 / 0.84 | 155.3 → 155 kJ/kg | 25.8% → 26% |
| E-7＝前線（1942–44） | 900℃ / 8 / 0.85 | 172.6 → 173 kJ/kg | 28.1% → 28% |
| E-8＝high-end practical（1945–46 technical coordinate） | 940℃ / 9.5 / 0.86 | **gross** 194 → 194 kJ/kg | **gross** 30.9% → 31% |

（T1=288K・cp=1.005・γ=1.4、部品効率を圧縮/膨張の双方に適用。検算ノイシャテル17.4%と整合、`core-generations` §1。）

つまり**世代表の「比仕事・熱効率」列は、独立データではなく示強3軸の計算結果を再掲したもの**。表に残してよいが、それは中央対角の便宜値であって、製品の値ではない。製品のgross w/η_thはTIT/PR/ηから計算するが、**shaft productはそこで止めない**。v40以降E4/E5はcooling/Δp/mechanicalを払った `w_inst` を作り、`P_shaft=w_inst×ṁ` で出す。旧 `E5 gross126×6=756 kW` はgross-derived targetでsuperseded。v41ではE4 6.7 kg/s、E5-S 7.6 kg/sをstandard product gas pathとして受領した。v44ではE6も同じ会計へ移し、non-Ni870°C `w_inst≈130.5 kJ/kg / η≈22.5%`、Ni920°C `w_inst≈148.7 / η≈23.5%`を受領した。E6-S旧1,520/1,700hpは1,300/1,500hp標準へ修正、E6-M 2,100hpは13.2kg/sでflat-ratedとして維持する。

以上から、E-n は**製品仕様ではなく、その年の示強3軸の前線（腕の上限）の中央値を束ねたラベル**と読み替える。

| E-5（約1934–37） | 約800℃ | 約6 | 0.83 | 約126 | 約22.5% |

## 4. 前線の三曲線——世代が対角線である実証

示強3軸は**別々の門・別々の速さ**で進む。だから「世代＝対角線」は比喩でなく、三本の前線曲線がたまたまその年に居る高さの断面である。年次でほどくと次のとおり【設定（年次）＋確認済み（部品効率の芯）】。

| 年（仮） | TIT | PR | 部品効率 η |
|---|---|---|---|
| 〜1921 | 540℃ | 2.5 | 0.77 |
| 〜1925 | 620℃ | 3.0 | 0.79 |
| 〜1928–29 | 690℃ | 3.5 | 0.80 |
| 〜1931–33 | 710℃ | 4.5 | 0.82 |
| 〜1934–37 | 800℃ | 6.0 | 0.83 |
| 〜1938–41 | 870℃ | 7.0 | 0.84 |
| 1942–44（E-7） | 900℃ | 8.0 | 0.85 |
| 1945–46（E-8 practical） | 940℃ | 9.5 | 0.86 |
| 1945–47（E-9 component/rig front） | ~1000℃ | 11〜12 | 0.86〜0.87 |

三軸は形が違う。

- **入口温度 TIT（比仕事の主動力・まだ伸びる）**：540→940℃をE8 practical、~1000℃をE9 component/rig frontとして扱う。とくに中盤（710→800→870）で**加速**する。門は基盤（耐熱鋼）＋着想（中空空冷翼・拡散皮膜）。**比仕事の成長（93→194＝+109%）はこの軸が牽引する**（圧力比は比仕事最適の近くに保つので、比仕事はほぼTITで決まる）。天井は翼材・冷却・鋳造精度で、まだ前線が前進する軸——E-7の900から**E-8（1945–46 technical coordinate）で940**へ。v37ではNi供給年を自動cutoffにせず、cooling passage/yield、vane/rotor/root/disk metal-temperature map、creep/oxidation/thermal fatigue、NDT/TBOを受領gateにする（`core-generations` §2）。
- **圧力比 PR（熱効率を買う・着想で伸び続ける）**：2.5→9〜10をE8 practical、11〜12をE9 component/rig frontとして扱う。多段軸流の段数を増やすほど上がり、E-4の4.5から**E-6で7、E-7（上端）で8、E-8で9〜10**へ。門は着想（アエロ）。**比仕事はTITが決めるので、PRの上昇は主に熱効率（比燃費・航続）を買う**。史実Jumo004/Metrovick F.2/Avon/J57等は**比較anchorにのみ使用し、浅井世界線のcalendar ceilingにはしない**。v37ではPR9.5/16段の平均一段圧力比≈1.151という内部設計量を重視し、縛りを段数増の重量・matching・clearance・サージ余裕（迂回＝可変静翼/抽気・多軸）へ置く。
- **部品効率 η（最も遅い・基盤天井）**：0.77→0.86 のゆるい単調増。門は着想（翼型）＋基盤（加工精度・隙間管理）。基盤天井 ≈ 0.85〜0.88（現代）で、小型端はさらに手前で頭打ち（§1b の弱結合）。

要点：**三軸が一斉に動く必然はない**。TIT は比仕事を、PR は熱効率を、別々の速さで押し上げる。TIT だけ前線・PR は中位・η は中位、という製品も前線に矛盾しない。E-n を「一斉に上がる階段」と読むと保守（中央値の相続）に戻る。三本の独立曲線として読むのが正しい。

## 5. 運転点軸の数値化——減格⇄寿命⇄比仕事

`turboprop-program` §5 の「減格して寿命を買う」方向は維持する。ただしv39で旧 **「翼金属温度−15℃ごとに寿命×2」** を普遍的rating則から降格した。Larson-Miller型に代表されるとおりcreep lifeはmetal temperatureへ強く敏感だが、倍率は alloy / stress / environment / process で変わり、さらに `ΔTIT != ΔTmetal` である。下表は**legacy sensitivity illustration**としてのみ残し、製品寿命の正準値を直接生成しない。E4/E5は `asai-works-e4-e5-hot-section-component-life-rebaseline-1931-37.md` のcomponent ledgerで閉じる。

| 運転点（減格 ΔTIT） | 比仕事 | 熱効率 | 寿命倍率 | 寿命の目安 | 当てる製品 |
|---|---|---|---|---|---|
| 0（全力・870℃） | 155（基準） | 25.8% | ×1 | 数百h級 | 高価値（高高度偵察・最良機） |
| −30℃（840℃） | 145（−7%） | 25.2% | ×4 | 約1,200h | 攻撃機（中庸） |
| −50℃（820℃） | 137（−12%） | 24.8% | ×10 | 約3,000h級 | 輸送・量産ワークホース |
| −80℃（790℃） | 127（−18%） | 24.2% | ×40 | 約1.2万h級 | 練習機・定置の極長寿命 |

読み：**比仕事は減格で緩く落ち、creep lifeはmetal temperature低下で強く伸びうる**。ただし表中の×4/×10/×40は旧感度例で、v39以降の正準寿命倍率ではない。ワークホースで減格を使う方向だけを保持する。

注意：

- これは翼**金属**温度の感度例。ガスTIT減とmetal-temperature減は同値でなく、cooling effectiveness / coolant temperature / flow distributionで動く。
- **材料系統は基準寿命と温度感度の両方を動かす**。倍率を材料非依存とは扱わない。ゆえに「非Ni＋減格」で量産の床、「Ni＋全力」で高価値の上端、と**材料系統×運転点で面ができる**。
- 減格の余剰は寿命でなく、冷却空気を減らす方向（正味効率↑・軽量）へ振ってもよい（`core-hierarchy` §3）。本表は寿命へ振った例。

## 6. 合成規則（要素→製品）

製品は、次の手順で軸上の一点を選ぶことで定義される。

1. **年（腕）を決める**→ 示強3軸の前線が決まる（§4）。
2. **各示強軸で前線以下の選択点を置く**（余剰は §1a の付け替えへ）。
3. **実体3軸を選ぶ**（規模 ṁ・軸構成・材料系統）。
4. **商品軸を選ぶ**（後端・艤装・運転点／格付け。減格の数値は §5）。
5. **従属量を計算する**：w＝f(TIT,PR,η)、η_th＝g(…)、P＝w×ṁ、寿命＝h(減格,材料,モジュール)。ジェット後端は推力で測る。

これで「エンジン機種」は、軸上の点（または近接した点の束）として一意に書ける。命名は `core-hierarchy` §7（世代E-n×寸法{S/M/L}×材料{無印/N}）を各点へ貼る。

## 7. 実演——同じ「E-6の腕」から2機種を要素で作り分ける

`turboprop-program` §5 の「同じ E-6 ターボプロップでも輸送と高高度偵察を作り分ける」を、要素表で裏打ちする。腕（E-6前線）と後端（プロペラ）は同じ。違うのは**軸上で選んだ点だけ**（減格の数値は §5）。

| 要素 | 高高度偵察（Ki-40・発展） | 大型輸送ワークホース |
|---|---|---|
| 腕（年） | E-6前線 | E-6前線 |
| 入口温度 TIT | 前線（約870℃）＝性能へ | 減格（−50℃級）＝寿命へ |
| 圧力比 PR | 前線寄り | 中庸 |
| 部品効率 η | 前線 | 前線 |
| 規模 ṁ | 中型 | 大型（置換量を最大化） |
| 軸構成 | 自由動力タービン | 自由動力タービン |
| 材料系統 | ニッケル（高温・長寿命） | 非ニッケル（自給・量産・禁輸に強い） |
| 後端 | プロペラ（高バイパス極限） | プロペラ |
| 運転点 | 全力・性能 | 減格・長寿命＋水メタ離陸 |
| →（従属）比仕事 | 約155（基準） | 約137（−12%） |
| →（従属）寿命 | 数百h級（Ni） | 数千h級（非Ni＋減格） |
| →（従属）実出力 | 中（中型 ṁ） | 大（大型 ṁ） |

同じ腕・同じ後端でも、**TIT/材料/規模/運転点の選択が違うだけで別のエンジン機種**になる。これが「E-6ターボプロップ」を一点でなく**面**として扱うということ。カタログ化は、この面の上に必要な点を打って §7命名を貼る作業に等しい。

## 8. これで開くこと（後続への接続）

- **エンジン機種カタログ**（前回の宿題）は、本軸表の点を埋める作業に化す。ターボプロップなら Ki-40系／天山系／重爆系／輸送系 × 規模 × 材料、で点を打つ。
- **横展開**：ジェット・舶用・戦車・定置も同じ九軸表を共有する。だから `handoff` §6 の「§7命名がどの分野にも降りていない」宿題は、本表を親にすれば一枚で片付く（各分野は本表の点として読む）。
- **保守の根を断つ**：製品が中央値を天井として相続する誤り（`aviation-forms` §7・§8 の過剰評価の根）は、「E-n は箱でなく目盛り」（§3・§4）で構造的に消える。

## v38 life/TBO vocabulary

寿命を一語で扱わない。

- `L_mat` = material / hot-section baseline life
- `L_core` = representative rated core hot-section life
- `H_qual` = cumulative qualification / endurance hours
- `TBO_prod` = product-specific overhaul / inspection interval at stated rating/duty

hoursとstart/thermal cyclesは別ledgerとする。`H_qual=150 h` はTBO 150 hを意味せず、深いderating/間欠運転の`TBO_prod`はfull-rating `L_core`を直接表さない。v38では既存寿命値をこの語彙へ再ラベルするだけで、数値再ratingは後続監査へ送る。

## v39 E4/E5 hot-section life authority

E4/E5の寿命正準は `asai-works-e4-e5-hot-section-component-life-rebaseline-1931-37.md` に従う。`L_core` はE4 250–450 h、E5 Ni@800℃ 400–700 h、E5非Ni@800℃ 150–300 h、E5非Ni@760–770℃ 350–600 h。liner交換intervalやproduct TBOをこの値と同一視しない。generic long-clockとexact alloy/process clockは別で、新material/processへはpartial resetを課す。
