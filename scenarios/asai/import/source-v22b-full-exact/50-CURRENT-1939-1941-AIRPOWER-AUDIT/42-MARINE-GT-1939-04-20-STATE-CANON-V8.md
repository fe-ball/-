# MARINE GT — 1939-04-20 PHYSICAL / PROGRAM STATE — V8 AIRPOWER12

> This is an Apr20 state closure, not a ship-adoption history. The current V10 marine dossier separates technical architecture from execution history; that distinction controls here.

## 1. What physically exists

By Apr20 Asai has active **shore-based marine qualification infrastructure**, inherited from 1935-38 work:

- water-brake / propulsive-load simulation;
- reducer and gear endurance;
- clutch/freewheel engagement and coast-down;
- shaft/torsional/vibration work;
- salt-spray / intake-separation / filter pressure-loss tests;
- water-ingestion, wash and corrosion procedures;
- hot-section inspection under marine salt exposure.

Exact rig count is not needed; these are established test functions, not paper studies.

## 2. E5 small-craft qualification architecture

The current low-risk E5 architecture is:

- an existing fast-craft hull family;
- two conventional/piston outer propulsion shafts retained for cruise/astern/harbor operation;
- one center shaft with E5-S gas turbine + free power turbine + single reduction + freewheel as boost/test path.

The corrected current E5-S common shaft product is about **1,000 hp class**. Legacy `1,300 hp E5-S` small-craft values are conditional/superseded as a standard product rating.

The purpose is to obtain real-sea evidence for salt/intake, gear, shaft, prop, start/stop and maintenance — not to prove a production torpedo boat by speed alone.

## 3. Physical craft count at Apr20

The latest V10 technical dossier explicitly marks execution history as a stop line: no build, launch, trial, achieved speed or qualification event is asserted.

Therefore Apr20 closes:

- completed/commissioned E5 GT qualification craft: **0 asserted**;
- dedicated 700-1,000 t lab ship: **0 asserted / not a technical prerequisite**;
- obsolete-hull conversion: selection remains open;
- large surface-ship GT installation: no current automatic adoption.

This is not a claim that the Navy cannot order such a platform. It means the current branch has not yet paid/recorded that event.

## 4. Why shore capability is still valuable

A sea craft is uniquely valuable for hull/prop/trim/real-spray evidence, but much of salt, reducer, bearing, hot-section and clutch mechanism can be accumulated ashore. Hence no single ceremonial test boat is required to make marine GT research real.

## 5. Future activation gate

If a Navy/yard decision activates the craft, use the one-GT boost architecture as the first low-risk sea qualification path. Do not revive the old two-GT + small-center-engine configuration as the default merely because it appeared in an earlier design paper.

Any later E6 50-55 t torpedo-boat, destroyer/cruiser/carrier boost or pure-GT ship remains a separate requirement/procurement gate.
