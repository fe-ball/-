# PRE-BRANCH HOMARE / HA-43 AIRFRAME INTEGRATION — CANON V8 AIRPOWER4

## Status
**CANON for branch-neutral design/integration states through 1943Q1.**

This file connects the engine availability states in files 11-14 and propeller/cooling states in file 15 to aircraft programs.
It deliberately does **not** select 1943+ procurement quantities, combat-derived requirements or theater outcomes.

## 1. Governing rule
An aircraft date is not justified merely because an engine exists.

For every program distinguish:
- requirement / program authorization;
- detailed-design manpower release;
- engine `EA-D/Q/S`;
- propeller `PA-D/Q/S`;
- cooling installation `CI-D/Q/S`;
- airframe prototype manufacture;
- first flight;
- military qualification;
- serial release.

A program whose requirement is combat-branch-sensitive cannot be made canonical simply because all of its technologies are ready.

## 2. Cross-program inheritance rule
V8 organizations are allowed to learn across programs when there is a plausible team/specification/test channel.
They are **not** allowed to teleport a complete installation.

Transferable:
- governor and propeller acceptance practice;
- high-power propeller vibration spectra and instrumentation methods;
- radial cowl pressure/temperature measurement methods;
- oil-cooler sizing/duct practice;
- Homare mount/accessory/service lessons;
- standardized fasteners, gauges, seals and inspection methods.

Aircraft-specific and requiring requalification:
- engine-mount loads;
- cowl/exit geometry;
- cooling-air distribution;
- propeller diameter/clearance;
- reduction ratio;
- landing-gear geometry;
- wing/fuselage interference;
- carrier folding/arresting loads;
- CG and control-force effects.

## 3. J2M / Raiden branch — high-power integration precursor
### Fixed prior V8 state
- 14-Shi formal date remains September 1939.
- Horikoshi team's detailed design effectively begins 1939Q4.
- V8 first-flight target remains **1941Q4, center around December**, conditional on Kasei/extension-shaft/cooling closure.

### What AIRPOWER4 adds
The initial J2M development installation does not need to wait for the mature Homare-class four-blade family.
The high-power four-blade lesson becomes especially relevant on the Kasei 23 / J2M2-class evolution.

V8 state by 1942H1:
- 3.3 m high-power four-blade hardware: `PA-Q` feasible for the installation;
- hydraulic pitch/governor path: preferred after bench/aircraft comparison;
- Kasei extension-shaft torsion and fan/cowl/oil-cooling work: active `CI-D -> CI-Q` program.

### Schedule implication
Because V8 J2M1 flight starts roughly a few months before the historical line and hydraulic four-blade work is already being qualified in parallel, a J2M2-class high-power installation can plausibly enter flight test around **1942Q3** rather than waiting for a late-1942 discovery of the entire integration problem.

This is a **central technical window**, not a fixed historical first-flight date.

### What J2M teaches later programs
Strong transfer:
- governor/hub qualification;
- propeller vibration and overspeed testing;
- cooling-pressure instrumentation;
- oil-temperature margin;
- high-power radial fighter maintenance access.

Weak transfer:
- extension-shaft geometry itself;
- exact fan/cowl configuration.

J2M remains a separate rapid-scramble interceptor program, not a disposable propeller testbed.

## 4. B7A / Ryusei branch — direct Homare carrier-aircraft integration
### Historical anchor
The B7A development requirement begins in 1941; the historical first prototype was completed in May 1942 with a large ~3.5 m propeller and development-state Homare.

### V8 interpretation
This program is unusually useful because its historical requirement timing already lies before the uncertain 1943 combat branch.
Therefore its technical development can be carried forward without inventing a later war-derived requirement.

### 1941H2
- airframe detailed design underway;
- Homare 10/11 development engines progressing toward `EA-D`;
- ~3.45 m four-blade family `PA-D -> PA-Q`;
- landing-gear/gull-wing/torpedo-clearance geometry fixes propeller diameter early rather than late.

### 1942Q1-Q2
Safe V8 center:
- prototype completion/first flight remains around **1942Q2, centered roughly April-May**;
- there is little reason to force a dramatic calendar acceleration because Homare development hardware, not a lack of airframe competence, is already the limiting gate.

At first flight:
- engine: Homare 11-class `EA-D`;
- propeller: ~3.45 m four-blade `PA-Q` or late `PA-D` with explicit envelope;
- cooling: `CI-D`, moving into aircraft qualification.

### 1942H2-1943Q1
V8 difference from history:
- fewer test interruptions caused by random engine/production inconsistencies;
- faster separation of engine defects from airframe/gull-wing/gear/control/cooling defects;
- Homare 12 / production-representative installation can move toward `EA-Q/EA-S + PA-S + CI-Q/S` as the engine family itself matures.

Not closed:
- production start date;
- fleet quantity;
- carrier availability/need;
- combat-derived weapons/load changes.

## 5. N1K1-J / Shiden — Homare fighter integration
### Prior V8 state retained
- Kyofu requirement: September 1940.
- simplified V8 Kyofu main path: first-flight center late 1941; practical test data in 1942Q1.
- land-fighter idea is plausible in Sep-Nov 1941; it does not have to wait for Kyofu first flight.
- N1K1-J remains justified as a fast conversion/bridge even when its long gear is known to be undesirable.

### AIRPOWER4 engine/propeller closure
By the relevant 1942 window:
- Homare 11/12: `EA-D`, progressing through qualification;
- 3.3 m four-blade: `PA-Q` available;
- fighter cooling installation: must still close `CI-D -> CI-Q` on the actual airframe.

Therefore the propeller is **not** a reason to defer first flight into 1943.

### First-flight window
Current V8 technical window is strengthened to:
- **1942Q4** robustly;
- center **October-November 1942** if prototype manufacturing proceeds normally;
- exact date remains non-canon because company/procurement scheduling has not been replayed day by day.

Historical 27 December 1942 remains a useful external anchor showing that the same basic engine/large-four-blade combination was physically achievable by year-end even without V8 improvements.

### What better Homare changes
It does **not** delete:
- long/telescoping landing-gear complexity;
- mid-wing packaging and maintenance burden;
- cooling and cowl drag;
- structural/weight cleanup opportunity.

It does:
- reduce engine-caused test aborts;
- make climb/reacceleration data more representative;
- expose landing-gear and airframe defects earlier;
- make a low-wing redesign decision easier to justify on airframe merits rather than being confounded by powerplant unreliability.

Automatic combat-flap timing remains governed by file 04; this file does not move a mature automatic system onto the first N1K1-J prototype.

## 7. Reppu-equivalent — what can be fixed before the 1942 requirement branch
This is the most important branch guard.

### What is safe to canonize
The need for a future Zero successor and internal aerodynamic/installation pre-study is foreseeable by late 1940/1941 even if the exact later specification changes.
Given V8 team release and engine visibility, Mitsubishi can maintain a **low-level successor design study during 1941** rather than treating the project as technically blank until a later formal specification.

Safe 1941 study content:
- carrier-fighter gross-weight / wing-area trades;
- folding geometry and deck footprint;
- 3.5-3.6 m propeller ground-clearance studies;
- Homare vs future Mitsubishi 18-cylinder engine envelope drawings;
- firewall/mount/cowl mock-ups;
- oil-cooler and inlet/exit studies;
- landing-gear geometry;
- armament/protection/fuel volume trades.

This is **pre-design**, not an authorized service aircraft.

### By 1942Q1
Branch-neutral technical capability can include:
- Homare installation drawings based on a 1,800-2,000 hp envelope;
- Ha-43 growth-envelope drawings based on roughly 2,200 hp and larger/heavier engine geometry;
- 3.6 m low-rpm propeller rig data;
- mock-up/static work that does not require a final 17-Shi-like requirement.

### Formal requirement guard
Whether a historical-equivalent 17-Shi requirement is issued, when it is issued, and its exact speed/climb/range/maneuver/protection values belong to combat/procurement replay.
Do not promote the historical July 1942 requirement automatically into worldline canon.

### Conditional path if an equivalent requirement exists in 1942
This is a planning consequence, **not a guaranteed event**:

#### Homare branch
- engine advantage: earlier/smaller/lighter; by late 1942 has `EA-Q` good-engine capability moving toward `EA-S`;
- propeller: 3.6 m class can be `PA-D/PA-Q`;
- by 1943Q1 detailed design and prototype manufacture can be substantially advanced because 1941 pre-study prevents a cold start.

#### Ha-43 branch
- engine advantage: greater absolute power/growth margin;
- engine state: selected flight-grade `EA-D` late 1942-1943Q1, not yet guaranteed `EA-Q`;
- mount/cowl/propeller static integration can proceed by 1943Q1;
- first-flight scheduling cannot be fixed until engine qualification/program priority is replayed.

### Engine-selection rule
Do not recreate the simplistic historical narrative:
`Homare failure -> switch to Ha-43 rescue`.

V8 rational selection is:
- Homare = earlier/light carrier-fighter path;
- Ha-43 = later/heavier growth path;
- parallel installation design is rational until flight, production and requirement evidence chooses between them.
