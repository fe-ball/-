# ジェット双発要撃機——開発史・名称・諸元（初飛行時と完成形）

これまでの検討を一旦まとめ、本命の双発ジェット要撃機について、開発史・名称（社内／軍）・所管と、**初飛行時**と**完成形**の諸元を一枚にする。規則は `tensei-engineer-kufu-shu.md`、コア数値は `asai-works-gt-core-generations.md`、構造模型は `asai-works-core-hierarchy.md`、形式・機体論は `asai-works-aviation-forms.md`／`asai-works-aviation-rework.md`。数値は【確認済み】【物理】【設定】【要確認】で区別し、固有名はすべて【設定】（当時的・非衝突で置いた仮称、差し替え可）。

---

## 1. 開発史の要約（GTの系譜の上に乗る）

- **核の系譜**（`core-generations`）：E-1（1921・正味出力の実証）→E-3（1928–29・将来性）→初号機E-4→E-5→E-6→上端。社内は「エリング装置の再現」で覆い、特殊鋼と過給機の現金が研究を養う。E系は達成のレールでなく**ベンチマークの帯**（`core-hierarchy` §2）。
- **形式の分岐**（`aviation-forms`）：同じ核の後端を替えるだけで、純ジェット／出力寄りバイパス／ターボプロップ／軸出力が連続して並ぶ。ファンは冷部なので温度天井を使わず推力を買える。
- **ジェットの段階**（`aviation-timeline`）：地上ベンチ（E-5・約1935–36）→懸架の原型機（G3M母機にE-5ジェットを吊る・約1936–37）→**専用実証機**（E-5・約300 kgf・約1936–39＝世界初He178 1939より前）→**双発要撃の完成形**（E-6）。
- **載せ替え機構**（`aviation-rework` §4-1）：機体は核の完成を待たず、暫定発動機で先に飛ばし本命核へ載せ替える。実証と完成形の期間は重なる（前例：瑞星→栄の零戦、機首ピストンで初飛行したMe262 V1）。これは**新規性の載せ方の律**（`tensei-engineer-kufu-shu.md` §2）の時間版——実績の機体・操縦・系統を土台に、核の異常だけを帰属可能にし、暫定核を後退路に残す。
- **本機の位置**：海軍の試製契約で、機体＝中島、発動機＋知財＝浅井。最初の専用実証機で「飛ぶジェット」を世界に先んじて示し、その経験を双発要撃の完成形に集約する。脅威（高高度爆撃B-29級＝史実1944）の前に、成熟した要撃機を持つ前倒しのリード。

## 2. 名称と所管

**所管＝海軍（局地戦闘機）**。理由：史実のジェットが海軍主導（橘花＝中島・Ne-20＝海軍系）、浅井の官需が海軍（艦政本部・工廠）中心、陸上の点防御要撃は海軍局地戦闘機（雷電・天雷の系統）の受け皿に合う。陸軍（キ番号・Ki-44の土壌）も候補だが本命は海軍。

| 対象 | 社内名称（浅井／中島） | 海軍名称 |
|---|---|---|
| 発動機・純ジェット | **E-6J**（E号機第6世代・噴流後端） | **ネ三〇（Ne-30）** |
| 発動機・出力寄りバイパス | **E-6JF**（同・ファン後端） | **ネ三〇改** |
| 機体（計画） | **噴進一号**、社内略「**噴一（ふんいち）**」 | **J2N**（局地戦闘機・中島。十四試局戦の中島側要求枠をこの世界では本機が吸収する作業案） |
| 制式・愛称 | — | **霹靂（へきれき）**：一一型＝純ジェット、二一型＝出力寄りバイパス |

固有名はすべて【設定】。海軍戦闘機の気象現象名の範囲から「霹靂（へきれき）」を採る。ジェットの社内呼称は当時語の「噴進（ふんしん＝噴射推進）」から「噴進一号」を維持する。略号は **J2N** で確定【2026-08-14・番号列照合】。海軍略号の数字は就役順ではなく、**機種カテゴリごとの海軍計画番号**（A5M＝九試／A6M＝十二試／A7M＝十七試と、番号と○試が一致しないことがその証拠）。同番号がメーカー記号違いで併存するのは**同一要求への競争試作**の場合で、史実にB5N／B5M、B4M／B4N／B4Y、D3A／D3N、E8A／E8K／E8Nの前例がある。本世界線では**十四試局地戦闘機**に対し、三菱が在来ピストン（雷電J2M）、中島＋空技廠＋浅井がジェット（霹靂J2N）を出し、性格が違うため**両案とも採用**された、と読む。九七式艦攻でB5N・B5Mが揃って採用されたのと同型。

## 3. 諸元——初飛行時と完成形

同じ機体を、暫定核で先に飛ばし（初飛行）、本命核へ載せ替えて完成形にする。三状態を並べる。数値の芯は中央値、上下は帯（`core-hierarchy` §2）。

| 項目 | 初飛行時（暫定） | 完成形・一一型（純ジェット） | 完成形・二一型（出力寄りバイパス） |
|---|---|---|---|
| 時期（仮） | 約1939–40 | 約1940–42 | 約1941–43 |
| 発動機 | E-6J 未完につき**暫定 E-5J ×2**（社内）／海軍 試製 | **E-6J ×2／ネ三〇** | **E-6JF ×2／ネ三〇改** |
| 推力（計） | 約600 kgf【物理】 | 約1,000 kgf【設定】 | 静止 約1,300〜1,400 kgf／高速時は減（後置ファン）【物理/設定】 |
| 全備重量 | 約3,600〜3,800 kg（武装・燃料を絞る）【設定】 | 約4,000 kg（3,800〜4,200）【設定】 | 約4,000〜4,300 kg【設定】 |
| 推力重量比 | 約0.16（非力・機体実証用）【物理】 | 約0.25【物理】 | 静止で約0.30〜0.34、最高速時は一一型以下【物理】 |
| 最高速度（海面） | 約550〜580 km/h【物理/設定】 | **約720 km/h**（高度7〜8 kmで約755〜775・対ピストン差+180〜220）【物理/設定】 | 約650〜685 km/h（−5〜10%）【物理/設定】 |
| 実用上昇限度 | 低い（暫定）【設定】 | 約12,000 m 級【設定】 | 約12,000 m 級、上昇率は一一型より良【設定】 |
| 武装 | 無/最小（実証）【設定】 | 高初速20mm×4（機首集中）、30mmは成長余地【設定】 | 同左【設定】 |
| 滞空 | 試験飛行のみ | 約66〜100分（点防御）【物理】 | 約88〜140分（内部）【物理】 |
| 航続 | — | 約770〜1,100 km（点防御）【設定】 | 内部 約1,300〜1,550 km／灯油増槽一対で約2,100〜2,400 km【物理/設定】 |
| 燃料 | 灯油・軽油 | 灯油・軽油 | 灯油・軽油＋**粗い使い捨て増槽**（不揮発で安全）【確認済み(燃料特性)/設定】 |
| 乗員 | 1 | 1 | 1 |
| 寸法（仮） | 全幅 約11 m・全長 約9.5 m・翼面積 約14 m²【設定/要確認】 | 同左 | 同左（ポッド後段が太く長い）【設定】 |
| 配置 | ポッド双発・前輪式・全金属（機首が空く） | 同左 | 同左 |
| 用途 | **機体・操縦・系統の実証**（性能は未代表） | 最速の点防御要撃 | 使える主力要撃／戦闘（護衛・哨戒は増槽で） |

要点。初飛行の暫定（E-5×2＝600 kgf・T/W0.16）は**非力で、示すのは機体・操縦・系統であって完成形の性能ではない**（瑞星零戦と同じ。`aviation-rework` §4-1）。本命のE-6へ載せ替えて一一型（最速720・点防御）になり、後端を後置ファンに替えた二一型が、最高速を少し譲って上昇・航続・離着陸を得た**使える主力**になる（`jet-interceptor` §4b・§4c）。

同時期の同等品（その年で測る）：零戦532（1940・20mm×2）、Ki-44 580（1942）。一一型の720はこれより**120〜180 km/h速い**。Me262（1944）や橘花（1945）とは並べない。

## 4. 速度の芯の取り方（再掲・検算）

橘花の海面623 km/hから実効抗力係数を逆算すると約0.037（粗い）。良い設計で約0.028（橘花より清浄・過大に寄せない）を芯に取ると海面約720 km/h【物理】。幅は粗ければ約615、非常に清浄なら約815。芯720、上下は帯。雛形は橘花（全備3,500〜4,080 kg・2×約475 kgf・海面623/高度696・30mm×2【確認済み】）とMe262（構成が最も近い）。二一型の650〜685は、720から後置ファンの最高速代償（−5〜10%、`aviation-forms` §3）を引いた値。

## 5. タグ・次の作業

- 【確認済み】：橘花（諸元・初飛行1945）、Me262（構成・1944）、零戦532（1940）・Ki-44 580（1942）、20mm Type99（初速600〜759 m/s）、灯油の引火点約38℃・密度約804（航空ガソリン約−40℃・約690）、瑞星→栄の零戦・機首ピストンのMe262 V1。
- 【物理】：推力重量比と全備重量、最高速度（抗力係数を橘花で校正）、暫定推力での速度、滞空、バイパスの代償。
- 【設定】：全年次、固有名（E-6J/E-6JF・ネ三〇・J2N・霹靂・噴進一号）、全備重量・武装・上昇限度・航続の帯、寸法。
- 【要確認】：機体メーカーの確定（中島で置く）、寸法の実数、給排気の組み込み、30mm搭載構造、増槽の具体、二一型の重量内訳。
- 次：需要の高い一型（一一型の最速要撃か二一型の主力）を、重量内訳（構造・燃料・武装・装甲）と高度別の速度・上昇・到達時間まで一段深く詰める。
