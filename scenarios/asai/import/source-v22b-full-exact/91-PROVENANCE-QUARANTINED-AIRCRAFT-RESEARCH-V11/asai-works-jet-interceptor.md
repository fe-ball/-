# ジェット実用機（双発要撃機）——契約・機種・性能

> **v46 engine authority / H→A fence.** E6-M-J is now ~850 kgf/engine non-Ni and ~900 kgf/engine Ni; E6-M-JF is ~950–1,000 kgf/engine (central ~984 at 835°C, BPR~1/FPR~1.30). Older 500 and 650–700 kgf engine values, and aircraft performance derived from them, are A_old/conditional until dedicated aircraft H→A. Authority: `asai-works-e6-m-jf-installed-thrust-rebaseline-1938-43.md`.

`asai-works-aviation-airframes.md` の「ジェット実用の初号機」（約1940–42、E-6）を、どういう契約でどこと結び、どういう機種として、どういう性能で現れるべきかで詰める。本稿は `tensei-engineer-kufu-shu.md` の規則に従い、数値は【確認済み】【物理】【設定】【要確認】で区別する。**性能はその年（1940–42）の実在機で測る**——Me262（1944）でも橘花（1945）でもない。形式の連続体（純ジェット↔出力寄りバイパス）は `asai-works-aviation-forms.md`、年次は `asai-works-aviation-timeline.md`。単発/双発・燃料・タイミングの洗い直しは `asai-works-aviation-rework.md`、開発史・名称・諸元（初飛行/完成形）は `asai-works-jet-interceptor-program.md`。

## 1. 契約と相手

- **顧客**：海軍が本命。浅井の海軍関係（艦政本部・工廠）と、史実のジェットが海軍主導だった事実（橘花＝中島の機体、Ne-20＝海軍系）に乗る。陸軍も候補で、Ki-44（速度・上昇を重視した要撃機）の土壌があるので受け皿になる。
- **形態**：海軍の試製（実験）契約で開発資金を取り、成れば制式。**浅井＝発動機（E-6）＋知財の保持＋発動機の量産**、機体＝一流メーカー（中島・三菱）または海軍航空技術廠（空技廠）。史実の橘花（海軍主導・中島の機体・石川島のNe-20）と同じ構図だが、発動機の源と知財を浅井が握るのが綾。
- **時機の論理**：1940–42は要撃の切迫前で、高高度爆撃の脅威は史実で1944年（B-29級）。だからこの契約は**前倒しの技術リード**として結ぶ。脅威が来た時に成熟した要撃機を持つ＝史実の橘花（1945年・実戦に間に合わず）より数年早く、しかも実用として。

---

## 2. 機種（役割）

- **陸上の高速・高高度要撃機**。双発（2×E-6）、重武装、点防御（短滞空）。
- ジェットの性質に素直＝巡航しない。上がって迎え撃つ。高高度で速度と上昇が効く（抗力が下がり、ジェットは高空で伸びる）。
- 配置はポッド型か翼内（`saiko`）。二基ぶんの推力で、本格的な要撃機になる。

## 3. 性能（目標）

| 項目 | 目標値 | タグ |
|---|---|---|
| 発動機 | E-6 ×2、推力計 約1,000 kgf | 設定 |
| 全備重量 | 約4,000 kg（3,800〜4,200） | 設定 |
| 推力重量比 | 約0.25 | 物理 |
| 最高速度 | **A_old：海面 約720 km/h／高度7〜8 km 約755〜775 km/h**。v46推力ではH→A再計算待ち | 旧物理／設定 |
| 上昇 | 良好（推力重量比0.25＝点防御に十分） | 物理 |
| 武装 | 導入時は高初速の20mm ×4（爆撃機狩り）。30mmは後の成長余地 | 設定／要確認 |
| 滞空 | 約66〜100分（点防御、巡航しない） | 物理 |
| 実用上昇限度 | 約12,000 m 級 | 設定 |
| 燃料 | 灯油・軽油（オクタンの制約を回避） | 設定 |

旧速度モデルは橘花から実効抗力係数を逆算して海面約720 km/hを芯としていたが、これは旧500 kgf/基を前提にした**A_old**である。v46では静止推力だけを置換せず、intake recovery・nacelle/wetted drag・engine mass/CG・fuel・altitude thrust・compressibilityを同時に閉じる。

雛形は橘花（全備3,500〜4,080 kg・2×約475 kgf＝約950 kgf・海面623/高度696 km/h・30mm×2【確認済み】）。E-6二基の約1,000 kgfは橘花よりやや強く、設計を清浄にする分だけ速い。

武装の置き方（開発史上の位置）：1940–42に日本が持つ航空機関砲は20mm（Type 99、海軍1939年制式。初速は低初速のModel 1の約600 m/sから高初速のModel 2の約759 m/sまで）【確認済み】。日本の30mm（Type 5・Ho-155）は1942年開発開始〜1945年で、この機の導入時には早すぎる。だから**導入時は高初速の20mmを機首に集中装備**する。発動機がポッド／翼内で機首が空くので、4門級の重武装が無理なく載る（カナード型ほどではないが、機首の遠慮はない）。口径をこの機のために新造するのではなく、既存の20mmと、伸ばした弾道（高初速）を使う。30mmは成長余地——日本の30mmが熟す1944–45、または輸入（独MK 101＝1940年・高初速、MK 103＝1943年・約860〜940 m/s）で前倒しもできる。彼の特殊鋼は高圧の砲身に効くので、高初速化に寄与しうる。高火力・高弾速を志向するのは正しく、機体は重武装と将来の30mmを受ける設計にするが、初手は実在の高初速20mmから。

## 4. 単発の軽量案（参考）

旧単発E-6（500 kgf）・全備約2,000〜2,300 kgの海面約595 km/h案は**superseded input / A_old**。v46 E6-M-Jは約850 kgf/基なので、単発廉価点防御案も専用H→Aを行うまで性能値を固定しない。

## 4b. 出力寄りバイパス派生——「速い刃」から「使える戦闘機」へ

純ジェットの双発要撃機は速いが、静止推力が弱く・燃費が悪く・足が短い（点防御の刃）。同じ機体の後端を**低バイパス（出力寄り）**に替えると、弱点が埋まる（`aviation-forms` §3）。ファンは冷部なので、温度天井（熱部）を一切使わずに推力を足せるのが要。

| 項目 | 純ジェット形 | 出力寄りバイパス形 | 効き |
|---|---|---|---|
| 後端 | 推進ノズル | 後置ファン（BPR≈1 / FPR≈1.30） | gas-generator単軸＋**独立free-LP-turbine/fan spool** |
| 最高速（海面） | **A_old：約720 km/h** | **A_old：約650〜685 km/h** | v46 H→Aで両者とも再計算 |
| 静止・離陸推力 | 基準 | 約1.3〜1.4倍 | 短い飛行場・急上昇 |
| 比燃費 | 基準 | 約2〜3割改善 | 滞空・進出が伸びる |
| 滞空 | 約66〜100分 | 約88〜140分 | 点防御から哨戒・直掩へ |

数値は `aviation-forms` §3 の帯と熱効率是正（圧力比7・`core-generations`）からの試算【物理／設定】。最高速を少し譲る代わりに、上昇・離陸・航続を得る。**純ジェット形＝最速要撃・記録、出力寄りバイパス形＝量産の主力要撃／戦闘**の二本立てにできる。映えるのは純ジェット形、数で効くのはバイパス形。超音速を狙わない以上、譲る最高速は捨ててよい余白で、機体は共用できる（`jet-interceptor-airframe` §1）。

## 4c. 燃料＝役割選択（点防御の自縛を解く）

短滞空は事実だが「点防御のみ」は自縛だった。バイパスで比燃費2〜3割改善、灯油は容積あたり熱量が約1割多く（密度約804 vs 約690 kg/m³）、かつ引火点約38℃（航空ガソリン約−40℃）で不揮発・安全【確認済み】。だから増槽は粗く安く使い捨てでき（薄板・木質）、湿潤翼も火災を恐れず使える。

同じ機体が、清浄なら点防御（上昇・速度）、安い灯油増槽を付ければ護衛・哨戒（航続）に変わる。交戦時は投棄。バイパス双発で内部のみ滞空約88〜140分・航続約1,300〜1,550 km、灯油増槽一対で約2,100〜2,400 km【物理／設定】。燃料は硬い上限でなく役割の摘み（`aviation-rework` §3）。

## 5. 同等品で見た位置と戦略

- **同時期（1940–42）の最良**：零戦 約532 km/h（1940・20mm×2）、Ki-44 約580 km/h（1942・速度/上昇重視の要撃機）【確認済み】。双発E-6要撃機の芯720は、これより**約120〜180 km/h速い**＝世代を跨ぐ速さ。これがその年の相手であって、Me262（1944・約870）や橘花（1945）と並べない。
- **差は高度でむしろ開く（最大の見せ場）**：ジェットは高度で速度を保ち伸ばす一方、ピストンは全開高度（零戦52 約565 km/h@6 km、Ki-44 約605 km/h@5 km）を超えると出力が落ちる。**要撃が起きる高度7〜8 kmでは、本機約755〜775 km/hに対しピストンは約540〜580 km/hで、差は+180〜220 km/hへ拡大**【物理／設定】。海面の+120〜180でなく、この高度差こそ点防御要撃の土俵（`aviation-forms` §7）。
- **戦略**：1940–42に実用要撃機として現れ、史実の橘花（1945・未戦）より数年早い。高高度爆撃の脅威（史実1944）を、成熟したジェット要撃機で迎えられる。燃料が灯油・軽油なのも、戦争後期の航空ガソリン枯渇に対し強い。
- **限界**：滞空が短い＝点防御に限る（巡航・進攻には向かない）。初期ジェットの信頼性・整備、給排気の機体組み込みは課題。誇張せず、要撃という一点で同時期の何より速い、が結論。

## 6. タグの区別

- 【確認済み】：零戦（1940・約532 km/h・20mm×2）、Ki-44（1942・約580 km/h・速度上昇重視）、橘花（全備3,500〜4,080 kg・2×約475 kgf・海面623/高度696 km/h・30mm×2・初飛行1945）、空技廠・中島・石川島Ne-20の構図、日本の航空機関砲（20mm Type 99＝1939年・初速600〜759 m/s、30mm Type 5/Ho-155＝1942開発〜1945）、独MK 101（1940）/MK 103（1943・約860〜940 m/s）。
- 【物理】：双発E-6の推力重量比、最高速度（抗力係数を橘花で校正）、滞空、単発案の速度。
- 【設定】：E-6の推力・全備重量・武装・上昇限度・各年次、契約の形態、清浄度の芯（CD0≈0.028）。
- 【要確認】：機体メーカーの確定、給排気の機体組み込み、滞空の燃料前提、30mm搭載の構造。

## 7. 次の作業

- 機体の作り手（中島・三菱・空技廠）を一つに絞り、据付（吸排気・重心・武装）を具体化する。
- 高度での速度・上昇・上昇限度を、高度の空気密度で試算する。
- 海軍要撃と陸軍要撃の要求差（艦上運用の可否、上昇率の目標）を分けて詰める。
