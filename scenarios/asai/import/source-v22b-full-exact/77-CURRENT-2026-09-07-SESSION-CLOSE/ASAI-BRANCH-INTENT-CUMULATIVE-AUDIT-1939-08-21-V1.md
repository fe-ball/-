# ASAI WORLDLINE — BRANCH INTENT & CUMULATIVE AUDIT V1
## Checkpoint: China 1939-08-21 / Nomonhan 1939-08-31

### 1. Branch intent

This branch is a **procurement / operational-use correction branch**, not a “make Japan win” branch.

Primary intent:
1. Rebase E5 Twin and Ki-42 from rare/special experimental assets into their already-supported 1937–39 military procurement lineage.
2. Separate capability -> qualification -> adoption -> production -> allocation -> serviceability -> forward presence -> combat use -> effect.
3. Carry every previously closed Asai effect forward; never delete old gains just because the aviation model is being corrected.
4. Replace old scarce-Ki40/special-recon effects where the new E5 system supersedes them; do not double count.
5. Add effects previously omitted:
   - persistent recon
   - BDA/restrike
   - same-airframe high cover
   - command/courier latency reduction
   - common-airframe sortie persistence
   - opportunity-cost release of conventional aircraft
6. Model enemy response as:
   observation -> recognition -> understanding -> decision -> resources -> implementation -> proficiency.
   None of these stages is automatic or free.
7. Better reconnaissance must also increase caution toward **unobserved** sectors; “not seen” is not “absent.”
8. Reopen nonlinear campaign gates only when the new physical/information delta actually crosses a threshold.
9. Do not force historical outcomes, and do not force anti-historical victories.

### 8. Nomonhan — revised branch vs historical reference

Published Japanese historical combat-loss figures cluster around **~17.4–17.7k combat casualties** depending on definition.

Against that scale, revised Japanese combat loss of ~9.35–9.85k is approximately:
- **~7.5–8.4k fewer combat casualties**
- roughly **43–47% below** the historical Japanese combat-loss scale

Soviet/Mongolian historical loss definitions vary more substantially.
The revised ~23.4–24.2k class remains within the broad order of archival historical Soviet/Mongolian casualty scales, while the Japanese loss is much lower than history.

Thus the exchange ratio is dramatically more Japan-favorable than history, even though Japan still loses the territorial/operational contest.
