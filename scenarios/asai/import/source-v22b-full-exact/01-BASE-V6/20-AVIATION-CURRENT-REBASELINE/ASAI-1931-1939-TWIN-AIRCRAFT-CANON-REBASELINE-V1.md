# ASAI 1931–1939 TWIN-AIRCRAFT CANON REBASELINE V1
Status date: 1939-09-01 00:00
Authority: current-branch aviation rebaseline.
Purpose: restore the continuous military twin lineage, define each block/configuration by what problem it solves, and prevent later summaries from turning a military prototype back into a generic research aircraft.

## 0. Authority correction

The twin lineage is continuous:

**E4 company systems testbed
→ structured military requested testing
→ 1935 H2–1936 H1 military technical-prototype requirement
→ 1937 E5 pure-jet military technical prototype
→ 1937 E5 aft-fan comparison prototype
→ 1938 development/service-evaluation block

There is no new "birth of the military twin program" in late 1938.

The following older statements are superseded only where they deny this Stage-M military requirement:
- Gate 64: "Asai-funded; not a formal military-requirement aircraft."
- Gate 68/69: No.2 as merely another company research airframe.
- Gate 76: aft-fan first flight deferred to Sep–Oct 1938.

## 1. What the military is buying

The military did not first ask Asai for "a jet fighter."

It first asks for a **militarily realistic high-speed twin technical prototype** that can answer several questions with the same basic aircraft:
- can a turbine twin return on one engine;
- can radio/photo equipment be integrated and kept usable;
- what happens when fuel is increased for useful radius;
- what payload/weapon volume can be carried without destroying speed;
- how quickly can the aircraft be turned around;
- can the propulsion system be supported by non-Asai personnel;
- which propulsion allocation—pure jet or aft-fan—best fits an actual military mission.

That broad requirement is intentionally narrowed only after flight data exist.

This distinction is the central anti-hallucination guard:
**military requirement exists before final service role exists.**

## 4. 1935 H2–1936 H1 military technical-prototype requirement

Status:
**MILITARY TECHNICAL REQUIREMENT — CLOSED**

The requirement directs a new E5 twin prototype.

Required characteristics:
- two seats for pilot + observer/test/mission crew;
- substantially higher speed than E4;
- practical radio/photo fit;
- greater fuel flexibility;
- one-engine return;
- representative mission-bay/weapon provision;
- maintainable nacelles;
- military-standard instrumentation/reporting.

The requirement deliberately does not fix:
- interceptor vs reconnaissance vs heavy fighter vs light strike as the final category;
- pure jet vs aft-fan as the final propulsion backend.

The first prototype is therefore a **requirements-discovery aircraft under an actual military contract/requirement**, not a company curiosity.

## 5. E5 Twin No.1 — pure-jet military technical prototype

First flight:
**1937 Q1–Q2 working band.**

Status by summer 1937:
**FLYING MILITARY-REQUIREMENT TECHNICAL PROTOTYPE**

Working physical anchors:
- 3.5–4.0 t class;
- crew 2;
- 2 × E5-J;
- installed/static thrust planning band roughly 430–470 kgf per engine;
- working low-altitude speed envelope roughly 510–560 km/h depending configuration and drag.

### 5.1 The aircraft is one prototype with several mission configurations

Do not create separate aircraft types from every test fit.

#### Configuration J-C — clean/high-speed
Purpose:
- interceptor/heavy-fighter speed envelope;
- climb;
- control at high dynamic pressure.

Allocation:
- fuel: LOW–MEDIUM;
- mission equipment: MINIMUM representative fit;
- ballast/armament: representative, not full operational burden;
- speed/climb: MAXIMUM.

Expected position:
upper part of the 510–560 km/h working band.

Military value:
shows whether the turbine twin can enter contemporary fighter/interceptor speed space.

#### Configuration J-R — reconnaissance/command
Purpose:
- high-speed photography;
- radio;
- useful radius;
- repeat sortie.

Allocation:
- fuel: HIGHER;
- photo/radio: FULL technical fit;
- speed: deliberately traded down;
- endurance/turnaround: HIGH priority.

Expected position:
middle/lower part of the 510–560 km/h envelope.

Military value:
shows that the aircraft's real advantage may be **getting information back**, not simply winning a speed record.

#### Configuration J-W — weapon/mission-bay
Purpose:
- representative cannon/weapon ballast;
- light-bomb/mission-bay load;
- recoil/vibration/inlet interaction;
- CG.

Allocation:
- weapon/mission load: HIGH;
- fuel: NORMAL;
- maximum speed: secondary.

Military value:
defines what the same basic aircraft gives up when turned into a heavy fighter or light strike aircraft.

### 5.2 1937 military judgment

Navy technical preference:
1. high-speed land interception / local defense as a high-value future role;
2. high-speed reconnaissance;
3. propulsion/nacelle/control learning.

Army technical preference:
1. high-speed reconnaissance / command reconnaissance;
2. heavy-fighter/escort envelope;
3. light high-speed strike.

Common conclusion:
**pure jet proves the speed end of the envelope, but fuel, repeat-sortie burden and low-speed thrust are too important to freeze the service configuration yet.**

This is why No.2 is not redundant.

## 6. Aft-fan research timing — corrected

The aft-fan cannot start as late as 1937–38.

Asai already owns free-power-turbine knowledge from the early turboprop/shaft program.

The early design choice is specifically to avoid making a conventional front-fan/multi-spool engine the central path.

Architecture:
**single-spool gas generator
→ separate one-stage free LP turbine
→ direct-drive aft fan + stator**

This still adds an LP/fan spool.
It is not mechanically free.

The advantage is that it reuses:
- free-power-turbine practice;
- governor/control practice;
- rear hot-section/shaft integration;
while avoiding an early long coaxial front-fan/multi-spool architecture.

Corrected chronology:
- 1933–34: E4-scale fan/free-turbine rig work;
- 1934–35: full-scale E4/E5 transition ground rigs;
- 1935–36: E5 aft-fan becomes a planned comparison backend in the military twin program;
- 1936: second development airframe planned/authorized;
- **1937 Q4: E5 Twin No.2 aft-fan first flight**;
- 1938: durability, controls, mission fuel and maintenance—not basic proof of concept.

## 7. E5 Twin No.2 — aft-fan military comparison prototype

Status:
**SECOND MILITARY DEVELOPMENT PROTOTYPE / PROPULSION-ALLOCATION COMPARISON**

The current later measured/qualified E5 aft-fan anchors remain useful:
- bench static 535–565 kgf;
- installed usable 515–545 kgf;
- complete dry 455–505 kg;
- BPR ~0.8–1.0;
- FPR ~1.25–1.30;
- TSFC roughly 15–18% below E5 pure comparison.

Interpretation:
these are mature/re-certified E5 aft-fan values by 1938 H1, not evidence that the concept first existed in June 1938.

### Capability allocation

Compared with No.1 pure jet:

- maximum/high-speed specific thrust: TRADED DOWN;
- static/low-speed thrust: UP;
- takeoff acceleration: UP;
- climb after takeoff: UP;
- go-around margin: UP;
- fuel consumption: DOWN;
- mission radius/endurance: UP;
- nacelle area/mass: UP;
- complexity: UP modestly because of free-LP/fan spool;
- thermal-material demand: does not rise in proportion because the fan is cold-side work.

Military judgment by early/mid 1938:
**aft-fan is no longer an exotic research option; it is the practical-mission alternative to pure jet.**

The comparison becomes:
- J = speed knife;
- JF = usable radius / low-speed thrust / repeated-mission configuration.

## 8. 1938 E5 development/service-evaluation block

Status:
**LIMITED MILITARY DEVELOPMENT / SERVICE-EVALUATION PROGRAM**

The technology does not remain at "two prototypes forever."

Once No.1 and No.2 answer the principal propulsion questions, the military needs enough aircraft to learn:
- crew procedures;
- field maintenance;
- engine/module exchange;
- radio/photo mission cycle;
- fuel handling;
- sortie generation;
- unit-level defects.

Working program size:
**6–10 aircraft-class total follow-on evaluation program**, exact delivered serial count still OPEN.

Preferred mix:
- minority pure-jet aircraft for clean/high-speed interception data;
- majority aft-fan aircraft for practical mission/endurance/maintenance data.

This is not a combat regiment and not mass production.

Military judgment:
**"E5 is good enough to buy operating knowledge even though E6 is already coming."**

This is deliberate product-block freezing.

## 9. Late-1938 requirement refinement — not requirement inception

Late 1938 is when the broad military prototype requirement is narrowed.

The decision is based on:
- pure-jet versus aft-fan flight data;
- China reconnaissance/communications experience;
- customer maintenance experience;
- fuel/range and landing/field burden.

### Navy direction
Two increasingly distinct needs appear:

**Navy H — high-speed land interceptor**
- speed/climb first;
- clean fuel state acceptable;
- short endurance accepted;
- pure jet favored.

**Navy M — usable local-defense/escort/recon system**
- more endurance;
- better takeoff/go-around;
- repeated sorties;
- aft-fan favored.

A later carrier branch must additionally pay deck/landing physics; it is not automatically produced from the land prototype.

### Army direction
The Army increasingly values:
- strategic/high-speed reconnaissance;
- heavy-fighter/escort comparison;
- command reconnaissance;
- useful field radius.

Therefore its preference leans more strongly toward the aft-fan/mission-oriented allocation, while still valuing pure-jet speed data.

No decision in 1938 says "all future aircraft use aft-fan."

Purpose:

## 14. Fuel and landing are part of the military decision

The twin program is explicitly tied to the broader Asai aviation philosophy.

More efficient propulsion or lighter structure does not automatically become speed.

The military can allocate the gain to:
- fuel;
- radio/photo equipment;
- weapons;
- protection;
- reserve/alternate field margin.

But added fuel raises landing weight.

At the same wing/CLmax:
- +10% landing weight gives roughly +4.9% stall-speed scale;
- +20% gives roughly +9.5%;
and landing/arresting energy rises faster still.

Therefore the high-speed twin solves landing by:
- mission fuel discipline;
- jettisonable external fuel where appropriate;
- fuel dump on large/high-value configurations if justified;
- stronger gear/brakes;
- high-lift refinement;
- runway/deck operating rules.

It does **not** automatically become the STOL aircraft.

The small TP/STOL family is the separate low-speed school created precisely because some missions cannot accept the high-speed twin's landing burden.

## 15. Production vision

The program must not be trapped between:
"prototype forever" and "mass production immediately."

### E5
Produce enough for development/service evaluation because:
- mission value is real;
- failure modes are bounded enough for supervised operation;
- maintenance knowledge has value even if E6 supersedes performance.

### E6
Freeze a production block only when:
1. the service chooses a real mission;
2. basic airframe/engine interface stops moving;
3. the remaining failures are supportable;
4. fuel, spares, maintainers and fields exist.

The research frontier may already be moving toward E7 components.
That does not prohibit an E6 production block.

## 16. 1939-09-01 military picture

### Navy
- E6-J: serious specialized land-interceptor candidate.
- E6-JF: serious practical local-defense / long-leg derivative candidate.
- carrier use: separate deck/landing gate; no automatic adoption.

### Army
- E6-JF: high-interest for fast reconnaissance/heavy-fighter/escort/command missions.
- E6-J: retained for speed/interception comparison.
- does not automatically displace Ki-46 or piston programs until cost, field support and mission value justify it.

### Joint conclusion
The military is no longer asking:
**"Can a turbine twin fly?"**

It is asking:
**"Which allocation of the turbine twin should we freeze into an operational block, and for which mission?"**

That is the correct institutional state by September 1939.
