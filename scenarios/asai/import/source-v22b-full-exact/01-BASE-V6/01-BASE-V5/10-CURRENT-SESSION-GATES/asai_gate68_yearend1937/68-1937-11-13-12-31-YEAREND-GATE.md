## 1. 戦線：年末まで大きな日付差は出さない

1937-11-18、嘉興–蘇州–常熟線では中国軍の増援が進み、雨天が日本軍作戦を遅らせている。
浅井の車両・砲兵・整備差はこの雨・道路容量・橋梁条件を消せない。

大きな占領日：
- 11/19 蘇州
- 11/25 無錫
- 11/30 広徳
- 12/02 江陰
- 12/08–09 鎮江 / 南京包囲完成
- 12/10 蕪湖方面
- 12/13 南京
- 12/24 杭州

をすべて**同日カレンダー**で維持する。

浅井差は局地的に数時間の先行を作るが、上海撤退を数時間早くした負のfeedbackによって中国側の一部人員も保存されている。
その保存兵は南京・後方線へ流入するため、日本側のF/M/S差がそのまま日付差へ累積しない。

南京守備では、87/88/36等の古参系は人数が多少多く残っても、上海以来の下級指揮官・重装備・通信・ cohesion損失を回復していない。
したがって「守備兵が少し増えた＝南京が数日延びる」ともしない。

**1937年を通じた重要結論：**
浅井の工業差は現場の可動率・損害・maintenance debtには既に明瞭だが、
1937年の主要戦役カレンダーを一日単位で変えるところまではまだ到達しない。

## 3. E5万能双発 — 年末までにかなり成熟

E5双発No.1は1937年の浅井航空研究の主役として継続。

年末の進捗目安：
- basic envelope: **80–90%**
- engine/nacelle integration: **75–85%**
- single-engine handling/return: **55–70%**
- camera/radio/mission bay: **60–70%**
- endurance/repeat sortie/TBO: **40–55%**
- live armament / real strike qualification: 依然低い

本機は「飛行機として成立するか」はもう主要問題ではない。
軍用化の律速は航続、TBO、再始動、throttle、高度推力、再出撃整備時間。

### 双発2号機
12月中に**研究用2号機1機を1938年建造することを承認**する。
これは軍の制式試作機ではない。

一機しかないNo.1へ
- pure jet性能
- endurance
- mission system
- aft-fan
を全部載せ替えると試験が止まるため、二機化する合理性が強くなった。

会社が構体を負担し、陸海軍技術側は試験費・計測・試験時間を買う形を中央案とする。
軍採用段階はA2+のまま。

## 4. E5単発 — 1937年内に初飛行まで進める

11/12に地上統合～初飛行直前だった一機は、
**1937年末までに初飛行達成をCLOSE**する。

正確な一日は固定せず、
**11月末～12月上旬**をcurrent canon date-bandとする。

年末までのworking：
- 初期飛行：8–15 sortie程度
- flight time：5–10 h程度
- 吸気 / CG / 中央後部発動機 / 尾部熱 / 基本操縦を実飛行で確認
- flight envelopeは約25–35%
- 軍用邀撃適合はまだ低い

したがってこれは成功した「architecture demonstrator」であり、
1937年制式邀撃機ではない。

**E6が初めて実用単発邀撃/偵察/戦闘機候補**という整理を維持する。

別建ての小型初期GT戦闘機は復活させない。

## 5. E5 aft-fan

## 9. 航空GT量産構想 — 年末に初めて“紙の計画”が完成

11月時点では大規模売込みを抑えていたが、
南京占領後も中国政府の抗戦継続が見え、12月下旬には日本側自身も「事変が当初想定を超えて長期化する可能性」を認識し始める。

ここで浅井は、
**航空E5量産の非常時能力回答書 / contingency production memorandum**
を完成させ、軍技術側へ回答できる状態にする。

これは量産受注ではない。

Working feasibility:
- 現混成工場を大きく壊さないpilot production：**6–10 flight-grade cores/month**
- 数か月の優先転換後：**20–30/month級**
- 1938拡張タービン設備がqualification後：**40–60/month級**を狙える

ただし、
- hot-section材料
- bearing
- balancing
- inspection
- skilled labor
- test cell
を別途割り当てる必要がある。

「今すぐ500機分作れる」という提案ではない。

12月末でもTrautmann和平工作が残るため、
**formal mass-series proposal/orderは1938年1月gateへ送る。**
