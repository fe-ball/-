# 1937-07-08 12:00–18:30 — 盧溝橋事件 afternoon gate

## 判定

**CLOSED-SAME THROUGH THE 18:30 WITHDRAWAL DECISION.**

正午から18:30まで、現地交渉は北平側へ重心を移し、日本側は強硬条件を提示しつつも、最終的には18:30を期して永定河東岸へ自発撤収する方針を決める。current branchの浅井系車両・通信・材料差を当てても、この決心を反転させるほどの確定差はまだ生じない。

11:40に通州方面から動き始めた部隊、および天津からの増強部隊はこの午後に接近するが、史料上の厳密な輸送手段・到着分刻みは未確定。浅井世界線では重車両の信頼性/牽引力が良い可能性があるものの、歩兵・戦車・砲兵を含む混成縦隊全体の移動速度を大幅に上げるものではなく、18:30の撤収決定より前に「圧倒的増援が既に現場に揃った」とは置かない。

## 1. 12:00前後 — 部分相互撤退案

午前の森田中佐―王啓元第37師参謀間の折衝では、中ノ島西側の日本軍と南側中国軍を相互に撤退させる方向がまとまり、中国側承認後、合図から2時間以内の実施が想定された。

### 浅井差監査

- 当事者・要求・現地配置は同じ。
- 車両性能は交渉条件の成立に関係しない。
- 浅井本人/企業の政治介入なし。

**判定：史実同様。**

## 2. 午後 — 中国側増強と日本側増援接近

第37師側では、第219団第3営が盧溝橋・宛平周辺、団司令部と第1・第2営が長辛店、第110旅・第220団が龍王廟―張道村線に展開しており、午後も警戒・増強が続く。

日本側では11:40に通州方面部隊が現地へ向けて出発している。また天津所在の支那駐屯軍からも増強部隊が動き、19時頃には到着済みとする同時代大使館記録ベースの整理がある。

### 編成・輸送の注意

史料からは、事件当時の支那駐屯軍が天津に歩兵第1聯隊第2大隊、戦車隊、砲兵聯隊、工兵・通信等を持っていたことは確認できる。また7月9日未明の命令には「機械化部隊」というまとまりが明記される。

一方、**7月8日午後にどの部隊がどの車両・鉄道便で何時何分に通過したか**は、現段階では一次史料crosswalk未完。したがって、後世叙述にある「第2大隊＋戦車＋砲兵＋工兵が正午天津発」等をそのままCLOSEDにはしない。

## 3. 浅井重車両はここで初めて効き得るが、まだ分岐しない

current branchでは1937年までに砲牽引車・重6×4等へ過給ディーゼルが量産横展開している。ただし以下の理由から、午後の増援を何時間も前倒ししない。

1. **全部の軍用車が浅井過給ではない。** 史実九四式六輪等のガソリン系も残る。
2. 混成縦隊の速度は最速トラックではなく、戦車・牽引砲・道路・交差点・隊形管理などの最遅要素で決まる。
3. 浅井差が強く出るのは登坂・過熱・牽引余裕・故障率であり、平坦道路の短時間最高巡航速度を倍増させる設定ではない。
4. 通州方面部隊については徒歩/車載/鉄道の比率自体が未確定。

したがってcurrent branchで許すのは、**道路機動だった部分に数十分orderの余裕、故障脱落の減少**まで。18:30より十分早く大兵力が現地へ揃い、その事実が撤収決心を反転させる、とはしない。

**判定：vehicle effect = latent/minor, no event divergence through 18:30.**

## 4. 16:00前後 — 北平で三案提示

寺平大尉は秦徳純との直接会見を試みるが、秦は軍事会議等を理由に接触を避ける。電話折衝で日本側は概ね、

1. 日本軍を永定河東、中国軍を西へ撤退、
2. 中国軍が撤退しなければ武装解除、
3. 第29軍首脳を現地へ出して共同処理、

という三方向の案を提示する。秦は主要案を拒絶し、日本側は交渉決裂に近いと受け止める。

### 浅井差監査

- 軍事的優位がまだ新技術によって露呈していない。
- 増援が接近中でも、史実日本側自身が強硬策と平和的折衝を同時に保持していた。
- 通信・車両差は秦の政治判断を変える直接情報ではない。

**判定：史実同様。**

## 5. 18:30 — 日本側、自発的東岸撤収を決定

岩谷研究が引用する北平大使館記録では、日本側はなお平和的折衝に望みをかけ、**18:30を期して自発的に永定河東側へ撤収することを決定**し、秦徳純へ通達した。

ただし河邉旅団長の腹案は、交渉が決裂すれば天津からの麾下部隊到着を待ち、盧溝橋を攻撃するというものだった。つまり撤収決定は「増援を呼ばない」決定ではなく、**増援を背後に持ちながら一度引いて交渉を継続する**決定である。

これはcurrent branchでも重要で、浅井重車両により増援の道路行軍が多少滑らかでも、決心構造を逆転させない。

**判定：18:30 withdrawal decision = CLOSED-SAME.**

## 6. 史料上の保留事項

### 北平城門閉鎖

一部二次資料には7月8日12:20の北平城門閉鎖が記されるが、今回の主要一次史料ベース研究で同時刻を十分cross-checkできていないため、このgateの因果ノードには使用しない。実際に閉鎖されていても、18:30までの浅井差を生む要素ではない。

### 通州/Tianjin増援のexact arrival

19時頃には「天津軍の増強部隊が到着」とする大使館記録ベースの記述があるため、18:30 cutでは**まだ到着時刻を前倒しCLOSEしない**。current branchのexact arrivalは次gateで、史実到着幅と輸送手段をさらに監査する。

## 7. 18:30 cut state

1937-07-08 18:30時点のcurrent branch：

- 午前の部分撤退案は完全履行には至っていない。
- 中国第37師側は盧溝橋・長辛店周辺の兵力を維持/増強。
- 日本側も通州・天津方面から増援を動かしている。
- 浅井系過給重車両は一部機動の故障率/牽引余裕に寄与し得るが、増援全体を決定的に早着させたとは置かない。
- 北平での交渉は難航。
- **日本側は18:30を期して永定河東岸へ自発撤収する決定を史実同様に行う。**
- したがって、ここまで明確なbranch divergenceはまだない。

次gateは **18:30→7月9日05:00**。ここでは18:42頃の東京中央からの不拡大指示、19時頃の日本側増援到着、中国側約1500名への増強、19時以後の複数交渉ルート、そして第219団側の夜襲判断が絡む。ここは初めて「増援が到着したのに攻めずに交渉する」という条件と、夜襲という局地判断を別々に判定する必要がある。
