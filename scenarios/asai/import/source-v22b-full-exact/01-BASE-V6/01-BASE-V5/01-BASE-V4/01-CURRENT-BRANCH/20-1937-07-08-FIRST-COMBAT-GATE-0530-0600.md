# 1937-07-08 FIRST COMBAT GATE — 05:30–06:00

## 判定範囲

1937年7月8日05:30頃、盧溝橋・宛平付近で本格交戦が始まってから、06:00頃に調査団・交渉系統の働きでいったん射撃停止となるまでの最初の約30分を扱う。

## 史実baseline

北海道大学法学論集「盧溝橋事件における現地交渉（I）」は、支那駐屯歩兵第1聯隊戦闘詳報、北平陸軍機関業務日誌、北平大使館記録等を用いて以下を再構成している。

- 05:00、一木大隊長は永定河へ前進し、龍王廟・南方トーチカに対して射撃準備を命じた。
- 日中合同調査団が到着したため一度前進を止め、部隊は朝食を取った。
- 龍王廟付近で再び前進する日本軍に対し、中国側が停止を促す射撃を開始した。時刻は05:30。
- 事態拡大防止のため動いていた調査団の活動もあり、06:00にはいったん戦闘が停止した。
- 中国側城内本隊は白旗を掲げたが、城壁の一部隊は散発射撃を継続した。
- 日本側大隊本部は盧溝橋鉄橋の麓まで後退し、一部を永定河中ノ島へ残置した。中ノ島南側には中国兵約30名が残り、相互警戒状態となった。

防衛研究所・岩谷將も、第3大隊戦闘詳報等に基づき、05:30に双方が交戦へ入ったことを確認している。

## closure

### 05:30 — 再前進に対する射撃、本格交戦
**CLOSED-SAME.** 前gateで閉じた条件からそのまま発生する。

### 05:30–06:00 — 最初の火戦
**CLOSED-SAME-WITH-NOISE.** 浅井世界線でも火戦そのものの規模・時間帯・戦術的性格は史実と同じとする。個々の命中・死傷は偶然性が大きいため人物単位・人数単位を固定しないが、戦闘結果を変える装備差は認めない。

### 06:00 — 一旦射撃停止
**CLOSED-SAME.** 停止理由は火力差ではなく、現地調査団と双方の不拡大交渉がまだ機能していたこと。浅井差はこの交渉条件を変えない。

### 06:00時点の配置
**CLOSED-DIRECTION.** 日本側大隊本部は鉄橋麓側へ後退し、一部を中ノ島に残置、中国側も対岸・城壁側で警戒を続ける。細かな分隊位置は固定しない。

## 九六式軽機関銃について

1937年の九六式軽機は制式化・低率生産の入口であり、現branchでは浅井工具/QCによって量産準備が史実より若干滑らかになる可能性がある。しかし、これを理由に1937年7月の支那駐屯歩兵第1聯隊を全面的に九六式へ更新しない。

このgateでは、仮に少数の九六式が混在していても、05:30–06:00の短時間火戦を別の戦術結果へ分岐させるほどではない。したがって具体配備数はOPENのまま、event結果はCLOSEする。

## 死傷者の扱い

7月8–9日の日本側累計死傷について後続資料に数字があるが、この最初の30分だけへ確実に分解できる史料を現時点で確保していない。

したがってこのgateでは、
- 「双方に死傷者が出る」までCLOSE
- 05:30–06:00だけの正確な死者・負傷者数はOPEN
- 特定人物の生死を浅井差で変更しない
とする。
