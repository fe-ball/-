# 1937-07-07 EVENT GATE — 盧溝橋事件開始時点

## ルール

現branchの偶発事象ルールは次の通り。

> **条件が実質同じなら偶発的な出来事も起こる。関連条件が違えば、その史実事象を強制せず再判定する。**

これは「歴史を必ず史実へ戻す」規則ではない。偶発事件の直前条件を比較し、差分がその偶発性に関係するかを判断するための規則である。

## 1937年7月7日への適用

史実では7月7日夜、北平南西の盧溝橋・宛平付近で日本軍が夜間演習中に中国第29軍と衝突した。7月8日付の米国外交電報は、衝突が7月7日深夜直前に起きたこと、日本軍が同地域で約2週間演習していたことを報告している。後日の米国大使報告は、最初の発砲が日本側・中国側のどちらだったかは確定不能とし、行方不明兵をめぐる捜索要求と宛平への立入り問題を記録している。

現branchで1937年7月7日までに大きく変わっているのは、日本本土の工業能力、重車両の一部、電源・通信支援、特殊弾薬、航空/GT研究などである。一方、この事件の直接の発火条件である、

- 北支の政治・軍事的緊張
- 豊台周辺の日本軍駐屯と夜間演習
- 宛平・盧溝橋周辺の中国第29軍配置
- 現地の近接した武装部隊同士の接触
- 行方不明兵・捜索要求をめぐる混乱が生じ得る状況

は、事件を消すほど変化していない。

したがってcurrent branchでは、**盧溝橋事件そのものは1937年7月7日夜に発生する。**

ただし、以下は史実結果として固定しない。

- 最初の一発を誰が撃ったか。史実資料でも確定していない。
- 7月8日以後の局地停戦、再衝突、増援規模。
- 北支での全面的拡大速度。
- 日本政府・陸軍中央・海軍・中国中央政府の後続判断。
- 上海への波及とその時期。

事件が発生した瞬間から、浅井世界線で実際に変わっている条件を入れて再シミュレーションする。

## dense-core弾材 — 事件開始時点での扱い

1937の軍用dense-core材配賦は、天然U 1.5–3t/年、W系0.5–1.5t-W equivalent/年をworking中央とする。用途は20–37mm級高初速対装甲火器が中心で、Uがqualificationを満たす限りWを特殊弾へ大量投入せず、HSS・WC工具へ温存する。

この特殊弾は7月7日の事件発火条件を変えない。だが事件が拡大し、装甲戦・対戦車戦が発生した時点で初めてbranch差として効く。
