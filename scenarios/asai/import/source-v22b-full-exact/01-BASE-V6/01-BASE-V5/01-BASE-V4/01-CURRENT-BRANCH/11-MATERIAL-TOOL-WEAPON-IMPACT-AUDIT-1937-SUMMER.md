# 1937年夏 材料・工具→兵器影響監査 V1

## 原則
- 浅井が設計指導に出向いたことを自動仮定しない。
- 効果経路を `材料購入 / 工具購入 / 部品購入 / 浅井規格採用 / 共同研究` に分離する。
- 特殊鋼は万能札ではない。防弾鋼・砲身鋼・構造鋼は個別認定が必要。
- 1937年までの浅井の強い直領域は、W系高速度鋼・超硬工具、耐熱鋼/高温試験、歯車・軸・軸受・熱処理・疲労/QC、排気ターボ。

## 1. 九六式軽機関銃
- 史実：1936採用。1937は生産立上げ期で、資料により生産開始・大規模化年の記述に差がある。少なくとも1937夏に大量配備済みと扱わない。
- 浅井経路：高速度鋼/超硬工具、ゲージ、熱処理材。銃そのものの設計主務ではない。
- 効果：加工歩留まり、工具交換、互換性、ばね/小軸の寿命下限。量産立上げを数か月単位で滑らかにする余地。
- 禁止：1937夏に数万挺、射撃性能の大幅向上、浅井が銃設計を改良した扱い。
- 判定：量産効果 中、性能効果 小、1937夏戦場効果 小。

## 2. 海軍九六式25mm機銃
- 史実：1935仏製評価、1936国産量産型。戦後技術調査では撃針寿命が旧250発→4000発へ改善。改善要因は熱処理だけでなく形状・加工変更を含む。
- 浅井経路：工具、熱処理、材料、寸法管理。設計変更は横須賀工廠側のfailure feedbackが必要。
- 効果：初期不良の再現・原因分離と改修量産を早められる。撃針等の小部品寿命改善は強く効き得る。
- 禁止：15発弾倉、旋回/俯仰、振動、照準能力を材料で解決しない。
- 判定：信頼性効果 中～大、対空戦闘性能総体は小～中。

## 3. 航空レシプロ発動機
- 史実：1936–37に航空発動機用クランク軸鋼の疲労・切欠き・熱処理研究が公刊され、Ni-Cr鋼・Ni-Cr-W鋼が有力材として論じられる。
- 浅井経路：クランク/歯車/軸受用特殊鋼、耐熱排気弁材、高速度工具、熱処理、探傷、ゲージ。三菱/中島には計算文化も別経路で浸透。
- 効果：同じ設計定格で故障下限・個体差を改善。排気弁焼損、クランク疲労、歯車/軸受寿命、加工rejectを減らす。設計余裕が確認できた系列だけ数%級の連続定格改善余地。
- 禁止：全発動機一律+10～20%、新合金だけで高ブースト化。
- 判定：寿命/量産 大、性能 小～中。1937以後の新設計ほど効く。

## 4. 重車両・砲牽引車ディーゼル
- 現branch：D-B 95–105hp、D-C 150–165hp等の浅井/共同過給ディーゼル系列が1937までに存在する。史実Type 94 6輪トラックそのものは初期ガソリンで、ディーゼル化は後なので「史実Type94全車にturbo」を禁止。
- 浅井経路：過給機完成品、純正/共同ディーゼル、歯車/軸/軸受材、耐熱排気系、工具/QC。
- 効果：車種を特定した枝では+20～30%級の出力差が現実に出る。高地/高温、牽引、登坂、回復加速の差は大きい。
- 禁止：既存史実ガソリン車を説明なしにターボディーゼル化。全軍トラック標準化。
- 判定：性能効果 大。ただし「どの車種に何基」が現branch最大の未監査点。

## 5. 九六式24cm榴弾砲
- 史実：1937年4月には陸軍技術本部が審査経過概要を作成。後世資料では過大散布界・射程不一致が解決せず少数生産。
- 浅井経路：工具、計測、データ集計、限定的材料。設計主務ではない。
- 効果：加工誤差/装薬lot/弾体公差が原因なら原因分離を速め得る。根本が砲架、弾道、弾薬設計なら解決しない。
- 中央提案：成功兵器へ救済せず、「原因同定を早め、改修か早期打切り」の効果を第一候補とする。
- 判定：現時点OPEN。性能ボーナス禁止。

## 6. 九七式中戦車チハ
- 史実：170hp級空冷ディーゼル、約38km/h。本格生産は1938以後。
- 現branch：180PS常用/200PS最大、39–40km/h。過給は設計競争時から比較される。
- 浅井経路：低圧turbo/intake、歯車/軸/軸受/クラッチ材料・QC。装甲板は魔法化しない。
- 効果：headline速度は小差。高温/高地・登坂・加速・重量余裕で差。増トルクを伝動寿命低下なしで受ける部分に特殊鋼/QCが重要。
- 禁止：1937夏大量生産、装甲強化の自動連鎖。
- 判定：性能差 中、1937夏数量差 小、1938以後の運用差 中。

## 7. 砲身・閉鎖機製造一般
- 史実：1936–37日本にも高速度鋼・超硬・熱処理研究は存在。1937呉海軍工廠では18-4-1系等の高速度工具研究が公刊される。大型砲身鍛造では大型プレス等の設備能力が別律速。
- 浅井経路：W系HSS、超硬、ゲージ、熱処理、研削、工具再生。
- 効果：難削鋼の切削時間、工具寿命、寸法再現性に直接効く。中小火器・閉鎖機・発動機部品では量産効果が大きい。
- 禁止：大型鍛鋼素材、巨大プレス、砲身内質そのものを工具で解決しない。
- 判定：量産効果 中～大、兵器単体性能 小。

## 8. タングステン/耐熱の扱い
- W系優位の第一用途は高速度鋼・超硬工具。完成兵器材へ無差別にWを入れない。
- Ni-Cr-W等の構造鋼はクランク軸等の疲労部位に限定採用が自然。
- 耐熱鋼はGT/排気ターボの長時間試験が強いfeedback sourceとなり、航空/車両/舶用内燃機関の排気弁・高温排気部へ横展開しやすい。
- 1937段階で浅井が有利なのは「未来合金」より、heat/process/lower-tailを長期記録していること。
