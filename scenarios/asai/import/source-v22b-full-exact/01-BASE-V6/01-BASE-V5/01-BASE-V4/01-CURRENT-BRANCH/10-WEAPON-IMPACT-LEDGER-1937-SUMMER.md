# 兵器影響・開発生産台帳 — 1937年夏

Current branch working ledger. 史実の1937年夏を切断面にし、浅井の材料・過給・計算・工具・電源・GTが影響し得る装備について、史実の進捗と現ブランチ差を分離する。

## 判定ルール

- **HOLD-HISTORICAL**: 史実の日程・headline性能を基本維持。浅井効果は品質・故障率・工程程度。
- **CLOSED / CLOSED-METHOD / CLOSED-DIRECTION**: 現branchで方向または数値が既に閉じている。
- **LIKELY / AUDIT**: 影響は自然だが、具体数量・日付の監査が必要。
- **HIGH-OPEN / OPEN-HOLE**: ここを動かすと1937年の景観が大きく変わるため優先監査。

## 景観の要点

1. 1937年夏の九七式は、Ki-15を除けば多くが「試作・前生産・量産準備」であり、大量配備ではない。
2. 実戦景観を作っているのは九四・九五・九六式の成熟層。浅井の即時効果もこの層の量産・信頼性に強く出る。
3. 現branchで最大の即時性能差は重車両の低圧ターボ、移動/固定GT電源。航空機のheadline性能差は意図的に小さく保つ。
4. 九七式チハは180PS常用/200PS最大。旧200/220PS設定は廃棄。1937夏に量産車が多数存在する設定にはしない。
5. 九六式軽機関銃、九六式25mm、九六式24cm榴弾砲は、浅井の加工/QC能力が歴史的な立上げ・故障問題に直接刺さるため優先監査対象。
6. 高密度芯special APは1937年に限定戦備化できるが、中央は20–37mm級高初速対装甲火器。天然Uで代替できる用途ではWを弾薬へ回さず、HSS・超硬工具へ温存する。

## 優先監査で見つかった穴

- 九六式軽機関銃：1937年の月産・工場設備・互換性。浅井ゲージ/QCで量産開始をどこまで滑らかにできるか。
- 九六式25mm機銃：撃針寿命改善の史実時期。浅井熱処理・形状・加工管理がいつ入るか。
- 九六式24cm榴弾砲：散布界の原因を設計・砲身・装薬・弾丸・砲床・計測に分解。救済されるか早期中止されるか。
- 九七式81/90/150mm迫撃砲：制式化・生産開始の一次資料crosswalk。
- 回収車・工作車・通信指揮車：1937年の実在型式と台数。浅井効果が作戦面で大きいのに現branch台帳が薄い。
- 九七式艦攻B5N・九七式戦闘機Ki-27：史実の日程に対してU4計算/試験文化が数か月動かせるか。大量前倒しは禁止。
- 九四/九五式牽引車・重6×4：浅井ターボ装着率と累積台数。中国戦初期の物流景観を決める。
- 航空/車載の「九七式機銃」：陸海軍の同名異機種を分離して数量台帳化。
