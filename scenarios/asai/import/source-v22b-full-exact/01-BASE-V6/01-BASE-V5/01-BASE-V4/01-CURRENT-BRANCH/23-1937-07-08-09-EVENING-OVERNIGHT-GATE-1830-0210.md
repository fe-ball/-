# 1937-07-08 18:30–1937-07-09 02:10 — 盧溝橋事件 evening/overnight gate

## 判定

この区間は **CLOSED-SAME through 02:10** とする。

18:30の日本側自発撤収決定後、東京中央の不拡大指示、天津増援の到着、北平/天津の複数交渉ルート、中国第37師/第219団の夜襲意図が並行する。しかし浅井世界線の工業差は、02:10までに成立する「5時撤兵」合意を破壊するほどの条件差を作らない。

次gateは **1937-07-09 02:10–07:10**。ここでは合意が現地部隊へ届かず、05:00に再射撃となる通信・伝令失敗を重点監査する。

## 1. 18:42 — 参謀本部の不拡大指示

史実では参謀本部は7月8日18:42、支那駐屯軍司令官に臨命第400号を発し、「事件の拡大を防止するため、更に進んで兵力を行使することを避ける」旨を指示した。

current branchでも中央の政治・軍令判断を変える浅井要素はないため、**18:42発令をそのままCLOSE**する。

ただしこの命令は、18:30に現地河邉旅団側が既に永定河東岸への自発撤収を決めた後に発せられている。したがって当夜前半については、命令の伝達が多少速い/遅いとしても「現地方針を撤収から攻撃へ反転させる」gateではない。

## 2. 19時頃 — 天津増援の到着

史実側の編成資料では、7月8日9時の軍命令で天津から正午出発を命じられた増援は、少なくとも以下を含む。

- 支那駐屯歩兵第1聯隊第2大隊（2個小隊欠）
- 支那駐屯戦車隊の1個中隊
- 支那駐屯砲兵聯隊第2大隊
- 工兵1個小隊

北大法学論集の一次史料合成では、19時頃には天津軍の増強部隊が到着したとされる。

### 浅井差

ここは初めて浅井の重車両技術が実物に触れ得る。

支那駐屯砲兵聯隊は1936年増強時に、山砲大隊と15cm榴弾砲の重砲大隊を持つ編制で、第2大隊は機械化重砲側である。史実系資料では15cm榴弾砲を自動貨車で牽引したとされる。current branchでは砲牽引車・重6×4が浅井低圧turboの主要軍需先なので、この縦隊の牽引/貨物車の一部に浅井系過給車が入る余地は高い。

しかし、次はCLOSEしない。

- 増援全車両が浅井turboである
- 19:00到着が18:20等へ明確に前倒しされる
- 戦車・砲・歩兵を含む混成縦隊の速度がtruck engineだけで大幅上昇する

史料の時刻自体が「19時頃」で粗いこと、戦車・砲・休止・道路が縦隊速度を律速することから、current branchでも **到着時刻は19時頃** とする。

許容する差は、過給牽引車/重貨物車について **過熱・故障落伍が少なく、到着時に揃って使用可能な車両がやや多い** というlogistics-readiness差。この差はまだ発砲命令がないため、当夜前半の政治/戦術結果を変えない。

## 3. 19:00前後 — 双方の不拡大意思と交渉

19時、秦徳純は日本大使館側へ事態不拡大に努力中と電話する。同時期、日本側では天津から飛行機で来平した和知中佐・鈴木大尉と今井武官らが、秦徳純、趙登禹、張允栄との会談に入る。

この会談では、中国側が事件拡大回避には同意するものの、撤退は双方同時、一部守備兵は残置したいとし、具体条件では妥結しない。

浅井の航空/材料差によって天津―北平のこの連絡飛行を変える理由はない。軍用量産GT航空機はまだ存在せず、既存機の信頼性差がこの便の成否を変えた史実上の律速も確認できない。**会談時刻・内容とも史実同様**。

## 4. 第37師/第219団の夜襲

一次史料を用いた研究では、第219団は8日に夜襲を敢行し、これは第29軍全体の統一命令というより第37師レベルの判断だったとされる。米海軍武官も8日22:10の電報で中国側夜襲を予期していた。

この夜襲意図を生む条件はcurrent branchで変わっていない。

- 第37師/第110旅/第219団の配置
- 日中双方への不信
- 日中双方の増援
- 日本軍の一時的東岸撤収
- 中国側局地指揮官の抗戦意思

したがって **第37師/第219団側の夜襲意図・局地夜間行動は発生する** とCLOSEする。

ただし、史料間で「敢死隊による橋頭堡奪回」等の時刻・人数・戦果の叙述が大きく異なるため、このgateでは具体的に「何時何分に何人を殺傷し、どの地点を占領した」とは固定しない。02:10以後の撤兵命令伝達失敗と05:00再射撃との接続を次gateで詰める。

浅井側では、この局地夜襲を察知・阻止する新しい暗視、レーダー、統合無線網等は存在しない。特殊鋼・九六式軽機のminor差も、夜襲そのものを消す条件にはならない。

## 5. 22:30–02:10 — 交渉は撤兵合意へ収束

22:30、加藤書記官は秦徳純邸を訪れ、原因論より緊迫状態の収拾を優先するよう申し入れる。中国側も原則的には永定河を境として兵力を引き離す案へ近づき、双方の差は小さくなる。

別系統の北平特務機関―張允栄、天津軍司令部―張自忠の交渉も夜通し継続する。

- 01:10頃：最初の半数を09日06:00、残りを同夕刻までに撤退させる案
- 01:30頃：張自忠側から04:00撤兵との連絡
- 02:10頃：張自忠が馮治安を説得したとして、05:00撤兵、龍王廟附近の第37師部隊を衙門口へ移すことで合意

current branchでも、浅井が政治交渉へ介入せず、通信体系そのものを置換していないため、**02:10までの合意形成を史実同様にCLOSE**する。

## 6. このgateで浅井が効かなかった/効いたもの

### 効かなかった
- GT移動電源車：既存の電話/電報/航空連絡が動いている。交渉の律速ではない。
- dense-core ammunition：装甲戦闘なし。
- E5/jet：軍用量産航空GTは存在しない。
- 特殊鋼：夜間交渉や中央命令を変えない。
- 浅井本人：現地/中央の不拡大交渉に介入しない。

### 初めてlatentに効く
- **過給砲牽引車・重貨物車**：天津増援、特に機械化15cm榴弾砲側の行軍落伍/過熱を減らし得る。
- ただし19時頃到着という粗い史実時刻を有意に前倒しするほどの証拠はない。
- よってこの時点の差は「増援の到着時戦備状態がやや良い」であって、event sequenceの分岐ではない。

## 7. 次gate
