# 1937-07-09 02:10–07:10 — 撤兵命令伝達失敗 / 05:00再射撃 gate

## 判定

この区間は **CLOSED-SAME through 07:10** とする。

02:10頃までに成立した05:00撤兵合意は、前線中国軍へ十分に伝達されない。05:00、日本軍が協定に従って盧溝橋駅附近へ集結・移動しようとすると中国側前線が射撃し、再び局地的な火戦となる。日中双方が命令未達を認識した後、混成連絡団を現地へ送り、06:40頃に現地到着、07:10頃に宛平県城へ入って第29軍の撤兵命令を直接伝達し、対立は一旦収束する。

浅井世界線の通信・電源・車両差は、このfailure chainを壊さない。理由は、失敗した主経路が中国側の前線命令伝達であり、日本側通信品質の改善だけでは代替できないためである。

## 1. 02:10–05:00 — 合意は成立したが前線へ届かない

北平/天津の交渉では02:10頃までに、05:00を軸とする中国軍撤兵と龍王廟附近部隊の移動が実務的に合意されていた。

しかし、一次史料を突き合わせた岩谷研究では、05:00になっても中国側現地部隊は撤兵を開始せず、協定に基づき盧溝橋駅附近へ集結しようとする日本軍へ射撃を始めた。

中国側が日本側へ説明した命令未達の理由は、

- 日本軍による電話線切断のため前線へ伝達できなかった
- 豊台から盧溝橋へ出した中国側伝令も日本軍に阻止され、到達できなかった

というものだった。

この「日本軍が線を切断した/伝令を阻止した」という因果説明そのものは当事者説明であり、current branchでは独立事実として断定しない。ただし **撤兵命令が05:00までに前線へ届かなかった結果** は複数史料と整合し、CLOSEする。

## 2. 05:00前後 — 再射撃

同時代FRUSでも、05:00に停戦・双方撤退が取り決められ、撤退開始後に中国側が退却中の日本軍へ再び射撃し、その後07:00頃までに再度停止したとの日本大使館説明が記録されている。

current branchでは、02:10までの合意、前線配置、日本側の撤収準備、中国側への命令未達という条件が史実と実質同じなので、偶発事象ルールにより **05:00前後の再射撃も発生** とする。

正確な最初の発砲地点、射撃開始分、死傷内訳は固定しない。

## 3. 浅井通信技術はこの失敗を救わない

### 日本側電話・測定器

浅井系の電機/計測品が一部軍需に入っていても、失敗の中心は中国第29軍内部から前線への命令伝達である。日本軍の交換機・線路試験器・電源車が多少良くても、中国軍前線へ撤兵命令を自動的に届ける回線にはならない。

### 移動GT電源車

電話線そのものが使えない/伝令が到着しない問題に、発電能力はほぼ無関係。したがって非gate。

### 無線

current branchには、支那駐屯軍歩兵の小部隊まで浅井製 tactical radio が普及し、しかも中国側指揮網と相互運用できるというCLOSED設定はない。よって「無線で中国側へ直接通知」は置かない。

## 4. 伝令阻止と日本側警戒配置

前夜までに日中双方は増援し、夜襲・散発射撃も経験している。したがって日本側前線警戒兵が、所属不明/中国側の移動者を自由通過させる条件にはなっていない。

浅井系重車両が天津増援の落伍を減らしたlatent差はあるが、02:10–05:00の前線検問/警戒配置を反転させるほどの差ではない。中国側伝令が史実で前線到達できなかった結果は保存する。

## 5. 05:10–06:40 — 混成連絡団を再派遣

命令未達が判明すると、日中双方は話し合い、第110旅副旅長、第29軍参謀、中島第29軍顧問、林耕宇らを派遣することとし、日本側も現地に伝令を出して撤退監視を続けた。

史料では05:10頃にこの処置が記録され、06:40頃に中島顧問らが現地へ到着した。

### 車両差の判定

06:40という所要時間を「浅井車なら30分短縮」とはしない。

- 混成連絡団であり、日本側だけの自動車縦隊ではない
- 発令/人員集合/通過確認/警戒線通過/現地接触を含む
- 移動距離だけで決まる所要時間ではない
- 史料時刻自体が「頃」である

したがって current branch でも **06:40頃到着** をCLOSEする。浅井車両が使われていたとしても史料分解能内のminor marginに留める。

## 6. 07:10 — 宛平入城、命令直接伝達

06:40頃に現地到着した中島顧問らは、07:10頃に宛平県城へ入り、中国側へ第29軍の撤兵命令を直接伝達し、05:00からの対立は一旦収束する。

FRUSでも、05:00の停戦後に再射撃があり、07:00頃には戦闘が再停止したと同時代に報告されている。時刻精度の違いは矛盾ではなく、current branchでは **07:10前後の現地伝達・収束** としてCLOSEする。

## 7. current branchへの意味

このgateは「浅井世界線なら通信が良いので偶発的再衝突が全部消える」という扱いを明確に否定する。

浅井が改善しているのは主に日本側の工業・軍需能力であり、中国軍の命令網を置換していない。共有通信路も存在しない。そのため、**相手側の伝達failureを日本側技術だけで救うことはできない**。

ここまでの世界線は依然として史実本線に非常に近い。

## 8. 次gate

**1937-07-09 07:10–正午/午後前半**

焦点：
1. 中国軍撤退の実施と日本側監視。
2. 日本側が監視のため2個中隊を残す判断。
3. 中国側がこの2個中隊を「日本軍は本当に撤退するのか」と問題視する過程。
4. 保安隊への警備引継ぎ。
5. 保安隊到着連絡の伝令阻止、雨天・外套による増援誤認、五里店附近の再衝突。
6. この局面に日本側通信・車両・識別/照明装備の浅井差が入るか。
