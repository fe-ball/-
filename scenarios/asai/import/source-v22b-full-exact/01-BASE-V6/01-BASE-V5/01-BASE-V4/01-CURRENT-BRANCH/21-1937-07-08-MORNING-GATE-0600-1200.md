# 1937-07-08 06:00–12:00 — 盧溝橋事件 morning gate

## 判定

**CLOSED-SAME THROUGH 12:00, with one transport question deferred.**

05:30–06:00の最初の火戦後、06:00から正午までの主要な史実イベントはcurrent branchでも維持する。浅井世界線の通信・電源・車両・材料差を個別に当てても、正午までの命令・交渉・局地射撃を変えるだけの成立済み介入はない。

ただし11:40に通州方面から出発した増援の**編成・輸送手段・到着時刻**は次gateへ送る。ここだけは道路輸送なら浅井車両差が初めて作用し得る。

## 1. 06:00–07:00 — 停止命令が完全には行き渡らない

史実一次資料を用いた岩谷研究では、06:00に停戦報告が北平大使館へ入った一方、07:00過ぎにも散発的な砲声が続いていた。櫻井顧問・寺平補佐官は、中国側の射撃停止後も日本側の停止命令が容易に徹底されなかったため、白旗掲示と巡回停止勧告を行い、最終的に聯隊長から停止命令を出すよう求めている。

### 浅井差監査

- **移動電源車**：非関与。これは電源不足ではなく、数百m～km単位で散開した前線部隊への命令伝達・射撃統制の問題。
- **浅井電機/通信**：portable wirelessの高密度配備をcurrent branchではCLOSEしていない。史実の伝令・電話・旗・現地巡回を置換しない。
- **九六式軽機/材料品質**：射撃停止命令の徹底性を改善する因果なし。

**判定：散発射撃継続は史実同様。**

## 2. 07:00–09:00 — 長辛店側からの射撃が残る

宛平城内の中国軍は停止するが、永定河西岸の長辛店方面から射撃が続き、朝の砲声は主として日本側と長辛店所在中国軍の間で生じたとされる。

### 浅井差監査

- dense-core AP：装甲目標なし。非関与。
- 過給重車両：既に現地へ展開済みの歩兵同士の射撃なので非関与。
- 特殊鋼/工具：短時間局地射撃で確認された故障律速なし。

**判定：史実同様。個別命中・死傷は固定しない。**

## 3. 07:00–12:00 — 軍用電話障害

7日夜以後、豊台―天津、豊台―北平間の軍用電話に障害が発生した。岩谷論文が引用する北平陸軍機関記録では、北平―豊台間は物理的切断ではなく「漏電の仕掛け」と考えられ、日本側の疑心を強める材料となった。

### 浅井差監査

ここは一見、浅井電機・エポキシ絶縁・移動電源車が絡みそうだが、**現branchでは差を付けない。**

1. 障害は発電不足ではない。九二式野戦電話のような当時の軍用電話は乾電池と手回し磁石発電機を持つlocal-battery/magneto系であり、GT電源車を横付けしても線路漏電は直らない。
2. current branchで浅井が当該北平―豊台軍用線の線材・絶縁・保守計器を直接納入していたというCLOSED設定はない。
3. 仮に浅井製測定器が一部存在しても、外部線路に意図的/偶発的な漏電要因が置かれたなら、診断時間が多少縮むだけで事件の午前中の政治判断を反転させる根拠にならない。

**判定：電話障害と、それが生む日本側の疑念は史実同様。**

## 4. 10:00–12:00 — 撤退交渉

王冷斎県長と牟田口聯隊長の間では午前11時を目標に双方撤退を交渉。日本側は盧溝橋・龍王廟の中国軍を永定河西岸へ撤退させることを要求し、中国側は承知せず、期限は12時へ延長された。

正午頃、森田中佐と王啓元第37師参謀の交渉で、中ノ島西側の日本軍と南側の中国軍を双方撤退させる方向で話がまとまり、合図後2時間以内の実施を想定した。

### 浅井差監査

- 交渉当事者、要求、現地兵力配置はcurrent branchで変えていない。
- 浅井本人/浅井社が現地政治交渉へ介入する経路なし。
- 軍事技術差がこの時点で相手の要求水準を変えるほど露呈していない。

**判定：交渉経過は正午まで史実同様。**

## 5. 中国側増強

正午頃までに長辛店所在中国軍は増強される。これは第29軍側の局地的警戒・増援判断であり、浅井世界線の日本工業差がまだ認識されていないため、同じ判断が発生する。

**判定：史実同様。**

## 6. 11:40 — 通州方面の日本軍増援が出発

史料では、通州方面に所在していた日本軍部隊が11:40に現地へ向けて出発したとされる。また事件第一報には、歩兵第1聯隊の「その他主力」が通州方面に派遣されており、これを招致中との記述がある。

### 編成上の注意

平時配置表では通州常駐は第1聯隊の1小隊とされる一方、事件直前には第1大隊主力が通州方面で露営演習中だったとする記録/回想もある。したがって、**11:40出発部隊を単純に「通州常駐1個小隊」だけとは固定しない。**

### 浅井差監査

- **出発命令時刻そのもの**は、交渉・脅威認識・指揮判断で決まり、車両性能で前倒しされない。
- したがって11:40出発はCLOSED-SAME。
- ただし、その後の移動が徒歩・鉄道・普通トラック・過給ディーゼルトラックのどれだったかで到着時刻は変わり得る。

**判定：11:40出発までCLOSED。到着時刻と輸送手段はOPEN。**

## 7. 12:00 cut state

1937-07-08 12:00時点のcurrent branch：

- 06:00の停止後も散発射撃は完全には止まっていない。
- 宛平側は概ね停止、長辛店方面との射撃が残る。
- 豊台―天津/北平軍用電話の障害は史実同様。
- 双方撤退交渉は進み、正午頃に部分撤退案が形成される。
- 中国側長辛店兵力は増強。
- 日本側通州方面部隊は11:40に出発済み。
- **浅井世界線による確定的な分岐はまだ発生していない。**

次gateは **12:00–18:30**。重点は、通州/北平方面部隊の実際の輸送・到着、北平城門閉鎖、天津側増援、現地撤退実行、18:30の日本側自発撤収判断。ここから車両・鉄道・通信・兵站差が初めて実時間へ反映し得る。
