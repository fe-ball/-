# 1937-07-09 07:10–16:00 — withdrawal monitoring / security-force misidentification gate

## 0. Closure

**CLOSED-SAME through 16:00.**

07:10頃に第29軍命令が宛平へ直接伝達された後、中国側撤退は正午頃まで進む。日本側は撤退監視のため2個中隊を残し、主力を豊台へ退かせる。この2個中隊残置は輸送能力不足ではなく意図的な監視措置なので、浅井系車両が良くても消えない。

撤退後の治安引継ぎをめぐって中国側が「保安隊」を送り込む過程では、到着連絡の伝令が日本側に阻止され、降雨時の外套が第29軍兵と同様であったことに加え、実際に派遣された部隊自体が馮治安直属の正規軍部隊を変装させたものだった。したがって日本側が「新たな第29軍増援」と判断する条件はcurrent branchでも実質同じで、五里店附近の衝突は保存する。

正確な衝突時刻、最初の武器使用、双方損害内訳は史料差があるためOPEN。事件の存在と「若干の死傷」が出たことまでをCLOSEする。

12:20頃には再交渉が進み、16:00頃までに中国軍の永定河西側への撤退と治安警備の引継ぎが完了する。この大枠もcurrent branchでは同じ。

## 1. 07:10–正午 — withdrawal monitoring

岩谷將「盧溝橋事件における現地交渉（I）」が引用する北平大使館記録・支那駐屯歩兵旅団資料では、07:10頃に宛平へ入った連絡団が第29軍命令を直接伝達した後、撤退は正午頃まで続く。日本側は撤退を監視し、2個中隊を現地監視に残して主力を豊台へ撤退させる。

中国側はこの2個中隊残置を問題視し、日本軍が本当に撤退するのか疑念を持った。

### current branch判定

- 浅井過給車両：**非gate**。2個中隊を残したのは故障車待ちや輸送不足ではなく監視任務。
- GT移動電源：**非gate**。監視任務の成立に外部大電源は不要。
- 浅井小火器/材料差：**non-branching**。この局面の律速は撤退確認と相互不信。

したがって日本側監視2個中隊残置まで史実同様。

## 2. 「保安隊」は単純な警察部隊ではなかった

重要な史料修正点。

当初は石友三が司令する冀北保安隊が宛平の治安を引き継ぐ予定だった。しかし中国側史料と日本側調査を突き合わせると、実際には宋哲元の命を受けた馮治安が、**馮直属の第2旅第1団第2営を変装させて派遣**しており、この部隊が日本側と衝突した。

さらに石友三系の冀北保安隊自体も、実員は第29軍各師から集められた兵で、石友三は訓練を請け負っていたに過ぎないとの同時代報告がある。

つまり日本側の誤認は、単に「雨で制服を見間違えた」だけではない。

1. 日本側へ到着を知らせる伝令が阻止された。
2. 雨天のため第29軍と同様の外套を着用していた。
3. 実体も第29軍系正規兵であり、外観・行動から“増援部隊”と見ることには強い状況証拠があった。

**偶発事象ルール上、この三条件がcurrent branchでも変わらないため衝突は保存する。**

## 3. 浅井通信/識別技術で回避できるか

### 3.1 tactical radio

旧current source `asai-works-radio-radar-reliability-rebaseline-1935-45.md` は、1935–38の浅井効果を巻線含浸、端子封止、電源、受領試験等へ置き、浅井自身を完成無線機メーカーにせず、小部隊までportable tactical radioが高密度普及したとはしていない。

したがって監視中隊、路上哨戒、交渉担当者が全員即時相互通話できる網は存在しない。

また仮に日本側内部通信が多少良くても、「近づいてくる集団は合意済み保安隊である」という情報そのものが伝令阻止によって欠落している。通信路の品質だけでは未知情報を生成できない。

### 3.2 optics / identification

current branchには1937年の歩兵監視用双眼鏡・暗視・IFF・識別標識を浅井が革命的に改善したCLOSED設定はない。雨天下で、同じ外套を着た正規兵を遠距離から「治安部隊」と識別する技術的gateはない。

### 3.3 vehicles

中国側部隊の輸送系に浅井は関与しない。日本側監視部隊も局地配置であり、重車両性能は誤認の原因ではない。

**判定：浅井差で衝突を消さない。**
