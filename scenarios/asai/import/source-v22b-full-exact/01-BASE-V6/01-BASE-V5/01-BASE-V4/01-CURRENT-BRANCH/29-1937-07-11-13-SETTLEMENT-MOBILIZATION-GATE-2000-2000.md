# 1937-07-11 20:00–1937-07-13 20:00 — settlement under mobilization / first post-truce incidents gate

## 0. Closure

**CLOSED-SAME through 1937-07-13 20:00, with Dahongmen cause OPEN.**

11日20時の現地協定成立後も、現地の不安定な発砲・日中双方の増援移動・日本側の予備動員が並行する。current branchでは浅井の車両・整備・通信・工業余力が日本側部隊のready fractionをわずかに改善するが、戦略輸送は鉄道、師団動員は招集/編成/馬匹/鉄道/海運が律速であり、11〜13日のdecision cycleを反転させない。

13日20時の参謀本部「北支事変処理方針」による現地解決維持・内地部隊派遣の保留までを史実同様にCLOSEする。

## 1. 11日夜 — agreement exists, but firing reports immediately continue

20時の三カ条協定成立後も、22:00〜22:30頃に北平で発砲音が聞こえる。同時代FRUSでは、日本側は「中国軍が盧溝橋北方数マイルで発砲したが日本軍は関与していない」と説明し、中国側は逆に「日本側が22:15頃に攻撃を再開した」と主張している。

この責任主体は固定しない。一方、協定成立直後にも発砲報が出て双方の不信が継続する、というeventはcurrent branchでも保存する。

浅井差はない。夜間警戒・散開部隊・誤認という局地条件が同じであり、浅井通信も相手側の認識を同期させるほど普及していない。

**判定：post-truce firing report = CLOSED-EVENT / RESPONSIBILITY OPEN。**

## 2. 12日 — local truce coexists with strategic movement

12日には北平で日本人居留民の退避が始まり、北平―天津・北平―漢口鉄道の運行にも断続的な支障が出る。天津では北方から来る日本軍増援が鉄道で断続的に到着し、上海発列車も天津以北へ進まない例が出る。

同時代には「豊台周辺2万人」など誇張を含む報道・情報が流れたため、current branchではこの数字を確定値にしない。後日の米陸軍武官情報では、7月15日までに天津へ到着した日本軍増援は約4,600名、北支駐屯軍総兵力は約12,000と見積もられている。また熱河方面の関東軍からは増強大隊が豊台へ入ったことが確認される。

### Asai transport audit

この増援の主軸は鉄道である。浅井系過給重車両・砲牽引車があっても、山海関/天津までの戦略移動時刻を大きく短縮しない。効果は荷卸し後の道路移動、牽引余裕、故障脱落率、整備性に現れる。

**判定：reinforcement arrival trend = CLOSED-SAME; road readiness delta only。**

## 3. Chinese central troop movement north remains the key strategic trigger

南京側では蒋介石が9日に北支へ複数師団を送る意向を示し、12〜13日には漢口・徐州方面から北上する部隊が実際に鉄道移動しているとの情報が日本側・外国側に入る。13日には中国外相も「6個師団が漢口方面から北上中、さらに追加あり」と説明している。

これは石原ら不拡大派が「万一に備え動員準備だけは必要」と判断する重要条件の一つであり、current branchでも中国側条件を変えていないため保存する。

**判定：Chinese central reinforcement movement = CLOSED-SAME。**

## 4. Korean 20th Division — mobilization starts, but no magical early arrival

11日付で朝鮮軍第20師団には北支派遣命令と応急動員命令が出され、動員第1日は13日とされた。

current branchでも同じ。浅井世界線では一部車両・工具・修理設備のready fractionは高いが、予備役復帰、戦時編成、装具交付、鉄道集結、港湾/海路、受入れ調整を消せない。

さらに7月14日時点の米軍武官情報では、日本内地・朝鮮から北支への実部隊移動はまだ確認されていない。従って13日中に第20師団が北支へ到着するような前倒しはしない。

**判定：20th Division emergency mobilization = CLOSED-SAME; no early theater arrival。**

## 5. 13日 — Dahongmen / ammunition-truck explosion

13日、北平南方2〜3マイル付近で日本軍の弾薬積載トラックが爆発し、周辺で「大戦闘が始まった」との誤報を生んだ。後世日本側叙述では大紅門事件として、中国第38師系兵による爆破・日本兵4名死亡とされる一方、同時代FRUSの後日総括は「弾薬を積んだ日本軍トラックの爆発」と記すだけで、直接原因を確定していない。

### branch causality

これはユーザー規則上、車両差を確認すべき偶発event。

- current branchは全軍用トラックを浅井turbo車に置換していない。一般輸送車には史実系ガソリン/NA車が多数残る。
- 当該車両の型式は未同定で、浅井製/浅井過給車とする根拠がない。
- 敵対行為による爆破なら原動機差はほぼ無関係。
- 弾薬事故なら車両/積載/火気条件が関係し得るが、原因資料が足りず浅井QCで消えるとは言えない。

従って**「弾薬トラックが爆発し、重大戦闘との誤報を生む」event自体は保存**する。一方、爆破主体、車種、正確な死傷内訳はOPEN-detailとする。

**判定：Dahongmen truck explosion = CLOSED-EVENT / CAUSE OPEN。**

## 6. 13日20:00 — home-island dispatch remains suspended

現地協定を受け、統帥部は内地部隊の実派遣を保留する。13日20時の「北支事変処理方針」では現地解決方針を維持し、中国側が協定を無視した場合や中央軍をさらに北上させる場合には断固措置を取る、という条件付き姿勢になる。

11日に決めた「備える」ことと、13日に「今すぐ内地3個師団を出さない」ことは両立する。

浅井世界線でもこの判断は変えない。浅井の工業力が高いからといって、現地で協定が成立しているのに5/6/10師団級の内地部隊を先行出航させる理由にはならない。むしろ動員準備を保持しながら待てる余裕が少し増えるだけである。

**判定：1937-07-13 20:00 home-island dispatch suspension = CLOSED-SAME。**

## 7. Asai-specific company response

11日の政府派兵声明と12〜13日の実増援・動員開始は、浅井にとって「政治へ介入する」triggerではないが、軍需企業としては無視できない。

current branchではこの時点から、浅井社内で以下を始めるのが自然なWORKING responseとする。

- 軍向けターボ/GT/電源車/工具/特殊鋼の在庫・仕掛品照会
- 重車両turboの交換品・repair cartridge stock確認
- E4固定/移動電源の即納可能台数確認
- 工場の二交代移行に必要な人員・材料だけ事前点検
- ただし正式大量増産は受注/軍要求が来るまで開始しない

浅井本人の「止めるための政治工作はしない」というcurrent-session条件とも整合する。

**判定：company readiness check = WORKING-HIGH-CONFIDENCE; no event effect yet。**

## 8. Current worldline at 1937-07-13 20:00

- 11日協定は生きているが、夜間の発砲報・小衝突・誤認は続く。
- 日本側では関東軍方面からの鉄道増援が実際に入り、朝鮮軍第20師団は13日を動員第1日として応急動員を開始。
- ただし13日中に朝鮮/内地師団が北支へ到着することはない。
- 中国中央軍は複数師団を北上させており、日本側の不信と予備動員論を維持させる。
- 13日には大紅門附近で日本軍弾薬トラック爆発事件が発生。事件自体は保存、原因責任はOPEN。
- 13日20時、日本中央は現地解決を維持し、内地部隊実派遣を保留する。
- 浅井差は鉄道戦略輸送や中央decisionを変えず、到着後readinessと軍需企業側の準備余力だけを改善する。

次gateは **1937-07-13 20:00 → 1937-07-17**。14日の騎兵殺害/小衝突、関東軍増援の北平到着、14日の天津→北平道路移動、交渉条件の追加、17日の廬山声明と日本側期限設定を個別監査する。
