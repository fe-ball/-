# 1937-07-07/08 INITIAL RESPONSE GATE — 盧溝橋事件の初動

## 判定範囲

このgateは1937年7月7日夕刻の夜間演習開始から、7月8日05:30前後に日中双方が本格的な交戦へ入るまでを扱う。

偶発事象ルール：

> 条件が実質同じなら偶発的な出来事も起こる。関連条件が変わっていれば史実結果を強制しない。

## 史実baseline

防衛研究所・岩谷將の一次史料ベース整理では、7月7日夕刻、支那駐屯軍歩兵第1連隊第3大隊第8中隊が盧溝橋付近で夜間演習を実施。22:40頃に中国軍陣地方向から銃声が聞こえ、演習を停止した。点呼で兵1名の不在が判明した。

連隊長牟田口廉也は大隊長一木清直に中国側との交渉を命じた。行方不明兵はほどなく帰隊し、その事実は7月8日02:00までに中国側へ伝えられたが、発砲・立入り・責任をめぐる問題は残った。

03:00前後に再び銃声があり、一木大隊は前進・射撃準備に入る。中国第29軍側は前進停止を要求したが、日本側が停止せず、05:30前後に双方が本格交戦へ入った。

FRUS同時代報告も、7月7日深夜直前の衝突、行方不明兵、宛平への立入り要求、7月8日早朝の再交戦を確認する一方、最初の発砲者は確定していない。

## event-by-event closure

### 1. 7月7日夕刻 — 第8中隊の夜間演習
**CLOSED-SAME.** 現branchでも実施される。

### 2. 22:40頃 — 銃声を聞き演習停止
**CLOSED-EVENT.** 発砲主体は固定しない。発砲/銃声という偶発事象は、局地条件が同じため保存する。

### 3. 点呼 — 兵1名の不在
**CLOSED-EVENT.** 同じ個人・同じ演習条件なら発生する。不在兵は史実同様ほどなく帰隊する。

### 4. 7月8日未明 — 宛平側との交渉・立入り/調査問題
**CLOSED-SAME.** 行方不明兵が戻っても、発砲責任と立入りをめぐる摩擦が残るため交渉は続く。

### 5. 03:00–03:30頃 — 再度の銃声
**CLOSED-EVENT.** この段階にも浅井差は介在せず、偶発性保存ルールにより発生する。

### 6. 一木大隊の前進・戦闘準備、牟田口の交戦許可
**CLOSED-SAME.** 現地指揮官・情報・距離・連絡条件が同じため、判断を変更する要素がない。浅井製重車両や電源車はこの決心の前提ではない。

### 7. 05:30前後 — 本格交戦
**CLOSED-EVENT.** 初動の分岐はここまで史実とほぼ同じ。

## 初動で浅井要素が「絡まない」こと自体の確認

- 兵力移動は局地・短距離であり、過給ディーゼル車の性能差が増援時刻を左右する局面ではない。
- 連絡は伝令・既存電話網で成立しており、小GT移動電源車や浅井電装は不可欠でない。
- 20–37mm dense-core special APは対装甲用であり、宛平・堤防陣地を巡る初動戦闘には実質無関係。
- 浅井が改善し得た九六式軽機関銃の量産は、1937夏の第1連隊第3大隊の具体配備率をまだ固定しない。史実の同連隊を描く資料では十一年式軽機関銃が確認されるため、初動火力を一律九六式へ置換しない。
