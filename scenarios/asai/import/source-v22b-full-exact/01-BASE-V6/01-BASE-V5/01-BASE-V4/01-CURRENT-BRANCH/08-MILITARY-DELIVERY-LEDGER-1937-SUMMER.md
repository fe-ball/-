# 浅井精機工業 軍需納入・採用見込台帳 — 1937年夏

## 0. 読み方

本稿は1937年夏を切断面として、浅井が軍へ「既に納入している」「限定試験・評価で渡している」「採用/量産準備に入っている」「まだ提案・見込み」の四段を分離する。
数量は旧台帳に確定基数がないものが多いため、`SOURCE-ESTABLISHED` と `WORKING-QUANTITY` を分ける。

2026-08-30 current-branch追加裁定：`基地移動電源` は1937年夏までに少数実用化・軍評価/限定納入済みとする。固定式E4 500kW級とは別に、APU/小GT系を用いる道路用移動電源車を置く。大型E4級可搬発電装置は牽引式・特殊用途の少数枝とする。

## 1. A — 定常量産・継続納入

### 特殊鋼・工具鋼
- 1918–19以後、民需＋官需。海軍工廠・造兵廠との古い取引。
- 完成兵器ではなく素材・加工能力の軍需基盤。
- 数量単位はt/年・鋼種別で別監査する。

### 金剛超硬・切削工具
- 1926以後、工廠・民需へ広く販売。
- 高速度鋼、超硬、工具寿命、加工能率を供給。
- 数量単位は工具個数/重量で別監査。

### 治具・限界ゲージ・工作機械の少量販売/貸与
- 1928以後。工廠・主契約メーカーへ工具付随で外販、貸与、工程指導。
- 歯切盤そのものは1937年時点で「万能成熟済み」とはしない。

### 計算・事務機、保守、技術計算工程
- 1927前後に工廠/造船へ事務カード機。
- 1928–29以後、技術計算受託・設備販売。
- 1930–32、軍/大手メーカー安全区画へ顧客内計算室。
- 1935–37、主要発動機メーカーU4、軍評価側U3級。
- 台数は別途計算機設備台帳で監査。

### 陸軍重車両用排気ターボ
- 1930–33 並行試験。
- 1934–37 量産横展開。
- 砲牽引車、重6×4軍用トラック、特殊装甲車が先行用途。
- 一般4×2全車には広げない。
- WORKING-QUANTITY: 1937年率 新造装着約250–330基、予備/交換約40–70基。合計約300–400基/年を監査中央候補。

## 2. A/B — 定常少量・限定量産

### E4固定式非常/尖頭発電装置
- 1931初引合、1932初納入。
- 顧客：海軍基地、要塞、海軍工廠、造兵廠。
- E4 simple product: 約500kW shaft、発電端475kW級。回生定置E4-Rは約444kWe continuous / 約482kWe bypass。
- SOURCE-ESTABLISHED: 初納入・用途は確立。基数は未監査。
- WORKING-QUANTITY: 新規15–25コア/年＋交換/予備5–10コア/年程度を第一候補。

### 小GT/APU系 移動電源車 — CURRENT BRANCH ADD
- `gt-apu` の「基地移動電源」を1937夏までに少数実用化へ昇格。
- 主用途：前線/島嶼基地、通信、飛行場整備、工兵、野戦修理、探照灯/計測設備等。
- 中央は道路用大型6×4/牽引車に小GT発電セットを搭載。E4 500kW丸ごとではなく、数十～100数十kWe級のAPU派生を主とする。
- 特殊用途としてE4級400–500kWe可搬/牽引発電装置も極少数可。
- WORKING-QUANTITY: 小型移動電源車5–12セット/年、E4級大型可搬0–3セット/年。

### 海軍向け特殊印字・切替・電気機械
- 1930年代前半～半ばの通常官需から暗号機関連へ接続。
- 接点、電源、印字同期、艦載耐久を改善。
- 暗号方式・鍵は軍区画であり浅井の商品一般技術と分離。
- 数量未監査。

### エポキシ絶縁・封止・補修材
- 1934–37 少量商品。
- 軍装備/電装/工具/補修の高価値部位へ限定使用。
- 構造FRPの軍大量納入とは別。

## 3. B — 限定試験・評価納入

### 潜水艦2-cycle複合掃気用排気ターボ
- 1934–37 陸上試験→限定海上試験。
- 既存掃気ブロワ＋排気ターボ＋aftercooler。
- 1937末でも艦隊標準ではない。
- WORKING-QUANTITY: 試験・予備を合わせ年5–10基級を候補。

### 航空高温排気ターボ
- 技術的には1930年代に成立可能。
- 高高度爆撃/要撃/偵察限定。低中高度一般戦闘機には機械式過給が有力。
- 1937夏はbench・換装・軍評価段階。
- WORKING-QUANTITY: 年8–15基級の試験/予備候補。

### E4/E5 航空GT・TP・pure jet / aft-fan 評価
- 1937夏までにGT/TP飛行試験の蓄積あり。
- current branchでは軍用量産航空GT納入はまだゼロ。
- 軍共同評価・貸与・試製コアだけが動く。
- WORKING-QUANTITY: 年10–20コア程度の社内＋軍共同試験枠。そのうち軍受領/貸与は数基～10基級。

### 舶用GT増速
- 1934から艦政共同研究。
- 1937夏は量産艇主機ではない。
- E5 marine qualificationは1938+の試験帯。
- 1937夏の軍向けはbench/艤装研究用数コア以下。

## 4. C — 採用済み/量産準備・近接需要

### チハ系過給ディーゼル
- 1937は量産準備域。
- current branchでは過給前提の中戦車/重車両系列への移行が見込まれる。
- 1938から新造装着需要が明確に増える。
- 具体台数は陸軍車両/OOB監査に送る。

### 軍用車両過給の増産
- 支那事変以後、重貨物、砲牽引、高地補償、回収/工兵/指揮通信車への需要増が最短で立つ。
- 現行ターボ量産ラインで増産可能。

### E5航空推進
- 1937夏時点では「採用」ではなく、量産能力を持つ提案候補。
- pure jet / aft-fanは主減速機不要で、E5コア増産能力を航空推進数へ直接変換しやすい。
- turbopropは航空主減速機・大型可変ピッチpropが別律速。

## 5. D — 提案/将来見込み（1937夏には納入数へ算入しない）

- E5 marine qualification高速艇（1938+）

## 7. 調達側から見た浅井（1937夏）

浅井は完成兵器量産会社ではない。軍からは、
- 特殊鋼・工具・ゲージを買う会社
- 重車両用過給機を量産供給する会社
- 計算/事務機と保守を軍安全区画へ入れる会社
- 基地の固定式GT非常電源と、少数の移動電源車を供給する会社
- 海軍/航空廠でGT・TP・高温ターボを共同試験する会社
として見える。

この取引履歴が、1937後半の航空発動機不足に対して「E5コアを別設備で増産できる」「pure jet/aft-fanなら航空主減速機を要しない」という提案の制度的信用になる。
