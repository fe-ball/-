# 海軍・造船への計算設備導入前史（仮置き）

> **PROVISIONAL / 非正準**。次回、艦種ごとの実開発史・失敗・日程へ計算差分を当てるための入口を固定する。友鶴・第四艦隊前の売り込みを軽視しない。

## 1. 売り込み時期の固定案

史実でも1920年代後半にホレリス式統計会計機械が三菱造船や呉海軍工廠へ導入された例がある。したがって、浅井が1934年になって初めて「カード計算」を海軍へ教える構図は遅すぎる。

世界線暫定年表：

| 年 | 浅井側 | 海軍・造船側 |
|---|---|---|
| 1924–26 | 社内差分機・カード集計 | 既存輸入PCSの認知あり |
| 1926末–27 | 商用カード機外販 | 造船所・工廠へ事務用営業 |
| 1928 | 乗算・表参照付き科学計算線 | 設計・試験部門へ技術計算を売込 |
| 1929 | 「計算型」安定 | 砲術・造兵が最初の強い軍科学計算顧客 |
| 1930–31 | 受託計算・技術計算設備 | 艦本・工廠・大手造船所が限定利用 |
| 1931–33 | 微分解析機 | 軸系・機関・操縦等へ拡張 |
| 1934 | — | 友鶴後、復原性・重量状態へ大規模横展開 |
| 1935–36 | — | 第四艦隊後、縦強度まで基盤設備化 |

結論：
- 海軍への最初の売込み：1927前後。
- 科学技術計算としての売込み：1928–29。
- 艦本設計実務への定着開始：1930前後。
- 友鶴・第四艦隊：導入の起点ではなく**用途と優先予算を全艦政へ広げる加速器**。

## 2. 1928–30：ほぼ省力化

最初にカード化されるもの：
- 排水量・重量表。
- 重心。
- 静水力表。
- 縦強度の積算。
- 燃料・清水残量。
- 原価・材料表。

主効果は人日・転記ミス・再計算の軽減。完成艦性能はほぼ変えない。

ただし重量カードにより設計途中の重量成長を早く発見する効果はある。これは「重いと早く分かる」だけで、条約制限や過大兵装要求を自動で止めない。

## 3. 1930–32：最初の小さな純差分

### 重量・復原性の状態列挙

代表3状態程度から、燃料・清水・弾薬・魚雷・バラストを変えた20–50状態級へ。

危険な状態を拾う確率は上がるが、復原性基準・風圧・旋回等のモデルが甘ければ友鶴事故は防げない。

### 推進器

直径、ピッチ、回転数、翼数、展開面積、半径方向荷重分布を多数比較。模型水槽を置換しない。

1931–33頃の純差分候補：
- 推進効率：0～0.5ポイント程度、好条件で1ポイント弱。
- より重要：キャビテーション、振動、侵食、巡航オフデザインでの外れ回避。

## 4. 1931–33：最初の明瞭な技術差は軸系・振動

蒸気タービン／ディーゼル→減速歯車→中間軸→推進軸→プロペラを多質点系として扱う。

- 固有振動はカード計算。
- 負荷変化・調速・時間応答は微分解析機。
- 実艦・試験台計測から剛性・減衰を更新。

暫定効果：主要軸系・減速機の大変更回数20–30%程度減候補。最高速を盛るのではなく、公試延長・軸受損傷・歯車振動・危険回転域を減らす。

## 5. 1934 友鶴事件

事故は原則発生する。

計算能力があっても、設計基準・動的復原性・風圧・旋回等の評価モデルが不足していれば防げない。

事件後の純差分：
- 全艦型の燃料・弾薬・バラスト・上部重量状態を大量再計算。
- 一律バラストだけでなく、艦橋軽量化、上部重量移設、バルジ、運用制限等を比較。
- 同じ安全性改善に必要な追加重量を5–15%程度少なくできるケースを検討帯とする。艦全体では小差。

## 6. 1935 第四艦隊事件

事故は原則発生する。

標準波浪荷重モデル自体が実際の台風波を外していた場合、計算速度は無力。事件後に新しい極端波条件が指定されて初めて能力が効く。

事件後：
- 艦型×波浪×積載×燃料×補強案を大量再計算。
- 一律増厚ではなく危険断面・座屈部を選択補強。
- 必要な追加構造重量を従来案より5–10%程度抑える可能性を検討。個艦・構造で要再較正。

## 7. 1936–39：基盤設備化

新艦設計で標準的に以下を持つ方向へ。

- 多状態重量・重心表。
- 復原性表。
- 複数波浪条件の縦強度表。
- 推進器候補表。
- 軸系危険回転数表。
- 燃料消費順序と復原性・トリム管理表。
- 代表的損傷・浸水状態の事前計算。

艦本は全計算を自分で行うより、基準・共通計算法・試験値を管理し、大手造船所が自社計算室で秘密設計を処理する方向へ。

## 8. 次回に確定していないこと

ここまでの数値は一般論・暫定帯。次回は必ず史実の個別艦開発史へ当てる。

特に確認すべきもの：
- 駆逐艦：吹雪型→初春型→白露／朝潮型の重量・復原性・第四艦隊後改修。
- 巡洋艦：最上型など条約・溶接・船体強度・復原性の問題。
- 空母：赤城・加賀改装、蒼龍・飛龍、翔鶴型の重量・復原性・航空艤装変更。
- 戦艦：改装艦、大和型の重量・防御・船体強度・推進器。
- 潜水艦：過給ディーゼルと軸系、航続・重量、艦本式機関の失敗。
- 補助艦：大鯨等のディーゼル機関失敗との接続。

各艦種で「史実の失敗原因」「問題が発見された日」「設計変更の時間」「計算で減らせる手戻り」「計算では救えない入力・材料・溶接・政治要求」を分離する。
