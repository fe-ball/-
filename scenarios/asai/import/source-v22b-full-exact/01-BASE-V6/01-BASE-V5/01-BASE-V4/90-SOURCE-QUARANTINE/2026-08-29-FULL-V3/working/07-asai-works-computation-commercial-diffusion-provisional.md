# 浅井計算部門の商用化・軍需拡散（仮置き）

> **PROVISIONAL / 非正準**。計算部門の「世間からの見え方」「営業経路」「軍需メーカーへの拡散」を整理する。軍の採用年・個別機密案件を正本化しない。

## 1. 世間から見える浅井計算部門

浅井計算部門は、未来的な秘密研究所として突然出現するのではない。

1920年代後半の外形は、急速な多角経営で注目される若い浅井精機が、祖業である織機・ジャカード・紋紙・精密機械の人材を使って**統計会計機械へ再度多角化した**、というもの。

地方紙・経済紙の語り口は、概ね以下でよい。

- 「織機から工作機械、過給機、今度は統計会計機械へ」
- 「国産統計機械」
- 「事務合理化の新機械」
- 当時のIBMが統計会計機械会社として知られている範囲では「日本のIBMとなるか」程度の期待記事も可能。

「多角経営」という語自体は昭和初期に既に新聞用語として成立しており、後世語扱いする必要はない。

## 2. 1920年代末から1930年代半ばの成長像

- 1926–27：事務用カード機を外販。会計、在庫、給与、統計が主。
- 1928–29：社内GT計算向けに発達した乗算・表参照等を、科学技術計算として外販・受託へ。
- 1930–32：事務用では世界水準へ追いつく努力を継続。科学技術計算では自社のGT・歯車・材料需要のため独特の先行が始まる。
- 1933–36：大型技術計算設備・微分解析機を含む「科学計算に強い国産メーカー」という評価が定着。
- 1937以後：主要都市に専業営業・保守体制。最新軍用・研究用機の存在は知られても、性能・配置・計算対象は機密。

重要なのは、**世界にない物を初手から作ったのではなく、世界水準への追随競争を続けた結果、科学技術計算の一部で追い越す**こと。

## 3. 販売網

織機・工作機械・原動機の営業網だけでは事務機市場に弱い。自然な成長は以下。

- 1928–32：事務機商・商社を代理店に使う。
- 据付、保守、業務分析、カード設計は浅井直轄技師が担当。
- 1933–36：主要都市に浅井直営サービス拠点。
- 1937前後：販売・サービス専門子会社または専門部門を分離。主要顧客は直接、地方は認定代理店。
- レンタル方式を重視し、財閥間の中立性と初期投資負担軽減を両立。

暫定商用モデル：1933–35の標準一式は穿孔・検孔・ソータ・集計印字を含み、工場原価7,000–10,000円、月額賃料300–420円程度を検討帯とする。小規模顧客はサービス・ビューローを利用。

## 4. 公開／秘匿の層

「計算機という分野そのもの」は秘匿しない。

- 公開：穿孔、ソート、集計、印字、会計、在庫、官庁統計。
- 公開または企業秘密：科学乗算器、表計算機、小型リレー計算器。
- 存在は曖昧、詳細は秘密：最大計算所、大型微分解析機、最新電子計算器。
- 軍機：軍用計算型、入力データ、結果、最新機の性能・台数・配置。

「浅井は計算機械会社でもある」は新聞情報。「最新機で何を何秒で計算しているか」が秘密。

## 5. 軍・軍需メーカーへの拡散

軍そのものより、砲術・兵器技術・軍需メーカーの設計部門が早期顧客になる。

### 1928–31

- 弾道試験整理、射表、補正表が最初の強い軍用科学計算候補。
- 艦上射撃盤を置換するのではなく、射撃盤へ入れるデータや設計表を作る側。
- 造船所・工廠では重量・原価・材料集計から設計計算へ自然に広がる。

### 1930年代前半

- 三菱、川崎、中島等の軍需メーカーは、機密設計を競合浅井へ丸投げせず、自社安全区画へ計算設備を導入する方向が自然。
- 浅井は機械と汎用「計算型」、保守を供給し、顧客固有の軍用計算型は顧客技師が作る。
- 指定保守員は身辺審査・固定配属・ダミー診断を使い、顧客カードや結果へのアクセスを最小化。

### 1930年代後半

- 大手：自社計算室。
- 中堅：カード処理は自社、重い問題は浅井または軍研究所。
- 小規模：機密性が許す範囲でサービス・ビューロー。
- 最新リレー／電子機：希少なので軍費・国策資金で配賦される可能性。通常カード機まで統制配給品にはしない。

## 6. 兵站・参謀への位置づけ

カード機は兵站・動員・鉄道・船腹・在庫にも非常に向く。しかし計算機は政治判断や作戦目的を合理化する魔法ではない。

利得：
- 定型集計の高速化。
- 変更後の再計算を安価にする。
- 入力値、途中集計、出典が残り、「数字は人間が作る」ことを可視化する。
- 複数前提・複数案を比較しやすい。

危険：
- 楽観的入力を使えば、無理な作戦をより精密に「成立可能」と示せる。
- 組織構造、攻勢志向、陸海軍対立、現地軍の自主行動を計算機だけで変えない。

石原莞爾など上級戦争指導者については、計算表が史実以上に整う可能性はあるが、1937年の対中戦拡大を止める決定的純差分とは現時点で認定しない。満洲国の行政・工業計画の効率化だけを薄く残し、国政転換は沙汰止み。
