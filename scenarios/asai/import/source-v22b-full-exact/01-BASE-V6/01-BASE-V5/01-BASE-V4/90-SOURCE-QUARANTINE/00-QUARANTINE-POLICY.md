# Source quarantine policy — FULL V4

This directory is a **source/provenance layer**, not the current-claim namespace.

- Files under this directory remain available as evidence, technical authority, prior overlays, archives, and provenance.
- Their physical presence does **not** promote their terminology, adoption state, product name, quantity, or chronology into the current branch.
- A legacy/source claim becomes current only when `01-CURRENT-BRANCH/03-CURRENT-BRANCH-INDEX.tsv` (or a newer SESSION-CLOSED record) explicitly carries it.
- When the same or similar name was reused with a changed meaning, treat the records as separate claims. Do not merge by name alone.
- `TERMINOLOGY-AND-SUPERSESSION-GUARD.tsv` is the first check when an older expression conflicts with current wording.

The quarantined 2026-08-29 FULL V3 tree is preserved byte-for-byte at the file level, including its nested v48r3/Marine V10 ZIP. Quarantine is therefore a **propagation barrier**, not deletion and not a declaration that every source inside is false.
