# 航空機・発動機の名称規則——史実相当名称を優先する

> **2026-08-23 v11 正本。** H→A監査の内部ラベルが正準名称へ侵入することを防ぐための規則。

## 0. 原則

1. **史実に相当する機体・型・発動機が存在する場合、史実の略符号・制式名称・型番号を踏襲する。**
   - 例：十二試艦上戦闘機の瑞星搭載試作機は **A6M1**。
   - 栄一二型搭載の量産初期型は **零式艦上戦闘機一一型（A6M2）**。
   - 折畳翼端を持つ艦上主力型は **零式艦上戦闘機二一型（A6M2）**。
   - 発動機も **栄一二型、栄二一型、瑞星二一型/ハ102** 等、史実相当名を優先する。
2. **史実相当型が存在しない世界線固有の型だけ、当時の命名規則に従って新規制式名/型番号を与える。**
3. `H/C/M/E/P/I/A`、`Z900`、`Z940`、`Z21N`、`S21` 等は**内部監査ラベル**として使用してよいが、本文の主名称にはしない。
4. 内部ラベルは初出でだけ括弧併記し、その後は史実名称または説明名称を使う。
5. 性能差・導入時期が変わっても、構造・用途・系列上の史実相当性が保たれる限り、安易に新型番号を作らない。

## 1. 零戦1939–41への適用

| 監査上の旧ラベル | v11以後の本文主名称 | 備考 |
|---|---|---|
| `A0-Z900` / `Z-900N` | **十二試艦上戦闘機（A6M1）・瑞星系900馬力試験装備** | 内部ラベル=`Z900`。海軍制式発動機型番を捏造しない。 |
| `A0-Z940` / `Z-940N` | **十二試艦上戦闘機（A6M1）・瑞星系940馬力比較装備** | 内部ラベル=`Z940`。艦戦高度向け過給設定は試験枝。 |
| `A0-S` | **零式艦上戦闘機一一型/二一型（A6M2）・栄一二型** | 内部監査上、1937要求から通したA0世代。 |
| `S21` | **栄二一型** | 内部比較ラベルのみ。 |
| `Z21N` | **瑞星二一型/ハ102級の零戦装備案** | 正式採用されない限り新しい海軍型番号を付けない。 |

## 2. オリジナル機への適用

史実相当機・計画がある場合はその名称を継承し、世界線差は改修記号/型番号の範囲で処理する。完全な新規要求から生まれた機体だけ、既存の海軍/陸軍命名規則または正本の固有命名規則に従って新規名称を与える。

「影機」は監査概念であって制式名称ではない。したがって `C/M/E/P/I` 等を機名へ混ぜない。

## 3. v13——A6M3への適用

- 栄二一型を積んだ1941全幅試作は、正式型決定前は **A6M3試作機**。
- 史実同等の11 m短翼構成を正式採用する場合は **零式艦上戦闘機三二型（A6M3）**。中央では比較試験枝なので、正式採用前に三二型の型番号を先付けしない。
- 長翼12 m・折畳翼端・栄二一型・燃料回復を持つ史実同等構成は **零式艦上戦闘機二二型（A6M3）**。世界線で出現時期が早くても史実名称を踏襲する。
- 瑞星二一型/Ha-102級装備は中央で非制式のため **A6M3瑞星二一型比較試験機**と記し、新型番号を作らない。
