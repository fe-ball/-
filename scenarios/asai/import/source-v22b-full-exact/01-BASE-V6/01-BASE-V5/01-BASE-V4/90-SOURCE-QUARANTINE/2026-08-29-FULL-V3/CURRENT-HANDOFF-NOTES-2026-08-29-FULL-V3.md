# 浅井世界線 handoff notes — 2026-08-29 FULL V3

## 方法論
- 歴史アナログは校正。史実年・性能を絶対上限にしない。
- 浅井直領域（GT/過給/内燃機関）は自費研究可。軍用大量採用は需要側から内生。
- 技術閉鎖≠採用閉鎖。TECHNICAL READY / WORLDLINE-PROBABLE / SCENARIO / SELECTEDを分離。
- 平時の開発時計を「計算が当たったから」で魔法的に縮めない。短縮対象は主にfailure loop。
- 用語は **計算集計機使用文化**。史実日本の技師が計算していなかったように扱わない。

## オレンジゾーン / 腱鞘炎理論
- O0 腱鞘炎：従来人間の計算・集計を機械化。原則性能差なし。
- O1 比較増加：同期間に多案比較。外れ案減少。史実案が最良なら性能差なし。
- O2 残差/故障loop：予測対実測、原因分離、再試験。手戻り・原因不明期間に差。
- O3 system：計算・水槽・試験・製造・伝達・較正を一工程として扱う。持続設計差。
- 海軍中央→工廠/大手メーカー→現場に1–3年級の吸収lag。
- D=設計時再配分、T=公試で露出、S=就役後改装で消費。

## 地上・舟艇の閉鎖
- 普通戦車：Type 97まで閉鎖。Chi-Haは三菱V12＋浅井低圧turbo/intake、約180PS normal/200PS max、peak torque約700Nm、39–40km/h。
- GT戦車：1938 ~15t、300/340hp prototype。技術成功、通常主力代替はfuel/dustで否定。特殊冬季枝。
- SR-III：~120hp NA diesel本流、GT不採用。
- 小発/大発/特大発：NA diesel本流。河川装甲艇は重量増で400–450hp turbo-dieselが自然。GT推進は通常不利。

## 小型舶用GT / 高速艇
- E5旧1,300hp舶用設定廃棄。E5-S ~1,000hp級。
- 1935 E4高速実験艇、1936 E5高速艇、1937 cruise turbo-diesel + central E5 GT boost architecture、1938 torpedo-capable trial craftがworking sequence。
- 高速艇にrecuperatorなし。巡航diesel＋simple GT boost。
- epoxyは構造接着/封止/重量CG反復へ。1938全FRP艇にはしない。

## 射撃指揮 / 愛知連携
漸進：1928–30砲術版O0→1931–33九一/九二式で愛知へ計算構造/機構誤差/実射残差支援→1933–36スニーカー通信/転記/手設定がbottleneck→1936–38 synchro/角度伝達/switchboard→1938–40 target designation/servo/時刻/電力/fuze setter/backup system。
- 型式番号≠system成熟度。九二式射撃盤＋九四式方位盤等が普通。
- F0 1928–30、F1九一式1931–32、F2九二式1932–34、F3九四方位盤1934–37、F4成熟九四system 1937–40、F5九八低角系1938–41（比叡testbed→大和型）。既存艦へ一律backfitしない。
- 高射は別枝：九一→九四高射。25mmは砲架/給弾/追従が律速。35–40mm gapは1941認識済みだが制式兵器なし。八九12.7cm→九八10cmの史実本流維持。
- retrofit：R0較正、R1配線/同期、R2方位盤/高射/switchboard、R3全体系/艦橋foundation。

## 戦闘艦漸進差（旧版再利用）
旧 H=史実 / I=配当を裸で吐く影艦 / A=実際浅井艦 を復活。旧gross dividendは性能bonusでなく設計自由度通貨。
- 最上/三隈：O1→O2、構造/溶接/砲塔支持問題をかなり史実通り踏む。
- 鈴谷：O2、旧gross 80–110tをI値として保存、大半を構造/砲塔支持/重心/配管/成長余裕へD化。
- 熊野：旧gross 100–130t、さらに整理。20.3cm換装は主にR0再較正。最上/三隈1940に九四高射backfitはWORLDLINE-PROBABLE候補。
- 金剛型：榛名1933–34先行11缶、霧島1934–36榛名TをD化、金剛1935–37 O2→3、比叡1937–40 O3。比叡旧gross 120–180tをI値として保存しFCS/電力/DC/通信/成長余裕へD化。
- 比叡：E4系400–450kW級非常GT generator 1基をP2として載せる線を会話上閉鎖。battery→GT急速復旧→diesel持続。翔鶴/大和へ即標準化しない。
- 利根/筑摩：旧gross 80–120 / 120–170t（I値）。同名FCSでも筑摩は較正/配線/同期一段成熟。152,000hp蒸気維持。
- 長門/陸奥：旧gross数値新造しない。長門先行実射/FCS test、陸奥が一部D化。大改装時高射は九一、九四は後年backfit。GT実機なし。
- 空母：加賀1934–35 O1→2/九一高射/GTなし。赤城1935–38 O2→3/九四高射/GT interface study。蒼龍O2、飛龍O2→3。翔鶴/瑞鶴O3、160,000hp蒸気維持、GT boostなし。

## 蒸気推進 / propeller / shafting
二重計上禁止。缶/タービン/gear=燃料→shaft、propeller/wake=shaft→推力、hull=推力→速度。
- 成熟1939–41普通蒸気艦：shaft-SFC working改善~0.5–1.5%、prop/wake純差permil～1%弱級。最高速は通常~0.1kt以下、多くはDへ。
- 本質は外れ案回収とrated-power availability。
- 朝潮1937末タービン翼事故は発生。GT側rotor/blade mode文化を調査へ流し、二節振動等を1939–40頃に実務上閉じる中央案。
- 陽炎：史実初期34.6→35.5kt回復（有効推進力約8%）は史実自身が取り戻した外れ。世界線は+8%ではなく最初1–2艦で閉じ後続反映。
- 夕雲O3、成熟知識を最初からD化。

## 改装空母 / GT boost
1941-12-08まで中央線で空母GT推進boost実搭載なし。
- 瑞鳳/祥鳳：52,000shp級steam勝利。diesel改善があってもstandardized steam優位。
- 龍鳳：元diesel保持+GTは必要追加出力大、steam replacement勝利。
- 千歳型：steam+diesel複合経験は参考、約29ktでGT不要。
- 大鷹：21→25.5kt ~19,919shp、E6約10基で不採用。23kt ~7,900shp/E6約4基はpayoff弱い。だが大型core LL20をpull。
- 隼鷹/飛鷹：25.5ktですでに十分、GT boost不採用。
- future strong：あるぜんちな丸級は改良diesel保持+E6/LL20 simple GT boostが史実steam総交換の強い競争相手。ScharnhorstはGT-electric候補。1941境界では未選択。

## 商船隊 / 転用候補
史実日本は既にmotor-ship nation。浅井が文化を発明しない。
- 1941物理船腹純増 working：中央+0.5～1.0%、上限~1.5%。
- 実効輸送力：中央+2～3%、上限~5%。新鋭高速cohortは実効+5～10%程度working。
- 浅井nativeは主に小中型高速4-cycle。大型商船は三菱/三井/B&W/Sulzer/MAN等が主役、浅井はturbo/fuel calibration/bearing/test/service packageを広販。
- 大型4-cycle既存retrofit：continuous +15–25%級workingを安全側。大型2-cycleは1930年代完全排気turbo一律化せず、mechanical blower残置turbo-assistを1938–41一部新造へ。出力+5–10%または同定格SFC/掃気margin。

硬い転用母集団：新田丸級3、橿原丸級2、あるぜんちな丸級2、Scharnhorst 1 = 約8隻。
浅井でoption upgrade：
- 氷川丸級3：4-cycle turbo retrofitで客船時19.3–19.8kt級working、B→B+。空母化0–1隻中央、非常時上限2隻程度option。
- 三池丸級：B+寄りだが輸送優先。
- 浅間丸/報国丸：改装可能でも高速輸送/AMC価値が高く空母優先でない。
- A型貨物/神川丸型：固定翼CVEより航空輸送/水上機支援。
- 川崎型高速油槽船：fleet train最優先、空母化しない。
技術的候補が増えても同時に輸送/給油価値も上がるためactual carrier純増には直結しない。1941 extra actual carrierは0～1隻程度見込み、損失後にさらに1–2隻を緊急抽出できるreal optionが増える。
