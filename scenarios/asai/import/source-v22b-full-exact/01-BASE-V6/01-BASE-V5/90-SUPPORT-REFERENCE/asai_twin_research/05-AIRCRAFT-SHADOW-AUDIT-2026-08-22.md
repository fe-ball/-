# 航空機 C/M/E/P/I/A 影機監査——v4入口（2026-08-22）

本稿は「浅井差」を一つの改善率へ潰さず、**計算C／素材M／発動機装備E／プロペラP／統合I／実機A**へ分けて再計算するための入口。親は `asai-works-computation-aviation-bridge.md`、材料は `01-MATERIALS-MASTER-INDEX-2026-08-22.md`、プロペラは `asai-works-propeller-control.md` と `asai-works-cfrp-program.md`。

## 1. 固定手順

| 影機 | 変更してよいもの | 変更してはいけないもの | 主に見る値 |
|---|---|---|---|
| H | なし | 全部 | 史実基準 |
| C | 計算、試験整理、探索幅 | 材料、エンジン実体、プロペラ材 | 抗力整理、重心、振動域、冷却、設計反復 |
| M | 素材・加工・接着・品質 | Cで得た分を再加算しない | 空虚重量、剛性、疲労、製造ばらつき |
| E | 過給、冷却、減速、排気推力、取付 | Pの効率改善を混ぜない | 軸出力/推力、全開高度、冷却抵抗、装備重量 |
| P | P0–P3 | エンジン出力そのもの | η、吸収馬力、径/回転数、振動、羽根質量/慣性 |
| I | C/M/E/Pを再最適化 | 単純加算 | 最高速、上昇、航続、離着陸、荷重 |
| A | 余剰の再投資 | 全部性能へ振ること | 燃料、武装、防弾、安全、寿命、整備、成長余裕 |

## 2. Mの年代ゲート

- **1938–42**：M1=特殊鋼・熱処理・工程・接着金属、M2=エポキシ・サンド・麻/GFRP二次構造。ここを主力とする。
- **1941–43**：GFRP構造用途が実用域へ。海上・航空の二次構造、外殻、保護を拡大。
- **1941–42 CFRP**：通常機のM3へ一律投入せず、実験枝。住友共同プロペラは例外的に回転疲労実証へ入る。
- **1944–**：CFRP実用機でM3を本格監査可能。

## 3. Pの年代ゲート

### P0——史実住友Hamilton系

1937試作開始、1939量産の史実受け皿をそのまま使う。可変ピッチ／定速化は「浅井発明」にしない。

### P1——計算だけ

浅井計算センターで翼素、ピッチ、回転数、径、減速比、速度・高度、共振を多数ケース比較する。純差分はピークηより**オフデザインの外れ回避、振動域回避、試験→再設計の速度**に置く。旧 provisional の「ピーク0–1ポイント、広い飛行域+1–2ポイント上限」は個別再計算までの監査目安。

### P2——住友金属プロペラ＋浅井材料／工程

Hamilton系の成熟した金属プロペラを捨てず、住友の羽根合金・鍛造・熱処理へ浅井の疲労試験・工程統計・接着/防食・管理図を共同工程として入れる。浅井の特殊鋼は主にハブ・根元金具・ピッチ機構側へ使う。根元、ハブ、締結、前縁、防食、バランス、寿命、ばらつきに効く。**P1で既に得た空力最適化をP2で再加算しない。**

P2の評価は「何%軽いか」を先に置かない。高出力化で増える遠心荷重と振動へ許容域を広げ、定速機構・減速機・エンジンとの整合を安定させることが主。

### P3——住友羽根＋浅井CFRP

`asai-works-cfrp-program.md` §2d。41–42は回転台・少数飛行実証。作業値は37 kg/枚、対応金属比−38%、羽根系回転慣性−40%。4枚なら金属相当約239 kg→CFRP148 kg、**羽根だけで約91 kg差**。装置全体差ではない。

低慣性は定速ガバナの応答を速めるが、負トルク／風車化への遷移も速くなる。したがってP3は `propeller-control` の負トルク制限器・自動フェザと**セットでI監査**する。

## 4. 直前論点の再評価——「住友プロペラ＋浅井素材」

正本を全部読むと、これは「計算Cの上澄み」ではなく、**P2とP3という独立の太い枝**である。従来の浅い評価が落としていたのは主に以下。

1. 住友側にHamilton系の史実設計・量産・ガバナ基盤が既にあるため、浅井はゼロからプロペラ会社を作る必要がない。
2. 浅井側には特殊鋼・熱処理・接着・FRP成形・疲労試験・管理図・回転試験台へ繋がる材料／工程体系がある。
3. CFRPプロペラは固定翼CFRPより早く「一次構造の限定実証」に使える。回転片持ち梁として疲労データを固定翼系列IIへ返せるからで、単なる軽量部品ではない。
4. ただし先端マッハ壁は残る。したがって凱風三一型の最高速をCFRPだけで増すより、羽根質量・慣性・疲労余裕を**減速機、機首重量、応答、寿命、整備、プロペラ径/翅数選択の自由度**へ配る方が妥当。

結論として、住友＋浅井素材は「プロペラ効率を数%足す技術」より、**高出力を安定して吸収するプロペラ系の成立範囲を広げる技術**として再評価する。性能増はIで個別に出す。


## 4a. 凱風三一型——最初のプロペラ影機再監査

正本 `asai-works-turboprop-fighter.md` の現行値は、E6-M-T約2,100 hp、単回転4–5翅、全備約4,500 kg、最高速約700–750 km/h、内部航続約1,650 km。**この表はP3 CFRPの91 kg級羽根差を明示的に織り込んだ表ではない**。しかも既存表はすでに浅井発動機・計算・構造を混ぜた旧統合値なので、正式なH/C/M/E/P段階のどれかへ遡及ラベルを貼らない。v4ではまずこれを **A_old（P3未明示の旧統合基準）** として凍結し、P3の純追加影機だけを切り出す。完全なH→C→M→E→P→I→A分解は同じ帳簿形式で次に行う。

P3の4翅代表案をそのまま当てると、羽根だけで約91 kg差＝全備4,500 kgの約2.0%。しかし凱風三一型の既存「構造＋系統＋乗員」には**±150 kg程度の未確定**が残り、しかも実機は4–5翅で羽根寸法が未確定。したがって91 kgを今すぐ正本重量から引くのは早い。

影機としては二つの配当を分ける。

- **I-軽量配当**：燃料・武装を増やさず、羽根差を総重量低下へ回す。4翅代表なら最大約2%の全備重量差。上昇・離着陸・機首慣性には効くが、最高速は先端マッハ壁のため小差。
- **A-燃料再投資**：総重量4,500 kgを維持し、羽根差を燃料へ回す。代表91 kgなら燃料850→約941 kg。ただしこれは**部品質量の帳簿上の上限例**で、実航続はプロペラ形状・L/D・予備燃料・重心を再計算してから確定する。正本1,650 kmへ自動加算しない。

さらに低慣性化はガバナ応答を改善する一方、負トルクへの落ち込みを速める。三一型単発では多発機ほど片発問題はないが、急減速・着艦復行・エンジン異常時の過回転／風車挙動をP3固有の試験項目にする。

**当面の判定**：凱風三一型における住友＋浅井CFRPは「最高速を700–750から明瞭に上げる札」ではなく、**2,100 hpを単回転で吸収する4–5翅系の質量・慣性・疲労余裕を改善し、重量配当をAへ返せる可能性が大きい札**。現行速度上限は据え置く。

## 5. 再基底化後の監査順（v5改定）

旧v4の「1941ピストン10機→凱風」という順は撤回する。比較対象の史実機を旧世界のまま残すと、オリジナル機のニッチ自体が誤るため。正準順は `asai-works-historical-aircraft-rebaseline.md` に移した。

1. **史実基準機**：年月・任務重量を固定してH→C→M→E→P→I→A。第1号の零戦二一型は `asai-works-zero-rebaseline.md` で実施済み。
2. **同年ライバル**：敵へ浅井技術を直接渡さずA'を作る。F4F系は `asai-works-f4f-rebaseline.md` で実施済み。
3. **ニッチNを再生成**：`asai-works-carrier-fighter-niche-1940-41.md` で実施済み。一般制空は零戦A0でほぼ閉鎖し、高高度/重装備長時間/灯油が空席。
4. **オリジナル機Oを要求仕様から再発生**：`asai-works-kaifu-11-requirement-reaudit.md` で採用論を再監査。旧一一型の一般主力を解除し、次はE5/E6共通帳簿→凱風X/一一型Iを実走。
5. **後続**：凱風二一/三一、陸軍軽戦/重戦、多発TP、CFRP実用機へ波及。

旧1941ピストン10機表は**retrofit比較表**として残し、必要な機から新Aへ置換する。

## 6. 出力表の標準形

各機ごとに最低限、以下を一表にする。

`型 / H重量 / C差 / M差 / E差 / P段階 / I再計算重量 / I速度・上昇・航続 / A再投資先 / 根拠ファイル / 未確定値`

これで「同じ軽量化をMとPで二回足す」「Eの排気推力をCへ混ぜる」「CFRPが存在する年に即全機一次構造へ入れる」を機械的に防ぐ。
