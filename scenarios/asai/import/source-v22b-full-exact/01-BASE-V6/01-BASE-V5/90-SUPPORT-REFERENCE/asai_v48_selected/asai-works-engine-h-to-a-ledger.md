# 発動機H→A上流帳簿——コア開発と航空機装備Eの境界

> **2026-08-23 正本追加。** 航空機H→C→M→E→P→I→Aのうち、従来Eへ押し込んでいた「発動機そのものの開発」を上流へ分離する。対象はレシプロ発動機を主とするが、考え方はGT/TPにも準用可能。

## 1. なぜ別帳簿が必要か

航空機側Eは、完成した発動機を機体へどう装備するかを扱う。

しかし世界線では1923から：

- 発動機試験計算
- 過給機
- ねじり振動
- 減速歯車
- 燃費/熱
- 材料・品質

へ浅井体系が入る。ここを航空機Eだけで扱うと、1937に「史実栄12」を固定入力にしてしまい、発動機が1930年代の計算文化で変わる可能性を失う。

逆に発動機Cを機体Cと一緒に加算すると二重計上になる。

## 2. 六段帳簿

### EH — Historical engine

その時点で史実に存在した：

- 設計案
- 試作機
- 性能表
- 耐久試験
- 故障
- 生産設備
- 顧客要求

を基底にする。

史実で失敗した案を「浅井なら知っているから存在しない」と消さない。

### EC — Computation

計算・データ工程だけ。

- 試験還元
- 多条件探索
- ねじり振動
- 熱/流量の粗探索
- 過給器/減速比の比較
- 故障条件分類
- 計算型/試験カード資産

物理試験時間、鋳造、加工、分解を魔法的に消さない。

### EMQ — Materials / Manufacturing / Quality

- 材料
- 熱処理
- 表面処理
- 公差
- ゲージ
- 釣合せ
- 管理図・統計品質
- 計測器

**ECと別契約。** 浅井計算機を買った三菱/中島が浅井MQを自動的に持つことは禁止。

### ES — Engine systems

コアを実用発動機にする内部システム。

- 過給器
- 減速機
- 気化器/燃料噴射/燃調
- 点火
- 潤滑
- 発動機内部の冷却設計
- 補機駆動

機体側カウル/吸気ダクト/排気推力とは境界を分ける。

### EI — Integrated engine

ベンチ、耐久、高度、重量、燃費を同じ帳簿へ統合する。

最低値：

- 離昇出力
- 高度別公称出力
- 乾燥/装備重量
- 外径
- BSFC/巡航燃費帯
- 気筒/油温余裕
- 耐久時間と故障分布
- 減速比・許容プロペラ負荷
- 整備/交換周期

未確定項目は帯またはunknownとし、都合のよい単一値を作らない。

### EA — Adoptable engine

その年のメーカー・軍が：

- 生産契約できる
- 整備教育できる
- 必要な材料を調達できる
- 試験を通せる

発動機。

EIで良い性能が出てもEAにならない場合がある。

## 3. 航空機側への受渡し

航空機H→Aでは、発動機を `EA(year, variant)` として受け取る。

その後の航空機Eで扱うもの：

- 発動機架
- カウリング
- 吸気ダクト
- 排気管/排気推力
- 機体側冷却出口/フラップ
- 機体側油冷却器配置
- 補機配置
- 重心・整備開口
- 発動機とプロペラPの最終取付整合

### 二重計上禁止

- 発動機ECで過給器候補探索 → 航空機Cで同じ探索を再加算しない。
- 発動機ESで内部冷却改善 → 航空機Eではカウル/流路の装備差だけ取る。
- EMQで減速歯車寿命改善 → Pで同じ材料寿命をもう一度取らない。

## 4. 時間配当の扱い

開発時間は三層に分ける。

1. **算術/解析時間**：ECで大きく短縮可能。
2. **設計反復の待ち時間**：計算がcritical pathなら短縮。
3. **実物時間**：加工、耐久運転、分解、飛行試験。原則そのまま。

ECの時間利得は：

- 日程前倒し
- 追加案探索
- 追加耐久
- 図面/品質整備

のどこへ再投資したかを明記する。

「計算が5倍速いから開発が5倍速い」は禁止。

## 5. 顧客成熟度Uとの接続

同じ計算機でもUでECの深さが違う。

- U1：試験還元中心
- U2：固有データを構内処理
- U3：自社計算型が設計判断へ
- U4：粗探索→重点試験→検算が組織の標準

EA比較ではメーカーごとにUを入れる。三菱U4と中島史実Hを比較する等は禁止。

## 6. 零戦での使用法

1937十二試艦戦なら：

1. 瑞星、金星、栄等をEHで列挙。
2. 各社のU4相当ECを入れる。
3. EMQ採用の有無を会社/契約ごとに判定。
4. ESで一速/二速過給、減速、燃調、潤滑、冷却を通す。
5. EIで高度出力、重量、径、燃費、耐久を比較。
6. 1939/40に実際に量産できるものだけEA。
7. 零戦の航空機EへEAを渡す。

この順で初めて「零戦が瑞星の大口顧客なら瑞星が変化する」を扱える。
