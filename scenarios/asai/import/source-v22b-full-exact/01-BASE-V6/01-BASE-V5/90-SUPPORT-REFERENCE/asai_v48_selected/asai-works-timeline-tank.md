## 1. 因果の幹（一段で）

浅井の排気過給は1920年代に舶用・定置で商品化され（第0世代＝翼車・軸受・耐久・量産品質の蓄積）、1930〜33年に既存トラック・牽引車・八九式級で車両条件（粉塵・負荷変動・冷却・振動）を実測し（第1世代）、1934〜37年に砲牽引車・軍用トラックから量産に入る（第2世代）。その量産と実測が**過給前提の専用車両ディーゼルと強化伝動系**を生み、戦車は実験車→第2世代（チハ標準型）→増力試験型（次世代車台試験）と段を踏んで、1939〜41年に**第3世代新中戦車**が立つ。ウラン合金芯弾が弾側の穴を埋める枝は不変（ただし2026-08の弾材再整理で**貫徹値の正準は持たない**＝`uranium-ap`）。GTは開戦前は試験段階に留まる。

## 3. 四つの横糸（時間で読む）

- **重量・寸法帯（インフラ）**：道路・橋梁・鉄道（車両限界・軸重・荷役）・船倉・揚重機・舟艇の**合成制約**。車幅約8ft級（2.4m前後）と15〜19t級は「全戦域で既存兵站との摩擦が比較的小さい量産主力帯」。20〜27t級は満州・大陸等で輸送/橋梁/回収を選ぶ**戦域限定中戦車帯**として研究可能、30t級はさらに配備先を大きく選ぶ。これは将来戦車の絶対上限ではない（規則4・`tank-next-generation-conditional-1939-45`）。
- **台数と性能の分離**：性能向上した車両の存在と、自動車化率の急増は別。生産台数・タイヤ・燃料・人員・道路・橋梁は過給機が動かせない制約（`military-diesel-vehicles` §0）。
- **高度補償**：中国・満州の標高・高温で定格を保つ。初期から広く効き、負担も小さい入口。
- **タングステン温存**：ウラン合金が弾芯の密度役を肩代わりし、タングステンを切削工具・耐摩耗材へ集中（`uranium` §2）。ただしウラン弾は「無料」ではなく**ウラン冶金ライン律速**の第二系列（`uranium-ap` §7）。

## 4. 「○○がある」を「○○が効く」へ

- **舶用・定置過給の商品化があるから** → 車両試験が既製部品と量産品質の上で回り → 第2世代の量産横展開（1934〜）が短期に立つ。
- **第1世代実験車があるから** → 伝動・冷却・足回りの実測が集まり → 増力試験型と過給前提専用機関の設計が根拠を持つ。
- **増力試験型（220〜240馬力）があるから** → 機関の上側を示しつつ → 量産はチハ標準を**200馬力連続／220馬力戦闘増力**に留め、220〜240馬力域は試験車へ分離して信頼性を保てる（規則2・3の分離）。
- **1939年以前から対戦車戦・次期戦車の問題意識があるから** → 第3世代要求を検討できる。**ノモンハン相当戦闘を経験した場合**は、不整地平均速度・信頼性・火力・無線・諸兵連合の優先順位を検証/加速する入力とする。発生そのものや教訓内容は戦史側で固定しない。
- 年表は「いつ良い戦車があるか」でなく「**どの段がどの段を開くか**」で読む。
