# 陸上用ターボディーゼルと戦車の世代発展（v27正本）

> 上流current=`asai-works-tank-early-computation-materials-rebaseline-1928-41.md`。浅井は戦車要求/車体設計の主務ではなく、過給器・材料・計算/QC供給者。

## 1. 原則

過給の価値は一律の馬力増加ではない。用途ごとに、(A)高地/高温補償、(B)穏当な増力、(C)次世代車台の試験、(D)過給前提設計へ分ける。最高速より登坂、不整地、速度回復、定格維持、寿命へ配当する。

## 2. 世代

### 1930–34 八九式試験
- 初期甲型は約100hp gasoline。
- 乙型用120hp diesel開発と並行して1932–34に140–150hp級過給試験。
- **120hp自然吸気が1934乙型量産本線**。過給車は伝動/冷却/履帯の試験台。

### 1933–37 ハ号・軍用車
- ハ号量産中央=**120hp自然吸気**。
- 過給は**120–125hp級flat-rated高地補償**が合理枝。
- 140–145hp級は少数試験。装甲20–25mm化や50km/h超級量産を自動的に導かない。
- 砲牽引車・重トラック等、便益が大きい用途では過給量産を先行させてよい。

### 1935–38 チハ
- 陸軍チニ/チハ競争の三菱高性能案へ浅井低圧過給を商品として供給。
- 170hp自然吸気比較車を残しつつ、**200hp連続/220hp短時間**を1938量産中央に採用。
- 220–240hpは1938–39強化車台試験に分離。

### 1938–41 新砲塔/チヘ
- 新砲塔チハ=200/220hp、47mm、4名二人砲塔。
- 一式チヘ=**240hp連続**。浅井過給は高温/高地flat-ratingに使う。
- **260hp operational boostはcurrentではない**。250–260hp級は工場/試験rating。

## 3. 材料・QC

初期主配当は歯車、軸、履帯ピン、ばね、軸受、砲身/閉鎖機、クラッチ/ブレーキ摩擦材、熱処理、限界ゲージ、ロット追跡。装甲板を一律軽く/強くする魔法ではない。GFRPは1942+別枝。

## 4. 固定禁止

- 「過給がある→ハ号を高出力/重装甲化」を禁止。
- 「チハは史実170hp完成後に浅井がturbo retrofit」を禁止。世界線チハは設計競争時から過給を比較する。
- 「浅井が未来の3人砲塔/50mm/無線を教える」を禁止。日本側の要求と試験から発生する。
