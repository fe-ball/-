# 浅井商品・利用可能性年代記——社内試作／商品化／外販／軍需採用を分ける（1903–1941）

> 目的：潜水艦その他のH→A監査で「浅井にその技術が存在する年」と「顧客が実際に使える年」を混同しないための共通ゲート。特に**排気タービン過給機／独立ガスタービン／ターボプロップを別物として扱う**。
>
> 本稿は既存年表を置換せず、各分野へ投入可能な技術の**利用可能性レジャー**として上に置く。数値・個別設計は各親資料を正本とする。

## 1. 四段階ゲート

各技術・商品は次の四段階を別々に記録する。

1. **R：社内研究・試作** — 浅井内部で原理・試作品・計算型がある。顧客はまだ使えない。
2. **P：商品化・社内量産可能** — 図面・検査・保守まで含め「売れる物」になった。ただし顧客導入は別。
3. **X：外販・顧客吸収** — 民需・既存取引先へ販売／リース／受託。購入日に浅井内部の熟練度を100%相続しない。
4. **N：軍需・個別計画で利用可能** — 工廠・艦政・軍需メーカーで秘密区画、受領試験、設計工程まで入った段階。Nになっても個別艦へ自動搭載はしない。

**禁止短絡**：R→N、P→全軍標準、X→顧客U4、試作コアE-n→同年の量産主機、材料在庫→製品認定、計算機保有→設計結果の即時改善。

### ビュッヒ年代の読み替え

正本で頻出する「**対ビュッヒ1925**」は比較用の略記として残す。ただし史実側は一点の年ではない。ABB系資料では**1924にBBCから高性能過給機が出荷**され、最初のターボ過給船は**1926就航**。したがって比較帯は**1924–26**で読む。

浅井側の正準は変更せず、**1923–24試作→1925実用商品→1926以後艦級展開**とする。これにより「1923に潜水艦へ量産ターボ」「1925に独立GT主機」のような誤読を禁止する。

## 4. 1938–41：潜水艦へ使える追加札

- **排気過給機**：成熟商品。潜水艦水上主機への標準化を検討可能。ただし主機本体の信頼性は別E/EMQ問題。
- **計算**：艦政・工廠で軸系振動、重量・トリム、多状態復原、推進器、材料統計へ深く入れる段階。ただし具体的な艦艇C成熟度は潜水艦監査で別途決める。
- **特殊鋼・熱処理・管理図・限界ゲージ**：使える。ただし耐圧殻、高張力鋼、クランク、噴射系、歯車は**部位ごとに採用契約と認定**を要求する。
- **工作機械**：1928から部門はあるが、歯切盤の「本格化」は1940–42。1930年代潜水艦の歯車・主機加工に後年級の精度を逆輸入しない。
- **エポキシ**：1939–41から艙内・ビルジ・合わせ面の封止、防食、電装ポッティングへ早く効く。耐圧殻そのものを接着構造へしない。
- **電刷子・積層布軸受・絶縁材**：周辺部品として使える。主電動機の全面刷新とは別。
- **蓄電池**：**浅井独自の高性能蓄電池化学／商品系列は存在しない。** ただしv21で、日本電池・湯浅等の史実鉛蓄電池産業をHに、1934–41の浅井C/M/Qをseparator・短繊維glass mat・槽/支持・外部seal・換気・cycle/shock試験へ入れる枝を正準化した。新品の比エネルギーを一律増加させず、製品構造・寿命curve・安全限界を変える。
- **主電動機／発電機**：潜水艦用専用motor系列そのものは史実Hを使う。浅井は1935–41の絶縁・ブラシ・巻線含浸・端子封止をメーカー/工廠へ供給し、v21で湿塩/温度/整流/衝撃を含むrating mapを正準化。効率・比出力の一律上積みは禁止。
- **独立GT主推進**：E-4商品化は1932–33、舶用増速試験は1934から。潜水艦の主推進へ使う場合は別研究枝であり、1930年代前半の標準案に置かない。

## 5. 潜水艦H→Aへ渡す初期状態

### 1927–29級潜水艦

使える浅井差：特殊鋼/工具、1925過給機の民需実績、社内計算文化。ただし海軍側Cはまだ浅い。**史実艦を大きく変えない基準期**。

### 1930–33級（海大・巡潜／艦本式研究開始）

初めて大きく効く可能性がある：

- 排気タービン過給機（P/X成熟済み。ただし潜水艦2サイクルでは掃気補助の試験窓。4サイクル商船の+30–40%を直接移植しない）
- 主機試験データのカード化・計算還元
- 軸系ねじり振動計算
- 材料・熱処理・ゲージ・管理図（別採用）

一方、まだ与えない：

- 1930年代後半級の工作機械精度
- 高性能蓄電池
- 高比出力主電動機
- E-4/E-5独立GT主機の標準装備
- エポキシ/GFRP耐圧殻

### 1934–37級

ここから計算＋**2サイクル用掃気補助／排気ターボ**＋材料品質を同時にIへ掛ける意味が大きくなる。ただしv17監査では1937末でも艦隊標準化せず、直列複合掃気の陸上/限定海上試験まで。海大六型b=85m、巡潜三型=100mは史実値を維持する。詳細=`asai-works-submarine-maturation-1934-37.md`。

## 6. 潜水艦監査における優先順位

1. **C：艦艇計算の顧客吸収年代**（艦政本部／横須賀工廠／民間造船所）
2. **E：艦本式ディーゼル本体**（過給機だけでなく燃焼・噴射・軸受・潤滑・クランク・複動機構・耐久）
3. **M/Q：耐圧殻鋼と主機材料・加工品質**
4. **P：水上／水中で異なるプロペラ運転点、キャビテーション・騒音・軸振動**
5. **電池chemistry・主電動機基本出力はH基準から開始**する。ただしv21以後、電池のseparator/glass mat/槽/換気/Q、主電動機の含浸/封止/rating mapは別勘定で改変可能。新品Wh/kgやhpを自動加算しない
6. Iで水上24 ktの価値を再判定し、余剰を速度・航続・信頼性・電池へどう配るか決める
