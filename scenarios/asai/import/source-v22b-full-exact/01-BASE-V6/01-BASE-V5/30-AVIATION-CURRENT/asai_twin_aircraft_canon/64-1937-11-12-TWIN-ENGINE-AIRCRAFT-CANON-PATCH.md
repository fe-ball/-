# 1937-11-12 双発高速実証機系統 — カノン化案

## 判定

**機体・開発系譜はカノン化してよい。**
ただし旧handoffの「材二号＝双発万能高速機」という名称同定は破棄する。

復元v48本体では「材二号」は1939–40の単座・構造材料試験機として定義されており、
1932–37に進んだ双発航空試験系統とは別物である。

以後、1937双発系統は暫定的に以下で呼ぶ。

- **E4双発汎用試験機**：1932–33頃から飛行試験・軍用システム試験を行う再使用試験機。
- **E5双発万能高速実証機**：E4試験機の知見を使い、1936–37までに成立した3.5–4 t級二座の高速mission demonstrator。
- 軍制式名称はまだ付与しない。
- 「材二号」は構造材料試験機の名称として残す。

旧overlayにあった「小型双発jet邀撃型」と「3.5–4 t級二座双発万能機」は、
1937時点では**別々の制式候補機を二機作ったとは解釈しない**。
同じE5双発実証系統について、
- 軽装・小燃料で邀撃包絡を見る構成
- 二座・大燃料・mission bayで偵察/軽爆/重戦包絡を見る構成
という試験構成・設計案の違いとして統合する。

これにより1937年の試作航空機乱立を避けつつ、
旧handoffが保持した「小型双発jet邀撃mission demonstrator」と
「双発万能高速機」の技術的内容を救済する。

## 開発史

### 1929–31
- E3→E4移行期に、母機懸架pod・燃料/制御配管・計測盤を先行整備。
- 目的は新作軍用機ではなく、飛行中のタービン挙動を安全に計測すること。

### 1931–33
- E4 pure-jet podの飛行試験。
- 専用単発実証機とは別に、**双発汎用軍用システム試験機**を成立させる。
- 代表値：全備3.6–4.0 t、翼面積26–28 m²、E4 jet 2基。
- E4時代の速度は約380–405 km/h級。
- 速度記録機ではなく、以下を実証するための機体：
  - 双発配置
  - nacelle交換
  - 片発停止時の操縦
  - 二重燃料・制御系
  - 無線・写真・mission bay
  - 整備アクセス
  - 軍技術者への顧客習熟

### 1934–36
- E4 shaft/TP/jet後端の比較、nacelle交換、計測・保守手順を蓄積。
- 軍はデータ閲覧・技術見学段階。正式な制式機要求ではない。
- 同時にE5用の高速化された双発機体案を詰める。

### 1936–37
- **E5双発万能高速実証機**が飛行試験段階へ入る。
- 1937夏までに「飛ぶかどうか」ではなく、mission envelopeを詰める段階。
- 浅井自費主体。陸海軍技術者の観察・共同計測は認めるが、正式軍要求機ではない。
- 1937-11-12時点でも制式採用・量産契約なし。

## 1937-11-12現在の代表仕様（WORKING）

### 機体
- 全備：**3.5–4.0 t**
- 乗員：**2**
- 双発pod/nacelle配置
- 機首または胴内に写真・無線・試験機材・軽武装/爆装用のmission bay余裕
- 大燃料構成と軽装高速構成を試験可能
- 全金属在来構造を基本とする

### 発動機
- **2×E5-J**
- 現行pre-audit static thrust：**430–470 kgf/基**
- 合計：**860–940 kgf**
- exact installed mass / altitude thrust / TSFC / restart-TBOはOPEN

### 速度
- 旧E4試験機そのままに近い抗力なら：約**470–500 km/h**
- E5専用に空力整理した3.5–4.0 t級機：
  **低高度約510–560 km/h級の感度**
- これは正式性能値ではなく、現E5 thrustと合理的CD0帯からのH→A前working envelope。

### 意味
1937年のA5M/Ki-27/Ki-15級の速度包絡へ入り、
軽装なら当時的に戦闘・駆逐用途を検討できる。
しかし速度だけで軍用実用性は閉じない。

主要な未成熟点：
- jet燃費と実用航続
- TBO / hot-section寿命
- throttle / acceleration / restart
- 高度別推力
- 片発時の実用上昇・帰投性能
- 武装射撃時の吸気/振動影響
- 量産nacelle / fuel-system整備負担

## 1937年秋の軍評価

### 陸軍
関心順位：
1. 高速偵察・司令部偵察の技術比較
2. 二座重戦/駆逐機の速度・武装包絡
3. 軽高速爆撃/襲撃
4. 純粋な点防御邀撃

ただしKi-15、Ki-21、Ki-27等の既存/進行計画があるため、
1937年にE5双発jetを緊急制式化する理由は弱い。

### 海軍
関心順位：
1. 陸上基地用高速要撃の技術研究
2. 高速偵察
3. engine/nacelle/control試験
4. 陸攻護衛・侵攻戦闘の将来研究

艦上化はこの機体の当面要求ではない。

### 採用段階
**A2+：advanced technical evaluation / military-access demonstrator**

- 軍による正式採用：なし
- 制式番号：なし
- 量産：なし
- 軍による試験費・計測器・試験空域提供：あり得る
- 追加試験機：1機程度を検討可能だが、1937年11月時点で確定しない

## 中国戦争から得るfeedback

中国戦線は本機を即採用させるより、要求の優先順位を整理する。

### 強くなる要求
- 高速写真偵察
- 無線・camera bayの実用配置
- 整備容易性
- 短時間での再出撃
- 双発機の片発帰投性
- 長距離進出時の燃料搭載

### 採用を急がせない要因
- 高高度高速爆撃機による本土脅威はまだ切迫していない
- 中国戦線では長航続・稼働率・短い滑走路適性の価値が大きい
- E5 pure jetは速度の割に燃料/TBO/推力余裕が未成熟
- 既存ターボ・工具・電源軍需が浅井の生産能力を吸っている
- 軍にも短期終戦期待がまだ残る

したがって1937秋の結論は、
**「戦闘機として採用」ではなく「次世代要求を作るための飛行データ源として継続」**。

## 今後の見込み

### 1937冬
- E5-J双発試験を継続。
- 片発・燃料・mission bay・無線/写真・模擬武装/軽爆装の試験を詰める。
- 軍は要求研究を開始してよいが、制式試作要求はまだ出さない。
- E5 aft-fan installed auditが進めば、この双発testbedを飛行評価母体に使う。

### 1938
分岐：
1. **pure jet E5**：
   - 技術実証として残る。
   - 航続/TBOが不足すれば実用戦闘機化を見送る。
2. **E5 aft-fan**：
   - static thrust / TSFC / installed massが監査を通れば、
     長距離戦闘・高速偵察側の比較試作へ一段進む余地。
3. **E6**：
   - 850–900 kgf/基 pure jet、950–1,000 kgf/基 aft-fan級になるため、
     初めて本格的な双発要撃/主力戦闘の軍要求を合理的に発生させられる。

### 1938–40
- E4/E5双発試験機をそのまま制式化するのではなく、
  その飛行・整備・mission-systemデータを使って**新造E6双発軍用機**へ移る。
- 既存v48の「E6双発要撃機が1940前後に実用化へ」という大筋は維持可能。
- E5実証機は、その制度的・技術的な前史として強くカノン化できる。

## Closure

### CLOSED / CANON
- E4時代に再使用可能な双発汎用軍用システム試験機が成立。
- 1937夏までにE5双発万能高速mission demonstratorが飛行試験中。
- 1937-11-12時点で軍正式要求・制式採用・量産は無し。
- 当時的戦闘/駆逐/偵察/軽爆の能力包絡へ入るが、用途はまだ固定しない。
- 1937秋の価値は「実戦機そのもの」より、双発jet軍用機の要求・整備・system integrationを先に学習できること。

### SUPERSEDED
- 「材二号＝1937双発万能高速機」。
  材二号は別の1939–40構造材料試験機として扱う。
- 「小型双発邀撃機」と「二座双発万能機」を1937に別々の飛行試作機として乱立させる解釈。
  1937では一つのE5双発mission-demonstrator系統の構成差/設計案として統合する。

### OPEN
- E4双発試験機の正確な初飛行日。
- E5双発実証機の正確な初飛行日と機数。
- E5-J installed mass / altitude thrust / TSFC / TBO。
- E5 aft-fanを1938に飛ばせるか。
- 軍が正式な双発jet要求を発出する年月。
- E6制式機の最終任務・所管・名称。
