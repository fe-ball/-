# Current-only aviation branch cleanup — 1937-11-12

Scope rule: this note uses only the present V4/current-session conclusions and the current raw-source items explicitly marked CURRENT/BASE-CURRENT. Old pre-v48 aircraft adoption histories, old names such as Kaifu/Hekireki, and archived STOL service histories are not revived here.

## Fixed-wing branches to keep

### 1. E4→E5 universal twin demonstrator line — KEEP / CANON
- E4 reusable twin military-style systems testbed is part of the closed early jet-flight evidence chain.
- By the current-session Gate 64 ruling, an E5 3.5–4.0 t two-seat high-speed mission demonstrator is treated as the continuation and is in flight by summer 1937.
- It is a mission demonstrator, not a service prototype: high-speed reconnaissance, heavy-fighter/interceptor envelope, light strike and systems-integration studies can all be exercised without fixing one service role.
- 1937-11 military stage: A2+ technical evaluation / military access; no formal designation or series procurement.

### 2. E4 clean-single demonstrator → E5/E6 central-rear single-engine line — KEEP AS ONE RESEARCH LINEAGE
- The current raw-source V12 closes the evidence sequence through an E4 clean dedicated single-engine jet demonstrator.
- The current V11 single-rear sizing explicitly says the central-rear architecture should NOT be restored as the first small GT fighter.
- Correct interpretation:
  - E4: research/record demonstrator;
  - E5: full-scale future-form demonstrator / architecture evidence;
  - E6: first credible operational interceptor/recon/fighter candidate.
- Therefore “Asai independently researching a single-engine interceptor architecture” is a fair description, but “a 1937 service-interceptor prototype is already complete” is too strong.

### 3. Separate small ‘Me-262-like / early GT fighter’ branch — DROP / MERGE
A second small fighter program is redundant. Any useful early-jet airframe evidence belongs either to:
- the E4/E5 single-engine demonstrator lineage, or
- the E4/E5 universal twin mission-demonstrator lineage.

Do not keep a third, separate small service-fighter project before the E6 gate.

## Materials fixed-wing line

### 4. Structural/material testbeds — KEEP, but as 1938+ test aircraft
Current BASE-CURRENT structural-testbed work supports a dedicated materials branch, but it should not be counted as a 1937 combat-aircraft family.

- Material No.1 concept: low-speed / short-field structural A/B test using a proven propulsion/airframe basis; 1938–39 test period.
- Material No.2 concept: single-seat high-dynamic-pressure structural test aircraft using proven jet propulsion; 1939–40 period.
- The latest current-session twin cleanup explicitly reserves “Material No.2” for this later structural-test role and removes it from the 1937 twin aircraft.

Because the V4 current history still keeps the exact old STOL/Material-No.1 identity under re-audit, do not lock the old pre-v48 STOL specifications or service-adoption history into this branch yet.

## Cultivation branches

### 5. Small TP / short-field / STOL practical line — KEEP AS WORKING CULTIVATION BRANCH
What the V4 branch actually closes/retains is narrower than the old STOL canon:
- by summer 1937, a practical small TP aircraft using partial plant-fiber composite structure has plausibly reached external evaluation / small-sale territory;
- exact aircraft identity, sales count, finished specifications and identity with the old STOL concept remain open.

Thus “STOL branch exists and is being cultivated” is acceptable.
“Old named STOL type with all old specifications is canon” is not.
