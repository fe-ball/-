## E6 / E7 principle
A more advanced engine generation does **not** automatically terminate lower generations. Research frontier, high-end military production, mature high-volume production and derated/service products can coexist.

## E6 capability frame carried forward
### E6-M pure jet
- PR ~7; 14-stage all-axial; ~13.2 kg/s center / ~14 kg/s high-flow trim.
- non-Ni production point ~850 kgf; Ni high-temperature point ~900 kgf.

### E6-M JF
- independent free LP turbine + aft fan; BPR ~1; FPR ~1.30.
- ~950-1,000 kgf static.
- about +21% static thrust and about -17% TSFC versus same-temperature pure-jet comparison in the existing design coordinate.

## New production model — CLOSED
Do not count only named engines. Track four stages:
1. **Core hardware** — common gas-generator physical hardware.
2. **Qualified core** — tested and binned into allowable rating/application.
3. **Finished engine package** — pure-J, JF, fixed power, mobile power, etc.
4. **Installation package** — aircraft, generator, vehicle, marine package.

### Binning
Highest aviation grade failure does not imply scrap if the core remains safe/useful at lower rating/application.
Track separately:
- flight-A yield;
- flight-B/derated aviation yield;
- ground/mobile/fixed grade;
- true reject / WIP;
- total usable-core yield.
Do not down-bin cracked/fundamentally defective hardware.

### E4-equivalent after E5 maturation
A newly manufactured "E4-equivalent" need not be a literal legacy E4 core. It can be a lower-rated/service-class product made with the mature E5-family process/parts where interfaces permit. Old E4 fleets still retain legacy spares and parts.

### Late differentiation
Option diversity raises efficiency only when common processing is preserved deep into the line and product differentiation occurs late. Too many early-diverging SKUs can reduce efficiency.
T-3/T-4 production-flow concepts support:
- common front-end processing;
- fixture swaps;
- duplicated inspection stations;
- standard interfaces;
- final branch into aviation/fixed/mobile/marine products.

### Core vs completed-engine bottleneck
T-AUX can become the bottleneck even when core capacity is adequate. A core is not a finished JF, generator package or mobile engine until fans/free turbines/governors/starters/generators/switchgear/pumps/wiring/package acceptance are available.

### Core-Equivalent Workload (CEW)
Maintain as a future auxiliary metric. One JF consumes one physical core but more total manufacturing/inspection workload than one pure-J because of the LP turbine/fan/control package. Do not fix exact CEW multipliers until shop-hour/process audit.

## Production-ledger rule
Future annual audits should have at least two ledgers:
### Core production
core starts / usable / flight-A / flight-B / ground-mobile / reject-WIP.
### Finished packages
pure-J / JF / E4-equivalent / fixed / mobile / marine-other / unpackaged cores.
