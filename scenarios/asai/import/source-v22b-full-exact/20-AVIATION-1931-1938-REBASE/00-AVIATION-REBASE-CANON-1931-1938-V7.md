# AVIATION REBASE CANON 1931–1938 — V7

This file supersedes V6 chronology where conflicting.

## E4 single
### Single No.1
- first flight: **1932 Q2**;
- Asai-owned;
- ~1.8 t, E4-J 300–330 kgf;
- max ~450–475 km/h, center ~460;
- useful flight 25–35 min;
- long takeoff, weak low-speed thrust/fuel/TBO;
- by end-1937 ~110–150 flights / 100–140 h.

### Single No.2
- first flight **1933 Q2–Q3**;
- Army-funded high-speed military technical test;
- radio/oxygen/armament-equivalent/fuel/climb/dive;
- by end-1937 ~90–120 flights / 80–110 h.

## E4 twin
### Twin No.1
- first flight **1932 Q4**;
- Asai-owned general demo/test;
- 3.6–4.0 t, E4-J ×2, two-seat;
- ~390–400 km/h clean;
- radio/photo/mission bay/fuel-payload trade/one-engine tests;
- end-1937 ~190–230 flights / 230–280 h.

### Twin No.2
- first flight **1933 Q3**;
- Army-funded;
- high-speed photo recon, Manchuria range, cold, altitude, radio, one-engine return;
- end-1937 ~150–190 flights / 210–260 h;
- **deployed North China Jul–Aug 1937** and used operationally.

### Twin No.3
- first flight **1933 Q4–1934 Q1**;
- Navy-funded;
- ocean navigation, high-speed recon, radio, land-based interception, naval maintenance;
- not carrier-capable;
- end-1937 ~125–160 flights / 170–220 h;
- **deployed Shanghai from ~19–20 Aug 1937**, later supports Hangchow Bay/Baimaokou/Nanking-area reconnaissance.

## P0/P1
- P0 donor/conversions 1933–35, 1–2 aircraft; free turbine/gearbox/governor/restart.
- P1 first flight 1935 H2–1936 H1; 3 aircraft by end-1937; fleet 300–450 h. One Asai, one Army/government evaluation, one external/lease.

## E5 single / Ki42
### E5 Single No.1
- design 1934;
- formal military requirement 1935;
- first flight **1936 Q2–Q3**;
- ~2.1–2.3 t, E5-J 430–470 kgf;
- top center ~570, band ~550–590 km/h;
- Army high-speed single-seat military prototype;
- end-1937 ~65–85 flights / 50–70 h.

### E5 Single No.2
- first flight **1937 Q2**;
- fuel/radio/oxygen/weapon weight/CG/brakes/landing/control fixes;
- ~550–575 km/h center;
- end-1937 ~30–45 flights / 25–35 h.

### military designation
- E5 single practical development receives Army **Ki-42** around 1937 Q3;
- 1937 Q4: 4-aircraft service-evaluation batch approved;
- possible 1938 adoption: **Type 98 Single-seat Fighter (Ki-42)**;
- no 1937 nickname.

Working late-1937 Ki42:
- span ~10.1–10.4 m; wing area ~15.8 m²;
- empty ~1.43–1.50 t; normal all-up ~2.00–2.08 t; max ~2.25–2.30 t;
- E5-J ~445–460 kgf;
- internal fuel ~430–470 L;
- wing loading ~127–132 kg/m²;
- T/W ~0.22;
- interim nose 7.7mm×4 class; provision for 12.7–20mm×2 later;
- tricycle landing gear recommended; Kayaba can supply nose oleo/shimmy/hydraulics;
- sea level ~485–495; 3 km ~530–540; 5 km ~555–570; 6 km ~570–580 km/h;
- climb to5 km ~8.5–9 min: top speed excellent, climb poor vs Ki-27;
- takeoff ~470–550 m good surface; safe field ~700–800 m;
- approach ~145 km/h;
- weak sustained low-speed turn; strong 350–500 km/h energy fight / BnZ / vertical;
- strong dive; initial limit Mach ~0.60–0.62.

Army keeps Ki-27 as ordinary agile fighter; Ki42 trends high-speed/interceptor role. 1938 likely Ki42-ko pure J vs otsu JF pressure; JF +15–20% thrust improves climb/takeoff/range but may slightly reduce top speed.

## E5 twin
### No.1 J
- first flight **1937 Q2**;
- two-seat ~3.5–4.0 t, E5-J ×2;
- J-C clean ~545–555; J-R recon ~520–535; J-W mission load ~510–525 km/h;
- end-1937 ~70–90 flights / 80–105 h;
- Navy primary contract, Army formal test slots.

### No.2 JF
- first flight **1937 Q4**;
- aft-fan;
- end-1937 ~15–22 flights / 15–25 h;
- low-speed thrust/takeoff advantage obvious; endurance/fuel finalized 1938.

### Army branches
**Ki40** = high-speed command reconnaissance from E5 Twin J-R; potential Type 98 Command Reconnaissance Aircraft.
- ~3.8–4.0 t;
- 5 km ~520–535, top recon config ~540;
- photo run 5–6 km at 330–380 km/h then escape 500+;
- J endurance ~3.0–3.4 h, ~1000–1250 km;
- JF ~3.7–4.2 h, ~1300–1550 km;
- stable photo platform, not fighter-like handling.

**Ki41** = two-seat high-speed fighter/interceptor.
- ~3.75–3.9 t;
- interim nose 7.7mm×4 + rear7.7×1; structure for heavy cannon;
- J max ~535–550, 5km climb ~7.5–8 min;
- JF ~520–540, climb ~6.5–7 min, better takeoff/range;
- poor turn, strong stable high-speed firing platform; second crew nav/radio/watch;
- one-engine return possible but combat over; JF better one-engine.

**Ki42** = single-seat high-speed fighter.

These recycle historical dead/paper Ki40–42 slots without moving Ki43 onward.

### Navy designations
Asai manufacturer code **As**.
- **J1As** first Asai land fighter (twin);
- **R1As** first Asai land reconnaissance aircraft;
- requirement names roughly 1937 “12-shi twin-engine land fighter” and “12-shi high-speed land reconnaissance.”
No later-war style nickname forced into 1937.

## 1937 operational success → procurement
E4 Twin combat success makes “no extra order” implausible.

Working sequence:
- late Aug–Sep: Army + Navy ask supply capacity;
- Sep–Oct: **E4 Twin additional trial batch ~4 aircraft**, center Army2/Navy2;
- 19 Nov manufacturing state: No.4 final assembly/near ground test, No.5 final assembly, No.6 structure assembly, No.7 structure/equipment prep;
- first additional completion late Nov–Dec, remainder Dec–early1938;
- these aircraft are **not** present for most 1937 battles.

E5 Twin follow-on grows from older 6-aircraft idea to **~8-aircraft development/evaluation contract**:
- Army Ki40×3, Ki41×2;
- Navy R1As×1, J1As×2;
- common structure starts in 1937, no operational squadron in 1937.

Ki42 evaluation batch: **4 aircraft**, manufacturing preparation starts 1937 Q4, flight/service eval in 1938.

## Kayaba
- independent client/collaborator, not Asai airframe branch;
- contact 1934–35; E4-J integration 1935–36;
- one E4-J-powered tailless research aircraft first flight 1937 H2, ~10–25 h by year-end;
- 3–4 E4-J cores supplied total flight/ground/spare;
- Kayaba supplies oleo/hydraulic/damper know-how to Asai;
- ramjet 1937 remains ground rig; no flight ramjet;
- Asai sells engines/services but protects compressor/turbine IP.
