# PHOTO METADATA / PUNCHED-CARD WORKFLOW — PLAUSIBILITY NOTE

## Closed conceptual ruling
The good 1930s solution is **not** to punch machine-readable holes directly into aerial negatives as the main data system.

Instead use three layers:
1. **Film = primary evidence + exposure metadata**. A small data chamber optically exposes frame ID / time / altitude / camera or similar instrument data into the frame margin.
2. **Punch card = searchable index metadata**. The same unique frame ID keys a card with mission, strip, frame, time, altitude, camera/lens, map sheet/grid, quality and later human interpretation tags.
3. **Map/overlay = spatial index**.

A Fairchild K-3A-class camera historically had an automatic instrument data recorder concept; therefore the basic idea is period-plausible. The Asai contribution is the interface/workflow, not inventing photography.

## Why not film perforation as the main data key
- edge area and fiducial/reference geometry matter;
- film is mechanically worse than cards as a punched-data medium;
- physical punch coding does not propagate naturally into ordinary prints/copies;
- optical data in the negative margin copies with the image.

## Automation limit
1937 aircraft should not automatically digitize every analog gauge into punch code. That would require fragile/heavy encoders/transducers.

Better:
- shutter contact increments frame counter;
- data chamber exposes clock/altimeter/ID scales or plates;
- optional event pulse can mark paper tape/log;
- ground staff transcribes/validates into punch cards after processing.

## Asai role versus other companies
Asai is **not a photography company**.

Likely division of labor:
- optics/camera/lens: Nippon Kogaku and similar firms;
- film/sensitized material/chemistry/photo supplies: Konishiroku and similar firms;
- military photo interpretation/maps/distribution: Army/Navy photo/survey organizations;
- radios: designated electrical/communications firms;
- Asai: aircraft/platform integration, camera mount/vibration/window, power, shutter/flight-record interface, instrumentation, ground support, special vehicle platform, workflow/index integration.

A mobile photo-processing truck can use an existing truck chassis plus Asai power/water/temperature/ventilation/vibration/layout package while the photo equipment inside is supplied by specialists.

## Military significance
The machine does not “recognize” photos. Human interpreters do.

The information-processing gain is retrieval/comparison:
“show me yesterday and today for grid G17, long-focus only, usable quality” can be found by sorting cards and retrieving matching negatives/prints.

This enables faster human change detection without anachronistic computer vision.
