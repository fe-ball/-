# AIRCRAFT RESEARCH QUARANTINE RULES — V11

## Purpose
Old aircraft branches are valuable provenance but dangerous current authority. V11 creates a hard quarantine so rediscovered concepts can be re-tested without silently restoring stale numbers, names or OOB.

## Quarantine location
`91-PROVENANCE-QUARANTINED-AIRCRAFT-RESEARCH-V11/`

Files there are not current even when their text uses words such as current, canonical, closed, confirmed, or authority. Those labels only describe the historical state of the old branch in which the file was written.

## Allowed use
- recover a forgotten requirement or design question;
- identify a possible institutional/customer-development path;
- identify geometry, configuration, material or mission hypotheses to re-test;
- compare why a branch was later cut;
- locate nomenclature conflicts.

## Forbidden automatic restoration
Do not automatically restore:
- old E5/E6/E7 engine output or thrust values;
- aircraft speed, range, climb, weight or deck-performance values;
- old procurement, service dates, combat release or OOB;
- type/model suffixes such as Ichiichi/Niichi/Sanichi merely because an old table used them;
- `Ki-40` or other old allocation/evaluation labels as present formal designations;
- A7M/A8N/J2N formal codes into research dates earlier than their formal gates;
- E5 Gaifu as a 1940 mass carrier-fighter mainstay;
- a dedicated 1941 J2N airframe solely because an old branch contained one.

## Restoration chain
A quarantined item returns only by passing, in order:
1. current propulsion/material H->A check;
2. development-history plausibility;
3. customer requirement / institutional sponsor;
4. prototype or formal program gate;
5. nomenclature/numbering gate;
6. production/service gate;
7. combat allocation/replay gate if applicable.

No later gate can be used to back-date an earlier one.

## Protected identity is not retroactive naming
V11 preserves the existing identity relationships A7M=Gaifu, A8N=Sakufu and J2N=Hekireki where prior current guidance protects them. This does not mean an X-aircraft in 1938 already carried that formal code or service name.
