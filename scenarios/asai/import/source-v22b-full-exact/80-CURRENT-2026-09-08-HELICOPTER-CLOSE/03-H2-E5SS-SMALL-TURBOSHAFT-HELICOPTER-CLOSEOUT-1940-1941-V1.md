# H2 SMALL TURBOSHAFT HELICOPTER CLOSEOUT — 1940-1941

`H2` is a V13 audit label, not a military designation.

## 1. Powerplant — E5-S-S small-edge product

V13 promotes the recovered small-shaft product into the current prewar helicopter closeout:

| item | V13 close |
|---|---:|
| generation/role | E5-derived small-edge turboshaft |
| mass flow | ~2.5 kg/s |
| pressure ratio | ~5.0-5.5 |
| TIT | ~760-780 C |
| hot-section policy | non-Ni standard; temperature reduced for life |
| normal power | **330 shp** |
| short power | **360 shp** |
| dry engine | **~120-140 kg** |
| thermal efficiency | ~18.5-20% |
| SFC | **~0.42-0.45 kg/kWh** |
| output architecture | free power turbine, ~8,000-10,000 rpm output-side class |

The helicopter main gearbox, mast, freewheel and tail-drive split are **not included** in the engine dry mass.

## 2. H2 airframe

| item | V13 close |

| architecture | single main rotor + tail rotor |
| main rotor | **three-blade articulated, 11.2 m** |

| growth/test maximum | **~1,400 kg** |

| normal crew | two |
| maximum short mission | **three persons OR one litter + attendant** |

## 3. Transmission and controls

- aircraft-side overall main reduction: **~35-40:1** from engine output to ~230 rpm rotor;
- main gearbox + freewheel + tail takeoff: working **~125 kg**;
- tail transmission/shaft/bearings/tail rotor: working **~40 kg**;
- conventional mechanical cyclic/collective/pedals remain standard;
- no standard hydraulic flight-control boost;
- a mechanical/hydromechanical governor is allowed for rotor-speed management;
- electronics remain measurement/diagnostic support rather than primary stabilization.

## 4. Performance

| item | V13 close |
|---|---:|
| maximum speed | **140-150 km/h** |
| cruise | **105-115 km/h** |
| practical endurance | **1.8-2.0 h** |
| practical range | **180-220 km** |
| climb | **2-3 m/s class** |
| useful altitude | **~2,500-3,000 m class** |
| armament | none |

At 1,350 kg and 11.2 m rotor diameter, adopted early-rotor efficiency bookkeeping gives ~265-305 shp engine-side hover demand after main-rotor, tail-rotor and transmission losses. Thus 330 shp normal is viable but not excessive; 360 shp short is hot/high, takeoff, climb and upper-weight margin rather than a continuous rating.

## 5. Mission configuration

Army evaluation:
- two-person liaison + radio;
- three-person short-distance carriage;
- litter + attendant;
- observer insertion/recovery;
- rough-terrain/limited high-ground landing tests.

Navy evaluation:
- two-person launch + one rescued survivor return;
- simple rescue hoist;
- naval radio;
- emergency flotation;
- corrosion protection;
- deck tie-down provisions;
- large-deck/support-ship trials first.

## 6. Closed development clock

- 1938-39: small-flow shaft-core design work;
- 1939-40: shaft/rotor-drive mule and component work;
- 1940: E5-S-S bench program;
- 1940H2: H2 tethered-hover/ground-integration band;
- **1941Q1: first free-flight band**;
- 1941Q2-Q4: repeated flight, autorotation, Army/Navy mission and transmission/durability trials;
- 1941YE: prototype/mission-test stage only; **no ordinary service release**.

Exact serial first-flight days and completed service TBO remain intentional opens.
