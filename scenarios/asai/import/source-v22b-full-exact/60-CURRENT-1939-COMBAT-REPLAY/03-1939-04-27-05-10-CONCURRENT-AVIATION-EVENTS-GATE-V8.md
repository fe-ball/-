## 2. HS-2 — first flight

Apr20 state: one complete pre-flight airframe with E6-S-J installed, ground/high-speed-taxi release band, initial ~475 kgf standard-flow rating.

### Event ruling

**1939-05-04: HS-2 completes first flight.**

Initial sortie:

- E6-S-J standard ~475 kgf point;
- approximately 15-18 min;
- landing gear and basic handling checks;
- Mach kept below ~0.45;
- no attempt to approach the planned M0.6+ research envelope;

Result: **PASS for initial flight release.** The sortie identifies only local calibration/trim work: pitot/static correlation, small left-right intake/trim asymmetry and instrumentation-zero corrections are addressed before envelope expansion. No compressor-surge or structural-flutter event is promoted.

Current HS-2 state at May10:
