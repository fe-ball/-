# Type 91 aerial torpedo / delivery-system consolidation

## Existing V10 authority retained

The V10 aerial-torpedo lineage remains current:

- 1938H2 E5 Twin torpedo-carriage work;
- 1939 2–4 E5 test aircraft for low-level/drop/sighting trials;
- 1940Q1 G4As practical trials;
- G4As combat qualification from September 1940.

G4As carries one ~45 cm Type 91 in a semi-recessed bay. Early terminal deceleration is used until the high-speed release envelope matures.

## Type 91 qualification

Working/canon bands retained from V10:

- 1940 high-speed goal ~390–430 km/h;
- 1941 Mod 2 normal qualification ~400–430 km/h;
- selected test points ~450 km/h;
- late-1941 correct-release entry reliability: Mod1 ~95–98%, Mod2 normal ~96–99%, Mod2 400–430 ~94–97%, selected 450 ~90–94%.

Historical Type 91 also progressed toward high-speed drops; worldline difference is earlier, more systematic requirement/measurement and platform integration.

## Common vs unique hardware

Shared with Type 93/95 where sensible:

- gyro/depth/steering QC;
- gauges and lot tracking;
- machining and acceptance discipline.

Not shared:

- oxygen propulsion system (Type 91 is not an oxygen-engine derivative);
- air-water entry physics;
- roll/pitch stabilization and release envelope are aerial-branch-specific.

## Platform interpretation

- G4As normal torpedo radius about 300–400 km, favorable 350–450 km working band.
- G4M reaches much farther but is slower.
- B5N keeps carrier flexibility.
- High-speed release mainly reduces threat exposure and compresses the enemy reaction window; it does not increase the torpedo's underwater range.
