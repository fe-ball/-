# 1942 REQUIREMENT / PROCUREMENT REPLAY GATE — V8

> Future gate card. Do not use this file to backflow 1942 decisions into the 1939–41 replay.

## Questions to resolve when clock reaches the gate

For each major aircraft/engine program:

1. What operational experience actually exists by 1942?
2. Which threats have been observed?
3. Which requirements are historical, moved, cancelled or regenerated?
4. What engines are physically available EA-D/Q/S?
5. What production lines/tooling are free?
6. What pilot/maintenance/base infrastructure exists?
7. What is the relative cost of piston vs turbine alternatives?
8. Which older aircraft remain adequate and cheap?

## Do not auto-import

- Pacific War historical losses;
- historical emergency production priorities;
- historical carrier losses;
- historical high-altitude B-29 requirement timing;
- late-war desperate interceptor requirements;
- historical material shortages unless worldline politics/logistics create them.

## Use difference-led history

Start from historical requirement/procurement only where unaffected, then apply worldline causal deltas.
