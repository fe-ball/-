# HOMARE QUARTERLY DEVELOPMENT / QUALIFICATION CANON — V8 AIRPOWER3

> **AIRPOWER3 current Homare quarter-by-quarter authority through 1943Q1.** This file refines the broader Homare audit with explicit maturity gates. It does not close later war production quantities.

## 0. Status semantics

Use:

- concept/design;
- component rig;
- full-engine development;
- endurance-qualified development;
- pilot/pre-series;
- production release;
- series-repeatable;
- service-qualified;
- fleet field reliability.

These are not the same event.

## 1. 1939Q4

High-power compact radial requirement/concept work is active. Nakajima can use mature Asai-origin test/QC methods already transferred. No Homare engine exists yet.

## 2. 1940Q1

Formal design begins in earnest.

Key worldline addition is design of the **test architecture** concurrently:

- bearing/rod/crank rigs;
- supercharger maps;
- mixture/temperature instrumentation;
- multi-fuel/ADI maps;
- domestic-oil tests;
- torsion/vibration;
- production CTQ/acceptance plan.

## 3. 1940Q2

Component drawings, castings/forgings/tooling and rigs progress. Early production-sensitive geometry is identified as a first-class risk.

## 4. 1940Q3

Full-engine assembly/test preparation. Subsystem rigs produce measured corrections. Unknown local defects still appear; foreknowledge does not remove workmanship/material reality.

## 5. 1940Q4

First full-engine hardware approaches running state. No service rating yet.

## 6. 1941Q1

First-running engines.

Objectives:

- establish base map;
- verify oil/scavenge/aeration;
- find hot cylinders;
- measure torsion/vibration;
- begin bearing/rod/crank teardown cycle.

Not squadron-ready.

## 7. 1941Q2

Development achieves ~1,800 hp class under controlled conditions and completes a long endurance target around the historical 300-hour development-test concept.

This is **development endurance**, not 300h fleet TBO.

Selected ~2,000 hp development branch opens.

## 8. 1941Q3

Low-octane/ADI and domestic-oil qualification deepens. Bearing geometry/finish/clearance/process corrections become production drawings/gauges rather than shop lore.

Altitude/supercharger map expands.

## 9. 1941Q4

Full-engine qualification package is substantially stable for the 1,800 hp-class branch. Supplier/tooling/acceptance process is being hardened.

Still not mass service.

## 10. 1942Q1

Pilot/pre-series engines; aircraft development allocation possible under EA-D/limited EA-Q conditions.

Production workers/process need real learning; do not call it mature mass production.

## 11. 1942Q2

Priority aircraft programs can receive credible ~1,800 hp-class development/service-trial engines.

10/12-series transition toward repeatability.

## 12. 1942Q3

Formal main production window.

Production release does not mean every unit/lot meets the best rating. Acceptance/rework/derating states matter.

## 13. 1942Q4

Early-series stabilization. ~2,000 hp-class 20/21 qualification proceeds, with high-altitude performance improving.

## 14. 1943Q1

Technically mature/reproducible good-engine specification exists.

Representative qualified good-engine envelope:

- takeoff/emergency ~1,950–2,000 hp;
- low-altitude rated ~1,800+ hp;
- near ~6 km ~1,600–1,680 hp, center ~1,640–1,650.

This does not close national output, average field TBO or degraded wartime supply.

## 15. Production-quality states

At any quarter distinguish:

- best development engine;
- accepted production engine;
- derated/rework engine;
- field service engine.

Do not use the best engine as the fleet average.

## 16. Integration gates

Aircraft must separately close:

- propeller;
- cooling/cowling;
- oil;
- exhaust;
- mount/CG;
- fuel map;
- vibration.

Homare maturity is necessary but not sufficient.

## 17. No future backflow

Later Ki-84/N1K/J2M/P1Y success or failure is not evidence of what engineers know in 1940–41 beyond the explicitly prepaid methods. Use later aircraft only as calibration when technically appropriate.
