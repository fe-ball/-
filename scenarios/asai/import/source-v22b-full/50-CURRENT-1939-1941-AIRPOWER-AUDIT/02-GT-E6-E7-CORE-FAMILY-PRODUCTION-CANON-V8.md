# GT E6 / E7 CORE FAMILY PRODUCTION CANON — V8 AIRPOWER2

> **AIRPOWER2 current GT family/production authority.** This file closes the pre-1941 E6/E7 core-family production semantics and prevents product-count inflation caused by treating every backend/rating as a separate full gas-generator line.

## 0. Core architecture rule

Separate:

- **gas-generator core scale/technology**;
- **backend** (shaft, pure jet, aft-fan/free-turbine, reheat/variable nozzle, etc.);
- **rating/material line**;
- **installed product**;
- **aircraft type**.

A J and JF using the same core are not two independent core industries.

## 1. E6 family center

Current E6-M accepted architecture:

- single gas-generator family;
- pure-J backend available;
- aft-fan/free-LP-turbine backend available;
- product ratings and material lines vary without automatically requiring a new core production line.

The principal industrial bottlenecks split into:

1. shared core: compressor, combustor, main turbine, shaft/bearings, core casing;
2. backend: nozzle/jet pipe vs free turbine/fan/duct/control;
3. auxiliaries: fuel/governor, starter, generator, pumps, filter, wiring/panel;
4. aircraft installation.

Therefore count cores, backend modules and complete installed packages separately.

## 2. 1939–40 facility implication

The T-works expansion should be read as flexible family capacity, not “one plant = one engine model.”

- T-1 mature processing supports E5/E6-family learning and lower-volume output.
- T-2 qualification in 1939 opens additional repeatable flight-grade processing.
- T-3 1940 qualification expands production-flow capacity.
- T-4 1940Q3-Q4 qualification / 1941H1 maturity is the large volume step.
- T-AUX removes non-core package bottlenecks progressively.

Do not multiply these capacities by number of variants.

## 3. E6 product accounting

For an aircraft requiring one E6-M package:

`1 shared gas-generator core + 1 backend package + auxiliaries + installation`

For Twin:

`2 cores + 2 backends + aircraft-specific controls/accessories`

Spare-engine policy must specify whether a spare is:

- complete installed package;
- bare core;
- backend module;
- depot repair pool.

A “20% spare engines” statement is meaningless unless this is clarified.

## 4. E7 chronology

Retained integrated E7 schedule:

- 1939 component/rig work;
- 1940H1 compressor/hot-section rigs;
- 1940H2 integrated gas-generator demonstrator;
- 1941H1 full-core ground development;
- 1941H2 ground-qualified development core / inherited aft-fan advanced-ground or limited flight candidate;
- earliest dedicated E7 aircraft 1942Q1-Q2 target.

This is an integrated-product clock. VSV, multi-spool, advanced cooling and other enabling branches may have earlier research roots but do not imply a complete E7 engine in 1939.

## 5. Production transition E6 -> E7

E7 does not instantly displace E6.

Early E7 production/qualification consumes:

- best precision machining;
- balancing/metrology;
- high-temperature material/heat treatment;
- development test cells;
- senior engineering attention.

Therefore, during early E7 development, mature E6 production may remain the volume military product. This is especially likely when E6 already meets operational needs and E7's first use is development aircraft or premium interception.

## 6. Backward process improvement

E7 development may improve E6 production by transferring:

- tighter process control;
- better balancing;
- improved coating/heat-treatment practice;
- inspection methods;
- bearing/seal production;
- fuel/governor acceptance.

This does not turn E6 into E7. It may increase E6 life/yield/repeatability while retaining E6 performance/rating.

## 7. Procurement guard

Technical capacity does not create military orders. Aircraft orders must close:

- requirement;
- cost;
- competing piston/turbine alternatives;
- pilot/maintenance training;
- base/logistics suitability;
- production priority.

E6 core capacity must not be counted twice across Single, Twin, bomber and export/license packages.
