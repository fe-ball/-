# PRE-BRANCH HOMARE / HA-43 AIRFRAME INTEGRATION CANON — V8 AIRPOWER4

> **AIRPOWER4 current pre-branch airframe-engine integration authority.** This file does not decide later procurement. It closes what aircraft developers can physically test through 1943Q1 given the engine calendars already accepted.

## 0. Core rule

An aircraft project can integrate only an engine that actually exists at the relevant development grade.

Use:

- EA-D development-flight engine;
- EA-Q service-qualified engine;
- EA-S series-repeatable engine;
- PA-D/Q/S propeller;
- CI-D/Q/S cooling/oil installation.

## 1. Homare integration clock

### 1941
Homare is engine-development hardware. No ordinary squadron aircraft integration.

### 1942Q1
Pilot/pre-series engines may support ground installation/mockup and selected development aircraft preparation.

### 1942Q2
Credible ~1,800 hp-class EA-D engines can fly on priority development aircraft after mount/prop/cooling gates.

### 1942Q3-Q4
10/12-series engine availability supports serious aircraft programs. 20/21 ~2,000 hp branch remains selected development/qualification.

### 1943Q1
Good 20/21-class engines may support prototypes/service trials; series allocation remains branch-dependent.

## 2. Ha-43 integration clock

### 1941
Design/component work only. Aircraft teams may do paper/mockup envelopes based on predicted size/mass.

### 1942Q1
First-running development engine center. Ground installation development possible.

### 1942H2
Selected EA-D aircraft engines plausible if development stays healthy. This supports prototype flight work, not production aircraft.

### 1943Q1
Strong development/qualification engine. Aircraft service introduction still depends on local program and procurement.

## 3. Fighter program implications

### Ki-44/J2M generation
Earlier high-power radial integration knowledge may improve cooling/prop/exhaust testing, but these programs cannot use Homare/Ha-43 before engines exist.

### Ki-84/N1K/J2M later growth
Do not backflow late powerplants. Their prototypes may benefit because engine/prop/cooling integration is healthier when their historical-like requirements arise.

### Reppu-line identity warning
Historical Reppu A7M data are not bare worldline A7M under the identity guard; use the local designation map before comparing.

## 4. Bomber/attack program implications

Large aircraft may absorb engine weight/diameter more easily, but endurance/fuel/cooling demands are higher. A development engine does not become a bomber service engine merely because installation volume exists.

## 5. Cooling/propeller simultaneous gate

A flight article with a new engine must reserve:

- propeller combination;
- cowling/baffle/oil cooler;
- exhaust installation;
- fuel/oil/control equipment;
- CG/mount structure.

If any are development grade, the aircraft is a development article.

## 6. No procurement closure

This file authorizes technically plausible prototype integration windows only. It does not select winners, order quantities or cancel historical programs.
