# OPEN — SHIDEN / AUTO COMBAT FLAP / ASAI AUTOMATION — V8

> This is an open technical problem, not a closed aircraft result. It records what may be available upstream and what remains to be paid later.

## 0. Question

Could Asai's earlier computation/electromechanical/control work accelerate the automatic combat-flap concept later associated with Shiden/Shiden-Kai?

Answer: **the control concept and component/test infrastructure can be early; a mature production automatic combat-flap system is not automatically present in 1939.**

## 1. Upstream capability potentially relevant

By late 1930s the worldline may already possess:

- reliable relays/solenoids/electromechanical logic;
- airspeed/pressure sensing and calibration;
- hydraulic actuator experience;
- analog/mechanical calculation methods;
- repeated instrumentation and data reduction;
- aircraft flap/gear hydraulic hardware;
- vibration/environmental testing;
- production QC.

This makes a simple automatic schedule technically plausible earlier than history if a requirement arises.

## 2. What still must be paid

A combat-flap system requires aircraft-specific closure of:

- desired lift/drag schedule vs speed/normal acceleration;
- sensor accuracy and lag;
- actuator response and hydraulic capacity;
- stability/handling when flaps move automatically;
- pilot override and failure mode;
- structural loads/fatigue;
- combat maneuver testing;
- maintenance/reliability;
- production repeatability.

The hard part is not inventing “automatic flaps”; it is making them safe and tactically useful over the aircraft envelope.

## 3. 1939 state

No blanket production automatic combat flap is closed.

Allowed state:

- concept understood;
- simple ground/flight experimental controller possible;
- instrumentation/control competence exists;
- if a fighter project has a strong low-speed/turn requirement, an explicit experimental branch may be opened.

Not allowed:

- all fighters magically receiving automatic combat flaps;
- Shiden later combat system backflowing unchanged into 1939;
- fixed turn-rate bonus without an aircraft-specific aerodynamic/load test.

## 4. Future trigger

Reopen when:

- a specific fighter requirement calls for maneuver lift beyond ordinary manual flap doctrine;
- wing loading rises enough that combat flap becomes attractive;
- hydraulic/electrical margin is available;
- test aircraft/time can be funded.

Until then this remains **OPEN capability**, not adopted equipment.
