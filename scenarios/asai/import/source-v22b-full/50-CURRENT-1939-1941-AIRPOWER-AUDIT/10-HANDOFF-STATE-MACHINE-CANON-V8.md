# HANDOFF STATE MACHINE CANON — V8

## Purpose

Define a compact state-machine vocabulary for technical handoffs so later chats do not confuse research, production and deployment.

## Generic product states

- **R0 concept:** architecture/idea only.
- **R1 component/rig:** physical subsystem rigs/coupons.
- **R2 integrated prototype:** working integrated article.
- **R3 qualification:** representative endurance/environment/acceptance work.
- **R4 production release:** drawings/process/acceptance stable enough for repeat production.
- **R5 service qualification:** service operating/maintenance/training package approved.
- **R6 serial service:** repeat procurement plus fielded units.

Local domain taxonomies may supersede these names; use this only as a bridge.

## Aircraft

Keep separate:

- airframe first flight;
- engine installation qualification;
- military acceptance;
- production acceptance;
- unit conversion;
- combat readiness.

## Engine

Keep separate EA-D / EA-Q / EA-S and local endurance/production states.

## Research generation

A technology-generation coordinate such as E7/E8 is not itself one of these maturity states. An E7 component can be R1 while an E6 service product is R6.

## Handoff rule

When passing to another chat, state:

- date;
- article/version;
- technical maturity;
- quantity physically existing;
- production capacity/order;
- allocation;
- serviceability;
- open gates.

Do not summarize only with “available.”
